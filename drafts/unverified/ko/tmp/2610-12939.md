# Surfing the Activation Wave: Analyzing the Information and Geometry of LLM Hidden States for Speculative Decoding

**Source**: Goel et al., arXiv, 2026-10-09

**Lead**: Speculative decoding accelerates LLM inference by using a fast draft model to propose tokens that a larger target model verifies. Current draft models are either small separate models or n-gram predictors that ignore the target model's internal state. This paper shows that the target model's own hidden states contain predictable "activation waves"—low-dimensional trajectory structure that can be extrapolated to generate high-quality draft tokens without any auxiliary model.

## Background

Autoregressive decoding is bottlenecked by sequential token generation: each token requires a full forward pass through the model. Speculative decoding mitigates this by generating draft tokens cheaply and verifying them in batch with the target model. The speedup depends critically on the draft model's acceptance rate. Existing approaches use: (a) small draft models (e.g., 1/10th the size) trained to mimic the target, requiring extra training and storage; (b) n-gram or retrieval-based drafters that ignore the target's current context; or (c) self-speculation using early-exit layers, which still requires architectural modifications.

The key insight: during autoregressive generation, the target model's hidden states evolve along structured trajectories in activation space. If these trajectories are predictable, the model can "surf" its own activation wave to draft future tokens.

## Activation Wave Discovery

**Hidden State Trajectories**: For each layer, the authors track the hidden state vector h_t at each generation step t. They find that across diverse prompts and models (Llama-3, Qwen-2, Gemma-2), the sequence {h_t} lies close to a low-dimensional manifold. Principal component analysis reveals that 3–5 principal components explain >85% of variance in hidden state evolution.

**Wave-like Dynamics**: The principal component coefficients follow smooth, wave-like curves—approximately sinusoidal with slowly varying frequency and amplitude. This regularity holds across layers, though deeper layers show higher-frequency oscillations. The wave structure emerges from the attention mechanism's recurrent-like dynamics: each token's representation is a weighted combination of previous representations, creating a dynamical system with stable attractors.

**Predictability**: Given the last k hidden states, a simple linear extrapolation (or a tiny MLP) predicts h_{t+1} with cosine similarity >0.95. The prediction error grows slowly with horizon, enabling 5–10 step lookahead.

## SurfSpec: Surfing the Activation Wave for Speculative Decoding

**Draft Generation**: At each verification step, the target model runs a forward pass to get h_t. Instead of waiting for the next token, a lightweight predictor (a 2-layer MLP per layer, ~0.1% of model params) extrapolates the next 5–10 hidden states. These predicted states are decoded to draft tokens via the target's output head (unembedding matrix).

**Verification**: The target model verifies the draft sequence in one batched forward pass (standard speculative decoding). Accepted tokens are committed; on rejection, the pipeline falls back to standard autoregressive generation for that step.

**Training the Predictor**: The MLP predictors are trained on-the-fly during a short warmup phase (100–500 tokens) using the target model's own hidden states as supervision. No external data or separate training run is needed. The predictors adapt to the specific prompt and generation context.

## Experiments

**Setup**: Models: Llama-3-8B, Qwen-2-7B, Gemma-2-9B. Benchmarks: MT-Bench, HumanEval, GSM8K, LongBench. Baselines: standard autoregressive, small draft model (1/10 size), n-gram draft, early-exit self-speculation. Metrics: acceptance rate, tokens/sec speedup, output quality (exact match on benchmarks).

**Results**:

| Model | Method | Acceptance Rate | Speedup | Quality (MT-Bench) |
|-------|--------|----------------|---------|-------------------|
| Llama-3-8B | Autoregressive | — | 1.00× | 8.42 |
| Llama-3-8B | Small draft (800M) | 0.68 | 1.85× | 8.35 |
| Llama-3-8B | SurfSpec (5-step) | **0.82** | **2.31×** | **8.44** |
| Llama-3-8B | SurfSpec (10-step) | 0.74 | 2.68× | 8.41 |
| Qwen-2-7B | SurfSpec (5-step) | 0.79 | 2.18× | 8.17 |
| Gemma-2-9B | SurfSpec (5-step) | 0.76 | 2.05× | 8.03 |

**Key Findings**:
- SurfSpec achieves higher acceptance rates than separate draft models because the predicted hidden states are from the *same* model, eliminating distribution mismatch.
- The 5-step lookahead hits the sweet spot: longer horizons increase per-step latency (larger batch verification) without proportional acceptance gains.
- On long-context tasks (LongBench), SurfSpec maintains speedup because the wave structure persists; small draft models degrade as context grows.
- The on-the-fly predictor training adds <2% overhead and converges in ~200 tokens.

**Ablations**: 
- Linear extrapolation alone achieves 0.71 acceptance (vs. 0.82 with MLP), showing the wave is largely linear but benefits from nonlinear correction.
- Predicting only the final layer's hidden state (vs. all layers) drops acceptance to 0.68—multi-layer prediction captures cross-layer dependencies.
- Removing on-the-fly adaptation (using pre-trained predictors) reduces acceptance by 8–12%, confirming context-specific dynamics matter.

## Relevance to Software Engineers

- **Zero-overhead speculative decoding**: SurfSpec needs no extra model weights, no architectural changes, and no external training data. It can be dropped into any transformer-based LLM serving stack (vLLM, SGLang, TensorRT-LLM) as a plugin.
- **Activation geometry as a diagnostic**: The wave structure (dimensionality, predictability, frequency) correlates with model quality and task difficulty. Monitoring it in production could detect distribution shift or degradation.
- **Extends to any token generation**: The same principle applies to diffusion models (predicting latents), video generation (predicting frame latents), and multi-modal models—the activation wave is a general property of autoregressive latent dynamics.
- **Hardware-friendly**: The predictor MLPs are tiny and can run on the same GPU/TPU with negligible memory/compute overhead. The batched verification step is already optimized in modern serving engines.
