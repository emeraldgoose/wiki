# Do We Need an LLM to Know Why Sources Conflict? Decision Models for Knowledge-Conflict Typing in RAG

**Source**: [arXiv:2610.36915](https://arxiv.org/abs/2610.36915) · **Published**: 2026-10-27
**Authors**: Parv Khatri, Harshul Jain, Mehak Kapoor, Tanya Sah

## Overview

When retrieved sources disagree, the appropriate response depends on why they disagree. Multiple valid answers, contested topics, stale information, and false sources each call for different behavior. Prior work showed that telling a generator the conflict type improves responses by roughly 24 points, but predicting the type is itself hard. This study asks whether typed decision models, which return probabilities over fixed options in one forward pass rather than generating text, can classify such conflicts quickly and cheaply. Under the original benchmark prompt, most evaluated decision models match or exceed a strong baseline's accuracy at substantially lower billed cost and latency. Cascading low-confidence predictions to a stronger model further improves the quality-cost trade-off.

## Key points

- Knowledge conflict type determines appropriate answer behavior.
- Decision models avoid text generation for fixed classification.
- They can match or beat a strong LLM baseline on several settings.
- Most evaluated models have much lower billed cost and latency.
- A cascading strategy sends only low-confidence queries upward.
- The cascade yields favorable quality-cost trade-offs.

## Details

The prompt is used verbatim from prior work, enabling direct comparability, but the evaluation scope is limited to one benchmark and one cascade construction. Confidence scores may miss some systematic errors, and routing policy quality directly affects the measured trade-off. Still, the study shows text generation is unnecessary for many conflict-typing decisions in retrieval pipelines.
