# Scaling Lean Theorem Proving for Real-World Code Verification

**Source**: [arXiv:2610.38174](https://arxiv.org/abs/2610.38174) · **Published**: 2026-10-28
**Authors**: Debargha Ganguly

## Overview

This paper presents EasyProver, a Lean proving system built from recursive agents with isolated contexts, asynchronous search, parallel tactic probing, and an elastic elaboration service. Using an off-the-shelf frontier model with no additional training, it proves 669 of 672 PutnamBench problems, all six IMO 2026 formalizations, resolves 597 of 600 NTP4VC verification conditions, and all 189 VERINA tasks by proof or refutation. Because these benchmarks are close to saturation, the paper also introduces Aegis, which converts competitive programming problems into much harder verification tasks over real implementations. Its pipeline writes safe Rust solutions, translates them into Lean with Aeneas, generates specifications, and labels each frozen statement with a kernel-checked proof or refutation. Aegis produces 2,045 differentially validated Rust-Lean program pairs and 11,533 candidate specifications. Unlike hand-written benchmarks, these tasks carry implementation-level obligations from fixed-width arithmetic, explicit failure, generated loops, casts, and functionalized mutation. On a stratified sample of 2,000 statements, EasyProver proves 1,054 (52.7%) within a 30-minute budget per statement. The same tasks can benchmark other provers and serve as rewards for reinforcement learning.

## Key points

- EasyProver is a Lean system with recursive agents, async search, parallel tactic probing, and elastic elaboration.
- It proved 669/672 PutnamBench problems and all six IMO 2026 formalizations.
- It resolved 597/600 NTP4VC conditions and all 189 VERINA tasks.
- Aegis converts competitive-programming problems into harder Rust/Lean verification tasks.
- It produced 2,045 Rust-Lean program pairs and 11,533 candidate specifications.
- On 2,000 sampled statements, EasyProver proved 1,054 within 30 minutes each.
