# Single-Transformer Latent Diffusion

**Source**: [arXiv:2611.29064](https://arxiv.org/abs/2611.29064) · **Published**: 2026-11-21 (v1)
**Authors**: Hao-Yu Hsu, Shenlong Wang, Alexander G. Schwing

## Overview

Latent generative models usually train three separate networks — an encoder that tokenizes pixels into latents, a generator that models the latent distribution, and a decoder that maps latents back to pixels — typically in stages, with the autoencoder frozen before the generator is fit. UNITE recently merged encoder and generator into one generative encoder trained in a single stage, but its decoder is still a separate network. This paper asks whether the decoder can be folded in as well, so that a single diffusion transformer (DiT) encodes, generates, and decodes.

The naive answer — letting UNITE's shared backbone decode as a third mode with learned readout tokens (UNITE++) — does not work: at ~215M parameters it matches UNITE on gFID (2.24 vs 2.23) but reconstructs much worse (rFID 2.20 vs 1.41), because latent readouts have no fixed spatial correspondence to image locations, forcing every pixel to gather its content from latents through attention. What makes full sharing work is to cast all three modes as position-aligned sequence maps over one fully shared backbone: the pixel patch, latent token, and noised latent token at sequence index i all refer to the same image location (K = N, one latent token per patch), each pass is length N+1 with a learned mode token (q_enc / q_gen / q_dec) prepended at position 0, and modes are separated only by that token, lightweight input/output heads (four projection heads, of which only the pixel output head is new), and AdaLN conditioning on (timestep, class).

Two timestep choices matter. Encoding reads clean image patches, so its timestep is the clean endpoint t_enc = 1 (with readouts it had to be t_enc = 0, matching the noise the readouts start from). Decoding also reads a clean latent, but at t = 1 the modes conflict on the output — encoding and generation produce the clean latent while decoding produces pixels, and near the clean endpoint the generation and decoding inputs are nearly identical, so the last blocks must serve two output spaces (layer-wise CKA between encoding and generation passes drops to 0.37 at t = 0.995 when decoding at t = 1). Giving decoding its own learned timestep embedding t_dec = -1 (outside [0,1]) removes the conflict (last-block CKA stays 0.92–0.93) and yields the best results. Training is a single stage from scratch with only a reconstruction loss (L1 + LPIPS on a slightly noised latent, for robustness) and a flow-matching loss that predicts the clean latent with stop-gradient on both target and input; no adversarial losses and no pretrained encoders (e.g., DINO). Mode-specific parameters (heads, mode tokens, decoding timestep) are 1.63% of Base parameters.

## Key points

- ImageNet-1K 256x256, matched sizes, 200 epochs, mean over five seeds, best CFG: UNIFIED (t_dec = -1) beats UNITE at all three sizes — Tiny 62M: gFID 2.78 vs 3.00 (IS 280.1 vs 272.4); Small 116M: 2.43 vs 2.76 (IS 295.9 vs 283.9); Base 215M: 2.08 vs 2.23 (IS 314.4 vs 282.1), with rFID 0.95 vs 1.41. Tiny UNIFIED (62M) nearly matches Small UNITE (117M, 2.76) with half the parameters.
- Ablation path at Base (Table 3): UNITE++ (readouts, t_enc=0, t_dec=1): gFID 2.24 / rFID 2.20. Position alignment alone (t_enc=0, t_dec=1): gFID 2.31 / rFID 1.39 — reconstruction fixed, generation worse due to timestep mismatch. t_enc=1 + t_dec=1: 2.15 / 0.97. t_enc=1 + t_dec=-1: 2.08 / 0.95 — each design choice isolated.
- Against published models under 250M parameters (Table 4), UNIFIED-B (215M, gFID 2.08, IS 314.4) is the lowest gFID with no pretrained autoencoder and no vision foundation model, trained only 200 epochs vs 600 for pixel-space baselines; UNIFIED-T (62M, 2.78) beats every 131–164M pixel-space baseline (2.96–3.66). In the full comparison, every model with lower gFID than UNIFIED-B has at least 545M parameters.
- CKA analysis: position-aligned UNIFIED encoding tracks the generation pass from early blocks (CKA 0.48–0.72 in blocks 1–5 at every t), while readout-based UNITE/UNITE++ stay at or below 0.15 until the last blocks (0.84–0.92) — readouts carry no image information until attention writes it in.
- Training/sampling budget: UNIFIED-B at 120 epochs already matches UNITE's final gFID (2.22 vs 2.23) with ~10% less compute; at 64 NFE UNIFIED reaches 2.23, surpassing both UNITE and UNITE++ at 256 NFE (2.28), with fewer sampling FLOPs (5.2 vs 12.8 TFLOPs/image). CFG is applied only for t in [0.1, 1].
- Text-to-image: replacing the class conditioner with Qwen3-0.6B text embeddings, pretraining on JourneyDB + BLIP3-o captions (100K iters, batch 1024, 10% text dropout), optional 2K-step SFT on BLIP3o-60k. At 256x256, UNIFIED-L (554M) beats pixel JiT (615M) and DiT DH-XL with FLUX-VAE (959M) on GenEval/DPG-Bench/GenAI-Bench (e.g., SFT GenEval 0.878 vs 0.841 / 0.516). At 512x512, UNIFIED-B (218M) reaches GenEval 0.87 and DPG-Bench 0.827, exceeding single-stage pixel models PixelFlow-XL/4 (882M, 0.60), PixNerd-XXL (1.2B, 0.73), PixelGen-XXL (1.1B, 0.79), and DeCo-XXL (1.1B, 0.86).
- Limitations: on QM9 molecules (unordered sets, no shared token grid) UNIFIED generates as well as UNITE but reconstructs slightly worse; full weight sharing means the latent space cannot be frozen — the reconstruction loss must stay active throughout training and each step pays for encoding and decoding passes alongside generation.

## Details

Method: each training step runs three passes on the same batch through the shared DiT backbone T_theta (RoPE, AdaLN on (t, c)): encoding E_theta(x) = P_z^out T_theta([q_enc; P_x^in(x)], t_enc=1, ∅), generation G_theta(z_t, t, c) = P_z^out T_theta([q_gen; P_z^in(z_t)], t, c), decoding D_theta(z) = P_x^out T_theta([q_dec; P_z^in(z)], t_dec, ∅). The latent is K = N tokens; z_t = t·z + (1−t)·ε rectified-flow interpolation with t = 1 clean. Losses: L_rec = E||x̂ − x||_1 + λ_perc·LPIPS(x̂, x) on a perturbed latent z̃ = z + σ_rec·ε_r, and L_gen = E||G_theta(sg(z_t), t, c) − sg(z)||²; total L = λ_rec L_rec + λ_gen L_gen. Inference: start from Gaussian noise at t = 0, integrate the flow over [0,1] with repeated generation passes (CFG only on t ∈ [0.1, 1]), then one decoding pass maps the final latent to pixels. Each optimizer step combines one reconstruction step and 12 flow-matching steps on the same batch. Appendices cover ImageNet training/eval protocols (adaptive dopri5 solver, shifted time grid, CFG settings), compute analysis, full baseline tables (Table 10, up to larger models), additional ablations, text-to-image details (50-step Euler, CFG 6.0, zero-shot FID on MS-COCO, 512x512 scaling), and QM9 molecular experiments. Project page: https://haoyuhsu.github.io/Unified-LDM/.
