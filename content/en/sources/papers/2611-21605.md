# ViRA: Toward Ultra-High-Resolution Visual Agents via Cross-Input Relative Policy Optimization

**Source**: [huggingface](https://arxiv.org/abs/2611.21605)
**Published**: 2026-11-16

## Overview

Visual agents answer ultra-high-resolution photo questions by zooming into relevant regions, but existing agents often answer from common sense instead of reading evidence. Standard RL on the final answer cannot correct this because a lucky guess earns the same reward as actually reading. CrossRPO (Cross-Input Relative Policy Optimization) trains agents on contrast sets: each set asks one question about several versions of an image differing only in a small evidence-bearing region, so only reading the evidence solves the whole set.

## Key points

- **CrossRPO**: rewards solving the whole contrast set, with proof it does not reinforce set-from-common-sense.
- **ViRA-Train / ViRA-Bench / ViRA-Bench-Real**: contrast sets built by editing one small object in 21–120 megapixel images, plus real-change photographed sets excluding editing traces.
- **ViRA-9B and ViRA-27B** trained with CrossRPO on only ~3,500 ViRA-Train items each.
- **63.3% set accuracy** on ViRA-Bench at maximum resolution vs 59.3% for GRPO; ViRA-9B most accurate open model of its size on all benchmarks.
- **ViRA-27B outperforms Claude Haiku 5.5 and GPT-6-Luna** (highest thinking level) on most benchmarks.

## Details

The paper argues that evidence-reading behavior cannot be fixed by answer-only RL because reward signal conflates lucky guessing with real perception. Contrast sets isolate the causal path — only looking at the evidence can solve the whole set.
