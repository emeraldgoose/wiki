# InstantFusion: A Shared Latent Interface for Heterogeneous Image Generators

**Source**: Dai et al., arXiv, 2026-10-09

**Lead**: Modern image generators differ in latents, architectures, and training recipes, and are deployed as isolated systems. The authors find independently trained models share partial compatibility—similar latent spatial organization, with unaligned mid-denoising handoffs preserving coarse layout. InstantFusion turns this into a reusable interface: a lightweight per-model Latent AutoEncoder (LAE) maps each frozen generator's intermediate states into a shared space and back, aligned on both states and denoising velocities, so denoising can switch models mid-trajectory without pairwise mappings.

## Background

Cross-model latent alignment work maps isolated states between model pairs but ignores how states evolve along denoising trajectories; trajectory-stitching methods assume a shared latent space. Transferring a denoising trajectory across heterogeneous latent spaces was therefore open. InstantFusion's premise is that state correspondence alone is insufficient—translated states must also follow the receiver's denoising dynamics.

## Method: LAEs plus Dynamics Alignment

Each of $M \geq 2$ frozen generators (sharing one VAE) gets a time-conditioned convolutional LAE, $z_t^m = E_m(x_t, t)$, $\tilde{x}_t^m = D_m(z_t^m, t)$, trained on paired noisy states from the same image at matched noise levels with $\mathcal{L} = \mathcal{L}_{rec} + \mathcal{L}_{align} + \lambda_{reg}\mathcal{L}_{reg} + \lambda_{dyn}\mathcal{L}_{dyn}$: pairwise state alignment, reconstruction (blocks the trivial collapse solution), norm consistency, and one-step displacement (velocity) alignment, since aligned states still show separated UMAP displacement clusters without it. At inference, a sender state translates as $x_{t_k}^{A\to B} = D_B(E_A(x_{t_k}^A, t_k), t_k)$, and an adaptive criterion hands off once the sender's predicted clean latent stabilizes across steps—no per-pair tuning, and new models join via their own LAE.

## Experiments

**Setup**: SD3, FLUX.1, Qwen-Image (plus Z-Image-Turbo / FLUX.2-Klein for acceleration); LAEs trained on 50k VisPrompt pairs with backbones frozen; metrics GenEval-v2, CVTG-2K, HPSv2, OneIG-Bench, PSNR/SSIM/LPIPS.

**Results**:

| Setting | Outcome |
|---------|---------|
| Reconstruction (1 round trip) | PSNR >31dB, SSIM >0.94, LPIPS ~0.03–0.04 |
| Cross-model transfer (Qwen→SD3 / Qwen→FLUX.1) | GenEval-v2 +12.92 → 35.06 / +13.68 → 36.54; CVTG-2K +0.28 / +0.18 |
| Acceleration | Qwen-Image 18.84s → 4.37s (Z-Image-Turbo hybrid) / 2.55s (FLUX.2-Klein); +DiCache 10.64s → 5.70s at equal quality |
| Cross-architecture on-policy distillation (Qwen→SD3) | HPSv2 26.27 → 26.46; removing $\mathcal{L}_{dyn}$ diverges training |
| Multi-preference composition | GenEval+HPSv2 experts: 30.97 / 30.68, near joint multi-reward GRPO without joint training |
| 3-stage rollout permutations | Stable across all 6 model orders |

Each handoff translates latents without extra denoiser evaluations, so hybrid runs add no theoretical NFE. Limitation: requires a shared autoencoder and compatible time parameterization, and hybrid inference hosts multiple backbones at once.

## Relevance to Software Engineers

InstantFusion suggests a compositional deployment pattern for generative models:

- **Route denoising across models by strength**: let a fast model draft early steps and a strong model finish (or vice versa), cutting latency several-fold while gaining double-digit benchmark points.
- **Compose specialists without joint retraining**: merge single-reward experts through the shared space instead of expensive multi-objective training runs.
- **Align dynamics, not just states**: when bridging models, match one-step velocities too—static latent bridges diverge under on-policy use.
- **Budget for multi-backbone serving**: hybrids need all participating models resident, so pair this with model offloading or staged hosting.
