# Diagnosing the Reference Gap: What Visual Scaffolds Can and Cannot Fix in Multimodal Reasoning

**Source**: [arXiv:2610.39419](https://arxiv.org/abs/2610.39419) · **Published**: 2026-10-29
**Authors**: Guizhen Chen, Weiwen Xu, Wotao Yin, Anh Tuan Luu, Hou Pong Chan

## Overview

Multimodal large language models can recognize visual content yet struggle to reason reliably over it across multiple steps. In counting, a model may see all objects but lose track of which ones it has counted. The paper argues that such failures, often attributed to perception, reveal a reference gap: the failure to bind language to the relevant visual entities, regions, or locations.

Motivated by the theory of visual routines, the authors test whether external references such as numbering can narrow this gap. They introduce ReGap-Bench, a paired benchmark of five visual reasoning tasks in which the scene and questions are aligned so the effect of added references can be measured. The study asks which kinds of visual scaffolds help and which do not.

## Key points

- Multimodal models can recognize content while still failing at multi-step reasoning.
- Counting failures can reflect lost binding between language and visual entities.
- The reference gap captures failures to bind language to relevant regions or objects.
- External references such as numbering are tested as a possible remedy.
- ReGap-Bench provides paired tasks for measuring the benefit of visual scaffolds.
- The evaluation distinguishes perception problems from binding problems.

## Details

The paper reframes visual reasoning failures as binding failures rather than pure perception failures. If a model sees objects but cannot maintain a reliable reference to them, recognition alone does not guarantee correct counting or comparison. ReGap-Bench is designed to isolate this issue by holding the scene fixed and varying the available reference. The results clarify that some visual scaffolds improve binding, while others only decorate the input without changing the reasoning outcome.
