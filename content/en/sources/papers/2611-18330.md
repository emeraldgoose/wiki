# Marimba: A System One Model for Speech

**Source**: [huggingface](https://arxiv.org/abs/2611.18330)
**Date**: 2026-11-19

## Overview

Speech applications repeatedly need small, well-scoped decisions over the same short audio window: turn-end detection for voice agents, term spotting, voice activity detection, and language identification. Existing audio language models answer through free-text generation, which is not calibrated over a typed decision space, and passing a single 1-best transcript to a text model throws away the recognizer's uncertainty about rare names or terms. Marimba (the name refers to the percussion instrument, not the Mamba architecture) applies the "typed decision" idea to speech: it accepts a short window plus a question with declared answer options, and returns a calibrated probability distribution over those options rather than free text.

The system is built on a frozen Qwen3-ASR 0.6B encoder that processes each 8-second window once. Lexical questions (term presence, keyword spotting) are scored zero-shot from the ASR decoder's greedy and beam-search hypotheses and calibrated with Platt scaling. Non-lexical questions use a question-conditioned head trained with option shuffling and held-out terms, plus a separate frozen layer-18 readout dedicated to turn-end detection. Language identification reuses the ASR model's own language scores. Speaker decisions (same speaker, speaker change, speaker count) use small readouts on layer-12 encoder features.

The evaluation covers public read speech, meetings, broadcast conversation, noise, and private Brazilian Portuguese medical consultations containing rare medication names and phonetic near-misses. The paper reports decoder AUROC of 0.80–0.92 on private conversational test sets and 0.92–0.97 on public read speech, Speech Commands four-way accuracy of 0.93, and a binary lexical ECE of at most 0.08.

## Key points

- One shared frozen encoder pass per 8-second window; all questions about the window reuse it, so adding a term or a question does not add a decoder pass.
- Lexical decisions are zero-shot: the fraction of five hypotheses (greedy plus four beam-search) containing the normalized term becomes the raw score, mapped to a probability by logistic regression on a held-out calibration split; near-miss inflections are kept as negatives via exact matching.
- Non-lexical decisions come from a question-conditioned head trained with option shuffling (so candidate order does not change the option-to-probability mapping) and a held-out-term protocol; calibration uses validation data only.
- Personal-information detection passes the greedy transcript to a private, curated PII pipeline (not released), reaching item-level F1 0.904 on synthetic Brazilian Portuguese speech and 1.000 on reference transcripts.
- Turn-end readout: logistic model on layer-18 features pooling the final two seconds, trained on 4,000 clips (C=0.01, refit on 5,768), Platt-calibrated on a separate 2,000-clip pool, frozen before a 500-clip public test.
- Speaker readouts on layer-12 features detect speaker change with AUROC 0.966–0.980 on AMI and VoxConverse (above an ECAPA baseline) and count speakers (0/1/2/3+) more accurately than pyannote 3.1.

## Details

**Method.** A cross-attention scorer g_phi computes a score per candidate option given the encoder hidden states, the question, and the candidate; a softmax over candidates (with temperature selected on validation data) yields p(c|x,q). Categorical questions share one scorer across candidates, binary questions use the binary distribution, and score-scale outputs use an appropriate proper scoring rule. Training freezes the encoder and optimizes only the question-conditioned head, with cross-entropy / binary cross-entropy losses, conversation-level splitting before task sampling, and calibration fitted on validation data. The voice-activity head was evaluated with Portuguese prompts and held-out Arabic, Hindi, Korean, and Russian prompts. Language identification uses the ASR model's own language scores, and turn-end detection uses the separate frozen layer-18 readout rather than the head.

**Results.** On private conversational test sets the decoder scores reach AUROC 0.80–0.92, versus 0.92–0.97 on public read speech; Speech Commands four-way accuracy is 0.93 with binary lexical ECE at most 0.08. PII detection reaches item-level F1 0.904 on synthetic Brazilian Portuguese (1.000 on reference transcripts). The layer-18 turn-end readout reaches AUROC 0.930, behind Smart Turn v3.2's 0.982 on Smart Turn's own test set; on an ICSI subset labeled by next speaker, Marimba reaches 0.716 versus 0.712, with the paired confidence interval including zero — i.e., no significant difference there. Speaker-change detection (layer-12) hits AUROC 0.966–0.980 on AMI and VoxConverse, above an ECAPA baseline, and speaker counting beats pyannote 3.1.
