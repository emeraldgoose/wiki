# Supervising the Visible State: Separating Representation from View Selection in Streaming Video

**Source**: [arXiv:2610.34926](https://arxiv.org/abs/2610.34926) · **Published**: 2026-10-26
**Authors**: Yihao Hu, Pan Wang, Yitong Lin, Zhihao Wen, Deyuan Liu, Hang Wang, Mingda Wan, Yiwen Zhao, Yutong Li, Yuchen Mao, Tao Lin

## Overview

An action seen once and the same action seen three times receive the same action-recognition label, so supervision does not require a model to count. Answers shared across histories that differ in event order, accumulation, or relations leave those distinctions unconstrained; this state under-specification is addressed by Visible-State Supervision (ViSS). ViSS trains on source-grounded probes of event identity, order, accumulation, relation change, and answer sufficiency. Under the same recent-frame interface, it improves OVO-Bench over strict-matched generic temporal supervision.

## Key points

- Separates representation from view selection in streaming video.
- Uses visible-state supervision to reduce under-specification.
- Improves temporal understanding benchmarks.

## Details

ViSS targets streaming video models by supervising the visible state rather than only final action labels, making temporal order and accumulation explicit.
