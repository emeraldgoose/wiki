# HALO: Human-Aligned Data Collection for WhoLe-body MObile Manipulation

**Source**: [huggingface](https://arxiv.org/abs/2611.16439)
**Published**: 2026-11-12

## Overview

HALO is a human-aligned data collection system for whole-body mobile manipulation. It aligns the operator's perception and action space with the robot while preserving direct physical feedback and natural locomotion. Operators guide the robot end-effectors through kinesthetic teaching and move a low-resistance platform without the deployed mobile base while performing bimanual manipulation — enabling more natural whole-body demonstrations than VR teleoperation or Mobile ALOHA.

## Key points

- **Up to 2.9x faster** demonstration collection versus Mobile ALOHA and VR teleoperation, with comparable or higher success rates.
- **Deployment-aligned demonstration processing**: calibrates and temporally aligns platform motion with the deployed base response; masks and inpaints demonstrator hands in recorded observations.
- **73.3% success rate** on a six-stage long-horizon mobile manipulation task involving repeated coordinated base and arm motion (e.g., zip-tie fastening).
- **Bridges the demonstration-deployment gap**: close human-robot coupling introduces discrepancies that deployment-aligned processing explicitly corrects.

## Details

Existing interfaces for whole-body mobile manipulation demonstrations trade off direct robot control, perception-action alignment, and operator mobility. HALO preserves kinesthetic teaching with natural locomotion via a low-resistance platform, giving demonstrations that resemble deployment. The processing pipeline (calibration, temporal alignment, hand masking/inpainting) ensures collected demonstrations match the deployed base dynamics and removes demonstrator artifacts from observations used for policy training.
