# MomentMem: Memorizing Key Moments for Robot Manipulation

**Source**: [arXiv:2611.26745](https://arxiv.org/abs/2611.26745) · **Published**: 2026-11-19 (v1)
**Authors**: Guangyu Zhao, Yongchang Zhang, Ruizhang Jiang, Zhihong Yu, Yuhao Zhang, Tao Wu, Qimin Zhou, Kunsong Shi, Haoran Wen, Zeyu Zhang, Yin Li, Kun Zhan, Yiwu Zhong

## Overview

Robotic manipulation often needs visual information that is no longer observable — e.g., an object's original location. Existing approaches keep full observation histories (redundant over long horizons) or text summaries (which drop precise visual detail). This paper studies visual moment memory: retaining such details from key moments for later manipulation. To measure it, the authors introduce VMBench, a suite of nine closed-loop manipulation tasks that require recalling precise visual details hard to describe in text — spatial locations, visual appearances, and their associations.

MomentMem is a hierarchical architecture that separates the two concerns: a VLM-based memorizer selects keyframes from visual observations independently of action prediction (unlike EventVLA, which predicts keyframes from predicted future actions inside one model), and an executor predicts actions conditioned on the selected memories. This separation lets the authors evaluate memory selection separately from closed-loop success and study memorizer generalization on its own. On VMBench, MomentMem averages 49.9% success — 31.7 points above the strongest baseline (EventVLA 18.2%, NativeMEM 15.8%), best on five tasks and tied on one more, with the largest gains on Placement Imitation, Mine Sweeper, and Seal Checking where evidence disappears from view; a memory-free π0.5 policy reaches only 7.0%. The memorizer also transfers zero-shot to unseen visual appearances, and adapts to an unseen task from a few memory annotations alone (43.7% vs 44.3% with full memory supervision). Competitive results on RMBench and real-robot manipulation round out the evaluation.

## Key points

- Problem: memory-dependent manipulation needs visual evidence that vanishes from the current view; full histories are redundant, text summaries lose precise visual detail.
- VMBench: nine closed-loop manipulation tasks requiring recall of spatial locations, appearances, and associations; includes visual OOD variants for memorizer-transfer tests and a held-out task for few-shot adaptation.
- MomentMem architecture: VLM memorizer selects keyframes from observations (independent of action prediction), executor conditions actions on the selected memories — enabling separate evaluation of memory selection vs task success.
- 49.9% average success on VMBench, +31.7 points over the strongest baseline (EventVLA 18.2%); memory-free π0.5 gets 7.0%; largest gains on Placement Imitation, Mine Sweeper, Seal Checking.
- Memorizer generalization: zero-shot transfer to unseen appearances; few-shot adaptation to an unseen task with only a few memory annotations reaches 43.7% (full supervision: 44.3%).
- Also competitive on RMBench and improves real-robot manipulation; code is released.

## Details

Baselines differ in how memory is stored and used — recurrent states, memory banks, compressed tokens, rule/heuristic keyframe selection, or action-conditioned keyframe prediction (EventVLA). MomentMem's memorizer learns when to save observations containing evidence needed later, rather than relying on predefined rules that must be re-tuned when memory requirements change. VMBench tasks are closed-loop and span spatial location, appearance, and association memory; the visual OOD variants test whether the memorizer relies on appearance rather than task semantics. Experiments report per-task closed-loop success (Table 2), memory-selection quality, zero-shot OOD transfer, few-shot adaptation curves on the held-out task, plus RMBench and real-robot results.
