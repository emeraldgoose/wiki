# WeFair: Fidelity-Aware Alignment from Human Feedback for Personalized Query Rewriting in Short-Video Search

**Source**: [arXiv:2610.16927](https://arxiv.org/abs/2610.16927) · **Published**: 2026-10-30
**Authors**: Yingtao Ren, Aolin Li, Cheng Cheng, Huiyun Hu, Huasheng Liang, Baoxing Xie, Jun Yuan, Haijun Wu, Yiwei Fu, Chenxing Wang

## Overview

Short-video search requires compact query rewriters that recover users' personalized intent from ambiguous queries under strict latency. Existing LLM-based methods use synthetic reasoning and consumption-behavioral feedback, but overemphasizing subsequent consumption can favor engaging content over the user's immediate need, causing intent drift. WeFair is a fidelity-aware alignment approach from human feedback for personalized query rewriting in WeChat short-video search. It preserves alignment with immediate user intent while leveraging personalized rewriting.

## Key points

- Addresses intent drift caused by over-weighting engagement signals.
- Uses human feedback to align rewrites with user fidelity.
- Targets low-latency, compact rewriters for short-video search.

## Details

WeFair focuses on fidelity-aware progressive alignment in multi-stage rewriting and integrates the aligned rewriter into retrieval and ranking pipelines. Experiments demonstrate improved personalized rewriting quality without excessive latency.
