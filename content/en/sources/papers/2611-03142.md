# DepthGraft: Structural Regularization through Hierarchical Cross-Layer KV Reconstruction

**Source**: [arXiv:2611.03142](https://arxiv.org/abs/2611.03142) · **Published**: 2026-11-02

## Overview

Scaling depth is still a primary lever for stronger Transformer language models, but in modern Pre-LayerNorm architectures adding layers does not reliably pay off. The residual stream funnels all preceding computation through a single hidden-state trajectory with fixed additive updates, so features formed in early layers are progressively diluted as the stack grows and become difficult for later layers to retrieve — depth-wise information dilution. Cross-layer connectivity such as Attention Residuals or MoDA-style attention over earlier keys and values mitigates this, but existing designs buy the shortcut with extra computation, memory traffic, or system complexity.

DepthGraft starts from a different reading of cross-layer key–value (KV) sharing. Beyond cache compression, every KV reuse edge is also a direct gradient path from a deep layer back to the source layer's KV projections, which turns KV sharing into an implicit structural regularizer on KV representation geometry. The paper's analysis shows the effect is topology-dependent: sharing topologies with enough source–reuse distance sharpen key retrieval directions and enrich the value content subspace, whereas adjacent-layer sharing and global-anchor designs do not fully exploit the mechanism.

The proposed architecture uses a hierarchical three-stage layout — shallow, middle, and deep stages of roughly L/3 layers each. Deep layers never materialize their own KV; each reconstructs it from a stride-aligned shallow–middle source pair, s(l) = l − 2L/3 and m(l) = l − L/3, through learnable per-channel coefficients, with key coefficients tied across RoPE rotation pairs so reconstruction commutes with rotary encoding and the standard KV-cache storage logic. Because the deep stage holds no independent KV, KV cache and prefill cost drop by roughly one third while prefill early completion and pipeline-parallel (PP/VPP) compatibility are preserved.

Trained from scratch on dense 0.5B–1.5B models and DeepSeekMoE-style 3B–16B models under both GQA and MLA, DepthGraft improves average downstream scores by +0.75, +0.85, and +2.42 points at 0.5B/1B/1.5B dense and +1.05, +2.29, and +3.61 at 3B/9B/16B MoE with GQA (9B MLA +3.68). The 16B MoE model gains +7.00 on MMLU-Pro, +6.61 on CMMLU, +6.41 on C3, and +5.84 on GSM8K. At 128K context, TTFT falls by 26.8% (9B MLA) and 28.8% (16B GQA) while decoding speed (TPOT) stays within 1% of baseline.

## Key points

- KV reuse edges double as cross-layer gradient paths: KV sharing is not just forward cache compression but an implicit structural regularizer on KV representation geometry.
- Topology decides the payoff: adjacent sharing underperforms even the plain GQA baseline, global-anchor sharing concentrates its benefit on a few anchors, and non-local distributed topologies work best.
- DepthGraft design: three-stage layout in which the deep stage reconstructs each layer's KV from a stride-aligned shallow+middle source pair with learnable coefficients — no independent deep-stage KV, so cache and prefill shrink by about one third.
- Ablations on the 16B A3B MoE model isolate the mechanism: detached shallow-copy matches the baseline (42.86 vs 42.38 average), enabling gradients raises it to 45.30, and hierarchical two-source reconstruction reaches 47.56, beating both single-source variants (45.30 and 43.58).
- Gains hold across attention variants and scales: 9B MLA improves by +3.68 average, and the 16B model gains +7.00 MMLU-Pro, +6.61 CMMLU, +6.41 C3, +5.84 GSM8K.
- Efficiency is preserved by construction: TTFT at 128K context drops 26.8% (9B MLA) and 28.8% (16B GQA) with under 1% TPOT overhead.
- Long-context retrieval survives cache sharing: after continued training at 32K, RULER average at 4K rises from 86.8 to 94.8 across needle-in-a-haystack, variable-tracking, and QA tasks evaluated at 4K–32K.

## Details

- Mechanism analysis (Secs. 3.2–3.3): sufficient source–reuse distance separates query spaces enough for the gradient interference that drives K/V specialization, and distributed gradient flow keeps any source layer from becoming a congestion point — the two design principles DepthGraft instantiates.
- Why two sources per deep layer: shallow memory preserves lower-level lexical and token-local patterns while middle-layer memory carries more abstract semantic states; stride alignment keeps each deep layer's two memory bases at the same relative depth position, preserving the ordering of representation evolution.
- Ablations decompose the gain: cross-layer gradients are the key source (detaching them removes the benefit), hierarchical reconstruction beats single-source copying, and the three-stage partition beats both 2-stage and 4-stage alternatives — more source stages is not automatically better.
- Systems behavior: the stride-aligned source mapping places each source–reuse triple on the same pipeline rank, so PP/VPP need no extra cross-stage KV communication, and prefill early completion is retained.
- Training dynamics: effective-rank improvements appear across nearly all layers rather than only source or reuse layers, and attention-sink behavior weakens during training, consistent with a better-organized memory pathway.
