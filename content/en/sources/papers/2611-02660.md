# HeLM: Hierarchical Explicit Language Memory for Non-Markovian Manipulation

**Source**: [arXiv:2611.02660](https://arxiv.org/abs/2611.02660) · **Published**: 2026-11-02
**Authors**: Gyeonghun Kim, Donghoon Kim, Minsoo Choi, Suyun Lee

## Overview

Vision-Language-Action models are strong at manipulation but many operate under a Markovian assumption, mapping only the current observation to an action. This leads to failures in tasks requiring working memory and history. HeLM proposes a hierarchical framework that maintains task-relevant history in explicit language.

Inspired by the human inner monologue, HeLM combines factorized event detection with event-triggered memory updates. Task-relevant observations are distilled into explicit language memory, enabling non-Markovian capabilities without storing full observation histories.

HeLM is evaluated across 10 non-Markovian real-world tasks with 56 variants, including inter-episode tasks that require persistent context across task boundaries. It improves intra-episode success by 12.8 percentage points over the strongest baseline and reaches 78% subtask success on compositional generalization, while using less memory and running faster than keyframe-based memory.

## Key points

- Introduces explicit language memory for non-Markovian manipulation.
- Moves beyond Markovian vision-language-action architectures.
- Uses factorized event detection and event-triggered memory updates.
- Evaluates on 10 non-Markovian real-world tasks with 56 variants.
- Includes five newly formulated inter-episode tasks.
- Improves success while using substantially less memory and faster runtime.
