# Stateless Language Agents: Scaling Long-Horizon Automated Research

**Source**: Qizheng Zhang et al., arXiv, 2026-10-06

**Lead**: Long-horizon LLM agents fail by replaying histories, duplicating work, and stalling while consuming tokens. The Stateless Language Agent (SLA) framework fixes this by making the harness own all durable research state (candidate solutions, measured outcomes) while agents remain stateless—each invocation receives a fresh, role-specific context reconstructed from the harness.

## Background

Automated research (AutoResearch) systems run LLM agents iteratively to propose, implement, and evaluate solutions. Current frameworks (e.g., GEPA, CodeEvolve, AdaEvolve) let agents carry conversation histories across invocations. This causes three failure modes at scale:
1. **History bloat**: Context grows with run length, wasting tokens on redundant context.
2. **Duplication**: Agents independently rediscover known failures.
3. **Stalling**: Agents stop experimenting while token budgets drain.

Evaluations typically use short horizons that saturate early, missing these pathologies.

## SLA Framework

SLA enforces a strict separation:
- **Harness**: Owns the research state—candidate solutions, evaluation outcomes, search trajectory. Reconstructs minimal, role-specific contexts for each agent invocation.
- **Advisor (stateless)**: Reads harness-summarized evidence across search directions, assigns concrete experiments to Workers.
- **Workers (stateless)**: Execute assigned experiments (code edits, kernel tuning, algorithm variants) with no memory of prior invocations.

Each agent sees only what the harness explicitly provides—an explicit design choice, not an accident of history.

## Results

Evaluated on three domains at budgets up to **1 billion tokens**:
- **Software engineering** (SWE-bench style)
- **Kernel optimization** (CUDA/Triton)
- **Algorithm design** (algorithmic discovery)

SLA achieves the **best final result on every task** and reaches the strongest kernel baseline's final performance with **over 84% fewer tokens**.

Ablations (shared checkpoints) show:
- Focused contexts and explicit assignments each contribute.
- Effects compound over full runs.
- Advisor consumes **< 0.6% of total tokens**.

Short-horizon evaluations misjudge research systems—SLA's advantage grows with budget.

## Relevance to SW Engineers

- **Agent architecture**: Statelessness is a scalable design pattern—state belongs in orchestration layer, not model context.
- **Token efficiency**: 84% reduction at billion-token scale directly translates to cost savings.
- **Observability**: Harness-owned state enables deterministic replay, debugging, and audit trails.
- **Parallelism**: Stateless Workers trivially parallelize; Advisor coordinates without bottleneck.
- **Evaluation rigor**: Long-horizon budgets expose failure modes invisible in short benchmarks.
