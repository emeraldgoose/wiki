# Every Token Needs Its Own Teacher: Multi-teacher Adaptive On-policy Self-distillation

**Source**: [arXiv:2610.40574](https://arxiv.org/abs/2610.40574) · **Published**: 2026-10-29
**Authors**: Yifu Luo, Chuang Ma, Zeyu Chen, Enkelejda Kasneci, Qi Chen, Gjergji Kasneci

## Overview

On-policy self-distillation has proven effective for post-training large language models by constructing a teacher conditioned on privileged references. Existing approaches either keep the teacher fixed throughout training by consistently exposing it to the full reference, or adapt partial reference exposure only across responses within each response. The paper argues that neither option is sufficient.

The key observation is that every token needs its own teacher: teacher preference can vary token by token within the same response. A teacher-intervention pilot study supports this by showing differing teacher preferences across tokens and by demonstrating that a preferred teacher can be identified per token through majority voting and KL-based selection.

Motivated by these findings, the paper proposes Multi-teacher Adaptive On-policy Self-Distillation (MTA-OPSD), described as the first token-level adaptive on-policy self-distillation method. It builds a multi-teacher pool of candidate teachers and lets every token adaptively select its preferred teacher during training. On Qwen3 models for mathematical reasoning, MTA-OPSD consistently outperforms existing on-policy self-distillation approaches, with average gains up to +5.9 over the base model.

## Key points

- Existing on-policy self-distillation methods keep the teacher fixed globally or vary exposure only across responses, which the paper argues is insufficient.
- Teacher preference differs across tokens within the same response, so each token should have its own teacher.
- Majority voting and KL-based selection can identify a preferred teacher for each token.
- MTA-OPSD introduces token-level teacher selection from a multi-teacher pool.
- It improves on prior approaches in mathematical reasoning experiments with Qwen3 models, with average gains up to +5.9 over the base model.
- Code is made available.

## Details

The method is evaluated on mathematical reasoning tasks using Qwen3 models and compared with existing on-policy self-distillation approaches, showing consistent improvements. The contribution centers on moving teacher supervision from a fixed or response-level scheme to token-level adaptation, while keeping a pool of candidate teachers. The released code supports reproduction.
