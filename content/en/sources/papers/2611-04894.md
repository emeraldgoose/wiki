# VisSearch-Bench: Evaluating Long Horizon Visual Search in Multimodal Agents

**Source**: [arXiv:2611.04894](https://arxiv.org/abs/2611.04894) · **Published**: 2026-11-03
**Authors**: ZhengXian Wu, Qianhao Nie, Zhuohong Chen, Junjie Gao, Yuyao Zhang, Yunyao Yu, Hangrui Xu, Cheng Cheng, Guiyu Ma, Jin Zhang, Xingzhong Xu, Kai Yang, Haoqian Wang

## Overview

Multimodal agents use web and image tools to answer questions beyond internal knowledge. Many search tasks use images only to identify an initial entity and then rely on text retrieval, offering limited insight into how agents connect information across images, objects, and search steps.

VisSearch-Bench focuses on visual context management: organizing and using visual information and linking it to other findings during search. Visually intensive tasks require combining object appearance, local details, or spatial relations with external information. The benchmark contains 204 human-written tasks across 7 main domains and 25 subdomains.

Task types include set-wise visual search, sequential visual search, hybrid wide-deep search, competitive visual disambiguation, and visual-structure-guided search. Each task provides a reference answer, traceable evidence, and scoring rules. Accuracy measures complete task success, while Process Score measures correctness and completeness of individual results and subquestion answers. Across 16 multimodal models, the best system fully solves only 26.47% of tasks even with search tools.

## Key points

- Provides 204 human-written visual search tasks across 7 domains and 25 subdomains.
- Focuses on visual context management during multi-step search.
- Defines five task categories including set-wise and sequential visual search.
- Includes reference answers, traceable evidence, and scoring rules.
- Uses accuracy and Process Score as complementary metrics.
- Shows that even the best tested system fully solves only about 26.5% of tasks.

## Details

The 41-page paper includes 22 figures. It highlights the difficulty of linking visual evidence with search results to produce complete answers.
