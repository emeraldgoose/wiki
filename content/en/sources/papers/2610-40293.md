# MAServeBench: Benchmarking Multi-Agent LLM Serving Systems with Hierarchical Collaboration Workloads

**Source**: [arXiv:2610.40293](https://arxiv.org/abs/2610.40293) · **Published**: 2026-10-29
**Authors**: Shengxuan Qiu, Haochen Huang, Shuzhang Zhong, Zizhuo Fu, Zebin Yang, Jianming Tong, Meng Li

## Overview

Large language model (LLM)-based multi-agent systems (MAS) coordinate specialized agents to solve complex tasks, turning each user request into interdependent model and tool operations. Unlike conventional serving of independent requests, these operations become ready at different times and carry evolving context as agents coordinate and exchange results. The resulting serving demand therefore changes in concurrency, computation, and memory pressure depending on collaboration structure, which can expose hardware bottlenecks that are not visible from request counts or token lengths alone. Recording the realized operations does not capture the collaboration rules that generated them, which limits reuse and controlled comparison.

MAServeBench addresses this by treating multi-agent collaboration as a configurable dimension of serving workloads. Its composable stages capture how agents coordinate and exchange context in documented MAS workflows, allowing native executions to produce different workloads even when task inputs and tools stay the same. Hierarchical Semantic Traces preserve realized operations and their typed dependencies for reproducible fixed-work replay and for consumption by architecture simulators. Task-linked measurements then connect workloads to serving execution and GPU/NPU hardware behavior, illustrating why serving efficiency does not always translate into timely task completion. The code is available at https://github.com/ShengxuanQiu/MAServeBench.

## Key points

- Provides composable stages that express agent coordination and context exchange independently of task binding.
- Generates native, collaboration-dependent workloads while retaining realized work for controlled replay.
- Hierarchical Semantic Traces preserve operations and dependencies for serving replay and architecture simulation.
- Validates functional behavior with recorded-work checks and native-to-replay conformance.
- Evaluates across GPU/NPU platforms, linking MAS execution shapes to compute, memory, and task-level SLOs.

## Details

The benchmark defines four reusable stage templates and composes them into multi-agent workflows, including spawn-fork-join-refinement and debate-style pipelines. A distinction between work generation (which calls and contexts emerge as agents coordinate) and work exposure (when those calls become eligible under their dependencies) supports both native realization and controlled fixed-work experiments.

Native evaluations use seven workflow structures and thirty shared task bindings spanning code, reasoning, finance, evidence processing, and science. Serving experiments run under vLLM/vLLM-Ascend, with 32/64/128 users in three-block runs and smaller fixed-work cohorts for release interventions. Validation covers 1,032 completed requests, 186 predecessor-release constraints with millisecond tolerance, and 204 paired replay comparisons that preserve payloads, token counts, operations, and dependencies.
