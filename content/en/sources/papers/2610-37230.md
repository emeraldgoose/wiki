# TAO: Tool-Aware Joint Scheduling for LLM-Based Agentic Serving

**Source**: [arXiv:2610.37230](https://arxiv.org/abs/2610.37230) · **Published**: 2026-10-27
**Authors**: Shuhuai Li, Shengdong Ye, Dongdong Ge, Yinyu Ye, Jianghao Lin

## Overview

Agentic services alternate between model inference on clustered GPUs and external tools on distributed CPUs. Existing systems often (1) ignore tool-return readiness in service evaluation, wasting limited resources, and (2) use heuristic strategies for GPU admission and placement, yielding suboptimal scheduling.

TAO is a tool-aware joint scheduling framework for LLM-based agentic serving. Its value interface combines near-term tool readiness, node-specific cache credit with time-aware decay, and token footprint; a dynamic program jointly selects and places waiting sessions under capacity constraints.

## Key points

- Introduces TAO for joint admission and placement in agentic serving.
- Value interface integrates near-term tool readiness, cache credit with time-aware decay, and token footprint.
- Uses a dynamic program under capacity constraints instead of heuristic admission/placement.
- Across 12 model-workload-concurrency settings: up to 26.8% latency reduction, 36.3% TTFT reduction, 29.5% decode throughput increase versus best SOTA baseline per metric.

## Details

By modeling tool readiness and cache value jointly with capacity, TAO better pipelines CPU tools and GPU inference, recovering waste in existing heuristic scheduling.
