# Think Twice: The Metis-1.6 Technical Report

**Source**: [arXiv:2610.37903](https://arxiv.org/abs/2610.37903) · **Published**: 2026-10-27
**Authors**: Praxis (2.94B, 0.46B active), Logos (10.23B, 1.18B active)

## Overview

Metis-1.6 is the latest step in a bet that better data, better training methods, and new architectures can buy capability that raw parameter count alone cannot, at a fraction of the cost. It introduces two language models trained from scratch by a single researcher: Praxis (2.94B parameters, 0.46B active per pass) and Logos (10.23B parameters, 1.18B active per pass). Both run a hybrid Mamba-2 and attention mixture-of-experts stack twice per forward pass, and were pretrained on 16x more data than Metis-1.5.

This report aims to measure the models honestly against similarly sized open models using one evaluation harness, and to document what went wrong. Release reports often describe only the working recipe; this one discusses failed optimizations, optimizer mismatches, and post-training issues in detail.

## Key points

- Two open models with complete training lineage, checkpoint hashes, and exact parameter accounting.
- Praxis and Logos use looped hybrid Mamba-2/attention MoE architectures to improve capability per active parameter.
- Compared with open models of similar size, 27 base-stage and 28 post-training comparisons are reported.
- The declared AdaMuon optimizer was never instantiated; attention matrices trained with AdamW due to a parameter-routing mismatch.
- Learned hashed n-gram memory failed: deleting its 1.77B-parameter table from Logos changed held-out loss by less than 1e-3 nats.
- Supervised fine-tuning exposed five failure modes and a verifier imbalance that shortened reasoning on unseen science questions.
- A length-reward sign inversion under group-mean normalization was found, proved, and fixed.

## Details

The Metis series progressed through 1.3, 1.4, and 1.5 before these models, scaling parameter counts while experimenting with hybrid blocks, mixture-of-recursions transformers, and latent MoE. Metis-1.6 represents the shift to two-pass looped hybrids on AMD Instinct MI300A accelerators.

On the training side, the report audits optimizer behavior rather than assuming intent. AdaMuon was declared but never instantiated, and routing mismatch moved attention matrices to AdamW. Hashed n-gram memory injection also failed to help, with learned gates closing and near-zero held-out loss change.

Post-training analysis covers five SFT failure modes, a verifier imbalance affecting science reasoning, and a length-reward issue fixed by a one-line change. Controlled 10B-token ablations then study loop design and the optimizer choices intended for the next architecture.
