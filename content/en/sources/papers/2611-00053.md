# SIMIT: Self-Improving Vision-Language Models via Imagination at Test-Time

**Source**: [arXiv:2611.00053](https://arxiv.org/abs/2611.00053) · **Published**: 2026-10-11
**Authors**: Mehmet Onurcan Kaya, Desmond Elliott, Dim P. Papadopoulos

## Overview

SIMIT is a test-time self-improvement framework in which a vision-language model creates its own query-specific training data before answering an unlabeled test query. The goal is to improve performance on a target test set without annotations or external models. Some test-time methods improve answers through longer reasoning or repeated sampling but leave the model unchanged. Others update the model using majority-agreement or self-judgment rewards, which can reinforce existing errors. SIMIT instead generates synthetic training data tailored to the query and uses it to improve the answer.

## Key points

- The framework targets vision-language models at test time.
- It improves the model without external labels or external models.
- Query-specific training data is generated before answering.
- Synthetic data reduces reliance on majority self-consistency.
- The method addresses confirmation bias in self-generated labels.

## Details

The key idea is to turn each test query into a localized learning opportunity. Rather than only sampling multiple answers or updating parameters from uncertain self-judgment, SIMIT first imagines relevant training examples. This lets the model refine its behavior for the specific query. The paper emphasizes improvement under the constraint of no annotations or external models, distinguishing it from test-time augmentation or self-distillation approaches that reuse potentially biased labels.
