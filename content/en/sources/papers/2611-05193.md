# Factorized MLLM Embeddings for Composed Image Retrieval

**Source**: [arXiv:2611.05193](https://arxiv.org/abs/2611.05193) · **Published**: 2026-11-03
**Authors**: WonJun Moon, Seongchan Kim, Dahun Kim, Seungryong Kim

## Overview

Composed image retrieval aims to retrieve a target image given a reference image and a modification text. Recent approaches using multimodal large language models have improved results, but compositional understanding remains underutilized because the composed query is directly mapped into a single retrieval embedding via contrastive supervision alone. FactEmbed decouples compositional query comprehension from building discriminative embeddings. It uses factorized latents that simulate intended visual modifications through an intermediate target imagination objective, encouraging them to ground into target semantics before retrieval. Then a factor-level contrastive loss and distillation of decomposed representations into a deeper attention layer propagate them. For efficient inference, the [EOS] token establishes a global embedding, and mean-pooled factorized latents rerank a short candidate list at negligible extra cost.

## Key points

- Direct single-embedding mapping underuses compositional understanding.
- Factorized latents simulate intended visual modifications.
- An intermediate target imagination objective grounds semantics.
- Factor-level contrastive loss is optimized.
- Decomposed representations are distilled into a deeper attention layer.
- Candidate reranking uses mean-pooled latents with almost no added cost.

## Details

Extensive evaluations across composed image retrieval benchmarks show FactEmbed outperforming prior work. The key idea is to separate target imagination from discriminative representation, which could improve robustness for complex text-modification cases. Cost and inference implications include an extra rerank that remains computationally cheap because it reuses the same forward pass. Evaluation should still cover datasets beyond the reported benchmarks to ensure generality.
