# EvoMemState: Evolving Memory State for Personal Agents

**Source**: [arXiv:2611.03743](https://arxiv.org/abs/2611.03743) · **Published**: 2026-11-02
**Authors**: Zhishang Xiang, Yunbo Tang, Zhongqiao Liu, Junkai Chen, Zerui Chen, Qingguo Hu, Yuxuan Zhang, William Grant, Qinggang Zhang, Jinsong Su

## Overview

Long-term memory lets LLM personal agents retain user information across interactions. Most existing systems maintain memories as independent facts, extracted, organized, updated, and retrieved individually. This fact-centric paradigm can miss how new facts update, constrain, or conflict with earlier ones, while leaving applicability, role, and priority implicit.

EvoMemState proposes a state-centric framework that augments persistent facts with two complementary states: relational states capturing how facts remain valid and relate over time, and a reasoning state deciding how facts apply to the current request. Three components implement this: ontology-guided memory state induction extracts persistent facts and constructs relational states; RL-based state evolution learns request-specific reasoning state generation; and state-aware reasoning combines facts, relational states, and the reasoning state to guide the agent.

Experiments on long-term dialogue and memory-use benchmarks show consistent improvements in retrieval completeness and memory-grounded response accuracy over existing memory systems.

## Key points

- Identifies limitations of maintaining long-term memory as independent facts.
- Adds relational states for validity and evolving relations among facts.
- Adds a reasoning state for applying facts to each current request.
- Uses ontology-guided induction to build persistent facts and relational states.
- Uses reinforcement learning to generate request-specific reasoning states.
- Improves retrieval completeness and memory-grounded response accuracy.

## Details

The framework is motivated by continuous personalized assistance across interactions. Code and implementation details are provided. Information retrieval and artificial intelligence are the relevant subject areas.
