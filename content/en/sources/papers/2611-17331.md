# TTB: Test-time Baking for Efficient Rendering of Decoder-only View Synthesis Models

**Source**: [arXiv:2611.17331](https://arxiv.org/abs/2611.17331) · **Published**: 2026-11-12
**Authors**: Chin-Yang Lin, Ryo Hachiuma, Jaesung Choe, Min-Hung Chen, Yu-Chiang Frank Wang, Yen-Yu Lin, Wei-Chen Chiu, Yu-Lun Liu, Cheng Sun

## Overview

Decoder-only Large View Synthesis Models regress novel views directly from a neural network instead of reconstructing 3D geometry, and a KV-cache over context views brings them state-of-the-art quality. That cache is a global scene state, but rendering time remains impractical under dense context views because every query attends linearly over it. LaCT replaces cross-view attention with Test-Time Training layers whose fast-weight MLPs adapt in an inner loop, achieving constant-complexity rendering at a significant quality cost, and initializing from pretrained decoder-only weights narrows the gap only partly.

TTB, Test-Time Baking, keeps cross-view attention and repurposes the fast-weight MLP: instead of learning from raw value tokens as TTT does, the inner loop learns the cross-view attention mapping explicitly from its input-output pairs. Attention is no longer replaced but collaborated with — the MLP bakes global scene information from the attention output into a lightweight state, so rendering keeps TTT's constant complexity while quality returns toward the attention baseline. The second key is a modality disentanglement: context tokens are split into camera-only context rendering tokens, which serve as TTB input and match the modality of novel-view queries, and context ground-truth tokens with image content, which serve as the mapping target. Only the full pairing aligns the modalities from the first block.

On benchmarks the combination reaches the Pareto frontier of PSNR against FPS: TTB renders at a constant 23 FPS, up to 23x faster than the DVSM cross-attention baseline and 2.3x faster than LaCT, while matching DVSM's quality and consistently surpassing LaCT across DL3DV, Re10K and in-the-wild scenes.

## Key points

- TTB achieves up to 23x rendering speedup with quality on par with the state of the art across several benchmarks, per the abstract.
- On DL3DV at 64 input views, DVSM reaches 31.11 PSNR but needs 60 s per frame at 1 FPS, while TTB with local-duplicate inference reaches 31.33 PSNR at 65 s and 23 FPS; LaCT manages 28.30 PSNR at 10 FPS.
- At 16 input views on DL3DV, TTB scores 27.00 PSNR at 23 FPS against DVSM's 26.86 at 4 FPS and LaCT's 24.70 at 10 FPS.
- Rendering stays at a constant 23 FPS whether 16 or 64 context views are used; the speedup is independent of context view count.
- Switching the inner-loop loss from LaCT's unnormalized dot product to MSE improves PSNR by +0.44 for TTB-minus versus +0.27 for TTT, and T=3 inner steps are adopted as the sweet spot.
- Residual learning and feedback in the TTB layer contribute roughly equally in isolation (+0.43 and +0.44 PSNR) and +0.52 combined.
- TTB is built on DVSM with 12 blocks rather than LaCT's 24; parameter counts are 271M for TTB, 244M for TTB-minus, 163M for DVSM, 379M for LaCT and over 1B for LagerNVS.
- Local-duplicate inference keeps K local copies of the per-layer fast-weight state, routed by k-means over per-view camera features, and closes the residual quality gap at large view counts.
- Out-of-domain evaluation covers MipNeRF360, Free and Hike at 960p and 512-pixel settings, where TTB closely matches DVSM and outperforms LagerNVS at 512 pixels.
- The reconstruction cost grows quadratically with the number of views because the in-loop cross-view attention provides the baking target, trading context prefill time for fast rendering.
- Project page: test-time-baking.github.io.

## Details

### From replacing attention to baking it

A naive TTT replacement of every cross-attention layer achieves constant space and linear time but sacrifices rendering quality. TTB instead targets the attention output itself, turning the fast-weight MLP from a replacement for attention into its collaborator; the ablation decomposition attributes the gap to three additive components — context pairing, MSE with T=3 inner steps, and replacing the linear-projection target with cross-view attention output. Stacking all three closes the quality gap to DVSM while retaining roughly 50 FPS rendering in the ablation setting.

### Context pairing and the modality gap

During context prefilling the model sees images and cameras, while novel-view decoding sees only cameras; TTB resolves the mismatch by feeding camera-only context rendering tokens as input and ground-truth context tokens with image content as the target. The t-SNE analysis in the paper shows that only the full pairing aligns the modalities from the first block. The inner loop follows LaCT in using the Muon optimizer.

### Benchmarks and inference regime

Qualitatively, TTB preserves thin, high-frequency structures such as handrails, window grilles and small text that LaCT and LVSM render with visible blur. When duplicate views are not available, the baseline TTB still reaches 29.29 PSNR at 64 views with 23 FPS. The authors note that for a small number of context views the speedup becomes marginal, for example 64 to 72 FPS at 256 by 256 resolution, because there is little cross-view state left to bake.
