# Sage S2.1 Flash Technical Report

**Source**: [huggingface](https://arxiv.org/abs/2611.21072)
**Date**: 2026-11-19

## Overview

We introduce Sage S2.1 Flash, a 320-billion-parameter general-purpose mixture-of-experts (MoE) model designed to reason over scientific evidence and act in interactive environments. It targets two recurring demands of scientific work: retrieving and interpreting visual evidence from the scientific literature, and acting on intermediate visual outputs to guide analysis. For scientific computer use, the model interprets the state of specialized software and uses visual feedback from its actions to decide how to proceed.

Sage Sci-Perception uses dedicated encoders for molecular graphs and biological sequences and represents spectra as ordered patches of measurements. Modality-specific projectors map these representations into the input space of a shared backbone, which processes them alongside text and images. Around this backbone, the team builds verifiable environments for agent training spanning tool use, search, and coding, as well as specialized workflows involving machine learning experiments and scientific software, with task completion checked against execution results, changes in environment state, or submitted artifacts.

The model is evaluated on 33 benchmarks across seven domains. In the primary comparison against five baselines, it ranks first on OfficeQA Pro (72.2), MLE-bench Lite (90.3 HumanRank), Harvey LAB, and SpreadsheetBench 2, and second on OSWorld-Verified (85.2), WebArena-Verified (67.6), and DeepResearch Bench II (54.2).

## Key points

- 320-billion-parameter general-purpose MoE model focused on scientific reasoning and interactive agency.
- Sage Sci-Perception: dedicated encoders for molecular graphs and biological sequences; spectra represented as ordered patches of measurements; modality-specific projectors feed a shared backbone alongside text and images.
- Agent capabilities are developed through verifiable environments for tool use, search, and coding, plus specialized workflows for ML experiments and scientific software.
- Verification of task completion uses execution results, environment-state changes, or submitted artifacts rather than model self-report.
- ToolSpace framework reconstructs a tool-composition space from real execution traces, synthesizes environments on demand, and generates long-horizon agentic tool-use tasks.
- Post-training uses XTuner as the training framework.
- Evaluated on 33 benchmarks across seven domains; Figure 1 reports 15 selected benchmarks where Sage S2.1 Flash ranks first on four and second on seven among six compared models.
- Results show particular strengths in using documentary evidence, producing verifiable workbooks, and carrying out machine learning tasks, with competitive performance in desktop and browser workflows requiring visual feedback.

## Details

Method: Sage Sci-Perception is the unified interface for scientific inputs. Each modality uses an encoder whose local states are combined with a learned identity embedding and passed through a projector (layer normalization, then two linear transformations with GELU). Optional side branches map explicit measurements (e.g., time or scale) into the language embedding space, and a readout branch can translate scientific prediction scores into additional embedding contributions; a context residual then exchanges information among states belonging to the same scientific object. All tasks within a modality share one complete projector, with the requested operation expressed through the instruction, so the same interface is reused across tasks.

Post-training scales verifiable environments ranging from general-purpose tool use, search, and coding to ML-experiment workflows and scientific-software interaction. ToolSpace, the tool-centric framework behind this, explores the tool space from real execution traces, synthesizes environments on demand, and generates long-horizon agent tasks to strengthen long-horizon orchestration.

Results: On 33 benchmarks across seven domains against five baselines, Sage S2.1 Flash ranks first on OfficeQA Pro (72.2), MLE-bench Lite (90.3 HumanRank), Harvey LAB, and SpreadsheetBench 2, and second on OSWorld-Verified (85.2), WebArena-Verified (67.6), and DeepResearch Bench II (54.2). The reported strengths are documentary-evidence use, verifiable workbook production, and machine learning tasks, alongside competitive desktop/browser workflow performance driven by visual feedback.
