# Multi-Agent Relay Thinking

**Source**: [arXiv:2610.35219](https://arxiv.org/abs/2610.35219) · **Published**: 2026-10-26
**Authors**: Xu Liu

## Overview

Existing multi-agent collaboration methods mainly explore a group-thinking topology, where agents independently generate solutions and aggregate outputs. This paper investigates an alternative relay-thinking topology, where reasoning ownership dynamically transfers across agents, allowing later agents to inherit and refine an evolving reasoning trajectory.

The paper introduces Multi-Agent Confidence-guided Relay, a framework for dynamic relay collaboration. Its key challenge is deciding when to relay and which agent should continue. MACR addresses this through confidence-guided relay triggering and a bidding mechanism that selects the next agent based on confidence. Experiments on four benchmarks show higher accuracy than strong single-model strategies, including gains on MathVista and MMStar, while using less token overhead than multi-agent strategies on HallusionBench and MMStar.

## Key points

- Group thinking aggregates independently generated solutions.
- Relay thinking transfers and refines one evolving reasoning trajectory.
- MACR dynamically transfers reasoning ownership across agents.
- Confidence-guided triggering decides when to relay.
- A bidding mechanism selects the next agent by confidence.
- Results improve accuracy while reducing token overhead in several benchmarks.

## Details

Relay collaboration lets heterogeneous agents contribute at different reasoning stages rather than solving the whole problem independently. Because later agents inherit an evolving trajectory, complementary insights can be integrated progressively. The confidence signals provide a practical trigger and selection mechanism without requiring exhaustive multi-agent aggregation. This makes relay collaboration a middle ground between single-agent reasoning and high-overhead multi-agent ensembles.
