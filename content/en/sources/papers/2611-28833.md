# Self-WSP: Can Language Models Improve Themselves Through Weight-Space Programming?

**Source**: [arXiv:2611.28833](https://arxiv.org/abs/2611.28833) · **Published**: 2026-11-21 (v1)
**Authors**: Guoming Ling, Shanshan Zhong, Kaixuan Zhang, Zhongzhan Huang

## Overview

Frontier language models can now read and edit the weights of a neural network much like code and thereby improve a small model — Weight-Space Programming (WSP). The paper asks whether a language model can do this to itself: Self-WSP. Concretely, Qwen3.5-0.8B plays two roles with one set of weights. As editor, it reads its own current weights (through an interface that lists a tensor catalog) and proposes an edit; as solver, it answers practice questions using a copy of the weights with the edit applied. The outer loop checks whether more answers are correct and, if so, replaces the current weights with the edited copy, so the next proposal comes from the edited model.

The headline result is many cases of genuine self-improvement: self-edits raise GSM8K accuracy from 11.8% to 62.2% and MATH500 accuracy from 7.0% to 32.2%, sometimes by changing only 16 parameters, and in some cases repeated self-editing keeps improving the model. But a closer look shows the gains lack interpretability: the model shows little understanding of the edits it makes, WSP driven by random search sometimes performs comparably, and the paper documents that most proposals fail, edits cluster in a catalog of locations, the numbers it writes copy statistics it reads, its explanations are often hallucinated, and kept edits often hurt performance.

## Key points

- Self-WSP loop: one model, two roles (editor reads own weights and proposes an edit; solver answers practice questions with the edit applied); an edit is kept only if it improves validation answers; continued runs let the best edited models keep self-editing.
- Results: GSM8K 11.8% -> 62.2% and MATH500 7.0% -> 32.2% via self-edits, in some cases by changing only 16 parameters; some repeated self-editing runs keep improving.
- Interfaces: the shuffled interface lists the tensor catalog in random order and the ordered interface lists it by layer; the paper compares both, and continued runs move the best shuffled models to the ordered interface.
- Controls: random search replaces the editor with a random sampler under the same budget; a single random edit is the best of edits tested individually on the original model; GPT-6's simpler edit turns out to be a random edit. Where self-editing beat random search is analyzed explicitly.
- Interpretability findings: a lucky edit is rare and most proposals fail; where the model edits follows the catalog; the numbers it writes copy the statistics it reads; explanations are often hallucinated; kept edits often hurt — so the self-improvement is real but not yet understood.
- Implication: Self-WSP is a promising path toward recursive self-improvement (RSI), but realizing it requires further exploration.

## Details

Section 2 describes the Self-WSP system (reading weights, writing weights, keeping edits, two interfaces, selection and testing, continued runs). Section 3 asks whether a model can improve itself through its weights with a few numbers. Section 4 probes whether the model knows what it is doing. Section 5 asks whether random edits do the same. The paper concludes that Self-WSP holds promise for RSI but that the mechanisms behind the gains are not interpretable yet.
