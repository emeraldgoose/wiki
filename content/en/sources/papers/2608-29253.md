# QCell: Recombining and Aligning Cell Queries for Overlapping Instance Segmentation

Source: Yaroslav Prytula, Anton Popov, Dmytro Fishman, arXiv:2608.29253, Aug 29, 2026. Accepted at BMVC 2026.

**Lead**: Instance segmentation of overlapping cells in microscopy stays hard because semi-transparent structures produce **weak boundaries and mixed visual evidence** exactly in the overlap regions. Existing methods handle this with local regions of interest or shape priors, but lack **global reasoning across overlapping objects**. QCell is a query-based model with two components: an **instance recombination module** that decomposes and recombines query representations in latent space — letting the model reason about complete object structure under overlap — and a **contrastive query alignment objective** combining distinctive-instance feature learning with separation of overlapping queries. It also introduces a new **Organoid** benchmark for overlapping cell segmentation, and achieves **+2.2 AP and +2.7 AJI on ISBI2014**.

## Why overlapping cells break instance segmentation

Instance segmentation assigns a distinct identity to every object. That assumption fails in microscopy for a specific physical reason: cells are **semi-transparent**. Where two cells overlap, the image contains:

- **Weak boundaries** — there is no sharp intensity edge to separate the objects
- **Mixed visual evidence** — the pixel values in the overlap region are a composite of both cells

This is not a resolution problem or a lighting problem. The information needed to separate the objects is genuinely absent at the pixel level; it has to be inferred from the parts that *are* visible.

Prior work approached this in two ways, and both are local:

- **Local regions of interest** — detect candidate regions, segment within each
- **Shape priors** — impose expected morphology on the result

The gap QCell targets is different: **neither approach reasons globally across overlapping objects.** If cell A overlaps cell B, evidence from A's unambiguous region and B's unambiguous region should jointly inform the separation in the ambiguous middle. Local methods cannot use that.

## Approach

QCell operates in query space, where each object is represented by a learned query vector.

### Instance recombination

The first component **decomposes and recombines query representations in latent space**. The intuition is that an overlapping object's identity is not present in any single local crop — it has to be assembled. By allowing the model to build up and tear down query representations, it can reason about the **complete structure of an object** that is partly occluded, rather than about whatever is locally visible.

### Contrastive query alignment

The second component is a training objective that does two things at once:

- **Distinctive instance feature learning** — pull queries of different cells apart in feature space
- **Separation of overlapping cell queries** — specifically push apart the queries of cells that overlap, which is the hard case

The two-part structure matters. A purely repelling objective collapses everything; a purely attracting one merges. Handling the overlap case *explicitly* is what separates this from generic metric learning.

## Results and the Organoid benchmark

QCell outperforms state-of-the-art methods across multiple benchmarks, with **+2.2 AP** (average precision) and **+2.7 AJI** (Aggregate Jaccard Index) on **ISBI2014**.

The paper also contributes a new **Organoid dataset benchmark** specifically for overlapping cell segmentation. This matters beyond the paper: existing public benchmarks for this task are sparse, which is part of why the problem has been under-addressed relative to its difficulty. A benchmark makes the problem measurable.

## Relevance to SW engineers

- When an object is only partly observable, local methods have a ceiling. Ask whether your system reasons across the whole object or only within a window.
- Semi-transparency is not a special case of poor imaging — it is a case where the deciding information is distributed, and must be reassembled globally.
- If you have a repelling loss that collapses on your hardest cases, consider splitting the objective: a general term plus an explicit term for the hard configuration.
- Benchmarks are infrastructure. The Organoid dataset may matter more long-term than the +2.2 AP.
