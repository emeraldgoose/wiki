# SketchDirector: Complex Scene Sketching via Agentic Layout Reasoning and Detail Refinement

**Source**: [arXiv:2610.41260](https://arxiv.org/abs/2610.41260) · **Published**: 2026-10-27
**Authors**: Yiqi Liang, Xiaodong Cun

## Overview

Existing sketch generation methods often rely on image guidance and are limited to individual objects or simplified scenes, leaving text-guided complex scene sketching underexplored. SketchDirector is an agentic framework that mimics the human sketching workflow and automatically generates multi-concept scene sketches from text.

Given a textual description, it first produces a coarse structural guide, then reasons about object layout and arrangement. A detail refinement stage improves structural consistency in distilling scene sketches from a diffusion prior, treating object curve segments as optimization units rather than unstructured point sets.

## Key points

- Targets complex scene sketching from text rather than individual-object sketching.
- Uses an agentic workflow that mimics iterative human sketch creation.
- Generates a coarse structural guide before object layout reasoning.
- Refines details to improve structural consistency.
- Evaluates multi-concept scene composition rather than only holistic images.

## Details

Traditional automatic methods often treat scene sketches as indivisible entities, making local edits difficult. Real sketching is iterative: artists revise, group, and rearrange elements and adapt refinement to their goals.

SketchDirector aims to bring this flexibility to automatic generation by combining layout reasoning with detail refinement over curve segments. This helps preserve structural relationships across multiple concepts in a scene.
