# Advances in Agentic Computer Graphics

**Source**: [arXiv:2611.01860](https://arxiv.org/abs/2611.01860) · **Published**: 2026-11-01
**Authors**: Hengyu Liu, Jihyeon Je, Ruiqi Wang, Mingxuan Wu, Haven Feng, Qixing Huang, Georgios Pavlakos, Hao Zhang, Jiajun Wu, Maneesh Agrawala, Leonidas Guibas, R. Kenny Jones, Shangzhe Wu, Guandao Yang

## Overview

Computer graphics is built on code, and LLM agents can now generate graphics code and iteratively refine it through feedback. This capability opens a potentially new paradigm in which graphics algorithms are increasingly built around agentic systems that automate progressively complex tasks. Agentic graphics research has expanded rapidly across a diverse range of tasks, making manual literature review difficult. The paper surveys advances in this area and considers automated review to keep pace with new developments.

## Key points

- Computer graphics relies heavily on code.
- LLM agents can generate graphics code.
- Feedback loops refine generated graphics code.
- Agentic systems can automate complex graphics tasks.
- Research in agentic graphics is growing quickly.
- Manual literature review is becoming difficult.

## Details

The paper situates agentic graphics as an emerging intersection of language agents and visual synthesis. Rather than only documenting tools, it maps tasks where agent loops can automate scene construction or algorithmic refinement. The growing volume of related work motivates systematic survey methods. The overall message is that graphics programming is becoming more agentic and that research should adapt to this pace.
