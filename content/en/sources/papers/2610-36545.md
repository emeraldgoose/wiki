# FrameForge: Harnessing Priors of Video Foundation Models for Unified Image Generation

**Source**: [arXiv:2610.36545](https://arxiv.org/abs/2610.36545) · **Published**: 2026-10-27
**Authors**: Yijing Lin, Zhendong Mao, Mengqi Huang, Yuxin Wang, Yongdong Zhang

## Overview

Unified conditional image generation requires a single model to preserve different aspects of a visual input while producing a target image following textual guidance. Pretrained video models encode visual transformations across time, but existing approaches assign condition and target to fixed temporal positions. FrameForge instead models conditional generation through input-adaptive virtual temporal relations: Mixture of Temporal Experts dynamically selects temporal RoPE experts with different virtual intervals to model distance from condition to target, while Chain of Temporal Reasoning uses a latent intermediate state and reasoning-bottleneck attention to transform condition into target. Experiments show strong results in subject-driven generation, canny-to-image generation, and image editing.

## Key points

- Uses video foundation model priors for unified image generation.
- Models adaptive virtual temporal relations between condition and target.
- Demonstrates strong results on multiple image generation/editing benchmarks.

## Details

FrameForge combines MoTE and CoTR to improve conditional image generation flexibility and performance.
