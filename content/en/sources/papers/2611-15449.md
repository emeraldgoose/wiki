# Reading the Unreadable: Text-Aware Image Super-Resolution Needs Reasoning

**Source**: [arXiv:2611.15449](https://arxiv.org/abs/2611.15449) · **Published**: 2026-11-28 · **Original**: 2026-11-11

## Overview

Text-aware image super-resolution aims to recover high-resolution images from low-resolution inputs while preserving textual content. Existing methods treat TAISR as a visual restoration problem augmented with text detection, segmentation or spotting modules, yet they rely on local visual evidence. Humans read heavily degraded text by reasoning over image context, logical patterns and prior knowledge, raising the question whether TAISR needs reasoning.

To test this, the authors introduce ReasonText, a human-curated benchmark that separates reasoning-required text from locally recoverable text, and Ground-Truth Text-Crop Accuracy, a recognition-based metric that measures restoration quality directly on ground-truth crops, avoiding errors from text detection. Evaluation of twelve recent real-world SR and TAISR models shows a consistent and substantial drop on reasoning-required text, with the best locally recoverable accuracy of 45.7% still exceeding the highest reasoning-required accuracy of 24.5%. The failure persists across architectures, backbones and training paradigms.

Two observations motivate a remedy. Text-conditioned SR models restore reasoning-required text substantially better when given ground-truth transcripts in their captions. Modern multimodal large language models can read degraded text in low-resolution images through reasoning. From this, the authors propose Reasoning Transfer via Captioning, a training-free plug-in that uses an external MLLM to infer degraded text and feeds the resulting caption to a frozen text-conditioned SR model.

RTC consistently improves six text-conditioned SR models, especially on reasoning-required text, and gains transfer to existing TAISR benchmarks SA-Text-test and RealText. Surprisingly, a real-world SR model with RTC outperforms the strongest TAISR model with RTC, suggesting that once reasoning is supplied, current text-aware modules add little benefit.

## Key points

- TAISR models rely on local visual evidence and hallucinate characters where local cues are insufficient.
- ReasonText provides perception-grounded difficulty levels and separates reasoning-required from locally recoverable text.
- GTTCA runs recognition on ground-truth crops of SR outputs, removing detection-stage contamination.
- Twelve models evaluated show systematic blind spots on reasoning-required text regardless of design choices.
- Text-conditioned SR models improve markedly when captions contain ground-truth transcripts.
- MLLMs can infer locally unreadable text from low-resolution images via reasoning.
- RTC injects MLLM-inferred text into captions for a frozen text-conditioned SR model, no training required.
- RTC improves all evaluated text-conditioned SR models on ReasonText and on SA-Text-test and RealText.
- With RTC, a strong real-world SR model can outperform the strongest TAISR model, indicating reasoning as a core design axis.

## Details

- ReasonText is human-curated to label each text instance by difficulty, enabling separate measurement of reasoning-required versus locally recoverable performance.
- GTTCA is computed by cropping the ground-truth text regions from SR outputs and running a recognizer, so detection errors do not confound restoration quality.
- The performance gap is large and consistent: lowest locally recoverable GTTCA across models is 45.7%, highest reasoning-required GTTCA is 24.5%.
- Text conditioning helps, but only when the correct transcript is provided; with inferred captions from an MLLM, restoration improves without retraining the SR model.
- RTC is plug-and-play and model-agnostic: an external MLLM writes a caption containing the inferred text, which replaces the default caption of the SR model.
- Improvements are largest on reasoning-required subsets, confirming that the gain comes from reasoning transfer rather than generic enhancement.
