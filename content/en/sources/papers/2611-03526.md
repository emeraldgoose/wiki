# Library of Layers (LoL): Adaptively Ordering Transformer Layers at Runtime

**Source**: [arXiv:2611.03526](https://arxiv.org/abs/2611.03526) · **Published**: 2026-11-02
**Authors**: Abdellah Rahmani, Sean McLeish, Ang Li, Sanae Lotfi, Pascal Frossard, Micah Goldblum

## Overview

Programmers chain reusable primitives such as conditionals and loops in different orders to implement algorithms, while existing language models always execute layers in the same order. Library of Layers (LoL) is an architecture that dynamically orders transformer blocks during inference to solve the problem at hand. It has one hyperparameter, the size of its global library of transformer blocks, allowing a smooth transition between parameter reuse and sparsity while generalizing autoregressive language models, mixture-of-depths designs, and early-exit methods.

## Key points

- Conventional transformers use a fixed layer order.
- Reusable blocks can be sequenced differently for different tasks.
- LoL orders layers dynamically at inference.
- Its single hyperparameter sizes the global layer library.
- It spans parameter reuse and sparsity.
- It generalizes several transformer design families.

## Details

The paper reframes transformer depth as a composable resource rather than a rigid sequence. At inference, LoL selects which blocks to use and in what order for a given problem. Varying the library size lets the model trade between sharing parameters and using specialized sparse subsets. This unifies concepts such as early exit, mixture-of-depths, and autoregressive transformers under one dynamic layer-selection mechanism.
