# MemInStream: Memorizing or Merely Recognizing? Rethinking Streaming Video Memory Evaluation

**Source**: [huggingface](https://arxiv.org/abs/2611.15640)
**Published**: 2026-11-11

## Overview

MemInStream is a benchmark dedicated to evaluating memory capabilities in streaming video understanding. It addresses the core ambiguity of existing memory-related benchmarks: an incorrect answer may reflect a failure in visual understanding rather than forgetting, and a correct answer may rely on linguistic priors or recent observations without requiring historical memory.

The benchmark develops an evidence-controlled validation protocol that associates each question with temporally localized evidence intervals. Questions are retained only when models can answer from the annotated evidence but cannot resolve them using recent observations, post-evidence observations, or textual input alone. This disentangles memory limitations from understanding failures and reduces memory-independent shortcuts.

## Key points

- **Evidence-controlled validation**: each question is tied to localized evidence intervals; validation requires that the question be answerable from the evidence yet not solvable from recent or textual input alone.
- **Four categories**: Episodic Retrieval, State Tracking & Updating, Multi-Evidence Integration, and Contextual Memory across diverse video scenarios.
- **Why QA accuracy alone is insufficient**: failures can arise from visual understanding rather than forgetting; success can rely on linguistic priors or recent observations without historical memory.
- **Goal**: provide a comprehensive and reliable benchmark for systematically evaluating memory in streaming video.

## Details

The benchmark's validation protocol ensures that retained questions reflect true memory "necessity" by filtering out those answerable by shortcuts. This is important for deployment settings where streaming video accumulates unbounded history and genuine long-range recall is the capability of interest. The four categories cover recall of specific episodes, dynamic state evolution, integrating evidence across temporally distant segments, and contextual interpretation.
