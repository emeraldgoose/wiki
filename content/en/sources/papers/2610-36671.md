# Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs

**Source**: [arXiv:2610.36671](https://arxiv.org/abs/2610.36671) · **Published**: 2026-10-27
**Authors**: Donghyeon Cho, Joowon Kim, Seungho Shin, Eunho Yang

## Overview

Diffusion vision-language models process their entire input at every denoising step, and since visual tokens make up 89-97% of this input on the benchmarks studied, most decoding computation is spent repeatedly processing the same image. Visual token pruning partially relieves this burden by removing part of the visual tokens, but it loses the removed information and still processes the remaining image at every step. To measure how often the image is actually needed, the authors compare LLaDA-V's predictions with and without the image at every decoding step and find that removing the image changes a token being unmasked at only 22.8% of steps on average and as few as 7.9%. They propose LOWN, a decoding method that decides at every step whether to process the image and how many tokens to unmask. LOWN predicts masked tokens without the image and processes the image only when this prediction disagrees with the last image-conditioned prediction. Agreement certifies the earlier prediction for reuse, and the number of certified tokens sets how many are unmasked in that step. Because need for the image differs across benchmarks, LOWN's adaptive decision is required rather than a fixed schedule. Without training or a tuned threshold, LOWN retains 99.6% of LLaDA-V's score on ten benchmarks at 35.3% of the decoding FLOPs on average. It also generalizes across LLaDA-based DVLMs, composes orthogonally with visual token pruning, and runs under key-value caching for further efficiency gains.

## Key points

- Visual tokens are 89-97% of DVLM input on studied benchmarks.
- Removing the image changes unmasked token selection at only 22.8% of steps on average.
- LOWN skips image processing when an image-free prediction agrees with the last image-conditioned one.
- Agreement certifies tokens for reuse and sets how many to unmask.
- Adaptive decisions matter because image need differs across benchmarks.
- LOWN retains 99.6% of score at 35.3% decoding FLOPs on average.
- It is training-free and composes with pruning and KV caching.

## Details

Visual token pruning still processes the remaining image every step, while LOWN can skip the image entirely when predictions agree. The certificate mechanism reuses validated image-conditioned predictions rather than discarding visual information permanently.
