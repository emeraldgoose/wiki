# Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs

**Source**: [huggingface](https://arxiv.org/abs/2610.36671)
**Date**: 2026-10-27


## Overview

Diffusion vision-language models (DVLMs) process their entire input at every denoising step. Since visual tokens make up 89–97% of this input on the benchmarks we study, most of the decoding computation is spent repeatedly processing the same image. Visual token pruning methods partially relieve this burden by removing part of the visual tokens, but they lose the removed information and still process the remaining image at every step.
