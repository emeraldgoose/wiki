# Less from More: Reinforcing Sparse Video Reasoning from Dense References

**Source**: [huggingface](https://arxiv.org/abs/2610.10893)
**Date**: 2026-10-07

## Overview

Video-language models (Video-LLMs) commonly assume that more temporal observations lead to more reliable reasoning, leading to architectures that process hundreds of frames. This paper challenges that assumption: the real challenge is not processing more frames efficiently, but learning to reason reliably when temporal evidence is limited. The authors propose SAVER (Sparse Video Reasoning), a dense-to-sparse post-training framework that uses dense video views as training-time references for sparse-frame inference. During reinforcement post-training, paired dense and sparse views are optimized with grounding rewards and a reliability-gated reference reward, encouraging the model to develop robust sparse-view reasoning without collapsing to the dense reference.

## Background

Recent Video-LLM families (Qwen-VL, InternVideo, Video-LLaVA) scale frame counts to improve performance on benchmarks like ActivityNet and NExT-QA. However, inference cost scales linearly with frames, and real-world deployment often faces bandwidth, latency, or compute constraints that limit frame budgets. Prior work on frame selection (e.g., uniform sampling, learned selectors) optimizes which frames to keep but doesn't teach the model to reason well with fewer frames.

## Methodology

SAVER operates in two phases:
1. **Dense reference construction**: For each training video, a dense view (e.g., 64 frames) and a sparse view (e.g., 4 frames) are sampled.
2. **Reinforcement post-training**: The model is trained with a grounding reward (does the answer match the dense-view ground truth?) and a reliability-gated reference reward (the sparse view's answer should be consistent with the dense view's, but only when the dense view is confident). This prevents the sparse view from simply mimicking the dense view's errors.

The framework is model-agnostic and applied to Qwen2.5-VL and InternVideo2.5.

## Key Findings

- **Sparse can match dense**: With SAVER post-training, 4-frame inference matches or exceeds 64-frame baselines on Video-MME, NExT-QA, and ActivityNet-QA.
- **Reliability gating matters**: Without the reliability gate, the sparse view collapses to the dense view's failure modes.
- **Efficiency**: 16x fewer frames at inference with comparable accuracy.

## Relevance to Software Engineers

For teams deploying Video-LLMs under latency or compute budgets, SAVER provides a post-training recipe to maintain reasoning quality at a fraction of the frame cost. The approach is compatible with existing Video-LLM checkpoints and doesn't require architectural changes.
