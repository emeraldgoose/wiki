# Rethinking Relative Policy Differences Transfer of On-Policy Distillation

**Source**: Wu et al., arXiv, 2026-10-09

**Lead**: Conventional on-policy distillation (OPD) needs a teacher substantially stronger than the student, because it matches the teacher's absolute distribution. Recent work instead transfers the *relative* policy difference between a proxy expert and a proxy reference—but it is unclear which differences carry useful supervision and which targets can use them. This paper derives a unified view where the expert–reference log-ratio defines an implicit reward for KL-regularized optimization (recovering OPD as a special case, generalizing to any-to-any transfer), and systematically shows that task-directed RL/SFT differences transfer consistently while scale-only gaps do not, with expert, reference, and target playing distinct roles.

## Background

OPD trains the student on its own rollouts with dense token-level teacher supervision (reverse-KL matching), reducing distribution shift versus offline SFT. But the signal goes uninformative when teacher and student are close, so production pipelines (Qwen3, MiMo-V2-Flash) still depend on much stronger teachers. Relative-update transfer relaxes this: given reference $\pi_{\mathrm{ref}}$ and adapted expert $\pi_{\mathrm{exp}}$, the student learns from the log-ratio $\log \pi_{\mathrm{exp}} - \log \pi_{\mathrm{ref}}$ on its own rollouts, so the source need not outperform the student. Prior studies only tested narrow RL-derived pairs, leaving the transfer conditions unmapped.

## A Unified Policy Optimization View (A2-OPD)

Conventional OPD's reverse-KL objective rewrites as KL-regularized optimization where the relative term $\log \pi_T - \log \pi_{\mathrm{ref}}$ acts as reward and a KL term anchors the policy—but the same reference appears in both, collapsing it to absolute matching. Decoupling them gives the any-to-any objective: the fixed proxy difference $\Delta_{\phi} = \log \pi_{\phi}^{+} - \log \pi_{\phi}$ scales by $\alpha$ as reward while the target regularizes toward its own $\pi_{\mathrm{ref}}$ with weight $\beta$. Since $\Delta_{\phi}$ encodes the task reward up to scale and a state-only normalizer, centering the per-action weight over actions removes the intractable normalizer and yields a variance-reduced on-policy actor loss evaluated token-wise. OPD, ExOPD, and prior relative-transfer methods all fall out as special cases (choice of proxy pair, target reference, $\alpha/\beta$).

## When Do Relative Differences Transfer?

Three findings from systematic Qwen3/Qwen2.5 experiments:

1. **Task-directed differences transfer; scale gaps don't.** With Qwen3-8B fixed as target, all RL/SFT pairs give target gains $G_T$ of +9.78 to +32.23 (e.g., Qwen3-4B-RL/Qwen3-4B: +26.84; Skywork-7B/Qwen2.5-7B: +32.23), while four scale-only pairs give +3.42 down to −1.03—despite comparable update magnitudes. Token-overlap trajectories confirm the target follows the task-aligned direction.
2. **Expert supplies capability; reference filters it.** Fixing the reference, stronger RL checkpoints raise both proxy and target gains (early→regular→late: $G_T$ 22.42→26.84→28.18). Fixing the expert (Qwen3-4B-RL), swapping the reference from base to early-RL cuts $G_T$ from 26.84 to 9.62—the reference removes shared behavior and exposes only the residual. The reference need not be the expert's training origin (Qwen2.5-3B reference gives the largest gain, 29.09).
3. **Useful differences aren't universal; compatibility is familial.** One difference helps Qwen3 targets (+9.78 to +29.09) but not Qwen2.5 ones (−2.46 to +2.72); outcome splits by model family, not by proxy–target KL distance. Switching to a same-family reference rescues failed transfers (Qwen2.5 targets turn positive). Success means the update moves the target toward the expert *and* generalizes—failing targets fit training accuracy while validation stays near zero.

## Experiments

**Setup**: Fixed transfer strength $\alpha/\beta = 1$, top-16 token distribution; proxy pairs from RL/SFT on DeepMath-103K (math) and Eurus-RL-Code (code); targets across Qwen3-1.7B/4B/8B and Qwen2.5-7B/7B-Instruct/7B-Math.

**Benchmarks**: Eight math benchmarks (AIME24/25/26, SMT25, CMIMC25, HMMT25-Feb/Nov, HMMT26-Feb; 16 samples) and three code benchmarks (HumanEval+, MBPP+, LCB; 8 samples). Metrics: proxy gain $G_P$, target gain $G_T$, realization ratio $R_{\mathrm{perf}} = G_T/G_P$, plus KL diagnostics.

**Results**:

| Setting | Math $G_T$ | Code $G_T$ |
|---------|-----------|-----------|
| Qwen3-4B-RL/Qwen3-4B → Qwen3-8B | +26.8 | +2.3 |
| Qwen3-4B-RL/Qwen3-1.7B → Qwen3-8B | +25.9 | +1.9 |
| Qwen3 pair → Qwen2.5-7B (cross-family) | −1.7 | −6.4 |
| Qwen2.5-based proxy → Qwen3-8B | +24.6 | +9.1 |

Transfer patterns persist across domains: configurations that succeed/fail on math do the same on code. Proxy gain correlates strongly with target gain (Pearson $r = 0.96$), but only for task-directed pairs.

## Relevance to Software Engineers

If you maintain post-training pipelines, the practical rules are: (a) reuse *update directions* (RL/SFT deltas), not bigger checkpoints—scale alone is weak supervision; (b) pick the reference deliberately, since it selects which residual the student sees; (c) match reference and target families, or budget for rescue experiments. The A2-OPD framing also unifies OPD variants under one loss, simplifying implementation: one centered actor loss with $\alpha/\beta$ controlling transfer strength. Limitation: all evidence is Qwen-family math/code; cross-architecture generality is untested.
