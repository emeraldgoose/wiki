# OSWAM: An Effective World Action Model with One-Step Action Generation

**Source**: [arXiv:2610.35850](https://arxiv.org/abs/2610.35850) · **Published**: 2026-10-26
**Authors**: Guowen Zhang, Liyi Chen, Xu Hu, Pengfei Wang, Jingfan Chen, Chenhang He, Lei Zhang

## Overview

Direct-policy World Action Models decouple action generation from explicit future visual prediction for efficient inference in autonomous driving and embodied control. However, they still require tens of denoising steps for competitive action quality. Reducing steps naively collapses the nonlinear multi-step trajectory into coarse updates and degrades quality. OSWAM introduces one-step action generation using imagination tokens that initialize diffusion with physical and action-conditioned priors, plus privileged information distillation with future conditioning. It achieves comparable or better results than multi-step baselines with about 3x speedup and real-time inference.

## Key points

- Addresses step-heavy denoising in direct-policy WAMs.
- Uses imagination tokens as structured action priors.
- Supports real-time, single-step action generation.

## Details

OSWAM combines world-action modeling with one-step diffusion, improving action quality and latency for autonomous driving and embodied control.
