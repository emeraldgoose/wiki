# MixTok: Adaptive Visual Tokenization with Global 1D Tokens and Sparse 2D Refinement

**Source**: Li et al., arXiv, 2026-10-09

**Lead**: Visual tokenizers force a bad trade: 2D grids preserve local detail but waste tokens on simple regions, while compact 1D sequences are efficient but blur fine structure—and nearly all assign every image the same token count regardless of complexity. MixTok combines a short 1D global representation with sparse 2D tokens allocated by a content-adaptive router that decides both *where* to refine and *how many* tokens each image gets under a target average budget. On ImageNet 256×256 it achieves rFID 1.195 (reconstruction, ~128 tokens) and gFID 1.95 (generation, ~131 tokens).

## Background

2D tokenizers (VQGAN, MAGVIT-v2) keep an explicit token↔location correspondence but allocate uniform density—smooth sky costs as much as textured objects. 1D tokenizers (TiTok, TA-TiTok, MAETok) aggregate globally into short sequences but struggle to recover local detail from the compact code. On the budget axis, most tokenizers are fixed-length per image; flexible variants (FlexTok's ordered coarse-to-fine sequences, ALIT's recurrent allocation, CAT's caption-based ratios) either don't choose per-image budgets or don't adapt spatial allocation. MixTok jointly solves both: spatial selection plus per-image budget under one average-budget constraint.

## Hybrid Visual Representation

Built on off-the-shelf tokenizers (TiTok-L-32 for 1D, LlamaGen VQ-16 for 2D/shared decoder), MixTok keeps the full 1D sequence $T_{\mathrm{1D}}$ plus selected 2D tokens $\{(r_k, t^{\mathrm{2D}}_{r_k})\}$ at locations $\mathcal{R}$, for $B = L + K$ content tokens (locations stored as side information). Since 1D features lack spatial correspondence, they are expanded to a grid via spatial queries $G_{\mathrm{1D}}$ and aligned by adapter $P_{\mathrm{1D}}$; the mixed decoder input replaces 1D-derived features with 2D features exactly at $\mathcal{R}$, then a shared decoder reconstructs. Training uses L1 + LPIPS + GAN losses with the 1D encoder/quantizer frozen.

## Content-Adaptive Router and Two-Stage Generation

The router has two parts. A **Reconstruction Grid Scorer** ranks locations by refinement priority from aligned 1D/2D features and the 1D-base reconstruction, supervised by local reconstruction-error reduction plus the mixed reconstruction loss via a differentiable selection surrogate. A **Budget Controller** applies top-$p$ selection to the softmax-normalized scores: keep the shortest prefix whose cumulative probability reaches $p$, so concentrated score mass means few tokens and dispersed mass means many; $p$ is calibrated once to hit the target average budget.

Generation is two-stage MaskGIT: stage 1 generates 1D tokens; a distilled **Generation Grid Scorer** (1D-base features only) plus the same top-$p$ rule picks $\mathcal{R}$; an Embedding Adapter maps base features to spatial context embeddings for unselected positions; a fine-tuned Halton-MaskGIT generates only the masked $\mathcal{R}$ tokens, and the shared decoder renders the final image.

## Experiments

**Setup**: ImageNet 256×256; main config TiTok-L-32 (32 1D tokens) + LlamaGen VQ-16 (16×16 grid); reconstruction evaluated on all 50K validation images (rFID, PSNR), generation via class-conditional gFID on 50K samples with the ADM evaluator; latency/FLOPs on one RTX 5090 at batch size 1.

**Benchmarks**: ImageNet reconstruction and class-conditional generation against TiTok, FlexTok, DetailFlow, One-D-Piece, MaskGIT, LlamaGen, AdaGen baselines.

**Results**:

| Task | MixTok | Closest baseline |
|------|--------|------------------|
| Reconstruction rFID / PSNR (~128 tokens) | **1.1950** / 19.51 dB | DetailFlow-16: 1.1370 / 19.46; TiTok-S-128: 1.7222 / 17.72 |
| Generation gFID (~131 tokens, 16 rounds) | **1.95** | TiTok-S-128: 2.00 (64 rounds); DetailFlow-32: 2.63 (39 rounds, ~2× tokens) |
| Transfer (ALIT–VQGAN, 128 tokens) | rFID 2.9453 → **2.4720** | ALIT-128 |

Sparse 2D refinement alone lifts generation gFID from 4.33 (1D base) to 1.95 with 8 extra sampling rounds; single-image latency is $3.77\times$ / $2.48\times$ faster than the TiTok/DetailFlow configs. Ablations confirm both components: learned scorer beats random/uniform/gradient-entropy rankings (1.1950 vs 1.40–1.66), and top-$p$ beats fixed-$K$ and shuffled budgets.

## Relevance to Software Engineers

MixTok matters wherever image tokens are a cost center: shorter, content-aware sequences cut autoregressive steps, KV-cache memory, and per-image latency in multimodal serving. The design pattern—cheap global pass, learned scorer, budgeted sparse refinement—is portable to other per-request adaptive-compute problems (e.g., token pruning, mixture-of-depth). Limits to note: reconstruction still needs dense 2D encoding, the second-stage generator runs on the full grid, and evaluation is ImageNet-256 only, so budget behavior at higher resolutions is unverified.
