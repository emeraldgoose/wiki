# TurnTurk-GPT: Text-Based Turn-Taking Prediction for Turkish

**Source**: [arXiv:2610.42010](https://arxiv.org/abs/2610.42010) · **Published**: 2026-10-27
**Authors**: Ahmet Tuğrul Bayrak, Fatma Nur Korkmaz, Nur Yağmur Tuncer, Mustafa Sertaç Türkel

## Overview

Spoken dialogue systems need to know when a user has finished speaking. Turkish NLP resources for turn-taking have been limited, and available speech resources have not covered this task well. TurnTurk-GPT is a text-based turn-taking predictor for Turkish built by fine-tuning a Turkish GPT-2 model with the TurnGPT objective.

The model is trained on synthetic and real dialogue and evaluated on real Turkish conversation against rule baselines, a zero-shot Turkish language model, and a commonly used multilingual model.

## Key points

- Focuses on text-based turn-taking prediction for Turkish.
- Fine-tunes a Turkish GPT-2 model using the TurnGPT objective.
- Uses synthetic and real Turkish dialogue for training.
- Evaluates on real Turkish dyadic conversation.
- Compares rule baselines, zero-shot Turkish LM, and multilingual model.
- Accounts for Turkish agglutinative and predominantly verb-final syntax.
- Released publicly as a baseline on Hugging Face.

## Details

Text-based predictors frame turn-taking as token-level prediction inside a language model. TurnGPT adds a turn-shift token to a pre-trained transformer and trains with causal language modeling loss, so the turn-shift probability can update incrementally as words arrive.

The paper notes that Turkish concentrates completion information in suffixes on the clause-final verb. This makes language-specific modeling important, especially given the limited Turkish turn-taking resources and benchmarks.
