# R^2Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop

**Source**: [arXiv:2610.22740](https://arxiv.org/abs/2610.22740) · **Published**: 2026-10-22
**Authors**: Mingda Zhang, Yun Huang, Qiang Huang, Yanjin Li, Rui Qian, Qichao Zhao, Tiesunlong Shen, Na Zhao, Jian Wang, Xiaoying Tang

## Overview

Agentic orchestration solves complex human tasks, but existing learning faces hand-designed curricula, advantage collapse when all rollouts reach the same outcome, and unreliable evaluation signals. R^2Orch proposes recursive self-play orchestration: an inner loop of self-play that improves the orchestrator on self-chosen tasks, and an outer loop that improves how the inner loop improves. The approach sits within a skill-internalization loop to make orchestration learning more robust.

## Key points

- Addresses hand-designed curricula and advantage collapse.
- Inner self-play loop on self-chosen tasks.
- Outer loop optimizes the improvement process itself.

## Details

R^2Orch shifts orchestration learning toward recursive self-improvement, combining self-play and skill internalization to improve both task solving and meta-level learning quality.
