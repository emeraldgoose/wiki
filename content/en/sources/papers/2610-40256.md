# When Requirements Interact: Scaling Long-Horizon Coding via Interdependent Specifications

**Source**: [arXiv:2610.40256](https://arxiv.org/abs/2610.40256) · **Published**: 2026-10-27
**Authors**: Yishuo Cai, Minzheng Wang, Liang Zhao, Linghao Zhang, Lei Li, Shicheng Li, Xu Sun, Fuli Luo

## Overview

Real-world software changes must satisfy multiple interacting requirements, such as interface compatibility and error handling, while preserving existing dependencies. Existing coding-agent benchmarks often lack sufficient specification quantity and diversity, emphasizing primary goals while ignoring constraints. This paper argues that specification design should organize requirements into interdependent specifications rather than accumulating independent checklist items.

CodeSpecWeave is a framework for synthesizing coding tasks with rich, interdependent specifications. Grounded in specification seeds derived from real developers, a synthesis agent explores repository context and iteratively develops task requirements and executable test suites. It intentionally creates coupled constraints that require simultaneous reasoning.

## Key points

- Coding agents need to handle multi-dimensional, interacting specifications.
- Existing task data falls short in specification quantity and diversity.
- Adding independent requirements can make tasks trivial checklists.
- CodeSpecWeave builds interdependent specifications and reliable verifiers together.
- Produces 4,670 training tasks across 2,865 repositories for reinforcement learning.
- CodeSpecWeave-Bench contains 100 tasks with 1,044 specifications.
- Evaluations reveal notable gaps and remaining headroom under interdependent requirements.

## Details

A task is represented as a repository, natural-language request, set of embedded specifications, and execution environment. The synthesis agent explores repository context and develops requirements and tests iteratively so constraints are coupled during implementation. The goal is to push agents toward holistic exploration and joint reasoning rather than isolated edits.

The benchmark is intended to evaluate leading coding agents under realistic, interdependent requirements and to provide scalable training data for long-horizon coding. Reported experiments show substantial gains over strong training baselines on DeepSWE-v1.1.
