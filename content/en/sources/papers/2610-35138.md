# Co-Design Bench: Multimodal Collaborative Coding Evaluation for Agentic Models

**Source**: [arXiv:2610.35138](https://arxiv.org/abs/2610.35138) · **Published**: 2026-10-26
**Authors**: Xilin Wei, Shengyuan Ding, Xinyu Fang, Tiancheng Gu, Yuchi Wang, Zhixun Li, Ziyu Liu, Yuhang Zang, Weixiang Yu, Cheng Lu, Chonggao Sun, Tong Zhou, Dahua Lin, Hang Zhang, Shuai Bai, Dayiheng Liu

## Overview

Evaluating human-AI co-design requires testing whether coding agents can translate real users' multimodal requests into working application revisions. Co-Design Bench is a reference-free benchmark of 273 tasks curated from 37,463 deduplicated queries across 26,314 real user coding sessions. Its two tracks, Multimodal Editing and Repository Editing, cover localized edits with optional image, audio, video, or document inputs and coordinated repository revisions. Tasks span three capability dimensions: Grounded Understanding, UI Transformation, and Functional Implementation. Each task pairs normalized requests and runnable pre-edit applications with 2,331 hidden expert-authored acceptance criteria. A judge-then-refute protocol grades criteria using source and browser evidence, challenges positive verdicts with a separate LLM verifier, and audits visual and interaction claims without gold code or target screenshots. Under a shared agentic harness, the strongest of ten model endpoints passed an average of 69.9% of criteria per task but fully satisfied only 26.4% of tasks. All ten endpoints achieved lower criterion completion on repository edits spanning three or four change types than on those spanning one or two. The benchmark thus provides a testbed for studying the gap between partial requirement satisfaction and complete task success under agentic execution for real-user application revisions.

Each task combines a normalized request with a runnable pre-edit application and hidden expert acceptance criteria, allowing evaluation of real-world revisions rather than isolated snippets.
