## Overview

Evaluating human–AI co-design requires testing whether coding agents can translate real users’ multimodal requests into working application revisions. We introduce Co-Design Bench, a reference-free benchmark of 273273 tasks curated from 37,46337{,}463 deduplicated queries across 26,31426{,}314 real user coding sessions. Its two tracks, Multimodal Editing (ME) and Repository Editing (RE), cover localized edits with optional image, audio, video, or document inputs and coordinated repository revisions.
