# UniSpark: Exploring Hybrid Attention for Multimodal Understanding and Generation

**Source**: [arXiv:2611.16517](https://arxiv.org/abs/2611.16517) · **Published**: 2026-11-12
**Authors**: Jiancheng Pan, Yuzheng Liu, Hengyuan Cao, Qiyuan Zhang, Yangyan Li, Biao Gong, Zheng Zhang, Ka Long Cheng, Xinyang Wang, Yujun Shen

## Overview

Unified multimodal models have to satisfy two conflicting workloads: understanding needs to interpret visual inputs, while generation needs to synthesize images from text or visual conditions, and both get expensive when high-resolution images and multi-image sequences flood the model with visual tokens. UniSpark-9B attacks this with a hybrid attention design. Its backbone is a Mixture-of-Transformer-Experts with roughly 9B parameters in each branch, and every layer mixes full attention for explicit query-key interactions with GatedDeltaNet linear attention, which propagates context through a recurrent matrix state at a cost linear in sequence length.

The paper's central modeling idea concerns what later predictions are allowed to see. In interleaved generation the model denoises an image as a noisy target, and once generated, its clean representation becomes context for subsequent text and image predictions. UniSpark keeps noisy targets private: they can read the public context of preceding text and clean visual blocks, but no later block can attend to them. Full-attention layers enforce this with blockwise masks, and linear-attention layers enforce it by discarding the recurrent-state updates made inside noisy blocks.

Training is a four-stage curriculum that jointly optimizes understanding and generation, scaling image synthesis from a 512-scale setting through 1024-scale refinement up to 2K. The selected sources contain 159.7M generation samples, 213.4M understanding samples, and 624.8K interleaved sequences. UniSpark scores 2470.3 on MME-S and 0.83 on GenEval, and qualitative examples extend the recipe to video generation and video editing after a post-SFT adaptation.

## Key points

- UniSpark-9B runs on a Mixture-of-Transformer-Experts backbone with approximately 9B parameters per branch; text and semantic visual tokens use the understanding expert while VAE latent tokens use the generation expert.
- Full-attention layers handle explicit token interactions, while GatedDeltaNet layers compress preceding context into a recurrent matrix state whose computation scales linearly with sequence length.
- Noisy visual targets are private: in full-attention layers no other block may attend to them, and in linear-attention layers their state updates are discarded after producing their outputs, so later predictions never see transient denoising noise.
- Switching experts does not reset accumulated context: understanding and generation tokens compute their own query, key, and value quantities but share the recurrent state and short convolution history along the permitted multimodal history.
- Training data include 159.7M generation samples, 213.4M understanding samples (with 10.0M OCR and 4.5M grounding), and 624.8K interleaved sequences.
- On understanding benchmarks UniSpark records the highest listed MME-P (1766.0), MME-S (2470.3), MMBench (86.7), and MMVP (72.0) scores, and beats BAGEL by 6.2 points on MM-Vet and 4.1 points on MathVista; on MMMU-Val it scores 56.7, below MetaQuery-XL's 58.6.
- After unified SFT it reaches 0.83 overall on GenEval for text-to-image generation, and 3.13 overall on ImgEdit editing evaluated with a Qwen3-VL judge on all 737 samples.
- Against BAGEL, median image generation latency drops from 11.76 to 7.27 seconds at 512 x 512 (1.62x) and from 45.80 to 14.16 seconds at 1024 x 1024 (3.23x); at 2048 x 2048 UniSpark is faster than SenseNova-U1 (51.48 versus 58.34 seconds) but uses 62.74 GB of peak memory versus 37.39 GB.
- At 1024 resolution BAGEL represents an image with 4,096 image tokens versus 1,024 for UniSpark and SenseNova-U1, so BAGEL's higher tokens-per-second does not translate into faster images.

## Details

### Hybrid MoT architecture with public context and private targets

Each decoder layer carries expert-specific normalization, attention projections, and feed-forward parameters, and the two experts exchange information only through the context each attention operator permits. The interleaved protocol is best seen in a sequence of text, noisy target, and clean-context blocks: a later text or noisy block can use earlier clean visual context but not earlier noisy targets, and a noisy target cannot peek at its own clean counterpart. Within a block, text uses causal attention while clean visual blocks and noisy targets use bidirectional attention. In linear-attention layers the public state advances only when the current block is public; a noisy target starts from the preceding public state, makes local updates for its outputs, and those updates are thrown away afterward.

### Data and staged training

The four-stage curriculum begins with joint multimodal foundation training, then a resolution-scaling stage lifts generation to a 512-scale setting, high-resolution refinement extends it through 1024-scale settings and up to 2K, and supervised capability refinement polishes answer accuracy and instruction following. Understanding inputs keep an independent resolution budget, so higher-resolution generation does not force every semantic condition to expand at the same rate. Interleaved sequences continue to contribute in later stages, exposing hybrid attention to longer visual blocks and cross-output dependencies.

### Measured efficiency and limits

The efficiency study runs each model on a dedicated H20-3e GPU in BF16 at batch size 1 with median latencies over 12 measured runs. UniSpark's advantage grows with resolution but costs memory, which the authors state openly as a resolution-dependent latency benefit with a memory cost. The authors also flag that the ImgEdit numbers use a different judge than the baselines and are therefore reference results rather than directly comparable scores, and that strong perception results do not imply uniformly better reasoning given the MMMU gap.
