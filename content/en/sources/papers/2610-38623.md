# Cross-Primitive Consistency in Jev

**Source**: [arXiv:2610.38623](https://arxiv.org/abs/2610.38623) · **Published**: 2026-10-28
**Authors**: Xu Liu, Guikun Chen, Kanzhi Wu, Wenguan Wang

## Overview

Jev supports efficient decision-making with large language models through typed querying primitives. The same semantic state can be expressed in different formats, such as binary queries and multiple-choice queries. Although this flexibility is convenient, the consistency of decisions across these primitive forms has not been systematically studied. This paper introduces PrimaCons, a four-axis benchmark that evaluates cross-primitive consistency while preserving the meaning of the original query.

Evaluations across three sizes of Jev reveal consistency violations on all four measured axes. The results show that changing the primitive representation of a question, without changing its semantics, can still change the model's decision. This suggests that primitive choice is not a neutral formatting issue; it can alter downstream decision behavior.

## Key points

- Cross-primitive consistency measures whether the same semantic decision is preserved when the query primitive changes.
- PrimaCons separates the evaluation into four axes so that different sources of inconsistency can be isolated.
- Experiments across three Jev scales show violations on every axis, rather than on only one edge case.
- The benchmark is designed to preserve query semantics, so observed differences reflect primitive inconsistency rather than task changes.
- The findings motivate careful primitive selection and consistency checks in Jev-based decision systems.

## Details

The paper frames Jev as a typed interface for LLM decision-making and argues that prior work has explored its capabilities, implementations, and extensions without testing whether decisions remain stable across equivalent primitive expressions. PrimaCons addresses that gap by holding semantics fixed while varying the primitive form. The reported violations are systematic enough to appear across models and axes, indicating that cross-primitive inconsistency is a shared failure mode rather than an isolated model artifact.
