# SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models

**Source**: [arXiv:2611.15777](https://arxiv.org/abs/2611.15777) · **Published**: 11 November 2026
**Authors**: Lichen Li, Ziping Dong, Sicheng Feng, Qi Li, Xinchao Wang

## Overview

System One models predict a distribution over predefined outcomes in a single forward pass, trading open-ended token generation for low latency and structured outputs that downstream software can consume directly. The authors argue that aggregate accuracy on current benchmarks reveals little about either the breadth of such models' abilities or the trustworthiness of their individual decisions. They therefore introduce SO-Arena, a benchmark that pairs a fine-grained capability leaderboard with a separate reliability score.

SO-Arena gathers 2,919 tasks from 40 established public sources into 11 domains organized into five capability families: semantic understanding, knowledge and reasoning, safety and policy compliance, evidence assessment, and agent task completion. Reference labels are manually verified against the evidence a model can actually see, nine domains carry difficulty tiers built from domain-specific criteria, and tasks are posed either as static judgments or inside web and tool environments where each decision changes the state for the next. Reliability is probed in two ways: every multiple-choice item is shown in its original order plus 12 reorderings, and the correct option is sometimes removed entirely so that a dependable model should answer Null.

The evaluation covers 21 models: 16 open-weight System One models ranging from 0.4B to 31B parameters, the auto-switching StartLux Auto, two closed decision APIs (Jev API 1.14 and OpenAI Decisions), and two closed System Two references, GPT-6 Sol and Luna. The headline finding is a disconnect between the two axes: capability and reliability rank models differently, and the best-performing System One model places only seventh on reliability.

## Key points

- SO-Arena spans 2,919 tasks: 2,300 static and 619 environment-based, the latter including 337 web tasks (100 single-step judgments and 237 reference-route tasks) and 282 interactive tool-use episodes scored under BFCL or ToolSandbox criteria.
- The capability score averages the hardest tier of each domain with equal domain weights, so larger domains cannot dominate the leaderboard and demanding tasks count most.
- GPT-6 Sol and Luna still lead overall capability, with the strongest System One models, GLiDE and KnowLine-31B, trailing Luna by about ten points.
- In exchange, every open-weight System One model answers within 0.3 seconds per task on a single H100 GPU, tens of times faster than the System Two references.
- The two most reliable models, JevAny-27B and Jev API 1.14, rank only eighth and sixth of 18 in performance, and the abstract notes the best-performing System One model ranks just seventh in reliability.
- Option-order stability is high almost everywhere: 14 of 18 System One models keep their answer in more than 0.8 of reorderings (between 0.83 and 0.94), while Laya falls to 0.35 and SII-4B, Kev-4B, and OpenAI Decisions sit between 0.68 and 0.72.
- Null discrimination tracks performance only loosely: Kev-27B, Jev API 1.14, and JevAny-27B each exceed the four best-performing System One models at noticing that no offered option is correct.
- Reasoning helps selectively: in Math, letting StartLux Auto think lifts its score from 50.8 to 92.5, close to Luna.
- In Knowledge & Commonsense, Sentiment & Emotion Understanding, and Retrieval & Reranking, System One models perform comparably to Luna; in Math, Scientific Reasoning, and Code Understanding, both tested sizes fall far behind.

## Details

### Benchmark construction

Tasks come from traceable public sources, with items carrying questionable labels dropped after human and LLM review, and each task records its source, version, and original identifier; model-derived references are flagged in metadata. Static tasks use three decision formats, including binary judgments posed as yes/no questions and ordinal scores on native scales; open-answer math problems, which have no natural options, receive distractors built from a base model's wrong answers, intermediate solution results, and rule-based near misses. Environment-based tasks either judge a recorded page state or act step by step: multi-step web tasks follow a replay-verified reference route, while tool-use episodes execute inside BFCL or ToolSandbox simulators that score each episode by the corresponding benchmark's success criteria.

### Where System One matches System Two

The gap to GPT-6 Luna depends strongly on the domain. In Intent & Routing, Safety, Task Completion Verification, Tool & API Use, and Web Interaction, GLiDE comes within 4 points of Luna while the smaller StartLux Instant trails by up to 29, and the larger, newer backbone of each model family wins in all five domains. In Math, Scientific Reasoning, and Code Understanding both 4B and 27B models trail significantly, and the added thinking mode closes the gap mainly in Math and Scientific Reasoning.

### What reliability adds

Order stability largely follows performance, and flip-rate analysis shows models change their answers much more often on reorderings of questions they answered wrongly than on ones they answered correctly, so instability arises mostly where a model performs badly. Null discrimination behaves differently, varying far more than order stability among models at similar performance levels, which the authors read as evidence that a performance score says little about whether a model notices a missing answer and that this property must be measured directly. The paper closes by arguing that capability and reliability are complementary dimensions that should be characterized and reported together for System One models.
