# VibePrevisBench: Evaluating Agentic Coding for 4D Scene Generation in Blender

**Source**: [huggingface](https://arxiv.org/abs/2611.15789)
**Published**: 2026-11-11

## Overview

VibePrevisBench is a benchmark for 4D scene reconstruction: an agent turns a brief into an executable 4D scene in Blender and renders a graybox proxy video that conditions controllable video generation. Its 242 tasks span four input kinds — scripts, photos, continuations, and reference videos. Each delivery is scored on two dimensions: rule-based Scene Check re-runs the code and compares the exported 4D scene with hidden ground-truth facts across nine dimensions, and VLM-based Screen Check asks a VLM judge whether the facts that pass can be recognized in the proxy video.

## Key points

- **Two checks**: Scene Check (rule-based, re-runs code against hidden facts in nine dimensions) and Screen Check (VLM judge whether passing facts are recognizable in the proxy video).
- **11 frontier coding agents** analyzed on evaluation results and trajectories.
- **Three observations**: (1) multimodal understanding separates agents, especially space and camera motion; (2) all agents master basic camera work and staging but fail at challenging requests; (3) agents inspect their own renders but fail to correct errors.
- **Implications**: agents need better visual understanding of space and camera, explicit checks for challenging requests, and item-by-item verification of renders against the brief.

## Details

The benchmark fills a gap in 4D scene evaluation: existing controllable video generation is conditioned on proxy videos, but no benchmark checks both those videos and the long, multi-shot scenes behind them. By re-running agent code and comparing against hidden ground truth, Scene Check measures whether the reconstructed scene is structurally correct, while Screen Check verifies whether the scene is perceivable in the rendered proxy — catching cases where code passes but the visual result does not.
