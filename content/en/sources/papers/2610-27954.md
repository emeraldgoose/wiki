# Lost in Recovery: Demystifying Recovery Behavior of Computer-Use Agents via Goal-Oriented Action Replay

**Source**: [arXiv:2610.27954](https://arxiv.org/abs/2610.27954) · **Published**: 2026-10-20
**Authors**: Byeonghun Bang, Sangwoo Park, Jinheon Baek, Kangsan Kim, Youngwan Lee, Sung Ju Hwang

## Overview

Recent advances in large vision-language models have enabled computer-use agents that automate digital workflows through fine-grained keyboard and mouse operations. These agents remain fragile in long-horizon settings, where errors accumulate and prior actions leave unintended side effects. Recovery becomes critical, but existing remedies are limited: environment resets are infeasible in proprietary settings, action replay is expensive over long horizons, and API-based rollback is restricted to web environments.

This paper presents ReTrace, a scalable framework for systematically studying recovery behavior in computer-use agents. It formalizes Transition-Consistent Recovery, requiring identical downstream actions from recovered and target states to yield identical outcomes. The criterion is operationalized through goal-oriented action replay after controlled error injection. ReTrace reveals that ideal recovery can unlock latent task completion capability, current agents fail to exploit that latent recovery capability, and accurate model-based recovery yields end-to-end gains.

## Key points

- Long-horizon computer-use agents remain fragile under accumulated errors.
- Recovery is critical but existing remedies are narrow or costly.
- ReTrace systematically evaluates model-based recovery.
- Transition-Consistent Recovery provides a formal criterion.
- Controlled error injection and replay make recovery behavior observable.
- Better recovery can unlock latent task completion capability.

## Details

The study reframes recovery as a measurable capability rather than an incidental side effect of agent design. By comparing outcomes from recovered and target states under identical downstream actions, ReTrace separates true recovery from accidental continuation. The findings suggest that computer-use agents often already contain latent recovery ability but fail to use it autonomously. Improving model-based recovery is therefore a direct path to more reliable long-horizon automation.
