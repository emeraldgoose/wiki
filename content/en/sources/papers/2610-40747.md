# Mage-VL-Cowork: A Full Training Recipe to Learn Hybrid Computer Use From Evolved Harnesses

**Source**: [arXiv:2610.40747](https://arxiv.org/abs/2610.40747) · **Published**: 2026-10-29
**Authors**: Xiaoyi Zhang, Haoqing Wang, Xinjie Zhang, Xiang Ming, Xing Wang, Senqiao Yang, Kaichen Zhang, Zhaoyang Jia, Andong Tan, Xinjiang Wang, Jinghao Guo, Yifei Shen, Xiao Li, Peng Zhang, Xun Guo, Jiahao Li, Shicheng Zheng, Jinglu Wang, Zongyu Guo, Wenxuan Xie, Bin Li, Yan Lu

## Overview

Effective computer-use agents should seamlessly combine visual GUI interaction with code and terminal execution within a single policy. Mage-VL-Cowork is introduced as a 4B hybrid computer-use agent trained from a generally multi-modally aligned checkpoint through an end-to-end, progressive five-stage curriculum across midtraining, supervised fine-tuning, and reinforcement learning.

To supply training data at scale, Mage-CUA-Forge replaces per-task agent construction with reusable, skill-conditioned generation workflows plus application-specific preparers. This produces 293,806 desktop and web tasks covering 6,915 skills while reducing recurring per-task expenditure by 82.6%. Instead of directly distilling a default teacher, the recipe evolves the teacher harness and instantiates specialized computer-use harrnesses to yield high-quality trajectories and stage-specific supervision.

The trained 4B model reaches 66.0% on OSWorld-Verified across training stages, with more efficient reasoning cost, achieving state-of-the-art performance at its parameter size and advancing on-device intelligence.

## Key points

- Hybrid computer-use agents need one policy spanning GUI, code, and terminal actions.
- A five-stage midtraining, SFT, and RL curriculum trains a 4B hybrid model from an aligned checkpoint.
- Large-scale skill-conditioned task synthesis yields 293,806 tasks over 6,915 skills and cuts per-task cost by 82.6%.
- Teacher harnesses are evolved rather than relying on a single default teacher.
- The 4B model reaches 66.0% on OSWorld-Verified with efficient reasoning cost.
- Project page and materials are released.

## Details

The paper presents a full training recipe rather than a single method: it combines a progressive curriculum, synthetic task generation across desktop and web applications, and evolved teacher supervision to produce trajectories and training signals at each stage. The reported OSWorld-Verified result is achieved at a 4B parameter size with improved reasoning efficiency.
