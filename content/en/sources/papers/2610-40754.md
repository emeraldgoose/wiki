# DyCraft: An Agentic System for Long-Horizon 4D Scene Generation

**Source**: [arXiv:2610.40754](https://arxiv.org/abs/2610.40754) · **Published**: 2026-10-29

## Overview

Frontier coding agents can generate high-quality 3D scenes and articulated assets, but they fail to create coherent long-horizon animations. Equipped with general-purpose harnesses, these agents produce physically implausible outputs — objects that interpenetrate, lack physical support, or move unnaturally. The root cause is that bare agents default to scripting the full animation in one pass, making verification and disentanglement of spatiotemporal constraints difficult. Drawing on human animators' practice, DyCraft introduces an agentic system that breaks animation into steps that coding agents can solve more reliably. DyCraft first expands the user's prompt into a detailed plan and builds a static scene. It then creates a 3D storyboard of key animation poses, where each frame is a static 3D scene the agent can build and debug in isolation. Storyboarding decomposes the problem into verified start and end state pairs, enabling the agent to author local motion between them using motion authoring tools. DyCraft is evaluated on 24 long-horizon, multi-shot animation tasks covering humanoid robots, human and animal characters, and physical mechanisms. Compared with a native GPT-6 agent in Codex and prior agentic baselines, DyCraft substantially reduces physical violations and generates higher-quality animated 3D scenes that are more often preferred by human raters.

## Details

DyCraft's architecture consists of three main components: (1) a prompt rewriting module that expands a user's high-level request into a structured plan, (2) a 3D scene construction module using CAD tools and scene graph authoring, and (3) a motion authoring pipeline that creates keyframe-to-keyframe animation segments with built-in verification at each boundary. The storyboard approach ensures that each local motion segment can be inspected and debugged before proceeding to the next, addressing the verification problem inherent in end-to-end animation generation. The system supports a range of animation domains including robot motion, character acting, and mechanical operation, with qualitative and quantitative results showing significant reductions in physical plausibility violations. Human preference evaluations consistently favor DyCraft-generated scenes over baselines. The code and model are released on Hugging Face, with a project page at https://dy-craft.github.io providing interactive demonstrations and reproducible scripts.
