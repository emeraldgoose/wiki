# Lab2Sim: Turning Real-World Experiment Videos into Interactive Virtual Experiments

**Source**: [arXiv:2611.02928](https://arxiv.org/abs/2611.02928) · **Published**: 2026-11-02
**Authors**: Xusen Hei, Jiali Chen, Jinyu Yang, Yi Cai

## Overview

Science experiment videos demonstrate how experiments are performed, but they offer no direct interaction for learners. Turning them into virtual experiments requires reproducing observed apparatus and state changes and enforcing preconditions for each operation. Lab2Sim is a benchmark of 218 science experiment videos with evidence-grounded specifications and 11,881 rubric items. To address it, the authors propose EduVideo2Code, which extracts procedures hierarchically, encodes them as explicit state machines to guide code generation, and refines results against rubrics.

## Key points

- Experiment videos lack interaction for learners.
- Virtual conversion needs apparatus and state reproduction.
- Preconditions for operations must be enforced.
- Lab2Sim contains 218 science experiment videos.
- It includes evidence-grounded specifications.
- EduVideo2Code uses hierarchical extraction and state machines.

## Details

The benchmark shifts educational video from passive viewing to manipulable simulation. Because learners may perform operations in varied orders, state machines encode legal transitions and required conditions. EduVideo2Code generates code guided by those structures instead of relying only on free-form reconstruction. Evaluation uses many rubric items to check both visual setup and behavioral correctness. The work targets interactive science learning from recorded experiments.
