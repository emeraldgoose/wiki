# SAE Interprets MoE: Sparse AutoEncoders Reveal Fine-Grained Expert Specialization

**Source**: [arXiv:2611.08089](https://arxiv.org/abs/2611.08089) · **Published**: 2026-11-05
**Authors**: Anyuan Zhuo, Shaohua Zhang, Yuan Lin, Pinyan Lu

## Overview

Mixture-of-Experts models route each token to a few experts, but the responsibility of an individual expert remains unclear. Existing analyses count how often an expert is selected on domain-labeled corpora, which fixes the taxonomy in advance, stays coarse, and records selection rather than contribution.

This work studies specialization in feature space by training a sparse autoencoder on the output of an MoE layer. Since that output is a router-weighted sum and the SAE encoder is affine, the pre-activation of every latent decomposes exactly over experts. Aggregated over a corpus, this gives each expert a dominant set of latents it principally drives.

On observed layers of Qwen3-30B-A3B, contribution is far more concentrated than gating, most latents have only one or two dominators, and overlap concentrates on a few expert pairs. Auto-interpreting these sets reveals a division of labor below coarse domains, with distinct experts for Java and front-end web code, or geometry and arithmetic or polynomials. Coarse domains occupy unequal numbers of experts. The SAEs and code are released.

## Key points

- Moves MoE expert analysis beyond selection counts.
- Trains an SAE on MoE layer output to study feature-space specialization.
- Decomposes each SAE latent exactly over contributing experts.
- Identifies dominant latents principally driven by each expert.
- Finds contribution more concentrated than routing.
- Reveals fine-grained specialization such as languages, code areas, and math subareas.

## Details

The study analyzes layers 4, 30, and 46 of Qwen3-30B-A3B. It argues coarse domain labels capture unequal expert allocations.
