# Do LLM Agents Still Need to Be Told How to Self-Improve?

**Source**: [arXiv](https://arxiv.org/abs/2611.23219)
**Published**: 2026-11-17

## Overview

LLM agents increasingly drive their own learning, but self-improvement methods still delegate only some components of optimization to models while humans specify the procedure. This paper asks whether increasingly capable models still need us to specify how they should self-improve. The authors study an autonomous paradigm in which, given basic primitives, resources and a general self-improvement goal, agents construct their own self-learning algorithm for context-based optimization.

Testbed: gameplay with limited information. A frozen LLM agent gets a compute budget and tools for collecting experience and updating text documents, and may freely experiment without an externally imposed loop or access to real-world data. A teacher variant of the same agent receives a general goal to improve the player through text (prompt edits, skill files), a budget, and tools ({Read, Write, Bash, Gameplay}) to observe the player and edit player context. Sufficiently capable models do self-improve, exhibiting strategies aligned with classic self-regulated learning frameworks and ML constructs like self-generated curricula; learned artifacts transfer across horizons, mechanics, and 3D navigation. Project page: https://ssundaram21.github.io/self-org/. License: CC BY-NC-SA 4.0.

## Key points

- Newer model generations teach themselves better (Sec. 4.1); models produce recognizable self-improvement strategies, quantifiable in gameplay/update behavior aligned with self-regulated learning and learnability constructs (Sec. 4.2).
- Self-learned artifacts transfer: improvement across game horizons, mechanics, and 3D navigation; self-generated games transfer to external benchmarks (ARC-AGI-3 Level 1, ARC-style tasks).
- Cross-model transfer of self-optimized context (Table 1, PuzzleScript-t20, mean ± std over 3 seeds): Opus 5 player — 25.4% (no artifact) → 47.5% (GPT-6 Astra's artifact); GPT-6 Astra player — 67.1% (none) → 72.1% (Opus 5's artifact). Text transfers in both directions despite GPT-6 Astra's higher baseline.
- Teacher information shapes generalization (Sec. 5.2): richer context initially helps both approximation (PuzzleScript-Narrow) and generalization (ARC-AGI-3), but at the highest token counts approximation improves while generalization plateaus/declines; tool/budget awareness raises performance, yet imposing matching t20 budgets improves t20 while t30 transfer falls — awareness biases toward task-specific specialization.
- Self-improvement needs no externally imposed loop: the teacher composes its own learning procedure (test game generation, player sessions, failure analysis, context updates) using only the toolset and budget.

## Details

- Setup: teacher–player structure; player plays turn-based games with undisclosed mechanics under compute and horizon budgets; teacher observes and rewrites player context (prompts, skill files) — no access to real games or validation scores. Benchmarks include PuzzleScript-t20/t30, ARC-AGI-3 (Level 1), MazeBench (Appendix B).
- Ablations: tool/budget awareness (PuzzleScript-t20 token/turn budgets vs transfer to t30), context size vs generalization, GEPA vs self-organized learning (Appendix D), self-regulated learning annotations, compute scaling of self-organization.
- Analysis: teacher session timelines (Appendix D.7), cross-artifact qualitative examples (E), SRL judge rubric (F).
