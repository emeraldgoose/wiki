# WeLM-Image: A Unified Image Generation Model towards Visual Intelligence

**Source**: [arXiv:2611.07392](https://arxiv.org/abs/2611.07392) · **Published**: 2026-11-05
**Authors**: Canmiao Fu, Chen Li, Guohui Zhang, Hao Lu, Hongyang Wei, Huadong Wu, Huaisong Zhang, Hubery Yin, Liyuan Cui, Qixin Yan, Tong Shao, Xiaoqiang Zhou, Xinhang Leng, Ying Zhang, Zhenhai Liu, Zhipeng Huang

## Overview

WeLM-Image is a unified image foundation model integrating multimodal understanding into text-to-image generation, instruction-guided editing, and multi-reference synthesis. It is designed for single-GPU deployment in consumer applications and processes text, reference images, and target latents as one interleaved sequence.

A Mixture-of-Transformers backbone combines shared attention with independent understanding and generation parameters to limit optimization interference. Mixture-of-Experts modules provide sparse capacity, with 31.7 billion stored parameters and about 5.4 billion generation parameters activated per target latent token. A generation-oriented data engine balances semantic coverage and editing tasks, supported by bilingual annotations and verified editing supervision.

Training separately optimizes generation and editing with rubric- and checklist-based rewards, then consolidates specialized policies through noise-aware on-policy distillation. The 1536-resolution model ranks first among evaluated open-source models on reported benchmarks. MeanFlow-based few-step distillation produces WeLM-Image-Turbo, generating a 1024x1024 image in 4.98 seconds on one NVIDIA H20 GPU.

## Key points

- Unifies understanding, generation, editing, and multi-reference synthesis.
- Processes text, reference images, and target latents as one interleaved sequence.
- Uses Mixture-of-Transformers and Mixture-of-Experts for capacity and interference control.
- Scales through a bilingual generation-oriented data engine.
- Optimizes policies with rubric- and checklist-based rewards.
- Distills specialized policies into a few-step turbo variant.

## Details

Progressive training reaches native 1.5K resolution. The paper reports comparisons on PRISM-Bench, Qwen-Image-Bench, and UnicBench, and includes deployment timing for the turbo variant.
