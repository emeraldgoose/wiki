# Apriel Voice 27B Preview: An Open Model for Speech, Reasoning, and Tool Use

**Source**: [arXiv:2610.40738](https://arxiv.org/abs/2610.40738) · **Published**: 2026-10-27
**Authors**: Aman Tiwari et al.

## Overview

A capable voice assistant needs more than transcription: it must understand requests, reason over context, sustain conversation, and invoke tools. Apriel Voice 27B Preview is an open speech-language model that uses a shared reasoning backbone to combine these capabilities.

Built on a post-trained Gemma checkpoint, it supports text, images, and audio. The training problem is to extend an already capable decoder with a speech interface without losing the behavior that makes it useful. This is addressed in two stages: multilingual transcription/translation/continuation with a frozen backbone, followed by broad supervised fine-tuning.

## Key points

- Open speech-language model for speech understanding, conversation, and tool use.
- Uses a shared reasoning backbone rather than separate cascaded modules.
- Combines speech understanding, response generation, and tool decisions.
- Supports text, image, and audio input.
- Built on a post-trained Gemma 26B-A4B checkpoint.
- Uses projector pretraining and supervised fine-tuning to preserve capability.
- Designed for real workflows requiring multi-turn evidence integration.

## Details

The paper argues that recognition accuracy alone is insufficient for voice-agent success because a model may transcribe correctly yet fail to follow constraints or invoke tools. Speech-conditioned models expose the reasoner to acoustic features instead of only transcripts.

Apriel Voice connects these capabilities through a shared backbone and separates the interface-learning problem from broader capability fine-tuning so existing reasoning and tool-use behaviors can be retained while adding speech.
