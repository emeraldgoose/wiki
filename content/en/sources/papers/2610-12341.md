# Can AI Agents Learn Their Way to the Top? Evaluating Heuristic Learning in a Long-Running Game Agent Competition

**Source**: Yang et al., arXiv, 2026-10-08

**Lead**: Adversarial games have driven AI from heuristic search to deep RL, but learning from limited experience remains hard. This work introduces **Adversarial Heuristic Learning (AHL)**: AI agents that refine *executable game policies* (code) through experience while keeping model weights fixed. The AAArena benchmark (12 games, 1,920 human programs) evaluates whether agents can learn their way to champion-level play.

## Background

Traditional game AI paradigms:
- **Heuristic search** (DeepBlue): Hand-crafted evaluation functions + search
- **Reinforcement learning** (AlphaGo): Learn value/policy networks from self-play
- **LLM agents**: Prompt models to generate actions directly

All three have limitations: hand-crafted heuristics don't adapt; RL requires massive compute and locks knowledge into weights; LLM agents lack long-horizon coherence. **Heuristic Learning (HL)** offers a middle ground: the agent *writes and revises code* that implements the policy. The model weights stay frozen; learning happens at the policy-code level.

## AAArena Benchmark

**12 authentic adversarial games**: Board games (Go, Chess variants), card games, resource management, real-time strategy—each with different state spaces, action spaces, and strategic depths.

**1,920 archived human programs**: Historical submissions from human programmers spanning years, providing a rich curriculum of strategies from novice to expert.

**Evaluation protocol**: AI agents start with a basic policy, then iteratively:
1. Play games against opponents (human programs or other agents)
2. Analyze wins/losses to identify policy weaknesses
3. Propose code revisions to the policy
4. Validate revisions via self-play
5. Repeat for a fixed interaction budget

Agents are ranked by Elo against the human program archive.

## Adversarial Heuristic Learning (AHL) Framework

The AHL agent operates on **policy code** (Python functions implementing `get_action(state)`):

```python
def get_action(state):
    # Policy logic here - editable by the agent
    return best_action
```

**Learning loop**:
1. **Experience collection**: Play N games, record trajectories
2. **Failure analysis**: LLM analyzes losing trajectories, identifies patterns
3. **Policy revision**: LLM proposes code changes (new heuristics, fixed bugs, new strategies)
4. **Validation**: Test revised policy against held-out opponents
5. **Accept/reject**: Keep revision if Elo improves; otherwise rollback

This is **learning at the code level**—interpretable, versionable, and transferable.

## Results

**Top AHL agents reach top-10% of human Elo** on multiple games after ~500 interactions.

**Key findings**:
- **Code revision beats weight updates**: AHL agents outperform RL baselines with 100× less compute on several games
- **Human curriculum matters**: Starting from human programs (vs. random) accelerates learning 3-5×
- **Failure-driven revision works**: Agents that explicitly analyze losses improve faster than those that only propose random mutations
- **Policy interpretability**: Winning policies are readable code—strategies can be inspected, debugged, and transferred

**Limitation**: AHL struggles on games with high-dimensional continuous actions (RTS micromanagement) where heuristic code is hard to write.

## Relevance to Software Engineers

AHL introduces a **new agent architecture pattern**: the agent *is* a code editor that learns by rewriting its own policy. This has implications for:
- **Self-improving code agents**: Agents that fix their own bugs by analyzing execution failures
- **Interpretable RL alternative**: Policy as code, not weights—auditable, patchable, explainable
- **Low-compute adaptation**: Adapt to new environments by editing heuristics, not retraining

The AAArena framework and human program archive are open-sourced at https://github.com/THU-CST-SAST/AAArena.
