# DecisionRank: On-Policy Distillation for Decision-Model Rerankers

**Source**: [arXiv:2610.42128](https://arxiv.org/abs/2610.42128) · **Published**: 2026-10-30
**Authors**: Yanran Wu, Dian Yu, Chongyang Bai, Jieyi Zhang, Rui Liu, Tianyi Chen, Shike Mei, Hang Cui, Frank Shyu, Sandeep Pandey, Luke Simon, Chunwei Liu, Xi Liu

## Overview

Decision models target structured tasks by directly predicting choices or scores, avoiding autoregressive decoding latency. Transferring a generative LLM's ranking knowledge to a decision model is difficult because the teacher expresses preferences as a ranked list of document ID sequences, while the student ranks using scores from the first-token position. DecisionRank bridges this gap with item-space on-policy distillation: it constructs the student's rollout by sorting document scores into a ranked list, correcting load imbalance during generation, and masking invalid items. These changes let the student learn the teacher's ranking structure without autoregressive decoding.

## Key points

- Decision models predict choices or scores directly rather than decoding text.
- They avoid autoregressive decoding latency in ranking tasks.
- Teacher models express preferences through ranked document ID sequences.
- Student models rank from first-token position scores.
- DecisionRank connects them through item-space on-policy distillation.
- It constructs rollouts from sorted scores and handles invalid items.

## Details

The central issue is representational mismatch between generative ranking and score-based ranking. DecisionRank does not make the student decode document sequences; instead it derives a ranking from the student's own scores. By constructing on-policy rollouts in item space, the training process exposes the student to its own mistakes while learning from the teacher's preference structure. Additional handling for load imbalance and invalid items keeps the distillation process stable. The result targets efficient decision-model rerankers that retain teacher-level ranking knowledge.
