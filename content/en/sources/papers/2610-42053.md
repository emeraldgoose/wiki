# REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control

**Source**: [arXiv:2610.42053](https://arxiv.org/abs/2610.42053) · **Published**: 2026-10-27
**Authors**: Pengfei Zhou, Yixing Ma, Zhengfeiyang Zhang, Haoyuan Chen, Zhenglin Wan, Hexin Wang, Wangbo Zhao, Yang You

## Overview

Foundation models are effective high-level reasoning brains but too slow for fine-grained control. Reactive policies such as VLAs are faster but weaker at generalization. REA is a Routed Embodied Agent runtime that combines a deliberative brain (system 2) with a reactive cerebellum (system 1) in an asynchronous architecture.

Its core idea is to let the brain prepare policies offline and intervene online only when needed, so no running policy waits for it. REA implements a three-level runtime and an embodied router with route memory, a boundary-triggered judge gate, and a shared-budget escalation ladder.

## Key points

- Unifies agent- and VLA-based systems across simulators using a common contract.
- Separates deliberative reasoning from reactive policy execution.
- Runs brain (system 2) and policies asynchronously.
- Uses an embodied router to coordinate intervention.
- Reports 95.9% success across 3,000 test episodes on LIBERO-Pro.
- Improves routing and control-time efficiency versus strong baselines.
- Evaluates across three simulators and real robots.

## Details

The runtime is designed for comparability across agents, VLAs, and programmatic policies. Asynchronous execution matters because slow models can advise online without blocking fast control loops.

The router's escalation ladder, route memory, and judge gate are intended to decide when slow assistance is worth the latency. Empirical results show near-oracle performance with less control time on large multi-task suites.
