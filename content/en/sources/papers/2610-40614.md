# L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory

**Source**: [huggingface](https://arxiv.org/abs/2610.40614)
**Date**: 2026-10-29


## Overview

Interactive world models generate visual content conditioned on user actions, yet maintaining spatial consistency over long-horizon exploration in real time remains challenging. Existing approaches rely on either temporal context or explicit 3D memory, both of which scale poorly because memory grows with the length of the generated stream. Moreover, explicit 3D memories condition latent video generators by re-encoding RGB renderings, which precludes real-time generation.
