# L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory

**Source**: [arXiv:2610.40614](https://arxiv.org/abs/2610.40614) · **Published**: 2026-10-29
**Authors**: Jinhyeok Choi

## Overview

Interactive world models generate visual content conditioned on user actions, yet maintaining spatial consistency over long-horizon exploration in real time remains challenging. Existing approaches rely on either temporal context or explicit 3D memory, both of which scale poorly because memory grows with the length of the generated stream. Moreover, explicit 3D memories condition latent video generators by re-encoding RGB renderings, precluding real-time generation. L3G-World introduces Latent 3D Gaussian Memory (L3G), which combines the efficiency of feed-forward reconstruction with a compact, rapidly renderable scene representation. A memory updater and a video diffusion transformer alternate autoregressively to generate spatially consistent worlds. The memory updater spawns Gaussians in newly observed regions and refines existing ones, so memory grows with scene extent rather than stream length. Each Gaussian stores a VAE latent feature, allowing the memory to be rendered directly into the DiT latent space without VAE re-encoding. Experiments show L3G-World achieves state-of-the-art generation quality and long-horizon spatial consistency, with up to 38.6x fewer 3D primitives, 3.2x faster memory updates, and 359x faster memory rendering relative to the most efficient prior 3D-memory baseline for each metric, enabling real-time world generation at 9 FPS.

## Key points

- Memory grows with scene extent rather than generated stream length.
- Each Gaussian stores VAE latent features for direct latent-space rendering.
- Memory updater and DiT alternate autoregressively.
- It achieves state-of-the-art long-horizon spatial consistency.
- It uses up to 38.6x fewer 3D primitives than the best prior baseline.
- Memory updates are up to 3.2x faster and rendering up to 359x faster.
- Real-time generation runs at 9 FPS.

## Details

L3G avoids VAE re-encoding by rendering stored latent features directly into the DiT latent space. The alternating updater/DiT design supports continuous generation without memory scaling with time.
