# VibeGame: Prompt-to-Game Development with AI-Native Engine and Self-Evolving Adversarial Agent Team

**Source**: [arXiv:2610.33106](https://arxiv.org/abs/2610.33106) · **Published**: 2026-10-22
**Authors**: Wenbo Hu, Ken Li, Jiazhe Wei, Yukang Cao, Weiyi Hong, Jiayi Dai, Chenjun Bai, Jiajun Liang, Yucheng Liao, Ruichuan An, Zeyu Lou, Haofan Wang, Yueming Lyu, Jingkang Yang, Ziwei Liu, Chenyang Si

## Overview

Large language model agents have enabled software development through natural-language interaction, but extending this paradigm to end-to-end game development remains challenging. Building a playable game requires coordinating code, scenes, assets, animations, physics, and configurations, while letting developers validate integrated behavior through interactive testing. VibeGame is a framework for creating complete 2D game projects from natural-language prompts and optional reference images. Its AI-native game engine represents project state as schema-validated structured text and provides frame-synchronous runtime control, enabling agents to inspect game states, execute actions, and verify behavior at their own pace. Built on this interface, an adversarial agent team of eight specialized agents separates implementation from review so problems are found and fixed through multi-round loops. For each conducted and accepted project, a training-free self-evolution mechanism distills it into reusable skeletons, modules, and collaboration contracts for future development. VibeGame is evaluated on prompt-assets-to-game, where agents receive an asset library, and prompt-to-game, where agents generate their own art. On a GameCraft-Bench subset, prompt-to-game with VibeGame consistently outperformed a range of agent harnesses using the same underlying model, including GPT-6.1-Sol.

## Key points

- The framework builds complete 2D game projects from prompts and optional images.
- Project state is represented as schema-validated structured text.
- Frame-synchronous runtime control lets agents inspect, act, and verify at their own pace.
- Eight specialized agents separate implementation from review in multi-round loops.
- Self-evolution distills accepted projects into reusable skeletons and contracts.
- Prompt-to-game outperformed comparable harnesses on a GameCraft-Bench subset.

## Details

The AI-native engine exposes inspectable state and controlled execution, making interactive validation possible for agents rather than only developers. The adversarial team structure and training-free self-evolution mechanism target reusability: successful projects become concrete artifacts and collaboration contracts for later projects.
