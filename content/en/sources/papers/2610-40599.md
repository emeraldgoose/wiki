# HairDeck: Animation-Ready Stylized Hair Cards from a Single Image

**Source**: [huggingface](https://arxiv.org/abs/2610.40599)
**Date**: 2026-10-29


## Overview

The hair of stylized characters in games and avatars is built from hair cards: artist-placed ribbons whose geometry is the visible hair, animated by spring bones. Existing image-based methods produce realistic hair or a single fused mesh, while CHARM, the only generator of stylized hair cards, decodes a hairstyle autoregressively as a long sequence of control points. Observing that a card hairstyle is an unordered set of artist-defined primitives, we propose HairDeck, which generates it as one: each card is a single token, and a set diffusion transformer denoises all cards together.
