# HairDeck: Animation-Ready Stylized Hair Cards from a Single Image

**Source**: [arXiv:2610.40599](https://arxiv.org/abs/2610.40599) · **Published**: 2026-10-29
**Authors**: Yuze He

## Overview

The hair of stylized characters in games and avatars is built from hair cards: artist-placed ribbons whose geometry is the visible hair, animated by spring bones. Existing image-based methods produce realistic hair or a single fused mesh, while CHARM, the only generator of stylized hair cards, decodes a hairstyle autoregressively as a long sequence of control points. Observing that a card hairstyle is an unordered set of artist-defined primitives, HairDeck generates it as one. Each card is a single token, and a set diffusion transformer denoises all cards together. From a single image, HairDeck generates the cards and the spring-bone chains that drive them, yielding an animatable asset that exports to downstream formats. On CHARM's test set, it lowers Chamfer distance by 44% and card-orientation error by more than half while running 33x faster; from single images it outperforms CHARM, image-to-3D pipelines, and strand-based methods.

## Key points

- Hair cards are artist primitives animated by spring bones.
- CHARM decodes hair autoregressively from control points.
- HairDeck treats the hairstyle as an unordered set of cards.
- Each card is a single token denoised together by set diffusion.
- It also generates the spring-bone chains from one image.
- It lowers Chamfer distance by 44% on CHARM's test set.
- It lowers orientation error by more than half and runs 33x faster.

## Details

The key idea is replacing autoregressive control-point sequences with set diffusion over cards. This better matches the unordered nature of hairstyles and yields faster, more accurate animatable assets.
