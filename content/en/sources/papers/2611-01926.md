# TAC-CoT: Tool-Empowered Implicit Chain-of-Thought via Interleaving Explicit Tokens

**Source**: [arXiv:2611.01926](https://arxiv.org/abs/2611.01926) · **Published**: 2026-11-01
**Authors**: Juseon Do, Sangmin Bae, Jeesu Jung, Hwanjun Song

## Overview

</span>LLM-based agentic systems are increasingly combined with CoT reasoning to solve tasks that require accurate reasoning, external knowledge, and multi-step deliberation. Yet, explicit CoT incurs substantial generation overhead, while implicit CoT, which replaces textual rationales with compact continuous tokens, does not naturally support the explicit communication interface required for agentic tool-use. We propose TAC-CoT, a tool-empowered adaptive implicit CoT framework that replaces explicit reasoning traces with compact latent reasoning segments while retaining textual tokens only for tool calls, observations, and final answers. This interleaved design enables agentic tool-use without verbalizing every intermediate reasoning step. Experiments on agentic math and QA benchmarks show that TAC-CoT improves accuracy by up to 8.8 points while reducing model forward passes by up to 6.8x.
