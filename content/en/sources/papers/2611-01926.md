# TAC-CoT: Tool-Empowered Implicit Chain-of-Thought via Interleaving Explicit Tokens

**Source**: [arXiv:2611.01926](https://arxiv.org/abs/2611.01926) · **Published**: 2026-11-01
**Authors**: Juseon Do, Sangmin Bae, Jeesu Jung, Hwanjun Song

## Overview

LLM-based agentic systems increasingly use chain-of-thought reasoning to solve tasks requiring accurate reasoning, external knowledge, and multi-step deliberation. Explicit chain-of-thought incurs substantial generation overhead, while implicit chain-of-thought, which replaces textual rationales with compact continuous tokens, does not naturally support the explicit communication interface required for tool use. The paper proposes TAC-CoT, a tool-empowered adaptive implicit chain-of-thought framework that replaces explicit reasoning traces with compact latent reasoning segments while retaining textual tokens only for tool calls, observations, and final answers. This interleaved design enables agentic tool use without verbalizing every intermediate reasoning step. Experiments on agentic math and QA benchmarks show that TAC-CoT improves accuracy by up to 8.8 points while reducing model forward passes by up to 6.8x. Analyses also show improved tool-use quality in both single- and multi-tool settings.

## Key points

- Explicit CoT is accurate but costly; implicit CoT saves tokens but lacks a tool communication interface.
- TAC-CoT uses compact latent reasoning segments plus explicit textual tokens only for tool calls, observations, and answers.
- The interleaved design keeps tool use while avoiding verbose intermediate reasoning.
- Benchmarks show up to +8.8 accuracy points and up to 6.8x fewer forward passes.
- Tool-use quality improves in both single- and multi-tool settings.

## Details

The framework is evaluated on agentic math and question-answering benchmarks where tools and multi-step reasoning are needed. Efficiency is measured in forward passes. Ablations of the latent/explicit split and tool usage patterns are in the linked source.
