# Towards Physically Grounded Articulated 3D Assets: A Multi-Agent Pipeline and Benchmark

**Source**: Cai et al., arXiv, 2026-10-09

**Lead**: 3D asset generation optimizes how objects look, not how they move and function. The authors present Artisan, which extends the single-agent Articraft approach with three independent agents—design (blueprint + design board), coding (Python program via an extended SDK), review (scores + issue list)—closed by MuJoCo collision and gravity-stability feedback. They also contribute a unified benchmark over spatial fidelity, physical plausibility, downstream robotic-task utility, and human judgments, on which Artisan leads in collisions and stability among 10+ models.

## Background

Appearance, articulation, mass, materials, stability, and collision-free motion are interdependent, but most methods handle one slice: feed-forward articulation models, material/mass predictors, or stability/collision refinements in isolation. Procedural generators enforce constraints but cover few object types; agentic Articraft writes 3D-building programs with an LLM, yet a single agent constructs and verifies its own program (self-evaluation bias) and never tests assets in an actual simulator. Artisan addresses both gaps: agent independence plus direct physical validation.

## Method: Multi-Agent Pipeline with Physical Validation

The pipeline maps $(\mathbf{p}, \mathcal{I}) \mapsto \mathcal{O} = \{\{\mathcal{G}_i, \rho_i, \mathcal{M}_i\}, (\mathcal{K}, \mathcal{J})\}$—part geometry, mass, PBR materials, kinematic tree, and joints with limits and couplings. The **Design Agent** emits a textual blueprint (parts, materials, kinematics, plus functional properties like coupled motions and task descriptions such as "raise the mixing head") and renders an orthographic/exploded-view design board. The **Coding Agent** iteratively edits and executes a Python program using reusable parameterized connectors (hinges, slide rails, rotary joints) instead of modeling joints from scratch, and annotates grasp regions, actuated joints, and success thresholds for downstream tasks. The **Review Agent** never edits code—it returns scores and structured issues (component, evidence, severity), blocking repairs that cheat physics at the cost of intended function (e.g. shortening door travel to pass collision checks). Each candidate runs MuJoCo collision sweeps (single/double/multi-joint sampled configurations after convex decomposition) and gravity tilt tests, with penetration depths and tilt angles fed back as the physics report.

## Experiments

**Setup**: 100 reference assets (ArtVIP, LightWheel) for spatial fidelity; ArtVIP for material/collision, 50 ABO objects for mass, 50 curated high-center-of-mass objects for stability; RoboTwin 2.0 (3 tasks) and RoboCasa365 (8 tasks) with $\pi_{0.5}$ policies plus blinded human evaluation of six methods in interactive MuJoCo scenes.

**Results (Artisan GPT-6 Astra vs. 10+ baselines)**:

| Aspect | Artisan | Best baseline |
|--------|---------|---------------|
| Spatial fidelity (ArtVIP) | Best in 8/11 metrics (IoU 0.7675, PSNR 18.65, pIoU 0.3587) | Articraft GPT-6 Astra close second |
| Collisions single / double / multi | 1.7% / 3.7% / 13.0% | 31–46% / 39–66% / 33–82% |
| Stability rest / articulated | 98% / 96% | 82–86% / 78–86% |
| RoboTwin / RoboCasa success (Native+Artisan training) | 84% / 43% | 80% / 39% native-only; Articraft-only 60% / 5% |
| Asset qualification R1/R2 | 100%/100% RoboTwin, 95%/44% RoboCasa | Articraft 62%/62%, 39%/8% |

Ablation confirms the physics loop matters: without it, collisions jump back to ~38–78%. Agentic methods also consistently beat task-specific feed-forward models (e.g. Instruct-Particulate) on most metrics.

## Relevance to Software Engineers

Artisan's patterns transfer to any code-generating agent pipeline:

- **Split builder from reviewer**: independent agents exchanging only artifacts (blueprint, program, issue list) reduce self-approval bias—applies to IaC, config, or code-gen agents.
- **Verify in the real runtime, not by inspection**: LLM visual/geometric checks missed what MuJoCo sweeps caught; execute generated artifacts in their target environment (simulator, staging, policy engine) and feed machine-measured reports back.
- **Ship parameterized primitives**: standard connectors beat free-form joint modeling; likewise, give coding agents vetted libraries rather than raw APIs.
- **Evaluate function, not just fidelity**: downstream task success and interactive human operation caught failures that render metrics missed—benchmark generated assets by use.
