# TeleChat to Xing4: Advancing Frontier Agentic Models on Domestic Chips and Frameworks

**Source**: [arXiv](https://arxiv.org/abs/2611.22115)
**Published**: 2026-11-17

## Overview

Xing 4 is a series of large language models extending the TeleChat lineage, developed through coordinated advances in model architecture and training infrastructure on Ascend (domestic Chinese chips) rather than GPUs. While most open-source models train on GPUs, scaling on domestic chips and frameworks poses significant systems challenges. This report describes the design principles and systems engineering behind the series: sparse activation, attention design, depth/width trade-offs, speculative decoding, architecture selection, large-scale pretraining, and reasoning/agentic post-training.

Representative configurations combine MLA with DSA and cross-layer IndexShare for long-context serving, incorporate optimized MHC operators for stability and efficiency, adopt a wider-and-shallower mixture-of-experts (MoE) topology, and pair a block-wise draft model with lightweight correction heads for speculative decoding. The authors open-sourced a 29B MoE member — trained entirely on Ascend NPUs using MindSpore, activating only 4B parameters per token, with native 256K-token contexts. A 285B-parameter model was pretrained on 8,192 Ascend 910C cards drawn from a large-scale production cluster.

## Key points

- Open-sourced Xing4 29B MoE: 4B active parameters per token, native 256K-token context, trained fully on Ascend NPUs with MindSpore — the first fully open member of the series.
- Measured systems wins: up to 4.68× prefill throughput over an MLA-only baseline; 2.67×–3.77× decoding throughput from speculative decoding; 16.1% throughput improvement from eliminating pipeline parallelism.
- Pretraining infrastructure (MindSpore HyperParallel): topology-aware hybrid sharded data parallelism (HSDP), owner-based execution for the distributed Muon optimizer, fine-grained selective recomputation with object-based exclusion and memory-budgeted selection, DSA long-sequence training optimizations (layer-wise indexer backward, Q-block pairing and layout planning, document-aware KV Compact); CPU affinity and core isolation reduce host scheduling interference.
- Post-training: TeleGym, a unified agent execution platform connecting execution, evaluation, and trajectory construction to policy optimization; disaggregated asynchronous execution, bounded oversampling, and partial rollout accommodate heterogeneous task durations while preserving trajectory continuity across policy updates. Task synthesis covers general agents and code agents.
- Scope: the report establishes an Ascend-oriented training foundation for continued Xing 4 development across scales and increasingly demanding reasoning and agent workloads; trillion-parameter training is ongoing.

## Details

- Architecture: long-context attention (MLA + DSA + cross-layer IndexShare), depth-width trade-offs studied explicitly, speculative decoding via block-wise draft model + lightweight correction heads; optimized MHC operators; wider-and-shallower MoE topology.
- Cluster: 285B-parameter pretraining on 8,192 Ascend 910C cards; CPU affinity/core isolation; HyperParallel distributed stack.
