# NorthCUA Technical Report: Turbocharging Computer-Use Agents through Experience at Scale

**Source**: [arXiv:2611.02102](https://arxiv.org/abs/2611.02102) · **Published**: 2026-11-01
**Authors**: Chaoyun Zhang, Bingxuan Li, Pinxue Guo, Yangfan Gao, Zikun Cai, Tianci Xie, Hui Li, Yuqi Huang, Yifei Cao, Bo Mao, Tian Tang, Qichang Zheng, Tongtong Liu, Xiaoxing Wang, Jinxiu Liu, Lizhi Lin, Zhou Shao, Maosen Zhou, Miao Zheng, Shuo Zhang, Yangji He, Kepeng Lei, Ning Zhao, Wei Shen, Zhenjiang Jin, Xinyue Zhang, Peng Sun, Zhenhua Han, Rui Zheng, Hang Yan

## Overview

Scaling computer-use agents from individual actions to complex software work requires experience that connects decisions to complete outcomes. NorthCUA is an integrated system that turbocharges computer-use agents through experience at scale. Its Experience Flywheel supplies diverse executable tasks to the NorthCUA Harness, which sustains long interactions, records decisions, and checks task outcomes. These records are used to curate verified trajectories. For unsolved tasks, recursive self-improvement evolves reusable skills and preserves verified milestones for later attempts.

## Key points

- Computer-use agents need experience tied to complete outcomes.
- NorthCUA integrates task supply, execution, and verification.
- The Experience Flywheel supplies diverse executable tasks.
- The Harness sustains long interactions and checks outcomes.
- Verified trajectories are curated from interaction records.
- Recursive skill evolution helps unsolved tasks.

## Details

The system closes the loop between trying software tasks and reusing successful experience. Task diversity comes from the flywheel, while reliability comes from outcome checking. Rather than only sampling agent actions, NorthCUA records and verifies whole interactions, producing data that connects decisions to results. For tasks that remain unsolved, reusable skills and preserved milestones make later attempts more capable. The focus is scaling computer-use ability beyond isolated actions.
