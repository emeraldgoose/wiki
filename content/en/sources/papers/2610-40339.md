# Wizard: Manipulate Any World in Real Time via Agentic Control

**Source**: [arXiv:2610.40339](https://arxiv.org/abs/2610.40339) · **Published**: 2026-10-27
**Authors**: Yuzhe Wu, Zijun Lin, Yeying Jin

## Overview

Recent video world models can generate increasingly realistic and interactive environments, and agentic frameworks decouple game logic and controllable world representations from visual generation. However, existing approaches support limited control flexibility, generalization, or real-time interaction. Wizard is introduced as an agentic game world model that enables player-customizable worlds with novel scenes, characters, and motions specified through reference images or free-form language.

It combines fine-grained character control, zero-shot generalization, real-time interaction, and mechanically consistent gameplay. Scenes are represented with geometric proxies encoding depth and height, while characters are represented by articulated skeletons. An agentic framework updates scene geometry according to camera inputs and animates skeletons according to action inputs, providing precise spatial and motion control to the causal video generator.

## Key points

- Enables real-time interaction and zero-shot generalization across unseen scenes, characters, and motions.
- Represents scenes with 2.5D geometric proxies and characters with articulated skeletons.
- Uses a vision-language model to retrieve compatible skeletons and animations from a motion library.
- Trains on 50.3 hours of aligned proxy-video pairs from diverse sources.
- Includes 750 scenes and 178 characters in the training dataset.
- Introduces adaptive masking to improve character identity preservation and reference alignment.
- Provides an agentic video-to-video framework for precise player control.

## Details

To train the model to follow structured proxies and generalize, the authors build aligned proxy-video data and construct an adaptive mask that restricts reference-image attention to corresponding character regions. This helps preserve character identity and alignment between reference images and generated videos.

The result is a system intended for player-driven game creation with broad customizability and real-time control. It expands the usable world and character space while maintaining mechanical consistency in gameplay.
