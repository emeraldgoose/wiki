# MemSteer: Turning User Histories into Supervision for Agent Memory Optimization

**Source**: [arXiv:2610.39276](https://arxiv.org/abs/2610.39276) · **Published**: 2026-10-27
**Authors**: MemSteer Authors

## Overview

Effective agent memory systems should adapt to a user's history and task requirements, but human-annotated supervision is costly and often unavailable. MemSteer converts unlabeled user histories into source-grounded QA-evidence supervision, which can then be used to evaluate and improve memory designs without updating model parameters.

The method relates source records and specifies how their facts jointly support a reference answer. An evidence-grounded answer plan guides question generation, while source-grounded verification checks the resulting annotations. The paper also introduces MemSteer-Opt, an evidence-guided memory-design optimizer that attributes mistakes to storage, retrieval, or answer generation and proposes targeted revisions.

## Key points

- Turns unlabeled user histories into supervision for agent memory design evaluation.
- Produces QA-evidence pairs grounded in source facts rather than only QA text.
- Uses evidence-grounded answer planning, source-grounded auditing, and verification.
- MemSteer-Opt uses QA performance to evaluate memory-design revisions.
- Attributes incorrect responses to storage, retrieval, or answer generation.
- Experiments on ATM-Bench and RHELM study utility and transfer to other user histories.
- Generated supervision is reported as useful across existing optimizers as well.

## Details

External memory systems store and organize user histories, but storage granularity, retrieval strategy, and answer-context construction all affect answer quality. MemSteer addresses the lack of labels for personal histories by generating supervision from the history itself.

Instead of training memory-construction policies with synthetic QA, MemSteer focuses on reliable feedback for evaluating and improving memory designs. Experiments investigate whether generated supervision can guide optimization, transfer across histories, adapt to new users, and provide more effective evidence-guided feedback.
