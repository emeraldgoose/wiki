# LiveFoley: Dynamic Real-Time Video-to-Audio Generation for Immersive Interactive Worlds

**Source**: [arXiv:2611.05988](https://arxiv.org/abs/2611.05988) · **Published**: 2026-11-04
**Authors**: Yusheng Dai, Vladimir Iashin, Kangdi Wang, Yuxuan Jiang, Ilpo Viertola, Weiqiang Wang, Qiuhong Ke, Min Zhao, Jianfei Cai

## Overview

Streaming video-to-audio (V2A) generation is essential for immersive interactive applications. However, real-time constraints leave existing streaming V2A methods far behind offline models. Supposedly, visual frontends shrink their receptive fields to cut look-ahead latency, severely degrading audio-visual alignment, and causal autoregressive diffusion backends denoise each audio patch in isolation, impairing quality. The paper presents LiveFoley, a streaming causal autoregressive diffusion architecture that addresses both bottlenecks with imperceptible latency. For the visual frontend, it introduces a Trailing Sliding Window that converts non-causal segment-level encoders into streaming modules without retraining. Simply realigning the window preserves precise audio-visual alignment, while a configurable hop size reduces frontend look-ahead below the human perceptual threshold. Building on this tunable hop size, the Unified Varhop Framework accommodates scenarios with diverse latency and computation budgets. For the audio backend, the authors explore widening the denoising window of the local diffusion transformer (LocDiT) head in two temporal directions. History LocDiT adds past context to improve quality at no latency cost and serves as the default. Alternatively, Future-Warmup LocDiT breaks the autoregressive deadlock with an approximate future condition, further improving quality at the cost of an acceptable backend look-ahead. Extensive experiments show LiveFoley matches offline models in temporal alignment and leads streaming systems in generation quality.

## Key points

- Streaming V2A is useful but existing methods lag offline models under real-time constraints.
- Shrinking visual receptive fields hurts AV alignment; causal patch-wise denoising hurts audio quality.
- Trailing Sliding Window turns non-causal encoders into streaming modules without retraining.
- Hop size tuning reduces look-ahead below perceptual threshold while preserving alignment.
- History/Future-Warmup LocDiT context variants improve backend quality under controllable latency.

## Details

The Unified Varhop Framework adapts latency and computation budgets. Experiments compare alignment and generation quality against offline and streaming systems. Full design, user-study, and benchmark details are in the linked source.
