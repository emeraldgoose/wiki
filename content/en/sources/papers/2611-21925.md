# DNeo: Your Parallel Draft Model Needs Better Target Feature Encoding

**Source**: [arXiv](https://arxiv.org/abs/2611.21925)
**Published**: 2026-11-16

## Overview

Speculative-diffusion decoding uses a small parallel drafter to generate b draft tokens in one forward pass, then verifies them in parallel with a larger target model; speed comes from multiple draft tokens passing verification simultaneously. Recent parallel drafters (DFlash, DSpark) improve draft quality by conditioning on target features via feature encoding, but standard feature encoding has three limitations: (1) it is lossy — dense encoding projections are destructive via a discovered effect called residual mixing; (2) it is memory-less — no record of previously processed proposals; (3) it samples features uniformly across target layers, omitting important hidden states.

DNeo addresses these with Mixture-of-Features Attention (MoFA), a lightweight feature-encoding approach with a working memory that encodes previously rejected proposals, plus 2-tap causal convolutions, prefix-only cross-attention, a fused causal head, non-uniform target layer selection (the DNeo protocol, isolating the contextually richer later half of the target), and the same drafter footprint. DNeo achieves 1.3× faster generation than SoTA (DFlash-2) without impacting drafter footprint or generation quality. Model weights and inference code are released.

## Key points

- Decoding speed (Qwen3-4B target, drafters trained by distillation): DNeo is up to +20.7% faster than the next-best method (DFlash-2) and always the fastest at temperature 1; up to +25.1% τ over SoTA parallel drafters, exceeding the τ of the SoTA AR drafter EAGLE-3 at temperature 1 (up to +21.0% τ), without draft trees.
- Why: speedup is the product of τ and round cost. EAGLE-3 beats DNeo's τ on four benchmarks at temperature 0, but DNeo is 1.15–1.34× faster there anyway (one-pass parallel drafting). Against parallel drafters, DNeo wins whenever its τ advantage outweighs its costlier causal head: every benchmark at T=1 (+32–40% τ over DFlash), math and code at T=0 (+17–19%), but not GPQA/MT-Bench at T=0 (+10–12%).
- Throughput: up to +58% higher tokens/sec at B=32 than DFlash-2 (Transformers serving); the gap widens under Transformers serving because DNeo's rounds are also cheaper (leaner prefix-only backbone). Only drafter to maintain throughput parity with AR at batch 64 (within 0.1%) while others fall 10–18% below.
- Ablations: MoFA improves TPF by +0.6 over dense encoding; rejection memory (cross-attention to previously rejected drafts) adds +0.17 TPF; the DNeo protocol (non-uniform layer selection) beats uniform spacing; the fused DNeo causal head (combining two common heads in latent space) beats either in isolation; prefix-only attention streamlines the backbone.
- DNeo dominates the throughput–speed Pareto frontier across H100 batch sizes 1–64 on six benchmarks.

## Details

- Components: MoFA feature encoding (mixture of target layers, structure-preserving), rejection memory (working memory of rejected proposals), 2-tap causal convolutions, DNeo causal head (latent-space fusion of two causal heads), prefix-only cross-attention, DNeo protocol for target layer selection.
- Setup: distillation for Qwen3-4B; benchmarks span math, code, GPQA, MT-Bench and others; temperatures 0 and 1; serving via SGLang and Transformers; batch sizes 1–64.
