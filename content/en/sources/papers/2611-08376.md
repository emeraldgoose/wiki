# Muir: Linear Attention with Sensitivity-Allocated Gating and Matched-Filter Readout

**Source**: [arXiv:2611.08376](https://arxiv.org/abs/2611.08376) · **Published**: 2026-11-05
**Authors**: Tushaar Gangavarapu, Gil Tabak, Clemens JS Schaefer

## Overview

Linear attention compresses context into a fixed-size key-value state for linear-time training and constant-memory inference. Gated delta-rule models decay this state and erase its prediction for an incoming key before writing a new value. Gated DeltaNet-2 generalizes this with channel-wise decay and decoupled erase and write gates.

The analysis in Muir shows state updates are far less sensitive to erasure than writes: key activation and unit normalization concentrate key energy onto sparse channels, whereas value writes scale all channels, so erasure can be lower rank. Slow-decaying state rows also accumulate larger norms, dominating unweighted readout and forcing stronger erasure to suppress interference.

Muir therefore fuses all gates into a sensitivity-allocated low-rank projection, re-weights state rows with a matched-filter readout gate, and reinvests saved parameters in a wider feed-forward network. It also designs a parallel update for stable training at large chunk sizes. Across sizes, Muir lowers perplexity, raises commonsense accuracy, and improves extractive recall over GDN-2, while matching GDN-2 throughput and training faster than Transformer baselines.

## Key points

- Analyzes sensitivity asymmetry between erasure and write in gated linear attention.
- Allocates sensitivity via a fused low-rank projection.
- Re-weights state rows with matched-filter readout.
- Reinvests saved parameters into a wider feed-forward network.
- Implements a stable parallel update for large chunks.
- Improves perplexity, commonsense accuracy, recall, and training speed at scale.

## Details

Muir extrapolates from 4K training length to 10M-token streams without perplexity drift at 1.34B parameters and maintains near-perfect passkey retrieval to 1M tokens with static readout. It matches GDN-2 throughput and reaches validation loss faster.
