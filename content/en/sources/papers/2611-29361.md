# Beyond Attention Maps: Understanding and Improving Medical MLLMs via Visual Values

**Source**: [arXiv:2611.29361](https://arxiv.org/abs/2611.29361) · **Published**: 2026-11-22 (v1)
**Authors**: Yichen Zhao, Fenghe Tang, Wenxin Ma, Rongsheng Wang, Zihao Wan, Shaohua Kevin Zhou

## Overview

Medical MLLMs are usually judged by whether they attend to the right regions, treating the spatial attention map [M] as the main key of visual perception — [M] decides where to read, the visual values [V] provide what is read. The paper tests this with a paired diagnostic VQA dataset: non-contrast (NC) and contrast-enhanced (CE) images of the same anatomy (liver CT, brain MRI, breast MRI; patient-level partitioning, annotation-guided sampling, clinician-reviewed QA in Appendix A), where the CE branch answers correctly and the NC branch incorrectly on the same question. Finding 1: across Qwen3-VL and MedGemma, NC and CE branches show nearly identical layer-wise attention-to-image fractions and high foreground attention-map cosine similarity despite opposite answers — where the model attends does not explain the prediction difference. Finding 2: bidirectional exchanges of [M] and [V] between branches show predictions are substantially more sensitive to [V]: transferring CE values into the NC branch gives much larger gains than transferring CE attention weights, and transferring NC values into the CE branch causes much larger degradation. A stress test perturbing NC attention weights with Gaussian noise (preserving mass) shows CE values remain beneficial, so attention facilitates values but does not account for their advantage.

Guided by this, the method VIVID (Visual Value Intervention Distillation) distills CE knowledge into an NC-only student on-policy. Per layer, the auxiliary branch picks the smallest set of non-background image tokens whose cumulative head-averaged attention reaches tau = 0.5 and mixes their values toward the CE teacher's with strength alpha = 0.5, keeping attention weights fixed (Eq. 1). The resulting prediction shift u_t = C(log p_aux - log p_S) (centered over the top-K=100 tokens plus a residual bin) is used to construct a response-guided target: project the teacher correction r_t = C(log p_T - log p_S) onto u_t keeping only positive alignment (d_t, Eq. 3), then q_t = softmax(log p_S + d_t) (Eq. 4). Training minimizes JSD(p_S, q_t) plus a weak CE supervision term weighted by w_t = clip(1 - ||d_t|| / ||r_t||) (Eq. 5); only the NC student is updated, and inference uses NC images only.

## Key points

- Diagnostic dataset: paired NC/CE medical VQA over liver CT, brain MRI, breast MRI with patient-level splits, annotation-grounded evidence generation, and clinical review (Appendix A); six test sets = internal + external per modality/cancer type.
- Findings: attention maps of NC vs CE branches are nearly identical (quantitatively and qualitatively) despite contrasting answers (Finding 1); bidirectional [M]/[V] swaps show [V] dominates prediction changes (Finding 2, Table 1), robust to Gaussian noise on attention weights (Table 2).
- VIVID main results (Table 3, accuracy): Qwen3-VL-2B + VIVID reaches 66.47 / 52.64 / 86.37 / 82.53 / 79.44 / 75.25 (internal/external liver/brain/breast) vs best off-the-shelf 54.26 (Gemini 3.5 Flash) on liver internal, beating OPSD/Med-OPD/VA-OPD on-policy distillation (63.98/64.36/62.85 liver internal); 4B + VIVID reaches 71.29 / 57.91 / 86.46 / 83.06 / 80.72 / 75.19 vs best off-the-shelf 70.99 and all distillation baselines. Delta vs best off-the-shelf is positive on most columns (e.g. +12.21 liver internal 2B, +17.03 4B).
- Zero-shot generalization retained: VQA-RAD, SLAKE, PMC-VQA, ChartQA scores stay strong; all methods use NC-only images at inference.
- Hyperparameters: alpha = 0.5, tau = 0.5, K = 100; ablations in Appendix C (training config, seeds, question types, patch selection/projection analysis, generated evidence quality).

## Details

Section 3 details the diagnostic: query [Q] attends to image-token keys [K] giving [M], aggregating values [V] into the readout; paired dataset construction (patient-level partitioning to avoid leakage, image standardization, annotation-guided sampling, annotation-grounded evidence, clinical QA). Section 4 gives the method equations (1)-(5) above. Section 5 reports Table 3 and analyses of distributions and visual values (5.3). Appendix B covers attention-map similarity across datasets, extended [M]/[V] intervention analyses, and consistency across training regimes. Project page: qiuzyc.github.io/VIVID.
