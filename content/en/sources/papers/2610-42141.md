# RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory

**Source**: [arXiv:2610.42141](https://arxiv.org/abs/2610.42141) · **Published**: 2026-10-27
**Authors**: Shengguang Wu, Suning Huang, Cherie Ho, Ria Doshi, Hao Zhu, Serena Yeung-Levy

## Overview

A frozen robot policy can perform much better when wrapped in an agent harness that decides when to query the policy, consult tools, or command the arm directly. Such harnesses are currently hand-built and redesigned for each robot or benchmark. RoboArchitect automates this process using a coding model that designs and optimizes the harness.

Given a frozen policy, auxiliary vision/language tools, and rollout recordings, the coding model diagnoses failures and proposes an updated harness. Across benchmarks and policies, auto-optimized harnesses substantially raise success on unseen scenes and tasks. The harness also gains persistent memory, allowing experience to accumulate without a predefined schema.

## Key points

- Automates design of robotic agent harnesses.
- Uses a coding model to diagnose failures and propose harness updates.
- Raises average success on unseen scenes from 9.7% to 43.3%.
- Raises average success on unseen tasks from 12.7% to 40.2%.
- Builds a single cross-embodiment harness from diverse training pools.
- Equips the harness with evolving persistent memory.
- Reports harness evolution trajectories and failure diagnoses.

## Details

The harness mediates policy calls, tool usage, and arm commands, making surrounding control code as important as the policy itself. RoboArchitect treats this harness as an optimizable artifact rather than manual engineering.

Persistent memory emerges from optimization rather than a fixed schema. The goal is to make frozen policies adaptable across robots, tasks, and environments through harness evolution.
