# Can Coding Agents Sustain Continual Evolution without Forgetting?

**Source**: [arXiv:2611.03219](https://arxiv.org/abs/2611.03219) · **Published**: 2026-11-02
**Authors**: Shangziqi Zhao, Yitong Zhang, Jia Li

## Overview

Harness self-evolution has emerged as an important paradigm for improving agent performance without modifying foundation model parameters. Prior studies show that evolving the agent harness on a single task can effectively enhance capabilities. The paper asks whether a harness can continuously evolve across multiple task types without catastrophic forgetting, which is important for coding agents in practice. It investigates this open question and examines how continual harness updates interact across tasks.

## Key points

- Harness self-evolution improves agents without model updates.
- Most prior work studies a single task.
- Real coding agents face multiple task types over time.
- Catastrophic forgetting is a concern.
- The paper investigates continual evolution across tasks.
- The question remains practically important.

## Details

The work shifts the focus from whether harness evolution works once to whether it can accumulate gains over time. Rather than changing model weights, it studies the harness as the adaptive component, analogous to continual learning at the tool and workflow level. The concern is that improvements for one task type might harm performance on earlier ones. By framing this as an open question, the paper invites evaluation of sustained agent adaptation rather than single-task optimization.
