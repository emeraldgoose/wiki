# SWE-Trail: History-Guided Trajectory Collection for Coding Agent Training

**Source**: [arXiv:2611.02074](https://arxiv.org/abs/2611.02074) · **Published**: 2026-11-01
**Authors**: Ziming Li, Lu Yu, Jiatan Huang, Qing Cui, Jun Zhou, Chuxu Zhang

## Overview

Coding agents solve repository issues through long sequences of exploration, editing, and validation. These trajectories are increasingly used as post-training data, so collection quality affects what the trained model learns. A common approach samples multiple trajectories independently for each issue and then selects or curates them. Independent sampling makes later trajectories redundant, even though earlier trajectories could guide where later collection effort should go. SWE-Trail exposes collection history to guide subsequent trajectory generation, making sampling less redundant.

## Key points

- Coding agent trajectories are useful post-training data.
- Trajectories include exploration, editing, and validation.
- Independent repeated sampling becomes redundant.
- Earlier trajectories contain useful guidance.
- History-guided collection targets redundancy.
- The method affects what the trained model learns.

## Details

The paper focuses on data collection rather than model architecture. It argues that trajectory distribution shapes learning outcomes, so redundant samples waste collection effort without improving coverage. By using history to steer sampling, SWE-Trail aims to discover new useful paths instead of repeating already seen ones. This may improve the efficiency and diversity of coding agent training data.
