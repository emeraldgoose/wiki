# PhotoGuider: Composition-Aware Cropping and 360^{circ} View Framing with Explainable Photographic Assessments

**Source**: [arXiv:2611.02897](https://arxiv.org/abs/2611.02897) · **Published**: 2026-11-02
**Authors**: Yuan-Kang Lee, Kuan-Lin Chen, Chia-Che Chang, Yu-Lun Liu

## Overview

Traditional image cropping assumes the photograph already contains the composition worth keeping, and only asks where to crop. A full 360-degree scene offers no such guarantee, because the viewing direction has to be discovered before anything can be framed. PhotoGuider is a measure-then-frame method that answers both questions with compact learned scorers over one shared set of composition-aware features. Features are extracted with foundation and task-specific vision models and structured into four photographic tokens: Subject, Composition, Aesthetics, and Integrity.

## Key points

- Conventional cropping searches inside an existing composition.
- A panoramic 360-degree scene requires discovering framing first.
- PhotoGuider addresses both cropping and view framing.
- Compact learned scorers perform measurement and framing.
- One shared feature set supports both tasks.
- Four photographic tokens explain the assessment.

## Details

The method differs from cropping-first photography pipelines by treating viewing direction as part of composition. It extracts shared visual features and scores them for subject prominence, composition, aesthetics, and integrity. These tokens are then used to choose both how to crop and where to look in a panoramic scene. The result is a more unified assessment of photographic quality and framing intent.
