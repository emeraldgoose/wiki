# MMMem: Self-Improving Agents with Task-Aware Multimodal Experience Consolidation

**Source**: [arXiv:2611.30287](https://arxiv.org/abs/2611.30287) · **Published**: 2026-11-23 (v1)
**Authors**: Yuxuan Chen, Changwei Lv, Yunfei Li, Zhongjing Du, Kehui Tan, Zijun Liao, Ruochong Zheng, Hao Chen, Can Deng, Zheni Zeng, Chang Liu, Jie Chen

## Overview

AI agents accumulate conversations, photos, and documents over long-term interactions, and later questions often require connecting evidence scattered across those records. Existing multimodal memory methods mostly store and retrieve raw records, but rarely retain the understanding gained while solving a task — so agents repeat the same mistakes on related questions. MMMem instead uses the task as the organizing unit of memory: each completed task is distilled into an "experience" that records the task context, the conclusion, and links back to the supporting sources.

MMMem combines four strategies. First, source-linked multi-view memory keeps the original text, images, and rendered pages alongside generated "scene views" — synthetic images that merge clues dispersed across several records — giving retrieval both literal and composed representations. Second, tasks generated from the agent's own sources align knowledge at two levels: a warm-up phase consolidates source knowledge into retrievable experiences in external memory before the first scored question, while self-training adapts the model's parametric knowledge (one epoch of LoRA with AdamW) to the task demands. Third, the same vision-language model writes experiences from completed tasks without reference answers or scoring feedback. Fourth, task-aware retrieval recalls source views plus relevant experiences for answering and verification, and reuse that is supported by the original evidence guides long-term retention of experiences.

## Key points

- Benchmarks: held-out subsets of LoCoMo (multi-session conversation memory, token F1), Mem-Gallery (image–dialogue association, EM/token F1/BLEU-1), and LooGLE v2 (long-document evidence integration, official aggregate score); readers are Qwen3.5-9B and MiniCPM-V 4.5 (8.7B), each trained separately.
- With Qwen3.5-9B, MMMem scores 65.84 F1 (LoCoMo), 77.21 F1 (Mem-Gallery), 29.97 (LooGLE v2); with MiniCPM-V 4.5, 56.40 / 70.27 / 24.67 — best on all six settings over eight baselines (Direct/Full/Recent Context, Dense RAG, OCR-Memory, MemOCR, Mem0, A-Mem). Relative gains over the best baseline: 36.9% (LoCoMo), 17.6% (Mem-Gallery), 15.2% (LooGLE v2).
- Over A-Mem with Qwen3.5-9B, MMMem gains +17.75 F1 on LoCoMo and +11.58 F1 on Mem-Gallery; Dense RAG beats Full Context in all six settings, and Full Context even degrades over Direct Answer with MiniCPM-V 4.5 — evidence selection matters as much as memory representation.
- Ablations: removing self-training is the largest drop in 4 of 6 settings (−5.65 F1 LoCoMo Qwen); removing task warm-up hurts most on LooGLE v2 (−6.62 Qwen, −2.13 MiniCPM) because LooGLE documents average ~1.5 scored questions each; removing experience memory costs −5.76 on LooGLE v2 (Qwen); generated views help on LoCoMo/Mem-Gallery (−1.36/−3.12 Qwen when removed) but are mostly skipped on text-centric LooGLE v2.
- Case studies (Mem-Gallery, MiniCPM-V 4.5): a generated scene view combining descriptions from two records moved the target bird from retrieval rank 10 to 2 and changed the answer from "Blue Jay" to "Lazuli Bunting"; a recalled experience linking "Dunlin" to Calidris alpina changed a photo count from five to six.
- Retrieval setup: source-view budgets of 3,000 tokens (LoCoMo) / 4,000 (Mem-Gallery, LooGLE v2), zero-shot reranking with Qwen3-Reranker-0.6B, top experience in a separate slot; experience memory resets per evaluation unit and warm-up is unscored.

## Details

MMMem's memory is built from source nodes (original text, images, rendered pages) plus generated scene views that combine clues across records. Warm-up writes experiences before the first scored question of each unit, which matters when a unit has few questions; self-training uses tasks generated from training units disjoint from evaluation (including LVBench and OVO-Bench as training-only data), with official training-unit question texts guiding style but no reference answers. Experience writing never sees reference answers or scoring feedback, and benchmark reference answers, annotated clues, and QA tags are excluded from retrieval. Ablations compare MMMem against "Only Training" (same trained reader with Dense RAG) and "w/o Training", showing parameter adaptation and the memory workflow contribute complementary gains. Limitations note that gains are smaller on LooGLE v2, where questions require combining evidence across long documents within the source-view token budget and each document yields only ~1.5 scored questions on average, leaving fewer opportunities to reuse experience from earlier answers.
