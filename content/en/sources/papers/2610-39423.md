# FDSML: Formula-Driven Supervised Metric Learning with Parameter-Aware Triplet Loss

**Source**: [arXiv:2610.39423](https://arxiv.org/abs/2610.39423) · **Published**: 2026-10-29
**Authors**: Shinei Arakawa

## Overview

Formula-Driven Supervised Learning enables vision pretraining without real images, but existing methods cast pretraining as classification on discretized labels, discarding continuity in the generative process. FDSML derives relational supervision from image-generation parameters beyond discrete class labels. It combines FineFractalDB, a refined fractal dataset with higher intra-class variation and more stable structures, with a Parameter-Aware Triplet Loss that assigns positives and negatives according to distances in the underlying Iterated Function System parameter space. This objective trains embeddings to respect parameter-derived relative similarity orderings. Experiments show FDSML improves transferability to image retrieval while remaining competitive on downstream classification and improving robustness under several corruption settings. On ResNet-50, Recall@1 improved from 65.6% to 74.0% on Stanford Online Products and from 56.2% to 78.4% on Stanford Cars over FDSL pretraining. The results suggest parameter-derived relational supervision provides a stronger synthetic pretraining signal than label-based classification for transfer beyond recognition.

## Key points

- Formula-driven FDSL pretraining needs no real images.
- Existing FDSL discards generative continuity by classifying discretized labels.
- FineFractalDB has higher intra-class variation and more stable structures.
- PA-Triplet Loss uses IFS parameter-space distances for positives and negatives.
- Embeddings learn parameter-derived relative similarity orderings.
- Recall@1 improved from 65.6% to 74.0% on Stanford Online Products.
- Recall@1 improved from 56.2% to 78.4% on Stanford Cars.

## Details

The supervision is relational rather than discrete: positives and negatives come from distances in the parameter space of the fractal generator. This preserves continuity that classification labels discard, yielding stronger synthetic pretraining for retrieval and robustness.
