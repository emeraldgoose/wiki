# FDSML: Formula-Driven Supervised Metric Learning with Parameter-Aware Triplet Loss

**Source**: [huggingface](https://arxiv.org/abs/2610.39423)
**Date**: 2026-10-29


## Overview

Formula-Driven Supervised Learning (FDSL) enables vision pre-training without real images, but existing methods cast pre-training as classification on discretized labels, discarding continuity in the generative process. We propose Formula-Driven Supervised Metric Learning (FDSML), which derives relational supervision from image-generation parameters beyond discrete class labels.
