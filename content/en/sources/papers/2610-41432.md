# Hybrid Computer Use: A Unified Programmatic, Semantic, and Visual Interface for General Agents

**Source**: [arXiv:2610.41432](https://arxiv.org/abs/2610.41432) · **Published**: 2026-10-30
**Authors**: Haoqing Wang, Xiaoyi Zhang, Sicheng Fan, Zhexin Zhang, Xinjie Zhang, Jiahao Li, Bin Li, Yan Lu

## Overview

Computer-use agents increasingly tackle tasks ranging from everyday desktop activities to long-horizon professional workflows, yet interfaces centered on screenshots and mouse-and-keyboard actions can impose a human-interaction prior. They require repeated screen interpretation while leaving the computer's semantic and programmatic capabilities underexposed. The paper argues for exposing these capabilities and letting models choose and combine them. It introduces Hybrid Computer Use (HCU), a unified interface for general agents combining three complementary channels: programmatic interaction through code and command-line tools, semantic interaction through accessibility (AX), and visual interaction through graphical user interfaces (GUI). HCU supports efficient AX interaction and guards against stale-state actions during channel switching, while a supplementary HCU skill guides agents in selecting and coordinating channels. Its AX tools return compact observations, execute actions in batches, and report effects as AX diffs, reducing round trips. On OSWorld 2.0, HCU achieves the highest Partial and Binary scores among compared systems. Trajectory analysis shows that all evaluated models improve with HCU, allocate work across channels differently, and outperform baselines in efficiency and task success, highlighting the value of unified interfaces that allow flexible channel selection and combination.

## Key points

- Screenshot/mouse-keyboard interfaces impose a human-interaction prior and underexpose semantic and programmatic capabilities.
- HCU unifies programmatic (code/CLI), semantic (accessibility), and visual (GUI) interaction channels.
- Dedicated AX tools provide compact observations, batched execution, and AX diffs to reduce round trips.
- The design guards against stale-state actions during channel switching and includes a skill for channel coordination.
- On OSWorld 2.0 HCU achieved the highest Partial and Binary scores; all tested models improved while allocating work differently.

## Details

Evaluation focuses on end-to-end task success and efficiency across desktop workflows. The paper analyzes how different models exploit the three channels and their failure modes. Implementation details and benchmark setup are in the linked source.
