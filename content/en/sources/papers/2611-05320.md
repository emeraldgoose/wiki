# PyRUA-DataFarm: LLM Agent as a Cost-Efficient Teleoperator for Real-Ready Robot Data

**Source**: [arXiv:2611.05320](https://arxiv.org/abs/2611.05320) · **Published**: 2026-11-03
**Authors**: Kewei Zhang, Juncheng Ma, Guodong Lv, Duomin Wang, Feixiang Ruan, Ruiyang Si, Chuanrui Zhang, Yuxuan Chen, Hao Chen, Yichen Liu, Yintianrun Zhang, Yufan Deng, Enze Xie, Daquan Zhou

## Overview

Teleoperation remains the default way to collect robot demonstrations, but every episode costs robot and operator time and every new task starts from scratch. The paper asks whether a coding agent can take over the teleoperator's job. In its DataFarm, the agent receives a data request and one calibration episode of the robot in the target scene, then rebuilds the task in simulation: it writes the scene, an expert controller, and a success judge. The simulator supplies exact actions, and a video model conditioned on real images renders each rollout as photographic video, generating all camera views together consistently. The output is real-ready data: synchronized camera views labelled with the robot's actions, on which a policy can be trained directly and deployed on the real robot. Independent judges certify the expert and every rendered episode before admission. On five real-robot tasks, policies trained only on farm data match policies trained on as many teleoperated episodes (93 vs. 84 successes in 100 trials), and under an unseen tablecloth and colored light they keep 87 successes where teleoperation-trained policies fall to 46. Adapting a task is fully automatic and costs about $21 of API usage on average, paid once per task, plus $5 for a render contract; every further episode costs about $0.80 on average for simulation, rendering, and review, with no robot or operator. One hour of three-view data for a task costs about $107 on average including these costs, slightly below a teleoperation quote of $117 in China and well below $290 in labor alone in North America.

## Key points

- Teleoperation is costly and task-specific; each new task starts from scratch.
- DataFarm has a coding agent rebuild the task in simulation from one calibration episode.
- The simulator provides exact actions; a real-image-conditioned video model renders all camera views consistently.
- Independent judges certify the expert and each rendered episode before admission.
- Farm-only policies match or exceed teleop-trained ones (93 vs 84 successes, 87 vs 46 under visual shifts), with ~$107 per hour of three-view data.

## Details

Evaluation spans five real-robot tasks, including unseen tablecloth and colored light conditions. Cost comparison includes robot/operator time and API/render/review costs. Full setup and benchmarks are in the linked source.
