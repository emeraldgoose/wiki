# Sparse Readout Prism: Explaining Logit-Lens Scores in Features Instead of Tokens

Source: Matteo He and 3 other authors, arXiv:2609.01936, Sep 1, 2026. Under review.

**Lead**: Lens methods track a language model's next-token prediction across layers by decoding intermediate hidden states into tokens — but a lens reading reflects both the hidden state *and* the readout (unembedding matrix) used to decode it. The paper shows that two lenses differing only in fitting corpus can report different tokens for identical hidden states, a dependence it names **corpus conditionality**. To isolate readout structure from the fitting corpus, it introduces the **Sparse Readout Prism (SRP)**: a decomposition of the readout using only its weights, expressing any token logit or logit difference as a sum of sparse readout-feature contributions. Replacing the readout with SRP's sparse approximation reconstructs **8.9–17.3 percentage points more** of tested logit differences than the strongest of six geometry-based baselines, and ablating features shifts logit differences in proportion to their SRP contributions.

## Corpus conditionality: the lens is not neutral

The standard mental model treats a fitted lens as a transparent window onto the hidden state. SRP's starting observation breaks that: refit the same lens on a different corpus and the token it reports for the same hidden state can change. Any lens analysis therefore confounds "what the model represents" with "what the readout plus fitting corpus prefers to say". Because SRP is built from readout weights alone with no corpus, it serves as a corpus-independent control for lens analyses — and reassuringly, while token readings drift with the corpus, the dominant readout feature stays stable.

## Readout features as a unit of analysis

Instead of asking "which token does this hidden state decode to", SRP asks "which sparse readout features produce this logit". That reframing exposes structure token identities obscure: contributions can be compared across tokens, contexts, layers, and lenses on a common feature basis. The causal check is direct — ablate a feature and the logit difference moves in proportion to that feature's attributed contribution — so the decomposition is not just descriptive but interventionally grounded.

## Caveats

This summary is abstract-based: effect sizes beyond the headline 8.9–17.3pp range, layer-wise patterns, and model coverage live in the 55-page full text and are not captured here. The method explains the readout side of lens readings, not hidden-state geometry itself — it complements rather than replaces activation-side interpretability. Stability of the dominant feature is reported qualitatively ("remains stable"); the precise conditions under which it breaks are a full-text question.

## Relevance to SW engineers

- If you use logit-lens or tuned-lens probes to debug model behavior in production, your readings are corpus-contingent — refit-sensitivity checks should be part of the workflow.
- Prefer explanations grounded in weights over explanations grounded in a fitting corpus when you need results that survive a data change.
- The ablation-proportionality test is a reusable validation pattern: any feature attribution you ship should move the output when intervened on.
- Code and dictionaries are released (GitHub + HuggingFace links in the paper comments), so this is directly reproducible.
