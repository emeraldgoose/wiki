# PREEN: Exemplar-Based Color Style Transfer with Smartphone Editor Presets

**Source**: [arXiv:2610.36896](https://arxiv.org/abs/2610.36896) · **Published**: 2026-10-27
**Authors**: Beomjin Ahn

## Overview

Exemplar-based color style transfer, also studied as photorealistic style transfer, is a routine photo-editing operation: a user picks a reference image whose look they admire and wants their own shot recolored to match. Mainstream methods are pixel-generative — from neural style transfer to diffusion editing — and whatever their quality, they emit rasters with no exposed editing parameters, while diffusion-based ones add multi-second latency and stochastic sampling that resists deterministic re-editing. That fits poorly with on-device, user-in-the-loop pipelines.

PREEN (Preset Regression via an Exemplar-based Editor Network) takes the alternative route of photo preset transfer: from a content image and a style reference it predicts a preset — a vector of editor slider values — such that applying it with a deterministic editor approximates the reference's look. The output is compact and interpretable, and unlike a rendered image it can be stored and re-edited, with no generative model at inference time. Concretely, the network maps the pair to a 2,929-parameter preset that a smartphone editor applies.

The central obstacle is supervision, because an arbitrary real reference has no preset ground truth. Parametric retouching benchmarks such as MIT-Adobe FiveK and PPR10K provide human-authored target edits but work in an auto-enhancement regime without a separate style reference, and no large-scale dataset pairs content, reference and a matching expert-graded target. The one reference-conditioned set with expert-graded targets the authors know of, PST50, offers just 50 pairs for evaluation. The prior method in this setting sidesteps the problem by sampling presets, which bounds the styles it can learn.

## Key points

- PREEN closes the supervision gap with a style-transfer teacher: the teacher's target looks are inverted into the editor's parameter space as pseudo-presets, producing a large corpus of pseudo-labeled triples for training on real reference pairs.
- Training has two phases: first a CLIP-conditioned regressor is pretrained on that corpus, then all base weights are frozen and only low-rank adapters are trained under an image-level CIELAB loss evaluated on the differentiable editor output, addressing the perceptual non-uniformity of the parameter-space loss used in phase one.
- On the human-curated PST50 benchmark, PREEN applies the reference's color while preserving structural fidelity and leads the baselines on pixel- and perceptual-fidelity metrics, with a compact preset predicted at sub-second on-device latency.
- The low-dimensional preset subspace exposes a single inference-time strength knob: a scalar applied to the chromaticity parameters traces a continuous default-to-vivid trajectory in one forward pass, with every intermediate state a valid editor preset.
- A two-axis human study finds a three-way divergence along that trajectory — raters prefer the vivid end for matching the reference but prefer the default as a standalone photo, a trade-off the knob spans without retraining.
- The paper positions itself against both raster-generative transfer and learned look-up-table approaches, and against Deep Preset, which established reference-conditioned preset regression but with sampled-preset supervision that confines the learnable styles to the sampled set.

## Details

Prior work is split into two families. Learning-based automatic retouching and compositing harmonization regress parameters toward a fixed goal — enhancement or in-image harmonization — rather than toward a separate style reference. Learned look-up tables, including image-adaptive 3D LUTs and NLUT, map colors through a discretized grid over the RGB cube; the authors note that NLUT requires a CUDA-only operator, so its metrics are measured on GPU with no CPU timing available. Within reference-conditioned preset regression, Deep Preset regressed an editor preset of 69 develop controls from a content–reference pair but trained on images re-rendered with sampled presets, so a ground-truth preset always existed; the closest later work, NCST, regresses a smaller global-only parameter set from a reference for video grading. PREEN revisits the setting without sampled-preset supervision, substituting a style-transfer teacher on real reference pairs.
