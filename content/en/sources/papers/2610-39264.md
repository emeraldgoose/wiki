# Online Dense Reinforcement Learning with Planning-Grounding Agent for UI Navigation on Live iOS Apps

**Source**: [arXiv:2610.39264](https://arxiv.org/abs/2610.39264) · **Published**: 2026-10-29
**Authors**: Peitong Duan

## Overview

Frontier vision-language models navigate user interfaces well but their high inference costs prohibit everyday use, while smaller models trained with supervised fine-tuning or offline reinforcement learning often memorize static trajectories, leading to brittle execution and inability to recover from errors. This paper proposes an online reinforcement learning framework that trains UI navigation agents directly on live iOS applications. The agent is decoupled into a Planning agent and a UI Grounding model. An LLM-as-a-Judge provides comprehensive reward signals, combining dense step-level feedback for intermediate progress with a terminal reward for overall task completion. The agent is optimized with Proximal Policy Optimization using step-level advantage estimation. The paper also introduces GiGPPO, a neighbor-conditioned value estimation method that improves critic stability by leveraging reward signals from visually similar states across concurrent trajectories. To support online training at scale, an infrastructure orchestrates hundreds of concurrent virtual iOS devices. Evaluations on UINavBench, iOSWorld, and AndroidWorld show that online RL agents substantially outperform both SFT and terminal-only RL baselines while accelerating convergence. Notably, 8B RL agents achieved nearly a sevenfold improvement over the SFT baseline in out-of-distribution generalization to Android, and tied Gemini-3.1-Pro while outperforming Gemini-3.5-Flash on real iOS applications.

## Key points

- The framework trains agents directly on live iOS apps rather than static trajectories.
- It separates Planning from UI Grounding.
- Rewards combine dense step-level feedback with terminal task-completion reward.
- PPO uses step-level advantage estimation.
- GiGPPO improves critic stability with neighbor-conditioned value estimation.
- Hundreds of concurrent virtual iOS devices support scalable training.
- 8B RL agents greatly improved out-of-distribution generalization to Android and matched strong closed models on iOS.

## Details

Dense rewards and live interaction are used to counter memorization and poor recovery in SFT/offline RL agents. The decoupled design lets planning and grounding improve jointly while the infrastructure makes online training practical.
