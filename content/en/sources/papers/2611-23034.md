# M3OPD-Reasoner: An Open Recipe for Post-Training Multimodal Reasoning with Multi-Teacher On-Policy Distillation

**Source**: [arXiv](https://arxiv.org/abs/2611.23034)
**Published**: 2026-11-18

## Overview

Multi-Teacher On-Policy Distillation (MOPD) lets a single student absorb the skills of several domain teachers by learning from its own generated responses. M3OPD-Reasoner is a fully open and complete recipe for post-training vision-language models over three reasoning domains: image STEM, image perception, and video. The authors curate two datasets — M3OPD-SFT-1.35M for supervised fine-tuning and M3OPD-RL-193K for RL with verifiable rewards — and compare recipes from Qwen3.5-9B: mixed-domain training (MixSFT / MixRL), one GSPO teacher per domain (directly or after SFT warm-up), and MOPD of those teachers into one student.

Evaluated on 21 decontaminated benchmarks, MOPD of teachers trained with GSPO directly from Qwen3.5-9B is the best recipe: the student closely matches each teacher on its domain and is on average above mixed training on the same prompts. Because MOPD already merges the domain capabilities MixRL would otherwise have to learn, its student is a stronger starting point for RL — the same prompts still improve the MOPD student, with no collapse, yielding the main model M3OPD-Reasoner-9B. All data, training code and checkpoints of every stage are released.

## Key points

- Overall (21 benchmarks, avg@8): Qwen3.5-9B 69.4 → MixRL 74.4 (+5.0), MixSFT 67.7 (−1.7), MixRL from MixSFT (baseline) 73.5 (+4.1) → MOPD (teachers directly from base) 75.2 (+5.8) → M3OPD-Reasoner-9B = MOPD + MixRL 75.9 (+6.5). With the SFT warm-up, teachers 75.2 → MOPD 75.2 → +MixRL 74.8.
- MOPD vs mixed training on the same prompts: MOPD of directly-trained teachers beats MixRL from base on average and on most benchmarks; MixSFT alone hurts (−6.6 on image STEM mean).
- MixRL on top of MOPD shows no collapse — most of the 21 benchmarks improve for both student variants, with the few drops small; the largest gain is on video. To the authors' knowledge, no prior VLM recipe has studied MixRL on top of MOPD on the same prompts.
- M3OPD-SFT-1.35M and M3OPD-RL-193K span image STEM, image perception and video; decontaminated against all 21 evaluation benchmarks.
- Releases: full data, training code and every stage's checkpoints (SFT, domain teachers, MOPD student, final) for reproducible research.

## Details

- Recipe: SFT (lmms-engine) → per-domain GSPO teachers (verl + vLLM rollout) → MOPD (student samples responses, domain teacher scores each token; routing by prompt domain) → optional MixRL on the same prompts with the same GSPO settings and a rule-based verifiable reward.
- Evaluation: lmms-eval, thinking enabled, 32,768-token response cap; eight samples per question (T=0.6, top-p 0.95, top-k 20), avg@8 accuracy; images ≤ 1,605,632 px, up to 150 sampled frames per video.
