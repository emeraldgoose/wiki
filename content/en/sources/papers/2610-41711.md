# Hierarchical Residuals: A Minimalist Decoupling of Residual Width from Compute Width

**Source**: [arXiv:2610.41711](https://arxiv.org/abs/2610.41711) · **Published**: 2026-10-30
**Authors**: Ziteng Wang, Jianqiao Lu, Xinyu Ma, Jintao Zhang, Jun Zhu, Yiyuan Ma, Jianfei Chen

## Overview

Residual connections are the backbone of modern Transformers: a standard PreNorm layer reads a normalized copy of the hidden state, computes an update, and adds it back, so one state of width d is carried through depth along an identity path while every attention and feed-forward module contributes an additive update. That design makes deep optimization practical, but it also ties the width of the state carried through depth to the working width of every layer. A line of recent architectures relaxes the constraint in different ways — Alternating Updates with multiple residual streams, Hyper-Connections and Virtual Width Networks with learned stream mixing, Manifold-Constrained Hyper-Connections stabilizing that mixing on a doubly stochastic manifold, and Attention Residuals retrieving representations from earlier layers — and the authors observe that all of them share two departures from vanilla residual addition: the effective residual state is expanded, and residual accumulation becomes explicitly regulated.

Those methods pay for the benefit with per-layer expanded states and intricate mixing, which add activation traffic and memory-bound residual operators that usually need fusion, recomputation, overlap or specialized kernels to recover throughput. Hierarchical Residuals (HiRes) asks whether the benefit comes from the wider state itself rather than from the particular operators, and proposes getting it with as little architectural change as possible.

## Key points

- HiRes groups adjacent Transformer layers into blocks and runs residual computation at two levels: ordinary d-dimensional PreNorm layers inside each block, and a wider D-dimensional outer residual state across blocks, updated with the familiar additive rule where D is greater than d.
- Two learned projections bridge the levels — a read projection maps the outer state into a block, and after inner accumulation a write projection maps the resulting inner state back — and the block write is added to the outer residual before post-normalization, which regulates the residual scale and keeps the outer recurrence as the residual motif of a vanilla PostNorm Transformer.
- The residual expansion ratio D/d is therefore selectable independently of each inner layer's compute width, and because read and write happen only at block boundaries, the extra parameters and compute are amortized over depth.
- Across model sizes and depths HiRes consistently outperforms vanilla residual addition, and fitted loss–compute scaling laws indicate a 1.30x improvement in FLOPs efficiency.
- On OLMoE-1B-7B pretraining for 500B tokens, HiRes achieves 0.0208 lower training loss and 1.14 points higher downstream accuracy.
- It is competitive with other residual expansion methods such as VWN, mHC and AttnRes while using less activation memory and I/O, and it is built only from dense projections and normalizations, needing neither specialized kernels nor infrastructure-level optimizations.

## Details

The construction places the two levels side by side: the outer recurrence is the residual motif of a vanilla PostNorm Transformer with an entire layer block standing in for a sublayer, so individual Transformer layers stay unchanged and the inner path keeps its PreNorm semantics. The paper contrasts this with the alternatives it benchmarks against — AltUp, Hyper-Connections, Virtual Width Networks, mHC and Attention Residuals — whose per-layer expanded states and mixing operators raise activation traffic and require fusion, recomputation, overlap or custom kernels on the memory-bound residual path. The claimed practical consequence is that residual width becomes a usable scaling variable expressed with standard operators, rather than one entangled with compute width or requiring new infrastructure.
