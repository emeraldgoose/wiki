# PyRUA-REAL: Robot Exploration and Adaptive Learning through RSI in the Real World

**Source**: [arXiv:2611.06768](https://arxiv.org/abs/2611.06768) · **Published**: 2026-11-04
**Authors**: Qiang Wang, Jianxin Bi, Shulong Jiang, Ruiyang Si, Wenbo Huang, Kaiqi Chen, Jiaxin Li, Liyun Li, Xuanyi Li, Daquan Zhou

## Overview

Coding agents powered by models such as GPT-6-Astra connect spatial reasoning with executable robot behavior, raising the question of how such agents can produce lasting improvements in robot capabilities from physical interaction. The paper studies embodied recursive self-improvement (RSI) through real-world exploration, code refinement, and deployment using PyRUA-REAL, a framework in which coding agents retain interaction experience as persistent memory and reusable executable skills that inform subsequent exploration and improvement. Its empirical study places physical manipulation at the center of the improvement process, examining how agents collaborate, what kinds of execution feedback support effective code refinement, and how task specifications and previously acquired skills influence robustness and task transfer. It also investigates the efficiency and capability of the resulting programs when deployed without an online agent for decision-making. Across eight real-world tasks, PyRUA-REAL achieves an average success rate of 91.1%. In complementary evaluation on 42 tasks from the RoboDojo benchmark, it achieves an average success rate of 84.4%. The study provides empirical guidance for turning physical exploration into reusable robot skills that support continued improvement and robust, efficient deployment.

## Key points

- Physical exploration can be turned into reusable, deployable robot skills through coding agents.
- PyRUA-REAL retains interaction experience as persistent memory and reusable executable skills.
- It examines agent collaboration, feedback types, task specs, and skill transfer for robustness.
- Resulting programs run without an online agent during deployment.
- Achieves 91.1% average success on eight real-world tasks and 84.4% on 42 RoboDojo tasks.

## Details

The study focuses on physical manipulation as the improvement mechanism. It also evaluates programs deployed without online agent decision-making. Scenario, success metrics, and collaboration details are in the linked source.
