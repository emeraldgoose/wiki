# SpecPilot: Autonomous Algorithm Discovery and Systems Optimization for Speculative Decoding

**Source**: [arXiv:2611.02501](https://arxiv.org/abs/2611.02501) · **Published**: 2026-11-02
**Authors**: Kunjun Li, Wenhao Chai, Yihao Liang, Yuezhou Hu, Shuyao Xu, Yi Pan, William X. Zheng, Kannan Ramchandran, Kurt Keutzer, Jiantao Jiao

## Overview

Speculative decoding accelerates memory-bound LLM decoding with a lightweight drafter, and parallel drafters further extend the speedup by drafting a whole block in one forward pass. It remained unclear whether released systems attain the full speedup that parallel drafting permits. SpecPilot identifies three challenges: single-request decoding accepts few tokens per step while reading every target weight, batching halves the speedup over autoregressive decoding, and optimizations are deployment-specific. It presents SpecPilot, an autonomous agentic loop that discovers algorithms and systems optimizations for each deployment. A cost model locates the largest gaps, parallel agents explore and integrate directions, token forcing checks outputs to detect reward hacking, and structured memory carries validated mechanisms across rounds and deployments.

## Key points

- SpecPilot optimizes speculative decoding without training or quality loss.
- A cost model guides each round toward the largest remaining speedup gap.
- Parallel agents explore optimization directions and integrate successful ones.
- Token forcing compares outputs with the stock system to detect reward hacking.
- Structured memory carries validated mechanisms to new rounds and deployments.
- Discovered optimizations include a general lossless 12-bit weight format and new verification mechanisms.

## Details

SpecPilot was evaluated across four target models, three drafters, two GPU platforms, and five benchmarks. With one request, speedup over autoregressive decoding rises from the stock system's 4.46 times to 10.87 times. With batching, it rises from 1.94 times to 3.93 times. The discovered optimizations include tree verification for hybrid recurrent targets, two-level verification, and three batching mechanisms. Results are tied to the tested software and hardware configuration and should be reproduced before assuming identical gains elsewhere.
