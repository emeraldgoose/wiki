# DAMI: Dual-Axis Memory Initialization for Enhanced Long-Context Retrieval in Gated Linear Attention

**Source**: [arXiv:2610.41994](https://arxiv.org/abs/2610.41994) · **Published**: 2026-10-30
**Authors**: Zhangchi Feng, Harry Jiang, Yangyifei Luo, Ray Zhang, Richong Zhang

## Overview

Linear attention scales linearly with sequence length, but its finite-state memory can limit long-context retrieval. In gated linear recurrences, memory retention depends on state decay, which is shaped jointly by gate parameters A_log and dt_bias and by input activations. Controlled Gated DeltaNet experiments show that both parameters remain highly correlated with their initial values after training, highlighting the importance of initialization. DAMI, Dual-Axis Memory Initialization, jointly configures these parameters before training and assigns geometric timescales along the head dimension, balancing information propagation and aggregation across layers.

## Key points

- Linear attention has linear scaling but finite-state memory constraints.
- Gated recurrence retention depends on state decay from gates and activations.
- Gate parameters stay correlated with their initial values after training.
- DAMI configures the relevant parameters before training.
- Geometric timescales are assigned along the head dimension.
- The design balances propagation and aggregation across layers.

## Details

The paper motivates DAMI through the observation that initialization dominates certain gate behavior after training. Rather than relying on default values, DAMI sets gate parameters jointly, using geometric progressions to span different retention horizons. This dual-axis treatment addresses both head-level timescales and layer-level roles. The method is evaluated in gated linear attention settings and targets long-context retrieval without changing attention scaling.
