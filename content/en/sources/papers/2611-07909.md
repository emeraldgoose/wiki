# EDGAR: Efficient Diffusion-Driven Gaussian Avatar Refinement via Synthetic Failure

**Source**: [arXiv:2611.07909](https://arxiv.org/abs/2611.07909) · **Published**: 2026-11-05
**Authors**: Kwan Yun, Minhyeok Bang, Colette Suhjung Koo, Junyong Noh

## Overview

Gaussian splatting enables efficient and photorealistic head avatar reconstruction, but monocular or image-based methods still suffer from under-constrained geometry and texture. Typical artifacts include blurring, stretching, and temporal instability. EDGAR is a conditional diffusion framework designed to enhance Gaussian avatars by correcting such artifacts while preserving identity fidelity.

Training uses EDGAR-SET, a hybrid triplet dataset of real-captured and synthetic-rendered samples that simulates realistic Gaussian avatar failure cases by pairing degraded renderings with ground-truth and reference images. EDGAR refines degraded frames through a fusion block that injects identity features from the self-supervised Sapiens model into a one-step diffusion backbone.

The model uses a Mixture-of-Experts architecture to address different degradation types and severities. Refined multi-view renderings are used as pseudo-targets to optimize a single underlying Gaussian avatar, so EDGAR need not run at every output frame. Evaluation across reconstruction methods and settings shows improvements in perceptual and reconstruction measures, better cross-view consistency, and robustness under extreme poses.

## Key points

- Refines Gaussian avatars with a conditional diffusion model.
- Preserves identity while correcting appearance artifacts.
- Uses synthetic and real paired failure examples for training.
- Injects Sapiens identity features into a one-step diffusion backbone.
- Addresses diverse degradations with a Mixture-of-Experts architecture.
- Improves reconstruction without running refinement for every rendered frame.
