# VisualArtifactSpec 1.0: Evaluating Visual Artifacts under Task Specifications

**Source**: [arXiv](https://arxiv.org/abs/2611.21382)
**Published**: 2026-11-16

## Overview

Visual artifact tasks test an agent's ability to translate task specifications and source materials into outputs that meet practical needs, and evaluating across artifact families helps distinguish broadly applicable authoring capabilities from strengths confined to one medium. VisualArtifactSpec 1.0 (VAS) is a benchmark of 211 creation and modification tasks spanning presentations, static graphics, animations and videos, and web interfaces. Each task specifies authoring objectives, source materials, constraints, and deliverables.

VAS evaluates two aspects separately: Task Fulfillment verifies explicit requirements and applicable functionality, while Artifact Performance assesses Content, Organization, Visuals, and Delivery. Task-specific rating anchors instantiate shared criteria for the intended audience, purpose, and medium, with judgments grounded in source materials and artifact inspection records. Nine model–harness configurations were evaluated on all 211 tasks; overall scores range from 42.12 to 70.52, and Artifact Performance accounts for 73.4% of the gap between the highest- and lowest-scoring configurations. Project page: https://accio-lab.github.io/VisualArtifactSpec; code: https://github.com/Accio-Lab/VisualArtifactSpec; data: https://huggingface.co/datasets/Accio-Lab/VisualArtifactSpec.

## Key points

- Overall scores (Table 8): GPT-6 Astra 70.52, GPT-6.1 Sol 69.37, Claude Opus 5.5 65.03, Kimi K3.1 Pro 62.38, DeepSeek-V4.1-Flash 60.03, Qwen3.8-Max 51.95 … bottom configuration 42.12. Task Fulfillment bases cluster near 46–50 for all configurations, so the ranking is driven by Artifact Performance adjustments.
- Artifact Performance dimensions (C/O/V/D point scores in [-50, 50]): Astra leads on Content (21.61), Organization (22.75), Visuals (20.14) and Delivery (21.22); Qwen3.8-Max's much lower Δ (5.87) reflects weaker visual/delivery choices rather than unmet requirements.
- VAS separates "did it do what was asked" (fulfillment base B, gated by explicit requirement and functionality checks) from "is it good for this audience/purpose/medium" (performance adjustment Δ from shared criteria Content/Organization/Visuals/Delivery with task-specific anchors).
- Artifact Performance explains 73.4% of the top-to-bottom gap, meaning explicit-requirement compliance alone does not discriminate strong from weak artifact authoring.
- Case studies relate recorded scores to visible choices: preserving evidence conditions locally (research audiences), adapting information density to phone-scale reading (general audiences), and maintaining correspondence through motion (animation).

## Details

- Families: presentations (P), static graphics (G), animations/videos (M), web interfaces (W); 151 non-web tasks retain an established purpose mapping, website assignments were reconstructed from task instructions (60-task aggregate).
- Evaluation: per-task fulfillment base B plus weighted performance adjustment Δ (S = B + Δ); criteria weights, dimension scores and exception handling in Appendix B; benchmark comparison definitions in Appendix C; scoring sensitivity, matched task sets and criterion-level error patterns in Appendix D.
