# SciGame: Let Agents Play the Scientific Discovery Games in the Real and Counterfactual World

**Source**: [arXiv:2610.37919](https://arxiv.org/abs/2610.37919) · **Published**: 2026-10-27
**Authors**: SciGame Authors

## Overview

LLM agents are increasingly used for scientific discovery, but existing benchmarks mix law inference with programming, score data fitting rather than prediction on unseen inputs, and fail to separate empirical evidence from pretrained priors. SciGame converts scientific literature into structured relations and tests whether agents can discover governing laws under controlled conditions.

It builds scientific cards recording a relation, variables, input domains, and applicability conditions. Each card yields two environments with the same interface: an Original environment implementing the source relation and a Counterfactual environment implementing a transformed relation. Tasks include Identification, where candidates are given, and Discovery, where they are not.

## Key points

- Addresses four benchmark gaps: protocol changes confounding task differences, metrics that may not test generalization, weak separation of experience and prior knowledge, and lack of counterfactual tests.
- Runs each task under Prior-only, Fixed observation, and Adaptive experimental design protocols.
- Compares original and counterfactual relations to probe memorization versus genuine discovery.
- Includes Identification and Discovery task settings with executable-expression submissions.
- Adds a live, knowledge-cutoff-aware Temporal collection to reduce benchmark memorization.
- Evaluates multiple LLMs in the reported setup.

## Details

SciGame is designed around the idea that scientific law discovery requires more than fitting data: agents must infer how inputs determine observables, generalize to unqueried inputs, separate evidence from prior knowledge, and revise hypotheses dynamically. The paired Original/Counterfactual environments keep the interface fixed while changing the underlying relation, making it easier to test whether an agent uses observations rather than memorized literature.

The benchmark also includes stable Historical collections and a rerunnable pipeline for recent papers with independent review. Its unified framework compares three protocols and three metrics across both task modes. Overall, it aims to measure scientific discovery capability more precisely than coding-heavy benchmarks.
