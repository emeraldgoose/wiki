# Axion 1.0: Open Agent Foundation Models, Simplified

**Source**: [arXiv:2611.03233](https://arxiv.org/abs/2611.03233) · **Published**: 2026-11-02
**Authors**: Yuqi Jia, Yunjie Tian, Jiayu Zheng, Yijun Liang, Jingchen Sun, Mengyu Zhao, Di Fu

## Overview

Axion 1.0 is a fully open agent foundation model that combines strong and broad agentic capabilities with a remarkably simple training recipe. It is trained in only three stages: two lightweight supervised fine-tuning stages followed by reinforcement learning. There is no dedicated mid-training, direct preference optimization, or on-policy distillation. The first stage develops strong self-contained reasoning through model-aware data construction by synthesizing challenging problems and adversarially strengthening them based on the base model's own successful solution strategies. The second stage extends capabilities to tool-dependent reasoning using automatically verifiable tasks grounded in real-world data and deterministic computation. Reinforcement learning then strengthens long-horizon reasoning and external tool interaction.

## Key points

- The training recipe has only three stages.
- It omits dedicated mid-training, preference optimization, and on-policy distillation.
- The first stage uses model-aware data construction and adversarial strengthening.
- The second stage uses automatically verifiable tasks grounded in real-world sources.
- Reinforcement learning targets long-horizon and tool-interaction capability.
- The complete recipe, data pipeline, prompts, and training code are released.

## Details

Despite the compact recipe, Axion 1.0 achieves strong performance across a broad suite of agentic benchmarks and is competitive with leading commercial models on several. Equally important, openness extends beyond weights: data construction, synthesis, filtering, verification, prompts, and training code are released for reproduction and extension. The results suggest that open agent foundation models can be practical and reproducible, though the reported performance is tied to the chosen benchmarks and base model.
