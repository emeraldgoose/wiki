# WebHarbor: Docking Real Websites for Evolving GUI Agent Environments

**Source**: [arXiv:2611.03634](https://arxiv.org/abs/2611.03634) · **Published**: 2026-11-02
**Authors**: Zhaoyang Wang, Qianhui Wu, Boyu Gou, Demi Wang, Jiacheng Zhang, and many collaborators

## Overview

GUI web agents need realistic and interactive environments that remain stable during evaluation and training. Live website evaluation suffers from changing content, access restrictions, and limited coverage of authenticated workflows, whereas existing synthetic training environments often lack functional depth and visual fidelity. WebHarbor proposes a suite of 153 executable and dockerized website environments that faithfully reconstruct the visual interfaces, content, and functional workflows of real-world web services under deterministic control. The suite is built through task-driven human-agent collaboration, allowing environments to evolve as new tasks expand their functional scope.

## Key points

- The suite contains 153 executable and dockerized website environments.
- It reconstructs visual interfaces, content, and functional workflows realistically.
- Environments remain deterministic and controlled during evaluation and training.
- Tasks span multi-step and post-authentication workflows.
- Human-agent collaboration expands and audits environment quality.
- WebHarbor also provides high-fidelity synthetic environments for reinforcement learning.

## Details

The suite comprises 3,518 tasks and auditable values such as visual fidelity, functional correctness, and task validity. Existing GUI agent evaluation often misses post-authentication workflows, which this suite covers. Beyond evaluation, a Qwen 4B-level GUI agent trained with reinforcement learning in WebHarbor generalizes to unseen tasks and performs competitively with leading open-source GUI web agents across four benchmarks. The results indicate that deterministic, high-fidelity web environments can support both reliable evaluation and cost-efficient training, provided tasks and websites remain representative of the target distribution.
