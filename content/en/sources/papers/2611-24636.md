# Clover-35B-A3B-Preview Technical Report

**Source**: [arXiv:2611.24636](https://arxiv.org/abs/2611.24636) · **Published**: 2026-11-18 (v1)
**Authors**: DiffuSpace Technical Team

## Overview

Diffusion language models reconstruct sequences through iterative denoising with multiple tokens predicted in parallel, connecting flexible generation order with efficient inference. Clover-35B-A3B-Preview is a mixture-of-experts diffusion language model with 35 billion total and 3 billion activated parameters that supports thinking-mode generation. It adapts Gated Delta Networks to block diffusion: each block combines recurrent memory of previously generated context with bidirectional softmax attention inside the current block, the historical memory readout competes with current-block tokens in a shared softmax, and the block includes learnable block-size calibration plus a separate zero-initialized right-context convolution branch. The report organizes evaluation around model quality, drafting/verification costs, and deployment under constrained memory. Code: github.com/DiffuSpace/Clover-35B-A3B-Preview; weights: huggingface.co/Diffuspace/Clover-35B-A3B-Preview.

## Key points

- Agent metrics: Clover leads the seven evaluated agent metrics, including 73.6 on SWE-bench Verified and 51.7 on Terminal-Bench 2.1.
- Speed: on internal agent workloads it reaches a reported 680 tokens/s using one NVIDIA GB300 GPU at BF16 precision and batch size one.
- Architecture: Gated Delta Networks inside block diffusion — recurrent memory of past context plus bidirectional softmax attention within the block, shared-softmax competition between history readout and current tokens, learnable block-size calibration, zero-initialized right-context convolution branch.
- Decision-model variant: generates answers to related questions jointly in one denoising pass; on an internal set of 500 groups, joint prediction raises question accuracy from 90.37% to 93.88% and all-correct group accuracy from 65.4% to 77.0%.
- Quantized deployment: on a single RTX 5070 Ti (16 GB VRAM) with SGLang + KTransformers hybrid GPU-CPU expert execution (96 GPU / 160 CPU experts per layer, INT4 group-size-32 expert weights, BF16 non-expert modules, AVX-512 CPU backend, 32K context, temperature 0, thinking on), full MATH-500 accuracy is 96.8% at 66.64 tokens/s with original top-8 placement; routing-informed expert placement (frequent experts on GPU) raises this to 97.6% at 97.52 tokens/s; top-6 verification gives 106.25 tokens/s at 96.0%.
- Baselines on the same MATH-500 setup: MiniCPM-V 4.7 97.4% at 49.51 tokens/s; Qwen3.6-35B-A3B 93.8% at 47.04 tokens/s.
- Decoding: self-speculative decoding with a block-level draft coreset threshold tau=0.9 (a lower tau=0.6 was also tested).

## Details

The report situates Clover among diffusion LM formulations (D3PM, RDM, SEDD, MDLM, DiffuSeq) and agent benchmarks. Evaluation covers model quality (including SWE-bench Verified and Terminal-Bench 2.1), drafting and verification costs (self-speculative decoding, draft sparsity/acceptance via the coreset threshold), and constrained-memory deployment: quantized INT4 expert placement on consumer hardware with hybrid GPU/CPU execution, where matching expert placement to workload demand is shown to matter as much as decoding optimization.
