# RealCLI: Toward a Unified Evaluation of Human-Agent Collaboration for CLI Agents

**Source**: [arXiv:2610.22507](https://arxiv.org/abs/2610.22507) · **Published**: 2026-10-15
**Authors**: Yunqi Liu et al.

## Overview

CLI agents increasingly execute longer-horizon tasks, yet existing benchmarks either assume user instructions stay fixed throughout execution or evaluate task outcomes without capturing runtime collaboration quality. REALCLI unifies the evaluation of task execution and human-agent collaboration on realistic CLI tasks.

## Key points

- Introduces REALCLI, a paired benchmark for execution plus collaboration quality.
- Measures collaboration across five dimensions, 22 sub-dimensions, and 51 interaction templates.
- REALCLI-EXEC supplies full specs upfront; REALCLI-COLLAB uses a scripted user with progressive info, corrections, constraint revisions, and authorization decisions.
- Best config achieves only 49.2% average score; joint collaboration score peaks at 37.6%.
- Reveals sharp gaps in task effectiveness vs collaboration quality, including steerability, trust calibration, and safety boundaries.

## Details

Task success alone is insufficient: collaboration quality lags and exposes steerability, trust calibration, and safety management weaknesses.
