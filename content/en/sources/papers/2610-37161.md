# WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training

**Source**: [huggingface](https://arxiv.org/abs/2610.37161)
**Date**: 2026-10-27


## Overview

Scaling supervised training for working agents requires diverse professional tasks that yield reliable expert demonstrations. However, missing or inconsistent task information can obstruct teacher execution and weaken the resulting supervision. We propose WorkFactory, a scalable framework for constructing coherent and executable professional tasks. Starting from professional intents, information-level planning builds an information support graph to guide task instantiation, explicitly representing the dependencies and locations of information required for the intended outputs.
