# GaussianRenderFormer: Transformer-based Rendering of 3D Gaussian Splats

**Source**: [arXiv:2611.05593](https://arxiv.org/abs/2611.05593) · **Published**: 2026-11-03
**Authors**: Shahaf Valencia Levy, Sagie Benaim

## Overview

Can a neural network learn to render 3D Gaussian splats on its own, with no rasterizer in the renderer? The paper presents GaussianRenderFormer, a transformer that takes a set of Gaussians and a camera and outputs the image directly. Each Gaussian becomes one token in a view-independent encoder, and a view-dependent decoder turns small patches of camera rays into pixels by attending to those tokens. Trained on 26,820 Objaverse objects pruned to 20,000 Gaussians each, GaussianRenderFormer renders 300 unseen objects at 38.08 dB PSNR against the full, unpruned splats, while rasterizing the same pruned input reaches 44.02 dB. The gap is not one of generalization; diagnostics are consistent with a bottleneck in the view decoder: telling it the projected footprint of each Gaussian, which it could in principle infer, adds 1.4 dB. Under-training is not ruled out. Code, trained models, and videos are available via the project page.

## Key points

- A neural renderer can take Gaussians and a camera and output an image directly, without rasterization.
- View-independent encoder tokenizes Gaussians; view-dependent decoder generates patches from ray tokens.
- Trained on 26,820 pruned Objaverse objects; evaluated on 300 unseen objects.
- Direct rendering reaches 38.08 dB PSNR vs rasterized pruned input at 44.02 dB.
- Providing projected Gaussian footprints adds 1.4 dB, suggesting a view-decoder bottleneck.
