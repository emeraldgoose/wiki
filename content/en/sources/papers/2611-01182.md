# Fast and Exact Relative-Position Attention via Structure-Aware Kernels

**Source**: [arXiv:2611.01182](https://arxiv.org/abs/2611.01182) · **Published**: 2026-10-31
**Authors**: Delyan Boychev, Ivo Petrov, Dimitar I. Dimitrov

## Overview

Relative-position attention is a compelling alternative to RoPE in domains such as audio: instead of encoding position through per-token rotations on queries and keys, it augments attention scores with additive content–position or bias–position terms, which lets a model express explicit, shift-invariant relationships between tokens at distance i−j. Learned relative biases also tend to generalize better than parameter-free encodings beyond the sequence lengths seen in training. The cost is mechanical: because relative terms depend on the pairwise offset, they require pairwise computation or lookups, which makes them incompatible with fused attention kernels and reintroduces the memory-bandwidth bottleneck that FlashAttention was designed to remove by streaming token blocks through on-chip SRAM.

Programmable attention frameworks such as FlexAttention fuse user-defined per-score callbacks and allow limited precomputation, but the authors note they still suffer redundant computation, repeated memory lookups and atomic contention during backpropagation. In practice, teams often abandon the encoding and retrain — replacing relative-position mechanisms as Flashzoi and FlashSwin do, or moving to RoPE-based alternatives such as ModernBERT.

This paper instead contributes an exact algorithm that folds additive relative-position terms into FlashAttention-style tiled computation, exploiting the block-level structure of relative distances across the attention matrix rather than treating every pairwise offset as an opaque per-element lookup. Queries and keys are projected only onto the offset ranges reachable within each token block, tile traversal is structured around constant- and variable-offset regions to maximize data reuse, and backward gradient accumulation is sharded by offset.

## Key points

- The method computes only the necessary key/query–relation products and reuses them across token pairs in both the forward and backward passes, instead of recomputing per-score terms.
- Offset-based gradient sharding and aggregation removes atomic contention entirely, which is one of the stated weaknesses of callback-based frameworks during backpropagation.
- The authors provide a unified, efficient Triton implementation across diverse relative-position attention mechanisms and evaluate it against naive and specialized implementations as well as FlexAttention, FlashAttention-4 and FlashInfer — including those frameworks augmented with the authors' own preprojected relation decomposition.
- For 8K-token sequences the method speeds up the forward pass by 1.8–6.4x and the backward pass by 2.0–21x, and reduces peak memory by up to 2.9–128x (forward) and 1.4–54x (backward) compared with the strongest baseline for each mechanism.
- End-to-end long-context transcription runs 1.8x faster with 2.4x less memory, and because the kernels use standard tiled attention structure the authors describe the result as a drop-in, hardware-efficient solution for scaling relative-position attention Transformers.

## Details

The evaluation covers production speech and text models and several relative-position mechanisms under one implementation, which the authors present as a unified alternative to per-mechanism specialized kernels. The comparison set is deliberately broad: naive implementations, previously specialized kernels, and state-of-the-art general frameworks (FlexAttention, FlashAttention-4, FlashInfer), with the latter group also tested after being augmented with the paper's preprojected relation decomposition so the gain is not attributed merely to that decomposition. The reported speedups and memory reductions are measured at 8K-token sequences, and the transcription result shows the effect surviving an end-to-end pipeline rather than only in kernel microbenchmarks.
