# Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents

**Source**: [arXiv:2610.34298](https://arxiv.org/abs/2610.34298) · **Published**: 2026-10-25
**Authors**: Zhenning Shi

## Overview

Language agents increasingly act through external tools and interactive environments, making the interface between model and executable capabilities part of the decision process. MCP and command-line interfaces can expose the same semantic operations through markedly different model-facing representations. This paper studies whether representational differences change agent behavior when executable capabilities are matched. It introduces Matched Interface Comparison and Analysis (MICA), which renders MCP and CLI from a shared semantic action contract and routes decoded actions through the same runtime. Across six models and three interactive environments, matched interfaces produced substantial differences in task performance and interaction cost. These effects extend beyond surface validity to semantic action selection, failure pathways, and recovery. Matched-state probes localize sensitivity to capability presentation, realization, and feedback. Paired natural trajectories revealed structured divergence in 94.3% of 2,004 episodes and showed that early differences propagate through subsequent interaction. The analysis identifies interface realization as a direct intervention boundary, so the paper introduces Decoupled Action Realization and Targeted Repair (DART), which preserves validated semantic commitments while repairing interface-specific realization. DART improved benchmark score in all six evaluated settings by up to 9.0 points and reduced MCP token cost in all three environments by up to 27.1k tokens per task. Together, the results establish interface representation as part of the closed-loop decision environment shaping agent behavior.

## Key points

- The same semantic actions exposed as MCP or CLI lead to different agent behavior.
- Six models and three interactive environments showed substantial performance and cost differences.
- 94.3% of 2,004 paired episodes diverged structurally.
- Early interface differences propagate through later interactions.
- DART improved score by up to 9.0 points in all six settings.
- DART reduced MCP token cost by up to 27.1k tokens per task in all three environments.

## Details

MICA isolates interface effects by rendering both interfaces from one semantic action contract and one runtime. Matched-state probes attribute sensitivity to presentation, realization, and feedback stages. DART then repairs realization without discarding semantic commitments, yielding both accuracy and token-cost benefits.
