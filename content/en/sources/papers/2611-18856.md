# Self-Improvement Memory Enables Continual Recursive Self-Improvement

**Source**: [arXiv](https://arxiv.org/abs/2611.18856)
**Published**: 2026-11-13

## Overview

Harness optimization for LLM agents — improving the context, tools, and execution scaffolding around a fixed policy model — is usually studied in a single fixed setting. In this work (Xin Yu was an intern at Google), the authors study Continual Recursive Self-Improvement (CRSI): continuing existing harness-optimization methods across compatible benchmarks or policy models. The key challenge is deciding which parts of an evolved harness to reuse or revise when either the benchmark or the model changes — the harness alone may not explain why earlier edits were made or how they performed.

They propose Self-Improvement Memory (SIM) for the harness optimizer (not the task-solving policy). SIM groups edits by recurring harness problem and records their rationale, predicted and observed outcomes, and evaluation context; new attempts extend this history as optimization continues. Across four domains (coding, text classification, agentic workspace tasks, engineering design), SIM achieves higher final scores than harness-only and root-cause-only continuation in both cross-dataset and pairwise cross-model comparisons; across ten independent coding source runs, paired continuations with SIM improve final scores by an average of 2.36 points over harness-only continuation (p = 0.003).

## Key points

- Cross-dataset CRSI (six dataset transitions): Full SIM finishes highest in all six, exceeding Harness Transfer by 2.43–4.35 points and Problem-Only (root-cause) Memory by 0.20–6.06 points; the margin over the strongest alternative ranges from 0.20 (NoMemory) to 4.35 (engineering) points.
- Source improvement does not guarantee a better target start: source RSI raises held-out source scores by 2.75–6.41 points, yet the FewShotAll harness starts target RSI below seed (72.92 vs 75.72); Harness Transfer reaches 74.12 (still below Cold Start 75.92), while Full SIM reaches 77.92.
- Cross-model CRSI (Opus 5.5 → Gemini 3.8 Flash): the Opus-evolved harness initially scores below Gemini's seed harness in every domain (deficits 0.60 in text classification to 5.48 in workspace); Full SIM finishes highest in all four domains, exceeding harness-only continuation by 3.60–11.33 points (workspace: Full SIM 84.75 vs Harness Transfer 73.42, both starting at 68.41).
- Continual improvement across generations (TB2.1, Gemini chain): CRSI beats Fresh RSI by 3.5 points on Gemini 3.5 Flash and 1.6 on 3.8 Flash, and finishes 0.8 points lower on Gemini 4 Argon (seed 89.7 / fresh 95.6 / CRSI 94.8).
- One harness for many models (text classification, Grok 4.20 Reasoning / Claude Opus 5.5 / Gemini 3.8 Flash): unified synthesis reaches 75.24 held-out — similar to separately evolved harnesses (75.20) and above the shared seed (73.28); sequential CRSI reaches 74.20.
- Coding source runs (ten independent): SIM continuations improve final scores by 2.36 points on average over harness-only continuation (p = 0.003).

## Details

- Problem formulation: Harness RSI optimizes an agent harness via execution feedback (propose, evaluate, select edits); CRSI continues this optimization under a changed benchmark or policy model, with transfer conditions defined for cross-dataset and cross-model settings.
- SIM contents: edits grouped by recurring harness problem, each with rationale, predicted and observed outcomes, and evaluation context; optimization rounds append to the history, so later attempts reuse and revise inherited edits informed by evidence.
- Comparison conditions: Cold Start (seed), Harness Transfer (evolved harness, no memory), Problem-Only Memory (root causes without outcomes/context), Full SIM (complete record).
- Ablations: SIM improves continuation from the same evolved harness; guides reuse/revision of inherited edits; preserves diagnoses while adding target evidence; supports earlier target progress and source retention in coding.
- Benchmarks: coding (Terminal-Bench 2.1/4), text classification, agentic workspace tasks, engineering design; equal-weight benchmark aggregation; held-out splits for both evolve and target evaluation.
- Caveats: CRSI is not uniformly better (Gemini 4 Argon −0.8 vs Fresh RSI; Harness Transfer below Cold Start in three domains); benefits are reported under the studied harness-optimization protocols and budgets; SIM targets the optimizer, not the policy.
