# Can Large Language Model Agents Learn by Watching Tutorial Videos?

**Source**: [arXiv:2611.01460](https://arxiv.org/abs/2611.01460) · **Published**: 2026-11-01
**Authors**: Haoyu Zhao, Zafeirios Fountas, Jun Wang

## Overview

Humans acquire knowledge from carefully crafted materials such as books and tutorial videos, but LLM agents remain frozen after training. The paper asks whether agents can learn from instructional videos without parameter updates. It introduces Tutorial Agentic Learning (TAL), a nonparametric approach that converts the wealth of human teaching into reusable agent knowledge. The central idea is to let agents ingest tutorial content and apply that understanding to future tasks, avoiding expensive large-scale parameter updates.

## Key points

- Tutorial videos contain rich instructional knowledge.
- LLM agents normally cannot update after training.
- Large-scale parameter updates are expensive.
- Tutorial Agentic Learning avoids parameter updates.
- The approach transfers tutorial understanding to future tasks.

## Details

The paper frames the challenge as bridging passive instructional content and active agent behavior. TAL treats tutorial videos as knowledge sources rather than merely evaluation artifacts. By keeping the base model fixed, it limits cost and deployment risk. The method targets reuse of human teaching across diverse future tasks and highlights a possible path for continual agent improvement without retraining.
