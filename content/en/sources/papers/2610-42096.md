# CausalWAM: Learning the Causes of Actions in World Action Models

**Source**: [arXiv:2610.42096](https://arxiv.org/abs/2610.42096) · **Published**: 2026-10-27
**Authors**: Juntao Cheng, Jinzhou Tang, Fan Feng, Henrik I. Christensen, Yujia Zheng

## Overview

World Action Models learn latent variables from observations and use them both to predict scene evolution and generate actions. While prediction may need the entire scene, only part of the scene actually causes a given action. Models fitted to demonstrations therefore do not automatically act using action-relevant latent variables.

CausalWAM introduces a constraint on the action side that leaves prediction free to use all latent variables. It argues that constraining dependencies between latent variables and action dimensions can separate action causes from prediction needs. Unlike methods that try to recover all latent variables, this only requires recovering the causes of actions.

## Key points

- Identifies a causal ambiguity in World Action Models.
- Distinguishes action-causing latents from latents needed for scene prediction.
- Adds a constraint on actions rather than all latent representations.
- Uses dependency constraints rather than full independent component recovery.
- Similar to nonlinear ICA and causal discovery research, but targets action causes.
- Addresses identifiability from demonstrations alone.

## Details

The paper uses examples such as block stacking, where action depends on block positions and gripper state while prediction also includes irrelevant background content. Fitting demonstrations well does not guarantee the action uses the correct latent variables.

Existing methods in nonlinear ICA, temporal dependence, and sparsity-related function classes aim to recover all latent variables. CausalWAM instead narrows the requirement to recovering causes of action, simplifying the problem and allowing prediction to remain unrestricted.
