# Advancing SVD-based LLM Compression via Layer-Wise Error Model Search

**Source**: [arXiv:2610.32878](https://arxiv.org/abs/2610.32878) · **Published**: 2026-10-23
**Authors**: Moritz Thoma, Maximilian Groezinger, Maximilian Forstenhäusler, Emad Aghajanzadeh, Manoj Rohit Vemparala, Christos Anagnostopoulos, Pierpaolo Mori, Nael Fasfous, Alexander Frickenstein, Daniel Mueller-Gritschneder, Ulf Schlichtmann

## Overview

Low-rank SVD-based compression is a promising way to reduce LLM computation costs, but existing methods face two limitations. Global rank allocation relies on uncalibrated error proxies that do not capture complex error propagation, and Fisher-based decompositions can suffer from severe rank collapse. This paper introduces Layer-wise Error Modeling Search (LEMS) and KFAC-SVD to address these two issues.

LEMS advances rank allocation by introducing a layer-wise error surrogate that combines local and global layer importance with a propagation bias, then solves global rank allocation as an integer linear programming problem. KFAC-SVD improves decomposition quality by using token-wise statistics, mitigating the rank deficiency observed in prior Fisher-based SVD approaches. Across Mistral, Qwen3, and Llama 3 families, LEMS consistently outperforms existing search strategies, with zero-shot accuracy gains up to 4.7 percentage points that generalize to 70B models. KFAC-SVD achieves an average 19% perplexity improvement.

## Key points

- Low-rank SVD compression can reduce LLM costs but has allocation and decomposition weaknesses.
- Global rank allocation often uses uncalibrated proxies.
- Fisher-based decompositions can suffer rank collapse.
- LEMS adds a layer-wise error surrogate and propagation bias.
- Rank allocation is formulated as an integer linear program.
- KFAC-SVD uses token-wise statistics to improve decomposition.

## Details

The paper separates rank allocation from decomposition quality. Better allocation chooses how much capacity each layer retains, while better decomposition determines how effectively retained capacity represents the original weights. LEMS focuses on propagation-aware allocation, and KFAC-SVD focuses on Fisher information without rank collapse. Together they improve both accuracy and perplexity across several model families and scales.
