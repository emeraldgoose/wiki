# AURA 2.0: From User-Driven Responses to Model-Initiated Conversations in Streaming Video

**Source**: [arXiv](https://arxiv.org/abs/2611.17048)
**Published**: 2026-11-12

## Overview

AURA 2.0, from Huawei Research (with HKUST and CUHK MMLab collaborators), is a streaming video large language model that moves beyond user-driven interaction. Its key advance is Model-Initiated Conversation (MIC): the model identifies topics worth discussing in the evolving visual stream and initiates conversation at appropriate moments without a user query, using conversational context to avoid repetitive or unnecessary interruptions. Two further capabilities extend the interaction surface: Stream-Aware Tool Calling (SATC), which invokes external tools from the current visual and conversational context and folds returned information into the ongoing interaction, and Interactive Visual Grounding (IVG), which supports bounding boxes in both user inputs (objects users mark on frames) and model outputs (frame-aligned boxes linking responses to specific regions).

To develop these capabilities, the team extends AURA's streaming interaction dataset with new MIC/SATC/IVG data, reaching approximately 11.4 billion tokens spanning 5,400 hours of video and 40 million training frames, with MLLM-based sample-level verification aligning queries, responses, tool calls, and boxes to a consistent video timeline. Training uses a three-stage scheme (streaming interaction and tool-use foundation; visual grounding and model-initiated conversation; capability composition and preference refinement) with focal-loss supervision on response-control tokens. Long-Horizon Interaction Memory (LHIM) summarizes salient events beyond the active visual window into textual context, complementing AURA's existing visual context management. Model weights and inference code are open-sourced.

## Key points

- IPIBench: AURA 2.0 reaches 49.30% Timing accuracy in Proactive Monitoring (approaching GPT-4o's 50.59%), 17.92% Repeated Proactiveness (near Gemini 3 Pro's 18.40%), the best Proactive Task Management average among evaluated models (37.96% Cancel, 17.87% Multi — exceeding Gemini 2.5 Pro and GPT-5.4), and 24.10/11.74/18.65 on R2P/RuP/RaP (R2P comparable to Gemini 3 Pro's 24.76%).
- StreamArena: 28.5% Real-Time Perception and 24.5% Historical Retrospection (L4 17.0%, exceeding AURA and other open-source streaming models); Proactive Interaction rises from 3.7% (AURA) to 12.8% (L1 29.7%), surpassing JoyAI-VL-Interaction (9.4%) and MOSS-VL-Realtime (11.8%); Tool use 18.5%, also above both.
- ProactiveVideoQA and PhoStream: AURA 2.0 reports leading performance among open-source streaming models (full tables in the paper; evaluated with PAUC and the official protocols).
- MIC-Bench (internal, 25 videos, 50 instances): with dialogue context, trigger rate 80.0% (20/25) at quality 4.10/5 and 3.0 msgs/min; visual-only context triggers 96.0% (24/25) at quality 3.62/5 and 3.5 msgs/min (173 messages: 93 Good / 65 Neutral / 15 Bad).
- SATC (167 questions over 55 clips): tools lift accuracy from 35.9% to 48.5% (+12.6 pp); the model invokes tools on 41.3% of questions (73 calls total).
- IVG (50-image COCO diagnostic): mIoU 0.906 vs backbone Qwen3.5-9B's 0.635; accuracy 94.0% vs 76.0%; boxes for 37/37 positive queries vs 26/37; abstains correctly on 11/13 absent targets vs 13/13 for the backbone.
- Inference efficiency (two ~140 GB accelerators, OmniInteract streams, median over pooled turns): 1 session TTFT 157 ms / TTFP 344 ms / RTF 0.135; 8 sessions 184/449/0.161; 16 sessions 234/601/0.203.

## Details

- Architecture: AURA 2.0 builds on AURA (Lu et al., 2026a), retaining Real-Time QA, Proactive QA, and Multi-Response QA while adding MIC, SATC, and IVG; response decisions in streaming remain based only on observations available so far.
- Training: three stages — (1) streaming interaction and tool-use foundation, (2) visual grounding and model-initiated conversation, (3) capability composition and preference refinement; focal-loss-based supervision on response-control tokens mitigates their class imbalance.
- Data: ~11.4B tokens, 5,400 hours of video, 40M frames; MLLM-based sample-level verification aligns queries, responses, tool calls, and bounding boxes along a shared video-chunk timeline.
- LHIM: as observations leave the active visual window, salient events are summarized as textual descriptions folded into the conversational context, preserving reference to earlier events for both user queries and MIC topic selection.
- MIC evaluation notes: two settings (Visual-Dialogue Context with annotated trigger windows; Visual-Only Context over entire videos) are not directly comparable; an MLLM judge (gpt-4o) scores messages with two annotators reviewing all judge outputs; interruption cost is tracked as median messages per minute.
- SATC examples: WebSearch resolves a "Zaochake" reservation as a breakfast experience at Xizha water market and identifies Brotherhood of Blades II from subtitle character names; a real-world query identifies Rome from the Colosseum and calls get_current_datetime + get_city_weather.
- Limitations: MIC quality is lower without an expressed user need (3.62 vs 4.10); some annotated trigger windows remain unaddressed; IVG abstains less reliably than the backbone on absent targets (11/13 vs 13/13).
- Open source: model weights and inference code released for reproducible research.
