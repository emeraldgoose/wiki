# Module-Aware Optimization for Graph Neural Networks

**Source**: [arXiv:2611.08379](https://arxiv.org/abs/2611.08379) · **Published**: 2026-11-05

## Overview

Optimizers impose different geometries on parameter updates. Adaptive methods such as Adam and AdamW treat parameters coordinate-wise, while matrix-aware optimizers such as Muon exploit weight-matrix structure through orthogonalized updates. Graph neural networks break the frame this choice assumes: the effective geometry of a GNN's weight matrices is shaped not only by the learned channel-mixing weights but also by the graph-propagated representations those matrices act on. A GNN layer multiplies its weights by features that the graph's message passing has already transformed, so an update that is perfectly normalized as a matrix can still be amplified in its effect on the layer output when it meets graph-propagated features.

GraphMuon is a graph-aware optimizer that adapts Muon's matrix updates to this reality. It performs orthogonalization in a metric defined by the covariance structure of the graph-propagated layer inputs, and it normalizes step sizes according to the update's induced effect on the layer representation rather than the raw matrix norm. The result is a graph-metric analogue of Muon's polar update step: the same matrix-orthogonalization philosophy, measured in the geometry the layer actually operates in.

The paper supports the design both theoretically and empirically. On the theory side, vanilla Muon can suffer graph-induced update amplification — its well-normalized matrix step producing outsized changes to layer outputs on propagated features — while GraphMuon mitigates this effect. On the empirical side, GraphMuon achieves 1.32×–2.42× validation-loss time-to-target speedups over AdamW on three large-scale OGB benchmarks, and across 15 dataset–architecture configurations spanning node classification, inductive graph classification, and graph regression it reaches the target loss faster in 13 cases while keeping predictive performance competitive or superior. The work appears at NeurIPS 2026 with code released.

## Key points

- The core observation: for GNNs, a matrix-normalized update does not control the layer-output change, because message passing changes the covariance of the features the weight matrix acts on — normalization must account for the propagated representations.
- GraphMuon modifies Muon in two coupled ways: orthogonalize the update in a metric defined by the covariance structure of graph-propagated layer inputs, and normalize the step size by the update's induced effect on the layer representation.
- Theoretical result: vanilla Muon can suffer graph-induced update amplification; GraphMuon mitigates it, yielding a graph-metric analogue of Muon's polar update step.
- Empirical headline: 1.32×–2.42× validation-loss time-to-target speedups over AdamW on three large-scale OGB benchmarks.
- Breadth: across 15 dataset–architecture configurations, GraphMuon attains lower time-to-target in 13 cases while maintaining competitive or superior predictive performance.
- Task coverage spans three GNN regimes: node classification, inductive graph classification, and graph regression.
- Positioning: coordinate-wise adaptive methods (Adam, AdamW) and matrix-aware methods (Muon) are treated as two ends of a geometry spectrum, with GraphMuon extending the matrix-aware end to the graph setting.
