# Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

**Source**: [arXiv:2611.18397](https://arxiv.org/abs/2611.18397) · **Published**: 2026-11-13
**Authors**: Run Luo, Kuan Zhang, Qi Deng, Yukun Chen, Zhihao Yang, Yufei Zhang, Renrong Hu, Yi Zhang, Guiyu Ma, et al. (Project Page: https://mihoyo-gamer.github.io/)

## Overview

Gamer (v2, 2026-11-13/17) is a generalist vision-language-action foundation model for long-horizon tasks in complex interactive environments — specifically games, spanning conventional 2D graphical interfaces and complex 3D simulated worlds. Its end-to-end architecture combines perception, memory management, and multi-step reasoning, and a single training and deployment pipeline serves both settings.

The key insight the paper pursues is that repetitive keyboard and mouse interaction trajectories — data abundant in games and embodied simulators — can support strong generalist policies, provided you scale data and learning algorithms around them. The model is first continue-pretrained on a dataset of tens of thousands of hours of device-level interaction, learning environmental dynamics across physical and virtual domains together.

From there, the authors layer three more components. Sparse-thinking instruction tuning sharply reduces redundant computation while keeping the reasoning needed for complex decisions. A stable multi-turn reinforcement learning method trains the long-horizon policy, explicitly addressing finite context windows, accumulated rollout errors, and sparse rewards. And for real-time interaction, a cloud-edge inference engine serves many simulated game environments concurrently, supports unbounded-context execution, and keeps online inference latency low.

Across multiple challenging 3D open-world games, Gamer demonstrates solid generalization and operational efficiency comparable to skilled players. It also achieves competitive results on conventional 2D game benchmarks.

## Key points

- One generalist model, both settings: the same architecture and training/deployment pipeline supports conventional 2D games (graphical/GUI-style input) and complex 3D simulated worlds.
- Data strategy: continue pre-training on tens of thousands of hours of device-level keyboard and mouse trajectories from simulated games and embodied environments, teaching shared dynamics across physical and virtual domains.
- Unified observation-action representation plus trajectory debiasing and temporal reweighting enable cross-game generalization and learning scaling laws.
- Sparse-thinking instruction tuning: substantially cheaper per-step reasoning than brute-force long CoT, while preserving the reasoning quality needed for decisions — key for real-time latency.
- Long-horizon RL (temporal-aware GRPO): a stable multi-turn method that addresses finite context windows, accumulated rollout errors, and sparse rewards, with verifiable rewards and temporal credit assignment.
- Serving: Streaming-vLLM cloud-edge inference serves many simulated game environments concurrently, supports unbounded-context execution, and keeps online latency low enough for real-time play.

## Details

The pipeline has four stages. Continued pre-training happens on a unified observation-action representation learned directly from raw device-level interaction. The authors handle the skew of human gameplay logs — some actions and contexts dominate — with trajectory debiasing and temporal reweighting, and study scaling laws for cross-game generalization: more distinct games and more hours per game both contribute, and the combination generalizes better than either lever alone.

Supervised fine-tuning then teaches the model to reason sparsely: instead of emitting long chains of thought at every step, Gamer emits reasoning only when the situation demands it (multi-level task conditioning). This keeps per-step inference cost compatible with real-time control and is the difference between a research demo and something that can hold 30+ FPS in a live game. The memory module (cross-context memory) carries needed history across turns so a finite context window does not break long-horizon tasks.

The RL stage is explicitly designed for long horizons. Standard policy gradients die here: context is finite, rollout errors accumulate, and rewards are sparse. Temporal-aware GRPO assigns credit temporally across the trajectory, uses verifiable reward signals where the game mechanics allow it, and updates the joint reasoning-action policy so that both the plan and the executor improve together.

For serving, the authors built Streaming-vLLM: a cloud-edge engine that runs inference for many simulated game instances in parallel, streams unbounded context (avoiding the usual sliding-window memory loss), and keeps latency low enough for interactive sessions. This systems work is what makes the model usable as a real-time player rather than an offline benchmark.

Results: in multiple 3D open-world games, Gamer achieves generalization and operational efficiency comparable to skilled human players, and it is competitive on 2D benchmarks. The authors read this as evidence that even repetitive low-level trajectories — clicks, moves, camera nudges — contain enough structure to train a strong generalist, a result with obvious implications for digital-to-physical transfer (these same trajectories look a lot like robot teleoperation logs).
