# ToolSpace: Scaling Tool-Centric Environment Synthesis for Long-Horizon Agents

**Source**: [arXiv:2611.05036](https://arxiv.org/abs/2611.05036) · **Published**: 2026-11-03
**Authors**: Guanting Dong, Zhichao Sun, Xinyu Yang, Rui Wang, Xin Deng, Jiajie Jin, and many coauthors

## Overview

Long-horizon agents compose diverse tools across MCP services into executable workflows, yet existing MCP environment scaling is data-centric. It first synthesizes a database and scenario, then derives tools and tasks from them, which can mismatch real interfaces and ground outcomes poorly. ToolSpace reverses this order with a tool-centric framework. It mines data, state, and retry dependencies from adjacent calls in execution traces of real MCP services and open agent corpora using deterministic rules rather than LLM judgment, then clusters the weighted tool-composition graph into environments. Databases are synthesized only for state-mutating environments, while query and stateless tools replay recorded returns. ToolSpace further performs state-aware random walks with rollback and decompiles each chain into a natural-language task with assertion-based checks.

## Key points

- The approach is tool-centric rather than database-centric.
- Dependencies come from real adjacent call traces by deterministic rules.
- A weighted tool-composition graph is clustered into environments.
- Databases are synthesized only for state-mutating environments.
- Tasks are generated from successful state-aware random walks.
- Assertion-based checks filter generated samples.

## Details

Applied to AutomationBench and Banking benchmarks, ToolSpace produces harder Pro versions on which seven frontier models drop by up to 38.2 points. Across seven long-horizon tool-use benchmarks, Qwen rises from 23.0 to 41.0 average score, or 43.2 with RL, and GLM-5.2 from 44.6 to 56.6, on par with Claude Opus 5. Ablations show execution-witnessed edges clearly outperform LLM-judged ones, and performance keeps improving with data and environment scale. The work is marked as ongoing and should be tracked for final changes.
