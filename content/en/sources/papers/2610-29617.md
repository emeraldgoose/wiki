# TernScope: Model-Hardware Co-Design for Efficient Ternary Endoscopic Segmentation

**Source**: [arXiv:2610.29617](https://arxiv.org/abs/2610.29617) · **Published**: 2026-10-21
**Authors**: Zhuoyu Wu, Wenhui Ou, Qiawei Zheng, Xuhong Qiu, Wenqi Fang, Raphaël C. -W. Phan

## Overview

Edge medical segmentation must reconcile small model size, high accuracy, and fast inference. TernScope addresses this tradeoff through model-hardware co-design, learning a compact segmentation network whose low-bit operators also simplify hardware execution. Split-channel large-kernel blocks preserve spatial context with limited computation, while branch fusion removes redundant inference paths. Ternary Progressive Quantization-aware Training adapts the fused network from deep to shallow layers, through the decoder, and finally to input and prediction layers.

## Key points

- Targets the model-size–accuracy–speed trilemma for edge endoscopy.
- Uses ternary quantization-aware training across network stages.
- Co-designs model and hardware execution for efficiency.

## Details

TernScope unifies architectural and quantization choices to produce deployable models that fit memory, delineate lesions accurately, and deliver predictions promptly on constrained hardware.
