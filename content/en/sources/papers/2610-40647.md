## Overview

Pixel-space generative models learn directly from noise to pixels, eliminating the separately trained autoencoder and its compression bottleneck. This simplicity, however, comes with a computational cost: the full-resolution image must be represented as Transformer tokens. Most pixel-space Transformers use one token per spatial patch, so the patch grid simultaneously determines what the model reads, what each token predicts, and how many tokens participate in global attention.
