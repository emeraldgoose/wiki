# Read, Allocate, Route: Role-Coupled Tokenization for Pixel-Space Generative Transformers

**Source**: [arXiv:2610.40647](https://arxiv.org/abs/2610.40647) · **Published**: 2026-10-29
**Authors**: Jiongfan Yang

## Overview

Pixel-space generative Transformers typically use one token per image patch, so capturing finer detail requires more tokens and makes global attention increasingly expensive. The authors observe that finer detail does not necessarily require more global communication: low-frequency structure benefits from global exchange, while high-frequency detail can be modeled locally. SpecSlot is a pixel-space rectified-flow Transformer that decouples output detail from global attention sequence length. It expands each spatial anchor into multiple slots, each assigned a disjoint band of DCT coefficients, separating anchor density from spectral subdivision. Only the lowest-frequency slot from each anchor participates in global attention, while all slots interact locally. A spatial head adds a local correction to the spectral prediction, while the generative state, target, and loss remain in pixel space. On ImageNet-256, SpecSlot achieved comparable final FID to a FLOPs-matched JiT control while converging faster. On ImageNet-512, it improved FID by 2.84 over the control with 3.9% fewer FLOPs, coming within 0.69 FID of JiT-B/16 at 38.2% lower cost. On text-to-image generation, it surpassed JiT-B/8 on DPG-Bench by 1.06 at 40.6% lower forward cost.

## Key points

- One token per patch makes global attention costly for finer detail.
- Low-frequency structure benefits globally; high-frequency detail can be local.
- Each spatial anchor expands into multiple DCT-band slots.
- Only the lowest-frequency slot joins global attention.
- All slots interact locally.
- The generative state, target, and loss remain in pixel space.
- SpecSlot converged faster and improved FID/cost across ImageNet and DPG-Bench.

## Details

Anchor density and spectral subdivision are separated, so raising spectral detail no longer enlarges the global sequence. The spatial head adds local correction while the rectified-flow objective stays in pixel space.
