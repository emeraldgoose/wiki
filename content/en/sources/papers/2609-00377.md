# FoldingAgent: Inferring Parametric Origami Procedures from Demonstration Videos

Source: Maya Moriya and 3 other authors, arXiv:2609.00377, Aug 31, 2026. Accepted to SIGGRAPH ASIA 2026.

**Lead**: Human origami knowledge is shared mostly through unstructured visual demonstrations, while computational methods need structured, parametric representations such as a crease pattern or an executable plan — and that gap is what this paper attacks. **FoldingAgent** is an agentic framework that infers explicit parametric folding programs directly from demonstration videos, using a pre-trained Vision-Language Model equipped with specialized tools to simulate geometric transitions, verify physical plausibility, retrieve and compare visual content, and evaluate its own predictions. Unlike models that predict static crease patterns, the agent operates sequentially and can re-plan its actions, mitigating the compounding errors inherent in multi-step folding. The authors also curate **PurelandFold**, a new benchmark of diverse Pureland origami videos with ground-truth geometry and action labels, and report that VLM reasoning plus tools and physical simulation successfully yields executable, physically plausible folding procedures.

## The gap: videos in, programs out

Most folding-by-computer work starts from structured input — a crease pattern someone already formalized. Humans, by contrast, learn from watching hands fold paper. Translating between those representations is the core problem: video is dense, ambiguous, and temporally extended, while a folding program must be exact. FoldingAgent defines a **parametric space** consisting of the paper's geometry plus a set of parametric folding actions, giving the agent a well-formed output language to aim at.

## How the agent works

The design pattern is VLM-as-reasoner plus tools-as-grounding. The pre-trained VLM supplies visual understanding and sequential decision-making, while the tool suite supplies what the VLM lacks: geometric-transition simulation (what would this fold actually do?), physical-plausibility verification (is that fold even possible?), visual retrieval and comparison (which demonstration moment matches?), and self-evaluation of predictions. Crucially, the agent **re-plans** rather than committing to one open-loop trajectory — each step can correct for earlier drift, which is the standard failure mode of multi-step folding prediction.

## What the results show

The abstract reports qualitative success — unstructured demonstrations converted into executable, physically plausible procedures on the PurelandFold benchmark — but gives no numeric metrics (no fold-accuracy percentages, no plausibility rates, no baseline comparisons). The concrete, checkable contribution at this level is therefore the framing plus the artifact: the parametric action space, the tool-using agent design, and the PurelandFold benchmark with ground-truth geometry and action labels that future work can be measured against.

## Caveats

This summary is abstract-based; all claims about performance come from the abstract's qualitative report, and the HTML/full text should be consulted for metrics, baselines, and ablations (e.g., how much each tool contributes). The evaluation is on Pureland origami — a constrained style — so generalization to complex multi-flap models is unshown. Project page and videos are referenced on the arXiv page.

## Relevance to SW engineers

- The architecture pattern transfers: a VLM (or LLM) reasoner plus domain simulators and verifiers, with re-planning to contain compounding error, beats open-loop prediction for any multi-step physical or procedural task.
- Defining a tight parametric action space before building the agent is the move that makes outputs executable rather than descriptive — worth copying for robotics, CAD, or UI-automation agents.
- A small ground-truth-labeled benchmark (PurelandFold) is what turns "it looks plausible" into something measurable; build the eval before trusting the demo.
