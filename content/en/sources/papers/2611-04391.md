# Human-to-Robot Transfer via Bridging Representation and Action Space in VLAs

**Source**: [arXiv:2611.04391](https://arxiv.org/abs/2611.04391) · **Published**: 2026-11-03
**Authors**: Junhyeong Park, Wook Jung, Taeyoung Kim, Huiwon Jang, Jinwoo Shin

## Overview

Pretrained Vision-Language-Action (VLA) policies provide a strong starting point for deployment, but adapting them to a target robot and environment still requires costly embodiment-specific demonstrations. Human demonstrations are far easier to collect, yet directly leveraging them is challenging due to the substantial human-robot embodiment gap, especially when the underlying VLA is pretrained primarily on robot data. The paper introduces H2RB (Human-To-Robot Bridge), a human-robot co-training framework for adapting pretrained VLA policies from unpaired human and robot demonstrations. H2RB bridges the embodiment gap at both interfaces: geometry-anchored alignment grounds human and robot observations in a compatible representation, while a decoupled-decoder tokenizer shares action latents without forcing both domains through a single action mapping. This lets human demonstrations provide useful behavioral supervision while retaining the rich visual, semantic, and control priors of the pretrained VLA. Across real-world tasks, H2RB raises object transfer performance from 8.0 to 51.8 and enables skill transfer to reach 62.7, in settings where co-train baselines totally fail to transfer human-demonstrated skills. The benefit persists under object-placement shifts, improving out-of-distribution transfer from 6.0 to 45.3. The work suggests a path for human demonstrations to serve as a scalable supervision source for adapting pretrained robotic policies and reducing dependence on costly target-robot data collection.

## Key points

- Adapting pretrained VLAs to a new robot still requires costly embodiment-specific demonstrations.
- Human demonstrations are cheaper but separated by a large human-robot embodiment gap.
- H2RB uses geometry-anchored alignment for observations and a decoupled-decoder tokenizer for action latents.
- Object transfer rises from 8.0 to 51.8, skill transfer reaches 62.7, and object-placement shifts improve from 6.0 to 45.3.
- Co-training baselines fail in settings where H2RB transfers human-demonstrated skills.

## Details

Results cover object transfer, skill transfer, and out-of-distribution object placement. Real-world task protocol and architecture specifics are described in the linked paper.
