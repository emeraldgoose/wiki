# Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training

**Source**: [arXiv:2611.04277](https://arxiv.org/abs/2611.04277) · **Published**: 2026-11-03
**Authors**: Kangning Zhang, Wenxiang Jiao, Bowen Fang, Shuai Shao, Jiachen Zhu, Rong Shan, Shijian Wang, Hao Wang, Yuan Lu, Weiwen Liu, Weinan Zhang

## Overview

Agent harnesses evolved from a common execution base exhibit locality, complementarity, and nonstationarity: variants repair different failures, and their utility changes as the policy learns. Chasing a universally superior harness is therefore not the best approach.

Harness-S instead rescues failures of a base execution system through sibling harnesses and transfers the resulting behavior into a single policy that remains effective under the original harness. Directional harness evolution develops specialized sibling harnesses along distinct repair directions and forms a fixed sibling harness pool during policy training. Complementary rescue training invokes that pool only when all initial attempts under the base harness fail.

Fresh rollouts under auxiliary harnesses replace failed groups for reinforcement learning. An adaptive router selects top-k variants using harness behavior profiles and LLM voting, with profile re-anchoring as the policy learns. Experiments on AppWorld, SWE-Gym, and DBBench show substantial policy-only training improvements when returning to the base harness.

## Key points

- Exploits complementarity among harness variants rather than seeking one best harness.
- Forms a reusable sibling harness pool along distinct repair directions.
- Trains only when all base-harness attempts fail.
- Transfers harness-elicited behaviors into the base-harness policy.
- Uses an adaptive router over harness behavior profiles.
- Reuses the router to improve rank-one inference at the same rollout cost.

## Details

The paper supports transfer through behavioral analyses and held-out cases. The reported tasks are AppWorld, SWE-Gym, and DBBench. Keywords include language model agents, agent harnesses, reinforcement learning, harness complementarity, and harness routing.
