# Ensemble Routing for Prompt-Adaptive Cost-Aware LLM Inference

**Source**: [arXiv:2611.10193](https://arxiv.org/abs/2611.10193) · **Published**: 2026-11-06
**Authors**: Saul Urso, Emanuele Carlini, Patrizio Dazzi, Matteo Mordacchini

## Overview

Web services backed by LLMs face heterogeneous requests and must balance response quality against inference cost: invoking an expensive model indiscriminately wastes resources, while always picking a cheap one erodes quality, and different users weigh this trade-off differently. Conventional routing answers with a single model per prompt, which cannot exploit the complementary capabilities of several LLMs; fixed ensembles combine multiple models but freeze both their composition and their cardinality, so cost cannot be tuned per prompt at inference time. The authors define ensemble routing as choosing, per prompt, both which models to invoke and how many.

PISA attacks the single-model case by estimating how likely each candidate model is to answer a given prompt correctly. Prompt embeddings are partitioned with X-means, and each query is represented by soft memberships over the learned centroids (a softmax over cosine distances whose concentration is controlled by a temperature), so capability estimation can draw on several neighboring prompt regions instead of one hard cluster. An independent L2-regularized logistic predictor per model, trained on historical correctness labels, turns those memberships into a capability estimate; each model's normalized average training cost supplies the cost term, and the router picks the model maximizing a utility that mixes predicted quality and cost with a weight the operator can set per request at inference time.

PISA-E reuses exactly these per-model estimates to select ensembles without training any ensemble-specific predictor. Candidate subsets are scored by the probability that a strict majority of their members answer correctly — a tractable surrogate computed with the Poisson-binomial dynamic program under a conditional-independence assumption — combined with an ensemble cost that sums member costs. Because an even-cardinality subset is always dominated by an odd-cardinality one under this surrogate (dropping one member lowers both the majority threshold and the cost), candidates are greedy prefixes of the utility ranking restricted to odd sizes up to eleven models. The selected models are queried in parallel and their responses merged by self-weighted BERTScore, a capability-aware variant of minimum Bayes risk decoding that weights each response by its predicted reliability.

Across four routing benchmarks under in-distribution and out-of-distribution conditions, PISA posts the highest macro-average cost-performance hypervolume among the evaluated single-model routers, and PISA-E the highest macro-average task performance among the evaluated ensemble approaches — beating the strongest competitors by 2.09 and 2.87 percentage points (ID, OOD) when quality is prioritized, and exceeding them at lower-cost operating points while cutting average inference cost by roughly 36% and 25%.

## Key points

- Capability estimation: X-means fixes both the cluster count and centroids; L2-normalized embeddings and centroids give memberships via a softmax over cosine distances with concentration parameter beta; each model gets its own logistic predictor fitted on binary correctness labels (evaluation scores thresholded at 0.5).
- Predictor regularization is chosen per model by 5-fold cross-validation minimizing log loss over 10 logarithmically spaced values between 1e-4 and 1e4, then refitted on the full training set.
- Routing objective: pick the model maximizing alpha times predicted capability plus (1 - alpha) times (1 - normalized cost); alpha is the cost-quality preference and is adjustable at inference time without retraining.
- Ensemble-success surrogate: strict-majority correct-answer probability over Bernoulli per-model outcomes with the PISA capability estimates as success probabilities, computed exactly with the Poisson-binomial dynamic program — no ensemble-specific training, no need to observe generated responses before selecting.
- Ensemble cost is the sum of member average costs, normalized by the sum of the k_max largest average model costs, so subsets of different cardinalities are comparable under one preference parameter.
- Greedy candidate construction: models ranked by single-model utility, candidates are prefixes of odd cardinality up to k_max = 11; odd-only search loses no optimal solution under the surrogate because any even subset is dominated by an odd sub-subset.
- Response resolution: self-weighted BERTScore — each candidate response is scored by capability-weighted BERTScore similarity against the other members' responses, with weights equal to normalized capability estimates (a capability-aware MBR decoding).
- Evaluation: LLMRouterBench Track-2, RouterBench, FusionBench, and SPROUT; five seeds; ID splits (70% development / 30% test, development further 80/20) and OOD (train on ID task groups, test on held-out task groups) with separately fitted routers; prompt embeddings from Qwen3-Embedding-8B.
- Single-model results (normalized hypervolume x 100): PISA macro-average 37.41 ID (vs 35.78 EmbedLLM-MF, 35.44 Avengers-Pro, 34.38 KNN) and 22.85 OOD (vs 21.33, 17.06, 20.02); best in six of the eight benchmark-setting combinations, including RouterBench ID 46.15 and FusionBench ID 42.57.
- Ensemble results: highest macro-average task performance among DFPE, LLM-TOPLA, SelectLLM, PairRanker (PT/FT), and BERTScore-MBR, by +2.09 pp ID and +2.87 pp OOD when prioritizing quality; at selected lower-cost operating points it still exceeds the strongest competitors while reducing average inference cost by about 36% (ID) and 25% (OOD).
- Adaptive vs fixed cardinality: on Track-2 ID the adaptive PISA-E reaches hypervolume 28.57 against 27.89 for the best fixed size (k=1) and a steady decay for larger fixed ensembles (14.55 at k=11); on RouterBench ID the fixed k=1 point is marginally ahead (46.99 vs 46.37), so the macro-average advantage comes from adapting size per prompt rather than from uniformly larger or smaller ensembles.
- Prompt-dependent ranking ablation: replacing prompt-specific ranking with global fit-set ranking while keeping the Poisson-binomial surrogate drops macro hypervolume from 39.35 to 34.39 (ID) and from 26.30 to 25.39 (OOD) — 32.82 vs 29.89 across all eight scenarios — with the adaptive variant winning all four ID benchmarks but losing FusionBench and SPROUT under OOD.
- Positioning: unlike hard-assignment cluster routers (UniRoute, Avengers-Pro) or clustering-plus-IRT (ZeroRouter), PISA uses soft memberships with per-model predictors; unlike cascades or sequential expansion (EMS, LightRouter), PISA-E selects a parallel ensemble before generation; unlike LLM-TOPLA/DFPE (one ensemble reused for all queries) or SelectLLM (adaptive composition, fixed size), it adapts both composition and cardinality.

## Details

- Publication venue: The ACM Web Conference 2027 (May 10-14, 2027, Dublin, Ireland); the arXiv v1 (2026-11-06) is the version documented here; license CC BY 4.0.
- Affiliations: all four authors are with CNR (Institute of Information Science and Technologies; Institute of Informatics and Telematics) and the University of Pisa, Italy.
- Baselines: single-model routing compared against EmbedLLM (latent factors from the model-question correctness matrix), Avengers-Pro, K-NN, and an MLP; an oracle selector that picks the best model per prompt from ground-truth scores bounds attainable performance.
- Ensemble baselines: DFPE and LLM-TOPLA (ensembles reused across queries), SelectLLM (input-adaptive composition, fixed cardinality), PairRanker in pretrained and fine-tuned variants using the PairRM pairwise reward model from LLM-Blender, and plain BERTScore-based MBR.
- Metrics: task performance is macro-averaged across task groups; cost-performance trade-offs are summarized by normalized dominated hypervolume (x 100) with the reference performance set to a random router and the reference cost to the 40th percentile (single-model) or 70th percentile (ensemble) of the full-pool cost distribution.
- Cost model: a model's cost is its average observed training-set cost, normalized by the most expensive model's average; ensemble cost aggregates member averages — no per-prompt price prediction is used.
- Appendix contributions: a Gaussian-copula extension that models dependence between member outcomes for ensemble-success estimation (Appendix B), a comparison of greedy selection against exhaustive surrogate optimization (Appendix E), and hypervolume reference-point and maximum-cardinality sensitivity studies (Appendices C-D).
- The cost-quality preference being tunable at inference time means one fitted router serves many operating points — hyperparameters and ensemble configurations were selected once per benchmark at alpha = 1 (quality-first) and reused across all alpha values.
