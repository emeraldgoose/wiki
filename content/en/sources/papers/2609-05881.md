# Broken on Arrival: Non-Functional Quantized LLM Artifacts in Public Model Registries and How to Catch Them

**Source**: [huggingface](https://arxiv.org/abs/2609.05881)
**Date**: 2026-10-25


## Overview

Developers download quantized large language models (LLMs) from public registries to run them locally. None of the registries we examined documented functional testing of their files. We tested all 305 eligible code-capable GGUF tags (the llama.cpp format) across 15 model lines in the official Ollama library, plus 22 popular Hugging Face community files. A 15-task code screen identified suspects, which we retested on all 164 HumanEval+ tasks. Seven official tags (2.3%) solved at most six of them. All were low-bit quantizations of models with at most four billion parameters.
