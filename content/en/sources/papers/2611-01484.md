# CrossSWE: Benchmarking Cross-Repository Joint Development for Coding Agents

**Source**: [arXiv:2611.01484](https://arxiv.org/abs/2611.01484) · **Published**: 2026-11-01
**Authors**: Silin Chen, Yuling Shi, Heng Lian, Zihan Zhang, Xiaodong Gu, Haotian Lin, Zhensu Sun

## Overview

As coding agents improve on software engineering benchmarks, recent work has increased task complexity through longer horizons and larger code changes. Real-world development often spans multiple interdependent repositories, requiring dependency reasoning, change propagation, and interface consistency. CrossSWE introduces a benchmark for cross-repository joint development comprising 171 real-world instances. It shifts the problem from editing scale within one repository to coordinating compatible changes across repositories.

## Key points

- Coding agents are approaching strong scores on existing SWE benchmarks.
- Real projects often span several repositories.
- Cross-repository work needs dependency reasoning.
- Changes must propagate consistently across interfaces.
- CrossSWE contains 171 real-world instances.
- The benchmark targets cross-repository joint development.

## Details

The paper argues that simply making single-repository tasks longer does not capture collaborative software evolution. Cross-repository joint development introduces alignment issues such as API consistency and version compatibility. CrossSWE provides concrete instances drawn from real development activity, enabling evaluation of whether agents can manage interface-level contracts while making coordinated changes. The focus is on realistic multi-repository tasks rather than isolated code edits.
