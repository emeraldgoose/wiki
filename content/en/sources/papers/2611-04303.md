# FlowTranslator: Training-Free In-Image Machine Translation with Flow-Based Editing

**Source**: [arXiv:2611.04303](https://arxiv.org/abs/2611.04303) · **Published**: 2026-11-03
**Authors**: Zhixian Li, Xingsong Ye, Yongkun Du, Yunyan Xiao, Yanglin Huang, Pinxuan Chen, Jiyu Zhuang, Cong Xu, Zhineng Chen

## Overview

In-image machine translation replaces text in an image with its translation while preserving the surrounding visual context. Existing task-specific models require massive paired training images before and after translation. FlowTranslator is a training-free framework that uses an OCR model and an LLM to generate a translation prompt, then injects it into a text-to-image diffusion model. It introduces Region Coupling Release, which partially decorrelates target-branch noise inside the text region early in the trajectory, and Coupling Expansion, which amplifies the emerging edit displacement mid-trajectory. These controls guide accurate and natural generation of translated text.

## Key points

- The approach is fully training-free.
- It transfers multilingual text generation ability to in-image translation.
- OCR and an LLM generate the translation prompt.
- Region Coupling Release acts early in the trajectory.
- Coupling Expansion amplifies the edit displacement mid-trajectory.
- Whole-image ScenePair translation reaches 40.1 percent exact-match accuracy.

## Details

Under the EasyOCR read-back protocol, FlowTranslator achieves average scores of 20.6 PRIM BLEU and 57.2 COMET, outperforming training-based UniTranslator. On more challenging whole-image ScenePair photographs translated into Chinese, it reaches 40.1 percent exact-match accuracy and surpasses existing editing systems. Some existing systems address only text rendering rather than the complete task. The results establish flow-based editing as a strong training-free baseline, though accuracy depends on OCR and read-back conditions.
