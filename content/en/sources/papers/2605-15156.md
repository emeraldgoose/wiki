# MeMo: Memory as a Model

## Overview

MeMo (Memory as a Model) is a modular framework that encodes new knowledge into a dedicated memory model while keeping the large language model (LLM) parameters unchanged. This approach addresses the fundamental limitation of static LLM knowledge by enabling efficient integration of timely, domain-specific information without costly retraining.

## Key Advantages

MeMo offers several significant advantages over existing knowledge integration methods:

1. **Cross-document relationship capture**: Effectively handles complex relationships that span multiple documents
2. **Robustness to retrieval noise**: Maintains performance even when retrieval systems return imperfect or noisy results
3. **No catastrophic forgetting**: Preserves the original LLM's pretrained knowledge since only the memory model is updated
4. **Plug-and-play compatibility**: Works with both open-source and proprietary closed-source LLMs without requiring access to weights or logits
5. **Corpus-size independent retrieval**: Memory model has fixed size, making inference costs independent of corpus size

## Technical Approach

MeMo consists of two main components:

### Memory Model Training
- A frozen Generator model transforms a target corpus into a reflection QA dataset
- Process includes: fact extraction, consolidation, verification, entity surfacing, and cross-document synthesis
- The resulting dataset trains a dedicated Memory model

### Inference Pipeline
- A frozen Executive model answers complex user queries
- Uses structured multi-turn protocol:
  1. Decomposes input into simpler, targeted sub-queries
  2. Retrieves intermediate responses from the Memory model
  3. Reasons over retrieved information to produce final answers

## Experimental Results

MeMo was evaluated on three benchmarks:
- **BrowseComp-Plus**: Demonstrated strong performance in complex question answering
- **NarrativeQA**: Showed effectiveness in narrative understanding and question answering
- **MuSiQue**: Achieved competitive results in multi-hop question answering tasks

The results show that MeMo achieves strong performance compared to existing methods across diverse settings, validating the effectiveness of the modular memory approach.

## Comparison with Existing Methods

MeMo combines the strengths of three existing paradigms while mitigating their limitations:

1. **Non-parametric methods**: Leverages off-the-shelf frontier models unchanged
2. **Parametric methods**: Internalizes knowledge in model parameters without catastrophic forgetting
3. **Latent memory methods**: Provides compact, queryable memory artifact with better transferability

## Significance

MeMo represents a significant advancement in LLM knowledge integration, offering a practical solution for applications requiring up-to-date or domain-specific knowledge while maintaining the benefits of pretrained models. The modular design makes it particularly suitable for real-world applications where knowledge freshness and computational efficiency are critical.
