# From Problem to Fix in Minutes: Automating Search Relevance Tuning with the Amazon OpenSearch Service Relevance Agent

**Source**: [AWS Big Data Blog](https://aws.amazon.com/blogs/big-data/from-problem-to-fix-in-minutes-automating-search-relevance-tuning-with-the-amazon-opensearch-service-relevance-agent) · **Published**: 2026-10-27

## Overview

Automating search relevance tuning means going from "my NDCG score is low" to "here is a better search query" in minutes. The Amazon OpenSearch Service Search Relevance Agent accelerates search quality improvements from within the UI: you describe the problem, it investigates behavioral data, runs sequenced evaluations, and generates an improved query validated against search quality targets. Earlier measurement work with UBI/SRW provides the diagnosis; the agent handles the harder action step.

## Key points

- Moves relevance tuning from manual query rewriting to an agent-driven workflow.
- Investigates behavioral data and runs sequenced evaluations automatically.
- Generates and validates improved queries against search quality targets.
- Builds on User Behavior Insights and Search Relevance Workbench skills.
- Keeps the workflow inside the OpenSearch Service UI.

## Details

The Relevance Agent closes the loop between diagnosis and remedy, letting teams act on NDCG gaps without leaving the service UI.
