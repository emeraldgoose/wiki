# How California built its Behavioral Health Public County Profile on Databricks

**Source**: [Databricks Blog](https://www.databricks.com/blog/how-california-built-its-behavioral-health-public-county-profile-databricks) · **Published**: 2026-10-09

## Overview

California's Department of Health Care Services launched the Behavioral Health Public County Profile — a first-of-its-kind public dashboard uniting behavioral health data from all 58 counties. Built on Databricks in a FedRAMP-authorized environment, it serves as the accountability engine for the Behavioral Health Services Act (BHSA) passed under Proposition 1, letting anyone compare counties on funding, services, and outcomes.

## From fragmented silos to one profile

County spending plans, demographics, homelessness services, and performance measures previously lived in incompatible systems with different cadences. The profile consolidates them so the public can compare counties, see who is and isn't served, track housing-related services, review each county's three-year BHSA Integrated Plan, and monitor outcome-tied performance measures — turning statutory reporting into democratic oversight.

## The platform behind the transparency

Spark Declarative Pipelines and Lakeflow Connect ingest dozens of county sources into one governed platform; Semantic Views define each metric once so cross-county comparisons are apples-to-apples; serverless compute removes infrastructure management; and end-to-end lineage plus FedRAMP-authorized security keep every published number traceable and protected. The lesson for data-driven government: treat transparency as a living data product, not a static periodic report, on infrastructure that scales as new measures arrive.
