# Lakebase Postgres is now generally available on Google Cloud

**Source**: [databricks](https://www.databricks.com/blog/lakebase-postgres-now-generally-available-google-cloud) · **Published**: 2026-11-02

## Overview

Lakebase Postgres is generally available on Google Cloud, allowing teams to run production-grade, serverless Postgres directly on the Databricks Data + AI Platform. The Lakebase architecture separates compute from storage, removing resource conflicts and infrastructure overhead. Operational and analytical data share the same storage layer, eliminating the need to build and maintain pipelines. The result is a Postgres database that scales with the application, shares one governance model, and reduces total cost of ownership.

## Capabilities

- Autoscaling and scale to zero: compute adjusts to traffic and shuts off when idle.
- Instant branching: create isolated, zero-copy branches of production data in seconds.
- Point-in-time recovery: restore the database to a specific moment after bugs or accidental deletions.

## Unified platform

Because operational and analytical data share the same storage foundation, analytics, applications, and agents run on a unified platform without fragile pipelines. Lakebase Postgres on Google Cloud is backed by the scale and trust of Google Cloud infrastructure.
