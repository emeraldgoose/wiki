# Building live intelligence: Databricks AI Search supports Streaming Tables, Materialized Views, and Managed tables using Iceberg

**Source**: [Databricks Blog](https://www.databricks.com/blog/building-live-intelligence-databricks-ai-search-supports-streaming-tables-materialized-views) · **Published**: 2026-10-26

## Overview

Databricks AI Search now natively supports Streaming Tables, Materialized Views, and Managed tables using Iceberg v3+ in addition to Delta tables. This enables live intelligence workloads where search and analytics reflect continuously updated data.

## Key points

- AI Search supports Streaming Tables and Materialized Views.
- Managed tables using Iceberg v3+ are now supported alongside Delta.
- Live intelligence workloads can query continuously refreshed data.
- Expands table format interoperability for search and analytics.
- Helps teams build near-real-time AI applications on Databricks.

## Details

The integration broadens AI Search to multiple storage formats and incremental tables, supporting near-real-time decision making.
