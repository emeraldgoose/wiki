# The Genie One MCP is now Generally Available

## Overview

Isolated agents each carry their own stale, hand-modeled view of the business and contradict each other on the same data. The now-GA Genie One MCP server fixes this with one governed interface: any agent can retrieve Genie One's answers over structured and unstructured data, grounded in Genie Ontology business context, while the server runs as a managed MCP Service inside Unity Gateway with centralized governance, policies, and audit logging.

## One governed entry point against agent sprawl

The MCP exposes tools to ask Genie One questions, fetch results, track progress, and steer responses, plus an MCP App embedding live visualizations and ontology citations. Connected clients — Claude, ChatGPT, Cursor, IDEs, internal tools — inherit domain semantics bridging relational tables and document stores without per-format connectors, so every surface returns consistent answers while complex subtasks route to specialized Genie Agents.

## Use cases in the wild

Teams use it to enrich agent-built slide decks with trusted numbers instead of skeleton outlines, to ground customer-outreach agents in per-account telemetry before sending CRM messages, and to anchor coding agents in agreed business definitions when touching product code. Anywhere a preferred agent needs governed business data, it invokes the MCP rather than maintaining its own context.
