# Personalizing Airbnb search by learning from the guest journey

**Source**: [airbnb blog](https://airbnb.tech/ai-ml/personalizing-airbnb-search-by-learning-from-the-guest-journey) · **Published**: 2026-07-27

## Overview

Airbnb search is personalized by learning from the guest journey. Rather than matching queries to static relevance signals, the approach models how guests browse, compare, and decide throughout the journey, using those signals to rank listings more personally.

## Key points

- Guest journey signals capture preferences beyond the initial query.
- Personalization uses sequential behavior across browsing, comparison, and booking steps.
- Listing ranking incorporates journey-level learning instead of only query matching.
- Search quality improves for diverse travel intents.
- The approach is data-driven and grounded in observed guest behavior.

## Details

Learning from the guest journey lets search adapt to evolving intent, improving relevance while maintaining a scalable ranking pipeline.
