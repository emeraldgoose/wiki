# Databricks와 SAP, 엔터프라이즈 AI 전환을 가속하는 엔드투엔드 데이터·AI 역량 공개

**원문**: [Databricks Blog](https://www.databricks.com/blog/databricks-and-sap-unleash-end-end-data-ai-capabilities-level-enterprise-ai-transformation) · **게시일**: 2026-10-30

## 개요
AI 모델은 그 어느 때보다 강력해졌지만, Fortune 500 기업 중 90% 이상이 핵심 프로세스를 운영하는 데 사용하는 SAP 시스템에 잠든 업무 맥락을 부족하게 합니다. SAP와 Databricks는 지난해 SAP Business Data Cloud에 SAP Databricks를 도입했고, 이제 Databricks의 전체 역량을 SAP Databricks로 가져오는 다음 단계로 나아갑니다. 핵심은 SAP Application Data Foundation으로, 커스텀 추출 파이프라인이나 데이터 복사 없이 SAP 애플리케이션 데이터를 SAP Databricks를 포함한 SAP Business Data Cloud 엔진에서 직접 소비할 수 있게 합니다. 또한 Genie, Lakeflow, Unity Gateway, Lakebase 등 역량 확장과 함께 Unity Catalog 기반의 SAP·비SAP 데이터 거버넌스를 제공하여, 수십 년간의 SAP 프로세스 데이터와 외부 데이터를 결합해 예측, 이상 탐지, 에이전트 애플리케이션을 구성하도록 돕습니다.

## 핵심 내용
- SAP Application Data Foundation은 커스텀 추출 파이프라인을 제거하며, SAP 데이터 제품을 SAP BDC로 제로카피 공유하여 복사와 사일로를 피합니다.
- AI는 SAP 업무 의미론 위에서 구축되어, Databricks 플랫폼이 연동한 SAP 데이터로 Gather, Lakeflow, Unity Gateway, Lakebase를 활용합니다.
- Unity Catalog와 Unity Gateway가 SAP·비SAP 데이터·모델·에이전트 전반의 거버넌스와 비용 통제를 통합합니다.
- 고객은 SAP BDC 내부에서 SAP Databricks와 함께 쓰거나, 거버넌스된 SAP 데이터 제품을 기존 Databricks 환경으로 가져와 임의 클라우드·모델에서 활용할 수 있습니다.
- 사례로 SAF-Holland가 고객·배송·자재 데이터 1억 건 이상을 통합해 분석속도를 5배 높이고, 수 주 걸리던 통찰을 수 분 안에 얻었다고 보고되었습니다.
- SAP와 Databricks 리더는 이번 파트너십이 SAP의 업무 프로세스 이해와 선도 Data+AI 플랫폼을 결합해 데이터를 자율 기업의 기반으로 만드는 것이라고 설명합니다.

## 상세
SAP 애플리케이션 데이터는 보통 데이터를 복사하고 업무 맥락을 잃으며 거버넌스를 파편화하는 커스텀 추출 파이프라인을 통해서만 접근할 수 있었습니다. Application Data Foundation은 SAP 데이터를 SAP BDC 엔진에서 소비 가능한 제품으로 노출해 총소유비용을 낮추고 빠르게 가치를 창출합니다. SAP Databricks 고객에게는 추가 파이프라인 없음, 의미론적으로 풍부한 데이터 위 모델 구축, 그리고 Genie·Lakeflow·Unity Gateway·Lakebase를 포함한 플랫폼 확장, Unity Gateway를 통한 다중 AI 거버넌스와 에이전트 통제가 따라옵니다.

파트너십은 아키텍처 선택과 영업 실행으로도 확장됩니다. 고객은 SAP BDC 안에서 SAP 데이터를 쓰거나 거버넌스된 SAP 데이터 제품을 기존 Databricks 환경으로 내보낼 수 있으며, SAP와 Databricks의 연합 필드 팀이 실행을 가속합니다. SAP Databricks와 SAP BDC Connect for Databricks는 오늘부터 사용 가능하며, Application Data Foundation의 세부 사항은 SAP 또는 Databricks 계정 팀과 상의해야 합니다.
