# Microsoft Ignite 2026의 Azure Databricks 세션

**Source**: [Databricks Blog](https://www.databricks.com/blog/azure-databricks-sessions-microsoft-ignite-2026)
**게시일**: 2026-11-17

## 개요

Azure Databricks는 2026년 11월 17–20일 샌프란시스코 Moscone Center에서 열리는 Microsoft Ignite 2026의 Visionary급 스폰서이며, The Hub의 부스 #5271R(11월 17–19일)과 The Social @ Canopy Hotel에서의 임원 미팅(11월 17–18일, 오전 9시–오후 5시 PT)을 운영한다. 주제는 "Build, Govern and Run AI that's yours" — Unity Catalog로 거버넌스되는 Microsoft Teams, Excel, Microsoft Copilot Cowork의 Genie를 통해 조직이 AI 파일럿에서 프로덕션 AI로 나아가도록 돕는 것이다.

## 주요 내용

- 대표 세션: "Build governed AI that understands your business context" — 11월 18일(수) 오후 2:15 PT, Robert Saxby(Databricks)와 Michel Porter(EY). EY의 감사 실무가 수십억 건의 레코드를 수집·변환·거버넌스하는 사례와 함께 Teams 및 Copilot Cowork의 Genie 라이브 데모를 진행한다.
- Azure Databricks for government cloud: Azure Government를 위한 현대적 데이터와 AI(라이트닝 토크, 11월 17일 오후 2:00) — 공공기관용 레이크하우스, 거버넌스, 주권.
- Azure Databricks AI Runtime으로 NVIDIA Nemotron 모델 파인튜닝(11월 18일 오후 1:20) — NeMo 후속 학습 실습, 영수증 추출 멀티모달 예시, 서버리스 GPU, 보안/거버넌스 고려사항.
- 에이전틱 AI를 확장하고 데이터를 자율적 행동으로(11월 18일 오후 1:45) — Diego Jarne(PwC), Bernhard Pfirrmann(Nokia), Eric Tranby(CareQuest Institute for Oral Health), Corrinne Walkaus(Markel)가 생명과학·보험·통신 분야의 Azure OpenAI + Azure Databricks + 레이크하우스 기반 에이전틱 AI를 논의.
- Azure Storage의 새로운 기능(11월 18일 오후 3:00) — David Meyer(Databricks)와 Microsoft가 ADLS와 OneLake의 AI-ready 데이터 기반을 소개.
- Agent 365로 엔터프라이즈 규모의 AI 에이전트를 관리·보안(11월 18일 오후 4:15) — 에이전트를 위한 컨트롤 플레인: 가시성, 내장 거버넌스, 엔터프라이즈급 보안.
- Azure Databricks, Foundry, Fabric, Copilot으로 AI를 구동(11월 19일 오전 10:15) — David Meyer와 Anavi Nahar(Microsoft)가 OneLake, Foundry, Copilot Studio, Power BI, Teams, M365 연동을 소개.
- 기타: Databricks + AMD + Replit 고객 리셉션(11월 17일 오후 6:00–8:00, Mariposa); 11월 17–18일 Databricks 임원의 비공개 미팅(Ignite 패스 불필요).

## 상세

- 행사 안내: Moscone Center; 부스 #5271R(The Hub, 11월 17–19일); Canopy Hotel 소셜 및 임원 미팅 11월 17–18일; 세션은 비즈니스 리더, 데이터 실무자, IT 리더, 개발자를 아우른다.
- 라인업은 거버넌스 AI를 강조한다. Genie, Copilot Cowork, Microsoft 365 경험의 기저에 Unity Catalog 거버넌스가 있으며, 규제 워크로드를 위한 정부 클라우드 및 FedRAMP 트랙 제공도 포함된다.
- 인접 주제의 Microsoft 주도 세션(Observability, Work IQ, Cobalt 200, 지하 데이터 등)도 일정 계획에 참고할 수 있도록 함께 안내된다.
