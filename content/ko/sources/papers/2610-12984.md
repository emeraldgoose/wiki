# Work2Skill: 재사용 가능한 에이전트 스킬 유도를 위한 인간 GUI 경험 포착

**Source**: Huang et al., arXiv, 2026-10-09

**핵심**: 컴퓨터 사용 에이전트는 정형 GUI 작업은 처리하지만, 절차가 인간 조작자의 머릿속에만 있는 낯선 소프트웨어에는 실패한다. Work2Skill은 화면·입력·접근성 트리 증거를 동기화해 인간 시연을 수집하고(WorkRecorder), 350개 에피소드 데이터셋(WorkDemo-350)으로 정리한 뒤, 도구 사용 에이전트가 각 에피소드를 재사용 가능한 스킬 파일로 만든다. 4개 실행 모델 모두에서 무스킬·기존 시연-텍스트 기준선을 능가한다.

## 배경

인간과 컴퓨터 사용 에이전트는 같은 GUI 상호작용 공간을 공유하므로, 시연은 절차 지식의 자연스러운 원천이다. 기존 연구는 시연을 지침·튜토리얼·스킬로 바꾸고, 벤더도 "스킬 기록" 기능을 내놓고 있다. 세 가지 간극이 남는다: 액션 좌표는 클릭 위치만 알려줄 뿐 컨트롤 의미를 알려주지 않는다; 연구마다 시연·하네스가 달라 유도 방법의 공정 비교가 불가하다; 고정 파이프라인은 정해진 탐색 순서를 강제해 불분명한 단계를 필요시 재방문하지 못한다.

## Work2Skill 프레임워크

**WorkRecorder** — 수집 인프라. 화면 녹화, 키프레임 이미지, 마우스/키보드 이벤트, 접근성 트리(AX) 스냅샷을 공통 타임라인에 기록하고, 이벤트를 액션(클릭, 드래그, 단축키)으로 묶어 키프레임·비디오 시점과 연결한다. 포인터 위치·타이밍·AT-SPI 조회로 목표 요소 연결을 수행해 클릭에 명시적 컨트롤 의미(이름, 역할, 경계)를 부여한다 — 좌표만이 아니다.

**WorkDemo-350** — 공유 증거 자원. 350개 검수 완료 인간 시연: MyPCBench Bounded Action 64 작업 + OSWorld-Verified 부분집합 286 작업, 총 약 8.48시간(에피소드당 평균 MyPCBench ~119초, OSWorld ~80초, 증거 이미지 각 ~24장). 모든 에피소드는 완전성과 작업 성공 검수를 통과했다.

**에이전트형 스킬 유도** — NexAU 도구 사용 에이전트가 증거를 필요시 탐색(타임스탬프 라벨 파일/이미지/비디오 도구)하면서 초안을 쓰는 과정을 반복하고, 스킬-크리에이터 정책에 따라 시연 고유 입력을 작업 의존 서술로 일반화하되 워크플로 규칙·단계 의존성·완료 검사를 유지한다. 출력은 역량당 `SKILL.md` 하나(Agent Skills 관례)이며, `finalize_extraction` 구조 검사를 거친다. 유도 중 스킬을 실행하지 않으므로, 하류 결과는 진정한 재사용을 측정한다.

## 실험

**설정**: 양 벤치마크 공식 작업 평가자; 스킬은 실행자 프롬프트 끝에 구분된 `<task_skills>` 블록으로 삽입해 모든 방법에 동일 적용. 실행자: GPT-5.5, Opus-4.8, Qwen3.5-35B-A3B, Qwen3.5-9B. 기준선: 무스킬, ShowUI-Aloha(액션 의미), Demo2Tutorial(튜토리얼 텍스트) — 동일 텍스트 가이던스 인터페이스와 동일 원천 에피소드로 맞춤 적용.

**벤치마크**: MyPCBench Bounded Action(64 작업), OSWorld-Verified 부분집합(286 작업), 일반화용 MyPCBench Jitter(요구사항 변경 변형 64개), 모델 전이용 GPT-5.5/Qwen3.5-9B 교차 조합.

**결과**(평균 점수 0–100; 성공률 = 만점 %):

| 설정 | 무스킬 대비 이득 | 더 강한 시연 기준선 대비 |
|---------|-------------------|---------------------------|
| MyPCBench (RQ1) | +4.67–10.54점, +6.25–25.00%p 성공률 | +3.95–7.79점 |
| OSWorld-Verified (RQ1) | +3.11–7.50점, +1.40–7.69%p 성공률 | +1.65–6.96점 |
| MyPCBench Jitter (RQ2, 재사용) | +3.93–8.64점, +6.25–9.38%p 성공률 | +4.28–6.25점 |

주요 지점: MyPCBench에서 GPT-5.5 성공률 48.44% vs. 양 기준선 37.50%; 유도/실행 모델 교차해도 스킬 전이(모든 조합이 무스킬 상회, GPT-5.5 유도 스킬 최선); 증거 절제 연구에서 전 모달리티 증거가 중요. 유도 토큰 비용은 모델 의존적이고 기준선보다 일관되게 싸지 않다 — 승리는 비용이 아니라 품질이다.

## 소프트웨어 엔지니어를 위한 시사점

- **재사용 절차 아티팩트**: `SKILL.md` 파일은 버전 관리되는 plain 마크다운 — 단일 에이전트 실행을 넘어 리뷰·diff 가능한 절차 지식.
- **하네스 비의존 주입**: 파이프라인 변경 없이 시스템 프롬프트에 스킬 텍스트를 덧붙이는 방식이라 동일 스킬이 실행자 간 호환 — 다중 모델 에이전트 스택의 실용 패턴.
- **증거 도구 패턴**: 타임스탬프 라벨의 필요시 탐색(성긴 비디오 스캔 후 모호한 액션 확대)은 전체 녹화를 컨텍스트에 넣지 않는다 — 모든 트레이스 분석 에이전트에 적용 가능.
- **평가 규율**: 공유 에피소드 + 공유 실행자 + 공식 평가자는 에이전트 개선 방법의 공정 비교 틀; Jitter 변형 아이디어(같은 앱, 바뀐 개체/제약)는 저렴한 재사용 테스트로 차용할 가치.
