# 프린키피아: 비디오 모델을 위한 관계형 물리 테스트

출처: Varun Varma Thozhiyoor 외 3인, arXiv:2609.04200, 2026-09-03. 프로젝트 페이지 principiabench.github.io.

**핵심 요약**: 생성 비디오의 물리 리얼리즘 판단은 어렵습니다. 절대 운동 측정이 프레임레이트·물체 크기·카메라 캘리브레이션에 의존하는데 생성 클립에는 다 모호하거나 없기 때문입니다. **프린키피아**는 캘리브레이션을 아예 우회합니다. 한 장면의 두 물체가 같은 법칙을 따르면 그 운동은 **캘리브레이션과 무관하게 예측 가능한 관계**를 만족해야 합니다. 이 관계 일관성으로 뉴턴 물리를 테스트하며, 통제 프로토콜 실세계 장면의 **8개 현상**(중력·반발·마찰·회전관성·포물선·운동량·진자·질량-용수철 진동)을 답니다. 결과: **6개 SOTA 비디오 생성 모델 수천 생성이 전부 0.42 이하**(VBench는 다 ~0.8) — 위반 탐지 VLM 최고도 **정확도 67%**, 대다수는 chance 수준입니다.

## 관계형 트릭

핵심 도구는 이미지 공간에서 직접 계산하는 **캘리브레이션 독립 일관성 점수**입니다. "이 공이 9.8 m/s²로 떨어지나"(스케일·프레임레이트 없이 답 불가) 대신 "이 두 낙하 물체가 중력이 요구하는 관계를 만족하나"를 묻습니다. 한 장면을 공유하는 짝 물체가 미지수를 소거해, ill-posed 절대 측정을 well-posed 상대 문제로 바꿉니다. 병진·회전·충돌·진동 동역학을 아릅니다.

## 격차가 말하는 것

| 신호 | 점수 |
|---|---|
| 프린키피아 최고 생성 모델 | ≤ 0.42 |
| 같은 모델 VBench | ~0.8 |
| 위반 탐지 최고 VLM | 67% |

시각 품질(VBench)과 물리 정확도는 거의 직교합니다. 현 생성기는 아름답게 틀린 물리를 렌더링하고, 현 VLM은 대개 구분도 못 합니다. 로보틱스·시뮬레이션·embodied 훈련용 비디오 모델 선정에 VBench식 점수만으로는 부족합니다.

## 주의할 점

이 글은 초록 기반입니다(전문 HTML 미검증). 일관성 점수 식·현상별 분해·6개 모델 정체는 PDF 확인이 필요합니다. 통제된 8개 현상이 실세계 물리 전체를 커버하지 못하고, 상관된 방식으로 함께 틀린 모델은 관계 테스트를 통과할 수 있습니다.

## SW 엔지니어와의 관련성

- 생성 비디오가 하류 시스템(sim-to-real, 합성 훈련 데이터)에 들어가면 물리 일관성 게이트를 추가하세요. 지각 품질 지표는 위반을 못 잡습니다.
- 관계형 테스트 패턴은 일반화됩니다. 절대 정답이 없을 때, 어떤 캘리브레이션에서도 성립해야 하는 **공동 관측 개체 간 관계**를 테스트하세요.
- 0.42 대 0.8 격차는 선정 기준 경고입니다. 벤치마크를 실제 필요한 속성(예쁨이 아니라 물리)에 맞추세요.
- VLM 탐지 최고 67%는 자동 위반 필터링이 아직 안 된다는 뜻입니다. 인간이나 규칙 검사를 루프에 두세요.
