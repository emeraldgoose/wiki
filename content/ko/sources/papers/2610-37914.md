# Muon Makes the First Mixture-of-Experts Layer Harder to Balance: Muon이 첫 MoE 레이어의 균형을 어렵게 한다

**원문**: [arXiv:2610.37914](https://arxiv.org/abs/2610.37914) · **게시일**: 2026-10-27
**저자**: Marcos Hernanz

## 개요

많은 open MoE 언어 모델은 AdamW 대신 Muon으로 training 하고 expert-routing bias로 load balance한다. recipes는 Muon이 router도 train해야 할지 disagree한다. 이 연구는 55M과 108M active parameters models에서 optimizer가 bias span (largest minus smallest per layer)에 어떤 변화를 주는지 measure한다. span은 all tokens가 same experts를 favor할 때 커지므로 layer balancing difficulty를 보여준다. shorter-run tuned learning rates에서 Muon은 every seed에서 first MoE layer의 span을 증가시키고 average roughly double화했다. other layers는 much less change했다. rise는 whichever optimizer trained router와 무관, network rest에 대한 Muon에서 나왔다. affected runs에서 first router inputs는 shared direction였고 warmup 직후 busiest expert가 fair share의 네에서 일곱 배를 처리했다. first 3,000 steps에서 batch mean을 subtract하면 loss barely change하면서 overload가 remove되었다. smaller model에서 Muon learning rate halving은 most rise를 remove하고 loss slightly improve했다.

## 핵심 내용

- bias span은 layer balancing difficulty를 나타낸다.
- Muon은 first layer bias span을 notable하게 증가시킨다.
- observed effect는 router之外 network에 대한 Muon에서 온다.
- first-router inputs는 affected runs에서 direction을 공유한다.
- batch mean centering inputs는 loss 변화 거의 없이 overload를 제거한다.
- Muon learning rate 절반 감소는 much rise를 alleviate한다.

## 상세

55M-108M active parameters scale에서 two scales와 multiple seeds, Muon과 AdamW router trade-off가 eval되었으며 study는 this scale에서 router keeping Muon을 somewhat favor한다. result는 short-run-tuned learning rates와 routing bias负载 balancing에 한정되며, larger sparser MoE에서 generalization은 별도 test 필요하다.
