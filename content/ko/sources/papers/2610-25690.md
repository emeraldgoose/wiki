# ScaleNav: 언어 조건 로컬 내비게이션을 위한 확장형 인터넷 비디오 사전 학습

**Source**: [huggingface](https://arxiv.org/abs/2610.25690) · Yang et al., 2026년 10월 19일 · arXiv:2610.25690
**Date**: 2026-10-19

**Lead**: 본 논문은 공개 인터넷 에고센트릭 비디오로부터 학습한 시각 역학을 로봇 내비게이션에 적용하는 ScaleNav 프레임워크를 제안한다. 세 단계 학습(비디오 사전 학습 → 행동 정렬 → 통합 미세 조정)을 통해 HabitatGS-LN에서 94.9%, Short-Horizon OVON에서 86.5%의 성공률을 달성한다. 실제 로봇 데이터 수집 비용과 시뮬레이션-실세계 간 격차를 해결하기 위해 다양한 실제 세계 장면의 내비게이션 경험을 활용한다.

## 개요

언어 조건 로컬 내비게이션은 로봇이 자연어로 설명된 보이는 대상을 찾아 이동하고 정확한 위치에서 멈추는 능력을 요구한다. 기존 정책은 실제 로봇 데이터 수집이 비용이 많이 들고 시뮬레이션 환경의 실세계 간 격차가 존재한다는 한계가 있다. ScaleNav은 인터넷 에고센트릭 비디오를 학습 소스로 사용해 목표 지향 시각 역학을 학습하고 이를 로봇 행동 생성에 적용한다.

## 세 단계 학습

1단계는 인터넷 에고센트릭 비디오에 대한 명령 조건 비디오 사전 학습으로, 카메라가 명령된 대상에 접근할 때 관찰이 어떻게 변화하는지 다양한 장면에서 학습한다. 2단계는 시뮬레이션 데이터의 행동 레이블을 사용한 행동 정렬로, 실행 가능한 행동 청크를 예측하도록 모델을 학습한다. 3단계는 모든 학습 가능한 구성 요소를 함께 최적화하는 통합 미세 조정이다. 전체 모델은 HabitatGS-LN에서 94.9% 성공률(SR)과 86.1% SPL을 달성하며, 비디오 사전 학습이 없으면 90.4%로 떨어진다.

## 주요 결과

- 전체 ScaleNav: HabitatGS-LN 94.9% SR / 86.1% SPL, Short-Horizon OVON 86.5% SR.
- 비디오 사전 학습 제외: 90.4% SR (인터넷 비디오 데이터의 가치 확인).
- 행동 정렬 제외: 93.6% SR / 85.1% SPL (정렬이 약 1.3점 기여).
- 비디오 재생 제외: 94.3% SR / 84.2% SPL (재생이 SPL 1.9점 향상).
- 별도 사전 학습 없이 함께 학습: 90.4% SR / 83.1% SPL — 세 단계 분리가 핵심.

## 주의사항

본 요약은 원본 논문의 요약 및 구조를 기반으로 작성되었으며, 전체 데이터셋 세부 정보와 지연 시간 측정은 원문을 참고해야 한다. 인터넷 에고센트릭 비디오의 다양성과 품질이 결과를 좌우하므로, 모든 내비게이션 도메인을 포괄하지 않을 수 있다.

## SW 엔지니어 관련성

- 비구조적 공개 비디오(인터넷 에고센트릭)로부터 사전 학습하는 방식은 레이블이 제한된 모든 도메인에서 확장 가능한 패턴이다.
- 사전 학습 → 정렬 → 통합 조정의 세 단계 분리는 비용 구조가 다른 데이터 소스를 결합할 때 채택할 가치가 있다.
- 86.5% / 94.9% 벤치마크는 내비게이션 에이전트 평가의 구체적 목표로 활용할 수 있다.
