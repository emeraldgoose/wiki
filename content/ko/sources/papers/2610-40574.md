# Every Token Needs Its Own Teacher: 다중 교사 적응형 온정책 자기증류

**원문**: [arXiv:2610.40574](https://arxiv.org/abs/2610.40574) · **게시일**: 2026-10-29
**저자**: Yifu Luo, Chuang Ma, Zeyu Chen, Enkelejda Kasneci, Qi Chen, Gjergji Kasneci

## 개요

온정책 자기증류는 권한 있는 준거 정보에 조건화된 교사를 구성해, 대형 언어 모델의 사후 학습에 효과적이다. 기존 접근은 학습 전체에 걸쳐 교사를 고정하거나, 각 응답 안에서는 부분 참고 정보 노출을 응답 단위로만 조절한다. 논문은 이러한 방식이 충분하지 않다고 주장한다.

핵심 통찰은 같은 응답 안에서도 토큰마다 선호하는 교사가 달라질 수 있다는 점이다. 교사 개입 예비 실험은 토큰마다 교사 선호가 다르며, 다수결 투표와 KL 기반 선택을 통해 각 토큰에 선호 교사를 식별할 수 있음을 보여준다.

이러한 결과에 영감 받아, 논문은 MTA-OPSD(Multi-teacher Adaptive On-policy Self-Distillation)를 제안한다. 여러 후보 교사로 구성된 다중 교사 풀을 만들고, 학습 중 각 토큰이 선호 교사를 적응적으로 선택하게 한다. 수학 추론 과제에서 Qwen3 모델을 대상으로 한 실험에서 MTA-OPSD는 기존 온정책 자기증류 방법을 지속적으로 상회하며, 기본 모델 대비 평균 +5.9까지의 향상을 보였다.

## 핵심 내용

- 기존 온정책 자기증류는 교사를 전역적으로 고정하거나, 응답 단위로만 노출을 조절해 한계가 있다.
- 같은 응답 안에서도 토큰마다 선호하는 교사가 달라진다.
- 다수결 투표와 KL 기반 선택으로 각 토큰의 선호 교사를 식별할 수 있다.
- MTA-OPSD는 다중 교사 풀에서 토큰 단위로 교사를 선택한다.
- Qwen3 모델의 수학 추론 실험에서 prior 방식을 꾸준히 상회했다.
- 코드가 공개되었다.

## 상세

제안 방법은 Qwen3 모델과 수학 추론 과제에서 기존 온정책 자기증류 접근과 비교되어, 일관된 향상을 보였다. 기여의 중심은 교사 감독을 고정 또는 응답 수준에서 토큰 수준 적응으로 옮기면서, 후보 교사 풀을 유지하는 데 있다. 재현을 위한 코드가 공개되었다.
