# MeMo: 메모리를 모델로

## 개요

MeMo(Memory as a Model)는 대형 언어 모델(LLM)의 파라미터는 그대로 유지한 채, 새로운 지식을 전용 메모리 모델로 인코딩하는 모듈형 프레임워크입니다. 이 접근법은 비싼 재학습 없이 최신 및 도메인별 정보를 효율적으로 통합할 수 있게 하여 정적 LLM 지식의 근본적인 한계를 해결합니다.

## 주요 장점

MeMo는 기존 지식 통합 방법에 비해 여러 중요한 장점을 제공합니다:

1. **문서 간 관계 캡처**: 여러 문서에 걸쳐 있는 복잡한 관계를 효과적으로 처리
2. **검색 노이즈에 대한 강건성**: 검색 시스템이 불완전하거나 노이즈가 있는 결과를 반환하더라도 성능 유지
3. **재앙적 망각 방지**: 메모리 모델만 업데이트되므로 원래 LLM의 사전 학습 지식 보존
4. **플러그 앤 플레이 호환성**: 가중치나 로짓에 대한 접근 없이 오픈소스 및 폐쇄형 소스 LLM 모두와 작동
5. **코퍼스 크기 독립 검색**: 메모리 모델이 고정 크기를 가지므로 추론 비용이 코퍼스 크기와 무관

## 기술적 접근법

MeMo는 두 가지 주요 구성 요소로 이루어집니다:

### 메모리 모델 학습
- 고정된 생성기(Generator) 모델이 대상 코퍼스를 반사 QA 데이터셋으로 변환
- 과정에는: 사실 추출, 통합, 검증, 엔티티 표면화, 문서 간 합성 포함
- 결과 데이터셋으로 전용 메모리 모델 학습

### 추론 파이프라인
- 고정된 실행기(Executive) 모델이 복잡한 사용자 쿼리에 답변
- 구조화된 다중 턴 프로토콜 사용:
  1. 입력을 더 간단하고 목표 지향적인 하위 쿼리로 분해
  2. 메모리 모델에서 중간 응답 검색
  3. 검색된 정보를 추론하여 최종 답변 생성

## 실험 결과

MeMo는 세 가지 벤치마크에서 평가되었습니다:
- **BrowseComp-Plus**: 복잡한 질의응답에서 강력한 성능 demon시
- **NarrativeQA**: 서사 이해 및 질의응답에서 효과성 입증
- **MuSiQue**: 다중 홉 질의응답 작업에서 경쟁력 있는 결과 달성

결과는 다양한 설정에서 기존 방법에 비해 MeMo가 강력한 성능을 달성하여 모듈형 메모리 접근법의 효과성을 검증합니다.

## 기존 방법과의 비교

MeMo는 세 가지 기존 패러다임의 강점을 결합하면서 각자의 한계를 완화합니다:

1. **비파라메트릭 방법**: 변경되지 않은 선진 모델을 활용
2. **파라메트릭 방법**: 재앙적 망각 없이 모델 파라미터에 지식 내부화
3. **잠재 메모리 방법**: 더 나은 이식성을 가진 간결하고 쿼리 가능한 메모리 아티팩트 제공

## 의의

MeMo는 LLM 지식 통합의 중요한 진전을 나타내며, 사전 학습된 모델의 이점을 유지하면서 최신 또는 도메인별 지식이 필요한 응용 프로그램에 실용적 해결책을 제공합니다. 모듈형 설계는 지식의 신선함과 계산 효율성이 중요한 실제 응용 프로그램에 특히 적합합니다.
