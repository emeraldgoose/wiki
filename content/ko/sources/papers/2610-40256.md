# 요구사항이 상호작용할 때: 상호 의존적 specification으로 장기 코딩 확장하기

**원문**: [arXiv:2610.40256](https://arxiv.org/abs/2610.40256) · **게시일**: 2026-10-27
**저자**: Yishuo Cai, Minzheng Wang, Liang Zhao, Linghao Zhang, Lei Li, Shicheng Li, Xu Sun, Fuli Luo

## 개요

실제 software change는 interface compatibility, error handling 등 다중 requirement를 만족해야 하며 기존 dependency를 깨뜨리지 않아야 한다. 기존 coding-agent benchmark는 specification 수와 다양성이 부족하고, complex constraint보다 primary goal을 강조하는 경우가 많다. 논문은 specification design이 독립 checklist item을 쌓는 방식이 아니라 requirement를 interdependent specification으로 조직해야 한다고 주장한다.

CodeSpecWeave는 풍부하고 상호 의존적인 specification을 가진 coding task를 합성하는 framework다. 실제 developer가 도출한 specification seed에 grounding된 synthesis agent가 repository context를 탐색하고 task requirement와 executable test suite를 iterative하게 함께 개발한다. 개별 implementation choice가 서로 영향을 주는 coupled constraint를 의도적으로 만든다.

## 핵심 내용

- coding agent는 multi-dimensional, interacting specification을 처리해야 한다.
- 기존 task data는 specification quantity와 diversity가 부족하다.
- 독립 requirement를 단순히 더하면 task가 trivial checklist가 될 수 있다.
- CodeSpecWeave는 interdependent specification과 reliable verifier를 함께 구축한다.
- 강화학습용 2,865개 repository에 걸친 4,670개 training task를 생성한다.
- CodeSpecWeave-Bench는 1,044개 specification을 포함한 100개 task로 구성된다.
- 평가 결과는 interdependent requirement 하에서 notable gap과 남은 headroom을 드러낸다.

## 상세

task는 repository, natural-language request, set of embedded specifications, execution environment로 표현된다. synthesis agent는 repository context를 탐색하고 requirement와 test를 iterative하게 개발하여 constraint가 implementation 과정에서 coupled되도록 한다. 목표는 isolated edit이 아니라 holistic exploration과 joint reasoning을 agent에게 강제하는 것이다.

benchmark는 realistic, interdependent requirement 아래에서 leading coding agent를 평가하고 long-horizon coding을 위한 scalable training data를 제공하는 것을 목표로 한다. 실험에서는 DeepSWE-v1.1에서 strong training baseline 대비 substantial gain을 보고한다.
