# TPPO: 언어 모델 추론을 위한 추적 가치 PPO

출처: Futing Wang 외 8인, arXiv:2610.16794, 2026-10-12.

**핵심 요약**: PPO는 검증 가능한 보상 기반 언어 모델 추론에서 널리 쓰입니다. 궤적을 따라가는 **가치 변화**가 토큰 수준 상대 신용을 특징짓지만, 표준 크리틱은 희소한 종료 보상 아래에서 이를 잘 추적하지 못합니다. **TPPO**(Tracking-Value PPO)는 연속 프리픽스 가치 사이의 관계를 분석해 이 변화를 모델링합니다.

## 가산 구조

연속 프리픽스 가치는 로그 오즈 공간에서 **가산 업데이트를 갖는 베이지안 분해**로 표현됩니다. TPPO는 이 구조를 이용해 위치별 스칼라 출력을 합산해 가치 로짓을 만드는 누적 가치 매개변수화를 씁니다. 이 출력은 재구성된 가치에 대한 종료 결과 감독으로 학습됩니다. 결과적으로 크리틱이 궤적 전체의 가치 진화를 더 일관되게 추적하고, 이점 추정이 안정됩니다.

## 결과

Qwen3-4B-Base와 Qwen3-8B-Base에서 PPO 대비 수학 추론 종합 점수를 각각 **7.0·8.4점** 올렸고 분포 밖 일반화도 개선했습니다. 이득은 Qwen3-4B, Qwen2.5-Math-1.5B, Qwen3.5-9B와 카운트다운·과학 코딩 과제로도 이어졌습니다. 분석에서 가치 진화 추적과 이점 추정이 더 정확해진 것을 확인했습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 가치 분해는 보상이 종료 시점에 주어지는 설정을 전제하므로, 중간 보상이 많거나 에피소드가 매우 긴 환경에서의 거동은 별도 확인이 필요합니다. 하이퍼파라미터 민감도와 PPO 외 기준선 비교도 원문을 보세요.

## SW 엔지니어와의 관련성

- 추론 모델 RL에서 이점 분산이 크다면 크리틱의 가치 매개변수화부터 점검하세요. TPPO의 누적 가치 방식은 구현 부담이 작은 대안입니다.
- 종료 보상만 있는 태스크(테스트 통과, 정답 일치)에서 토큰 수준 신용을 얻는 데 적합합니다.
- 수학 외 도메인으로 옮길 때는 보상 희소성과 궤적 길이 분포를 먼저 확인하세요.
