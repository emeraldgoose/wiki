# 코딩 에이전트 학습용으로 좋은 데이터란 무엇인가? SWE-Gym에 대한 체계적 연구

**원문**: [arXiv:2611.30207](https://arxiv.org/abs/2611.30207) · **게시일**: 2026-11-23 (v1)
**저자**: Yikai Zhang, Mai Xu, Yunbei Zhang, Qirui Jin, Kenan Li, Yuwen Jia, Jinwei Yao, Xiangyu Zhang, Jielun Tan, Jin Pan, Zijian Jin, Xiao Sun

## 개요

강화학습은 숨겨진 테스트가 보상을 결정하는 소프트웨어 작업으로 코딩 에이전트를 학습시키지만, 기존 작업 컬렉션은 보통 참조 수정(reference fix)에 대해서만 테스트를 검증합니다. 이 논문은 보상 레이블의 정확성에 초점을 맞추어 어떤 작업이 좋은 학습 데이터가 되는지 묻고, 두 LLM 계열로 의심되는 테스트 오류를 실행하여 SWE-Gym을 감사합니다. 핵심 발견은 '풀지 못한' 것이 종종 '잘못 레이블된' 것임을 의미한다는 점입니다. 9B 베이스 모델이 전혀 풀지 못하는 작업의 74%가 올바른 수정을 거부하는 테스트(위음성, false negative)를 하나 이상 포함하는 반면, 때때로 푸는 작업에서는 20%에 불과합니다. 패스율은 작업이 보상을 내는지 여부만 보여줄 뿐, 그 보상이 올바른지 여부는 보여주지 못합니다.

저자들은 결함이 있는 작업을 수정하거나 제거하여 SWE-Gym-Verified를 구축합니다. 모든 단언(assertion)을 판정하고refferen witnesses를 실행하여 위음성을 확인하고, 잘못 통과하는 패치를 반례(counterexample)로 확인한 뒤 테스트를 강화합니다(위양성). 단언을 판정한 2,001개 작업 중 1,091개(55%)가 위음성 판정을 받았으며, 이 경향은 두 계열 모두의 확인(68% vs 13%)과 인간 레이블(61% vs 21%)에서도 유지됩니다. 동일한 크기와 매칭된 난이도에서 학습한 결과(Clean과 Orig는 베이스 모델 패스율 약 49%로 일치), 감사된 작업으로 학습한 정책이 SWE-bench Verified에서 +2.4, SWE-bench Pro에서 +2.7 높은 점수를 세 개의 시드에서 기록한 반면, 풀지 못한 작업을 단순히 버리면(Orig+Filter) 그러한 향상이 없습니다. 위양성은 Clean 작업의 고유한 통과 패치 중 26.1%를 차지하고(추가로 37.3%는 판정 불가), 그중 4분의 1을 잡는 테스트를 추가해도 held-out pass@1은 감지 가능한 변화가 없습니다.

## 핵심 내용

- 전혀 풀지 못한 SWE-Gym 작업의 74%가 위음성 결함(테스트가 올바른 수정을 거부)을 가지며, 이는 때때로 푸는 작업의 20%와 대비됩니다. 판정된 작업 전체에서는 55%가 위음성 판정을 받았습니다.
- SWE-Gym-Verified는 실행 증거가 포함된 1,087개 감사 작업, 학습セット, 전체 감사 파이프라인을 공개합니다.
- 감사된(Clean) 학습 데이터는 동일한 크기/난이도에서 Orig보다 SWE-bench Verified +2.4, SWE-bench Pro +2.7 pass@1 우위를 보이며, 풀지 못한 작업을 버리기만 해서는 향상이 없습니다.
- 위양성은 Clean 작업 통과 패치의 26.1%이며(모든 패스 횟수에서 19~36%), 이들을 잡도록 테스트를 강화해도 held-out pass@1은 변하지 않습니다.
- 전혀 풀지 못한 위음성 작업은 Orig 그룹의 11.1%를 차지하지만 기울기가 전달되는 그룹은 0.9%에 불과해 대부분 보상 0을 받고 연산을 낭비합니다.
- 수정 시에는 해법을 누설하지 않고 누락된 요구사항을 명시하는 Requirements 블록을 추가하며, 두 개의 프런티어 모델이 누설이 없다고 판정하고 작업이 감사를 다시 통과한 경우에만 수용됩니다(588회 시도 중 184회).

## 상세

방법(3~4장): 수정은 fail-to-pass(F2P) 테스트를 통과하면서 pass-to-pass(P2P) 테스트를 깨지 않아야 하며, 모든 합리적 패치를 거부하는 테스트가 있는 작업은 모든 샘플에 보상 0을 줍니다. 위음성은 두 LLM 계열의 실행 witness로 확인되고(810개 확인 판정에서 두 계열이 같은 테스트에서 실패), 위양성은 반례로 확인한 뒤 골드 패치와 위양성이 아닌 모든 패치에서 통과하는 테스트만 유지하는 방식으로 강화합니다(143개 작업의 493개 테스트). 실험(5장): 3개 시드에 걸쳐 80 스텝 × 16 작업 × 8 샘플의 GRPO 실행, 학습 저장소와 겹치지 않는 held-out Verified-397 및 SWE-bench Pro로 평가, 100개 작업 개발 분할로 체크포인트를 선정. RQ2는 3,840개 8샘플 그룹을 통해 레이블 오류가 학습 신호에 도달하는 방식을 추적하고, RQ4는 강화가 점수에 영향이 없음을 보입니다. 공개(부록 A)에는 감사 작업, 판정 증거, 학습セット, 파이프라인 코드가 포함됩니다.
