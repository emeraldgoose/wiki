# 프롬프트 적응형 비용 인식 LLM 추론을 위한 앙상블 라우팅

**원문**: [arXiv:2611.10193](https://arxiv.org/abs/2611.10193) · **게시일**: 2026-11-06
**저자**: Saul Urso, Emanuele Carlini, Patrizio Dazzi, Matteo Mordacchini

## 개요

LLM 기반 웹 서비스는 요청마다 성격이 달라 응답 품질과 추론 비용의 균형을 맞춰야 한다. 비싼 모델을 무분별하게 쓰면 자원이 낭비되고, 늘 싼 모델만 고르면 품질이 무너지며, 비용 선호는 사용자마다 다르다. 기존 라우팅은 프롬프트마다 모델 하나만 고르므로 여러 LLM의 상호 보완적 능력을 활용할 수 없고, 고정 앙상블은 여러 모델을 결합하더라도 구성과 개수가 고정되어 프롬프트별로 비용을 조절할 수 없다. 저자들은 이를 앙상블 라우팅 문제로 정식화한다. 프롬프트마다 어떤 모델을 몇 개 호출할지 동시에 정하는 것이다.

PISA는 단일 모델 선택을 위해 각 후보 모델이 주어진 프롬프트를 올바르게 답할 확률을 추정한다. 프롬프트 임베딩을 X-means로 분할한 뒤, 쿼리를 학습된 중심점들에 대한 소프트 멤버십(코사인 거리에 대한 소프트맥스, 집중도는 온도 매개변수가 조절)으로 표현해 하나의 군집에만 의존하지 않고 주변 여러 영역의 정보를 활용한다. 모델별로 독립적인 L2 정규화 로지스틱 예측기가 과거 정답 레이블에서 이 멤버십을 능력 추정치로 바꾸고, 비용 항은 학습셋 평균 비용을 정규화한 값이다. 라우터는 예측 품질과 비용을 α로 섞은 효용을 최대화하는 모델을 고르며, α는 운영자가 요청 단위로 추론 시점에 정할 수 있다.

PISA-E는 바로 이 모델별 추정치를 재사용해 앙상블 전용 예측기 없이 앙상블을 고른다. 후보 부분집합은 "과반수 멤버가 정답을 낼 확률"로 점수를 매기는데, 조건부 독립 가정 아래 포아송-이항 동적 계획법으로 정확히 계산되는 다루기 쉬운 대리 지표다. 여기에 멤버 비용 합을 더해 비용을 반영한다. 이 대리 지표 아에서는 짝수 개 앙상블이 항상 홀수 개 부분집합(하나를 빼면 과반 기준도 비용도 내려간다)에 밀리므로, 후보는 효용 순위의 접두사 중 홀수 크기(최대 11개)로 한정된다. 선정된 모델들은 병렬로 호출되고, 셀프 가중 BERTScore(예측 신뢰도로 응답별 기여를 가중하는 최소 베이즈 리스크(MBR) 디코딩 변형)로 응답을 합친다.

분포 내(ID)·분포 외(OOD) 네 라우팅 벤치마크에서 PISA는 평가된 단일 모델 라우터 중 최고 매크로 평균 비용–성능 하이퍼볼륨을, PISA-E는 평가된 앙상블 기법 중 최고 매크로 평균 과업 성능을 기록했다. 품질 우선 조건에서 PISA-E는 가장 강한 경쟁 기법을 각각 2.09·2.87%p 앞섰고, 낮은 비용 구간에서도 경쟁 기법의 성능을 넘어서면서 평균 추론 비용을 약 36%·25% 줄였다.

## 핵심 내용

- 능력 추정 설계: X-means가 군집 개수와 중심점을 함께 정하고, L2 정규화된 임베딩·중심점에 대해 온도 β로 집중도가 조절되는 코사인 거리 소프트맥스가 멤버십을 준다. 모델별 로지스틱 예측기는 평가 점수를 0.5에서 임계 처리한 이진 정답 레이블로 학습된다.
- 예측기 정규화 강도는 모델마다 5-폴드 교차검증으로 로그 손실을 최소화하는 값을 고른다. 후보는 1e-4부터 1e4까지 로그 간격 10개이며, 선택된 예측기는 전체 학습셋으로 재적합된다.
- 라우팅 목적식: α·예측 능력 + (1−α)·(1−정규화 비용)을 최대화하는 모델 선택. α는 비용–품질 선호로, 재학습 없이 추론 시점에 조정할 수 있다.
- 앙상블 성공 대리 지표: PISA 능력 추정치를 성공 확률로 하는 모델별 베르누이 변수의 과반 정답 확률. 포아송-이항 동적 계획법으로 정확히 계산하므로 앙상블 전용 학습도, 선정 전 응답 생성도 필요 없다.
- 앙상블 비용은 멤버 평균 비용의 합을 k_max개 최대 평균 비용의 합으로 나눠 정규화한다. 이 덕분에 크기가 다른 부분집합을 하나의 선호 매개변수 아래 비교할 수 있다.
- 탐욕적 후보 구성: 모델을 단일 모델 효용으로 순위 매기고, 그 순위의 접두사 중 홀수 크기(k_max = 11까지)만 후보로 삼는다. 대리 지표 아에서 짝수 부분집합은 홀수 부분집합에 지배되므로 홀수만 고려해도 최적해를 잃지 않는다.
- 응답 결합: 셀프 가중 BERTScore. 각 후보 응답을 나머지 멤버 응답과의 BERTScore 유사도로 점수 매기되, 가중치는 정규화된 능력 추정치다(능력 인식 MBR 디코딩).
- 평가 설정: LLMRouterBench Track-2, RouterBench, FusionBench, SPROUT 벤치마크, 5개 시드. ID는 70% 개발/30% 시험(개발을 다시 80/20) 분할, OOD는 ID 과업군으로만 학습해 홀드아웃 과업군에서 평가하며 라우터는 따로 적합한다. 프롬프트 임베딩은 Qwen3-Embedding-8B.
- 단일 모델 결과(정규화 하이퍼볼륨 ×100): PISA 매크로 평균 ID 37.41(EmbedLLM-MF 35.78, Avengers-Pro 35.44, KNN 34.38), OOD 22.85(각 21.33, 17.06, 20.02). 8개 벤치마크–설정 조합 중 6개에서 1위이며 RouterBench ID 46.15, FusionBench ID 42.57를 포함한다.
- 앙상블 결과: DFPE, LLM-TOPLA, SelectLLM, PairRanker(사전학습/미세조정), BERTScore-MBR 가운데 최고 매크로 평균 과업 성능. 품질 우선 시 ID +2.09%p, OOD +2.87%p이고, 선정된 저비용 구간에서는 약 36%(ID)·25%(OOD)의 평균 추론 비용 절감과 함께 성능도 앞선다.
- 적응형 vs 고정 크기: Track-2 ID에서 적응형 PISA-E 하이퍼볼륨은 28.57로 최선의 고정 크기(k=1) 27.89를 앞서고, 고정 앙상블은 커질수록 k=11에서 14.55까지 꾸준히 나빠진다. 반면 RouterBench ID에서는 고정 k=1이 근소하게 앞서(46.99 vs 46.37)므로, 매크로 평균 우위는 크기를 프롬프트별로 조절하는 데서 온다.
- 프롬프트 의존 순위 소거 실험: 프롬프트별 순위를 학습셋 전역 순위로 바꿔도 포아송-이항 대리 지표는 유지하면, 매크로 하이퍼볼륨이 ID 39.35→34.39, OOD 26.30→25.39로 떨어진다(전체 32.82 vs 29.89). 적응형이 ID 네 벤치마크 전부에서 이기지만 OOD의 FusionBench·SPROUT에서는 전역 순위가 더 좋다.
- 기존 연구와의 차별점: hard 배정 군집 라우터(UniRoute, Avengers-Pro)나 군집+IRT(ZeroRouter)와 달리 소프트 멤버십+모델별 예측기를 쓴다. 캐스케이드나 순차적 확장(EMS, LightRouter)과 달리 생성 전에 병렬 앙상블을 선택하며, 전체 쿼리에 하나의 앙상블을 재사용하는 LLM-TOPLA·DFPE, 구성만 적응하고 크기가 고정인 SelectLLM과 달리 구성과 크기를 모두 적응시킨다.

- 단일 모델 베이스라인: 모델–질문 정답 행렬에서 잠재 요인을 학습하는 EmbedLLM, Avengers-Pro, K-NN, MLP. 정답 점수로 프롬프트별 최적 모델을 고르는 오라클 선택기가 성능 상한을 제시한다.
- 앙상블 베이스라인: 쿼리 간 재사용 앙상블인 DFPE·LLM-TOPLA, 입력 적응형 구성에 고정 크기인 SelectLLM, LLM-Blender의 PairRM 보상 모델을 쓰는 PairRanker(사전학습·미세조정 두 변형), 일반 BERTScore 기반 MBR.
- 지표: 과업 성능은 과업군 매크로 평균. 비용–성능은 정규화 지배 하이퍼볼륨(×100)으로 요약하며, 기준 성능은 무작위 라우터, 기준 비용은 전체 풀 비용 분포의 40백분위(단일 모델)·70백분위(앙상블)다.
- 비용 모델: 모델 비용은 학습셋 관측 평균 비용을 최고가 모델 평균으로 나눈 값이고, 앙상블 비용은 멤버 평균의 합이다. 프롬프트별 가격 예측은 쓰지 않는다.
- 부록: 멤버 결과 간 의존성을 반영한 앙상블 성공 추정의 가우시안 코퓰라 확장(부록 B), 탐욕 선택과 대리 지표 전수 최적화의 비교(부록 E), 하이퍼볼륨 기준점·최대 크기 민감도 연구(부록 C·D).
- 비용–품질 선호를 추론 시점에 조정할 수 있다는 것은 적합된 라우터 하나로 여러 운영 지점을 지원한다는 뜻이다. 실제로 하이퍼파라미터와 앙상블 구성은 벤치마크마다 α = 1(품질 우선)에서 한 번 선택했고 모든 α 값에 재사용됐다.
