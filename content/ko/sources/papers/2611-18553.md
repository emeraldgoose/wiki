# WeightBench: 가중치 공간 프로그래머로서의 언어 모델 평가

**Source**: [arXiv](https://arxiv.org/abs/2611.18553)
**게시일**: 2026-11-13

## Overview

WeightBench(University of Southern Mississippi)는 Weight-Space Programming(WSP), 즉 대형 언어 모델이 다른 신경망의 파라미터를 직접 조작하는 능력 — 네트워크가 무엇을 학습했는지 읽고, 실패하는 네트워크를 고치고, 기울기 없이 처음부터 동작하는 네트워크를 작성하는 능력 — 을 평가하는 벤치마크다. 점점 더 강력한 LLM을 5개 트랙(Static Diagnosis READ, Surgical Patching FIX, Infeasibility Verification META, Zero-Shot Weight Synthesis WRITE, Hardware-Aware Optimization SYSTEMS)의 42개 WSP 태스크에서 평가하며, 대상 네트워크는 2K 파라미터 제어 정책부터 7B 파라미터 언어 모델까지 이른다.

이 프레임워크는 엄격한 실행 환경과 감사 계층(가드 주입이 있는 샌드박스 실행, 연산자 계량, 데이터 흐름 출처 추적, 감사 플래그·격리 로직, 레드팀 감사 검증)을 절차적 태스크 스케일링 및 오염 완화와 결합하여, 에이전트가 무차별 시행착오로 WSP 제약을 우회하지 못하게 한다. 결과는 완전히 평가된 모델 간 명확한 스케일링 거동을 보이며, 현재 모델이 진정한 가중치 공간 프로그래밍의 초기 단계에 있음을 보여준다.

## 핵심 내용

- 매크로 WeightBench 점수: Claude Opus 5.5(0.535) > Sonnet(0.466) > Haiku(0.402). DeepSeek v4-flash는 전체 최하위(0.215)이자 최고 격리율(42회 중 13회).
- GPT-6.1-sol(38개 태스크 실행)은 공통 태스크에서 0.568(Opus 0.546), TR-01(0.928)과 TR-04(0.863) 최고 평균을 기록했으나 TR-03(0.260)에서는 Claude 모델들보다 훨씬 낮다.
- TR-04(Weight Synthesis)가 모델 간 격차를 가장 크게 만든다: Opus 0.829, Sonnet 0.569, Haiku 0.369, DeepSeek 0.000, GPT-6.1-sol 0.863 — zero-shot 가중치 합성은 실제로 가능하지만 불균등하다.
- TR-03(Infeasibility Verification): 세 Claude 모델 모두 모든 태스크에서 0.485–0.500, 사실상 무작위 추측 기준. 모델은 가중치만으로 차단된 능력과 빠진 능력을 구분하지 못한다.
- TR-05(Hardware-Aware Optimization): 모든 에이전트가 저조(0.177–0.238) — 데이터 없는 비특권 압축은 여전히 매우 어렵다.
- TR-02(Surgical Patching)는 대체로 미해결: 에이전트는 일반 능력에 대한 부수적 손상 없이 표적 행동 수정을 실행하지 못한다. 추론 루프 4개 태스크에서 Opus(3개)와 Sonnet(1개)만 0점 초과.

## 상세

- 트랙 구성: READ(가중치 정적 진단), FIX(외과적 패치), META(불가능성 검증 — 불가능한 편집 인식), WRITE(zero-shot 가중치 합성), SYSTEMS(하드웨어 인식, 데이터 없는 압축·최적화).
- 감사: 엄격한 연산 감사, 격리된 실행 환경, 하드 편집 예산. 연산자 계량과 데이터 흐름 출처 추적으로 출력 생성 경위를 추적하고, 감사 플래그로 비준수 실행을 격리하며, 레드팀 감사 검증을 포함한다.
- 오염 완화: 생성기와 반암기 조치를 갖춘 절차적 태스크 스케일링으로, 암기된 해법이 인스턴스 간에 일반화되지 않게 한다.
- 태스크 유효성·기준선은 에이전트 평가 전에 검증되며, 매크로 점수는 5개 트랙에 걸쳐 트랙별 내역과 함께 보고한다.
- 결론: LLM은 자연어 의미를 네트워크 파라미터의 기하학에 직접 매핑할 수 있으나(zero-shot 제어 정책 합성이 이를 확인), 외과적 패치나 파국적 부수 피해 없는 대형 언어 모델 압축에 필요한 정밀도는 부족하다. WSP는 아직 초기 단계다.
- 향후 계획: 추가 모델(예: Claude Fable)에 대한 완전 평가와 동적 난이도 스케일링을 추진하여, WeightBench를 WSP를 공학 분야로 성숙시키는 시험대로 삼을 계획이다.
