# Mage-VL-Cowork: 진화한 하네스로 배우는 하이브리드 컴퓨터 사용 전체 학습 레시피

**원문**: [arXiv:2610.40747](https://arxiv.org/abs/2610.40747) · **게시일**: 2026-10-29
**저자**: Xiaoyi Zhang, Haoqing Wang, Xinjie Zhang, Xiang Ming, Xing Wang, Senqiao Yang, Kaichen Zhang, Zhaoyang Jia, Andong Tan, Xinjiang Wang, Jinghao Guo, Yifei Shen, Xiao Li, Peng Zhang, Xun Guo, Jiahao Li, Shicheng Zheng, Jinglu Wang, Zongyu Guo, Wenxuan Xie, Bin Li, Yan Lu

## 개요

효과적인 컴퓨터 사용 에이전트는 GUI 기반 시각 상호작용과 코드, 터미널 실행을 하나의 정책 안에서 자연스럽게 결합해야 한다. Mage-VL-Cowork는 일반 멀티모달 정렬 체크포인트에서 출발해, midtraining, 지도 학습, 강화 학습을 아우르는 5단계 점진적 커리큘럼으로 학습된 4B 규모의 하이브리드 컴퓨터 사용 에이전트다.

대규모 학습 데이터 공급을 위해 Mage-CUA-Forge는 과제별 에이전트 구성을 재사용 가능한 스킬 조건화 생성 워크플로와 응용별 준비 도구로 대체한다. 이를 통해 6,915개 스킬에 걸친 293,806개 데스크톱 및 웹 과제를 생성하면서, 반복적 과제당 비용을 82.6% 줄였다. 가설은 단일 기본 교사를 직접 증류하는 대신, 교사 하네스를 진화시키고 특화된 컴퓨터 사용 하네스를 인스턴스화해 고품질 궤적과 단계별 감독을 만들었다.

학습된 4B 모델은 더 효율적인 추론 비용으로 OSWorld-Verified에서 66.0%에 도달했으며, 동일 파라미터 규모에서 최첨단 성능을 달성하면서 온디바이스 지능의 최전선을 끌어올렸다.

## 핵심 내용

- 하이브리드 컴퓨터 사용 에이전트는 GUI, 코드, 터미널 동작을 하나의 정책으로 묶어야 한다.
- 5단계 점진적 midtraining, SFT, RL 커리큘럼이 4B 하이브리드 모델을 학습한다.
- 스킬 조건화 과제 합성이 293,806개 과제를 만들어 과제당 비용을 82.6% 줄인다.
- 기본 교사 대신 교사 하네스를 진화시켜 지도 신호를 생성한다.
- 4B 모델이 OSWorld-Verified에서 66.0%를 달성했다.
- 프로젝트 페이지와 자료가 공개되었다.

## 상세

논문은 단일 기법이 아니라 전체 학습 레시피를 다룬다. 점진적 커리큘럼, 데스크톱 및 웹 응용 전반의 합성 과제 생성, 진화한 교사 감독을 결합해 각 단계의 궤적과 학습 신호를 만든다. OSWorld-Verified 결과는 4B 파라미터 규모에서 더 효율적인 추론 비용과 함께 달성되었다.
