# Exploring Collaboration between a language and a non-language agent

: LLMs are increasingly deployed as orchestrators coordinating specialized subagents through natural language — but in domains like game playing and robotics, the strongest available agents are *not* language models, so integrating them requires **verbalization**: compressing rich continuous representations into sparse text summaries at every step. This paper asks whether verbalization is a bottleneck and answers with **LLAMIA-Bench**, six collaborative chess tasks across three facets (behavioral imitation, state assessment, natural-language explanation), each unsolvable by either the LLM or the chess engine alone. Its fix is **latent state internalization**: projecting the subagent's continuous representations directly into the LLM's token stream as learned state tokens, with dynamic re-encoding as actions advance the environment. The gap between internalization and verbalization — the **verbalization debt** — widens through training and persists from 4B to 14B parameters, while a single 14B **LLAMIA** model matches or exceeds task specialists and frontier models including GPT-5.1 with tool access, and generalizes out-of-distribution where task-specific finetunes collapse.

Why verbalization should be suspect: Every orchestrator–tool interaction today passes through text: the subagent's state gets summarized into words, the LLM reasons, and the loop repeats. That text bottleneck discards most of the subagent's representation at exactly the moment precision matters. Chess is the ideal testbed because the non-language expert (the engine) is superhuman yet genuinely inarticulate — its knowledge lives in continuous state, not sentences — so any collaboration gain or loss can be attributed to the interface

Latent state internalization: Instead of translating state into words, internalization projects the subagent's continuous representations directly into the LLM's token stream as learned state tokens, re-encoded dynamically as actions advance the environment state. The LLM then attends over live subagent state the way it attends over words — no summarization step, no information thrown away at the boundary.
