# VLA에서 표현·행동 공간 다리로 구현하는 인간-로봇 전이

**원문**: [arXiv:2611.04391](https://arxiv.org/abs/2611.04391) · **게시일**: 2026-11-03
**저자**: Junhyeong Park, Wook Jung, Taeyoung Kim, Huiwon Jang, Jinwoo Shin

## 개요

사전학습 VLA 정책은 배포 시 강한 출발점이 되지만, target robot/environment에 적응하려면 여전히 costly한 embodiment-specific demonstration이 필요하다. 인간 demonstration은 수집이 훨씬 쉽지만, underlying VLA가 주로 robot data로 사전학습되었을 때 특히 human-robot embodiment gap이 커서 직접 leverage가 어렵다. 논문은 unpaired human/robot demonstration으로부터 사전학습 VLA policy를 적응시키는 human-robot co-training framework H2RB(Human-To-Robot Bridge)를 소개한다. H2RB는 양쪽 인터페이스에서 embodiment gap을 잇는다: geometry-anchored alignment는 human/robot observation을 compatible representation으로 grounding하고, decoupled-decoder tokenizer는 단일 action mapping으로 강제하지 않고 action latent를 공유한다. 이 설계는 인간 demonstration이 유용한 behavioral supervision을 제공하면서 사전학습 VLA의 풍부한 시각/의미/control prior를 보존하게 한다. real-world task에서 H2RB는 object transfer를 8.0에서 51.8로 크게 높이고 skill transfer 62.7을 가능하게 하며, co-train baseline이 human-demonstrated skills를 전이하지 못하는 settings에서 동작한다. object-placement shifts에서도 OOD transfer가 6.0에서 45.3으로 향상된다. H2RB는 인간 demonstration을 scalable supervision source로 사용해 사전학습 로봇 정책 적응을 이루고 costly target-robot data collection 의존을 줄이는 경로를 제시한다.

## 핵심 내용

- 사전학습 VLA 적응에는 여전히 costly embodiment-specific demonstration이 필요하다.
- human demonstration은 저렴하지만 large human-robot embodiment gap이 존재한다.
- H2RB는 geometry-anchored alignment와 decoupled-decoder tokenizer로 gap을 둘 인터페이스에서 연결한다.
- object transfer 8.0→51.8, skill transfer 62.7, placement-shift OOD 6.0→45.3.
- co-train baseline이 실패하는 settings에서 H2RB는 human-demonstrated skill을 전이한다.

## 상세

결과는 object transfer, skill transfer, OOD object placement를 포괄한다. task protocol과 architecture 세부는 연결된 논문을 참고한다.
