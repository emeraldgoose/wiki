# SAS: 컨텍스트 랭킹의 종단간 최적화를 통한 단순 어텐션 희소화 (Simple Attention Sparsification via End-to-End Optimization of Context Ranking)

**저자**: Zhiwei Li, Lei Zhu, Hao Gu, Xiang Hu, Yan Wang, Haitao Mi, Sirui Han, Leo Liang, Zhijiang Guo · **발행일**: 2026년 9월 11일 · **arXiv**: [2609.13141](https://arxiv.org/abs/2609.13141) · **HuggingFace**: [https://huggingface.co/papers/2609.13141](https://huggingface.co/papers/2609.13141)

## 초록 (Abstract)

사후 훈련(Post-Training) 어텐션 희소화(Sparsification)는 각 쿼리에 대해 소수의 컨텍스트 단위(토큰 또는 블록)만을 선택함으로써 사전 훈련된 트랜스포머의 이차($O(N^2)$) 누적 어텐션 연산 비용을 줄입니다. 기존의 학습 가능한 방법들은 일반적으로 경량 셀렉터(Selector)를 사용해 컨텍스트 단위의 점수를 매긴 후, 불연속적인 하드 Top-K 선택을 적용하기 때문에 언어 모델링 손실(Language Modeling Loss)의 기울기(Gradient)가 차단됩니다. 결과적으로 이들 기법은 기본 모델의 레이어별 조밀한(Dense) 어텐션 분포를 증류(Distill)하는 방식을 사용해 왔습니다. 그러나 이는 셀렉터가 기존 모델의 조밀한 어텐션 가중치를 모사하도록 유도할 뿐, 고정된 어텐션 예산(쿼리당 참조할 컨텍스트 단위 수) 내에서 실제 예측에 미치는 영향을 직접 반영하지 못하여 제한된 예산을 덜 유용한 단위에 유실시키는 문제가 있었습니다.

이러한 정렬 불일치(Misalignment)를 해결하기 위해 본 논문은 언어 모델링 손실을 통해 컨텍스트 랭킹을 종단간(End-to-End)으로 최적화하는 게이트형 희소 어텐션 메커니즘인 **SAS (Simple Attention Sparsification)**를 제안합니다. 핵심 아이디어는 훈련 중 셀렉터의 연속적인 점수를 어텐션 로짓(Logit)에 주입하여 표준 역전파를 통해 손실 함수가 셀렉터를 직접 업데이트할 수 있도록 하는 것입니다. 본 논문은 이 단순한 구조가 실전에서 효과적으로 작동하기 위한 핵심 설계를 제시합니다:
1. 어텐션 Softmax 내부에 Log 형태로 게이트 배치
2. 정규화된 Softmax 게이트를 통해 항상 유지되는 현재 블록 대비 과거 컨텍스트의 스케일 보정
3. 하드 선택 대신 연속적 점수를 유지하여 모델이 상대적 우선순위를 학습하도록 유도

또한 긴 시퀀스 훈련을 지원하기 위해 SAS를 FlashAttention 스타일의 연산에 통합한 메모리 효율적인 **Triton 커널**을 구현했습니다. 추론, 장문 컨텍스트 이해 및 에이전트 과제 전반에 걸쳐 SAS는 제한된 어텐션 예산 조건에서 특히 뛰어난 성능 향상을 보였습니다.

## 배경 및 문제 제기 (Background and Problem Setup)

표준 트랜스포머 아키텍처는 이전 모든 토큰에 대해 전체 어텐션을 계산하므로, 컨텍스트 길이 $N$이 증가함에 따라 메모리 및 연산 복잡도가 이차식 $O(N^2)$으로 대폭 증가합니다. 이는 장문 컨텍스트 응용, 대화형 에이전트, 다중 턴 대화 시스템에서 심각한 병목을 유발합니다.

이를 완화하기 위해 사후 훈련 어텐션 희소화 기법은 쿼리당 일부 컨텍스트 단위만 선택합니다. 기존의 학습 가능한 희소화 방법은 보통 2단계로 동작합니다:
1. 경량 셀렉터가 후보 컨텍스트 단위를 평가.
2. 불연속적 Top-K 연산으로 상위 단위를 선택.

그러나 하드 Top-K 연산은 미분 불가능하므로 표준 언어 모델링 손실의 기울기가 셀렉터로 전달되지 못합니다. 이에 대한 우회책으로 기존 연구들은 교사(Teacher) 모델의 전체 조밀 어텐션 분포를 증류해 왔습니다. 하지만 이는 근본적인 목적함수 불일치를 유발합니다:
- **증류 정렬 불일치**: 조밀한 어텐션 가중치를 모사하는 것은 셀렉터가 엄격한 희소 예산 $K$ 하에서 실제 예측 기여도를 평가하는 대신 기존 조밀 분포를 복제하도록 강제합니다. 이는 예산이 매우 제한적인 상황에서 비효율적인 토큰 선택으로 이어집니다.

## 방법론 (Methodology)

SAS는 셀렉터의 연속 점수를 어텐션 연산 과정에 직접 주입함으로써 기울기 차단 문제를 해결하고, 주 언어 모델링 손실을 통해 컨텍스트 랭킹 셀렉터를 종단간으로 최적화합니다.

### 종단간 게이트형 어텐션 메커니즘
- **로짓 공간 게이팅**: 불연속 마스크를 후처리로 적용하는 대신, SAS는 경량 셀렉터 네트워크를 통해 각 컨텍스트 단위 $i$에 대한 연속 게이팅 점수 $g_i$를 계산합니다.
- **Log 형태의 Softmax 주입**: 셀렉터의 연속 점수 $g_i$는 Softmax 연산 직전 어텐션 로짓에 직접 주입됩니다:
  $$\text{Attention}(Q, K, V)_i = \text{softmax}\left(\frac{Q K_i^T}{\sqrt{d}} + \log g_i\right) V_i$$
  $\log g_i$를 Softmax 내부에 배치함으로써, 언어 모델링 손실에 대한 표준 역전파가 기울기 $\frac{\partial \mathcal{L}_{\text{LM}}}{\partial g_i}$를 자동 계산하여 교차 엔트로피 손실을 최소화하는 방향으로 셀렉터를 직접 훈련시킵니다.

### 핵심 아키텍처 설계
1. **정규화된 Softmax 게이트**: 항상 유지되는 현재 쿼리 블록과 과거 컨텍스트 블록 간의 공정한 스케일 보정을 위해, SAS는 온도(Temperature) 스케일링된 Softmax를 사용하여 컨텍스트 블록 전체에 대해 게이팅 점수를 정규화합니다.
2. **연속 점수 보존**: 훈련 과정에서 하드 이진 선택을 강제하지 않고 연속적인 게이팅 가중치를 유지함으로써, 모델이 컨텍스트 블록 간의 세밀한 상대적 우선순위를 학습할 수 있도록 합니다.
3. **예산 인식 보정**: 셀렉터는 목표 어텐션 예산 $K$에 맞추어 점수 분포를 자연스럽게 조정하며, 유용성이 높은 토큰에 확률 질량을 집중시킵니다.

### 메모리 효율적 Triton 커널 구현
- 긴 시퀀스 훈련 시 연산 효율성을 위해 SAS 전용 **Triton GPU 커널**을 개발했습니다.
- 이 커널은 Log 형태의 게이트 점수 주입을 FlashAttention 블록 단위 실행에 융합(Fusion)하여, $O(N^2)$ 크기의 희소 어텐션 행렬을 메모리에 직접 전개하지 않고도 GPU 메모리 오버헤드를 최적으로 유지합니다.

## 실험 결과 (Results)

SAS는 수학적 추론, 장문 컨텍스트 검색, 에이전트 상호작용 벤치마크에서 기존 최고 수준의 희소 어텐션 기법들과 비교 평가되었습니다:

- **모든 예산 구간에서의 일관된 우위**: SAS는 평가된 모든 희소 비율(Sparsity Ratio) 구간에서 조밀 어텐션 증류 기반 베이스라인을 일관되게 상회했습니다.
- **엄격한 예산 제약 하에서의 탁월한 성능**: 어텐션 예산 $K$가 극도로 제한된 환경(예: 전체 컨텍스트의 5%~10%만 참조)에서 SAS는 가장 큰 성능 격차를 나타내어, 종단간 최적화가 증류 방식보다 훨씬 뛰어난 품질의 컨텍스트를 선택함을 증명했습니다.
- **연산 및 메모리 효율성**: Triton 커널과의 결합을 통해 SAS는 다운스트림 과제 정확도 손실 없이 장문 추론 시 메모리 사용량을 대폭 줄이고 어텐션 연산 속도를 향상시켰습니다.

## 한계점 및 열린 질문 (Limitations and Open Questions)

- **재훈련 필요성**: SAS 사후 훈련은 처음부터 전체 모델을 훈련할 필요는 없으나, 게이팅 메커니즘 정렬을 위해 타겟 컨텍스트 상에서 경량 셀렉터를 추가 파인튜닝해야 합니다.
- **블록 단위 입도(Granularity) 트레이드오프**: 블록 단위 희소화는 토큰 단위 선택에 비해 인덱싱 오버헤드를 대폭 줄이지만, 유용한 블록 내에 포함된 불필요한 토큰까지 함께 유지될 수 있습니다.
- **하드웨어 전용 최적화**: 커스텀 Triton 커널은 현대 NVIDIA GPU에 최적화되어 있으므로, Apple Silicon, AMD ROCm, TPU 등 타 하드웨어 가속기로 포팅하려면 별도의 커널 수정이 필요합니다.

## 소프트웨어 엔지니어를 위한 시사점 (Relevance to Software Engineers)

장문 컨텍스트 LLM 및 에이전트 시스템을 구축하는 ML 엔지니어와 시스템 아키텍트에게 SAS는 다음과 같은 핵심 통찰을 제공합니다:

1. **종단간 목표 정렬의 중요성**: 컨텍스트 프루닝 시 어텐션 증류에만 의존하지 마십시오. 실제 과제 손실을 사용한 종단간 최적화가 고정된 연산 예산 하에서 훨씬 우수한 컨텍스트 셀렉터를 생성합니다.
2. **FlashAttention 내부 게이트 융합**: FlashAttention 커널 내부에 Soft Logit 게이트($\log g_i$)를 직접 주입하는 방식은 하드웨어 가속 메모리 효율성을 해치지 않으면서 학습 가능한 컨텍스트 선택 능력을 추가하는 매우 깔끔한 패턴입니다.
3. **예산 적응형 컨텍스트 관리**: 엄격한 지연 시간이나 메모리 제약 하에서 LLM 서비스를 운영할 때, SAS를 사용하면 답변 정확도를 유지하면서 쿼리 부하에 따라 어텐션 예산 $K$를 동적으로 확장/축소할 수 있습니다.
4. **에이전트 장기 대화의 연산 병목 해소**: 컨텍스트 윈도우가 지속적으로 누적되는 다중 턴 에이전트 환경에서 SAS 블록 희소화를 적용하면, 컨텍스트 증가에 따른 연산 지연 병목을 효과적으로 해소할 수 있습니다.
