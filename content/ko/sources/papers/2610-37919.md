# SciGame: 실세계와 반사실 세계에서 과학 발견 게임을 수행하는 에이전트

**원문**: [arXiv:2610.37919](https://arxiv.org/abs/2610.37919) · **게시일**: 2026-10-27
**저자**: SciGame Authors

## 개요

LLM agent가 과학 발견에 쓰이기 시작했지만 기존 benchmark는 법칙 추론과 프로그래밍을 섞고, unseen input 예측보다 data fitting을 채점하며, empirical evidence와 pre-trained prior를 충분히 분리하지 않는다. SciGame은 scientific literature를 구조화된 관계로 바꾸고, 제어된 조건에서 governing law를 발견할 수 있는지를 평가한다.

relation, variable, input domain, applicability condition을 기록하는 scientific card를 구성한다. 각 card는 동일한 interface를 가진 두 environment를 만든다. Original environment는 source relation을 구현하고, Counterfactual environment는 변형된 relation을 구현한다. Identification은 candidate가 주어지는 task이고, Discovery는 candidate가 주어지지 않는 task다.

## 핵심 내용

- protocol 변경이 task 차이를 가리는 문제, generalization을 잘 검사하지 않는 metric, experience와 prior knowledge 분리 부족, counterfactual test 부재라는 네 가지 한계를 다룬다.
- 각 task는 Prior-only, Fixed observation, Adaptive experimental design protocol로 실행된다.
- original과 counterfactual relation을 비교하여 memorization과 genuine discovery를 구분한다.
- executable expression 제출이 포함된 Identification과 Discovery task setting을 제공한다.
- benchmark memorization을 줄이기 위한 live, knowledge-cutoff-aware Temporal collection을 추가한다.
- 보고된 설정에서 여러 LLM을 평가한다.

## 상세

SciGame은 과학 법칙 발견이 데이터 fitting 이상을 필요로 한다는 생각에 기반한다. agent는 input이 observable을 어떻게 결정하는지 추론하고, 관측되지 않은 input으로 generalization하며, evidence와 prior knowledge를 분리하고, hypothesis를 동적으로 수정해야 한다. Original/Counterfactual pair는 underlying relation만 바꾸고 interface를 고정하므로 agent가 observation을 사용하는지 memorized literature에 의존하는지 더 잘 시험할 수 있다.

benchmark는 안정적인 Historical collection과 독립 review가 포함된 rerunnable pipeline 기반 Temporal collection을 갖는다. unified framework는 두 task mode 전반에서 세 protocol과 세 metric을 비교한다. 전반적으로 coding-heavy benchmark보다 과학 발견 capability를 더 정밀하게 측정하는 것을 목표로 한다.
