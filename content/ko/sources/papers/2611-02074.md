# SWE-Trail: 코딩 에이전트 학습을 위한 히스토리 기반 궤적 수집

**원문**: [arXiv:2611.02074](https://arxiv.org/abs/2611.02074) · **게시일**: 2026-11-01
**저자**: Ziming Li, Lu Yu, Jiatan Huang, Qing Cui, Jun Zhou, Chuxu Zhang

## 개요

코딩 에이전트는 탐색, 편집, 검증의 긴 시퀀스를 통해 저장소 이슈를 해결한다. 이런 궤적은 점점 더 사후 학습 데이터로 사용되므로 수집 방식이 학습된 모델의 학습 내용을 좌우한다. 일반적인 접근은 이슈마다 궤적을 독립적으로 여러 번 샘플링한 뒤 선택하거나 큐레이션하는 것이다. 그러나 독립적으로 샘플링이 반복될수록 이후 궤적은 점점 더 중복되고, 이전 궤적이 이후 수집 노력의 방향을 안내할 수 있음에도 활용되지 않는다. SWE-Trail은 수집 히스토리를 노출해 후속 궤적 생성을 안내하고 샘플링 중복을 줄인다.

## 핵심 내용

- 코딩 에이전트 궤적은 유용한 사후 학습 데이터이다.
- 궤적에는 탐색, 편집, 검증이 포함된다.
- 독립 반복 샘플링은 중복으로 이어진다.
- 이전 궤적은 유용한 안내를 담고 있다.
- 히스토리 기반 수집은 중복을 다룬다.
- 방법은 학습된 모델의 학습 내용에 영향을 준다.

## 상세

논문은 모델 아키텍처보다는 데이터 수집에 초점을 둔다. 궤적 분포가 학습 결과를 형성하므로 중복 샘플은 커버리지를 개선하지 못한 채 수집 노력만 낭비한다. 수집 히스토리를 사용해 샘플링을 조향함으로써 SWE-Trail은 이미 본 경로를 반복하기보다 새로운 유용한 경로를 발견하고자 한다. 이는 코딩 에이전트 학습 데이터의 효율과 다양성을 개선할 수 있다.
