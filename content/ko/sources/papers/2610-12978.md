# 픽셀 확산 트랜스포머를 이끄는 표현 학습

**Source**: Pan et al., arXiv, 2026-10-09

**핵심**: 시각 표현은 이해를 위해 만들어졌지만, 생성에 유용한 표현이 무엇인지는 불분명하다. 저자들은 픽셀 확산 트랜스포머에서 강한 정렬 의미가 픽셀 합성 과정에서 소멸하고, 특화된 픽셀 디코더가 부담을 재배분할 뿐 도움이 안 됨을 보인다. 해결책인 표현 가이던스(RG)는 compact 병목 표현을 만들고 디코더가 이를 쓰도록 강제해, plain 트랜스포머로 ImageNet 256x256 FID 1.55를 달성한다.

## 배경

최신 비전 인코더는 인식에 잘 전이되므로, 생성 모델도 그 특징을 빌려 쓴다 — 잠재 공간으로 쓰거나 중간층 정렬 목표(REPA 등)로 쓴다. 그러나 생성은 인식과 다르다: 전역 의미와 공간 구조를 모든 픽셀까지 보존해야 한다.

이 논문은 원시 픽셀에서 직접 합성하는 픽셀 확산 트랜스포머(pDiT)를 plain 트랜스포머 JiT 기준으로 연구한다. 두 가지 발견이 방법의 동기가 된다:

- **표현 품질 향상이 곧 생성 향상이 아니다.** JiT-B 한 층을 DINOv2에 정렬하면 해당 층 의미가 좋아지지만, 픽셀 예측에 가까워질수록 이득이 소멸한다. REPA-4는 초반 학습을 가속하지만 최종 FID가 기준선보다 나쁘고(4.80 vs. 4.56, 200 에폭), 깊은 정렬일수록 더 나쁘다(REPA-6: 5.38, REPA-8: 8.33).
- **아키텍처 분리는 개선이 아니라 재배분이다.** 특화 픽셀 디코더(PixelDiT, DiP, DeCo)는 인코더가 유지하는 정보(전역 의미 vs. 공간 구조)를 바꾸지만, 파라미터·FLOP를 늘리면서도 생성 이득이 일관되지 않다(PixelDiT는 바닐라와 동등한 FID 4.26 vs. 4.17에 파라미터 55% 증가).

## 표현 가이던스(RG)

plain 트랜스포머를 유지하고 표현 인터페이스에 두 가지 장치를 둔다:

1. **병목으로 compact하게 형성.** 인코더 출력을 저차원 선형 병목($d = 128 \ll D$)에 통과시켜 암시적 잠재 공간을 만들고, 생성 관련 정보를 간결한 표현으로 강제한다. 디코더는 이 표현만 토큰별 adaLN 조건으로 보고, 자체 패치 임베딩과 소수 블록(기본 8 인코더 / 4 디코더)을 갖는다.
2. **가이드 목표 enforced 활용.** 학습 중 표현을 확률 0.1로 드롭해 동일 네트워크의 표현-없는 예측을 얻고, 두 디코더 예측의 차이가 플로우 매칭 목표를 수정한다:

$$v_{RG} = v + (s-1)\, sg(\Delta v_{rep}), \quad \Delta v_{rep} = v_{\theta}(z_t, t, r) - v_{\theta}(z_t, t, \emptyset)$$

RG 스케일 $s = 1.4$($s = 1$이면 plain 플로우 매칭으로 환원). 오프셋은 EMA 교사로 계산하고, 20 에폭 웜업 뒤 $t \in (0.3, 1]$ 구간에 적용하며, 중간 인코더 층의 REPA 정렬 손실과 합친다.

수렴 시 표현이 예측 속도에 기여하는 비중이 증폭되어, 학습 분포가 표현과 일관된 샘플 쪽으로 뾰족해진다 — 클래스 라벨 대신 모델 자신의 학습 표현이 이끄는 학습시점 CFG 유사체다.

## 실험

**설정**: ImageNet-1K 클래스 조건부 생성 256x256·512x512(AdamW, 배치 1024, logit-normal 타임스텝, CFG 포함 50-스텝 Heun 샘플링); 텍스트-이미지 변형 RG-T2I-L/16은 MiniT2I 블록 + 고정 FLAN-T5-Large 인코더, CC12M 사전학습 후 120K 혼합 파인튜닝.

**벤치마크**: ImageNet FID/IS/정밀도/재현율; 텍스트-이미지는 GenEval(553 프롬프트)과 DPG-Bench(1,065 프롬프트).

**결과**:

| 모델 | 파라미터 | 벤치마크 | 점수 |
|-------|--------|-----------|-------|
| RG-XL/16 | 725M | ImageNet 256x256 FID | **1.55**(픽셀 공간 최고) |
| RG-L/16 | 459M | ImageNet 256x256 FID | 1.79(2B JiT-G 1.82를 능가) |
| RG-XL/16 | 725M | ImageNet 512x512 FID | **1.74**(픽셀 공간 최고) |
| RG-T2I-L/16 | 912+341M | GenEval / DPG-Bench | **0.89** / **87.1** |

RG-T2I는 더 큰 잠재 모델(SD3 8B: 0.68/84.1, FLUX.1-dev 12B: 0.67/83.8)과 동일 레시피 MiniT2I 기준선을 모두 넘는다. PCA 시각화는 RG가 인코더 층에 선명한 의미 윤곽을 유지하고 디코더 층에 고주파 디테일이 집중되는 기능 분화를 확인한다 — REPA만으로는 잃는 특성이다.

**절제 연구**(B/16, 200 에폭): 병목 폭은 200 에폭에선 비슷하나 600 에폭에서 $d = 128$이 최선; 정렬은 3층이 6/8층보다 좋음; 8/4 인코더-디코더 분할이 최선.

## 소프트웨어 엔지니어를 위한 시사점

- **효율 패턴**: 459M RG 모델이 20억 파라미터 기준선을 능가 — 확산 서빙 비용에서 표현 설계가 규모를 대체할 수 있다.
- **학습시점 가이던스**: 학습 중 EMA 순전파 2회 추가, 추론 비용 0 — 다른 플로우 매칭 파이프라인에도 이식 가능한 저렴한 기법.
- **표현 디버깅**: 층별 PCA 분석(의미 인코더 vs. 고주파 디코더)은 정렬 손실이 출력까지 살아남는지 확인하는 재사용 가능한 레시피.
- **plain 아키텍처 확장**: 커스텀 픽셀 디코더 커널 없이 표준 트랜스포머 블록만 사용 — 기존 추론 스택에 배포가 단순하다.
