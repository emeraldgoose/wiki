# MAServeBench: 계층적 협업 워크로드를 통한 다중 에이전트 LLM 서빙 시스템 벤치마킹

**원문**: [arXiv:2610.40293](https://arxiv.org/abs/2610.40293) · **게시일**: 2026-10-29
**저자**: Shengxuan Qiu, Haochen Huang, Shuzhang Zhong, Zizhuo Fu, Zebin Yang, Jianming Tong, Meng Li

## 개요

대규모 언어 모델 기반 다중 에이전트 시스템은 복잡한 작업을 수행하기 위해 전문화된 에이전트들이 협력하도록 만들며, 하나의 사용자 요청이 상호 의존적인 모델 호출과 도구 작업의 묶음으로 변환된다. 전통적인 방식처럼 요청들을 독립 작업으로 처리하지 않기 때문에 이들 작업은 서로 다른 시점에 준비되고, 에이전트가 조율하면서 컨텍스트도 계속 변한다. 따라서 서빙 수요는 동시성, 계산, 메모리 압력으로 변환되며, 협업 구조에 따라 하드웨어 병목이 드러난다. realized operation을 기록해도 이를 만들어낸 협업 규칙은 보존되지 않아 재사용과 통제 비교가 어렵다.

MAServeBench는 다중 에이전트 협업을 서빙 워크로드의 구성 가능한 차원으로 다뤄 이 문제를 해결한다. 문서화된 다중 에이전트 워크플로에서 에이전트 조율과 컨텍스트 교환을 잡아내는 구성 가능한 단계들이 있어, 작업 입력과 도구가 같더라도 서로 다른 워크로드를 생성할 수 있다. 계층적 시맨틱 트레이스는 realized operation과 타입이 붙은 의존성을 보존하여 재현 가능한 고정 워크 재생과 아키텍처 시뮬레이터 입력으로 쓰인다. 작업 연결 측정은 워크로드를 서빙 실행과 GPU/NPU 하드웨어 동작으로 연결하여, 서빙 효율이 항상 작업 완료 시점으로 이어지지는 않는 이유를 보여 준다. 코드는 https://github.com/ShengxuanQiu/MAServeBench 에서 제공된다.

## 핵심 내용

- 조율과 컨텍스트 교환을 작업 바인딩과 독립적으로 표현하는 구성 가능한 단계를 제공한다.
- 네이티브로 협업 의존적 워크로드를 생성하면서 realized work는 controlled replay를 위해 보존한다.
- 계층적 시맨틱 트레이스는 서빙 replay와 아키텍처 시뮬레이션을 위해 operation과 의존성을 보존한다.
- 기록된 워크 검사와 네이티브 대비 replay 정합성으로 기능적 동작을 검증한다.
- GPU/NPU 플랫폼 전반에서 다중 에이전트 실행 형태를 계산, 메모리, 작업 수준 서비스 수준 목표로 연결한다.

## 상세

벤치마크는 네 가지 재사용 가능한 단계 템플릿을 정의하고 이를 spawn-fork-join-refinement 같은 파이프라인과 debate 스타일 흐름으로 합성한다. work generation과 work exposure의 차이를 두어 네이티브 realization과 통제된 고정 워크 실험을 모두 지원한다.

네이티브 평가는 코드, 추론, 금융, evidence processing, 과학 분야의 서른 개 공통 작업 바인딩을 이용하는 일곱 가지 워크플로 구조를 쓴다. 서빙 실험은 vLLM/vLLM-Ascend 기반으로 세 블록 run에서 사용자 32, 64, 128명을 쓰고 release 개입에는 더 작은 고정 워크 cohort를 쓴다. 검증은 1,032건 완료 요청, millisecond 허용 오차의 186개 선행 의존 release 제약, payload와 token 수, operation, dependency를 보존하는 204건의 paired replay 비교를 포함한다.
