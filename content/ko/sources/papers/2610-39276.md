# MemSteer: 사용자 이력을 에이전트 메모리 최적화 supervision으로 변환하기

**원문**: [arXiv:2610.39276](https://arxiv.org/abs/2610.39276) · **게시일**: 2026-10-27
**저자**: MemSteer Authors

## 개요

효과적인 agent memory system은 사용자의 이력과 task requirement에 맞춰 적응해야 하지만, 인간이 annotation한 supervision은 비용이 크고 자주 구하기 어렵다. MemSteer는 라벨 없는 사용자 이력을 source-grounded QA-evidence supervision으로 변환하여 model parameter를 갱신하지 않고도 memory design을 평가하고 개선할 수 있게 한다.

방법은 source record들을 연결하고 그 facts가 reference answer를 jointly support하는 방식을 명시한다. evidence-grounded answer plan이 question generation을 안내하고, source-grounded verification이 annotation을 검사한다. 논문은 mistake를 storage, retrieval, answer generation 중 어느 단계에서 비롯되었는지 attribute하고 targeted revision을 제안하는 evidence-guided optimizer인 MemSteer-Opt도 소개한다.

## 핵심 내용

- 라벨 없는 사용자 이력을 agent memory design 평가용 supervision으로 변환한다.
- source facts에 grounding된 QA-evidence pair를 생성한다.
- evidence-grounded answer planning, source-grounded audit, verification을 사용한다.
- MemSteer-Opt는 memory design revision 평가에 QA performance를 사용한다.
- 잘못된 응답의 원인을 storage, retrieval, answer generation으로 구분한다.
- ATM-Bench와 RHELM 실험에서 utility와 다른 user history로의 transfer를 조사한다.
- generated supervision은 다른 existing optimizer에도 유용하다고 보고한다.

## 상세

외부 memory system은 user history를 저장하고 organize하지만 storage granularity, retrieval strategy, answer-context construction이 모두 답변 품질에 영향을 준다. MemSteer는 개인 이력에 라벨이 없는 문제를 history 자체에서 supervision을 생성함으로써 해결한다.

synthetic QA로 memory-construction policy를 훈련하는 대신 MemSteer는 개인 history에서 memory design을 평가하고 개선하기 위한 reliable feedback에 초점을 둔다. 실험은 generated supervision이 optimization을 안내할 수 있는지, 다른 history로 transfer되는지, new user에 adapt하는지, evidence-guided feedback이 optimization을 개선하는지 조사한다.
