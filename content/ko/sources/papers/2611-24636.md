# 클로버-35B-A3B-프리뷰 기술 보고서

**원문**: [arXiv:2611.24636](https://arxiv.org/abs/2611.24636) · **게시일**: 2026-11-18 (v1)
**저자**: DiffuSpace Technical Team

## 개요

확산 언어 모델은 여러 토큰을 병렬로 예측하면서 반복적 디노이징으로 시퀀스를 재구성하여, 유연한 생성 순서와 효율적 추론을 연결한다. 클로버-35B-A3B-프리뷰는 총 350억 개 파라미터 중 30억 개가 활성화되는 mixture-of-experts 확산 언어 모델로 사고 모드 생성을 지원한다. 블록 확산에 게이티드 델타 네트워크(Gated Delta Networks)를 적용한다. 각 블록은 이전에 생성된 컨텍스트의 순환 메모리와 현재 블록 내부의 양방향 소프트맥스 어텐션을 결합하고, 이력 메모리의 읽기 결과가 현재 블록 토큰과 하나의 공유 소프트맥스에서 경쟁하며, 학습 가능한 블록 크기 보정과 별도의 0으로 초기화된 오른쪽 컨텍스트 합성곱 분기를 포함한다. 보고서는 모델 품질, 초안/검증 비용, 제한된 메모리 아래에서의 배포를 중심으로 평가를 구성한다. 코드: github.com/DiffuSpace/Clover-35B-A3B-Preview, 가중치: huggingface.co/Diffuspace/Clover-35B-A3B-Preview.

## 핵심 내용

- 에이전트 지표: 클로버는 평가한 7개 에이전트 지표에서 선두를 기록했으며, SWE-bench Verified 73.6, Terminal-Bench 2.1 51.7을 포함한다.
- 속도: 내부 에이전트 워크로드에서 NVIDIA GB300 GPU 하나, BF16 정밀도, 배치 크기 1 기준으로 680 토큰/초의 생성 속도를 보고한다.
- 아키텍처: 블록 확산 내부의 게이티드 델타 네트워크 — 과거 컨텍스트의 순환 메모리와 블록 내 양방향 소프트맥스 어텐션, 이력 읽기와 현재 토큰 간의 공유 소프트맥스 경쟁, 학습 가능한 블록 크기 보정, 0으로 초기화된 오른쪽 컨텍스트 합성곱 분기.
- 결정 모델 변형: 연관된 질문들에 대한 답을 한 번의 디노이징 패스로 함께 생성한다. 내부 500개 그룹 집합에서 공동 예측은 질문 정확도를 90.37%에서 93.88%로, 그룹 전체 정답률을 65.4%에서 77.0%로 높인다.
- 양자화 배포: 단일 RTX 5070 Ti(16GB VRAM)에서 SGLang + KTransformers 하이브리드 GPU-CPU전문가 실행(레이어당 GPU 96개/CPU 160개전문가, INT4 그룹 크기 32전문가 가중치, 비전문가 모듈 BF16, AVX-512 CPU 백엔드, 32K 컨텍스트, 온도 0, 사고 모드 켜짐)으로 MATH-500 전체에서 정확도 96.8%에 66.64 토큰/초(원래 top-8 배치). 라우팅 정보를 활용한전문가 배치(자주 쓰이는전문가를 GPU에 배치)는 이를 97.6%에 97.52 토큰/초로 높인다. top-6 검증은 96.0%에서 106.25 토큰/초를 낸다.
- 같은 MATH-500 설정의 베이스라인: MiniCPM-V 4.7은 97.4%에 49.51 토큰/초, Qwen3.6-35B-A3B는 93.8%에 47.04 토큰/초.
- 디코딩: 블록 레벨 초안 코어셋 임계값 tau=0.9를 쓰는 자기 추측 디코딩(더 낮은 tau=0.6도 실험했다).

## 상세

이 보고서는 클로버를 D3PM, RDM, SEDD, MDLM, DiffuSeq 같은 확산 LM 공식과 에이전트 벤치마크 사이에 위치시킨다. 평가는 모델 품질(SWE-bench Verified, Terminal-Bench 2.1 포함), 초안 및 검증 비용(자기 추측 디코딩, 코어셋 임계값을 통한 초안 희소성/수락률), 그리고 제한된 메모리 배포를 다룬다. 여기서는 소비자용 하드웨어에서의 INT4 양자화전문가 배치와 하이브리드 GPU/CPU 실행을 다루며, 워크로드 수요에 맞게전문가 배치를조정하는 것이 디코딩 최적화만큼 중요함을 보인다.
