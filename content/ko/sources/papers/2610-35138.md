# Co-Design Bench: 에이전틱 모델을 위한 멀티모달 협업 코딩 평가

출처: Xilin Wei 외 15인, arXiv:2610.35138, 2026-10-26.

**핵심 요약**: 인간-AI 공동 설계를 평가하려면 코딩 에이전트가 실제 사용자의 멀티모달 요청을 작동하는 애플리케이션 수정으로 바꿀 수 있는지 시험해야 합니다. **Co-Design Bench**는 26,314개 실제 사용자 코딩 세션의 37,463개 중복 제거 쿼리에서 선별한 **273개 과제**로 구성된 참조 없는 벤치마크입니다. 두 트랙, Multimodal Editing(ME)과 Repository Editing(RE),는 이미지·오디오·비디오·문서 입력이 있는 국소 편집과 조정된 저장소 수정을 다룹니다. 과제는 Grounded Understanding, UI Transformation, Functional Implementation 세 역량 차원을 가로지릅니다. 각 과제는 정규화된 요청과 실행 가능한 수정 전 애플리케이션을 2,331개 숨겨진 전문가 수락 기준과 짝합니다. **판정 후 반박(judge-then-refute)** 프로토콜은 소스와 브라우저 증거로 기준을 채점하고, 별도 LLM 검증기로 긍정 판정에 도전하며, 골드 코드나 목표 스크린샷 없이 시각·상호작용 주장도 감사합니다. 공유 에이전틱 하네스 아래 10개 모델 엔드포인트 중 가장 강한 것은 과제당 평균 **69.9% 기준**을 통과했지만 과제 전체를 완전히 만족한 것은 **26.4%**에 불과했습니다. 10개 엔드포인트 모두 변경 유형이 3~4개인 저장소 편집에서 1~2개인 경우보다 기준 완료율이 낮았습니다. Co-Design Bench는 실제 사용자 애플리케이션 수정에서 에이전틱 실행 하의 부분 요구사항 만족과 완전 성공 사이 간극을 연구하는 테스트베드를 제공합니다.

## 핵심 내용

- 26,314개 세션의 37,463개 쿼리에서 273개 과제를 선별했다.
- 두 트랙은 멀티모달 편집과 저장소 편집이다.
- 세 역량 차원은 Grounded Understanding, UI Transformation, Functional Implementation이다.
- 판정 후 반박 프로토콜이 별도 LLM 검증기로 긍정 판정에 도전한다.
- 가장 강한 엔드포인트는 과제당 69.9% 기준 통과, 26.4% 완전 성공.
- 변경 유형 3~4개 편집에서 모든 엔드포인트 성능이 낮았다.

## 상세

벤치마크는 참조 없이 골드 코드나 목표 스크린샷 없이 시각·상호작용 주장을 감사합니다. 각 과제는 정규화된 요청과 실행 가능한 수정 전 애플리케이션, 숨겨진 전문가 수락 기준을 결합해 단편이 아닌 실제 수정을 평가합니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 기준 설계와 프로토콜 파라미터 세부는 원문을 함께 확인해야 합니다.

## SW 엔지니어와의 관련성

- 실제 사용자 요청 기반 평가가 생성 코드의 실용성을 더 잘 드러냅니다.
- 부분 요구사항 만족과 완전 성공의 간극을 별도로 추적해야 합니다.
- 참조 없는 판정은 골드 정답 부재 상황에서도 평가를 가능하게 합니다.
