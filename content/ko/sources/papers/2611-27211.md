# 개인화된 장문 텍스트 생성을 위한 명시적 스타일 추출

**출처**: huggingface
**출판일**: 2026-11-20
**URL**: https://arxiv.org/abs/2611.27211

## 개요

개인화된 장문 생성은 언어 모델이 특정 사용자의 방식으로 새로운 텍스트를 작성하도록 요구한다. 기존의 일반적인 접근법인 검색 증강 생성은 사용자의 과거 텍스트 몇 개를 프롬프트에 넣지만, 모델이 그 중 무엇을 가져올지는 암묵적으로 결정하게 둔다. 이러한 암묵적 방식은 어떤 스타일 습관이 이전되는지 점검하거나 제어하기 어렵게 만든다.

본 논문은 StylePrism을 제안한다. StylePrism은 어휘 선택, 구문 패턴, 화용론 및 어조, 구조적 조직, 담화 표지, 교차 과제 지문 등 7개 범주로 구성된 28개 스타일 측면을 분류한 체계다. 이 체계는 단어 빈도와 완화 표현부터 수사적 역할 분포와 마무리 표현까지, 구체적이고 검증 가능한 용어로 글쓰기 스타일을 설명하는 명시적 스키마를 제공한다.

추론 시점에 분류 체계를 활용하기 위해 SP-Refine이 제안된다. 검색된 사용자 샘플을 입력으로 받아 SP-Refine은 먼저 StylePrism을 관찰된 패턴, 인용 증거, 피해야 할 습관으로 채운다. 이후 샘플을 바탕으로 초안을 작성하고, 이 프로필에 대해 두 차례 수정하며 스타일 기준에 대한 자체 점수를 근거로 가장 약한 부분을 고친다. 더 저렴한 변형인 SP-Infer는 프로필을 이용한 단일 암묵적 추론 호출로 구현된다.

## 핵심 포인트

- SP-Refine은 세 가지 장문 LongLaMP 과제와 세 가지 LLM 계열에서 LongLaMP의 검색 증강 기준선보다 ROUGE와 METEOR 비교 27개 중 25개에서 더 좋은 성능을 보였다. 평균 개선율은 10.2%, 최대 35.8%다.
- 추출된 프로필로 사용자의 실제 텍스트를 주석했을 때 StylePrism은 수사적 움직임의 순서부터 리뷰어의 서명까지 구체적이고 검증 가능한 습관을 포착한다.
- 제거 실험은 프로필이 샘플 대체가 아니라 수정 지침으로 작용함을 보인다. 프로필만으로 작성하면 27개 비교에서 모두 성능이 떨어진다.
- 스타일 충실도 개선은 DeepSeek에서 가장 크고 GPT에서 가장 작으며, LLM 평가 기준에서 형식 항목이 거의 1점 상승한다.
- 참조를 볼 수 있게 한 오라클 변형은 추론 시점에 사용할 수 없는 정보가 남은 개선을 가져야 함을 보여준다.

## 상세

평가는 LongLaMP의 세 가지 장문 과제를 세 가지 LLM 생성기로 수행하고, 참조 기반 지표와 스타일 충실도와 과제 품질을 별도로 평가하는 규칙 기반 LLM 평가기를 함께 사용한다. 스타일 충실도는 어휘 선택, 구문, 어조, 담화, 형식을 평가하며, 과제 품질은 포괄성, 사실성, 유창성, 길이를 다룬다.

저자들은 사용자가 추출된 프로필에서 벗어나는 지점을 분석하고 부록 F에 기준별 LLM 평가 점수를 제시한다. 단일 암묵적 추론 호출이 비용이 적게 들면서 SP-Refine에 근접함을 지적해 실용적인 절충안을 제공한다.
