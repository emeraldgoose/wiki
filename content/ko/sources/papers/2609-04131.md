# Beyond Retrieval: Progressive Latent Memory Evolution for Streaming Video Understanding

: Streaming video understanding forces models to process continuous visual input under strict causality and bounded memory. Existing training-free methods compress history into an external memory bank and retrieve query-relevant evidence as extra visual context — a **store-and-retrieve** paradigm where history never becomes part of the model's reasoning state. This paper introduces **LatentStream**, a retrieve-and-**internalize** framework that progressively absorbs historical evidence into compact, fixed-length latent memory tokens. Frozen-backbone results: **64.2% on OVO-Bench (+10.2)**, **76.9% on StreamingBench**, plus 66.6% VideoMME, 74.0% MLVU, and 62.1% LongVideoBench — with lower peak memory and halved per-token decode latency.

Three coordinated components: Query-agnostic Hierarchical Streaming Memory (HSM) organizes the stream into short-, mid-, and long-term levels under a fixed token budget (8 + 64 frames, 2048-token global budget), using Jenks Natural Breaks partitioning to route short-to-mid evidence into drop/compress/preserve groups and merge spatially redundant mid-to-long pairs.

What the results show: On Qwen2.5-VL-7B, Backward Tracing jumps from 44.7% to 60.0% on OVO-Bench; ablations show HSM alone lifts 54.0→58.1, adding PMO reaches 62.4, and full HME reaches 64.2. Crucially, evolved latent tokens beat merely appending retrieved evidence (64.2 vs 59.7), and retrieved tokens are removed before final decoding — the gain is internalization, not context stuffing.

Caveats: All experiments use Qwen2.5-VL 3B/7B backbones at 1 fps; hyperparameters (R=4 iterations, K=22 tokens/group, B=8, σ=10%) are tuned on OVO-Bench and may not transfer. The entropy-progression reward assumes confidence tracks correctness, which can misfire on ambiguous queries. Offline long-video gains are a bonus result, not the design target.

Relevance to SW engineers: - Store-and-retrieve vs retrieve-and-internalize is a general memory-architecture choice for any streaming system, not just video — the same tradeoff applies to long-lived agent context.
- Fixed-length latent state bounds serving cost: peak memory and per-token latency both drop because context stops growing.
- Test-time optimization without weight updates is a deployable pattern: frozen model, per-request refinement, discarded afterward.
