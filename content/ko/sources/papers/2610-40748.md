# WorldBridge: World Action Model에서 video와 action을 bridge하여 task generalization 높이기

**원문**: [arXiv:2610.40748](https://arxiv.org/abs/2610.40748) · **게시일**: 2026-10-27
**저자**: Jun Cen et al.

## 개요

physical environment에서 embodied model의 broad task generalization은 여전히 central challenge다. 논문은 World Action Model에서 task generalization을 두 가지 complementary capability로 연구한다. video generalization은 new task의 visual evolution을 예측하고, action generalization은 그 task에 대한 actionable control을 생성한다.

WorldBridge는 video prediction과 action generation을 Mixture-of-Transformers architecture로 coupling하는 WAM이다. separate video와 action expert를 joint flow-matching objective로 train하고, structured attention mask로 두 modality를 bridge한다.

## 핵심 내용

- condition 변화 robustness뿐 아니라 task generalization 자체를 studied한다.
- video generalization과 action generalization을 둘 다 필요한 capability로 정의한다.
- in-distribution video-action data만으로는 OOD task generalization이 limited하다고 보고한다.
- separate video와 action expert를 갖는 MoT architecture를 사용한다.
- expert를 joint flow matching으로 jointly train한다.
- visual prediction과 action generation을 connect하는 structured attention mask를 사용한다.

## 상세

embodied generalization research는 object arrangement, camera viewpoint, lighting, visual appearance variation에 대한 robustness에 자주 초점을 맞춘다. WorldBridge는 training distribution 밖 task에서 visual/control-wise performance를 검토한다.

dense video supervision을 action generation과 coupling함으로써 action-labeled robot data coverage를 넘어 physical interaction을 learn하는 것을 목표로 한다. architecture는 coordinate되면서도 각 expert의 distinct role을 유지하도록 설계된다.
