# Reading the Unreadable: 텍스트 인식 이미지 초해상도에는 추론이 필요하다

**Source**: [arXiv:2611.15449](https://arxiv.org/abs/2611.15449) · **게시일**: 2026-11-11

## 개요

텍스트 인식 이미지 초해상도 Text-Aware Image Super-Resolution, TAISR는 저해상도 입력에서 고해상도 이미지를 복원하면서 텍스트 내용을 보존하는 것을 목표로 한다. 기존 방법은 TAISR를 텍스트 검출·분할·스포팅 모듈이 추가된 시각 복원 문제로 다루지만 국소 시각 정보에만 의존한다. 인간은 이미지 맥락, 논리 패턴, 선행 지식을 통해 심하게 열화된 텍스트를 읽는다. 이로부터 TAISR가 추론을 필요로 하는지가 제기된다.

검증을 위해 저자들은 추론이 필요한 텍스트와 국소적으로 복원 가능한 텍스트를 구분하는 인간 큐레이션 벤치마크 ReasonText와 검출 오류를 배제해 복원 품질을 측정하는 인식 기반 지표 Ground-Truth Text-Crop Accuracy, GTTCA를 제안한다. 최신 실세계 SR 및 TAISR 모델 12개를 평가한 결과, 추론이 필요한 텍스트에서 일관되고 상당한 성능 저하가 관찰된다. 국소 복원 가능 텍스트의 최고 정확도 45.7%는 추론 필요 텍스트의 최고 정확도 24.5%를 여전히 상회한다. 실패는 아키텍처·백본·학습 패러다임에 무관하다.

개선 동기는 두 가지 관찰에서 나온다. 텍스트 조건부 SR 모델은 캡션에 정답 전사본이 주어지면 추론 필요 텍스트를 훨씬 더 잘 복원한다. 현대 멀티모달 LLM은 추론을 통해 저해상도 이미지의 열화된 텍스트를 읽을 수 있다. 이를 바탕으로 저자들은 외부 MLLM이 열화된 텍스트를 추론해 캡션으로 제공하고, 이를 고정된 텍스트 조건부 SR 모델에 공급하는 학습 자유 플러그인 Reasoning Transfer via Captioning, RTC를 제안한다.

RTC는 텍스트 조건부 SR 모델 6개를 일관되게 개선하며 특히 추론 필요 텍스트에서 효과가 크고, 기존 TAISR 벤치마크 SA-Text-test와 RealText로도 전이된다. 놀랍게도 RTC 적용 시 실세계 SR 모델이 가장 강력한 TAISR 모델을 능가하는데, 이는 추론이 공급되면 현재 텍스트 인식 모듈의 추가 이득이 적다는 것을 시사한다.

## 핵심 내용

- TAISR 모델은 국소 시각 정보에만 의존하고 국소 단서가 부족한 곳에서 문자를 환각한다.
- ReasonText는 지각 기반 난이도 수준을 제공하고 추론 필요 텍스트와 국소 복원 가능 텍스트를 분리한다.
- GTTCA는 SR 출력의 정답 크롭에서 인식을 수행해 검출 단계 오염을 제거한다.
- 평가된 12개 모델은 설계 선택과 무관하게 추론 필요 텍스트에 시스템적 맹점이 있다.
- 텍스트 조건부 SR 모델은 캡션에 정답 전사본이 포함되면 뚜렷이 개선된다.
- MLLM은 추론을 통해 저해상도 이미지의 국소적으로 읽을 수 없는 텍스트를 추론할 수 있다.
- RTC는 학습 없이 고정된 텍스트 조건부 SR 모델의 캡션에 MLLM 추론 텍스트를 주입한다.
- RTC는 ReasonText는 물론 SA-Text-test와 RealText에서 평가된 모든 텍스트 조건부 SR 모델을 개선한다.
- RTC로 강력한 실세계 SR 모델이 가장 강력한 TAISR 모델을 능가해, 추론이 핵심 설계 축임을 보여준다.

## 상세

- ReasonText는 각 텍스트 인스턴스를 난이도별로 라벨링해 추론 필요와 국소 복원 가능한 성능을 별도로 측정한다.
- GTTCA는 SR 출력에서 정답 텍스트 영역을 크롭한 뒤 인식기를 실행하므로 검출 오류가 복원 품질 평가를 교란하지 않는다.
- 성능 격차는 크고 일관적이다. 모델 전반의 최저 국소 복원 가능 GTTCA는 45.7%이고, 최고 추론 필요 GTTCA는 24.5%이다.
- 텍스트 조건화는 도움이 되지만 정답 전사본이 제공될 때만 유효하다. MLLM으로 추론한 캡션을 사용하면 SR 모델을 재학습하지 않고도 복원이 개선된다.
- RTC는 플러그 앤 플레이이며 모델 비종속적이다. 외부 MLLM이 추론 텍스트를 포함한 캡션을 작성하고, 이는 SR 모델의 기본 캡션을 대체한다.
- 개선폭은 추론 필요 부분집합에서 가장 크며, 이는 이득이 일반적인 향상보다 추론 전이에서 온다는 것을 확인한다.
