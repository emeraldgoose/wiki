# 분리된 예측 의사결정: 에이전트를 위한 공유 조건부 예측기

**원문**: [arXiv:2611.02075](https://arxiv.org/abs/2611.02075) · **게시일**: 2026-11-01
**저자**: Lang Mo, Xingxuan Zhang, Qi Wang, Mingchao Hao, Hao Yuan, Chunjing Gan, Wang Lu, Peng Cui

## 개요

에이전트의 의사결정은 배포 시 관찰로부터 드러나는 경험적 관계에 의존하며, task description만으로는 해결되지 않을 수 있다. DPDM은 이질적 에이전트 decision을 shared pretrained learner를 사용하는 conditional prediction으로 공식화한다.

언어 모델은 현재와 과거 기록의 semantic representation을 제공한다. 범용 조건부 predictor는 그 evidence로부터 task-defined target을 예측한다. pretraining은 재사용 가능한 추론 능력을 제공하고 deployment evidence는 두 모델의 neural parameter를 업데이트하지 않고도 문제 특정 예측을 인스턴스화한다. tool judgment, candidate preference, reasoning assessment는 evidence-and-query interface를 공유하며, prediction은 decision rule을 통해 choice로 매핑된다.

Qwen3.5-27B를 semantic encoder로 사용한 DPDM은 평가된 history budget에서 50개 benchmark의 평균 accuracy를 78.80%에서 84.92%로 높인다. ToolPRMBench 작업에서는 34.26%와 28.87%의 절대 개선을 보인다. history가 늘어날수록 accuracy가 향상되며 imbalanced history에서도 balanced accuracy가 개선된다.

## 핵심 내용

- semantic knowledge와 empirical inference capability를 분리한다.
- 이질적 에이전트 의사결정을 위한 shared conditional predictor를 사용한다.
- 배포 시 model parameter를 업데이트하지 않고 예측한다.
- decision rule로 prediction을 choice에 매핑한다.
- tool judgment, candidate preference, reasoning assessment를 개선한다.
- 상호작용 history가 늘어날수록 개선이 커진다.

## 상세

이 연구는 agent capability의 상호 보완적인 source로 language pretraining의 semantic knowledge와 structured-data pretraining의 empirical inference를 정의한다. 하나의 frozen LimiX-2 predictor가 다섯 task category를 담당하며 50개 benchmark 결과를 보고한다.
