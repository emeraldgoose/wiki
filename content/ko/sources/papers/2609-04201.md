# Scal3R: 확장 가능한 온라인 3D 복원을 위한 효율적 다중 상대 포즈 쿼리 학습

출처: Chin-Yang Lin 외 7인, arXiv:2609.04201, 2026-09-03. ECCV 2026. 프로젝트 페이지 linjohnss.github.io/scal3r/.

**핵심 요약**: 온라인 3D 복원 모델은 긴 비디오에서 무너집니다. 매 포즈를 **고정된 첫 프레임 앵커** 상대값으로 회귀하니 훈련 분포를 한참 벗어난 외삽을 강제받고, 작은 드리프트가 쌓여 기하 붕괴로 증폭되기 때문입니다. 논문의 핵심 관찰은 디커플링입니다. **프레임별 깊이는 안정적인데 깨지는 것은 전역 포즈 헤드뿐** — 국소 기하는 멀쩡합니다. **Scal3R**은 온라인 복원을 **다중 참조 상대 포즈 쿼리**로 재정의합니다. **완전 동결 백본**에 비대칭 어텐션으로 주입한 경량 학습 토큰(파라미터의 ~1%)이 여러 과거 키프레임 상대 포즈를 쿼리하고, 온라인 포즈 그래프 최적화+루프 클로저가 장거리 드리프트를 누릅니다. **단일 GPU 8시간** 수렴, 온라인 베이스라인 대비 **KITTI 평균 ATE 60% 초과 감소**, Virtual KITTI·Sintel·TUM-Dynamic·ScanNet·7-Scenes SOTA입니다.

## 동결이 통하는 이유

진단이 처방을 정합니다. 백본의 국소 기하가 실패에서 살아남으니 통째 재훈련은 연산 낭비에 멀쩡한 것을 깰 위험 — 그래서 포즈 쿼리 토큰만 훈련합니다. 먼 앵커 하나 대신 **여러 과거 키프레임**에 질의하면 매 추정이 훈련 분포 근처에 머물고, 잔여 드리프트는 포즈 그래프+루프 클로저 층이 처리합니다.

## 효율 프로파일

| 항목 | 수치 |
|---|---|
| 학습 파라미터 | ~1% (토큰만, 백본 동결) |
| 훈련 비용 | 단일 GPU 8시간 |
| KITTI 평균 ATE 감소 | 온라인 베이스라인 대비 60% 초과 |
| SOTA 데이터셋 | Virtual KITTI, Sintel, TUM-Dynamic, ScanNet, 7-Scenes |

GPU 8시간의 데이터셋 횡단 SOTA는 이례적으로 싼 적응 이야기입니다. 동결 백본+토큰 패턴이 무거운 일을 합니다.
