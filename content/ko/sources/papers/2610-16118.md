# 냉장고 속 코끼리: 장기 비디오 이해를 위한 상수 메모리 프레임 패킹

출처: Shuo Gao 외 2인, arXiv:2610.16118, 2026-10-12.

**핵심 요약**: 한 시간짜리 비디오, 스트리밍 피드, 영화 길이 콘텐츠는 비전-언어 모델을 한계로 몰아갑니다. 프레임마다 시각 토큰으로 인코딩하는 표준 방식은 시퀀스가 비디오 길이에 **선형으로 증가**해 메모리와 추론 지연이 감당하기 어려워집니다. 토큰 축소나 키프레임 선택은 시퀀스를 줄이지만 **O(n) 스케일링**을 그대로 남겨 근본 병목을 해결하지 못합니다. **FramePack-U**는 임의 길이 비디오를 **상수 메모리**로 고정 크기 시각 표현에 압축하는, 놀랍도록 단순한 **훈련 없는** 프레임 패킹 프레임워크입니다.

## 작동 방식

미세조정이나 아키텍처 수정이 필요 없고, 추론 시 기성 VLM에 바로 붙습니다. 고정 토큰 예산 아래 **(1)** 각 프레임을 텍스트 프롬프트와의 의미 유사도로 점수화하고 다양성 주도 방식으로 순위를 매기며, **(2)** 선택된 프레임을 다양한 해상도로 고정 길이 컨텍스트 창에 패킹합니다. 기억 예산을 **지시와 관련 있고 시각적으로 다양한** 프레임에 집중시키는 것입니다. 이론적으로는 임의 개수를 담을 수 있지만, 여러 설정에서 강건하게 일반화되는 경험적 구성을 제시합니다.

## 결과

LongVideoBench·MLVU·Video-MME에서 FramePack-U는 다양한 모델 계열·파라미터 규모·프레임 예산에서 전체 해상도 베이스라인과 기존 토큰 축소·키프레임 선택을 일관되게 앞섰습니다. 특히 Qwen3.5-35B-A3B의 128프레임 예산에서 세 벤치마크 각각 **+12.9%·+10.6%·+9.7%** 를 기록했습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 의미 유사도 점수는 텍스트 인코더 품질에 의존하고, 세밀한 시각 정보가 필요한 순간(작은 글자, 빠른 동작)은 압축에서 손실될 수 있습니다. 최적 프레임 수와 해상도 배분은 워크로드별로 검증해야 합니다.

## SW 엔지니어와의 관련성

- 장기 비디오 서비스에서 메모리가 선형으로 터진다면, 모델 교체 전에 고정 예산 프레임 패킹을 먼저 적용해 보세요.
- 훈련 없는 추론 래퍼는 기존 VLM 스택에 붙이기 쉽습니다.
- 프레임 선택이 질의와 얼마나 관련 있는지, 다양성 점수가 실제 정확도에 기여하는지 자체 평가셋으로 확인하세요.
