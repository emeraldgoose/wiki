# S-Space: 멀티모달 언어 모델의 공간 작업공간 탐색

**Source**: Shi 외, arXiv, 2026-10-09

**핵심**: 멀티모달 LLM은 공간 추론에서 가능성을 보이지만 내부 표상을 잘 모른다. 저자들은 중간 활성화의 3차원 선형 부분공간인 S-Space를 발견했다—물체 토큰 표상이 수평·수직·거리 축의 연속 좌표를 인코딩한다. S-Space가 내부 공간 작업공간으로 동작함(지각이 위치를 쓰고, 추론이 변환하고, 언어 응답이 읽음)을 보이고, 이를 시점 전환 문제 실패 진단에 사용한다.

## 배경

공간 추론은 재구성·내비게이션·계획·조작에 중요하지만, MLLM은 관점 전환 같은 인간에게 쉬운 과제에서 뒤처진다. 최종 답변만으로는 실패 원인이 지각인지 계산인지 알 수 없다. 인간의 "정신 작업공간" 개념에서 착안해, MLLM도 공간 정보를 인코딩·변환·발화하는 내부 작업공간을 갖는지 묻는다.

## S-Space 식별

S-Space는 모델·층별(중간층)로 정의되며 $\mathcal{S} = \mathrm{span}\{v_x, v_y, v_z\}$ 세 단위 벡터로 구성된다. 각 축은 그래디언트 절차로 찾는다: "사과가 컵의 왼쪽인가 오른쪽인가?" 같은 상대 질문에서 답변 로짓 대비를 물체 토큰 활성화로 미분하고, 질의·기준 역할 반대칭 차분을 템플릿·순서·예제에 평균한다. 판독은 순전파 한 번과 선형 투영 $c_t = V^\top h_t$이며, 상대 판단은 좌표 차이 $m_g = c_{q,g} - c_{r,g}$의 부호다.

## 내부 공간 작업공간으로서의 S-Space

세 가지 성질이 작업공간임을 입증한다:

- **정확도**: 투영 좌표가 실제 물체 위치와 강하게 상관되고, 좌표만으로 답해도 모델 자체 발화와 동등하며, CV-Bench·EmbSpatial·SpatialTunnel에 일반화된다.
- **인과성**: S-Space 좌표를 수정해 은닉 상태에 되쓰면 공간 판단이 바뀌고(무작위 수정 대비), 무관한 색 판단은 유지된다—모델이 공간 답변에 S-Space를 인과적으로 선택 사용한다.
- **지속성**: 단일 물체 질의나 비공간 색 질문으로 바꿔도 같은 고정 축이 정확한 공간 판단을 지원한다—프롬프트 유발이 아닌 내재 구조다.

사례 연구에서 S-Space는 화면 밖 개체와 관찰자 토큰("you")도 위치시키고, 언어 맥락("moving past you" vs "toward you")에 따라 이동하며, 언어 편향을 계승한다("socialist"는 왼쪽, "conservative"는 오른쪽).

## 실험

**설정**: COCO 상대 공간 질문으로 Molmo2-ER·Qwen3.5-4B·Qwen3.6-27B의 S-Space 식별, CV-Bench·EmbSpatial·SpatialTunnel·SpinBench(관점 전환)·MMSI-Bench(방위)로 평가.

**관점 전환 결과(SpinBench 정확도, %)**:

| 모델 | 직접 답변 | +추론 | S-Space + 회전 |
|-------|--------|-----------|---------------|
| Molmo2-ER | 60.96 | — | 94.52 (+33.56) |
| Qwen3.5-4B | 60.96 | 62.33 (+1.37) | 91.10 (+30.14) |
| Qwen3.6-27B | 60.96 | 83.56 (+22.60) | 95.21 (+34.25) |

원천 시점 관계 오라클을 줘도 직접 답변은 뒤처지고(60–73%) S-Space+회전은 97.92–99.31%에 달해, 병목이 지각이 아닌 계산임을 드러낸다. CoT 추적에서 좌표가 목표 시점으로 점진 회전하지만 불완전하고, 방위 토큰 분석에서 기준틀 결합이 드러난다("east"는 이미지 오른쪽, "north"는 위와 정렬).

## 소프트웨어 엔지니어를 위한 시사점

시각-언어 애플리케이션 디버깅 렌즈로 활용 가능하다:

- **지각 실패와 추론 실패 분리**: 인코더를 탓하기 전 내부 좌표를 프로브하라—S-Space가 정확하면 수정은 추론/변환 단계에 있다.
- **명시적 변환을 가드레일로**: 로봇·AR 같은 시점 의존 과제에는 모델에게 추론을 맡기기보다 판독 좌표에 결정적 회전을 적용하라.
- **기준틀 결합 주의**: 지도 방위(N/E)와 이미지 방위(좌/상)를 섞는 시스템은 출력을 검증하라—모델이 두 표상을 부분 공유한다.
