# 코딩 에이전트는 망각 없이 지속적으로 진화할 수 있을까?

**원문**: [arXiv:2611.03219](https://arxiv.org/abs/2611.03219) · **게시일**: 2026-11-02
**저자**: Shangziqi Zhao, Yitong Zhang, Jia Li

## 개요

하네스 자가 진화는 foundation 모델 파라미터를 수정하지 않고 에이전트 성능을 개선하는 중요한 패러다임으로 떠오르고 있다. 선행 연구는 에이전트 하네스를 단일 작업에서 진화시키면 능력을 효과적으로 향상할 수 있음을 보여 준다. 논문은 실제로는 코딩 에이전트가 시간이 지나며 여러 작업 유형을 다룰 수 있어야 하므로, 하네스가 치명적 망각 없이 여러 작업 전반에서 지속적으로 진화할 수 있는지를 묻는다. 이 개방형 질문을 조사하며 지속적인 하네스 갱신이 작업 사이에서 어떻게 상호작용하는지 살펴본다.

## 핵심 내용

- 하네스 자가 진화는 모델 갱신 없이 에이전트를 개선한다.
- 선행 연구는 주로 단일 작업에서 진화를 다룬다.
- 실제 코딩 에이전트는 시간에 걸쳐 여러 작업 유형을 맞이한다.
- 치명적 망각이 우려된다.
- 논문은 여러 작업에 걸친 지속 진화를 조사한다.
- 이 질문은 실제 응용에서 중요하다.

## 상세

연구는 하네스 진화가 한 번 성공하는지를 넘어 시간에 걸쳐 성과를 축적할 수 있는지로 초점을 옮긴다. 모델 가중치를 바꾸기보다 도구와 workflow 수준에서 적응하는 구성 요소로서 하네스를 연구한다. 한 작업 유형에서의 개선이 이전 작업에서 성능을 해칠 수 있다는 것이 우려 사항이다. 이 문제를 개방형 질문으로 제시함으로써 논문은 단일 작업 최적화가 아니라 지속적 에이전트 적응 평가를 촉구한다.
