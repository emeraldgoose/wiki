# Beam 모델 기술 보고서

**원문**: [arXiv:2611.26358](https://arxiv.org/abs/2611.26358) · **게시일**: 2026-11-19 (v1)
**저자**: Reflection Team 등

## 개요

Beam은 코딩, 추론, 에이전트 워크로드에 맞게 설계·최적화된 희소 MoE(Mixture-of-Experts) 모델로, 총 501.3B, 활성 23.4B 파라미터 규모다. 동급 모델 대비 3~4배 적은 추론 연산으로 프런티어 수준의 추론 성능을 낸다. 사전학습에는 23.8T개의 다양하고 정제된 고품질 토큰이 투입되었고, 검증 가능하고 정답을 기준으로 한 데이터로 진행되는 새로운 2단계 중간학습 단계가 일반 능력을 해치지 않으면서 실효 컨텍스트 길이를 1M 토큰까지 늘렸다.

후학습의 중심은 10.5K대의 GB300 GPU에서 4주에 걸쳐 100M회가 넘는 롤아웃을 생성한 대규모 완전 비동기 강화학습 캠페인이었다. 이는 지금까지 오픈 랩이 수행한 것 중 최대 규모의 RL 학습이다. RL 연산량이 늘어남에 따라 능력은 계속 향상되었고 포화 징후가 없었으며, 학습에 포함되지 않은 평가(held-out) 점수는 단조롭게 상승했다. 예를 들어 BrowseComp는 해당 시점까지 검색/브라우징 작업이 전혀 없었는데도 학습 27% 시점의 50.1에서 83% 시점의 57.9로 올라 교차 영역 일반화를 보였다. 비동기 RL 시스템에서는 가중치 평균 대신 온폴리시 전-어휘 디스틸레이션으로 expert를 병합했다.

서빙 효율성은 하드웨어-모델 심층 협설계에서 나온다. FP8/NVFP4 양자화와 1.93B 파라미터 규모의 추측 디코딩(speculative decoding) 드래프터 DFlash 2가 쓰인다. 안전성 측면에서 대화 턴과 유해 카테고리를 평균하면 Beam은 유해 요청의 88.9%를 거부하거나 주제를 전환하면서도 무해 요청의 81.5%는 수용한다. 이는 파레토 프런티어(Pareto frontier) 위에서 오픈 가중치 모델 중 가장 높은 거부/전환률이다.

## 핵심 내용

- 아키텍처/규모: 희소 MoE, 총 501.3B / 활성 23.4B 파라미터; 23.8T 사전학습 토큰; 정답 기준 데이터 기반 2단계 중간학습으로 1M 토큰 컨텍스트 달성.
- 후학습: 10.5K대 GB300 GPU에서 완전 비동기 RL, 4주간 100M+ 롤아웃; 연산 증가에 따라 점수가 계속 상승(포화 없음); 온폴리시 전-어휘 디스틸레이션으로 expert 병합.
- 에이전트/코딩 벤치마크: SWE-bench Verified 80.6, SWE-bench Multilingual 75.7, SWE-bench Pro v1 62.2, DeepSWE v1.1 43.4, Terminal-Bench v2.1 77.7, SWE Atlas Codebase QnA 29.3→32.5(보고서의 teacher 대비 병합 student 열 기준).
- 추론/지식: AIME 2026 97.3, GPQA Diamond 90.2, HLE(도구 없음) 36.1, SciCode 47.2; 일반 능력으로 AA-LCR 66.3→78.7, LongBench v2 66.8, IFBench 77.
- 효율성: 동급 대비 3~4배 적은 추론 연산; FP8/NVFP4 양자화; 1.93B 파라미터 DFlash 2 추측 드래프터.
- 안전성: 유해 요청 거부/전환 88.9% vs 무해 요청 수용 81.5% — 오픈 가중치 모델 중 파레토 프런티어에서 가장 높은 거부율.

## 상세

학습 파이프라인: 사전학습 레시피는 깊이 확장 잔차 연결(depth-scaled residual connection)과 웹/코드/STEM/PDF 데이터 큐레이션(가속기별 튜닝을 거치는 OCR 내부 처리, 반복 탐지, 빈 페이지 필터링, OCR 신뢰도 필터링, HTML-to-Markdown 변환 포함), 중복 제거 및 디컨태미네이션, 데이터 부족 subsampling(DLS)을 이용한 테일 패칭을 다룬다. 중간학습은 두 단계로 이루어진다. 1단계는 STEM/틈새 지식, 경쟁 프로그래밍, 소프트웨어 엔지니어링(저장소 수준 이해, 기능 구현), 터미널 사용을 다지고, 2단계는 컨텍스트를 확장한다. 후학습에는 SFT에 이어 고연산 비동기 RL(비동기 롤아웃, 샘플링/라우팅/수치 일관성, 보상 무결성, 추론 계산량(reasoning effort) 및 토큰 효율성 제어)로 학습된 에이전트 expert가 포함되며, SWE, 터미널 사용, 수학/과학, 경쟁 코딩, 웹 검색, 전문 지식 작업, 일반 도구 사용에 걸친 작업 큐레이션이 뒤따른다. 인간 가치에 정렬하는 정렬 teacher(SFT + RL)가 모델을 인간 가치에 맞추고, 온폴리시 디스틸레이션이 에이전트 expert와 정렬 expert를 병합한다. 홀드아웃 RL 평가(pass@1, 추론 계산량 512)에서 학습 진도에 따라 벤치마크 점수가 상승했으며 포화 징후는 없었다.
