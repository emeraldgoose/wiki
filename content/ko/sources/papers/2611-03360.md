# Every Pixel Is an Option: 의료 초음파 생체 계측을 위한 System One 모델

**원문**: [arXiv:2611.03360](https://arxiv.org/abs/2611.03360) · **게시일**: 2026-11-02
**저자**: Moein Heidari, Junbo Rao, Yudan Chen, Yasamin Medghalchi, River Jiang, Wenjin Chen, David J. Foran, Jasmine Grewal, Ilker Hacihaliloglu

## 개요

초음파 랜드마크에서 수동 캘리퍼 배치에 의존하는 생체 계측은 조작자 간 변동성을 가져온다. Kev-Bio는 임상 측정 질문으로 초음파 랜드마크 검출을 안내하는 vision-language 모델이다. 좌표를 직접 예측하는 대신 언어 모델의 결정 표현으로 각 캘리퍼 엔드포인트에 대한 쿼리를 생성하고, 이를 공유 밀집 초음파 특징과 매칭해 공간 확률 맵을 만든다. 랜드마크 좌표와 임상 측정 값은 이 확률 맵에서 도출되며, 모델은 위치 결정 손실과 임상 측정 손실로 종단간 학습된다.

## 핵심 내용

- 모델은 초음파 생체 계측의 조작자 간 변동성을 다룬다.
- 별도 예측 헤드 대신 임상 측정 질문이 검출을 안내한다.
- 긴 추론 연쇄보다 System One 결정 모델에서 영감을 받았다.
- 쿼리 표현은 밀집 특징과 매칭되어 공간 확률 맵을 형성한다.
- 좌표 직접 예측 대신 위치 불확실성을 명시적으로 모델링한다.
- 종단간 학습에 위치 결정과 임상 측정 손실이 모두 사용된다.

## 상세

Kev-Bio는 9개 뷰의 FU/GU Biometry 2026 데이터셋에서 평균 방사 오차 22.50픽셀, 임상 측정 평균 절대 오차 15.38을 달성했으며 전반 성능에서 비교 기준선을 능가했다. 결과는 여러 해부학적 뷰에서의 효과를 보여준다. 임상 품질은 획득 프로토콜, 랜드마크 정의, 해부 신체 집합에 의존하므로 실제 배포에서는 로컬 장비와 인구집단으로 검증해야 한다.
