# Using Grounded Theory for Agent Behavior Analysis at Scale

: Understanding what agents actually do requires methods that scale to thousands of trajectories and surface *new* patterns in long, unfamiliar tasks — exactly where pre-built classifiers fall short. This paper imports **grounded theory**, a six-decade-old qualitative method from the social sciences with a principled saturation criterion and an auditable trail from data to theory, into agent trajectory analysis. It introduces **AutoTraceGT**, the first multi-agent pipeline that automates grounded theory on agent trajectories, iteratively performing open, axial, and theoretical coding until saturation and producing a behavioral taxonomy tailored to each task. Across six trajectory corpora, AutoTraceGT codebooks recover **73–91 percent** of the failure modes in human-annotated taxonomies while surfacing additional patterns those taxonomies miss. Used as a deductive feature space, the codebook outperforms zero-shot and few-shot LLM baselines on downstream failure prediction.

Why pre-built classifiers fall short: A classifier can only find what it was built to look for. In long, unfamiliar agent tasks the interesting behaviors are often the ones nobody pre-registered — novel failure modes, unexpected strategies, interaction patterns that only emerge at scale. Manual qualitative analysis catches these but does not scale to thousands of trajectories. The paper's move is to take a method designed for exactly this situation — grounded theory, where theory is built bottom-up from data with an explicit stoppin

AutoTraceGT: coding until saturation: AutoTraceGT is a multi-agent pipeline that mirrors the classic grounded-theory sequence: open coding (label what you see in the trajectories), axial coding (relate codes to each other), and theoretical coding (integrate them into a narrative), iterating until the saturation criterion says there is nothing new left to find. The output is a behavioral taxonomy tailored to each task, plus an auditable trail from raw trajectories to theory — something a black-box classifier never gives you.

Caveats: This summary is abstract-based; the 33-page full text will carry the details that matter (the saturation operationalization, the six corpora, baseline prompts). The 73–91% range is recovery against human taxonomies, which are themselves imperfect ground truth — recovering 100% would arguably mean overfitting to human blind spots. And "outperforms LLM baselines" is relative to zero-shot and few-shot prompting, not to a fine-tuned failure classifier.
