# visual foundation model의 공간 상태 representation probing

**원문**: [arXiv:2610.40636](https://arxiv.org/abs/2610.40636) · **게시일**: 2026-10-27
**저자**: Baiqiao Yin, Zhongang Cai, Ruisi Wang, Qiwei Liang, Lei Yang, Ziwei Liu

## 개요

visual foundation model은 개별 image 인식에 강하지만 공간 perception은 view를 넘어 object와 geometry, localization을 지속적으로 track하는 persistent state를 요구한다. 이 논문은 그런 model이 단순한 current-frame appearance가 아니라 spatial state representation을 내부적으로 인코딩하는지 probing한다.

spatial state는 observer에 대한 environment configuration이며 visible 영역을 벗어난 object와 update된 self-location을 포함한다. 연구는 current observation 이상의 정보를 요구하는 수준으로 네 가지 capability를 평가한다: spatial structure, object persistence, predictive spatial update, actionability.

## 핵심 내용

- visual foundation model의 spatial state를 위한 controlled probing framework를 소개한다.
- spatial structure, object persistence, predictive update, actionability를 검사한다.
- representation과 layer에 따라 spatial capability가 다르게 나타난다고 보고한다.
- spatial readout이 layer 선택과 streaming prefix에 의존함을 보여준다.
- prediction이 spatial readout interface를 어떻게 바꾸는지 연구한다.
- represented state를 actionability와 goal-directed progress에 연결한다.

## 상세

논문은 observer가 세계의 일부만 보면서도 hidden object를 track하고 self-motion을 account해야 한다고 주장한다. classical object-file theory, spatial updating, path integration이 네 probe level을 동기 부여한다.

explicit 3D map을 가정하지 않고, available representation이 spatial inference를 support하는지를 조사한다. temporal prefix, intervention, control, predictive objective를 통해 accessible spatial information과 readout robustness를 검토한다.
