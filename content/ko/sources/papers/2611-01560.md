# 로봇 사용 에이전트의 민주화: 개방 모델을 활용한 통합 하네스

**원문**: [arXiv:2611.01560](https://arxiv.org/abs/2611.01560) · **게시일**: 2026-11-01
**저자**: Jiarui Yuan, Yuxin Zuo, Xiaoyu Huang, Wenbo Zhang, Kwanyoung Park, Junlin Yang, Tianxiang Zhang, Ruoqu Chen, Yutao Ouyang, Bingxiang He, Xingtai Lv, Hongjin Wu, Jiajun Liu, Jiahao Zhao, Tianwei Luo, Haozhan Li, Cheng Qian, Jiaxin Ge, Huan-ang Gao, Kaisen Yang, Jiaqi Deng, Qixin Xu, Siqiao Huang, Bowen Zhou, Mengdi Xu, Zhiyuan Liu, Pieter Abbeel, Ning Ding

## 개요

로봇 사용 에이전트는 유망한 제로샷 조작 능력을 보여 왔지만, 최전선 폐쇄 모델에 의존하면 추가 학습 연구가 제한된다. 이 의존성을 낮추기 위해 uni-robot-agent라는 통합 하네스를 소개한다. 이 하네스는 경쟁력 있는 개방 가중치 로봇 사용과 추가 학습을 지원한다. 특권 입력 없이도 개방 모델 하나가 RoboDojo Score 31.39를 달성해 공개된 GPT 계열 결과 28.97과 여러 VLA/WAM 기준선을 넘어선다. 또한 19개 실제 작업에서 경쟁력 있는 성능을 보인다. 하네스는 폐쇄 모델 의존성을 제거함으로써 로봇 사용 에이전트 연구를 민주화한다.

## 핵심 내용

- 로봇 사용 에이전트는 제로샷 조작 능력을 보여 준다.
- 최전선 폐쇄 모델 의존은 개방 연구를 제한한다.
- uni-robot-agent는 개방 가중치 대안을 제공한다.
- 하네스는 추가 학습을 지원한다.
- 개방 모델이 경쟁력 있는 RoboDojo 점수를 달성한다.
- 많은 실제 작업에서 경쟁력 있는 성능을 보인다.

## 상세

기여는 방법론만큼 인프라적이다. 에이전트 하네스를 통합하고 개방 모델을 지원함으로써 이 프로젝트는 연구자가 폐쇄 API 호출에만 의존하지 않고 학습 개선을 연구할 수 있게 한다. 보고된 벤치마크 결과는 개방 가중치 모델이 로봇 조작 작업에서 폐쇄 기준선과 경쟁할 수 있음을 보여 준다. 연구는 접근 가능한 모델에 대한 실험을 장려하며 에이전트 연구의 민주화를 강조한다.
