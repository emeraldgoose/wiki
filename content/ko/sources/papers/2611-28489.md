# RGB 공간 생성으로 통합 비전 인식을 여는 Open Vision Banana

**원문**: [arXiv:2611.28489](https://arxiv.org/abs/2611.28489) · **게시일**: 2026-11-21 (v1)
**저자**: Xu Lin, Ruilin Yao, Haoran Xu, Zixiang Wang, Ming Ma, Yu Zhao, Pu Miao, Chonghan Liu

## 개요

Vision Banana는 폐쇄형 이미지 생성기를 "인식을 RGB 이미지로 그려내도록" 지시조정하면하면 범용 비전 모델이 된다는 것을 보였다. Open Vision Banana는 이것이 오픈 생성기에도 적용되는지, 아니라면 무엇이 실패하는지 묻는다. OVB는 Qwen-Image-2.1의 7B diffusion 생성기를 meteric depth와 semantic·instance·referring segmentation을 아우르는 하나의 지시 기반 모델로 개조하며, LoRA 하나와 공개 학습 데이터만 사용한다. 각 태스크는 "task contract"로 정의되는데, RGB 인코더·지시·디코더가 하나의 명세를 공유하고 학습 전에 호환성을 검사해 하나의 생성기 안에 태스크들이 공존할 수 있게 한다.

두 번의 100k 업데이트 실행에서 나온 42개 체크포인트, 여섯 번의 정확한 가중치 공간 병합, 여덟 번의 짧은 통제 실행을 외부에서 평가했다. 폐쇄형 시스템과의 격차는 포괄적이 아니라 구체적이고 측정 가능했다. 상대적 기하는 일찍 학습되지만 절대 스케일은 어느 한 샘플로도 확정되지 않고, depth와 2D 분할은 공유 어댑터를 놓고 경쟁하며, 가중치 병합은 이 트레이드오프 위를 움직일 뿐 벗어나지 못한다. 마지막으로 검증 flow loss가 낮을수록 Cityscapes 정확도가 낮아, 학습 loss로 체크포인트를 고를 수 없다.

## 핵심 내용

- Metric depth: 중앙값 정렬 NYUv2 delta-1은 학습 내내 0.89~0.93을 유지하는 반면, 정렬하지 않은 delta-1은 0.11~0.50 사이를 배회한다. 즉 상대적 장면 구조는 일찍 배우지만 절대 스케일은 배우지 못한다. 10개 시드 앙상블은 재학습 없이 정렬 안 한 delta-1을 0.348에서 0.516으로 높여, 스케일이 단일 샘플에 의해 확정되지 않음을 보인다.
- 이미지별 중앙값(스케일) 정렬은 depth 오차 중 스케일이 차지하는 비율을 보여준다. 정렬 안 한 delta-1 0.497이 NYUv2에서 0.926으로, ETH3D에서 0.225가 0.974로, DIODE-Indoor에서 0.353이 0.926으로 오른다.
- 태스크 경쟁: 지속적인 적응은 정렬 안 한 NYUv2 delta-1을 초기화 0.278에서 17.5k 업데이트 시 0.407, 100k 시 0.497로 높이지만, 같은 구간에서 Cityscapes mIoU는 0.386에서 0.355, 0.298로 떨어진다. depth와 2D 분할이 공유 어댑터를 반대 방향으로 당긴다. 기점 수치: NYUv2 0.278(정렬 0.873), ETH3D 0.292(0.924), DIODE-Indoor 0.300(0.844), Cityscapes mIoU 0.386, RefCOCOg cIoU 0.466, ReasonSeg gIoU 0.417.
- 체크포인트 선택: 검증 flow loss 감소와 Cityscapes mIoU 사이의 Spearman rho가 약 -0.9 — loss가 낮을수록 분할 정확도가 낮으므로 loss로 체크포인트를 고를 수 없다. 여섯 번의 정확한 가중치 공간 병합은 depth 대 분할 트레이드오프 위를 움직일 뿐 벗어나지 못하고, 비교한 세 모델 중 어느 하나도 모든 벤치마크에서 우세하지 않다.
- 평가의 건전성: NYUv2·ETH3D·ReasonSeg는 학습 데이터를 전혀 기여하지 않고, DIODE와 RefCOCOg는 학습 분할을 기여해 동일 출처 held-out으로 보고된다. 모든 점수는 학습/평가 이미지 식별자가 분리된 하나의 공통 평가 프로토콜에서 나온다.

## Details

OVB는 코드, task contract, 학습 데이터, 모든 평가 출력을공개 plus Hugging Face 모델 저장소를 공개한다. Task-contract 메커니즘(공유 RGB 인코딩 명세, 지시 형식, 디코더, 학습 전 검사)이 동결 기반 생성기 하나에 이기종 인식 태스크 넷을 하나의 LoRA로 공존시키는 열쇠이며, 체크포인트 연구는 오픈 생성기 인식 학습의 실무 지침이 된다. 학습 loss가 아니라 벤치마크별 외부 평가를 신뢰하라는 것이다.
