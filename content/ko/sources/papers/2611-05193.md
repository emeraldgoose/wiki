# Factorized MLLM Embeddings for Composed Image Retrieval: 구성 요소별 MLLM embedding으로 CIR 개선

**원문**: [arXiv:2611.05193](https://arxiv.org/abs/2611.05193) · **게시일**: 2026-11-03
**저자**: WonJun Moon, Seongchan Kim, Dahun Kim, Seungryong Kim

## 개요

Composed image retrieval은 reference image와 modification text를 입력으로 target image를 찾는다. 최근 MLLM 활용 방식도 진전되었지만, composed query를 contrastive supervision alone으로 single retrieval embedding에 직접 mapping 하기 때문에 compositional understanding이 underutilized된다고 본다. FactEmbed는 구성적 query comprehension과 discriminative embedding 구성을 decouple 한다. intended visual modifications를 simulate 하는 factorized latents와 intermediate target imagination objective를 사용해 retrieval 전에 target semantics를 ground하도록 유도한다. factor-level contrastive loss와 decomposed representation distillation을 deeper attention layer로 전파한다. efficient inference에서는 [EOS] token으로 global-level embedding을 구성하고, same forward pass에서 생성된 mean-pooled factorized latents로 short candidate list를 rerank 한다.

## 핵심 내용

- direct single-embedding mapping은 compositional understanding을 underuse한다.
- factorized latents는 intended visual modifications를 simulate한다.
- intermediate target imagination objective가 semantics를 ground한다.
- factor-level contrastive loss가 최적화된다.
- decomposed representations가 deeper attention layer로 distill된다.
- reranking은 거의 추가 비용 없이 mean-pooled latents를 사용한다.

## 상세

composed image retrieval benchmarks 전반에 걸쳐 FactEmbed는 prior works를 능가했다. 목표는 discriminative representation przed target imagination 분리이며, 복잡한 text modification cases에서 견고성을 높일 수 있다. inference 비용에서도 rerank는 이미 수행한 forward pass를 재사용해 저렴하게 끝난다. 다만 reported benchmarks 외의 dataset에서도 평가해 generality를 확인해야 한다.
