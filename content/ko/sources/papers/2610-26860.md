# OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory

**Source**: [arXiv 2610-26860](https://arxiv.org/abs/2610-26860) · **Date**: 2026-10-19

**Lead**: MLLM의 시각 추론이 내부 추론 예산만으로는 한계가 있음(22개 벤치마크). OpenVLHarness는 능력 계층(도구 인터페이스+증거 렌더링)과 지속적 멀티모달 메모리(이미지, 구조화 데이터, 웹 참조 주소화)로 외부 증거 획득·검사·합성 지원. 코딩 인터페이스로 저장 데이터 위 프로그램 실행. 22개 벤치마크에서 평균 9.7-12.6점 향상.
