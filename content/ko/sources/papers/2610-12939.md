# 활성화 파도 타기: LLM 은닉 상태의 정보와 기하학 분석을 통한 추측적 디코딩

**Source**: Goel et al., arXiv, 2026-10-09

**Lead**: 추측적 디코딩(Speculative decoding)은 빠른 드래프트 모델로 토큰을 제안하고 큰 대상 모델이 검증하게 하여 LLM 추론을 가속화한다. 현재 드래프트 모델은 대상을 모방하도록 학습된 작은 별도 모델이거나, 대상 모델의 내부 상태를 무시하는 n-그램 예측기이다. 이 논문은 대상 모델 자체의 은닉 상태가 예측 가능한 '활성화 파도(activation waves)'—보조 모델 없이 고품질 드래프트 토큰 생성을 위해 외삽 가능한 저차원 궤적 구조—를 포함함을 보인다.

## 배경

자기회귀 디코딩은 순차적 토큰 생성에서 병목된다: 각 토큰마다 모델 전체를 순전파해야 한다. 추측적 디코딩은 드래프트 토큰을 싸게 생성하고 대상 모델로 배치 검증하여 이를 완화한다. 가속 비율은 드래프트 모델의 수용률에 결정적으로 의존한다. 기존 접근법은: (a) 작은 드래프트 모델(대상의 1/10 크기)을 대상 모방용으로 학습—추가 학습과 저장 필요; (b) 대상의 현재 문맥을 무시하는 n-그램 또는 검색 기반 드래프터; (c) 조기 종료 레이어를 사용하는 자기-추측—여전히 아키텍처 수정 필요.

핵심 통찰: 자기회귀 생성 중, 대상 모델의 은닉 상태가 활성화 공간에서 구조화된 궤적을 따라 진화한다. 이 궤적이 예측 가능하다면, 모델은 자신의 활성화 파도를 '타고' 미래 토큰을 드래프트할 수 있다.

## 활성화 파도 발견

**은닉 상태 궤적**: 각 레이어에 대해, 생성 단계 t마다 은닉 상태 벡터 h_t를 추적. 다양한 프롬프트와 모델(Llama-3, Qwen-2, Gemma-2)에서, 수열 {h_t}이 저차원 매니폴드 근처에 있음을 발견. 주성분 분석으로 은닉 상태 진화 분산의 85% 이상을 3–5개 주성분이 설명함을 확인.

**파도 같은 역학**: 주성분 계수들이 완만하고 파도 같은 곡선—천천히 변하는 주파수와 진폭의 근사 정현파—을 따름. 이 규칙성은 레이어 전반에서 유지되나, 깊은 레이어에서 더 높은 주파수 진동 나타남. 파도 구조는 어텐션 메커니즘의 순환적 역학에서 출현: 각 토큰 표현이 이전 표현들의 가중 조합이므로, 안정적 끌개(attractor)를 가진 동역학 시스템 생성.

**예측 가능성**: 최근 k개 은닉 상태가 주어지면, 단순 선형 외삽(또는 작은 MLP)으로 h_{t+1}을 코사인 유사도 >0.95로 예측. 예측 오차는 지평(horizon)에 따라 천천히 증가하여 5–10 단계 전방 예측 가능.

## SurfSpec: 활성화 파도 타기로 추측적 디코딩

**드래프트 생성**: 각 검증 단계에서 대상 모델이 순전파로 h_t를 얻음. 다음 토큰을 기다리는 대신, 경량 예측기(레이어당 2층 MLP, 모델 파라미터의 ~0.1%)가 다음 5–10개 은닉 상태를 외삽. 예측된 상태들은 대상의 출력 헤드(임베딩 해제 행렬)를 통해 드래프트 토큰으로 디코딩.

**검증**: 대상 모델이 드래프트 수열을 한 번의 배치 순전파로 검증(표준 추측적 디코딩). 수용된 토큰은 커밋; 거부 시 해당 단계는 표준 자기회귀 생성으로 폴백.

**예측기 학습**: MLP 예측기들이 짧은 워밍업 단계(100–500 토큰) 동안 대상 모델 자체의 은닉 상태를 감독 신호로 사용하여 즉석에서 학습. 외부 데이터나 별도 학습 실행 불필요. 예측기들이 특정 프롬프트와 생성 문맥에 적응.

## 실험

**설정**: 모델: Llama-3-8B, Qwen-2-7B, Gemma-2-9B. 벤치마크: MT-Bench, HumanEval, GSM8K, LongBench. 기준선: 표준 자기회귀, 작은 드래프트 모델(1/10 크기), n-그램 드래프트, 조기 종료 자기-추측. 지표: 수용률, 토큰/초 가속, 출력 품질(벤치마크 정확 일치).

**결과**:

| 모델 | 방법 | 수용률 | 가속 | 품질 (MT-Bench) |
|-------|------|--------|------|----------------|
| Llama-3-8B | 자기회귀 | — | 1.00× | 8.42 |
| Llama-3-8B | 작은 드래프트 (800M) | 0.68 | 1.85× | 8.35 |
| Llama-3-8B | SurfSpec (5-단계) | **0.82** | **2.31×** | **8.44** |
| Llama-3-8B | SurfSpec (10-단계) | 0.74 | 2.68× | 8.41 |
| Qwen-2-7B | SurfSpec (5-단계) | 0.79 | 2.18× | 8.17 |
| Gemma-2-9B | SurfSpec (5-단계) | 0.76 | 2.05× | 8.03 |

**핵심 발견**:
- SurfSpec이 별도 드래프트 모델보다 높은 수용률 달성: 예측된 은닉 상태가 *동일* 모델에서 나오므로 분포 불일치 제거.
- 5-단계 전방 예측이 최적: 더 긴 지평은 단계당 지연 증가(더 큰 배치 검증) 대비 수용률 이득 비례하지 않음.
- 장문맥 과제(LongBench)에서 SurfSpec은 파도 구조가 지속되어 가속 유지; 작은 드래프트 모델은 문맥 증가 시 성능 저하.
- 즉석 예측기 학습이 <2% 오버헤드 추가, ~200 토큰 내 수렴.

**소거 실험**:
- 선형 외삽만으로 0.71 수용률 달성(MLP는 0.82), 파도가 대체로 선형이나 비선형 보정으로 이득.
- 최종 레이어 은닉 상태만 예측 시(전 레이어 대비) 수용률 0.68로 하락—다중 레이어 예측이 레이어 간 의존성 포착.
- 즉석 적응 제거(사전 학습된 예측기 사용) 시 수용률 8–12% 하락, 문맥 특이 역학이 중요함 확인.

## 소프트웨어 엔지니어와의 관련성

- **제로 오버헤드 추측적 디코딩**: SurfSpec은 추가 모델 가중치, 아키텍처 변경, 외부 학습 데이터 불필요. 모든 트랜스포머 기반 LLM 서빙 스택(vLLM, SGLang, TensorRT-LLM)에 플러그인으로 탑재 가능.
- **활성화 기하학으로서 진단**: 파도 구조(차원수, 예측 가능성, 주파수)가 모델 품질과 과제 난이도와 상관관계. 프로덕션에서 모니터링하면 분포 변화나 성능 저하 감지 가능.
- **모든 토큰 생성에 확장**: 같은 원리가 확산 모델(잠재 예측), 비디오 생성(프레임 잠재 예측), 멀티모달 모델에 적용—활성화 파도는 자기회귀 잠재 역학의 일반적 속성.
- **하드웨어 친화적**: 예측기 MLP가 작아 동일 GPU/TPU에서 무시할 메모리/연산 오버헤드로 실행. 배치 검증 단계는 현대 서빙 엔진에서 이미 최적화됨.
