# 잠재 피드백은 연산량과 데이터를 증폭한다

**출처**: [huggingface](https://arxiv.org/abs/2611.20404)
**게시일**: 2026-11-16

## 개요

고품질 학습 데이터가 바닥나면 흔히 쓰는 방법은 최상의 데이터를 여러 에폭 반복해 학습하는 것이지만, 반복할수록 추가 패스가 얻는 것은 줄어든다. 잠재 피드백(각 토큰의 최상위 층 상태를 다음 토큰의 입력으로 되먹임하는 방식)은 그 잉여 연산을 쓰는 또 다른 방법이다. 이 논문은 이 방식이 공정한 기준선, 즉 같은 FLOPs를 더 많은 에폭에 쓰도록 주어진 바닐라 트랜스포머를 이길 수 있는지를 묻는다. 기존 잠재 피드백 연구는 학습 토큰 수를 고정한 채 비교했고 데이터 반복 자체를 다루지 않아, 이 질문은 열린 문제로 남아 있었다.

저자들은 60M부터 778M 파라미터까지의 모델 규모, 비임베딩 파라미터당 12.5~400개의 고유 토큰(UTPP), 1~4 에폭(반복을 포함해 파라미터당 최대 1,600 학습 토큰)에 걸친 통제된 사다리 실험을 수행했다. 잠재 피드백 모델과 바닐라 트랜스포머 모두 모든 규모와 고유 데이터 양에서 개별적으로 튜닝되었고, 고유 토큰 풀은 중첩되고 중복이 제거되어 비교가 깨끗하게 이루어졌다.

핵심 결론은 잠재 피드백이 고정된 이득이 아니라 증폭기로 작동한다는 점이다. 고유 데이터가 고정되면 트랜스포머의 손실에 더 적은 연산으로 도달하고, 에폭이 고정되면 더 적은 고유 데이터로 그 손실에 도달한다. 두 절감 효과 모두 파라미터당 고유 데이터가 많아지고 반복이 늘어날수록 커지며, 다운스트림 과제 결과도 검증 손실 곡선과 일치한다. 유일한 예외는 고유 데이터가 모델 규모에 비해 극히 부족한 영역으로, 오늘날의 모델은 이 영역과 거리가 멀다.

## 핵심 내용

- 잠재 피드백은 각 토큰의 최상위 층 상태를 학습된 맵을 통해 다음 토큰의 입력으로 보내며, 논문은 피드백률 p = 0.15를 사용해 모델 규모에 따라 약 1.20~1.27배의 연산 비용이 추가된다.
- 전체 실험 격자에서 잠재 피드백은 동일한 FLOPs가 주어진 바닐라 트랜스포머를 능가하지만, 고유 데이터가 모델 규모 대비 극히 부족한 경우는 예외다.
- 고유 데이터가 같으면 더 적은 연산으로, 에폭이 같으면 더 적은 고유 데이터로 같은 손실에 도달하며, 최대 연산량의 48%와 고유 데이터의 47%를 절감할 수 있다.
- 두 절감 효과 모두 파라미터당 고유 데이터가 늘고 반복 횟수가 많아질수록 커진다.
- 두 모델에 단일 스케일링 법칙을 적합시켜 잠재 피드백을 더 많은 유효 파라미터를 가진 트랜스포머로 취급하면, 60M~271M 모델로 적합한 결과가  held-out 778M 손실을 0.3% 이내로, 두 모델 간 격차를 0.05% 이내로 예측한다.
- 연산이 아니라 데이터가 병목일 때, 같은 규모의 모델에는 잠재 피드백이 FLOP의 더 나은 쓰임새다.

## 상세

**방법.** 두 아키텍처는 하나의 현대적 디코더 백본(pre-norm RMSNorm, 회전 위치 임베딩, QK-norm, SwiGLU, 분리된 임베딩, OLMo 2 스타일 초기화)을 60M, 134M, 271M, 778M 규모로 공유한다. 행렬은 NorMuon(정규화된 Muon 변형)으로, 임베딩과 출력 헤드는 AdamW로 학습한다. 잠재 피드백 변형은 최상위 층에서 다음 입력으로 이어지는 경로를 p = 0.15로 추가한다. 학습 데이터는 Dolma 3 샘플을 중복 제거하고 Paloma 벤치마크와 문단을 공유하는 문서를 제거해 Paloma를 깨끗한 홀드아웃 평가로 사용할 수 있게 했다. 문서는 모든 접두사가 전체 샘플의 소스·주제 혼합비를 유지하도록 정렬되어 고유 데이터 풀은 엄격히 중첩된다. 각 (모델 규모, 고유 데이터, 연산 예산) 셀은 학습률과 타임스케일에 대해 튜닝된 실행이다. 저자들은 이어서 잠재 피드백이 용량 배율(적합된 계수 3개와 측정된 비용 계수)을 통해서만 반영되도록 두 모델에 하나의 결합 스케일링 법칙을 적합했고, 나머지 계수는 모두 공유된다.

**결과.** 잠재 피드백의 우위는 연산 배율(고유 데이터와 손실이 같을 때 트랜스포머 예산 대 잠재 피드백 예산)과 데이터 배율(에폭과 손실이 같을 때 트랜스포머 고유 데이터 대 잠재 피드백 고유 데이터)로 표현된다. 두 배율 모두 파라미터당 고유 데이터와 반복 횟수가 늘어날수록 커지며, 이는 반복 에폭이 기본 전략인 데이터 제약 영역에서 증폭 효과가 정확히 누적됨을 뜻한다. 60M~271M 모델로 적합한 결합 스케일링 법칙은 홀드아웃된 778M 규모의 손실을 0.3% 이내로, 모델 간 격차를 0.05% 이내로 외삽하며, 더 많은 고유 데이터와 반복에서도 두 절감이 계속 커질 것이라 예측한다. 관측된 최대 절감은 연산량의 48%와 고유 데이터의 47%이며, 다운스트림 평가도 검증 손실의 그림과 일치한다.
