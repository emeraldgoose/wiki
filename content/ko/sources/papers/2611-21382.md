# VisualArtifactSpec 1.0: 과제 명세 하의 시각 아티팩트 평가

**Source**: [arXiv](https://arxiv.org/abs/2611.21382)
**게시일**: 2026-11-16

## Overview

시각 아티팩트(visual artifact) 과제는 에이전트가 과제 명세와 소스 자료를 실용적 요구를 충족하는 산출물로 옮기는 능력을 시험한다. 아티팩트 계열을 가로질러 평가하면 널리 적용 가능한 저작 능력과 특정 매체에 국한된 강점을 구분할 수 있다. VisualArtifactSpec 1.0(VAS)은 프레젠테이션, 정적 그래픽, 애니메이션·비디오, 웹 인터페이스를 아우르는 211개 생성·수정 과제로 구성된 벤치마크다. 각 과제는 저작 목표, 소스 자료, 제약, 산출물을 명세한다.

VAS는 두 측면을 분리해 평가한다. Task Fulfillment는 명시적 요구사항과 적용 가능한 기능을 검증하고, Artifact Performance는 Content, Organization, Visuals, Delivery를 평가한다. 과제별 평가 앵커(rating anchor)가 의도된 독자·목적·매체에 맞게 공통 기준을 구체화하며, 판단은 소스 자료와 아티팩트 검사 기록에 근거한다. 아홉 가지 모델–하네스 구성을 211개 과제 전체에서 평가한 결과 종합 점수는 42.12~70.52 범위였고, 최고·최저 구성 간 격차의 73.4%를 Artifact Performance가 차지했다. 프로젝트 페이지: https://accio-lab.github.io/VisualArtifactSpec; 코드: https://github.com/Accio-Lab/VisualArtifactSpec; 데이터: https://huggingface.co/datasets/Accio-Lab/VisualArtifactSpec.

## Key points

- 종합 점수(Table 8): GPT-6 Astra 70.52, GPT-6.1 Sol 69.37, Claude Opus 5.5 65.03, Kimi K3.1 Pro 62.38, DeepSeek-V4.1-Flash 60.03, Qwen3.8-Max 51.95 … 최하위 구성 42.12. Task Fulfillment 기본 점수는 모든 구성에서 46~50 근처에 몰려 있어 순위는 Artifact Performance 보정(Δ)이 결정한다.
- Artifact Performance 차원(C/O/V/D, [-50, 50] 점수): Astra가 Content(21.61), Organization(22.75), Visuals(20.14), Delivery(21.22) 모두 선두이며, Qwen3.8-Max의 낮은 Δ(5.87)는 요구사항 미충족이 아니라 시각·전달 선택의 약함을 반영한다.
- VAS는 "요청한 것을 했는가"(명시적 요구·기능 검사로 게이팅되는 기본 점수 B)와 "이 독자·목적·매체에 적합한가"(공통 기준 Content/Organization/Visuals/Delivery와 과제별 앵커로 얻는 성과 보정 Δ)를 분리한다.
- Artifact Performance가 상·하위 격차의 73.4%를 설명하므로, 명시적 요구 준수만으로는 강한 아티팩트 저작을 구분할 수 없다.
- 사례 연구는 기록된 점수를 가시적 선택과 연결한다: 근거의 조건을 국소적으로 보존하기(연구 독자), 전화기 화면 크기에 맞게 정보 밀도 조정하기(일반 독자), 모션 전반에 걸친 대응 유지하기(애니메이션).

## Details

- 계열: 프레젠테이션(P), 정적 그래픽(G), 애니메이션/비디오(M), 웹 인터페이스(W). 211개 중 151개 비웹 과제는 확립된 목적 매핑을 유지하고, 웹사이트 배정은 과제 지시에서 재구성했다(60개 과제 집계).
- 평가: 과제별 기본 점수 B와 가중 성과 보정 Δ(S = B + Δ)로 산출. 기준 가중치·차원 점수·예외 처리는 Appendix B, 벤치마크 비교 정의는 Appendix C, 채점 민감도·일치 과제 집합·기준별 오류 패턴은 Appendix D에 수록.
