# CARTBench: 타임라인이 있는 복합·모호한 요청에 대한 쇼핑 조언 루브릭 평가

**원문**: [arXiv:2611.05862](https://arxiv.org/abs/2611.05862) · **게시일**: 2026-11-04

## 개요

LLM 쇼핑 어시스턴트가 다중 턴 대화에서 제품을 추천하는 시대지만, 실제 쇼핑 니즈는 복합적이고 모호하며 만료된다. 지난 기한의 선물, 한 가방 제한, 알 수 없는 병원 목록이 그 예다. 기존 쇼핑 벤치마크는 타임라인 입력을 명시적으로 다루지 않고, 미확인 선호를 열어 둔 답에 점수를 주는 곳도 없다. 그래서 이미 만료된 니즈를 따르는 조언인지, 그리고 요행 맞힘이 정당화된 조건부 답변인지 구분할 수 없다. CARTBench는 CART(Complex and Ambiguous Requests with Timelines), 즉 타임라인이 있는 복합·모호한 요청을 겨냥한다.

설계는 두 장애물이 결정했다. 데이터 희소성: 실제 상업 데이터 접근이 어렵고 기밀 대화에서 복합·모호 니즈를 찾는 주석은 비용이 크다. 그래서 실제 상업 쇼핑 니즈에서 층화 표집으로 17개 소매 도메인과 8개 의도를 아우르는 대표 사례 169건을 골라, 니즈 변화와 미응답 질문을 남기는 타임스탬프 대화를 내부 검색 플랫폼의 제품 기록 1,603건과 짝지었다. 기준 표준화의 어려움: 공용 체크리스트로는 사례별 니즈를 담을 수 없고, 공통 기준 없이 사례마다 기준을 쓰면 일관성이 흐트러진다. 그래서 전문가들이 완료된 주문에서 수작업으로 골라낸 우수 답변에서 이상 응답 원칙 네 가지를 증류하고, 이를 사례별 루브릭으로 구체화했다. 동결된 실험 루브릭은 Core(요구 행동), Excellence(그 이상의 고품질 조언), Safety(사례별 위험) 세 계층의 전문가 주석 기준 1,328개로 이뤄진다. 모델은 루브릭 없이 원칙만 Principle-Guided CART 프롬프팅으로 받는다.

대표 결과는 이해–실행 격차다. 동결 루브릭 아래 첫 전체 스위트 평가(GPT-6.1-Sol, Claude-Opus-5 등 플래그십 상용 API 7개 모델과 35B 이상 오픈 웨이트 3개 모델)에서 열 모델 중 셋이 Core에서 90%를 넘지만, Excellence에서 45%를 넘는 모델은 하나도 없다. 상용 모델의 목표 정렬은 97.6~99.2%로 포화인데 반해 요구 준수와 불확실성 보존은 그 뒤를 따르고, 모든 필수 검사를 통과한 모델은 없으며, 오픈 웨이트 계층은 Core에서 68.9~80.3%로 크게 뒤처진다. 판정 신뢰도는 높다. 13,280개 판정 라벨 중 13,239개(99.69%)가 익명화된 전문가 검토와 일치했다.

실패 분석이 격차의 위치를 보여준다. 근거 없는 제품 주장(F7), 진술된 속성에서 성급히 뛰어넘은 사용자별 적합성 보장(F8), 미지를 확정된 것으로 처리(F2)가 모든 모델에서 되풀이된다. 문맥 상태 혼동(F1)은 전체로는 사소하지만 과업 전환 사례에서 가장 빈번한 진단 모드다. 결정적 미지 상황에서는 불확실성 붕괴보다 증거·적합성 오류가 더 많다. 가장 인상적인 것은, 해결된 니즈와 증거 검사를 모두 통과한 답변 중에도 13.0%가 실행 계획 검사에서 떨어진다는 쇼핑 실현 가능성 신기루다.

## 핵심 내용

- 벤치마크 구성: 사례 169건, 17개 소매 도메인, 8개 의도, 타임스탬프 대화, 제품 기록 1,603건, Core·Excellence·Safety 3계층 동결 기준 1,328개. 날짜와 구간으로 활성·만료·미확인 역사적 니즈를 구분한다.
- 전문가가 완료 주문의 우수 답변에서 증류한 이상 응답 원칙 네 가지: 현재 구매 결정에 답하라. 활성 니즈를 따르고 미지를 보존하라. 주장에 근거를 대고 상충을 설명하라. 명확하고 유용한 결정 도움을 줘라.
- Core 결과: Qwen3.8-Max 95.4%, GPT-6.1-Sol 95.9%, DeepSeek-V4-Pro 91.0%가 90%를 넘는다. Claude-Opus-5 89.0, Kimi-K3 89.3, MiniMax-M3 88.8, MiMo-V2.6-Pro 87.0이 그 뒤고, 오픈 웨이트 Qwen3.5 계열은 68.9~80.3%다.
- Excellence에서는 격차가 무너진다. 최고는 Claude-Opus-5 39.8%, 다음이 Kimi-K3와 Qwen3.8-Max 37.2, GPT-6.1-Sol 29.6으로 Core 수행에 크게 못 미치고, 오픈 웨이트는 18.9~25.4%에 머문다.
- 격차의 능력별 분해: 상용 모델의 목표 정렬(GA)은 97.6~99.2%로 사실상 포화인 반면 불확실성 보존(UP)은 87.5~96.2%이고 오픈 웨이트에서는 65.7~78.6%로 떨어진다. GA가 요구 준수(RA)를 앞서는 것은 10개 모델 전부, UP 앞서기는 9개 모델이다.
- 상호작용하는 제약이나 의존적 선택을 조율해야 하는 제약 시나리오가 10개 모델 중 7개에서 Excellence 최저율이다.
- 안전은 모델별 차이가 크다. GPT-6.1-Sol은 사례별 위험 검사를 100.0% 통과하지만 MiniMax-M3는 82.2, 오픈 웨이트 계층은 60.0~84.4%다.
- 모든 모델의 공유 실패 모드: 근거 없는 제품 주장 F7, 정당화되지 않은 사용자별 적합성 보장 F8, 미지를 확정 취급하는 F2. 근거 있는 쇼핑 조언에는 뒷받침된 제품 사실과 사용자 니즈로의 정당한 연결이 모두 필요하다.
- 시나리오 구조가 중요하다. 과업 전환 사례에서는 문맥 상태 혼동 F1이 가장 빈번한 진단 모드이고(연속성이 상태 추적을 보장하지 않음), 결정적 미지 상황에서는 F2보다 F7·F8이 더 자주 나타나 미지 보존만큼 주장 경계도 중요하다.
- 실현 가능성 신기루: 해결된 목표·요구·불확실성·증거 검사를 모두 통과한 답변 중 13.0%가 계획 검사에서 실패한다(95% 구간 8.1~18.4). 요구 충족이 실행 가능한 추천을 보장하지 않는다.

## 세부 사항

- 비용과 규모: 정가 기준으로 169건 전체 평가 한 번이 API 모델당 추론·판정 합산 24달러 미만이라 대규모 모델 선별이 저렴하다. 보고된 평균±표준편차는 세 번 반복 평가에서 나온다.
- 제품 증거는 모델 간 동일하다. 내부 제품 검색 플랫폼이 제공한 제목·가격·사양·설명 기록 1,603건을 캐싱했고, 빠진 필드는 빠진 채 두었으며, 검색 결과가 사용자 선호나 적합성을 의미하지는 않는다.
- 루브릭 설계: 1,328개 기준 각각은 관찰 가능한 행동 하나를 검사하고 뒷받침된 대안을 인정한다. 전문가 검토를 거친 동결 세트이며, Excellence는 Core 최소 의무를 넘어 비교·우선순위·조건부 조언에 점수를 준다.
- 판정 프로토콜: Principle-Guided CART 프롬프팅 아래 루브릭 기반 판정. 전문가 한 명이 익명 조건에서 독립 검토했고(99.69% 일치), 보고 점수는 전문가 확정 라벨을 쓴다.
- 진단 범위: 실패한 Core 응답–기준 사례마다 AI 보조 1차 진단을 하나 붙이고, Excellence·Safety 실패는 제외하되 불확실 코드는 분모에 남긴다. 시나리오 비율은 모델과 사례를 동등 가중한다.
- 한계 노트: 선물·여행 의류 같은 일반 시나리오는 다루지만 박물관 재연용 고증 의상, 극지 탐사 장비 같은 전문 니즈와 구매–반품–교체 주기에 걸친 조언 갱신은 과제로 남는다.
