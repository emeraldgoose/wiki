# MetaKernelBench: 코드를 넘어선 GPU 커널 지식 전이 측정

출처: Xueyi Chen 외 7인, arXiv:2610.05014, 2026-10-04.

**핵심 요약**: 최근 GPU 커널 최적화 에이전트는 학습한 내용을 지식 베이스나 증류된 스킬로 보관합니다. 커널 벤치마크는 각 시도의 구현을 정확성과 속도로 채점하지만, **보관한 경험의 재사용 가치**는 측정하지 않습니다. **MetaKernelBench**는 한 커널 DSL에서 얻은 경험이 **다른 DSL의 같은 문제**에 대한 새 시도를 개선하는지 측정합니다.

## 구성

74개 문제는 6개 계열의 융합된 서브그래프이며, 각각 **DSL만 다른 CuTe DSL·TIRx 변형 쌍**으로 제시됩니다. 에이전트는 각 변형을 단독으로 시도하고, 배운 것을 자연어 스킬로 증류하도록 지시받습니다. 이 스킬은 원 시도가 검증을 통과했는지와 무관하게 전이됩니다. 스킬은 같은 모델이 다른 DSL에서 수행하는 스킬 조건부 시도의 **유일한 추가 입력**입니다. 시도별 예산을 맞춘 뒤 같은 변형의 단독 시도와 비교해 정확성과 종단 간 런타임을 채점합니다.

## 결과

6개 모델·양방향에서 단독 시도 대비 **쌍별 향상이 -19%에서 +29%** 까지 나타났습니다. 네 모델은 양방향에서 이득이 있었지만, 모든 모델·방향에서 **16~45% 문제의 회귀**가 발생했습니다. 결과는 원 시도의 성공 여부만이 아니라 **원 시도가 대상의 단독 시도보다 나은지**를 따랐습니다. 원본이 대상보다 우수할 때 비교의 71%가 개선됐고, 열등할 때 54%가 회귀했습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 자연어 스킬 증류는 모델의 자기 평가에 의존하므로, 스킬 품질과 실제 전이 효과가 어긋날 수 있습니다. DSL 쌍 구성과 예산 일치 방식은 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 커널·성능 에이전트의 지식 베이스를 "쌓였는지"가 아니라 **다른 환경에서 재사용했을 때 빨라지는지**로 평가하세요.
- 스킬 전이는 원본 시도가 대상보다 나을 때만 기대해야 합니다. 무조건 전이하면 회귀가 늘어납니다.
- DSL·하드웨어가 바뀌는 팀에서는 전이 벤치마크를 회귀 테스트에 넣으세요.
