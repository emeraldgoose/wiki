# 생물학적 추론 모델은 언제 생물학적 입력을 쓰는가?

출처: Ada Fang 외 5인, arXiv:2610.00898, 2026-10-01.

**핵심 요약**: 생물학적 추론 모델은 사후학습으로 LLM을 생물학 파운데이션 모델 표현과 생물학 텍스트에 연결하며, 벤치마크 정확도를 "LLM이 이 입력을 추론한다"는 증거로 받아들입니다. 이 논문은 DNA·단백질·단일세포 과제의 6개 모델에서 그 가정을 직접 검사합니다. 결론은 불편합니다. **정확도 상승이 생물학적 입력의 기여를 보장하지 않습니다.**

## 어떻게 검사했나

한 생물학적 입력만 교란하고 질의와 나머지 입력은 고정했습니다. 한 게놈·단백질·세포의 파운데이션 모델 표현을 다른 것의 텍스트와 짝지어 **증거 충돌**을 만들고, 언어 모델이 받는 표현에 선형 프로브를 적합했으며, 추론 흔적을 실제 입력과 대조했습니다.

## 결과

**Evo2와 ESM3는 평가 과제에서 BioReason·BioReason-Pro 성능에 거의 기여하지 않았습니다.** DNA 서열을 섞어도 BioReason의 질병 예측 정확도는 거의 변하지 않았고, 증거 충돌에서 두 모델은 각각 **97.9%·99.7%**로 텍스트를 따랐습니다. 반면 Evo2·ESM3 표현으로 학습한 선형 프로브는 과제 타깃을 예측했습니다. 즉 표현에는 과제 관련 정보가 있지만, 모델이 이를 충분히 활용하지 못합니다. ChatNT·Prot2Text-V2·CellWhisperer와 Cell2Sentence-Scale의 유전자 문장은 기여가 확인됐습니다.

## 주의할 점

BioReason-Pro의 SFT·RL 체크포인트와 42개 BioReason 체크포인트 모두에서 정확도 증가가 입력 기여 증가를 뜻하지 않았습니다. 또한 BioReason 추론 흔적은 뉴클레오타이드 변화를 잘못 진술하고, BioReason-Pro는 충돌 상황에서 최종 예측에 없는 기능을 서술했습니다. 초록 기반 정리이므로 과제별 수치는 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 멀티모달 모델을 붙일 때 "입력이 성능에 실제로 쓰이는가"를 교란·충돌 실험으로 확인하세요. 정확도만으로는 텍스트 단축(shim)을 놓칩니다.
- 표현 인코더의 정보량과 모델의 활용도는 별개입니다. 프로브 정확도와 최종 과제 기여를 함께 측정하세요.
- 추론 흔적을 사용자에게 보여준다면, 흔적이 실제 입력·예측과 일치하는지 별도 검증이 필요합니다.
