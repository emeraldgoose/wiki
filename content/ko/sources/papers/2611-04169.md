# 길이는 저렴하고 경쟁은 그렇지 않다: Attention이 Retrieval Context Rot을 예측한다

**원문**: [arXiv:2611.04169](https://arxiv.org/abs/2611.04169) · **게시일**: 2026-11-03
**저자**: Yinuo Liu

## 개요

언어 모델은 왜 긴 입력에서 실패하는가? 전형적 답은 길이다. 이 논문은 검색의 경우 길이는 저렴하고 경쟁이 문제가 된다고 주장한다. 0.5B에서 3B 매개변수, 네 가족의 다섯 오픈 모델에서 중립 채움은 거의 영향이 없어 한 모델은 32K 토큰까지 정확도가 0.97~1.00을 유지한다. 동일 위치의 증거 형식 statements는 정확도를 0.16~0.33으로 낮춘다. 질의 키에 충돌하는 rival 값을 주는 단일 statement는 손실을 9~110배 증가시키고, 추가 rival마다 손실이 더해진다. 126,473회 시험에서 증거에 남은 attention 질량은 손실 분산의 최대 58%를 설명하며 로그 길이는 최대 8%만 설명한다.

## 핵심 내용

- 검색에서 중립 채움은 긴 길이에서도 정확도 손실이 작다.
- 증거형 방해물은 중립 채움보다 정확도를 훨씬 더 크게 낮춘다.
- 단일 경쟁 statement는 손실을 9에서 110배로 증가시킨다.
- 추가 rival statement는 손실을 더 가중한다.
- 증거에 남은 attention 질량이 실패를 강하게 추적한다.
- 마스킹 채움 프로토콜은 검색 통제에서 강한 길이 효과를 재현하지 못한다.

## 상세

논문은 검색 context rot을 마스킹 채움 현상과 구분하고 126,473회 시험을 수행한다. 마스킹 채움은 MMLU에 길이 효과를 재현할 수 있지만 검색에서는 보이는 채움이 정확도 손실을 없게 하고 마스킹이 32K 토큰에서 45포인트를 손실한다. 공개된 프로브와 시험 수준 측정은 attention 경쟁 진단을 지원하지만 임계값은 모델 가족, 크기, 검색 task, 표시 조건에 의존한다. 결론은 검색에서 context rot이 주로 attention 경쟁 문제라는 점이다.
