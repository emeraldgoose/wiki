# 비디오 생성과 에이전트 하니스의 만남: 에이전트 기반 비디오 생성, 에이전트 기반 월드 모델링, 재귀적 자기개선

**원문**: [arXiv:2610.40191](https://arxiv.org/abs/2610.40191) · **게시일**: 2026-10-29
**저자**: Liaoyuan Fan, Yuhao Zheng, Dongxing Mao, Hangyu Ran, Siyuan Hu, Weijia Mao, Rui Zhao, Weijia Wu, Guian Fang, Yanzhe Chen, Zeyu Zhu, Yuxin Jiang, Yiren Song, Yuchao Gu, Junchao Yi, Qi Hu, Dan Kong, Alex Jinpeng Wang, Kevin Qinghong Lin, Mike Zheng Shou, Wei Liu

## 개요

비디오 생성은 종단 간 합성에서 에이전트 기반 생성으로 진화하고 있다. 계획, 도구 사용, 피드백이 결합되어 제어 가능한 다중 샷 비디오를 만든다. 동시에 비디오 월드 모델은行動 조건 관찰과 예측된 미래를 제공해 에이전트의 상호작용 환경으로 쓰인다. 이 논문은 비디오 생성기 같은 모델 주위의 실행 런타임인 에이전트 하니스를 통해 이 두 영역의 교차점을 연구한다. 하니스는 에이전트의 맥락을 구성하고 도구를 제공하며 상태를 유지하고 피드백을 라우팅하며 예산을 강제한다.

보고서는 에이전트 기반 비디오 생성, 에이전트 기반 월드 모델링, 재귀적 자기개선의 세 방향으로 구성된다. 생성이나 월드 모델링을 고립된 능력으로 보는 대신, 하니스가 고급 비디오 모델을 에이전트가 사용할 수 있게 만드는 계층임을 강조한다.

## 핵심 내용

- 비디오 생성은 직접 합성에서 계획과 도구 사용이 결합된 에이전트 파이프라인으로 이동하고 있다.
- 다중 샷 일관성은 모델 용량뿐 아니라 피드백과 제어에 의존한다.
- 비디오 월드 모델은에이전트에게行動 조건 미래를 제공할 수 있다.
- 에이전트 하니스는 맥락, 도구, 상태, 피드백, 예산을 관리한다.
- 보고서는 세 방향으로 분야를 정리한다.
- 하니스는 모델과 에이전트 사이의 통합 계층으로 제시된다.

## 상세

이 논문은 비디오 모델을 더 큰 에이전트 시스템의 구성 요소로 본다. 생성만으로는 작업 상태, 도구 접근, 예산 제약을 관리할 수 없으므로 실행 런타임이 이 자원들을 조율해야 한다. 월드 모델은 에이전트가 상호작용할 수 있는 예측 환경을 더하고, 재귀적 자기개선은 생성된 경험을 같은 파이프라인 개선에 사용하는 방향을 제안한다. 그 결과 고급 비디오 생성과 에이전트 인프라가 함께 발전할 수 있는 시스템 수준 관점을 제공한다.
