# Halley: 광학 AI 데이터센터 네트워크용 예측 제어 평면

**원문**: [arXiv:2611.04408](https://arxiv.org/abs/2611.04408) · **게시일**: 2026-11-03
**저자**: Manav Mishra, Krishna M. Sivalingam

## 개요

frontier AI model는 전용 네트워크로 연결된 수만 개 accelerator에서 AI 데이터센터에서 학습되며 매 training step마다 모두 동시에 데이터를 교환한다. 랙 간 네트워크는 광이고 laser/switch에 이르는 네 계층 각각 fixed/after-the-fact 정책으로 운영된다. enclosure/cooling/power를 공유하는 laser들은 함께 실패할 수 있고 fixed spare ratio에서는 correlated failure가 pool availability를 아무리 pool을 키워도 사실상 상한에 가둔다. 논문은 각 resource의 next state를 읽고 failure 발생 전에 행동하는 comprehensive predictive control plane framework Halley를 제안한다. 각각 formal guarantee를 가진 네 구성 요소가 있다: LightReserve는 coverage bound를 위한 laser pool sizing, FoldFit은 optimal 대비 11/9 내 switch scheduling, ThermaLead는 one-step-ahead control로 microring holding, TriageGuard는 highest-risk module 보호를 담당한다. Halley는 각 계층에 배포 정책을 확신이 없을 때 defer하는 predictive controller를 제공한다. simulation 구성 시 spares 고갈 window loss가 발생하면 effective goodput이 65.2%에서 76.5%로 상승하고, dark channel bandwidth만 loss일 때 67.4%에 도달한다. MW당 training throughput이 최대 1.03-1.17배이거나 동일 training에 필요한 data center capacity가 3.3-14.7% 줄 수 있다. fallback circuits는 formal verification되고 commercial FPGA timing과 130nm signoff를 통과했다.

## 핵심 내용

- correlated laser failure는 pool size와 무관하게 fixed spare ratio에서 availability 상한을 만든다.
- Halley는 네 네트워크 계층에서 resource next state를 기반으로 proactive control을 한다.
- 각 구성요소는 formal guarantee를 제공한다.
- controller는 uncertain 시 deployed policy로 defer한다.
- 시뮬레이션에서 65.2%→76.5%(full window loss), 67.4%(bandwidth loss), capacity 3.3-14.7% 절감.

## 상세

구성요소 수준 controller들을 compose한다. formal verification, FPGA timing, 130nm signoff가 practical deployment를 뒷받침한다. 전체 metric과 component derivation은 연결된 원문을 참고한다.
