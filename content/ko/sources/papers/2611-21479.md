# LynnReal-Hand: 손 제어로 세계 상호작용을 여는 길

**Source**: [huggingface](https://arxiv.org/abs/2611.21479)
**게시일**: 2026-11-17 (v2)

## 개요

LynnReal-Hand는 정밀한 상호작용 모델링과 효율적인 스트리밍 생성을 통합한 손 제어 비디오 세계 모델이다. 상호작용 비디오 세계 모델은 텍스트와 카메라 제어로 탐험을 가능하게 하지만, 직접적인 객체 상호작용에는 더 정밀한 제어가 필요하다. 손은 자연스러운 인터페이스이지만, 복잡한 손-객체 동역학과 실시간 연산 부담 때문에 연속적인 손 움직임을 일관된 시각 반응으로 번역하는 것은 어렵다.

## 핵심 내용

- **10만 개 상호작용 클립**: 다양한 실/합성 환경을 아우르며, 정밀한 손 동작과 객체 상호작용을 개선하기 위한 손 인지 감독을 개발했다.
- **인과 플로우 맵**: 소수 스텝 생성을 위한 인과 플로우 맵을 학습하고, 상호작용 동역학과 시각적 외형을 정제하기 위해 보완적 비디오·이미지 프라이어를 결합하는 **영역 인식 score distillation**을 도입했다.
- **Ultra-Fast-VAE**: 재구성 충실도를 유지하면서 연산 비용을 크게 낮춘 소형 비디오 디코더.
- **HandBench 결과**: 풀 시퀀스 FVD 181.67, MANO Dice 93.02; 3스텝 인과 모델 MANO Dice 92.49.
- **실시간**: 단일 H200에서 540p 스트리밍 **18.03 FPS**, 741ms 지연, 34.89GB 최적화 피크 GPU 메모리.

## 상세

모델의 설계 원칙은 직접적인 객체 상호작용이 텍스트나 카메라만으로는 부족한 풍부한 행동 인터페이스를 요구한다는 것이다. 영역 인식 score distillation은 비디오 프라이어(시간적 상호작용 동역학)와 이미지 프라이어(공간적 외형)를 결합해 소수 스텝 생성의 누적 오류를 교정한다. Ultra-Fast-VAE는 디코딩 비용을 충실도 손해 없이 줄인다. 코드, 가중치, 10만 개 클립 데이터셋이 공개될 예정이다.
