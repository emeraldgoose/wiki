# HeLM: 비마르코프 조작을 위한 계층적 명시 언어 메모리

**원문**: [arXiv:2611.02660](https://arxiv.org/abs/2611.02660) · **게시일**: 2026-11-02
**저자**: Gyeonghun Kim, Donghoon Kim, Minsoo Choi, Suyun Lee

## 개요

Vision-Language-Action 모델은 조작 능력을 크게 향상시켰지만 많은 모델이 현재 관찰만 action으로 매핑하는 마르코프 가정 아래 동작한다. 이 가정은 작업 memory를 필요로 하는 과제에서 실패를 초래한다. HeLM은 task-relevant history를 명시적 언어로 유지하는 계층적 프레임워크를 제안한다.

human inner monologue에서 영감을 받아 factorized event detection과 event-triggered memory update를 결합한다. task-relevant observation을 명시적 언어 memory로 정제해 full observation history를 저장하지 않고도 non-Markovian capability를 제공한다.

HeLM은 56개 variant를 포괄하는 10개 non-Markovian 실제 과제에서 평가되며, task boundary를 넘어 persistent context를 요구하는 inter-episode task 다섯 개가 포함된다. 가장 강한 baseline보다 intra-episode success를 12.8 percentage points 높이고 compositional generalization에서 78% subtask success를 달성하며, memory 사용량은 적고 runtime은 빠르다.

## 핵심 내용

- non-Markovian 조작을 위한 명시적 언어 memory를 도입한다.
- 마르코프 vision-language-action 구조를 넘어선다.
- factorized event detection과 event-triggered memory update를 사용한다.
- 10개 real-world task와 56개 variant에서 평가한다.
- 새로 formulated한 inter-episode task 다섯 개를 포함한다.
- 성공률을 높이면서 memory 사용량과 runtime을 줄인다.
