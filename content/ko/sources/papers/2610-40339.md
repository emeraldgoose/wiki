# Wizard: 에이전틱 control로 어떤 세계든 실시간 조작하기

**원문**: [arXiv:2610.40339](https://arxiv.org/abs/2610.40339) · **게시일**: 2026-10-27
**저자**: Yuzhe Wu, Zijun Lin, Yeying Jin

## 개요

최근 video world model은 점점 더 realistically하고 interactive한 virtual environment를 생성할 수 있으며, agentic framework는 game logic과 controllable world representation을 visual generation에서 분리한다. 그러나 기존 접근 방식은 control flexibility, generalization, real-time interaction에 제약이 있다. Wizard는 reference image나 free-form language로 지정된 novel scene, character, motion으로 player-customizable game world를 만들 수 있는 agentic game world model로 소개된다.

fine-grained character control, zero-shot generalization, real-time interaction, mechanically consistent gameplay를 결합한다. scene은 depth와 height를 인코딩하는 geometric proxy로 표현하고, character는 articulated skeleton으로 표현한다. agentic framework는 camera input에 따라 scene geometry를 업데이트하고 action input에 따라 skeleton을 animate하여 causal video generator에 정밀한 spatial/motion control을 제공한다.

## 핵심 내용

- unseen scene, character, motion에 대해 real-time interaction과 zero-shot generalization을 제공한다.
- scene은 2.5D geometric proxy, character는 articulated skeleton으로 표현한다.
- vision-language model이 motion library에서 compatible skeleton과 animation을 retrieval한다.
- 다양한 source의 aligned proxy-video pair 50.3시간으로 훈련한다.
- dataset은 750 scene과 178 character를 포함한다.
- character identity preservation과 reference alignment 개선을 위해 adaptive masking을 도입한다.
- 정밀한 player control을 위한 agentic video-to-video framework를 제공한다.

## 상세

model이 structured proxy를 follow하고 generalize하도록 저자들은 aligned proxy-video data를 구축하고, reference-image attention을 corresponding character region으로 제한하는 adaptive mask를 만든다. 이는 character identity와 reference image/generated video alignment 보존에 도움이 된다.

결과적으로 broad customizability와 real-time control을 갖춘 player-driven game creation system을 지향한다. gameplay mechanical consistency를 유지하면서 사용 가능한 world와 character 공간을 확장한다.
