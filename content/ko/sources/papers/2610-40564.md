# 단일 알고리즘으로 foundation model 훈련하기

출처: Yuda Song, arXiv:2610.40564, 2026-10-29.

**핵심 요약**: foundation model은 보통 데이터와 학습 알고리즘이 모두 바뀌는 **사전학습, 중간학습, SFT, RL** 단계로 학습됩니다. 저자들은 이 알고리즘적 분리가 **필연적이지 않음**을 보입니다. 적절한 RL 목적을 모델 생성 target 분포에 대한 **maximum-likelihood fitting**으로 유도하면 모든 단계를 **단일 likelihood-based training algorithm**, 즉 통일 학습 아래 놓을 수 있습니다. 이 관점은 foundation-model lifecycle을 어떤 데이터를 어떤 비율과 시점에 학습할지 선택하는 문제로 바꾸며, conventional staged training은 특수한 경우가 됩니다. 저자들은 정적 데이터와 RL 생성을 단일 trainer에서 섞는 **통일 학습 시스템**으로 프레임워크를 구현했습니다. controlled 및 real-world 실험에서 통일 학습은 정확도-계산 tradeoff와 task coverage를 개선하고 더 넓은 능력을 유지하며 continual learning의 더 강한 출발점을 제공했습니다. 이 연구는 수학 원리, 훈련 인프라, 능력 개발을 연결하는 foundation-model training의 unified science의 토대를 놓습니다.

## 핵심 내용

- 사전학습·중간학습·SFT·RL은 보통 알고리즘적으로 분리된다.
- RL 목적을 모델 생성 target 분포에 대한 MLE fitting으로 유도한다.
- 모든 단계가 단일 likelihood-based 알고리즘 아래 놓인다.
- 통일 학습은 정적 데이터와 RL 생성을 한 trainer에서 섞는다.
- 정확도-계산 tradeoff와 task coverage를 개선한다.
- 더 넓은 능력을 유지하고 continual learning 시작을 강화한다.
- staged training은 데이터 스케줄링의 특수 경우가 된다.

## 상세

통일은 중심 설계 질문을 알고리즘 선택에서 **데이터 선택·비율·시점**으로 옮깁니다. 구현 시스템은 controlled와 real-world 양쪽에서 이를 보여줍니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 목적함수 유도와 trainer 구현 세부는 원문을 함께 확인해야 합니다.

## SW 엔지니어와의 관련성

- 학습 파이프라인을 알고리즘별로 분리하지 않고 데이터 스케줄로 설계할 수 있습니다.
- MLE 기반 통일은 RL과 supervised 단계를 one trainer로 정리합니다.
- 인프라 단순화와 재현성에 유리합니다.
