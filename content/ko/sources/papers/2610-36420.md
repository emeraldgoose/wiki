# SO-101 Bench: 접근 가능한 공간 조작

출처: Truman Hickok, arXiv:2610.36420, 2026-10-27.

**핵심 요약**: SO-101 같은 저비용 로봇 팔은 로봇 학습의 가장 흔한 입문점이지만, 그 위에서 공간 제약이 있는 언어 조건 작업을 수행하는 공개 정책은 없고 기존 SO-101 벤치마크는 단순 작업과 적은 held-out 객체로 실제 하드웨어에서만 돌아갑니다. **SO-101 Bench**는 실제 SO-101 장비의 Isaac Lab 디지털 트윈 위에 구축된 **언어 조건 공간 조작 시뮬레이션 벤치마크**입니다. 태스크 4개, 채점 계열 5개, seen·unseen-instance·unseen-class 분할의 객체 138개, held-out 외관·회전 맞춤 계획·가림 기억 부분집합을 포함한 평가 에피소드 916개, 모든 학습 정책을 동등한 연산 예산으로 파인튜닝하는 시뮬레이션 데모 3,629개를 가집니다. 트윈은 실제 로봇처럼 정책을 순위화합니다. 실데이터 없이 학습한 5개 정책, 4개 VLA, 1개 LLM 에이전트는 같은 가중치를 미지의 환경·객체로 실제 로봇에서 실행했을 때 정확히 같은 순위를 유지했습니다(Spearman rho = 1.00, MMRV = 0.000), 다만 시뮬레이션은 성공률을 과대평가합니다. 9개 VLA와 월드-액션 모델 중 최고 학습 정책은 약 61%를 기록했으며 공간 배치, 미지 객체 클래스, 회전 맞춤 계획이 아직 열린 문제입니다. 코드를 작성하고 잡기는 학습 정책에 맡기는 LLM 에이전트는 83.2%를 기록했고, ablation은 이 우위가 하네스 선택과 언어 모델 선택에서 온다고 보여줍니다.

## 핵심 내용

- 디지털 트윈 기반 시뮬레이션 벤치마크로 접근성을 높인다.
- 태스크 4개, 채점 계열 5개, 객체 138개, 평가 에피소드 916개를 포함한다.
- 모든 학습 정책은 데모 3,629개로 동등한 예산으로 파인튜닝한다.
- 시뮬레이터의 정책 순위가 실제 로봇과 정확히 일치한다(Spearman rho = 1.00).
- 최고 학습 정책은 약 61%, LLM 에이전트는 83.2%를 기록했다.
- 공간 배치, 미지 클래스, 회전 맞춤 계획이 아직 열린 문제다.

## 상세

벤치마크는 특수화된 실험실 로봇이 아니라 접근 가능한 하드웨어를 겨냥합니다. 시뮬레이터가 절대 성공률을 과대평가하므로 순위 주장이 절대 성능 주장보다 강하며, LLM 에이전트 결과는 ablation으로 하네스와 모델 선택의 기여를 분리합니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 시뮬레이터 설정과 정책 학습 세부는 원문을 함께 확인해야 합니다.

## SW 엔지니어와의 관련성

- 저비용 하드웨어 벤치마크는 로봇 학습 진입 장벽을 낮춥니다.
- 시뮬레이터는 순위에는 신뢰할 수 있어도 절대 성공률은 과대평가할 수 있습니다.
- LLM 에이전트가 계획을 쓰고 학습된 정책이 실행하는 혼합 구조가 강합니다.
