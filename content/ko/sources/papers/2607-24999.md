# CogBattery: 언어 모델의 인지 과제 행동과 구조에 대한 인간 기준 평가

**원문**: [arXiv:2607.24999](https://arxiv.org/abs/2607.24999) · **게시일**: 2026-07-27

## 개요

인지 과제는 통제된 방식으로 다른 조건들을 비교하고, 공개된 인간 데이터는 사람이 각 조건에서 어떻게 반응하는지 기록한다. 집계 정확도로는 얻을 수 없는 모델 대 인간 직접 비교가 가능한 이유다. 문제는 효과의 방향만 같게 재현하면서 오류는 전혀 다르게 만드는 모델이다. CogBattery는 23개 계열의 오픈 웨이트 모델 54개를 13개 인지 패러다임의 텍스트 적응판에 돌리고, 패러다임마다 출처 연구의 인간 데이터(대부분 참가자 단위 기록)와 조건·응답 유형별로 비교한다. 작업 기억, 간섭 통제, 기억, 마음읽기, 메타인지 같은 다섯 그룹을 아우른다.

이 설계는 앞선 평가들이 비워 둔 질문에 답한다. 가장 가까운 기존 연구들은 1~16개 과제에 4~40개 모델을 다뤘고(CogBench 7/40, CogEval 1/8, CogProbe 16/4) 인간 데이터를 norms나 스케일링 상수로만 썼다. CogBattery는 특정 오류 차이와 확신 보고 차이가 계열을 넘어 얼마나 되풀이되는지, 최소 수준 게이트를 통과한 모델 사이에서도 격차가 남는지, 과제 점수 구조가 인지적 의미를 지니는지를 묻는다. 구조 비교는 같은 사람들에게 여러 과제를 실시한 네 인간 코호트로만 한정된다. 조건 효과가 튼튼해도 개인차 신뢰도까지 보장하지는 않기 때문이다.

행동 결과는 뚜렷하다. 방향을 공유해도 오류는 다르다. 2-back에서 두 집단 모두 방해 자극(lure)에 일치 반응을 더 많이 하지만, 모델은 평범한 비표적 자극도 사람보다 .257 더 많이 잘못 수용한다(54개 중 39개). Stroop 간섭은 훨씬 크다. 충돌 조건에서의 오류 증가가 모델 0.371 대 인간 0.051이고, 비일치 시행에서 단어 자체로 답하는 비율이 .376 대 .042이다. 언어적 확신 보고는 정답과 오답을 인간보다 나쁘게 가른다(Type-2 AUROC .573 대 .714, 54개 중 47개). 반면 토큰 확률은 인간 보고에 필적한다. 그리고 54개 중 37개 모델이 항상 같은 금액을 건다. 정확한 분류를 하면서도 말이다. 최소 수준 게이트 통과자 사이에서도, 27B 이상 모델에서도 격차는 남는다.

구조 결과는 인지적 해석을 조심스럽게 만든다. 모델 점수는 두 차원을 공유하고 첫 차원이 스케일과 밀접히 묶이지만, 큰 모델이 인간에게 더 가까운 것은 아니다. 미리 정의된 다섯 그룹의 인지 분류는 같은 크기의 무작위 분할보다 홀드아웃 계열 점수를 더 잘 예측하지 못했다. 논문의 결론은 방법론적이다. 인간 효과 방향의 재현이 인간 같은 행동을 증명하지 않으므로, 비교에는 방향만이 아니라 오류와 확신 보고가 필요하다. CogBattery는 새 모델을 검증할 수 있게 같은 텍스트 자료, 조건별 인간 기준, 채점기를 공개한다.

## 핵심 내용

- 범위: 오픈 웨이트 모델 54개, 23개 계열, 13개 패러다임. 각 패러다임을 출처 연구의 조건별 인간 데이터와 비교한다. 기존 평가들은 1~16개 과제에 4~40개 모델, 인간 자료도 norms 수준에 그쳤다.
- n-back: 방해 자극 효과는 평범한 비표적 오경보의 과잉 위에 얹혀 있다(+.257, 구간 [.159, .341], 54개 중 39개, 23개 계열 평균 중 19개). 표적과 방해 자극의 구분도 약하다(적중 빼기 방해 자극률 .048 대 인간 .367). 27B 이상에서도 과잉이 남는다(.351, 9개 중 7개).
- Stroop: 모델 정확도가 일치 시행 .926에서 비일치 .555로 떨어진다(인간은 .976에서 .925). 비일치 시행에서 단어 자체로 답하는 비율은 .376 대 인간 .042다. 27B 이상에서 격차는 .089로 줄지만 남는다(9개 중 4개).
- 숫자 폭은 방향은 같고 크기가 다르다. 순방향 9자리에서는 인간보다 낫고(.750 대 .327), 역방향 3자리에서는 못 진다(.611 대 .961). 순방향 빼기 역방향 격차가 모델 0.419 대 인간 0.047이다.
- CVLT 회상 기울기는 뒤집혀 있다. 인간은 학습 시행마다 1.549개 단어를 얻지만 모델은 0.287개를 잃는다. 배터리 전체에서 가장 큰 −1.836 차이다.
- 언어적 확신은 인간 메타인지보다 약하다(Type-2 AUROC .573 대 .714). 그러면서 보정 문항에서 모델은 더 확신하고(.859 대 .793) 덜 정확하다(.659 대 .722). 잘 측정된 41개 모델의 토큰 확률 AUROC는 .763으로 인간보다 .049 높다.
- 판돈: 54개 중 37개 모델이 항상 같은 금액을 건다(29개는 낮게, 8개는 높게, 23개 계열 중 19개). 정확도 86.7%의 Gemma3 27B도 항상 낮게 건다. 상수 판돈은 대체로 응답 라벨을 따를 뿐 확신을 반영하지 않는다.
- 최소 수행 게이트도 격차를 지우지 않는다. 게이트 통과 모델 사이에서 DS 격차 0.378(53개), NB 0.266(32개), ST 0.348(51개), FL 0.319(18개)다.
- 구조: 13개 과제 점수에 주성분 분석(순열 병렬 분석)과 MINRES 요인 분석을 적용하면 두 공유 차원이 나오고 첫 차원이 스케일에 묶인다. 그러나 미리 정의된 그룹의 계열 홀드아웃 예측 이득은 신뢰도 보정 후 δ* = −.011 [−.078, .075]로 무작위 분할보다 나은 증거가 없다. 대조 실험에서는 인간 규모의 그룹화를 100번 중 97번 탐지한다.

## 세부 사항

- 버전 노트: 원 이름은 CogArena였고 v1은 2026-07-27, 현재 개정판 v2는 2026-10-30이다. 이 요약은 v2를 따른다.
- 핵심 엔드포인트(모델 빼기 인간, 표 4): DS 순방향 빼기 역방향 +0.372, NB 비표적 오경보 +0.257, OS 문자 위치 정확도 −0.182, ST 충돌 오류 증가 +0.320, FL +0.066와 GN +0.040(구간이 0을 포함하며 27B 이상 9개 모델 중 누구도 go 금지 오경보가 없다. 인간 .214), CVLT 기울기 −1.836, DRM 새 자극 빼기 방해 자극 오경보 +0.293, SM 출처 정확도 +0.052, FB 거짓 믿음 정확도 −0.210(인간 .983), EP 정신 상태 기울기 +0.013, CAL Type-2 AUROC −0.141.
- 토큰 확률 재실험: 직접 응답 51개 모델을 같은 Ollama 빌드와 가중치로 다시 돌려(단계 일치 95% 이상) 첫 응답 위치에서 두 선택지 확률을 상위 20개 토큰 기준으로 재정규화해 읽었다. 80문항 중 40개 이상에서 두 선택지가 상위 20에 든 41개 모델이 대상이며, 모델 내부에서 두 확신 측도의 상관은 약하다(중앙값 rho = .16).
- 계열 홀드아웃 예측: 한 계열을 남겨 두고 훈련 계열들로 표준화, 나머지 12개 과제의 첫 주성분, 같은 그룹 과제의 잔차 평균을 맞춘다. 능선 페널티는 1e-06 고정이고 이득은 20,000쌍 재표집으로 평가하며, 기준은 3/3/3/2/2 크기의 600,600개 분할 전체다.
- 인간 코호트 비교: SRO에서 인간 그룹화 대비는 δH = .158, 모델은 δM = −.022로 차이 .180 [−.102, .371]가 0을 포함한다. 모델의 작업 기억 상관 .076(인간 .317)은 신뢰도 탓이 아니다(모델 신뢰도 0.972 이상). Ball 코호트는 DRM 채점에 따라 달라진다(네이티브 오경보 채점 .249 [.064, .402], 풀링 균형 정확도 .493 [.195, .704]). 두 코호트를 더 보면 6개 과제쌍 중 5개에서 모델 상관이 인간을 넘고, 유의한 것은 DS–ST(.44 대 .06)뿐이다.
- 상수 판돈 주의: 상수 판돈 모델의 높음 빼기 낮음 정확도는 0이 아니라 정의되지 않은 값이다. 본 실험의 1-또는-2-사탕 라벨은 반균형화되지 않았고, 재실험의 두 A/B 라벨 지도에서 51개 중 30개 모델이 판돈의 90% 이상에서 같은 문자를 골랐다.
