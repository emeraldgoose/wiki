# REA: asynchronous brain-cerebellum control을 위한 routed embodied agent runtime

**원문**: [arXiv:2610.42053](https://arxiv.org/abs/2610.42053) · **게시일**: 2026-10-27
**저자**: Pengfei Zhou, Yixing Ma, Zhengfeiyang Zhang, Haoyuan Chen, Zhenglin Wan, Hexin Wang, Wangbo Zhao, Yang You

## 개요

foundation model은 high-level reasoning에 강하지만 fine-grained control에는 너무 느리다. VLA와 같은 reactive policy는 빠르지만 generalization에 약하다. REA는 deliberative brain(system 2)과 reactive cerebellum(system 1)을 asynchronous architecture로 combine하는 Routed Embodied Agent runtime이다.

핵심 아이디어는 brain이 policy를 offline으로 준비하고 online에서는 필요한 경우에만 intervene하여 running policy가 wait하지 않게 하는 것이다. REA는 three-level runtime와 route memory, boundary-triggered judge gate, shared-budget escalation ladder를 포함한 embodied router를 구현한다.

## 핵심 내용

- agent- 및 VLA-based system을 simulator 전반에서 common contract로 unify한다.
- deliberative reasoning과 reactive policy execution을 separate한다.
- brain(system 2)와 policy를 asynchronous으로 실행한다.
- intervention을 coordination하기 위한 embodied router를 사용한다.
- LIBERO-Pro의 3,000 test episode에서 95.9% success를 보고한다.
- 강한 baseline 대비 routing과 control-time efficiency를 개선한다.
- 세 simulator와 real robot을 across evaluate한다.

## 상세

runtime은 agent, VLA, programmatic policy를 across comparability를 높이도록 design되었다. slow model이 빠른 control loop를 block하지 않고 online advice할 수 있으므로 asynchronous execution이 중요하다.

router의 escalation ladder, route memory, judge gate는 slow assistance가 latency 가치가 있을지 결정하려는 의도다. empirical result는 large multi-task suite에서 near-oracle performance를 less control time으로 달성한다.
