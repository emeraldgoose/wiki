# DNeo: 병렬 드래프트 모델에는 더 나은 타깃 특징 인코딩이 필요하다

**Source**: [arXiv](https://arxiv.org/abs/2611.21925)
**게시일**: 2026-11-16

## Overview

Speculative-diffusion 디코딩은 작은 병렬 drafter가 한 번의 순전파로 b개의 드래프트 토큰을 생성하고, 더 큰 타깃 모델이 이를 병렬 검증한다. 여러 드래프트 토큰이 동시에 검증을 통과할 때 더 빠른 추론이 가능하다. 최근 병렬 drafter(DFlash, DSpark)는 타깃이 계산한 풍부한 특징에 조건화해 드래프트 품질을 높이는데, 이를 feature encoding이라 한다. 그러나 표준 feature encoding에는 세 가지 한계가 있다: (1) 손실적 — 인코딩 투영이 residual mixing이라 불리는 발견된 효과를 통해 타깃 특징 공간을 파괴한다, (2) 무기억 — 이전에 처리된 제안(proposal)의 기록이 없다, (3) 타깃의 모든 레이어를 균일하게 표집해 중요한 hidden state를 빠뜨린다.

DNeo는 이를 해결하기 위해 Mixture-of-Features Attention(MoFA)을 제안한다. 이전에 거부된 제안을 인코딩하는 작업 기억을 갖춘 경량 feature-encoding 방식으로, 여기에 2-tap causal convolution, prefix-only cross-attention, 융합 causal head, 비균일 타깃 레이어 선택(DNeo 프로토콜, 타깃의 맥락이 풍부한 후반부를 격리)을 더했으며 drafter 용량은 그대로다. DNeo는 drafter 용량과 생성 품질에 영향 없이 SoTA(DFlash-2)보다 1.3배 빠른 생성 속도를 달성한다. 모델 가중치와 추론 코드가 공개됐다.

## Key points

- 디코딩 속도(Qwen3-4B 타깃, 증류로 학습한 drafter): DNeo는 차선책(DFlash-2)보다 최대 +20.7% 빠르고 temperature 1에서는 항상 가장 빠르다. SoTA 병렬 drafter 대비 최대 +25.1% τ이며, temperature 1에서는 SoTA AR drafter EAGLE-3의 τ도 넘어선다(최대 +21.0% τ) — draft tree 없이 달성한 τ 향상이다.
- 왜 빠른가: 속도 향상은 τ와 라운드 비용의 곱이다. EAGLE-3가 temperature 0의 네 벤치마크에서 DNeo의 τ를 앞서지만 그곳에서도 DNeo가 1.15–1.34배 빠르다(한 번의 순전파로 병렬 드래프트). 병렬 drafter와 비교하면 DNeo는 τ 이득이 더 비싼 causal head 비용을 상회할 때 이긴다 — T=1의 모든 벤치마크(+32–40% τ vs DFlash), T=0의 수학·코드(+17–19%)에서 이기고 GPQA/MT-Bench T=0(+10–12%)에서는 못 이긴다.
- 처리량: B=32에서 DFlash-2(Transformers serving)보다 최대 +58% 높은 tokens/sec. Transformers serving에서 격차가 벌어지는 이유는 DNeo의 라운드가 더 싸기 때문(더 가벼운 prefix-only backbone). 배치 64에서 AR과 처리량 동등(0.1% 이내)을 유지하는 유일한 drafter — 다른 drafter들은 10–18% 아래로 떨어진다.
- 절제 실험: MoFA는 dense encoding 대비 TPF +0.6, rejection memory(거부된 드래프트에 대한 cross-attention)는 무기억 drafter 대비 TPF +0.17, DNeo 프로토콜(비균일 레이어 선택)은 균일 간격을 상회, 융합 DNeo causal head(두 공통 head를 잠재 공간에서 결합)는 각각 단독보다 우수, prefix-only attention은 backbone을 경량화.
- H100에서 배치 크기 1–64, 여섯 벤치마크 전반에 걸쳐 throughput–speed Pareto 프런티어를 지배한다.

## Details

- 구성 요소: MoFA feature encoding(타깃 레이어들의 혼합, 구조 보존), rejection memory(거부된 제안의 작업 기억), 2-tap causal convolution, DNeo causal head(잠재 공간 융합), prefix-only cross-attention, 타깃 레이어 선택을 위한 DNeo 프로토콜.
- 설정: Qwen3-4B용 증류; 벤치마크는 수학·코드·GPQA·MT-Bench 등; temperature 0과 1; SGLang과 Transformers로 serving; 배치 1–64.
