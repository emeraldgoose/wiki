# 정책 동기화 언어-행동 이중 부트스트래핑을 통한 내비게이션의 데이터 중심 재귀적 자기 개선

출처: Songze Li 외 13인, arXiv:2610.15782, 2026-10-11.

**핵심 요약**: 비전-언어 내비게이션은 자연어 지시를 따라 목표 위치에 도달해야 하므로 고품질 언어 감독이 필수입니다. 사람 주석은 비싸서 확장 가능한 데이터 합성이 연구됐지만, 기존 방법은 내비게이션과 지시 생성을 별도 모델로 두거나 과제별 구성요소로 결합하며, 갱신 전에 고정 모델로 전체 궤적 코퍼스를 주석해 **생성 감독이 진화하는 정책보다 뒤처지는** 문제가 있습니다.

## RSI-Nav

**RSI-Nav**는 정책 동기화 언어-행동 이중 부트스트래핑을 통한 데이터 중심 재귀적 자기 개선 프레임워크입니다. 비전-언어→행동 지시 수행과 비전-행동→언어 지시 생성을 **하나의 공유 모델** 안에서 통합합니다. 지도 미세조정으로 기본 능력을 세운 뒤, 라벨 없는 궤적을 **작은 샤드**로 나눠 점진 처리합니다. 현재 모델이 샤드의 지시를 생성하고, 실행해 목표 달성과 경로 효율을 평가하고, 합격 샘플을 남긴 뒤 **다음 샤드 전에 즉시 자기 갱신**합니다. 이 샤드 단위 갱신이 새 감독을 현재 정책에 맞춥니다. 공간 추론이 내비게이션에 도움이 되므로 공간 이해 데이터도 넣습니다.

## 결과

R2R-CE에서 **68.6% SR**, RxR-CE에서 **72.4% SR**을 기록했고, 더 강한 지시 생성 유용성과 재귀 진화 후 공간 이해의 완만한 개선을 보였습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 자기 생성 지시를 자기 평가하는 루프는 편향과 붕괴 위험이 있습니다. 샤드 크기, 합격 기준, 공간 데이터 비율, 실제 로봇 환경 전이는 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 합성 감독을 만들 때 전체 데이터를 한 번에 라벨링하지 말고, 현재 정책으로 조금씩 생성·평가·갱신하세요.
- 지시 생성과 수행을 같은 모델에 두면 두 능력의 정렬이 좋아지지만, 평가 기준을 외부에 고정해야 붕괴를 막을 수 있습니다.
- 샤드 단위 파이프라인은 실패 시 롤백과 재현이 쉬운 운영 패턴입니다.
