# 필요할 때만 보기: 효율적 diffusion VLM을 위한 인증 기반 시각 라우팅

출처: Donghyeon Cho 외 3인, arXiv:2610.36671, 2026-10-27.

**핵심 요약**: Diffusion VLM(DVLM)은 denoising 단계마다 전체 입력을 처리하고, 연구한 벤치마크에서 visual token이 입력의 **89–97%**를 차지해 대부분의 디코딩 계산이 같은 이미지를 반복 처리하는 데 쓰입니다. visual token pruning은 일부 시각 토큰을 제거해 부담을 줄이지만 제거된 정보를 잃고 나머지 이미지를 매 단계 계속 처리합니다. 이미지가 실제로 얼마나 필요한지 측정하기 위해 저자들은 LLaDA-V의 예측을 매 디코딩 단계에서 이미지 있을 때/없을 때 비교해, 이미지 제거가 unmask되는 토큰을 바꾸는 경우가 평균 **22.8%**, 최소 **7.9%** 단계뿐임을 찾았습니다. 저자들은 매 단계 이미지를 처리할지와 unmask할 토큰 수를 결정하는 **LOWN**이라는 디코딩 방법을 제안합니다. LOWN은 이미지 없이 masked token을 예측하고, 이 예측이 마지막 이미지 조건 예측과 **불일치**할 때만 이미지를 처리합니다. 일치하면 이전 예측을 재사용할 수 있도록 인증하고, 인증된 토큰 수는 해당 단계에서 unmask할 토큰 수를 정합니다. 벤치마크마다 이미지 필요성이 다르기 때문에 고정 스케줄이 아니라 LOWN의 적응적 결정이 필요합니다. 훈련이나 튜닝된 threshold 없이 LOWN은 10개 벤치마크에서 **99.6% 점수를 평균 35.3% 디코딩 FLOP**으로 유지했고, LLaDA 기반 DVLM 전반에 일반화되며 visual token pruning과 직교적으로 조합되고 KV caching으로 더 가속됩니다.

## 핵심 내용

- 연구 벤치마크에서 visual token이 DVLM 입력의 89–97%를 차지한다.
- 이미지 제거는 평균 22.8%, 최소 7.9% 단계에서만 unmask 선택을 바꾼다.
- LOWN은 image-free 예측과 image-conditioned 예측 불일치 시에만 이미지를 처리한다.
- 일치는 이전 예측의 재사용 인증과 unmask 수 결정으로 이어진다.
- 이미지 필요성은 벤치마크마다 달라 적응이 필요하다.
- 훈련 없이 10개 벤치마크 점수 99.6%를 평균 35.3% FLOP으로 유지했다.
- pruning과 KV caching과도 조합 가능하다.

## 상세

visual token pruning은 나머지 이미지를 매 단계 계속 처리하지만 LOWN은 예측 일치 시 이미지를 완전히 건너뛸 수 있습니다. 인증 메커니즘은 시각 정보를 영구히 버리기보다 검증된 이미지 조건 예측을 재사용합니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 인증 규칙과 LLaDA-V 평가 세부는 원문을 함께 확인해야 합니다.
