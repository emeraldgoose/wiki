# 이질적 방향 변량 인코딩을 이용한 임상 뇌 MRI 유연 다중 스택 초해상화: 나이지리아 코호트에서의 전문의 판독 평가

**게시일**: 2026-11-16 (arXiv v1 제출일)

## 개요

고해상도 등방성 뇌 MRI는 신경방사선학적 판독에 중요하지만, 일상적인 임상 프로토콜은 특히 자원이 제한된 환경에서 빠른 비등방성 2D 촬영에 의존하는 경우가 많습니다. 이러한 촬영은 방향, 정렬, 해부학적 커버리지가 서로 달라 부분적으로 겹치는 영상 스택을 만들어 냅니다. 기존의 학습 기반 초해상화 방법은 일반적으로 단일의 제약이 부족한 입력이나, 이상화된 촬영 기하를 가정한 고정된 다중 스택 구성에 의존합니다.

이 논문은 유연한 다중 스택 뇌 MRI 초해상화를 위한 시퀀스 독립적 프레임워크 MS-HVED를 소개합니다. 사용 가능한 축상·관상·시상 스택을 각각 독립적으로 인코딩하여 다중 스케일 가우시안 사후분포를 만들고, 시야(FOV)를 인식하는 Product-of-Gaussians(PoG) 방식으로 융합하여 지원되지 않는 영역의 기여를 제한합니다. 물리 기반 도메인 무작위화는 경사 촬영, 부분 커버리지, 영상 아티팩트 등 이질적인 실제 임상 촬영 조건을 시뮬레이션합니다.

합성 벤치마크를 넘어, 저자들은 의료 영상 연구에서 과소대표된 집단인 나이지리아 코호트의 일상 뇌 MRI 30건을 대상으로 외부 임상 검증을 수행했습니다. 이 검사들은 44개의 실제 사례와 7명의 전문 신경방사선학자가 참여한 맹검 판독 연구의 가장 큰 구성 요소였으며, 전참조 지표만으로는 알 수 없는 실제 임상 영상 품질에 대한 근거를 제공합니다.

## 핵심 내용

- MS-HVED는 추론 시 {축상, 관상, 시상} 비등방성 스택 중 임의의 비어 있지 않은 부분집합으로부터 재구성할 수 있으며, 한 개 이상의 방향이 누락되어도 재학습이나 구조 변경이 필요 없습니다. 방향별 FOV 마스크가 복셀 단위로 각 스택의 정밀도 기여를 조절합니다.
- 물리 기반 도메인 무작위화로 촬영 기울기, 부분 시야, 아티팩트를 모델링하여 이상화된 격자가 아닌 실제 임상 촬영 기하에 대해 융합의 강건성을 확보했습니다.
- 합성 벤치마크에서 MS-HVED는 경쟁력 있거나 우수한 재구성 충실도를 달성했고, 저해상도 입력 대비 하위 조직 분할 성능도 향상되었습니다.
- 나이지리아 외부 검증 코호트에서 MS-HVED는 전체 영상 품질에 대해 지도 학습 기준선보다 210건의 쌍대 평가 중 187건에서 선호되었습니다.
- 모든 임상 코호트를 합쳐 전체 품질 점수에서 MS-HVED가 모든 입력을 사용했을 때 더 높았고(5.93 대 4.49, p<.001), 축상 또는 관상 입력을 생략한 경우에도 선호가 유지되었습니다(p<.001).

## 상세

**방법.** 사용 가능한 각 방향은 독립적인 변량 인코더로 처리되어 잠재 다중 스케일 가우시안 사후분포 파라미터를 예측합니다. 방향별 사후분포는 다중 스케일 Product-of-Gaussians로 복셀 단위 융합되며, 방향별 FOV 마스크가 각 스택의 정밀도를 공간적 범위에 따라 가중합니다. 융합은 사용 가능한 방향 집합에 대해 정의되므로, 동일한 네트워크가 O ⊆ {Ax, Cor, Sag}의 임의의 비어 있지 않은 부분집합을 처리할 수 있습니다. 융합된 잠재 다중 스케일 사후분포에서의 샘플은 공유 초해상화 디코더를 거쳐 등방성 고해상도 볼륨으로 재구성되며, 선택적으로 방향별 디코더가 입력 스택을 재구성합니다. 스펙트럼 정규화된 변량 헤드와 물리 기반 도메인 무작위화가 학습을 안정화하고 이질적인 임상 촬영을 시뮬레이션합니다. 저자들은 전참조 충실도 지표가 모든 재구성 아티팩트를 포착하지 못한다는 점을 한계로 명시하며, 이 점이 전문의 판독 연구의 동기입니다.

**결과.** 정답이 알려진 합성 벤치마크에서 MS-HVED는 기준선 대비 경쟁력 있거나 우수한 재구성 충실도를 보였고, 저해상도 입력보다 하위 조직 분할 성능이 향상되었습니다. 임상 데이터에서는 나이지리아 코호트의 일상 검사 30건을 대상으로 한 외부 검증이 44건의 실제 사례와 7명의 전문 신경방사선학자가 참여한 맹검 판독 연구 안에서 이루어졌습니다. 나이지리아 코호트에서 MS-HVED는 전체 영상 품질에서 210건의 쌍대 평가 중 187건에서 선호되었고, 모든 임상 코호트에서는 전 입력 사용 시 전체 품질이 더 높았으며(5.93 대 4.49, p<.001), 축상 또는 관상 입력이 빠진 경우에도 이 우위가 유지되었습니다(p<.001). 코드는 논문에 안내된 링크에서 제공됩니다(원문 참조).
