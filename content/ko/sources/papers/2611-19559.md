# ResWAM: 무엇이 유지되는가가 아니라 무엇이 변하는가를 학습하는 월드-액션 모델

**Source**: [arXiv](https://arxiv.org/abs/2611.19559)
**게시일**: 2026-11-14

## Overview

월드-액션 모델(WAM)은 비전-언어-액션(VLA) 정책에 미래 프레임 예측을 더해 행동이 물리 세계에 미치는 영향을 정책이 예측하게 만든다. 기존 WAM은 완전한 미래 관측을 감독하지만, 액션 청크 동안 관측은 거의 변하지 않으므로 미래 손실이 과제 관련 로봇·객체 움직임보다 정적 배경 복사에 지배된다. 또한 대형 비디오 생성 모델이나 별도의 월드 모델에 의존해 학습·추론 연산 부담이 커지고 폐루프 배포를 어렵게 한다.

ResWAM은 대신 시각적 잔차 학습을 적용한다. 고정된 DINOv3 공간에서 현재 프레임→미래 프레임의 특징 변화만 감독한다. 잔차 타깃은 더 높은 특징 랭크를 가지며 장면 변화를 더 풍부하고 다양하게 표현하고, 배경이 아니라 로봇 팔과 조작 대상에 공간적으로 집중된다. ResWAM은 총 2.3B 파라미터 모델로, 경량 0.5B 듀얼 브랜치 DiT가 조건부 플로우 매칭으로 액션 브랜치와 잔차 브랜치를 공동 학습하며, 외부 궤적에 대한 로봇 사전학습 없이 동작한다.

## Key points

- 로봇 사전학습 없이 평균 성공률 최고: LIBERO-Plus 81.1%, RoboTwin 2.0 93.8%, RoboDojo 성공률 9.40% / 점수 13.41.
- 비교 방법 중 최저 연산량: 학습 2.7–4.0 TFLOPs, 추론 1.0–1.4 TFLOPs.
- 실로봇 조작(Open, Put, Stack): 평균 성공률 80.0%, π₀.₅ 대비 +10.0%, 92.7 ms 지연.
- 잔차 특징은 완전한 미래 특징보다 유효 랭크가 높고, 정적 배경이 아니라 로봇 팔과 조작 대상에 집중된다.
- 제거 실험: 잔차 브랜치 품질이 정책 성능을 예측; 잔차 예측 품질과 예측 특징의 랭크가 학습 단계에 따라 향상; 조건부 플로우 매칭 기반 듀얼 브랜치 DiT로 액션·잔차 브랜치를 공동 학습.

## Details

- 아키텍처: VLM 백본 + 0.5B 듀얼 브랜치 DiT(액션 브랜치 + 잔차 브랜치), 총 2.3B 파라미터; 비디오 생성 모델이나 별도 월드 모델 불필요.
- 학습: 잔차 브랜치에 조건부 플로우 매칭 적용; 잔차는 현재/미래 프레임을 고정 DINOv3 특징 공간에서 계산; 벤치마크 데모 외 외부 로봇 사전학습 없음.
- 추론: 경량 폐루프 배포 프로파일; 실로봇 환경에서 92.7 ms 지연; FLOPs는 부록 D의 고정 프로토콜로 측정.
- 벤치마크: LIBERO-Plus, RoboTwin 2.0, RoboDojo(시뮬레이션) 및 실세계 Open/Put/Stack 조작; 대형 비디오 생성 기반 WAM, 별도 월드모델 기반 WAM 등과 비교.
- 유의점: 로봇 사전학습 없이 보고된 결과; RoboDojo 절대 성공률은 여전히 낮음(9.40%); 잔차 품질은 고정 DINOv3 공간의 표현력에 의존.
