# WeightCode: 가중치 공간 프로그래밍으로 신경망에 새 능력 설치하기

**원문**: [arXiv:2611.25476](https://arxiv.org/abs/2611.25476) · **게시일**: 2026-11-19 (v1)
**저자**: Bo Li, Taoyong Cui, Bob Zhang, Mengran Li, Chengyang Zhang, Yang Zhang, Pheng Ann Heng, Wanli Ouyang, Zhenfei Yin, Yingcheng Wu, Ling Yang

## 개요

신경망은 능력을 가중치에 저장하지만, 명시적 작업 지식을 더하는 것은 여전히 어렵다. 가중치 공간 프로그래밍(WSP)은 실행 프로그램이 네트워크 가중치를 직접 읽고 만들거나 수정하는 패러다임이다. WSP 프레임워크인 WeightCode는 고정된 언어 모델이 작업 지식과 네트워크의 기존 가중치만으로 학습된 네트워크에 새 계산을 설치하는 실행 가능한 가중치 프로그램을 작성한다. 그라디언트 학습이 없고, 설치 후에는 새 능력이 LLM 없이 독립적으로 실행된다.

로봇류 명령 수행에서 문법이나 8개 시연만 주어진 가중치 프로그램은 이전에 본 적 없는 명령 조합을 0%에서 99.8% 정확도로, 새로운 pickup 동작을 0%에서 98.4% 성공률로 가능하게 하면서 원래 명령과 내비게이션 능력은 유지한다. ImageNet에서는 가우시안 노이즈용 2개, 대비 저하용 2개 — 각각 손상 64장과 깨끗한 64장의 라벨만, 동일한 검사와 유지 규칙 — 4개 프로그램이 ImageNetV2에서 깨끗한 정확도를 0.89%p 이내로 유지하며 순이득 +8.84~+17.62%p를 달성, 미세조정 8개 방법 중 최고(+8.67/+3.38)와 고정 참조를 능가한다. CIFAR-10 ViT-Lite에서는 첫 프로그램들이 +32.79/+16.51로 최고 미세조정(+22.78/+7.89)을 앞선다.

ViT에서 인과적 개입 실험은 설치된 노이즈 교정 게이트가 복원력 이득을 주도함을 보인다(게이트가 깨끗한 입력이 아닌 노이즈 입력에서 열린다).동시에 선택적 활성화가 깨끗한 정확도를 보존한다. 추가 LLM 호출 없이 같은 프로그램을 독립적으로 학습된 5개 ViT에 다시 실행하면 네트워크별 편집이 만들어진다. 10개 프로그램이 평균 83~110%의 이득을 유지(가우시안 노이즈 프로그램 +27.55~+30.54, 평균 +28.57, 깨끗한 변화 −0.19~+0.07)하는 반면, 고정 가중치 편집을 복사하면 무시할 만한 이득밖에 없다. 이미 편집된 네트워크를 위해 작성된 6개 프로그램은 이전에 설치된 노이즈 이득을 유지하면서 대비 복원력을 +5.23~+14.50%p 더 더한다. 즉 재사용 가능한 가중치 프로그램을 통해 능력이 누적된다.

## 핵심 내용

- WSP 패러다임: 실행 프로그램이 네트워크 가중치를 직접 읽고 수정한다. WeightCode의 고정 LLM이 작업 지식 + 기존 가중치로 가중치 프로그램을 작성하며 그라디언트 없이 설치되고 설치 후 독립 실행된다.
- 명령 수행: 문법 또는 8개 시연 → 미학습 명령 조합 0%→99.8% 정확 일치, 새 pickup 동작 0%→98.4% 성공, 원래 능력 보존.
- ImageNet 복원력: 손상당 64장 + 깨끗한 64장 라벨만으로 4개 프로그램이 순이득 +8.84~+17.62%p(가우시안 +10.47/+17.62, 대비 +8.84/+14.26) vs 최고 미세조정 +8.67/+3.38, ImageNetV2 깨끗한 정확도 0.89%p 이내 유지. CIFAR-10 ViT-Lite +32.79/+16.51 vs +22.78/+7.89.
- 메커니즘: 인과 개입으로 기존 MLP 유닛 안에 설치된 게이트가 노이즈 입력에서 열려 노이즈 이동을 제거함을 확인. 선택적 활성화가 깨끗한 정확도를 지킨다.
- 전이: 같은 프로그램을 독립 학습된 5개 ViT에 새 LLM 호출 없이 재실행해도 83~110% 이득 유지. 고정 가중치 편집 복사는 무시할 만한 이득 — 패치가 아니라 프로그램이 전이된다.
-구성: 이미 편집된 네트워크용 6개 프로그램이 노이즈 이득을 유지하며 대비 복원력 +5.23~+14.50%p 추가 — 가중치 프로그램으로 능력 누적.

## 상세

실험 프로토콜은 예시, 검사, 유지 조건을 통제한다. 모든 방법이 동일한 손상 64장과 깨끗한 64장 라벨, 8회 검사, 유지 규칙을 받는다. 교정구성에 조건 라벨이 필요 없다 — 네트워크 예측, 이미지 통계, 라벨된 검사 피드백만으로 충분하다. ablation에서 이득의 원천은 유닛 선택보다 게이트된 계산임이 확인된다. 베이스라인은 동일한 제약하에서 미세조정 8개 방법과 고정 참조. 코드가 공개된다.
