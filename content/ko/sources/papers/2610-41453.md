# 모호한 도구 결과와 부분 실행을 다루는 AI 에이전트의 근거 기반 복구

**원문**: [arXiv:2610.41453](https://arxiv.org/abs/2610.41453) · **게시일**: 2026-10-30
**저자**: Genliang Zhu, Xiaobo Chen, Ziyuan Wang, Chu Wang

## 개요

도구 호출이 시간 초과되면 AI 에이전트는 진짜로 모호한 상태에 놓인다. 해당 작업이 실패했을 수도, 공급자 쪽에 이미 반영되었을 수도, 아직 진행 중일 수도 있는데 다른 워크플로 단계는 이미 끝난 뒤다. 워크플로 전체를 다시 실행하면 이중 청구나 중복 알림 같은 되돌릴 수 없는 효과가 겹칠 수 있고, 멈추면 정당한 의무가 이행되지 않은 채 남는다. 논문은 이를 근거 기반 작업 복구로 정식화한다. HTTP 오류를 아무 일도 없었다는 증명으로 취급하는 대신, 승인된 의무와 공급자가 선언한 능력, 공개 기록과 양립 가능한 상태 위에서 추론하도록 만든다.

설계의 중심에는 두 장치가 있다. 첫째는 공유 허용성 검사로, 제안된 모든 행동을 키 만료, 인가 시점, 의존 관계, 잔여 효과 기준으로 실행 전에 걸러낸다. 둘째는 종료 인증서로, 실제 개인적 목표 달성과 공개적으로 뒷받침되는 안전한 완료를 분리하고 미지와 인계 상태를 명시적으로 남긴다. 보증은 제3자의 정확히 한 번 실행을 가정하는 것이 아니라 선언된 공급자 능력에 묶인다. 구현은 관찰 의존적 계획과 별도 구현된 효과 이력 심판기를 짝지었다.

실증 작업은 두 부분이다. 37개 과제에 대해 다섯 정책을 비교하는 유한 연구와, 두 로컬 모델에 대해 모델용 계획 조언이 복구를 돕는지를 묻는 사전등록된 과제 홀드아웃 비교이며, 기록된 116개 궤적 전부가 독립적으로 리플레이되었다.

## 핵심 내용
- 37개 과제에서 계획과 세 가지 능동 대조(검증-대기 규칙, 능력 규칙, 탐욕 선택)가 각각 28건의 안전한 완료를 인증했고, 즉시 중지는 시작 시점에 이미 만족 가능한 2건만 인증했다.
- 어느 정책도 복구 과정에서 새로 만든 불변식 위반이나 거짓 완료 주장이 없었고, 과제당 3개는 처음부터 절대적 과거 위반을 안고 있었다.
- 완료 수가 같아도 자원 거래가 다르다. 공동 계획은 합성 비용 단위 188과 논리 행동 103을 쓰는데 능력 규칙은 192와 105로, 4개의 비용 단위와 2개의 행동을 아끼는 대신 9.585초의 추가 선택 계산을 치른다.
- 사전등록된 과제 홀드아웃 연구에서는 19개 과제군의 58쌍을 두 로컬 모델 openai/gpt-oss-20b와 zai-org/glm-4.7-flash로 공유 방패 아래에서 실행했다.
- 계획 조언은 58쌍 중 30건을 인증한 반면 증거 프롬프트는 9건에 그쳤다. 차이는 36.2퍼센트포인트(과제군 부호 뒤집기 정확 검정 p = 0.0078)이고, 21쌍은 조언으로만, 9쌍은 둘 다로, 28쌍은 어느 쪽으로도 완료되지 않았다.
- 조언은 자원도 덜 썼다. 제안은 272회 대 399회, 관측된 프롬프트·완성 토큰은 202,508 대 282,293이었고, 기각된 안전하지 않은 제안은 317에서 123으로, 거짓 완료 주장은 218에서 76으로 줄었다.
- 116개 궤적 전부가 독립 파이썬 리플레이를 통과했고, 두 모델 모두 조언 조건에서 완료 차이가 양수였다.
- 고정된 설정은 온도 0, 입력 상한 2,048토큰, 출력 상한 96토큰, 추론 예산 128, 에피소드당 최대 8개의 모델 제안이었다.
- 조언 조건은 허용된 행동 101개를 실행한 반면 증거 프롬프트는 34개에 그쳤고, 두 조건 모두 네 개의 에피소드는 모델 호출 없이 이미 인증 가능했다.

## 세부 사항

### 복구 문제의 정식화
각 과제는 승인된 의무, 계약이 선언한 공급자 능력, 에이전트가 관찰할 수 있는 공개 이력으로 정의된다. 공통 행동 검사는 키 만료, 인가 시점, 의존 관계, 잔여 효과를 모든 조건에서 똑같이 처리하므로, 새로운 위반이 0이라는 결과는 특정 계획기가 아니라 공유 실행 계약에 돌려진다. 인증은 미래 효과 접두사를 시간이 같은 직렬화까지 포함해 모두 검토한다. 복구 후 복원 쓰기가 뒤따르는 보상은 기각되고, 유한한 같은 값 대체는 인증 가능하며, 지연이 미지인 감시 대기는 미해결로 남는다.

### 1부: 37개 과제의 다섯 정책
결정론적 프레임은 20개 합성 템플릿과 독립 심판기를 사용한다. 공동 계획은 비용 단위 188과 논리 행동 103, 능력 규칙은 192와 105, 검증-대기 규칙은 191과 106, 탐욕 선택은 비용 단위 195에 행동 94로, 어느 팔도 모든 자원 척도를 지배하지 않는다. 각 능동 팔은 여섯 개의 인계와 세 개의 미해결 과제를 남긴다. 순차적 깊이 우선 계획기가 28이 아닌 27개 완료를 낸 이전 수집본은, 완성된 탐색 층을 하나의 목표 아래 비교해야 하는 이유를 보여준다. 그 계획기는 놓친 퇴직 과제에서 반복적으로 기다렸고 마감까지 대체 이행을 활성화하지 못했다.

### 2부: 사전등록된 모델 비교
홀드아웃 축은 잠재 과제다. 여덟 과제 파일럿 이후 남은 29개 과제 전부가 두 모델과 두 전략에 투입되어 116개 에피소드와 58쌍을 만든다. 증거 프롬프트 조건은 공개 복구 근거와 행동 스키마를 보여주고, 조언 조건은 여기에 경계가 있는 계획기의 다음 행동 추천을 추가한다. 모델이 여전히 행동을 제안하고 공유 방패가 허용성을 결정한다는 점은 같다. 조언은 58쌍 중 30건(51.7%)을 인증한 반면 증거 프롬프트는 9건(15.5%)이었고, 허용 행동은 101개 대 34개, 제안은 399회에서 272회로 줄었다. LM Studio 기반 번들 두 개 모두 인터페이스 오류나 출력 잘림 없이 고정 프레임 전체를 완주했다.

### 적용 범위와 한계
이 비교는 공유 방패 아래에서 평가된 조언 인터페이스를 측정할 뿐, 탐색 기반 조언과 규칙 기반 조언을 인과적으로 분리하지 않으며, 규칙 유도 조언과 적법 행동 목록 인터페이스는 모델 조건이 아니었다. 합성 비용 단위, 논리 행동, 논리 시간은 화폐 가격과 실제 지연과는 별도로 보고되고, 선택 벽시계 시간은 계산 대리 지표일 뿐이다. 네이티브 영속성은 여덟 실행기 사례로 자격을 확인했고, Atomix 데모와 UndoBench 스모크 실행은 모델 기준선이 아니라 파이프라인 자격 확인으로 유지된다.
