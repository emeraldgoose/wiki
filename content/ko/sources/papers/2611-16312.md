# Alloy: 로봇 학습을 위한 다중 재질 물리 엔진

**원문**: [arXiv:2611.16312](https://arxiv.org/abs/2611.16312) · **게시일**: 2026-11-12
**저자**: Pranay Gupta, Deepanshu Rohilla

## 개요

쓸모 있는 로봇의 일거리는 강체가 아닌 것들 — 수건, 케이블, 물, 모래 — 이 많다. 그러나 로봇을 대규모로 학습시키는 시뮬레이터는 강체에 가장 강하고, 다른 재질을 더하려면 보통 두 번째 엔진과 손으로 쓴 연결 코드, 손으로 고른 타임 스텝, 조용히 망가진 세계를 걸러내는 자체 검사까지 만들어야 했다. Argon Robotics의 Alloy는 강체 로봇, 천, 케이블, 액체, 입상 재질, 소프트바디를 한 씬에 담는 로봇 학습용 오픈소스(Apache-2.0, `pip install alloy-engine`) 물리 엔진이다. Newton, MuJoCo Warp, Warp 위에 만들어졌고, 하나의 GPU(또는 CPU)에서 수천 개의 평행 세계를 돌리며, 새로운 사용자인 코딩 에이전트를 위해 명시적으로 설계됐다.

객체는 하나의 파이썬 인터페이스로 한 번만 기술한다. 라우터가 재질에 맞는 솔버를 배정하고 그 이유를 기록한다. 솔버들은 프록시 바디를 통해 모든 제어 스텝 안에서 자세와 접촉력을 주고받으며, 스텝 크기는 인터페이스 강성에서 정해지고 필요하면 세계별로 조정된다. 모든 평행 세계는 OK·DEGRADED·INVALID의 건강 등급을 받고, INVALID 판정 세계는 나머지가 계속 도는 동안 동결되어 물리 실패와 정책 실패를 구별할 수 있다. 에이전트를 위해 문서는 패키지 안에 들어 있고, 모든 오류 메시지는 수정 방법을 알려 주며, JSON을 말하는 CLI와 Model Context Protocol 도구 서버로 엔진이 노출된다.

핵심 증거는 콜드 테스트다. Claude Opus 5.5 코딩 에이전트의 독립 세션 8개가 각각 L4 GPU 하나를 단 새 가상머신에서 패키지가 제공하는 것만 읽고 패키지 인덱스에서 프리릴리스를 설치하고, 학습·평가 코드를 직접 쓰고, 동작하는 정책을 학습시켰다.

## 핵심 내용

- 콜드 에이전트 결과(alloy-engine 0.1.0rc2, L4 한 장, 행당 학습 1회, 윌슨 95% 구간): Unitree Go2 보행은 PPO 4.1분 학습(4,096 세계)으로 보류 성공 97%(497/512)를 달성했다. 같은 정책을 학습 중 최대 113N보다 센 150N·0.1초 밀침에도 두 시드에서 252·248/256회(97–98%) 버텼다.
- 케이블 들올리기(시험자가 만든 과제): 1,024 세계 PPO에서 약 15분 만에 94.5%, 약 30분 만에 95.7%. 출고 환경 따르기: 38.5분 학습 후 92%(118/128). 에이전트가 직접 만든 컵 따르기 과제는 두 번째 보상 버전에서 약 70분 만에 보류 256/256으로 75% 충전 기준을 통과했다.
- 모방 학습: 256 세계에서 수집한 스크립트 시연 1,000개로 3층 신경망을 66초 만에 행동 복제로 학습해 보류 픽앤플레이스 256/256 성공.
- L4 한 장에서 처리량은 세계 수와 함께 늘어난다. Franka Panda 씬은 1→64 세계에서 약 39배, 면 시트는 약 20배, 200ml 따르기는 약 13배, 상자에 떨어지는 물건 3개는 1→512 세계에서 약 377배가 됐다.
- 영상 기반 학습을 위한 렌더링: L4 한 장에서 1,024 세계 기준으로 64×64 깊이 이미지를 초당 70,786장, 128×128에서 16,111장, 256×256에서 4,133장 렌더링한다. 분할을 추가해도 비용 변화는 1% 미만이다.
- 물리 정확성은 닫힌형 해와 대조 검증한다. 강체 운동과 마찰, 봉의 굽힘·비틀림·처짐·좌굴, 정지 액체의 압력, 소프트 솔리드의 응력 등 10개 선별 검사를 실행 전 정해둔 허용오차와 비교했다.
- 신뢰성: 1,024개 세계에 5cm 블록 10개를 최대 0.5mm 위치 차이로 쌓고 5초 시뮬레이션한 결과, 강체 설정 3단계 모두에서 두 번의 독립 실행에서 오류 0개였다(오류 = 블록이 1cm 초과 이동·침하 또는 비유한 값 발생).

## 상세

논문은 Alloy를 로봇 학습용 강체 엔진(MuJoCo, MuJoCo Warp, Isaac Lab, ManiSkill3)과 별도 프로그램으로 존재하는 재질별 솔버 사이에 위치시키고, '카드'로 쓰는 씬 기술, 이유를 기록하는 라우팅, 결합, 스텝 크기 선택, 건강 등급, 다중 세계·카메라·로봇 실행, 에이전트용 인터페이스(패키지 내 문서, JSON CLI, MCP 도구 서버)를 설명한다. 콜드 테스트 프로토콜은 학습과 다른 무작위 시드의 보류 에피소드에서 시험자가 쓴 스크립트로 원시 시뮬레이터 상태에서 성공을 판정했고, 보행·케이블 행의 평가 에피소드 중 INVALID 판정은 없었다. 저자들은 인터페이스가 아직 바뀔 수 있는 초기 0.x 릴리스이며 알려진 한계를 공개 목록에 두고 있다고 분명히 밝힌다.
