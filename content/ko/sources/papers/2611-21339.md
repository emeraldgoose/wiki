# MovieRoll: 장편 비디오 롤아웃을 위한 체계적 프레임워크

## 개요

스트리밍 비디오 생성은 훈련 지평을 넘어서도 품질을 유지해야 하며, 자체 생성한 과거(히스토리)와 커지는 캐시 비용을 처리해야 한다. Peking University, Tencent Hunyuan, HKUST가 공동으로 제안한 MovieRoll은 스트리밍 미세 조정, 장기 롤아웃 증류, 장기 지평 추론을 하나의 파이프라인으로 연결한 베이스→증류(base-to-distilled) 프레임워크로, 이벤트 단위로 이어지는 분 단위 영상을 생성한다.

먼저 Window-wise Teacher Forcing(WinTF)으로 견고한 다단계 베이스 모델을 만든다. WinTF는 각 청크를 진행적 노이즈 수준에서 동시에 노이즈 제거하며, 윈도우 내부에서는 양방향 어텐션을, 이전 히스토리에는 인과적 접근을 사용한다. 효율적인 히스토리 유지를 위해 계층적 KV 캐시 압축(HieraKV)을 적용한다. 이는 계층별 어텐션 패턴을 활용해 얕은 계층에는 전체 히스토리를, 깊은 계층에는 sink+최근 히스토리를 유지하며, 캐시 메모리를 최대 78% 절감하면서 생성 품질을 오히려 높인다.

이 베이스 위에서 누적 장기 튜닝 기반 분포 매칭 증류(CuLT-DMD)를 적용한다. 긴 자체 롤아웃 동안 파라미터를 고정한 채 국소 기울기를 평균 낸 뒤 한 번에 업데이트하므로, 각 업데이트가 여러 시간 위치의 감독을 결합하면서도 하나의 국소 계산 그래프만 유지한다. 훈련 지평을 넘어서는 생성에는 KV 재계산으로 두 모델의 컨텍스트를 제한하고, AnnealCFG(guidance annealing)로 깨끗한 종점에 가까워질수록 guidance를 낮춰 MovieRoll-Base를 안정화한다. FBCA 어텐션과 PS-VAE 디코딩이 효율적 훈련과 스트리밍 출력을 뒷받침한다.

HeliosBench에서 MovieRoll-Base는 최대 15초 영상으로 훈련했음에도 30초에서 경쟁력을 유지하고, MovieRoll-Distilled는 단일·다중 이벤트 평가 모두에서 최대 60초까지 비교 방법 중 최고 총점을 기록하며, 지속적인 자연스러움과 활발한 모션을 결합한다.

## 핵심 내용

- Window-wise Teacher Forcing(WinTF): 진행적 노이즈 수준의 청크를 동시 노이즈 제거, 윈도우 내부 양방향 어텐션 + 인과적 히스토리 접근.
- HieraKV: 계층별 KV 캐시 압축 — 얕은 계층 전체 히스토리, 깊은 계층 sink+최근 유지. 캐시 메모리 최대 78% 절감과 품질 향상.
- CuLT-DMD: 분포 매칭 증류 기반 누적 장기 튜닝. 긴 자체 롤아웃 중 파라미터 고정, 국소 기울기 평균, 업데이트당 하나의 국소 계산 그래프 — 소수 스텝 생성기의 장기 롤아웃 훈련을 가능하게 함.
- 장기 지평 추론: KV 재계산으로 두 모델의 컨텍스트 제한, AnnealCFG로 깨끗한 종점 방향 guidance를 점차 감소시켜 안정화.
- 시스템 지원: Flash Block-wise Causal Attention(FBCA), 병렬 스트리밍 VAE 디코더 PS-VAE.
- 결과: MovieRoll-Base는 ≤15초 훈련 후 30초에서도 경쟁력 유지, MovieRoll-Distilled는 HeliosBench 최대 60초 평가에서 최고 총점.
- 프로젝트 페이지·코드·가중치가 공개되어 있다 (Tencent-Hunyuan/MovieRoll, huggingface.co/yunyangge/MovieRoll).

## 상세

**방법.** MovieRoll은 점진적으로 증가하는 노이즈 수준에서 잠재 청크의 롤링 윈도우를 함께 노이즈 제거한다. 완전히 노이즈 제거된 청크는 즉시 방출되고 KV 상태는 이후 생성을 위해 캐시된다. 윈도우 내부는 양방향, 이전 히스토리에는 인과적으로 어텐션한다. WinTF는 깨끗한 히스토리와 이벤트 프롬프트에 조건화된 병렬 윈도우 감독으로 MovieRoll-Base를 훈련한다. HieraKV는 측정된 어텐션 패턴에 따라 계층별 캐시 예산을 배분한다. ODE 초기화 후 CuLT-DMD가 베이스를 소수 스텝 생성기로 증류한다 — 긴 자체 롤아웃 동안 파라미터를 동결하고 시간 위치별 국소 기울기를 누적·평균한 뒤 단일 업데이트를 적용해, 롤아웃 전체에 역전파하는 메모리 비용을 피한다. 추론 시에는 히스토리 임계값 또는 프롬프트 전환 시점에 KV 캐시를 재구성해 두 모델의 컨텍스트를 제한하고, AnnealCFG가 베이스 모델 노이즈 제거 과정에서 guidance를 점차 낮춰 장기 드리프트를 억제한다. FBCA(블록 단위 인과 어텐션 커널)와 PS-VAE(병렬 스트리밍 VAE 디코더)가 훈련 및 스트리밍 출력 효율을 완성한다. 스트리밍 비디오 프롬프트 재작성 스킬과 임계값 기반 KV 재계산이 외삽과 인터랙티브 프롬프트 변경을 처리한다.

**결과.** 최대 15초 영상으로 훈련한 MovieRoll-Base는 HeliosBench 30초 구간에서도 경쟁력을 유지한다. MovieRoll-Distilled는 단일 이벤트와 다중 이벤트 평가 모두에서 최대 60초까지 비교 방법 중 최고 총점을 기록하며, 연속된 이벤트 프롬프트 전반에 걸쳐 피사체 정체성과 자연스러운 모션을 유지한다(그림 1은 10초마다 새 프롬프트로 여섯 이벤트에 걸쳐 동일 인물의 연속성을 보여 준다). HieraKV로 캐시 메모리를 최대 78% 절감하면서 품질이 향상된다.
