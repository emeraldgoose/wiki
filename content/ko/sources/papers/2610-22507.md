# RealCLI: CLI 에이전트의 human-agent collaboration을 위한 통합 평가

**원문**: [arXiv:2610.22507](https://arxiv.org/abs/2610.22507) · **게시일**: 2026-10-15
**저자**: Yunqi Liu et al.

## 개요

CLI 에이전트는 점점 longer-horizon 과제를 수행하지만, 기존 벤치마크는 user instruction이 실행 내내 고정된다고 가정하거나 runtime collaboration quality를 반영하지 않은 최종 결과만 평가한다. REALCLI는 현실적 CLI task에서 과제 실행과 human-agent collaboration quality를 통합 평가한다.

## 핵심 내용

- 과제 실행과 collaboration quality를 함께 평가하는 paired benchmark REALCLI를 제시한다.
- collaboration을 5개 차원, 22개 sub-dimension, 51개 interaction scenario template로 측정한다.
- REALCLI-EXEC는 완전한 사양을 upfront로 주고, REALCLI-COLLAB은 progressive information, correction, constraint revision, authorization decision을 제공하는 scripted user를 둔다.
- 최고 구성도 평균 49.2%에 그치고 joint collaboration score는 37.6%가 최고다.
- task effectiveness와 collaboration quality가 크게 diverge하고, steerability, trust calibration, safety boundary management에서 모델이 약했다.

## 상세

과제 성공만으로는 부족하다: collaboration quality가 뒤처지며 steerability/trust calibration/safety 관리 약점이 드러난다.
