# DexDuet: 학습된 연락 보존 bimanual dexterity 학습

**원문**: [arXiv:2611.30495](https://arxiv.org/abs/2611.30495) · **게시일**: 2026-11-23 (v1)
**저자**: Haoran Zhang, Haokai Ding, Han Zhou, Zuxing Lu, Heng Zhang, Xingxing Zuo

## 개요

인간은 양손으로 물체를 다룬다. 한 손이 물체의 어느 부분을 붙잡고(접촉) 다른 손이 조작하면, 로봇도 같은 구조로 해야 한다. 그러나 로봇 손은 인간 손과 크기, 관절학적 특성, 구동 방식이 달라 데모를 그대로 재생할 수 없다. 최근 방법들은 사람의 모션을 로봇 손으로 리타겟팅한 뒤 시뮬레이션에서 trajectory 를 학습해 객체 추적 성능을 높였다. 그러나 객체 trajectory 만 추적하는 것은 두 손이 물체와 상호작용하는 방식, 즉 접촉 보존을 결정하지 못한다. 접촉이 어긋나면 로봇이 잘못된 부위를 만지거나 손가락이 미끄러질 수 있다.

DexDuet 는 접촉 보존을 첫 목표로 삼는다. 인간 손이 물체의 어떤 부분을 접촉점으로 유지하면 로봇 손도 같은 부분을 유지해야 한다. 이를 객체 상태 오류를 최소화하되 contact drift window bound 를 동시에 만족하는 최적화로 정리했다. DexDuet 는 세 가지 과제, 즉 역할이 다른 동시 bimanual 조작, 서로 다른 로봇 embodiment 간 접촉 보존, 어려운 조작 단계를 세 컴포넌트로 해결한다. (1) 두 개의 interaction reward 가 로봇 손과 인간 손을 객체 기준으로 비교한다. (2) bimanual policy 를 두 개의 weight-sharing per-hand policy 로 분해하고, 서로의 관찰을 조건으로 하되 손별 PPO clipping 으로 한 손의 갱신이 다른 손을 막지 않게 한다. (3) A-RSI 는 segment 별 adaptive curriculum 로 assistance 수준을 조절하고, keyframe 시작 상태로 실패를 반복하지 않게 한다.

## 핵심 내용

- 벤치마크: 네 개의 suite(DexMachina, SPIDER, ManipTrans, V2D)에 걸쳐 세 시뮬레이터와 다섯 개의 robot embodiment 를 다룬다. DexMachina suite 는 Genesis 시뮬레이터에서 인조/알고리로/... 실제 실기 재현.
- DexDuet 는 네 벤치마크 전반에서 객체 추적 ADD-AUC 를 11~41점 개선하고, 접촉 보존 Contact-AUC 도 함께 개선했다.
- 매칭 추적 테스트: ADD-AUC 가 3점 이내로 비슷한 122 pair run 중 DexDuet 는 117건에서 인간과 더 잘 접촉을 보존했다. logistic regression 으로 pair 선택이 Contact-AUC 에 큰 양(+) coefficient(3.79) 를 갖는다.
- Ablation: interaction reward 를 제거하면 Contact-AUC 가 80.5 에서 49.0 으로 떨어지고, contact reward 만 제거하면 65.4, hand-graph reward 만 제거하면 71.5. unified policy 는 62.1 로 낮고 single-level curriculum 로 대체하면 74.2 로 떨어졌다.

## 세부 사항

문제 설정: 인간의 T-frame demonstration(손 pose + object part pose)로 policy 를 학습한다. policy 는 (a) 객체가 demonstrated state 를 따른다는 오류 평균을 최소화하고, (b) 로봇 손이 인간과의 hand-object contact 를 보존한다는 drift 를 제한해야 한다.

DexDuet 의 policy 는 두 개의 Gaussian per-hand policy 의 곱으로 joint action 를 표현한다. 공유 actor network 로 각 hand 가 자신의 관찰(관절 상태, wrist pose, keypoint, object state, tracking error, 이전 action) 과 partner 의 상태와 이전 action 를 받아 joint position target 을 만든다. PPO 는 손별 clipping 으로 학습한다.

A-RSI 는 uniform assistance schedule 대신 segment 별 assistance level 을 사용한다. episode 시작 segment 는 high failure rate 를 선호하는 sampling 으로 고른다.

한계: contact mapping 의 embodiment gap(손가락 수가 적은 손은 일치하는 finger 만 사용)과 simulator(net force 기반) 의 한계가 지적되었다.
