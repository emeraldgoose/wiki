# 픽셀에서 행동으로: native 비전-언어-행동 정책으로 가기

**원문**: [arXiv:2611.06918](https://arxiv.org/abs/2611.06918) · **게시일**: 2026-11-04
**저자**: Weichen Fan, Haiwen Diao, Penghao Wu, Siyuan Hu, Ziqi Huang, Tianqi Liu, Mingze Sun, Ziyi Wang, Zhongang Cai, Hanming Deng, Quan Wang, Lei Yang, Lewei Lu, Fangzhou Hong, Zhaoxi Chen, Dahua Lin, Ziwei Liu

## 개요

VLA 모델들은 보통 perception이 먼저 visual encoder로 compress되고 action reasoning이 afterwards에 begin한다는 premise 위에 built된다. yet manipulation은 often precisely 이 abstraction에 most vulnerable한 visual signals, e.g. local geometry, boundaries, depth, subtle state changes에 hinge한다. 논문은 action policy가 fixed visual endpoint를 inherit할지 evolving visual computation에 directly access할지 ask한다. it introduces NEO-VLA, structurally encoder-free VLA framework. images는 lightweight patch convolutional layers로 tokenized되고 language와 backbone 전반에 jointly evolve하여 flow-matching action expert가 different depths의 instruction-conditioned visual representations에서 draw할 수 있게 한다. 이 simple change는 consistent pattern을 reveal한다: native architectures는 controlled comparisons에서 encoder-based counterparts outperform; full fine-tuning은 gap을 reduce하지만 erase하지 못하고, additional scale alone cannot recover it. more strikingly, layer-wise probing은 action-critical signals가 often final visual representation well before peak함을 show한다. diverse manipulation settings/distribution shifts across NEO-VLA는 stronger/more robust control을 achieves한다. together, embodied control은 fixed encoder output보다 computational hierarchy across visual representations access에서 benefit함을 suggest한다.

## 핵심 내용

- standard VLA는 perception을 visual encoder로 compress한 뒤 action reasoning을 시작.
- manipulation은 local geometry/boundaries/depth/subtle state changes에 크게 의존.
- NEO-VLA는 encoder-free: patch convolution tokenization 후 visual features가 language와 함께 evolve.
- action expert는 multiple depths의 instruction-conditioned visual reps에서 draw.
- native architectures가 encoder-based보다 우위이며 signals는 final layer 전에 peak.

## 상세

evaluation은 diverse manipulation tasks와 distribution shifts를 포괄한다. probing analysis는 performance를 representational depth와 link한다. full architecture/benchmark details는 연결된 원문을 참고한다.
