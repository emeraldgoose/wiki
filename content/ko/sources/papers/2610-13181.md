# MixTok: 전역 1D 토큰과 희소 2D 정교화를 결합한 적응형 시각 토큰화

**Source**: Li 외, arXiv, 2026-10-09

**핵심**: 시각 토크나이저는 나쁜 절충을 강요한다: 2D 그리드는 세부 묘사를 살리지만 단순 영역에 토큰을 낭비하고, 간결한 1D 시퀀스는 효율적이지만 미세 구조가 뭉개진다—게다가 거의 모두 이미지 복잡도와 무관하게 동일한 토큰 수를 할당한다. MixTok은 짧은 1D 전역 표현에 희소 2D 토큰을 덧붙이되, *어디를* 정교화할지와 이미지마다 *몇 개를* 할당할지를 목표 평균 예산 아래에서 정하는 콘텐츠 적응형 라우터로 배분한다. ImageNet 256×256에서 재구성 rFID 1.195(약 128 토큰), 생성 gFID 1.95(약 131 토큰)를 달성한다.

## 배경

2D 토크나이저(VQGAN, MAGVIT-v2)는 토큰↔위치 대응을 유지하지만 균일 밀도를 할당한다—매끈한 하늘이 복잡한 질감과 같은 비용을 치른다. 1D 토크나이저(TiTok, TA-TiTok, MAETok)는 전역 집계로 짧아지지만 간결한 코드에서 세부 복원이 어렵다. 예산 축에서도 대부분은 이미지당 고정 길이고, 가변형(FlexTok의 coarse-to-fine 순서 시퀀스, ALIT의 점진 할당, CAT의 캡션 기반 비율)은 이미지별 예산 선택이나 공간 배분 중 하나만 다룬다. MixTok은 둘을 함께 푼다: 하나의 평균 예산 제약 아래 공간 선택 + 이미지별 예산.

## 하이브리드 시각 표현

기성 토크나이저(TiTok-L-32의 1D, LlamaGen VQ-16의 2D/공유 디코더) 위에 구축되며, 전체 1D 시퀀스 $T_{\mathrm{1D}}$와 선택 위치 $\mathcal{R}$의 2D 토큰 $\{(r_k, t^{\mathrm{2D}}_{r_k})\}$를 유지해 콘텐츠 토큰 $B = L + K$개를 만든다(위치는 부가 정보로 저장). 1D 특징은 공간 대응이 없으므로 공간 쿼리 그리드 $G_{\mathrm{1D}}$로 확장하고 어댑터 $P_{\mathrm{1D}}$로 정렬한 뒤, $\mathcal{R}$ 위치에서만 1D 기반 특징을 2D 특징으로 교체해 공유 디코더로 복원한다. 학습은 L1 + LPIPS + GAN 손실이며 1D 인코더/양자화기는 고정한다.

## 콘텐츠 적응형 라우터와 2단계 생성

라우터는 두 부분이다. **재구성 그리드 스코어러**는 정렬된 1D/2D 특징과 1D 기반 복원 영상에서 위치별 정교화 우선순위를 매기며, 국소 재구성 오차 감소량과 미분 가능 선택 서로게이트를 통한 혼합 복원 손실로 지도된다. **예산 컨트롤러**는 스코어를 softmax 정규화한 뒤 top-$p$ 선택을 적용한다: 누적 확률이 $p$에 닿는 최단 prefix만 유지하므로, 점수 집중 시 토큰이 적고 분산 시 많아진다. $p$는 목표 평균 예산에 맞게 한 번 보정한다.

생성은 2단계 MaskGIT이다: 1단계가 1D 토큰을 생성하고, 증류된 **생성 그리드 스코어러**(1D 기반 특징만 사용)와 동일한 top-$p$ 규칙으로 $\mathcal{R}$을 정한 뒤, 임베딩 어댑터가 미선택 위치에 공간 콘텍스트 임베딩을 제공하고, 파인튜닝된 Halton-MaskGIT이 마스크된 $\mathcal{R}$ 토큰만 생성해 공유 디코더가 최종 영상을 렌더링한다.

## 실험

**설정**: ImageNet 256×256; 주 구성은 TiTok-L-32(1D 32개) + LlamaGen VQ-16(16×16 그리드); 재구성은 검증 50K 전체(rFID, PSNR), 생성은 클래스 조건부 gFID(ADM 평가기, 시드당 50K), 지연/FLOPs는 RTX 5090 단일·배치 1 기준.

**벤치마크**: TiTok, FlexTok, DetailFlow, One-D-Piece, MaskGIT, LlamaGen, AdaGen 대비 ImageNet 재구성·클래스 조건부 생성.

**결과**:

| 과제 | MixTok | 가장 가까운 기준선 |
|------|--------|------------------|
| 재구성 rFID / PSNR (~128 토큰) | **1.1950** / 19.51 dB | DetailFlow-16: 1.1370 / 19.46; TiTok-S-128: 1.7222 / 17.72 |
| 생성 gFID (~131 토큰, 16 라운드) | **1.95** | TiTok-S-128: 2.00 (64 라운드); DetailFlow-32: 2.63 (39 라운드, 약 2배 토큰) |
| 전이성 (ALIT–VQGAN, 128 토큰) | rFID 2.9453 → **2.4720** | ALIT-128 |

희소 2D 정교화만으로 생성 gFID가 4.33(1D 기반)에서 8개 추가 라운드로 1.95까지 개선되며, 단일 이미지 지연은 TiTok/DetailFlow 구성 대비 $3.77\times$/$2.48\times$ 빠르다. 애블레이션도 두 요소를 지지한다: 학습 스코어러가 무작위/균일/그래디언트-엔트로피 순위보다 우수(1.1950 vs 1.40–1.66)하고, top-$p$가 고정 $K$·셔플 예산보다 우수하다.

## 소프트웨어 엔지니어를 위한 시사점

이미지 토큰이 비용 중심인 곳이라면 MixTok이 직접 관련된다: 짧고 콘텐츠 인식적인 시퀀스는 멀티모달 서빙에서 자기회귀 스텝, KV 캐시 메모리, 이미지당 지연을 줄인다. 설계 패턴—저렴한 전역 패스, 학습된 스코어러, 예산 제약 희소 정교화—은 다른 적응형 연산 문제(토큰 가지치기, mixture-of-depth 등)에도 이식 가능하다. 한계: 재구성에는 여전히 조밀한 2D 인코딩이 필요하고, 2단계 생성기가 전체 그리드에서 동작하며, 평가는 ImageNet-256뿐이라 고해상도에서의 예산 거동은 미검증이다.
