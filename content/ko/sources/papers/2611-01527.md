# 도구 상태에서 과학적 행동으로: 생의학 연구 에이전트의 의사결정 출처 감사

**원문**: [arXiv:2611.01527](https://arxiv.org/abs/2611.01527) · **게시일**: 2026-11-01

## 개요

생의학 연구 에이전트는 문헌을 검색하고 분자·세포 특징을 살펴보며 다음에 무엇을 조사할지 선택하지만, 최종 판정은 이 과정의 일부만 담고 있습니다. 두 실행이 서로 다른 문서를 선택하거나 다른 문장을 인용하면서도 같은 주장에 대해 같은 결론을 내릴 수 있습니다. 논문은 조용히 오염된 도구 값이 이러한 증거 선택을 바꾸는지, 그리고 변화를 되돌리려면 도구 출력의 어느 만큼을 복원해야 하는지를 묻습니다.

BioAgent-DF는 이를 의사결정 출처(decision provenance) 감사로 정식화합니다. 증거 경로 충실도는 기록된 검색·읽기·인용 끝점에서 지정된 참조 실행과의 일치를 뜻하고, 과학적 의사결정 충실도(BioAgent-DF의 DF)는 행동, 항목 선택, 판정까지 아우르는 더 넓은 감사입니다. 배경은 결함 있는 GPU의 무음 데이터 손상(silent data corruption)입니다. Case 1(크기 의존형) GPU는 큰 행렬 경로에서 짧은 프로브보다 자주 실패하고, Case 2(확장 트리거형) GPU는 짧은 프로브에서도 실패하며, 이런 GPU의 유한하지만 잘못된 출력은 일반적인 NaN/Inf 모니터링을 통과해 도구 결과까지 도달할 수 있습니다.

방법은 쌍대 감사입니다. BioAgent-DF는 한 과학 계산 지점에서 참조 값과 후보 값을 저장하고, 이를 원래 좌표에 복원하거나 이식한 뒤, 남은 도구·에이전트 단계를 정상 하드웨어에서 실행합니다. 여덟 개의 SciFact 배치에서 Qwen3.5-4B는 세 개의 캡처-클레임 조합에서, Gemma 3 4B IT는 네 개의 조합에서 반복 가능한 인용 변화를 보였고, 이 일곱 조합은 두 개의 클레임을 포괄합니다. 전체 복원은 판정을 바꾸지 않은 채 참조 증거 집합을 복원했으며, 기본 프롬프트에서 관찰된 판정 변화는 명시적 예제 프롬프트에서는 재발하지 않았습니다. 보완적인 도구·옵티마이저 실험은 수치 상태 복구, 순위 목록 복구, 에이전트 가시 이력 복원을 서로 구분합니다.

위험이 가장 큰 곳은 에이전트가 실제 실험을 지시하는 곳입니다. hERG 심장 안전성 분석 배정 실험에서 3-멤버 Chemprop D-MPNN 앙상블이 2,009개 내부 홀드아웃 화합물을 점수화했고, GPT-6.1 Sol 에이전트가 Biomni A1 기본 워크플로로 측정할 Top-402를 선택하고 패치클램프 분석 여부(트리아지)를 정했습니다. 무음 수치 오류는 고정 예산 후보 목록이 차단제로 레이블된 화합물 수를 유지하는 동안 검사 결정 자체를 바꾸었습니다. 에이전트가 결함 값을 사용한 뒤 이전 실행 상태를 복원하고 인증된 점수를 제공하자 변경된 39개 결정이 모두 복구된 반면, 예측 파일 교체는 아무것도 복구하지 못했고 잘못된 행동은 실행되지 않았습니다. 산술 검사의 스트리밍 구현은 원래 FP64 구현 대비 전방 실행·검증 총 시간을 42.4% 줄였고 플래그와 복구 출력은 동일했습니다.

## 핵심 내용

- 안정적인 판정 뒤에 증거 경로가 바뀔 수 있습니다. 감사는 최종 답변과 함께 에이전트가 무엇을 읽고 인용했는지 기록해야 합니다.
- 반복 가능한 증거 경로 변화는 실재하지만 집중되어 있습니다. 상위 검색 변화를 기준으로 선별한 Case 2 캡처에서 두 클레임, 두 4B 모델에 걸친 일곱 캡처-클레임 조합이며, 선별하지 않으면 후보 값의 불일치가 정상 재실행과 다르지 않았습니다.
- 원래 좌표 개입이 원인 값을 특정합니다. 확인된 모든 사례에서 전체 복원은 참조 읽기·인용을 되돌렸고, 참조 경로를 복원하면서 후보 경로를 재현하는 부분 행렬 마스크는 없었습니다.
- 에이전트 모델 자체를 결함 하드웨어에서 실행하면 Case 1의 220건, Case 2의 240건 후보 요청이 모두 vLLM 요청 수준 NaN 진단을 트리거해 도구 호출이 하나도 완료되지 않았습니다. 따라서 재생 실험은 망가진 에이전트가 아니라 오염된 도구 값을 분리합니다.
- hERG 배정에서 집계 지표는 실패를 숨겼습니다. Top-402는 여전히 351개의 레이블된 차단제를 담고 있었지만 구성과 트리아지 결정은 바뀌었습니다. 공개 hERG IC50 434 nM인 K5612(CHEMBL3804918)는 네 소스에서 목록에서 빠졌고, 차단제로 레이블된 K12252와 K1461은 검사 없이 진행으로 배정되었습니다.
- 탐지에는 올바른 검사가 필요합니다. 무결성·확률 범위 검사는 16개 결함 소스 중 하나도 잡지 못했지만, 반올림 한계를 둔 행/열 체크섬은 여덟 번의 정상 검증기 실행에서 오경보 없이 16개 모두를 잡았습니다.
- 복원은 비용 위계를 따릅니다(결정 복구 비용은 전체 상태 복원 이하). 11~254개 좌표 복원으로 수백 개 예측이 여전히 다른 상태에서 변경 결정이 복구되었고, 마진 0.009354로 경계에 가장 가까운 68개 화합물을 재계산하는 R1+M 규칙은 정상 배정과 일치했습니다.

## 상세

- SciFact 프로토콜: search, read, finish를 실행하는 에이전트가 문장 인용과 함께 SUPPORT, REFUTE, NOT_ENOUGH_INFO를 반환합니다. 검색 1회, 문서 읽기 최대 6회, 에피소드당 16회 호출, 응답 384 토큰, 온도 0 조건입니다. 메커니즘 연구는 11개 클레임의 27개 Case 2 캡처-클레임 조합을 7개 조건에서 3회씩 반복(모델당 567회 시도)했고, 내용 마스킹·미선택 대조를 포함한 프롬프트당 1,386회 시도를 수행했습니다. 기본 Qwen은 1,386회를 모두 완료한 반면 기본 Gemma는 800회 완료(559회 예산 소진, 27개 잘못된 JSON 출력)했습니다.
- 감사가 구분하는 것: 수치 진단은 적용 가능한 한계로 뒷받침되는 산술 이상과, 두 정상 참조 사이에서도 멤버십을 바꾸는 일반 정밀도 효과를 구분합니다. PBMC에서 중간 BF16 축소를 끄면 두 참조 간 Top-10 불일치 174건이 0이 되었지만 두 건의 순서 불일치는 남았습니다.
- 결정 커밋 관점: 연구 에이전트가 자동화 실험실을 지시할 때 바뀐 결정은 곧 바뀐 실험이며, 집계 지표가 이를 드러내지 않을 수 있습니다. 따라서 검증은 결정이 커밋되는 지점에 있어야 합니다. 플래그된 미해결 점수는 신뢰할 수 있는 하드웨어에서 재계산하고, 폐기된 값을 사용한 에이전트는 해당 값을 읽기 전에 저장된 실행 상태에서 재개하며, 인증된 결정만 커밋합니다.
- 후속 과제: 공유 계산 예산 안에서 어떤 계산을 검증·재실행할지, 어떤 의존 실행 상태를 복원할지, 어떤 측정을 얻을지 고르는 복구 에이전트, 그리고 평가 참조를 에이전트에게 숨겨 결함 탐지·신뢰 증거 확보·결정 복구·올바른 커밋을 따로 채점하는 벤치마크 제안.
- 도구: NVIDIA GPU의 수치 이상을 탐지하고 진단 기록을 수집하는 공개 도구 Aritheia가 https://github.com/INTOSYN/Aritheia_GPU_Test 에서 제공됩니다.
