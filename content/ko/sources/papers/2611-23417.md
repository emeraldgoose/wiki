# 자기 회귀적 뷰 모델

**원문**: [arXiv:2611.23417](https://arxiv.org/abs/2611.23417) · **게시일**: 2026-11-17 (v1, v2는 2026-11-20)
**저자**: Jensen, Zhou, Samuel Rota Bulo, Denis Rozumny, Duncan Zauss, Peter Hedman, Nikhil Keetha, Philip Torr, Christian Rupprecht, Andrea Vedaldi, Peter Kontschieder

## 개요

목표는 장면을 하나 이상의 이미지나 비디오로 받았을 때 요청된 가상의 카메라 궤적을 따라 장면의 비디오를 생성하는 것이다. 관찰된 영역은 재구성하고, 카메라가 움직이면서 새로 보이는 콘텐츠는 합성하며, 재방문 시 입력과 모델 자신의 이전 출력 모두와 일관성을 유지해야 한다. NeRF나 3D 가우시안 스플래팅 같은 재구성 방법은 입력 뷰에 명시적인 3D 일관 표현을 맞추며 여러 시점에서 충실한 렌더링을 위해 조밀한 캡처가 필요한 반면, 비디오 생성기는 보지 못한 콘텐츠를 합성할 수 있지만 궤적이 길어질수록 입력과 이전 출력에서 벗어날 수 있다. 자기 회귀적 뷰 모델(AVM)은 그 대신 장면을 뷰의 스트림으로 생성하며, 명시적인 3D 표현을 따로 맞추지 않는다.

## 핵심 내용

- 통합된 인컨텍스트 인터페이스: AVM은 이미지나 비디오에 조건화해 요청된 카메라 경로를 따라 짧은 클립을 생성한다. 동일한 인터페이스로 재구성, 보간,탐색, 재방문을 처리하며, 단일 이미지에서 조밀한 이미지 집합과 동기화된 비디오 스트림까지 다양한 컨텍스트를 지원하고 정적 및 동적 장면에서 카메라 제어, 이벤트 프롬프트, 장구간 재방문을 지원한다.
- 제한된 활성 컨텍스트: 입력과 생성 이력(이전 클립의 생성된 뷰)에서 관련 뷰를 검색하므로 전체 과거가 아닌 제한된 활성 컨텍스트에 조건화한다.
- 학습: 사전학습된 양방향 비디오 확산 트랜스포머를 flow matching으로 N-in-1-out 형태로 미세조정한 뒤, 인과 모델을 자신의 롤아웃에서 조정해 사실성 향상, 디노이징 단계 감소, 장구간 드리프트 완화를 달성한다.
- 규모: 학습은 약 800만 개의 장면과 비디오 클립으로 확장된다.
- 평가: 카메라 제어, 텍스트 제어, 시각적 품질, 역동성, 희소 및 4D 재구성, 장구간 일관성 벤치마크에서 생성 능력과 장면 지속성을 평가하며, 하나의 인컨텍스트 인터페이스가 다양한 입력과 출력 설정에 적응함을 보여준다.

## 상세

1장은 NeRF/3DGS 스타일의 재구성(조밀한 캡처와 3D 표현 맞추기)과 순수 비디오 생성(장구간 드리프트)에 맞서 뷰 스트림 생성을 주장한다. 방법의 핵심은 프리필 이미지/비디오와 생성 이력으로부터의 검색 기반 활성 컨텍스트, 양방향 비디오 확산 백본의 N-in-1-out flow matching 미세조정, 인과 롤아웃 조정이다. 이 문서는 최신 리비전(v2, 2026-11-20)을 기준으로 작성했으며 원본 v1은 2026-11-17에 제출되었다. 프로젝트 페이지: autoregressive-view-model.github.io.
