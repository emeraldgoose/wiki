# 어디서 배우고 얼마나 rollout할 것인가: GUI Agents를 위한 효율적 적응형 학습

**원문**: [arXiv:2610.39251](https://arxiv.org/abs/2610.39251 · **게시일**: 2026-10-29
**저자**: Yuxiang Chai, Quyu Kong, Panrong Tong, Steven Hoi, Yue Wang

## 개요

trajectory-level GRPO는 multi-step GUI agents training의 common approach지만 complete trajectories를 repeatedly rollout from task root하는 방식은 inefficient할 수 있다. task-level rewards는 which intermediate decisions require improvement에 coarse supervision을 주고, mastered prefixes는 difficult states에 도달하기 전에 repeatedly re-executed된다. 논문은 where to learn과 how far to roll out을 jointly addressed하는 two-stage adaptive training framework를 제안한다. successful expert trajectories에서 reusable intermediate checkpoints를 construct하고 action disagreement를 이용해 informative pivots를 select한다. Stage I은 pivots에서 one-step RL을 수행해 uncertain local decisions를 improve하고, Stage II는 task progress에 따라 adaptive local/suffix/root training으로 policy responsibility를 progressive하게 expand한다. recoverable checkpoints는 intermediate state에서 repeated training을 가능하게 하며, 앞 trajectory replay 앞 trajectory를 다시 실행하지 않아도 된다).

## 핵심 내용

- reusable intermediate checkpoints는 mastered prefix replay를 avoid한다.
- action disagreement가 uncertain local decisions를 식별한다.
- Stage I은 selected pivots에서 one-step RL 수행한다.
- Stage II는 local, suffix, root training으로 확장한다.
- intermediate state recovery가 training efficiency improve.
- environment interaction decreases while task performance increases.

## 상세

MobileGym과 CUA-Gym-Hub across에서 method는 vanilla trajectory-level GRPO 대비 56~61% environment interaction 감소와 task performance 향상을 보였다. 결과는 states와 rollout ranges에 training을 jointly allocate하면 GUI-agent RL efficiency를 substantial improve 가능함을 demonstration한다. checkpoint construction은 successful expert trajectories와 pivots에 depend할 수 있으며 noisy environments, broad action spaces, weak task-level rewards에서 benefits differ할 수 있다.
