# 엔티티 대체 응답의 프롬프트 간 재사용

**원문**: [arXiv:2611.00352](https://arxiv.org/abs/2611.00352) · **게시일**: 2026-10-30
**저자**: Jinkun Chen, Xuemin Yu, Sijia Han, Vlado Keselj

## 개요

이 연구는 모델 가중치를 고정한 상태에서 엔티티 대체 응답이 서로 다른 영어 사실 질의 사이로 얼마나 전이되는지 묻는다. 단순히 답변이 바뀌었는지만 확인하는 것이 아니라, 하나의 질의에 부착된 은닉 상태 변화가 다른 동일 엔티티 질의로 얼마나 전파되는지, 그리고 예측된 상대 로그 확률 변화와 측정된 변화가 정렬 조건에서 어떻게 비교되는지를 격리해서 본다. 결과는 소형 체크포인트에서는 특정 조건 下에서 상당한 오류 회복이 가능하다는 점을 보여주지만, 규모가 커지거나 챗 포맷이 들어가면 결과가 포맷이나 코호트 의존성이 되어 논문은 일관된 전이 성공보다는 조건 의존성을 더 강조한다.

중심 방법론은 알려진 답변 접두어 조건에서 두 후보 답변의 상대 로그 확률 변화를 예측값과 측정값으로 비교하는 것이다. 동일 엔티티에 대한 목표 질의를 기준으로, 두 source 질의에서 파생된 기대 변화를 주입해 그 효과가 재현되는지 시험한다. 중간 표현을 주입하는 hidden-reuse 방식과 source의 output-level 변화를 직접 이어 붙이는 직접 재사용 방식을 구분하기 때문에, 유용한 정보가 중간 표현에 더 잘 담기는지 이미 계산된 answer score에 더 잘 담기는지를 분석할 수 있다.

논문은 크게 세 결론을 제시한다. 첫째, 타 관계 은닉 재사용는 0.5-1B Qwen과 Llama 체크포인트에서 변화 없음 오류를 약 45%에서 49% 정도 줄인다. 둘째, Gemma-2-2B는 포맷 민감도가 더 크며 기본 begin-of-sequence token 처리 방식을 복원했을 때 plain text 성능이 크게 개선된다. 셋째, 성공적인 전이가 대체 특이적을 의미하지는 않는다. 목표 관계 출처에서는 사후 분석 상 수치 advantage가 챗 밖에서 0.2에서 0.9 봇이며, 측정 advantage 역시 대체 특이적하지 않게 남는다. 또한 작은 plain format 모델에서는 타 관계 은닉 재사용가 주로 두 질의가 공유하는 shift를 재현하는 경향이 있다.

## 핵심 내용

- 연구 대상은 답변 전환 여부가 아니라 엔티티 대체 응답이 다른 사실 질의 사이로 전이되는지 여부다.
- hidden-reuse는 aligned 은닉 상태 변화를 목표의 뒤쪽 층 실행 전 깊이 50% 지점에 주입한다.
- 직접 재사용는 source output-score 변화를 더 직접적으로 적용한다.
- 0.5-1B Qwen과 Llama에서는 타 관계 은닉 재사용가 변화 없음 오류를 각각 45%와 49% 줄인다.
- Gemma-2-2B는 begin-of-sequence 기본 처리를 끈 plain text 조건에서 약 22% 감소, 한 비교를 통과한다.
- 관련 토큰 처리 protocol을 복원하면 58%에서 68%에 도달하고 세 코호트 모든 비교를 통과한다.
- 더 큰 체크포인트, chat format, 새로운 엔티티 실험에서는 재현이 일어나지만 포맷이나 코호트-의존 실패도 함께 나온다.
- 작은 plain format 체크포인트에서는 타 관계 은닉 재사용가 두 질의가 공유하는 shift를 주로 재현한다.
- 목표 관계 출처에서는 hidden-reuse의 post hoc advantage가 chat format 밖에서 0.2에서 0.9 나트 수준이다.
- 두 질의의 entity token 위치에 relation-neutral change를 넣으면 관계 선택적 오류가 random이나 다른 대체 항목의 변화보다 더 크게 감소하여 receiving question dependence를 보여준다.

## 상세

- **known answer alignment.** 예측값과 측정값 비교는 답변 접두어가 공개된 조건에서 이루어져 shift만 떨어내기 cleanly 비교할 수 있다.
- **BOS 민감도가 크다.** 동일 모델이 token handling protocol을 복원하면 partial에서 거의 전 비교 통과로 가므로, 인터페이스 세부 사항을 부차적 artifact로 보면 안 된다.
- **replacement specificity는 미확인.** target-relation 조건 아래 hidden-reuse의 추가 advantage는 작고, 대체 특이적이 아니며, 조건에 따라 미확인 상태로 남는다.
- **함의.** intermediate-state reuse는 유용할 수 있지만 parameter count, format, cohort 의존성이 강하며, entity replacement 주장에는 매칭된 관리 조건이 필요하다.
