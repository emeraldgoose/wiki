# OpenFrontiers: 공개 연구 문제 모음과 과학적 재발견 벤치마크

**원문**: [arXiv:2610.37739](https://arxiv.org/abs/2610.37739) · **게시일**: 2026-10-27
**저자**: Jiarui Yao

## 개요

대형 언어 모델은 연구 수준 문제 solving에 점점 능력을 보이지만, 그에 맞는 문제 모음과 평가 체계는 아직 부족하다. OpenFrontiers는 공개 연구 문제의 구조화된 코퍼스와 최근 해결된 수학 문제에 대한 소급 벤치마크를 결합해 이 공백을 메운다.

코퍼스는 12,151개 문제의 문제 진술, 맥락, 진행 상태 등 정보를 기록한다. 벤치마크는 200개 문제로 구성되며 2026년에 해결된 110개와 아직 open인 90개가 포함된다. 각 문제는 Lean 4 진술을 포함하고 자동화 프로브와 두 개의 독립 리뷰로 검사된다. HQ-50 부분 집합은 품질 기준으로 문제를 더 제한한다. 평가 프로토콜은 폐쇄 책, 동결된 검색, 실시간 웹 조건에서 isolated sandbox의 두 독립 검사기로 형식 증명을 채점한다.

HQ-50에 대한 7개 대형 언어 모델 에이전트 평가는 표준 예산 하에서 폐쇄 책 재발견이 드물며 최대 40개 해결 문제 중 7개에 그친다는 결과를 보여준다. 실시간 웹 성공은 대체로 게시된 해답을 검색한 결과로 해석된다. 문제 코퍼스와 형식 검수 부분 집합, 문서화된 해답을 연결해 연구 수준 재발견 측정의 토대를 제공한다.

## 핵심 내용

- 공개 연구 문제의 구조화된 코퍼스와 형식 검수 재발견 벤치마크를 결합한다.
- 12,151개 문제의 진술, 맥락, 진행 상태를 기록한다.
- 200개 수학 문제 benchmark와 Lean 4 진술, 독립 리뷰를 제공한다.
- HQ-50 부분 집합으로 더 높은 품질 문제에 집중한다.
- 여러 검색 조건에서 두 독립 검사기가 형식 증명을 채점한다.
- 폐쇄 책 재발견은 드물고 실시간 웹 성공은 주로 검색된 해답에 의존한다.

## 상세

이 자원은 광범위한 문제 코퍼스를 문서화된 해답이 있는 형식 평가 부분 집합에 연결한다. 실험은 7개 모델 에이전트와 표준 예산으로 수행하며, 해결된 문제와 아직 open 문제를 구분한다. 현재 open 과학 문제의 해결 진전을 연구하는 데 활용할 수 있다.
