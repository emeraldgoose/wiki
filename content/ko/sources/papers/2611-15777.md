# SO-Arena: 시스템 원 모델의 능력 스펙트럼과 신뢰성 벤치마크

**원문**: [arXiv:2611.15777](https://arxiv.org/abs/2611.15777) · **게시일**: 2026년 11월 11일
**저자**: Lichen Li, Ziping Dong, Sicheng Feng, Qi Li, Xinchao Wang

## 개요

시스템 원(System One) 모델은 긴 토큰 생성 없이 한 번의 순전파로 미리 정의된 선택지에 대한 분포를 예측한다. 긴 추론 과정을 생략하는 대신 지연 시간이 짧고 결과가 구조화되어 있어 후속 소프트웨어가 곧바로 쓸 수 있는 것이 장점이다. 다만 기존 벤치마크의 종합 정확도만으로는 이런 모델의 능력이 어디까지 넓은지, 개별 판단이 얼마나 믿을 만한지 알기 어렵다는 것이 이 논문의 출발점이다. 저자들은 이를 보완하기 위해 능력 리더보드와 별도의 신뢰성 점수를 함께 제공하는 SO-Arena를 소개한다.

SO-Arena는 공개 소스 40곳에서 모은 2,919개 과제를 11개 도메인, 다섯 능력 계열로 묶는다. 계열은 의미 이해, 지식과 추론, 안전과 정책 준수, 근거 평가, 에이전트 과제 수행이다. 모든 정답 레이블은 모델이 실제로 볼 수 있는 근거와 대조해 수동으로 검증하며, 9개 도메인에는 도메인별 기준으로 나눈 난이도 등급이 붙는다. 과제는 고정된 입력을 판단하는 정적 과제와, 웹이나 도구 환경 안에서 한 결정이 다음 상태를 바꾸는 환경 기반 과제로 나뉜다. 신뢰성은 두 가지 방법으로 검사한다. 각 문항을 원래 순서와 12가지 재배열로 보여주어 답이 흔들리는지 확인하고, 정답 선택지를 아예 빼서 모델이 정답이 없음을 알아보는지 살핀다.

평가 대상은 21개 모델이다. 0.4B에서 31B 규모의 오픈 웨이트 시스템 원 모델 16개, 상황에 따라 추론을 켜고 끄는 StartLux Auto, 폐쇄형 의사결정 API인 Jev API 1.14와 OpenAI Decisions, 그리고 시스템 투(System Two) 참조 모델인 GPT-6 Sol과 Luna가 포함된다. 핵심 발견은 두 축이 서로 어긋난다는 점이다. 능력 순위와 신뢰성 순위가 일치하지 않으며, 가장 성능이 좋은 시스템 원 모델은 신뢰성에서 겨우 7위를 기록했다.

## 핵심 내용

- 과제 구성은 정적 2,300개와 환경 기반 619개다. 환경 기반 과제는 웹 과제 337개(단일 판단 100개, 참조 경로형 237개)와 BFCL이나 ToolSandbox 규칙으로 채점하는 도구 사용 에피소드 282개로 이루어진다.
- 능력 점수는 각 도메인에서 가장 어려운 등급만 평균하고 도메인 가중치를 모두 같게 두어, 큰 도메인이 리더보드를 지배하지 못하게 한다.
- GPT-6 Sol과 Luna가 전체 능력에서 여전히 앞서며, 가장 강한 시스템 원 모델인 GLiDE와 KnowLine-31B도 Luna보다 약 10점 뒤진다.
- 대신 모든 오픈 웨이트 시스템 원 모델은 H100 GPU 한 장에서 과제당 0.3초 이내에 답해, 두 시스템 투 참조 모델보다 수십 배 빠르다.
- 신뢰성 1, 2위인 JevAny-27B와 Jev API 1.14는 성능 순위에서는 18개 중 각각 8위와 6위에 머문다.
- 선택지 순서를 바꾸면 18개 중 14개 모델이 안정성 0.8을 넘기며(0.83에서 0.94 사이) 답을 유지하지만, Laya는 0.35로 떨어지고 SII-4B, Kev-4B, OpenAI Decisions는 0.68에서 0.72 사이다.
- 정답 없음 판별은 성능과 느슨하게만 연결된다. Kev-27B, Jev API 1.14, JevAny-27B는 성능 상위 네 모델보다 정답 빠짐을 잘 알아차렸다.
- 추론 모드는 선택적으로 도움이 된다. 수학 도메인에서 StartLux Auto가 추론을 허용받으면 50.8점에서 92.5점으로 뛰어 Luna에 근접한다.
- 지식과 상식, 감성과 감정 이해, 검색과 재정렬에서는 시스템 원 모델이 Luna에 필적하지만, 수학, 과학 추론, 코드 이해에서는 두 규모 모두 크게 뒤진다.

## 세부 사항

### 벤치마크 구성

과제는 출처를 추적할 수 있는 공개 데이터에서 가져오고, 사람과 언어 모델이 함께 검토해 의심스러운 레이블은 제외한다. 각 과제는 출처, 버전, 원래 식별자를 기록으로 남기고, 모델에서 파생된 참조는 메타데이터에 표시한다. 정적 과제는 세 가지 형식을 쓰는데, 예/아니오 판단과 원래 척도를 유지하는 서수 평점이 포함된다. 선택지가 없는 수 서술형 문제에는 기저 모델의 오답, 풀이의 중간 결과, 규칙 기반 근사 오답으로 방해 선택지를 만들어 넣는다. 환경 기반 과제는 기록된 페이지 상태를 판단하거나 단계별로 행동하는데, 다단계 웹 과제는 재생으로 검증된 참조 경로를 따라가고, 도구 사용 에피소드는 BFCL이나 ToolSandbox 시뮬레이터가 해당 벤치마크의 성공 기준에 따라 점수를 매긴다.

### 시스템 투 모델과의 격차

GPT-6 Luna와의 격차는 도메인에 따라 크게 달라진다. 의도와 라우팅, 안전, 과제 완료 검증, 도구와 API 사용, 웹 상호작용에서는 GLiDE가 Luna를 4점 이내로 따라잡지만 StartLux Instant는 최대 29점 뒤진다. 이 다섯 도메인에서는 모델 계열의 더 크고 새로운 백본이 항상 이겼다. 반면 수학, 과학 추론, 코드 이해에서는 4B와 27B 모두 크게 뒤쳐지며, 추론 모드는 주로 수학과 과학 추론에서만 격차를 줄였다.

### 신뢰성이 밝히는 것

순서 안정성은 대체로 성능을 따라간다. 뒤집기 분석에서 모델은 맞힌 문항보다 틀린 문항의 재배열에서 답을 훨씬 자주 바꾸므로, 불안정은 주로 성능이 나쁜 곳에서 생긴다. 정답 없음 판별은 다르게 행동한다. 비슷한 성능 수준에서도 모델 간 편차가 순서 안정성보다 훨씬 크기 때문에, 성능 점수만으로는 모델이 빠진 정답을 알아차리는지 알 수 없으며 직접 측정해야 한다고 저자들은 강조한다. 논문은 능력과 신뢰성이 별개의 보완적 차원이며 시스템 원 모델을 평가할 때 함께 보고해야 한다고 결론짓는다.
