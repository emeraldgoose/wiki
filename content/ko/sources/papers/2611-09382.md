# 가중치 공간 프로그래밍 탐색: 능력, 일반화, 한계

**원문**: [arXiv:2611.09382](https://arxiv.org/abs/2611.09382) · **게시일**: 2026-11-06
**저자**: Junru Hu, Cheng Tang, Wei Li, Hongze Zhu, Chun-Mei Feng, Qi Zhang, Yirong Chen, Ming Hu

## 개요

모델 적응은 보통 그래디언트 기반 미세조정으로 이루어지지만, 이 논문은 다른 방식을 다룬다. 가중치 공간 프로그래밍(Weight-Space Programming, WSP)은 추론 에이전트가 모델의 원시 파라미터를 직접 읽고 개입을 결정해 수정된 가중치를 되돌려 쓰는 방식으로, 전 과정 어디에도 그래디언트나 역전파가 등장하지 않는다. 기존 연구가 이 능력을 소개했지만 실제로 어디까지 가능한지는 알려져 있지 않았다. 어떤 수준의 향상이 가능한지, 한 작업을 위해 만든 편집이 다른 작업에도 도움이 되는지, 그리고 이 접근이 어디에서 한계에 부딪히는지 — 이 논문은 단일 사례가 아니라 체계적인 평가로 이 질문들에 답한다.

실험 설정은 에이전트 파이프라인이다. GPT-6 Astra가 편집 에이전트로 동작해 Qwen3.5 두 규모(0.8B와 9B)를 대상으로 하며, 가중치 분석과 수정에는 지속형 파이썬 환경을 쓰고 추론은 별도의 GPU 워커가 담당한다. 원본 체크포인트는 끝까지 덮어쓰지 않는다. 16개의 편집 궤적 — 모델·벤치마크 쌍마다 하나, 0.8B MATH에는 독립 탐색 세 개 추가 — 각각에 순전파 도구(forward-tool) 요청 50회 예산이 주어져 행동을 진단하고 개입을 구성하며 후보를 평가한다. 편집은 float32로 계산해 bfloat16으로 저장하며, 허용되는 트랜스포머 블록 파라미터로 제한된다. 토큰 임베딩, 최종 정규화, 언어모델 헤드는 고정이다. 이 범위 안에서 에이전트는 희소 MLP 수정, 랭크-1 갱신(rank-one update), 어텐션 헤드 스케일링, 또는 이들의 조합을 자유롭게 만들 수 있다.

핵심 결과는 놀랄 만큼 작고 표적화된 편집만으로도 큰 향상이 가능하다는 것이다. 전체 홀드아웃(held-out) 평가에서 정확도가 MATH-500(수학 추론 벤치마크)에서 최대 29.45포인트, GPQA Diamond(대학원 수준 과학 QA)에서 4.42포인트, IFEval(지시 이행 벤치마크)에서 36.72포인트, SciBench(대학 수준 과학 계산 문제집)에서 17.11포인트 올라갔고, 가장 좋은 MATH-500 편집은 단 1,023개 파라미터 값만 바꿨다. 그러나 논문은 한계도 똑같이 분명하게 짚는다. 독립 탐색 사이에서 결과 편차가 크고, 16개 궤적 중 6개는 후보 개선을 신뢰 있게 검증하지 못해 원래 가중치를 그대로 유지했으며, 교차 작업 전이는 실재하지만 고르지 않다.

## 핵심 내용

- 일곱 벤치마크(MATH, MMLU-Pro, IFEval, GPQA Diamond, MedXpertQA, SciBench, SciCode)와 두 모델 규모(Qwen3.5-0.8B, Qwen3.5-9B)에 걸친 16개 편집 궤적. 각 궤적은 순전파 도구 요청 50회 예산을 받으며 그래디언트에는 접근할 수 없다.
- 홀드아웃 집합에서의 큰 국소 향상: MATH-500 +29.45, GPQA Diamond +4.42, IFEval +36.72, SciBench +17.11포인트. 최고의 MATH-500 편집은 한 층의 단일 출력 열에서 1,023개 BF16 값만 변경했다.
- 추가 편집 없이 이어지는 교차 작업 전이: 수학 편집 체크포인트가 GPQA Diamond에서 3.03, IFEval에서 12.18, SciBench에서 20.10포인트를 올리는 동안 SciCode는 변하지 않았다. 9B에서는 IFEval 편집이 SciBench를, SciBench 편집이 IFEval을 끌어올렸다 — 그러나 일부 전이는 미미하거나 오히려 해롭다.
- 신뢰성 격차: 16개 궤적 중 6개에서 에이전트는 원래 가중치를 유지했다. 개발 +29.69포인트를 기록한 9B MATH 후보는 홀드아웃 MATH-500에서 오히려 0.35포인트 떨어졌다.
- 개입 구조가 규모보다 중요: 세 번의 독립 MATH 탐색이 모두 23번째 층 MLP 다운 프로젝션을 겨냥했음에도 1,023개, 1,037,572개, 1,981,083개 값을 수정하며 각각 +29.45, +5.00, +27.30포인트를 얻었다. 수정한 파라미터 수만으로는 효과를 예측할 수 없다.
- 소형 모델일수록 개선 여유가 크다: Qwen3.5-0.8B가 일곱 벤치마크 전 카테고리에서 9B보다 큰 최고 개발 향상을 보였는데, 이는 훨씬 약한 베이스라인과 일치한다(예: MATH-500 8.35% 대 97.70%).

## 상세

**방법.** 각 반복에서 에이전트는 현재 가중치와 누적된 관찰로 갱신량 Δθ를 구성해 θ ← bf16(θ + Δθ)로 적용한다. 피드백은 상호 보완적인 두 모드로 온다. 작업 성능을 재는 자기회귀 생성과, 토큰 로그확률과 중간 활성값을 노출해 기계론적 분석을 돕는 교사 강제(teacher forcing)다. 최종 체크포인트는 개발 피드백만으로 선택하되 원래 가중치를 유지하는 선택지가 있으며, 선정 후에는 동일한 평가 조건의 홀드아웃 테스트에서 베이스 모델과 비교한다.

**벤치마크와 분할.** 일곱 벤치마크는 수학 추론(MATH, 개발은 GSM8K/MATH 학습셋 + AIME, 평가는 MATH-500), 일반 지식(MMLU-Pro), 지시 이행(IFEval, 541개 공식 프롬프트를 270/271로 고정 분할), 과학 QA(GPQA Diamond, 개발은 GPQA Main), 의료 QA(MedXpertQA-Text), 과학 추론(SciBench, 수치 답을 5% 상대 허용 오차로 채점), 과학 코딩(SciCode, 실행 가능한 완전 코드 체인 평가)을 다룬다.

**홀드아웃 결과.** 0.8B에서 유지된 편집은 MATH-500을 8.35에서 37.80으로, IFEval을 21.40에서 58.12로, SciBench를 1.38에서 18.49로, GPQA Diamond를 25.25에서 29.67로 끌어올렸다. 9B의 향상은 작았다(IFEval +1.85, SciBench +3.03, SciCode +1.54). 여섯 궤적은 원본 체크포인트를 유지했다: 0.8B의 MedXpertQA와 MMLU-Pro, 9B의 MATH, GPQA Diamond, MedXpertQA, MMLU-Pro. 각 경우 개발 향상이 더 넓은 검증에서 줄어들거나 반전되었다(예: 9B GPQA 탐색의 초기 +6.25는 재평가에서 사라졌다). 0.8B MATH 전체 궤적은 작업 방식을 잘 보여준다. 50회 요청을 생성 32회와 교사 강제 18회로 배분하고, 행동 진단에서 구성 요소 탐색, 표적 개입, 대조군 검증, 확장 검증으로 나아갔다.

**분석.** 세 가지 발견이 두드러진다. 첫째, 가중치 공간 개입은 보지 못한 문제로 일반화된다. 세 번의 독립 MATH 탐색이 모두 양의 홀드아웃 향상(+29.45, +5.00, +27.30)을 냈고, 작업별 편집도 다른 홀드아웃 벤치마크를 끌어올렸다. 둘째, 탐색은 경로 의존적이다. 같은 모델, 같은 벤치마크, 심지어 같은 대상 텐서(23번째 층 MLP 다운 프로젝션)에서 구조가 서로 다른 세 개입이 매우 다른 성과를 냈다. 셋째, 전이는 존재하지만 비대칭이며 작업 쌍에 따라 달라진다. 0.8B IFEval 편집 체크포인트 역시 MATH와 SciBench를 개선했지만, 어떤 개입은 다른 작업에서 성능 하락을 낳기도 했다.

**한계.** 저자들은 개발 향상이 신뢰할 만한 홀드아웃 향상으로 항상 이어지지 않는다는 점, 반복 평가에 큰 계산 비용이 든다는 점, 그리고 성공적인 편집과 일반화를 지배하는 메커니즘이 아직 불명확하다는 점을 강조한다. 여러 파라미터 위치를 동시에 수정할 때의 효과나 개발 데이터 크기와 다양성의 영향도 미해결 과제다. WSP는 아직 장기 추론이나 복잡한 에이전트 작업에서 체계적으로 평가되지 않았다.
