# DiLE: 범용 멀티모달 임베딩을 위한 차별인 잠재 공간 학습

**원문**: [arXiv:2611.25419](https://arxiv.org/abs/2611.25419) · **게시일**: 2026-11-19 (v1)
**저자**: Ben Kang, Junda Wang, Yuxuan Yuan, Hang Li, Yuhan Liu, Xin Chen, Wanting Geng, Tong Lin, Pei Fu, Dong Wang, Jian Luan, Huchuan Lu

## 개요

멀티모달 대형 언어 모델은 범용 멀티모달 임베딩 모델의 입력 이해를 크게 향상시켰지만, 그 이해가 관련 항목을혼동되는 대안과 구분하는 데 필요한 증거를 임베딩이 보존한다는 보장은 없다. DiLE(Discrimination-Aware Latent-Space Learning)는 작업 안내와 온폴리시 검색 피드백을 결합해 압축된 잠재 표현이 판별 증거를 유지하도록 한다.

방법은 세 부분이다. 작업 안내 잠재 공간 학습(TLSL): 추론 지시에 이끌리는 소수의 학습 가능 쿼리가 각 입력에서 작업 관련 정보를 추출해 압축된 잠재 공간에 담고, 보조 답변 생성감독이 이해와 검색 모두에 유용하도록 표현을 형성한다. 공유-개별 전문가 적응(SPEA): 공유 전문가는 작업 간 공통 지식을, 개별 전문가는 작업별 차이를 포착해 모달리티와 작업에 걸친 작업별 판별 요구를 수용한다. 온폴리시 하드 네거티브 증류(OPHD): 학생이 스스로 혼동되는 후보를 검색하고, Qwen3-VL-8B 리랭커 교사가 그에 대한 세밀한 관련성 분포를 제공한다. 역KL 목적이 학생의 임베딩 기반 유사도 분포를 교사의 판단에 맞춘다. 후보는 갱신된 학생 스냅샷으로 주기적으로 갱신되어감독이 학생의 진화하는 혼동을 추적한다.

두 백본 세대를 아우르는 4개 모델구성에서 DiLE는 MMEB-v2, UVRB, MRMR에서 최고 성능을 달성한다. UVRB 16개 데이터셋(텍스트/구성/시각 작업 × 거친/세밀/장문맥 도메인)에서 Qwen3-VL-4B 기준 DiLE는 평균 56.2로 종전 최고 52.9, Qwen3-VL-2B는 49.6 vs 44.7을 기록했으며, 이득은 모든 작업·도메인·하위 도메인 그룹에 걸쳐 고르다.

## 핵심 내용

- 동기: MLLM 기반 임베딩 모델은 입력을 이해하지만 관련 항목을 단단한 하드 네거티브와 가르는 증거가 임베딩에서 사라질 수 있다.
- TLSL: 추론 지시로 안내되는 소수 잠재 쿼리가 단일 검색 벡터로 작업 관련 정보를 모은다. 보조 답변 생성감독이 이해 신호를 추가한다.
- SPEA: 공유 전문가는 작업 간 공통 지식을, 개별 전문가는 작업별 차이를 인코딩해 지식 공유와 작업별 판별 집중을양립한다.
- OPHD: 온폴리시 하드 네거티브 증류 — 학생이 자신의 검색으로 혼동 후보를 고르고, Qwen3-VL-8B 리랭커가 세밀한 관련성 분포를 제공하며, 역KL이 학생의 유사도 분포를그것에 맞추고, 후보는 학생 스냅샷으로 주기 갱신된다.
- 4개구성(두 백본 세대, 예: Qwen3-VL-2B/4B)에서 MMEB-v2, UVRB, MRMR SOTA: UVRB 평균 56.2(4B), 49.6(2B) vs 종전 52.9, 44.7.
- 랭킹 점수/마진 손실(CPRD류)이나 반복 증류와 달리, OPHD는 학생이 선택한 하드 네거티브에서 학생의 전체 유사도 분포를 교사 관련성에 역KL로 맞춘다.

## 상세

DiLE는 2단계(TLSL+SPEA 후 OPHD)로 단일 벡터 인코더를 학습한다. 검색 벡터는 잠재 쿼리의 은닉 상태를 풀링해 얻는다. 하드 네거티브 관련종래 방법에는 랭킹 점수/마진, CPRD의 정보성 하드 네거티브 상대 순서, 갱신된 검색기로 후보를 고르는 반복 증류, Rabtriever의 생성 리랭커로부터의 토큰 수준 역KL 증류가 있다. OPHD는 학생 자신의 검색 정책이 어떤 네거티브를 배울지 결정하게 함으로써 온폴리시 증류를 검색에 적용한다. 평가는 MMEB-v2, UVRB(3작업 × 3도메인 × 3하위 도메인 16개 데이터셋), MRMR에서 이루어지며, 한 모달리티나 작업 유형에 국한되지 않음을 보이기 위해 그룹별로 결과를 보고한다.
