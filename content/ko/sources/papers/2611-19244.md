# 에이전트 온폴리시 증류는 LLM의 ReAct 패턴을 암묵적으로 재구성한다

**Source**: [arXiv](https://arxiv.org/abs/2611.19244)
**게시일**: 2026-11-14

## Overview

온폴리시 증류(OPD)는 학생 모델이 생성한 궤적을 감독하여 전문 능력을 언어모델 에이전트에 이전하는 기법이지만, 상호작용 행동에 미치는 교차 도메인 효과는 불분명했다. 이 논문은 순수 자연어 일반 추론(GR), 코드 해석기 도구를 쓰는 일반 추론(CI), ALFWorld(ALF), τ²-bench의 네 도메인에서 OPD가 ReAct(추론–행동–관찰) 패턴을 어떻게 바꾸는지 살피고, 단일 도메인 OPD와 다중 도메인 MOPD 혼합을 모두 분석한다.

핵심 발견은 두 가지다. 첫째, 도메인 감독은 답에 도달하는 경로를 바꾼다. GR 감독은 수학 과제의 도구 시도율을 70.4%에서 14.4%로 낮추면서 정확도를 16.7%에서 38.0%로 높인다. 둘째, ALFWorld 감독은 심각한 부정적 전이를 일으킨다 — τ²-bench 정확도가 41.5%에서 6.6%로 급락하고, 사용자 정보 의존성을 위반하는 도구 호출이 잦아진다. 소스 도메인 학습 궤적만으로 이를 완화하기 위해, 저자들은 도메인 특화 RL 전후의 교사 선호도 변화에 기반한 선택적 OPD를 탐구하며, 상위 95% 위치를 유지하면 τ²-bench 정확도가 11.5%에서 29.9%로 회복된다(소스 학습 상충 관계 존재).

## Key points

- CI-only OPD는 ALFWorld 정확도를 0.129→0.402(+0.273), τ²-bench를 0.415→0.510(+0.095)으로 높인다. 반면 ALF-only OPD는 τ²-bench를 0.415→0.066(−0.349)으로 급락시킨다. 도메인 감독의 효과는 자기 과제를 넘어 전이되며, 소스–타깃 쌍마다 결과가 다르다.
- GR 감독은 수학을 자연어 유도 쪽으로 이동시킨다: 도구 없는 정답 비율이 Base 2.4%→30.1%, 도구 시도율 70.4%→14.4%, 루프형 코드 궤적 304→97건, solver 호출 75→8건, 정확도는 38.0%로 상승. ALF 감독도 유사한 이동(정확도 38.3%, 도구율 11.5%)을 보이고, CI 감독은 73.0%의 도구 시도율과 47.6%의 도구 포함 정답 비율(정확도 52.4%)을 유지한다.
- CI→ALFWorld: 정확도 12.9%→40.2%, 정확 반복율 4.5%→0.7%, 피드백 후 변경율 90.8%→94.3%. CI→τ²-bench: 도구 시도 비율은 거의 불변(95.8%→95.9%), 리테일 정확도 0.481→0.653(추가 성공 76건 중 55건), 참조 쿼리 커버리지 54.5%→67.5%, 오류 피드백 비율 32.6%→23.5%.
- ALF→τ²-bench 실패 양상: 사용자 정보 의존성을 위반하는 도구 호출과 함께 요청형 텍스트를 빈번히 생성 — 마지막 5% 위치에서 ask–call 동시 발생률이 급등한다.
- 선택적 OPD(교사 선호도 변화 Δ 상위 위치만 유지): 토큰 10%만 남겨도 소스 과제(ALFWorld) 이득의 약 80%(14.3%→69.4%)를 얻고 τ²-bench는 31.1%로만 하락; 10%→95%로 늘리면 ALF 정확도는 69.4%→76.6%로 상승하고 τ²-bench는 안정적; 마지막 5% 위치를 넣으면 τ²-bench가 29.9%→11.5%로 급락하고 ask–call 동시 발생률이 24.3%→97.1%로 치솟는다. 무작위 95% 유지는 Top95 결과를 재현하지 못한다.
- MOPD(과제 매칭 감독 혼합)는 ALF 감독이 τ²-bench에 유발하는 대화 실패를 완화한다.

## Details

- 설정: 단일 도메인 OPD 및 2~3개 도메인 MOPD로 학생을 학습하고, 도구 유/무 수학·ALFWorld·τ²-bench에서 소스 도메인 검증 체크포인트로 평가; 큰 롤아웃 배치와 50–60회 업데이트.
- 모델/교사: CI 교사, ALF·τ² 교사를 도메인별로 구성; 학생은 공유 베이스에서 초기화되어 고정 체크포인트로 평가.
- 선호도 기반 선택: 도메인 특화 RL 전후의 교사 선호도 변화(Δ)로 위치를 채점하고 상위 retained fraction(10/20/50/95/99/100%)만 유지; GR→CI 선택적 감독 확장과 GR prefix 감독도 실험.
- 대조군: Advantage Top95/Top98(부호 있는 일반 advantage 하위 5%/2% 제외, 계수 질량이 거의 비교 가능), Absolute-Δ Top95(|Δ| 최소 5% 제외, 크기만 검증), 구조적 마스킹·부정 마스킹, 랭킹 규칙 대조(43.56% vs 41.02% 계수 질량 제거).
- 유의점: 소스 도메인 학습과의 상충 관계가 있으며, 효과는 연구된 도메인·교사·유지 비율 설정에 한정된다. Phase 3는 마지막 5% 토큰이 파괴적 간섭을 담당함을 보여준다.
