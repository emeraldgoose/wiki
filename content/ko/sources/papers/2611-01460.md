# LLM 에이전트는 튜토리얼 동영상을 보고 학습할 수 있을까?

**원문**: [arXiv:2611.01460](https://arxiv.org/abs/2611.01460) · **게시일**: 2026-11-01
**저자**: Haoyu Zhao, Zafeirios Fountas, Jun Wang

## 개요

인간은 책과 튜토리얼 동영상과 같은 정성껏 제작된 자료에서 지식을 습득해 미래 작업에 적용한다. 그러나 대규모 언어 모델 에이전트는 학습 후 고정된 채로 남는다. 논문은 파라미터 갱신 없이도 에이전트가 강의형 동영상에서 학습할 수 있는지를 묻는다. 이를 위해 비모수적 접근법인 Tutorial Agentic Learning (TAL)을 도입하여 방대한 인간 교수 자원을 재사용 가능한 에이전트 지식으로 변환한다. 핵심 아이디어는 튜토리얼 내용을 흡수해 미래 작업에 적용함으로써 비용이 큰 대규모 파라미터 갱신을 피하는 것이다.

## 핵심 내용

- 튜토리얼 동영상에는 풍부한 교수 지식이 담겨 있다.
- LLM 에이전트는 보통 학습 후 갱신되지 않는다.
- 대규모 파라미터 갱신은 비용이 높다.
- 튜토리얼 에이전틱 학습은 파라미터 갱신을 피한다.
- 튜토리얼 이해를 미래 작업으로 전달한다.

## 상세

연구는 수동적 교수 콘텐츠와 능동적 에이전트 행동 사이의 간극을 연결하는 문제를 제시한다. TAL은 튜토리얼 동영상을 단순한 평가 자료가 아니라 지식 원천으로 취급한다. 기본 모델을 고정함으로써 비용과 배포 위험을 제한한다. 방법은 재학습 없이 인간 교수 지식을 다양한 미래 작업에 재사용할 경로를 목표로 한다.
