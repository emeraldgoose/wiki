# Innata-0: 모델-에이전트 공동 설계 기반의 네이티브 체현 월드 시스템

**원문**: [arXiv:2611.30254](https://arxiv.org/abs/2611.30254) · **게시일**: 2026-11-23 (v1)
**저자**: Innata Team 외 39명 (Yu Bai, Ziyi Bai, Yuxuan Cai 등; 전체 목록은 arXiv 초록 페이지 참조)

## 개요

물리 세계에서 신뢰할 수 있고 적응적인 행동을 지원하기 위해 저자들은 월드 모델과 에이전트를 함께 설계·정렬하는 네이티브 체현 월드 시스템 Innata-0를 제안합니다. 모델 쪽에서는 월드 액션 모델이 월드 이해와 비디오 생성을 담당하는 두 개의 8B 타워(각 36층)와, 은닉 폭 1280·FFN 3840으로 줄인 별도 파라미터의 약 1B 액션·촉각 생성 타워를 결합합니다. 에이전트 쪽에서는 Innata-0-Agent가 시스템 코디네이터로서 장문 계획, 실패 복구, continual evolution을 지원하며, 공유 컨텍스트, 구간 단위 설명, 의미적 하위 작업, 실행 결과, 증거를 담은 통합 주석 레코드를 사용합니다. 하나의 레코드는 여러 데이터 준비 브랜치에서 재사용됩니다.

체현 데이터는 통합 정보 추출 및 주석 파이프라인으로 구축됩니다. Qwen3.8-Flash-Next가 한 번의 구조화된 응답으로 의미·관계·시간·지각 품질 필드를 생성하고, DOVER, VTSS, LAION 미학 예측기, PaddleOCR로 품질을 필터링합니다. 학습 데이터는 비전-언어 이해, 비디오 생성, 그리퍼 및 정교한 조작(그리퍼 열림을 [0,1]로 정규화, 고정 128채널 관절 레이아웃, Hand32 기능 각도, Ego128 기반의 1인칭(Ego) 표현), 촉각 센싱에 걸쳐 있습니다. 손 재구성은 13개 데이터셋의 관절·MANO감독는으로 학습된 모델을 사용하며, Wan2.2-Fun-5B-Control 특징을 기반으로 1인칭 비디오를 손 골격과표준 손목에 정렬된 기능 각도로 매핑합니다.

평가에서는 오픈소스 최고 수준의 체현 성능을 보입니다. WorldArena 2.0 Track 1에서 EWM 67.63, RoboCasa365에서 전체 성공률 60.2%, Atomic-Seen 작업에서 88.4%로 1위를 기록했습니다. 인프라 섹션에서는 대규모 학습 레시피를 보고합니다. 기울기 누적 2스텝, BF16, 전체 재계산, 정적 컴파일을 적용하면 텍스트-투-비디오 레시피가 마이크로배치당 3,072 U / 98,304 V 토큰을 지원합니다. 128개 GPU에서 온라인 T2V 감사는 MFU 31.04%(트랜스포머만 25.28%)를 달성했고, 패킹은 DROID 액션 처리량을 9.64에서 22.39 샘플/s로 높였으며, 고정 형태와 컴파일은 36.76 샘플/s(추가 워커 시 39.09)를 달성했습니다. 호스트 메모리는에 695에서 335 GiB로 감소했습니다.

## 핵심 내용

- WorldArena 2.0 Track 1: EWM 67.63으로 오픈소스 모델 중 최고; RoboCasa365: 전체 성공률 60.2%, Atomic-Seen 88.4%(1위).
- 월드 액션 모델 = 36층 8B 타워 2개(이해 + 비디오 생성) + 폭을 줄인 약 1B 액션/촉각 타워(은닉 1280 / FFN 3840).
- 통합 주석 레코드(공유 컨텍스트, 구간 설명, 하위 작업, 결과, 증거)가 데이터 준비 브랜치 간에 재사용되며 에이전트의 메모리/검증/복구 루프에 공급됩니다.
- 액션 표현: 고정 128채널 관절 레이아웃, [0,1]로 정규화된 그리퍼 열림, Hand32 기능 각도, 양손목+양손+카메라를 묶은 Ego128 1인칭 표현; 13개 데이터셋의 MANO감독는으로 Wan2.2-Fun-5B-Control 특징 위에서 손 재구성.
- 인프라: 128-GPU T2V MFU 31.04%; 컴파일된 정적 버퍼 36.76~39.09 샘플/s(DROID 액션 패킹 전용 9.64 대비); 64K→96K 토큰 전환에서 8.9% 처리량 향상; 호스트 메모리 695→335 GiB; 어텐션(FlagGems) 1.39~1.41배 커널 가속, 추론 커널 시간의 34% 차지.

## 상세

2~3장은 데이터 구축(2.1~2.6: 개요, 통합 추출/주석, VLU 데이터, 비디오 생성 데이터, 그리퍼 2.5.1과 정교한 조작 2.5.2를 포함한 액션 데이터, 촉각 데이터)과 월드 액션 모델(3.1 아키텍처, 3.2 인프라, 3.3 학습)을 다룹니다. 4장은 에이전트(작업 구조/실행, 검증 및 적응적 복구, 경험 기반 진화, 인프라)를 다룹니다. 5장은 이해, 비디오 생성, 정책, 촉각 피드백이 있는 정책을 평가합니다. 부록 8~13은 통합 주석 레코드, 이해 학습, 정교한 손(1인칭 손 재구성, Hand32/Ego128), 촉각 모델링, 인프라 세부사항(실험 조건, 실행 트레이드오프, FLOP 회계, 8-GPU 연속 에 걸쳐 11,136개 논리 상태를 유지하는 복구), 에이전트 구현/도구 세트를 다룹니다.
