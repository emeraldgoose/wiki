# Random is almost enough? BestRand를 이용한 안정적이고 저비용인 벤치마크 압축

**원문**: [arXiv:2611.00883](https://arxiv.org/abs/2611.00883) · **게시일**: 2026-10-31
**저자**: George Ling, Shanshan Zhong, Lijin Yang, Hao Yang, Nanxiang Li, Zhongzhan Huang

## 개요

벤치마크 압축은 전체 벤치마크 점수에 가까운 결과를 내는 작은 부분 집합으로 모델을 평가해 평가 비용과 시간을 줄이려 한다. 본 논문은 추정 오차를 정량적으로 분석해 대부분의 무작위 부분 집합은 작은 오차를 내지만 일부는 훨씬 큰 오차를 내는 long-tailed 분포를 보인다는 점을 보여준다.

따라서 무작위 샘플링만으로도 높은 확률로 강한 성능을 얻을 수 있지만 드물게 발생하는 큰 오차 때문에 불안정하다. 이런 불안정성은 현대 기초 모델에 내재되어 있으며 모델 평가 수가 늘어나도 지속된다. 논문은 무작위 샘플링의 효율을 유지하면서 high-error tail을 줄이는 BestRand를 제안한다.

BestRand는 70개 이상의 text, multimodal, agent benchmarks와 vision-language-action 평가에서 검증된다. 높은 오차 위험과 평균 추정 오차를 줄이고 construction cost도 크게 낮추며, score-range, model-family, temporal shift를 포함한 out-of-distribution estimation error도 개선한다.

## 핵심 내용

- 대부분의 무작위 벤치마크 부분 집합은 작은 추정 오차를 내지만 드물게 큰 오차가 생긴다.
- 모델 평가 수가 늘어나도 오차 불안정성이 지속된다.
- BestRand는 무작위 샘플링 효율을 유지하면서 high-error case를 줄인다.
- 70개 이상 benchmark와 VLA 평가에서 방법을 검증한다.
- 높은 오차 위험과 평균 추정 오차를 낮춘다.
- 여러 shift type에서 out-of-distribution estimation을 개선한다.

## 상세

논문은 추정 오차 분포에 대한 analytical approximation과 benchmark compression accuracy와 reliability를 예측하는 실질적 guidance를 제공한다. 코드와 데이터가 공개되어 추가 연구를 지원한다. 이 연구는 preprint이다.
