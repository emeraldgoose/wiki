# AURA 2.0: 사용자 주도 응답에서 모델 주도 대화로 — 스트리밍 비디오에서의 대화 시작

**Source**: [arXiv](https://arxiv.org/abs/2611.17048)
**게시일**: 2026-11-12

## Overview

화웨이 리서치(HKUST·CUHK MMLab 공동)의 AURA 2.0은 사용자 주도 상호작용을 넘어서는 스트리밍 비디오 대형 언어 모델이다. 핵심 발전은 Model-Initiated Conversation(MIC)으로, 모델이 진화하는 시각 스트림에서 논의할 가치가 있는 주제를 식별하고 사용자 질의 없이도 적절한 시점에 대화를 시작하며, 대화 맥락을 이용해 반복적이거나 불필요한 끼어들기를 피한다. 두 가지 추가 능력도 상호작용 표면을 확장한다. Stream-Aware Tool Calling(SATC)은 현재 시각·대화 맥락에서 외부 도구를 호출하고 반환된 정보를 진행 중인 상호작용에 반영하며, Interactive Visual Grounding(IVG)은 사용자 입력(사용자가 프레임에서 표시한 객체)과 모델 출력(응답을 특정 영역에 연결하는 프레임 정렬 박스) 양쪽에서 바운딩 박스를 지원한다.

이를 위해 AURA의 스트리밍 상호작용 데이터셋을 MIC/SATC/IVG 데이터로 확장해 약 114억 토큰, 5,400시간의 비디오, 4,000만 학습 프레임 규모를 구성했고, MLLM 기반 샘플 단위 검증으로 질의·응답·도구 호출·박스를 일관된 비디오 타임라인에 정렬했다. 학습은 3단계(스트리밍 상호작용·도구 사용 기반 → 시각 그라운딩·모델 주도 대화 → 능력 조합·선호 정제)로 진행되며, response-control 토큰에는 focal-loss 기반 감독을 적용한다. Long-Horizon Interaction Memory(LHIM)는 활성 시각 창을 벗어난 주요 사건을 텍스트 맥락으로 요약해 보존한다. 모델 가중치와 추론 코드는 오픈소스로 공개된다.

## 핵심 내용

- IPIBench: Proactive Monitoring Timing 정확도 49.30%(GPT-4o 50.59%에 근접), Repeated Proactiveness 17.92%(Gemini 3 Pro 18.40%에 근접), Proactive Task Management 평균 최고(Cancel 37.96%, Multi 17.87% — Gemini 2.5 Pro와 GPT-5.4 초과), R2P/RuP/RaP 24.10/11.74/18.65(R2P는 Gemini 3 Pro 24.76%와 비슷).
- StreamArena: Real-Time Perception 28.5%, Historical Retrospection 24.5%(L4 17.0%, AURA 및 기타 오픈소스 스트리밍 모델 초과). Proactive Interaction은 AURA 3.7% → 12.8%(L1 29.7%)로 상승해 JoyAI-VL-Interaction(9.4%)과 MOSS-VL-Realtime(11.8%)을 상회. Tool use 18.5%로 둘 다 상회.
- ProactiveVideoQA와 PhoStream: 오픈소스 스트리밍 모델 중 최고 수준의 성능을 보고(전체 표는 논문 참조, PAUC 및 공식 프로토콜로 평가).
- MIC-Bench(내부, 25개 비디오, 50개 인스턴스): 대화 맥락 설정에서 트리거율 80.0%(20/25), 품질 4.10/5, 3.0 msgs/min. 시각 전용 설정에서는 트리거율 96.0%(24/25), 품질 3.62/5, 3.5 msgs/min(173개 메시지: Good 93 / Neutral 65 / Bad 15).
- SATC(55개 클립, 167개 질문): 도구 사용으로 정확도가 35.9% → 48.5%(+12.6 pp)로 향상. 질문의 41.3%에서 도구를 호출(총 73회).
- IVG(COCO 50장 진단 세트): mIoU 0.906(백본 Qwen3.5-9B 0.635), 정확도 94.0%(76.0%), 양성 쿼리 37/37에 박스 반환(26/37), 부재 대상 올바른 기권 11/13(백본 13/13).
- 추론 효율(가속기 2장 ~140 GB, OmniInteract 스트림, 풀링된 턴의 중앙값): 1세션 TTFT 157 ms / TTFP 344 ms / RTF 0.135; 8세션 184/449/0.161; 16세션 234/601/0.203.

## 상세

- 아키텍처: AURA 2.0은 AURA(Lu et al., 2026a)를 기반으로 Real-Time QA, Proactive QA, Multi-Response QA를 유지하면서 MIC, SATC, IVG를 추가한다. 스트리밍 응답 결정은 지금까지 관찰된 정보만 사용한다.
- 학습: 3단계 — (1) 스트리밍 상호작용·도구 사용 기반, (2) 시각 그라운딩·모델 주도 대화, (3) 능력 조합·선호 정제. response-control 토큰의 클래스 불균형을 완화하기 위해 focal-loss 기반 감독을 적용한다.
- 데이터: 약 114억 토큰, 5,400시간 비디오, 4,000만 프레임. MLLM 기반 샘플 단위 검증으로 질의·응답·도구 호출·바운딩 박스를 공유된 비디오 청크 타임라인에 정렬한다.
- LHIM: 관찰이 활성 시각 창을 벗어나면 주요 사건을 텍스트 설명으로 요약해 대화 맥락에 반영하여, 사용자 질의와 MIC 주제 선택 모두에서 이전 사건을 참조할 수 있게 한다.
- MIC 평가 참고: 두 설정(주석된 트리거 창이 있는 Visual-Dialogue Context, 전체 비디오 대상 Visual-Only Context)은 직접 비교 불가. MLLM 판정자(gpt-4o)가 메시지를 채점하고 두 명의 주석자가 모든 판정 출력을 검토했다. 끼어들기 비용은 재생 전체의 분당 메시지 수(중앙값)로 추적한다.
- SATC 예시: WebSearch로 "Zaochake" 예약을 Xizha 워터마켓의 아침 식사 체험으로 식별하고, 자막의 인물 이름(Lu Wenzhao, Shen Lian)에서 Brotherhood of Blades II를 식별한다. 실제 날씨 질의에서는 콜로세움으로 로마를 인식해 get_current_datetime과 get_city_weather를 호출한다.
- 한계: 사용자의 명시적 요구가 없으면 MIC 품질이 낮아지고(3.62 대 4.10), 일부 주석된 트리거 창이 다뤄지지 않으며, 부재 대상에 대한 기권이 백본보다 덜 안정적이다(11/13 대 13/13).
- 오픈소스: 재현 가능한 연구를 위해 모델 가중치와 추론 코드가 공개된다.
