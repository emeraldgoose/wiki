# 듀얼 플로우: 역문제를 위한 이미지-측정 결합 보간

**Source**: [arXiv:2611.05843](https://arxiv.org/abs/2611.05843) · **게시일**: 2026-11-04
**Authors**: Sevket Ege Yesilyurt, Figen S. Oktem

## 개요

선형 역문제 — 블러 제거, 초해상도, 압축 센싱 등 — 를 푸는 생성 모델 기반 방법들은 대개 획득한 잡음 낀 측정값을 이미지 영역 샘플링의 조건 신호로만 취급한다. 이미지에 대한 확산·흐름 사전이 데이터 정합 항, 가이던스, 사후 샘플링 기법으로 유도되는 방식이다. Dual Flow는 측정값을 이렇게 밖에 두지 않는다. 하나의 잡음 낀 관측값에서 깨끗한 이미지와 그에 대응하는 무잡음 측정값을 동시에 추정하는 결합 추정 문제로 과제를 정식화하고, 이미지 영역과 측정 영역을 동시에 달리는 결합 흐름 모델로 푼다.

메커니즘은 유용한 방식으로 비대칭이다. 획득한 잡음 측정값은 측정 상태를 초기화하는 데만 쓰인다. 그 뒤로는 이미지 상태와 측정 상태가 현재값에 기반해 결합 갱신되며 더 이상 원시 관측값에 직접 의존하지 않는다. 두 상태가 결합 흐름 아래에서 함께 진화하기 때문에, 최종 이미지·측정 추정값은 구조적으로( By construction) 기저 순방향 모델을 만족함이 보장된다. 즉 이미지와 측정이 서로를 잇는 물리 법칙에 합의하는 지점까지 보간된 쌍이 나온다.

논문은 이 결합 흐름의 샘플링 갱신식을 유도하는데, 여기에는 결합 상태가 주어졌을 때 깨끗한 이미지의 조건부 기댓값이 필요하다. 아울러 결합 상태의 충분통계량에 대한 폐형 표현식을 증명한다. 이 환원이 실용적으로 중요하다. 요구되는 조건부 기댓값을 연산자 의존적이고 상관된 잡음을 가진 이미지 영역 가우시안 디노이징 문제 풀기로 얻을 수 있어서, 이 정식화로 학습한 단일 속도 예측 네트워크가 유도된 충분통계량에서 조건부 기댓값을 추정한다. 다양한 선형 역문제와 이미지 데이터셋 실험에서 왜곡 지표와 지각 품질 양면에서 최고 수준 성능을 보고하며, 추론 단계 수를 넘어서는 하이퍼파라미터 튜닝 없이 경쟁 방법보다 짧은 복원 시간을 달성한다.

## 핵심 내용

- 결합 정식화: 이미지 복원과 측정 디노이징을 하나의 결합 추정 문제로 취급하고, 이미지 전용 샘플러를 측정값으로 조건화하는 대신 이미지·측정 두 영역의 결합 흐름으로 푼다.
- 관측값의 일회용: 잡음 낀 측정값은 측정 상태 초기화에만 쓰이고, 이후 결합 갱신은 현재 이미지·측정 상태에만 의존한다.
- 구조적 순방향 모델 정합: 최종 이미지·측정 추정값이 기저 순방향 모델을 만족함이 보장되어, 복원 결과와 디노이즈된 측정값이 같은 궤적의 상호 정합 출력으로 나온다.
- 이론적 환원: 결합 흐름 샘플링 갱신에는 결합 상태가 주어진 깨끗한 이미지의 조건부 기댓값이 필요하고, 이 값은 결합 상태의 폐형 충분통계량으로부터 계산 가능하다.
- 실용적 학습 목표: 조건부 기댓값이 연산자 의존적·상관 잡음의 이미지 영역 가우시안 디노이징 문제로 환원되며, 속도 예측 네트워크가 충분통계량에서 이를 추정하도록 학습된다.
- 실험 결과: 다양한 선형 역문제와 이미지 데이터셋에서 왜곡 지표(오차 기반 척도 등)와 지각 품질 양면에서 최고 수준 성능.
- 사용 편의성: 추론 단계 수 선택 외 하이퍼파라미터 튜닝이 필요 없고, 복원 시간이 경쟁 방법보다 짧다.
- 점 추정을 넘어서: 모델 불일치에 대한 강건성 분석, 다양한 그럴듯한 복원 생성, 복원 불확실성 특성화 분석이 추가로 제공된다.

## 상세

### 결합 흐름의 구성

모델은 이미지 상태와 측정 상태 두 개를 유지하며 결합 흐름이 이들을 지배한다. 원시 데이터가 들어오는 곳은 초기화뿐이다. 잡음 측정값이 측정 상태를 시드하고, 이미지 상태는 사전에서 출발한다. 이후 샘플러는 각 상태의 속도가 시스템의 결합 상태에 의존하는 결합 갱신을 반복한다. 깨끗한 이미지 추정이 측정 디노이징과 얽힌다. 측정 상태가 정화되면 순방향 연산자를 통해 이미지 상태를 구속하고, 이미지가 선명해지면 그럴듯한 무잡음 측정의 모습에 되먹임된다.

### 충분통계량이 중요한 이유

결합 흐름의 샘플링 갱신은 순진하게는 결합 사후분포에 대한 기댓값을 요구한다. 논문의 폐형 충분통계량은 샘플러가 결합 상태에 대해 알아야 할 것을, 깨끗한 이미지의 조건부 기댓값을 계산할 수 있는 양으로 압축한다. 이 조건부 기댓값이 가우시안 디노이징 문제로 정식화될 수 있고(잡음 구조가 순방향 연산자에 의존하고 픽셀 간 상관됨), 전체 샘플러가 학습된 디노이징형 네트워크의 반복 평가로 환원된다. 이것이 방법을 구체적으로 만든다. 유도된 정식화로 학습한 단일 속도 예측 네트워크가 모든 갱신을 담당한다.
