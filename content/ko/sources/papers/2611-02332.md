# LEANGUARD: 도구 사용 에이전트를 위한 Lean 검증 가드레일

**원문**: [arXiv:2611.02332](https://arxiv.org/abs/2611.02332) · **게시일**: 2026-11-02
**저자**: Sreehari Sankar, Debargha Ganguly, Vikash Singh, Mohsen Hariri, Weicong Chen, Yanyan Zhang, Shouren Wang, Wang Yang, Chaoda Song, Alexander Nemecek, Osama Zafar, Idan Davidovich, Yuting Shao, Kai Ye, Biyao Zhang, Xinpeng Li, Joe Stubbs, Erman Ayday, Jing Ma, Vipin Chaudhary

## 개요

도구 사용 언어 모델 에이전트는 도메인 정책이 금지한 동작을 실행할 수 있다. LeanGuard는 호출이 환경에 도달하기 전에 모든 제안된 도구 호출을 Lean4로 작성된 정책과 비교 검사하는 런타임이다. 정책은 실행 히스토리에 대한 범위 있는 과거 시점 시각 연산자와 상태 조건을 결합한다. 평가는 실패 시 차단으로 동작하고 의사결정 절차는 LeanLTL 의미론과 동등함이 증명된다. 거부된 호출은 피드백을 통해 규칙과 힌트를 전달하거나, 메타프로그래밍이 더 나은 호출을 검색하는 증명 기반 복구로 교정할 수 있다.

## 핵심 내용

- 도구 호출은 실행 전에 검사된다.
- 정책은 Lean4로 작성된다.
- 정책은 상태와 시간적 히스토리 제약을 결합한다.
- 평가는 실패 시 차단으로 동작한다.
- 의미론은 LeanLTL과 검증된다.
- 거부된 호출에는 피드백 또는 복구를 제공한다.

## 상세

동기는 도메인 안전 제약이 모델 동작에만 의존해서는 안 된다는 것이다. LeanGuard는 정책 명세와 실행을 분리하고 형식 검증을 사용해 거부 결정을 신뢰할 만하게 만든다. 두 교정 경로는 에이전트에게 실행 가능한 정보를 준다. 하나는 위반 규칙을 직접 식별하는 피드백이고, 다른 하나는 허용 가능한 대안 호출을 검색하는 증명 기반 복구이다. 설계는 도구 사용 에이전트를 위한 검증 가능한 가드레일을 강조한다.
