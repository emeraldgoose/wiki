# NorthCUA 기술 보고서: 경험 수집을 통한 컴퓨터 사용 에이전트 가속

**원문**: [arXiv:2611.02102](https://arxiv.org/abs/2611.02102) · **게시일**: 2026-11-01
**저자**: Chaoyun Zhang, Bingxuan Li, Pinxue Guo, Yangfan Gao, Zikun Cai, Tianci Xie, Hui Li, Yuqi Huang, Yifei Cao, Bo Mao, Tian Tang, Qichang Zheng, Tongtong Liu, Xiaoxing Wang, Jinxiu Liu, Lizhi Lin, Zhou Shao, Maosen Zhou, Miao Zheng, Shuo Zhang, Yangji He, Kepeng Lei, Ning Zhao, Wei Shen, Zhenjiang Jin, Xinyue Zhang, Peng Sun, Zhenhua Han, Rui Zheng, Hang Yan

## 개요

개별 동작에서 복잡한 소프트웨어 작업으로 컴퓨터 사용 에이전트를 확장하려면 결정과 완전한 결과를 연결하는 경험이 필요하다. NorthCUA는 대규모 경험을 통해 컴퓨터 사용 에이전트를 가속하는 통합 시스템이다. Experience Flywheel은 다양한 실행 가능한 작업을 NorthCUA Harness에 공급하고, 하네스는 긴 상호작용을 유지하며 결정을 기록하고 작업 결과를 확인한다. 이 기록은 검증된 궤적을 큐레이션하는 데 사용된다. 풀리지 않은 작업에는 재귀적 자기 개선이 재사용 가능한 기술을 발전시키고 검증된 중간 지점을 보존하여 나중 시도에 활용한다.

## 핵심 내용

- 컴퓨터 사용 에이전트는 완전한 결과와 연결된 경험이 필요하다.
- NorthCUA는 작업 공급, 실행, 검증을 통합한다.
- Experience Flywheel은 다양한 실행 가능한 작업을 공급한다.
- 하네스는 긴 상호작용을 유지하고 결과를 확인한다.
- 상호작용 기록에서 검증된 궤적을 큐레이션한다.
- 재귀적 기술 발전이 풀리지 않은 작업을 돕는다.

## 상세

시스템은 소프트웨어 작업 시도와 성공 경험 재사용 사이의 루프를 닫는다. 작업 다양성은 플라이휠에서, 신뢰성은 결과 확인에서 나온다. 에이전트 동작만 샘플링하는 데 그치지 않고 NorthCUA는 전체 상호작용을 기록하고 검증해 결정과 결과를 연결하는 데이터를 만든다. 여전히 풀리지 않은 작업의 경우 재사용 가능한 기술과 보존된 중간 지점이 나중 시도를 더 유능하게 만든다. 초점은 개별 동작을 넘는 컴퓨터 사용 능력 확장이다.
