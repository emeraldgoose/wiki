# OpenFlyV2: 항공 인지와 탐색을 위한 온보드 시각-언어-행동 모델

출처: Junli Liu 외 11인, arXiv:2610.39287, 2026-10-29.

**핵심 요약**: 인간 인지는 환경을 이해하고 지시 대상에 주의를 두며 공간 관계를 추론하고 행동하기 위해 공유된 지각 기초를 유연하게 사용합니다. 항공 로봇에 유사한 기능 구조를 부여하는 일은 여전히 어렵습니다. 기존 시스템은 개별 능력에 특화되거나 오프보드 계산에 의존하며 자원 제약 플랫폼에서 폐루프 동작을 유지하지 못합니다. **OpenFlyV2**는 공유 시각-언어 표현을 사용해 의미 이해, 언어 접지 인지, 공간 추론, 연속 항공 제어를 **하나의 모델**에서 수행하는 통합 온보드 비전-언어-행동 아키텍처입니다. compact action expert가 공유 멀티모달 문맥을 단기 비행 웨이포인트로 변환하고, motion-aware temporal memory와 action prior가 폐루프 실행의 계산 비용을 줄입니다. 저자는 70,000개 탐색 궤적과 60,000개 시각-언어 지시-응답 쌍으로 구성된 시뮬레이션 데이터셋을 만들었습니다. OpenFlyV2는 NVIDIA Jetson Orin NX에서 **12웨이포인트 액션 청크를 10Hz로 전부 온보드 생성**합니다. 실세계 항공 훈련 데이터 없이 시뮬레이션에서 물리 쿼드로터 비행으로 제로샷 전이해 네 실제 환경에서 **48% 탐색 성공률**을 달성했습니다. 결과는 넓은 시각-언어 역량과 연속 폐루프 비행이 자원 제약 항공 플랫폼의 단일 모델에서 공존할 수 있음을 보여줍니다.

## 핵심 내용

- 공유 시각-언어 표현이 인지·추론·제어를 한 모델에서 지원한다.
- compact action expert가 단기 웨이포인트를 생성한다.
- motion-aware temporal memory와 action prior가 폐루프 비용을 줄인다.
- 데이터는 약 70,000개 궤적과 60,000개 지시-응답 쌍으로 구성된다.
- 12웨이포인트 청크를 Jetson Orin NX에서 10Hz로 온보드 생성한다.
- 실세계 훈련 데이터 없이 네 환경에서 48% 성공률을 달성했다.
- 시뮬레이션에서 실드론으로 제로샷 전이한다.

## 상세

온보드 설계는 오프보드 의존성을 피하고 의미·공간 역량을 연속 제어와 결합합니다. 효율성은 별도 특화 모듈 대신 compact 액션 생성과 메모리/action prior에서 옵니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 데이터셋 생성 절차와 비행 평가 세부는 원문을 함께 확인해야 합니다.
