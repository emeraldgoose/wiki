# TeleChat에서 Xing4로: 국내 칩·프레임워크 기반 프런티어 에이전틱 모델의 발전

**Source**: [arXiv](https://arxiv.org/abs/2611.22115)
**게시일**: 2026-11-17

## Overview

Xing 4는 TeleChat 계보를 확장한 대규모 언어 모델 시리즈로, GPU가 아닌 Ascend(국내 칩)에서 모델 아키텍처와 학습 인프라의 공동 발전을 통해 개발됐다. 대부분의 오픈소스 모델은 GPU로 학습되지만 국내 칩과 프레임워크에서의 스케일링은 상당한 시스템 도전을 제기한다. 이 보고서는 시리즈의 설계 원칙과 시스템 엔지니어링을 다룬다: 희소 활성화, attention 설계, 깊이/폭 트레이드오프, speculative decoding, 아키텍처 선택, 대규모 사전학습, 추론·에이전틱 사후학습.

대표 구성은 장문맥 serving을 위해 MLA에 DSA와 cross-layer IndexShare를 결합하고, 안정성과 효율을 위한 최적화된 MHC 연산자, 더 넓고 얕은 mixture-of-experts(MoE) 토폴로지, speculative decoding을 위한 블록 단위 draft 모델과 경량 보정 head의 조합을 채택한다. 저자들은 29B MoE 멤버를 공개했다 — MindSpore로 Ascend NPU에서만 학습됐고 토큰당 4B 파라미터만 활성화하며 네이티브 256K 토큰 컨텍스트를 지원한다. 285B 파라미터 모델은 대규모 프로덕션 클러스터의 8,192장 Ascend 910C로 사전학습됐다.

## Key points

- 공개된 Xing4 29B MoE: 토큰당 4B 활성 파라미터, 네이티브 256K 컨텍스트, Ascend NPU + MindSpore로만 학습 — 시리즈의 첫 완전 공개 멤버.
- 측정된 시스템 이득: MLA 단독 대비 최대 4.68배 prefill 처리량; speculative decoding으로 2.67~3.77배 디코딩 처리량; 파이프라인 병렬 제거로 16.1% 처리량 향상.
- 사전학습 인프라(MindSpore HyperParallel): 토폴로지 인식 hybrid sharded data parallelism(HSDP), 분산 Muon 옵티마이저의 owner-based 실행, 객체 기반 제외와 메모리 예산 기반 선택을 갖춘 fine-grained selective recomputation, DSA 장문맥 학습 최적화(레이어별 indexer backward, Q-block pairing·layout planning, 문서 인식 KV Compact); CPU affinity와 core isolation으로 호스트 스케줄링 간섭 감소.
- 사후학습: TeleGym — 실행·평가·궤적 구성을 정책 최적화로 연결하는 통합 에이전트 실행 플랫폼. 분리형 비동기 실행, 상한 있는 oversampling, partial rollout으로 이질적인 과제 지속 시간을 수용하면서 정책 업데이트 사이의 궤적 연속성을 보존. 과제 합성은 일반 에이전트와 코드 에이전트를 포괄.
- 범위: 이 보고서는 점증하는 추론·에이전트 워크로드와 다양한 규모로의 Xing 4 지속 개발을 위한 Ascend 지향 학습 기반을 확립한다. trillion 파라미터 학습이 진행 중이다.

## Details

- 아키텍처: 장문맥 attention(MLA + DSA + cross-layer IndexShare), 깊이/폭 트레이드오프를 명시적으로 연구, 블록 단위 draft 모델 + 경량 보정 head의 speculative decoding; 최적화된 MHC 연산자; 더 넓고 얕은 MoE 토폴로지.
- 클러스터: 8,192장 Ascend 910C로 285B 사전학습; CPU affinity/core isolation; HyperParallel 분산 스택.
