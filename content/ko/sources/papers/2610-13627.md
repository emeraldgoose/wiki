# AMLworld-Compact: 비용 효율적 LLM 평가와 오류 진단을 위한 중요도 가중 다운샘플링

**Source**: Nitarach 외, arXiv, 2026-10-09

**핵심**: AMLworld 최소 테스트 분할의 LLM 평가는 거래마다 그래프 프롬프트가 필요해 한 번에 백만 건이 넘는다. 저자들은 HT-Coreset 프로토콜로 만든 AMLworld-Compact를 제시한다: 모든 불법 테스트 거래를 유지하고, 지도 점수 난이도 층에서 정상 거래를 표집한 뒤, Horvitz–Thompson 포함 가중으로 전체 테스트 지표를 추정한다. 이 프롬프트에서 7개 오픈 가중 LLM의 가중 정밀도는 전부-불법 예측 기준선 수준에 머문다—높은 재현율에 변별력은 거의 없다.

## 배경

자금세탁 탐지는 거래가 불법 활동에 속하는지 묻고, 근거는 다중 홉 계좌/송금 이웃(예: gather-scatter 패턴)에 걸친다. AMLworld의 HI-Small·LI-Small 테스트 분할은 각 백만 건이 넘고 불법 비율은 0.12%·0.05%에 불과하다. 클래스 비례 소표본은 불법 사례가 너무 적고, 균형 표본은 비가중 정밀도·F1을 왜곡한다. 선행 연구의 소규모 균형 부분집합 점수는 실제 유병률이 아닌 부풀려진 불법 비중을 반영한다. 목표는 모델 호출 감소, 희귀 사례 전수 유지와 진단, 전체 테스트 지표 추정의 세 가지다.

## HT-Coreset 구축

전체 테스트 분할과 지도 점수(LightGBM·XGBoost·GCPAL + GFP 그래프 피처)를 입력으로 한다:

1. **불법 엣지 전수 유지**(HI-Small 1,251건, LI-Small 756건)—재현율 신호와 8개 유형 모두 보존.
2. **정상 엣지의 난이도 층화**: 평균 스코어 확률의 난이도 $d(e) = 1 - 2\lvert\bar{p}(e) - 0.5\rvert$로 하드 네거티브(고득점 정상)에 정상 예산 최대 30%를 배정하고 나머지를 3개 난이도 3분위로 나눠 모든 정상 엣지가 양의 포함 확률을 갖게 한다.
3. **역포함확률 가중** $w_e = 1/\pi_e$: 가중 혼동 행렬이 전체 테스트 추정치가 되며(고정 예측에 불편향), 재현율은 정확하고 정밀도·F1은 비율 추정치다. 비가중 집계는 1:2 부풀림 부분집합 진단용이다.

각 대상은 GFP 피처, 타입화 서브그래프 프롬프트(대상 송신 계좌에서 BFS 깊이 2), 가중치를 함께 제공하며, 이웃은 전체 그래프에서 가져오므로 표집이 건별 문맥을 줄이지 않는다.

## 실험

**설정**: 공개 세트는 HI-Small 3,753건·LI-Small 2,268건(불법:정상 1:2)으로 대상 수 271배·611배 감소. 한 부스터 족을 층 구축에서 제외한 500회 표집으로 오차 검증, 7개 오픈 가중 thinking 모델(GPT-OSS·Nemotron-3·Qwen3.5, 활성 3–27B)을 few-shot·zero-shot 5회씩 평가.

**표집 결과**: 공개 크기에서 HT-Coreset F1 RMSE는 0.00–2.58pp로 균일 표집+HT 가중 4.44–7.41pp를 압도하고 12개 데이터셋–방향–예산 비교 전부 최저이나, 95% 보수 구간 폭은 27–55pp로 넓어 모든 예측자에 정밀 추정을 보장하지는 않는다.

**LLM 탐지 결과(HI-Small)**:

| 지표 | LLM 범위 | 기준 |
|--------|-----------|-----------|
| HT 가중 F1 | 0.230–0.253% | 0.246% (전부-불법) |
| 정밀도 리프트 | 0.94–1.03 | 1.0 (전부-불법) |
| Zero-shot 재현율 | 97.8–100% (1개 모델 82.9%) | — |
| 비가중 F1 | 40.7–50.6% | 68.1% (ML 부스터) |

Few-shot 예시는 탐지보다 유형 식별에 더 일관되게 도움된다. 1,000건 출력 감사에서 어휘 자가 점검 표식은 정답의 84.5%뿐 아니라 오답의 56.2%도 통과한다—통과가 정답 근거가 아니다.

## 소프트웨어 엔지니어를 위한 시사점

불균형 workload의 저렴하고 정직한 LLM 평가 템플릿이다:

- **희귀 사례 전수 유지 + 나머지 층화**: 양성 전부 유지와 저비용 스코어러 난이도 기반 중요도 표집이 균일 표집보다 지표 충실도가 높다.
- **가중치와 비가중치 수치 분리 보고**: 부풀림 데이터의 부분집합 점수(F1 40–50%)는 그럴듯해 보이지만 전체 유병률 추정치는 자명 기준선 수준이다—둘 다 공개해야 자기기만이 없다.
- **자가 점검 표식 불신**: "그래프 대조 확인" 같은 어휘 추적은 오답 대부분도 통과한다—통과를 증거로 쓰지 말고 정답과 대조 감사하라.
- **가중치와 함께 공개**: 포함 확률을 부분집합과 함께 배포하면 누구나 동일 사례에서 전체 모집단 추정치를 재현할 수 있다.
