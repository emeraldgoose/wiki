# 두 번 생각하기: Metis-1.6 기술 보고서

**원문**: [arXiv:2610.37903](https://arxiv.org/abs/2610.37903) · **게시일**: 2026-10-27
**저자**: Praxis (총 2.94B, pass당 0.46B 활성), Logos (총 10.23B, pass당 1.18B 활성)

## 개요

Metis-1.6은 raw parameter count만으로는 얻을 수 없는 capability를 훨씬 낮은 비용으로 얻을 수 있다는 가설을 검증하기 위한 다음 단계다. 한 명의 연구자가 처음부터 훈련한 두 모델을 제시한다. Praxis는 총 2.94B parameters에 pass당 0.46B active, Logos는 총 10.23B parameters에 pass당 1.18B active다. 둘 다 hybrid Mamba-2와 attention mixture-of-experts stack을 forward pass당 두 번 실행하며, Metis-1.5보다 16배 많은 데이터로 사전훈련되었다.

이 보고서는 비슷한 크기의 open model과의 성능을 하나의 evaluation harness로 솔직하게 비교하고, 동시에 무엇이 잘못되었는지를 기록하는 데 목적이 있다. 보통 release report는 동작한 recipe만 설명하지만, 이 보고서는 실패한 최적화, optimizer 불일치, post-training 문제를 자세히 다룬다.

## 핵심 내용

- 완전한 훈련 lineage, checkpoint hash, exact parameter accounting을 공개한 두 개의 open model이다.
- Praxis와 Logos는 active parameter당 capability를 높이기 위해 looped hybrid Mamba-2/attention MoE 구조를 사용한다.
- base stage 27개, post-training 28개의 유사 크기 open model 비교가 보고된다.
- 선언된 AdaMuon optimizer는 실제로 instantiate되지 않았고, routing mismatch로 attention matrix가 AdamW로 훈련되었다.
- learned hashed n-gram memory는 실패했으며, Logos에서 1.77B-parameter 테이블을 삭제해도 held-out loss가 1e-3 nats 미만으로 변했다.
- 지도 미세조정에서 다섯 가지 failure mode가 드러났고, verifier imbalance가 보지 못한 science question의 reasoning을 짧게 만들었다.
- group-mean normalization 하의 length reward sign inversion이 발견, 증명, 수정되었다.

## 상세

Metis 계열은 hybrid block, mixture-of-recursions transformer, latent MoE 실험을 거치며 1.3에서 1.5까지 발전했다. Metis-1.6은 AMD Instinct MI300A에서 두 pass looped hybrid 구조로 이동한 단계를 나타낸다.

훈련 측면에서 보고서는 의도만 믿지 않고 optimizer 동작을 감사한다. AdaMuon은 선언됐지만 실제로 instantiate되지 않았고, routing mismatch는 attention matrix를 AdamW로 이동시켰다. hashed n-gram memory injection도 도움이 되지 않았으며 learned gate가 닫히고 held-out loss 변화가 거의 없었다.

post-training 분석은 다섯 가지 SFT failure mode, science reasoning에 영향을 준 verifier imbalance, 한 줄 수정으로 해결된 length reward 문제를 다룬다. 이어 controlled 10B-token ablation이 다음 architecture를 위한 loop design과 optimizer 선택을 조사한다.
