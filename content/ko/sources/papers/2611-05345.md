# Adversarial Speculative Reasoning Improves Long Horizon Agents: 중요한 추론 지점의 draft rejection 학습

**원문**: [arXiv:2611.05345](https://arxiv.org/abs/2611.05345) · **게시일**: 2026-11-03
**저자**: Hongyin Luo, Wei Fang, Lijie Yang, Owen Stepan, Daniel Suit, Jeff Krapf, Dana Wensberg, Jack O'Brien

## 개요

Speculative decoding은 보통 LLM decoding을 가속하는 순수 systems optimization으로 취급되어 모델 behavior를 바꾸지 않는다고 여겨졌다. 이 시각에서는 더 나은 draft model training도 purely acceptance rate에 집중되어 왔다. 논문은 long-horizon agent reasoning에서는 이 시각이 성립하지 않는다고 주장한다. frontier open-weight models를 복잡한 agentic tasks에서 측정한 결과 verification window 안에서 numerical noise가 커지고, thinking process의 draft acceptance outcome이 30 steps 이후 output distribution을 변경할 수 있어 reasoning accuracy를 random direction으로 noticeably influence한다. proposed method는 such noise를 control함으로써 target model reasoning을 개선하며, training draft to be rejected at critical reasoning points를 통해 verification restarts와 target sampling renewal을 유도한다.

## 핵심 내용

- speculative decoding은 long-horizon agents에서 항상 behavior-neutral이 아니다.
- verification-window noise가 long-horizon output에 영향 줄 수 있다.
- critical reasoning points는 agent traces에서 식별된다.
- draft는 해당 지점에서 rejection되도록 adversarial preference로 학습된다.
- 그 지점에서 verification이 restart하고 target sampling이 재개된다.
- target model이나 output distribution은 변경되지 않는다.

## 상세

complex agentic coding benchmarks에서 end-to-end success rate는 target output distribution 변화 없이 hosted parameters의 0.06~0.28% training으로 향상되었다. 결과는 speculative decoding을 pure accelerator에서 context precision을 active allocate하는 도구로 재규정한다. critical reasoning point 식별과 agent trace quality에 의존한다.
