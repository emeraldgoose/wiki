# BEND 2.0: DNA 설계에 필요한 능력 벤치마킹

**원문**: [arXiv:2611.03806](https://arxiv.org/abs/2611.03806) · **게시일**: 2026-11-02
**저자**: Andreas Bjerregaard, Rachael DeVries, Dionysia Danai Brilli, Panagiotis Antoniadis, Yan Li, Anders Krogh, Wouter Boomsma, Ole Winther, Frederikke Isa Marin

## 개요

유전체 파운데이션 모델은 DNA 서열과 편집 제안에 점점 더 많이 사용되지만, 설계 성공에 필요한 능력은 현재 벤치마크가 측정하지 않는다. BEND 2.0은 DNA 변화 효과 예측과 그 예측이 서열 설계를 지도할 수 있는지를 평가하는 DNA 언어 모델용 벤치마크다. 다섯 실험 데이터셋 위의 여덟 작업에서 모델 선택, 표현 접근 방식, 개별 예측기 너머의 전이, 벤치마크 정확도와 설계 유용성의 차이를 연구한다.

## 핵심 내용

- 여덟 작업은 다섯 실험 데이터셋에 걸쳐 있다.
- 효과 예측과 설계 지도 역량을 모두 측정한다.
- 동결 표현에 대한 선형 리드아웃은 모델 네이티브 출력과 맞먹거나 이를 능가할 수 있다.
- 기능 후학습이 역량을 크게 향상한다.
- 선형 리드아웃은 시험법과 유전자를 가로질러 잘 전이한다.
- 강한 평균 예측은 더 약한 문맥 의존 예측을 가릴 수 있다.

## 상세

결과는 모델 선택과 표현 접근 방식 모두 성능에 영향을 준다고 보여준다. 선형 리드아웃은 시험법과 유전자를 가로질러 잘 전이하여 개별 예측기 데이터 너머의 기능 패턴을 포착함을 시사한다. 그러나 평균 효과의 정확한 예측은 문맥 의존 효과의 정확한 예측을 뜻하지 않으며, 복합 돌연변이 효과의 정확한 예측은 상호작용 예측을 뜻하지 않는다. 설계 작업에서 모델 예측은 필요한 후보 수를 줄일 수 있지만 모델 선택에 큰 여지가 남는다.
