# 일치된 능력, 다른 행동: 언어 에이전트를 위한 MCP·CLI 인터페이스 통제 연구

출처: Zhenning Shi, arXiv:2610.34298, 2026-10-25.

**핵심 요약**: 언어 에이전트가 외부 도구와 상호작용 환경을 통해 행동하면서, 모델과 실행 가능한 능력 사이의 **인터페이스** 자체가 결정 과정의 일부가 됩니다. MCP와 CLI는 같은 의미 동작을 매우 다른 모델 대상 표현으로 노출할 수 있습니다. 이 논문은 실행 능력이 일치할 때 표현 차이가 에이전트 행동을 바꾸는지 연구합니다. 저자는 공유 의미 동작 계약에서 MCP와 CLI를 렌더링하고 디코딩된 행동을 같은 런타임으로 보내는 **Matched Interface Comparison and Analysis(MICA)** 를 도입했습니다. 6개 모델과 3개 상호작용 환경에서 일치된 인터페이스는 작업 성능과 상호작용 비용에 **상당한 차이**를 냈습니다. 이 효과는 표면적 유효성을 넘어 의미적 동작 선택, 실패 경로, 복구까지 확장되었습니다. 짝 상태 조사는 민감성이 능력 표현, 실현, 피드백 단계에 국소화됨을 보였습니다. 2,004개 에피소드 중 94.3%에서 짝 자연 궤적이 구조적으로 분기했고 초기 차이가 후속 상호작용으로 전파된다는 것을 보였습니다. 저자는 인터페이스 실현을 직접 개입 경계로 식별하고, 검증된 의미 약속은 보존하면서 인터페이스별 실현만 고치는 **Decoupled Action Realization and Targeted Repair(DART)** 를 도입했습니다. DART는 6개 평가 설정 모두에서 점수를 최대 9.0점 올리고 3개 환경 모두에서 작업당 MCP 토큰 비용을 최대 27.1k 토큰 줄였습니다. 결과적으로 인터페이스 표현은 에이전트 행동을 형성하는 폐루프 결정 환경의 일부입니다.

## 핵심 내용

- 같은 의미 동작도 MCP와 CLI로 노출하면 에이전트 행동이 달라진다.
- 6개 모델, 3개 환경에서 성능과 비용 차이가 상당했다.
- 2,004개 짝 에피소드 중 94.3%가 구조적으로 분기했다.
- 인터페이스 차이는 후속 상호작용으로 전파된다.
- DART는 6개 설정 모두에서 최대 9.0점 향상했다.
- DART는 3개 환경 모두에서 작업당 토큰을 최대 27.1k 줄였다.

## 상세

MICA는 하나의 의미 동작 계약과 런타임으로 두 인터페이스를 렌더링해 인터페이스 효과를 분리합니다. 짝 상태 조사는 표현·실현·피드백 단계별 민감성을 밝힙니다. DART는 의미 약속을 버리지 않고 실현만 고쳐 정확도와 토큰 비용 모두를 개선합니다.
