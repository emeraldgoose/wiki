# VLM을 로봇 조작 파운데이션 모델로 학습하는 법 엿보기

**원문**: [arXiv:2611.29338](https://arxiv.org/abs/2611.29338) · **게시일**: 2026-11-22 (v1)
**저자**: Meng-Hao Guo, Yi Zhang, Zhe-Han Mo, Han-Zheng Wang, Jia-Jun Wang, Xin-Sheng Chen, Jiaxi Song, Yi-Xuan Deng, Jia-Ning Li, Xuanyu Chu, Hengrui Zhang, Huan-ang Gao, Yongming Rao, Shi-Min Hu

## 개요

최근 GPT-6 Astra에 대한 평가는 범용 VLM이 작업별 미세조정 없이도 로봇을 조작할 수 있음을 보여주지만, 그 뒤의 학습 레시피는 공개되지 않았다. 이 논문은 그러한 능력을 접근 가능한 레시피로 재현하는 방법을 묻고, VLM을 조작 파운데이션 모델로 학습하는 두 가지 구성 요소인 nanoAstra로 답한다. 첫 번째인 의미론적 행동 모델링은 로봇 행동을 재구성한다. 조밀하게 샘플링된 제어 단계(액션 청크)를 감독하는 대신, 시연을 행동적 결정 지점에서 의미 단계로 분할한다. 의미 단계는 `move x +5.0`이나 `gripper open` 같은 재사용 가능한 매개변수화된 동작 원시 요소들의 묶음으로, 각 원시 요소에는 다음에 무엇을 해야 하는지를 명시하는 진행 설명이 붙는다. 두 번째인 능력 보존 지도 미세조정(CP-SFT)은 구체화, 좌표 규약, 실행 가능한 행동 공간을 고정하는 로봇 전용 시스템 프롬프트를 사용해 조작 출력을 구조화된 행동 공간에 가두어, 모델이 로봇에 특화되면서도 사전학습된 비전-언어 능력과의 간섭을 최소화하도록 한다.

데이터 파이프라인은 ABC-130K, AgiBot, HiFi-UMI, HY-UMI(실제 로봇과 핸드헬드 그리퍼 녹화 포함)를 필터링, 규약/카메라 정렬, 조밀한 캡션을 단 하위 작업 분할, 의미 단계 구성, 일반 VQA 데이터와의 혼합이라는 다섯 단계를 거쳐 5,000시간 이상의 로봇 데이터를 통합한다. nanoAstra-9B는 Qwen3.5-9B에서 초기화해 56대의 H20 GPU에서 한 에폭 동안 전체 미세조정한다(유효 배치 56팩, 팩당 평균 약 188개 샘플, bf16, ZeRO-2, 8,192 토큰 시퀀스). 십진 자릿 가중치와 명시적 부호 감독을 포함한 변형 바서슈타인 수 토큰 손실이 행동 값의 수치 정밀도를 높인다.

## 핵심 내용

- 제로샷 조작: RoboTwin 2.0 랜덤화 벤치마크(50개 작업, 작업당 10회 실행, 실제 세계 데이터만 사용 — 시뮬레이션 궤적이나 벤치마크 미세조정 없음)에서 nanoAstra-9B는 17.8% 성공률을 기록했다. 최고 VLA 베이스라인(LingBot-VLA-2.0 10.8%, 나머지 1.4–2.4%),거의 0에 가까운 WAM(DreamZero 0.2%, LingBot-VA 0.0%), 동급 또는 더 큰 VLM(사고 모드 8.2–10.8%, 비사고 모드 3.2–4.0%)을 모두 앞섰다.
- 스트리밍 실행: 단일 H20에서의 추론이 해당 동작 실행보다 빠르기 때문에, 단계가 스트리밍되는 대로 실행하고 현재 회차가 끝나기 전에 다음 회차를 요청할 수 있다. 추론 중에도 시뮬레이터를 멈추지 않는 RoboTwin 2.0 평가에서 스트리밍은 로봇 유휴 시간을 35.0%에서 6.9%로 줄이고(회차당 대기 2.1 → 0.2 스텝), 공식 시간 제한 내 성공률을 11.2%에서 12.9%로 높였다.
- 학습 벤치마크를 넘어선 전이: RoboDojo Open(8개 작업, 모델당 400 에피소드)에서 nanoAstra-9B는 4.75% 성공(19/400)을 기록해 미조정 Qwen3.5-9B(0.25%)를 크게 앞섰고, 보고된 모델 중 최고 성공률과 진행 점수를 달성했다.
- 능력 보존: VQA 벤치마크(MMMU, ERQA, CV-Bench-2D/3D)는 학습 초기에 하락했다가 부분적으로 회복한다. 최종 점수 53.1% / 41.0% / 81.6% / 87.6%는 초기 58.6% / 47.3% / 82.2% / 92.6% 대비 대략 5.0–6.3포인트(비전 벤치마크 기준) 낮은데, 이는 조작 학습이 일반 VLM 능력의 상당 부분을 유지하면서 공존함을 보여준다.
- 실패 분석: 대표적 실패 사례들은 폐루프 회차가 거듭될수록 동작 매개변수화와 작업 상태 추정 오류가 누적되는데(예:전자레인지 문을 직선 이동으로만 부분 개방, 진행 상황이 완료된 하위 작업이나 무관한 물체로 표류), 이는 관절형 물체를 위한 객체 중심 원시 요소와 완료된 하위 작업의 명시적 추적을 동기로 한다.

## 세부 내용

2장은 파이프라인을 상세히 다룬다. 데이터 필터링, 규약 및 카메라 정렬, 조밀한 캡션을 단 하위 작업 분할, 결정 지점에서의 의미 단계 구성(각 관측에 진행 설명과 실행 가능한 행동 시퀀스가 짝지어짐), 로봇 데이터와 일반 VQA 예시를 혼합하는 공동 레시피가 포함된다. CP-SFT(2.2절)는 응답 디코딩 공간을 구조화된 행동 형식으로 부드럽게 제약하고, 평균 교차 엔트로피 위에 십진 자릿 가중치, 부호 반전 토큰 쌍에 대한 부호 항, 숫자 토큰만의 정규화를 적용한 변형 바서슈타인 수 토큰 손실을 추가하며, 손실은 GPU와 그래디언트 누적 across 모든 원본 샘플에 대해 평균한다. 3장은 설정(Qwen3.5-9B 초기화, ms-swift, 코사인 스케줄의 AdamW 최고 학습률, 웜업 0.01, 가중치 감쇠 0.1, 이미지당 392개 비전 토큰), RoboTwin 2.0 및 RoboDojo 벤치마크, 학습 과정 모니터링(최종 손실 EMA 약 0.35), 실패 분석을 다룬다. 4장은 VLA/WAM/VLM 에이전트 베이스라인과 체화된 데이터 파이프라인을 검토한다. 코드와 프로젝트 페이지: nanoastra.github.io.
