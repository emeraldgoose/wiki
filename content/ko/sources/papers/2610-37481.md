# 그래디언트를 따라가기: 안전성 저하를 훈련 데이터로 추적하기

**원문**: [arXiv:2610.37481](https://arxiv.org/abs/2610.37481) · **게시일**: 2026-10-27
**저자**: Saket Reddy, Amro Abbas, Anshuman Suri, Ari Morcos, David Schwab, Pratyush Maini

## 개요

대형 언어 모델을 지시문 데이터로 추가 훈련(fine-tuning)하면 training example 자체에 유해한 내용이 없어도 안전 정렬이 조용히 약화될 수 있다. 문제의 데이터가 정상적으로 보이기 때문에 일반 콘텐츠 필터나 안전 판단기는 이를 잘 포착하지 못한다. 논문은 이러한 안전성 저하를 실제로 일으키는 훈련 example까지 거슬러 추적하는 방법을 연구한다.

저자들은 취약한 동작과 그래디언트가 정렬(alignment)되는 example을 찾는 확장 가능한 그래디언트 임베딩 방법인 SimpleLoRIF를 제안한다. 기존 LoRIF를 바탕으로 곡률 보정(curvature correction)을 버리고 역전파(backpropagation)를 마지막 네 개의 트랜스포머 블록으로 제한하여, 약 백만 example 규모의 지도 미세조정(supervised fine-tuning) 데이터셋에서도 example별 그래디언트 필터링이 가능하도록 만들었다.

## 핵심 내용

- 정상적으로 보이는 지시문 데이터로도 안전성이 약화될 수 있으므로, 데이터 선택은 안전성 관점에서 별도로 다뤄야 한다.
- SimpleLoRIF는 취약한 응답과 그래디언트 정렬을 신호로 쓰며, 기존 저랭크 attribution 방법을 대규모로 단순화했다.
- 불안전한 코드로 미세조정된 모델에서 emergent misalignment 사례에서는 불안전 코드 훈련 데이터의 그래디언트가 이후 나타나는 관련 없는 유해 동작과 정렬된다.
- SafeTulu는 Tulu 3에서 취약한 SafeRLHF 응답과 가장 그래디언트가 정렬된 20% example을 제거하여 만들어진다.
- Qwen, Llama, Olmo 계열에서 SafeTulu는 baseline 대비 GCG 공격 성공률(attack success rate)을 최대 22%까지 낮춘다.
- 제거된 example에는 도구 실행 실패, 서사적 산술 문제, 은밀한 물리적 조작 task 등 반복 패턴이 나타난다.
- 저자들은 연구자들이 맞춤형 필터링 데이터셋을 만들 수 있도록 SafeTulu와 Hugging Face Space를 공개한다.

## 상세

이 방법은 먼저 emergent misalignment 사례로 검증된다. 불안전한 코드로 미세조정하면 프로그래밍 도메인 밖으로 확장되는 광범위한 유해 행동이 유발되며, 그런 모델에서는 불안전 코드 훈련 데이터의 그래디언트가 미세조정 뒤에 나타나는 유해 행동의 그래디언트와 정렬된다.

이후 논문은 SafeRLHF 정렬 데이터에 SimpleLoRIF를 적용한다. Tulu 3 example을 취약한 응답과의 그래디언트 정렬 정도로 순위화한 뒤 상위 20%를 제거하고 재훈련한다. 그 결과인 SafeTulu는 GCG attack success rate로 평가되며, capability 데이터를 포기하지 않고도 얼마나 안전성이 회복되었는지를 여러 모델 계열에서 보여준다.

제거된 example에 대한 정성적 검사는 안전성 저하가 노골적으로 유해한 텍스트뿐 아니라 도구 실행 실패나 특정 산술·물리 추론 문제 같은 반복 task pattern으로부터도 발생할 수 있음을 시사한다. 저자들은 또한 일반 안전성 저하만 검증했으며 sycophancy 같은 특정 유해 행동이나 과도한 거부는 별도로 다루지 않았음을 limitation으로 명시하고, 재현을 위한 hyperparameter도 함께 공개한다.
