# 언어 모델의 자기 보존

**Source**: Cho, Chunara & Behrouz, arXiv, 2026-10-08

**핵심**: 지속 학습은 사전학습 모델을 새 태스크에 적응시키지만, 보존용으로 제공된 리플레이 데이터는 모델이 아는 것의 일부만 다룬다. 이 논문은 모델이 *스스로를 보존*할 수 있는지 묻는다: 동결된 업데이트 전 모델로 태스크 뱅크에서 리플레이 데이터를 생성하고, 리플레이할 태스크까지 고르는 방식이다. Qwen3 모델(0.6B–4B) 실험에서 생성된 리플레이는 홀드아웃 역량을 보호하고, 뱅크 결합은 보호를 강화하며, 새 태스크 정보를 활용한 대상 선택은 4B에서 효과가 있다.

## 배경

새 태스크에 언어 모델을 파인튜닝하면 기존 행동이 저하될 수 있다(파괴적 망각). 저장된 예제를 리플레이하거나 간섭을 고려해 업데이트하는 표준 지속 학습 방어책은 제공된 보존 근거에 의존한다. 그러나 원본 학습 데이터가 없으면 그 근거는 모델 역량의 일부만 다루고, 망각은 제공된 태스크 범위를 넘어선다.

최근 연구는 모델이 학습 데이터 없이도 유용한 리플레이를 생성할 수 있음을 보인다(LAMOL, Self-Synthesized Rehearsal, Self-Replay). 이 논문은 두 설계 결정을 분리한다: *얼마나* 복습할지 vs *무엇을* 복습할지. 그리고 더 넓은 대상 커버리지와 모델 주도 대상 선택이 리플레이 목록 밖 행동을 보호하는지 검증한다.

핵심 측정 통찰: 평균 정확도는 망각을 숨길 수 있다. 새로 맞춘 답이 기존에 맞던 답의 손실을 상쇄하기 때문이다. 저자들은 짝지어진 업데이트 전후 예측에서 *유지율*(Retention)—초기에 맞던 답 중 이후에도 맞는 비율—도 함께 보고한다.

## 태스크 뱅크와 태스크 뱅크 자기-리플레이

**태스크 뱅크**는 보존 대상의 작은 목록이다: 각 항목은 태스크 이름, 행동과 입출력 형식 설명, 선택적 예시를 담는다. 항목 간 스킬은 겹칠 수 있다.

**태스크 뱅크 자기-리플레이** 파이프라인:

1. **선택**: 뱅크에서 복습할 항목 선택(무작위, 뱅크만 보는 모델 선택, 새 태스크 정보를 함께 보는 모델 선택)
2. **생성**: 동결된 업데이트 전 참조 모델로 리플레이 질문과 답 생성
3. **파인튜닝**: 새 태스크 예제와 생성된 리플레이를 섞어 지도 손실로 학습

선택자, 리플레이 생성자, 학습자는 같은 체크포인트를 쓰더라도 역할이 분리된다. 홀드아웃 태스크(예제, 라벨, 설명, 점수)는 뱅크 구성과 대상 선택 모두에서 제외되므로, 홀드아웃 결과는 목록 *밖* 보호를 측정한다.

## 실험

**설정**: Qwen3-0.6B, 1.7B, 4B(망각 진단은 Qwen3.5-4B 추가). 새 태스크: MedQA(1,024개 예제, 1 에폭, lr 1e-5, 5 시드)와 TRACE의 C-STANCE. 태스크 뱅크: MMLU, HellaSwag, GSM8K, BoolQ. 홀드아웃: ARC-Challenge, WinoGrande, PIQA, SVAMP.

**벤치마크**: 새 태스크 정확도 향상 + 기존 태스크 정확도 변화(%p)와 짝지어진 예측에서의 유지율(맞음→맞음).

**결과**:

| 발견 | 결과 |
|---------|--------|
| 평균이 망각을 숨긴다 | 4개 태스크 평균 순변화 +0.05%p 뒤에 3.56% 손실 vs 3.61% 이득이 숨어 있음 |
| 넓은 리플레이가 단일 대상을 이긴다(C-STANCE, 4B) | 홀드아웃 평균 Δ: SFT −4.34%p, 단일 태스크 −3.99%p, 실제 리플레이 +0.86%p, 자기-리플레이 +1.07%p; 새 태스크 이득은 모두 ≈ +27.8%p |
| 부분 뱅크 결합이 전 규모에서 도움 | 결합 유지율 88.70% / 93.28% / 96.01%(0.6B/1.7B/4B), 더 좋은 부분 뱅크 대비 +4.42/+3.32/+2.99%p |
| 새 태스크 인식 선택은 4B에서만 효과 | 무작위 92.94% 대비 95.69%(+2.75%p), 뱅크만 보기 93.42%; 4개 중 2개 대상으로 전체 뱅크 수준에 근접; 0.6B/1.7B에서는 이득 없음 |
| 고정 예제 예산은 트레이드오프 | 256행 중 59행을 리플레이로 대체: 최악 홀드아웃 −1.56 → −0.68%p, 대신 MedQA 이득 +1.17 → +0.49%p |
| 낮은 학습률이 두 목표에 모두 유리 | C-STANCE Qwen3-1.7B, 1e-7: 새 태스크 +12.01%p, 홀드아웃 유지율 97.02%; 1e-5에서는 적응 붕괴 |

제공된 대상을 넘어 모델이 뱅크를 스스로 확장하는 것은 탐색 단계에 머문다: 단일 팔 파일럿에서 정확도 하락.

## 소프트웨어 엔지니어를 위한 시사점

새 도메인(의료 QA, 스탠스 분류, 사내 도구)에 LLM을 파인튜닝하는 팀에게:

- **저장된 히스토리 불필요**: 현재 모델의 동결 복사본이 자체 회귀 테스트셋을 생성—원본 학습 데이터를 보관할 수 없거나 보관하지 않을 때 유용
- **평균이 아니라 유지율을 측정**: 태스크별 정확도와 기존 정답 유지율을 함께 추적; 평균이 0 근처라도 ~3.5% 답변이 뒤바뀔 수 있음
- **깊게보다 넓게 커버**: 다양한 리플레이 대상 결합이 단일 태스크 예제 증량보다 낫다; 잘 고른 2개 대상이 전체 뱅크 보호에 근접
- **예산 트레이드오프를 감안**: 고정 학습 예산에서 리플레이 토큰은 새 태스크 토큰을 대체—보존 대가로 새 태스크 이득 축소 예상
- **학습률이 1차 변수**: 단기 업데이트 체제에서 1e-7이 1e-5를 습득과 유지 모두에서 앞섬
