# AuditFL: open federated learning를 위한 contract-backed clearing layer

**원문**: [arXiv:2610.41278](https://arxiv.org/abs/2610.41278) · **게시일**: 2026-10-27
**저자**: Alexandros Balla, Spyros Lalis

## 개요

federated learning은 raw data를 local에 유지하지만 많은 deployment는 client admission, checkpoint distribution, update collection, aggregation, reward를 trusted coordinator에게 의존한다. AuditFL은 open setting에서 auditable FL을 위한 contract-backed clearing layer다.

ledger가 small state transition을 order/validate하고 model bytes는 content identifier로 referenced된 distributed off-chain storage에 보관한다. task coordinator가 round 정의와 weight aggregation의 trusted authority를 가지며 chain은 admission, deposit, termination, reward operation을 기록한다.

## 핵심 내용

- weak trust assumption을 가진 open federated learning을 target으로 한다.
- small state transition을 위해 contract-backed ledger를 사용한다.
- model bytes는 content-addressed off-chain storage에 보관한다.
- round와 aggregation authority는 trusted task coordinator가 가진다.
- audition 가능한 admission, deposit, termination, reward를 on chain에 기록한다.
- FL에 insufficient한 naive blockchain design보다 higher-level을 지향한다.
- consensus assumption과 round-level state-machine detail을 clarify하려 한다.

## 상세

federated learning은 data movement가 expensive, sensitive, restricted 되는 경우 useful하다. AuditFL은 client가 strong bootstrap guarantee 없이 join할 수 있는 open FL setting으로 적응한다.

design은 large model artifact와 ledger state transition을 구분한다. chain은 order와 validation을 기록하고 storage가 bulky data를 handling한다. 이를 통해 audition을 모든 model byte가 blockchain을 pass하지 않아도 practical하게 만든다.
