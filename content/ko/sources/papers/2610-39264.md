# 라이브 iOS 앱 UI 탐색을 위한 계획-그라운딩 에이전트와 온라인 조밀 강화학습

출처: Peitong Duan, arXiv:2610.39264, 2026-10-29.

**핵심 요약**: VLM은 UI 탐색에 강하지만 높은 추론 비용이 일상적 사용을 막고, SFT나 오프라인 RL로 학습한 작은 모델은 정적 궤적을 암기해 취약하고 오류 복구를 못합니다. 저자들은 **라이브 iOS 애플리케이션에서 직접 UI 탐색 에이전트를 훈련하는 온라인 강화학습 프레임워크**를 제안합니다. 에이전트는 **Planning agent**와 **UI Grounding model** 두 구성요소로 분리됩니다. LLM-as-a-Judge가 포괄적 보상 신호를 제공하며 중간 진전에 대한 **조밀 단계 보상**과 전체 태스크 완료 **terminal 보상**을 결합합니다. PPO로 step-level advantage 추정을 써서 최적화합니다. 시각적으로 유사한 상태의 보상 신호를 병행 궤적에서 활용해 critic 안정성을 높이는 neighbor-conditioned value estimation **GiGPPO**도 도입합니다. 스케일을 위해 수백 개 동시 가상 iOS 기기를 오케스트레이션하는 인프라를 구축합니다. UINavBench, iOSWorld, AndroidWorld 평가에서 온라인 RL 에이전트는 SFT와 terminal-only RL baseline을 크게 앞서며 수렴도 빨랐습니다. 특히 8B RL 에이전트는 Android OOD 일반화에서 SFT baseline 대비 거의 7배 개선을 보였고, 실제 iOS에서 Gemini-3.5-Flash보다 높고 Gemini-3.1-Pro와 동률이었습니다.

## 핵심 내용

- 정적 궤적 암기 대신 라이브 iOS 앱에서 직접 훈련한다.
- 계획과 UI 그라운딩을 분리한다.
- 조밀 단계 보상과 terminal 보상을 결합한다.
- PPO는 step-level advantage 추정을 사용한다.
- GiGPPO는 neighbor-conditioned value estimation으로 critic 안정성을 높인다.
- 수백 개 동시 가상 iOS 기기로 스케일한다.
- 8B 에이전트는 Android OOD 일반화를 7배 개선하고 iOS에서 강한 모델과 경쟁했다.

## 상세

조밀 보상과 라이브 상호작용으로 SFT/오프라인 RL의 암기와 복구 부족 문제를 다룹니다. 분리 설계로 계획과 그라운딩이 함께 개선되고 인프라가 온라인 훈련을 실용화합니다.
