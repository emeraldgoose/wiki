# GameWM: 상호작용 중심 월드 모델을 이용한 차세대 비디오 게임으로 향하기

**출처**: [arXiv:2611.19247](https://arxiv.org/abs/2611.19247) · **게시일**: 2026-11-14

## 개요

50년 이상 비디오 게임은 더 나은 그래픽, 더 자연스러운 상호작용, 더 몰입적인 게임플레이를 추구해왔다. 생성형 비디오 모델이 이제 세 영역 모두에 영향을 미친다. 신경망은 이미 출시된 게임의 대부분 픽셀을 그리며, 최근 월드 모델은 가벼운 게임 엔진이 월드 상태를 유지하도록 하고 비디오 모델이 엔진의 거친 프록시 영상을 최종 프레임으로 변환하게 한다. 그러나 이러한 시스템은 비디오 모델을 엔진이 이미 작성한 동작만 재스타일링하는 렌더러로 취급하여 생성 능력을 대부분 활용하지 못하고 게임 다양성을 제한한다.

GameWM은 명확한 작업 분담을 기반으로 차세대 게임을 위한 설계를 제시한다. GameWM 엔진은 정확해야 할 규칙, 상태, 카메라, 월드 레이아웃을 유지해 비디오 모델이 이를 기억할 필요가 없도록 한다. GameWM-VM은 손으로 작성하기 비싼 세계의 외관과 플레이어 상호작용의 디테일을 생성한다. 하나의 게임 메커니즘은 시각적·물리적으로 매우 다른 방식으로 구현될 수 있지만 결과는 엔진이 계산한 것과 동일하게 유지된다.

## 핵심 내용

- 작업 분담이 정확한 엔진 상태와 생성형 비디오 렌더링을 분리한다.
- 엔진은 규칙, 상태, 카메라, 레이아웃을 보존하고 VM은 시각 요소와 상호작용 디테일을 생성한다.
- 탐색보다 상호작용에 중심을 둔 데이터 엔진.
- 작성된 캐릭터 시트, 장면 아트, 스킬 설명을 입력받는 인터페이스.
- 플레이를 위한 실시간 인과 변형과 함께 5B~33B 파라미터 모델 패밀리.
- 각 플레이어는 고유한 캐릭터, 월드, 스킬을 통해 동일한 게임의 새로운 버전을 경험하면서도 이벤트는 엔진의 타이밍과 결과를 유지한다.

## 상세

GameWM은 상호작용 중심 데이터 엔진, 작성 인터페이스, 모델 패밀리로 구성된 완전한 시스템이다. 이 설계는 게임 로직의 결정성을 희생하지 않으면서 메커니즘별 개인화를 가능하게 한다.
