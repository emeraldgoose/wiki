# SLA: continual pre-training을 통한 spatial-language-action model scaling

**원문**: [arXiv:2611.08373](https://arxiv.org/abs/2611.08373) · **게시일**: 2026-11-05
**저자**: Fuhao Li, Wenxuan Song, Qizhou Huang, Ziyang Zhou, Jingbo Wang, Junwu E, Pengwei Wang, Yan Wang, Shunbo Zhou, Haoang Li

## 개요

reliable robotic manipulation은 semantic understanding과 precise three-dimensional control을 both 요구한다. VLA foundations는 대체로 2D vision-language pre-training에서 visual representations를 inherit하고, spatial supervision은 task-specific adaptation에서만 introduce된다. SLA는 broader robot experience에서 spatial understanding을 transferable foundation-model capability로 learned한다.

SLA는 pretrained pi05 policy에서 initialize하고 action prediction과 frozen 3D perception model의 spatial representations 사이 intermediate visual embeddings alignment을 jointly optimize하며 continual pre-training한다. diverse embodiments, tasks, scenes를 cover하는 curated heterogeneous robot datasets를 unify한다.

feature-dependent gates가 spatial supervision을 위해 multiple VLA layers의 visual embeddings를 adaptively aggregate한다. teacher는 RGB observations alongside partially available depth and camera calibration을 exploit해 heterogeneous geometric annotations를 effectively use한다. probabilistic state dropout은 visual cues reliance를 encourage하고 demonstration trajectories overfitting을 mitigate한다. all auxiliary components는 training-only라 original inference architecture와 pretrained VLA weights reuse가 direct하다.

## 핵심 내용

- continual pre-training을 통해 VLA의 spatial understanding을 scale한다.
- visual embeddings를 frozen 3D perception representations에 align한다.
- diverse embodiments와 scenes를 covered heterogeneous robot datasets를 curated한다.
- feature-dependent gates로 layer aggregation을 adapt한다.
- partial depth와 calibration annotations을 leverage한다.
- 모든 auxiliary components는 training-only로 사용된다.
