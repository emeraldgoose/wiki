# PyRUA-REAL: real world에서 RSI를 통한 로봇 탐사와 적응 학습

**원문**: [arXiv:2611.06768](https://arxiv.org/abs/2611.06768) · **게시일**: 2026-11-04
**저자**: Qiang Wang, Jianxin Bi, Shulong Jiang, Ruiyang Si, Wenbo Huang, Kaiqi Chen, Jiaxin Li, Liyun Li, Xuanyi Li, Daquan Zhou

## 개요

GPT-6-Astra 같은 모델 기반 coding agents는 spatial reasoning과 executable robot behavior를 connect하여, physical interaction으로부터 로봇 capability의 lasting improvements를 agents가 how produce할 수 있는지 question을 raise한다. 논문은 PyRUA-REAL을 사용해 real-world exploration, code refinement, deployment를 통한 embodied recursive self-improvement (RSI)를 study한다. framework에서 coding agents는 interaction experience를 persistent memory와 reusable executable skills로 retained하고 subsequent exploration/improvement를 inform한다. empirical study는 physical manipulation을 improvement process center에 두고 agents collaboration, effective code refinement를 support하는 execution feedback kinds, task specifications와 acquired skills가 robustness/task transfer에 끼는 influence를 examine한다. 또한 online agent decision-making 없이 deployed되는 resulting programs의 efficiency/capability도 investigate한다. eight real-world tasks에서 91.1% average success, RoboDojo 42 tasks에서 84.4% average success를 달성한다. physical exploration을 continued improvement와 robust/efficient deployment를 support하는 reusable robot skills로 turn하는 guidance를 제공한다.

## 핵심 내용

- physical exploration을 coding agents로 reusable deployable skills로 전환.
- persistent memory/reusable executable skills로 recursive self-improvement.
- collaboration, feedback, task spec, skill transfer 영향 분석.
- online agent 없이 deployed programs 평가.
- real tasks 91.1%, RoboDojo 84.4% success.

## 상세

physical manipulation을 improvement center로 둔 study다. online agent decision 없이 배포 평가도 포함된다. scenario/success metrics/collaboration details는 연결된 원문을 참고한다.
