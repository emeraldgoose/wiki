# OmniShowcase: 다중 뷰 이미지로부터의 전방향 subject-consistent 비디오 생성

**원문**: [arXiv:2610.35684](https://arxiv.org/abs/2610.35684) · **게시일**: 2026-10-26
**저자**: Junyeong Ahn, Geonwoo Kim, Kinam Kim, Gihwi Kim, Hoonjin Jung, Hyojin Jang, Jaegul Choo

## 개요

입력에 보이지 않는 표면이 노출되는 시점에서 몇 장의 reference 이미지로 특정 주제의 비디오를 생성하기는 어렵다. 초기 subject-to-video(S2V)는 단일 reference 이미지에 조건을 걸어 시점 변화 시 보이지 않는 외관/기하를 추정해야 했다. 최근에는 다중 reference view로 확장했지만 관찰을 잇는 3D 구조를 명시하지 않고, 학습 데이터도 시점 변화가 같은 객체를 보존한다는 보장이 약하다.

OmniShowcase는 geometry-driven camera trajectory로 360도 orbit까지 포함하는 자동 데이터 합성 파이프라인과, reference view에서 재구성한 표면 노멀 map 턴테이블로 geometry conditioning을 제공한다.

## 핵심 내용

- 다중 뷰 이미지로부터 주제 일관 비디오를 전방향 생성하는 OmniShowcase를 제시한다.
- geometry-driven diverse camera trajectory로 360도 orbit을 포함한 학습 비디오를 합성한다.
- 생성 프레임과 temporal alignment 없이 reference view에서 재구성한 surface-normal map 턴테이블로 조건을 준다.
- 12개 카메라 모션/88개 trajectory 구성의 Showcase-4K와 source mesh/카메라 파라미터를 포함한 ShowcaseBench를 공개한다.
- 최고의 subject identity/3D consistency와 경쟁력 있는 비디오 품질/모션을 달성한다.

## 상세

다중 뷰 reference와 일관된 주제 렌더링 사이의 불일치 문제를 surface-normal turntable과 geometry-driven orbit으로 3D 기하를 명시함으로써 해결한다.
