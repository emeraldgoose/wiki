# LLM은 사후 학습 중에 자신의 환각을 암기한다

**원문**: [arXiv:2611.26863](https://arxiv.org/abs/2611.26863) · **게시일**: 2026-11-19 (v1)
**저자**: Anirudh Atmakuru, Tanya Goyal

## 개요

추론 도메인이 프런티어 모델의 사후 학습 레시피를 형성했다. 결과 기반 RL 보상이나 가설을 세우고 되돌아보는 "사고적" 행동 같은 말이다. 그러나 모델은 수학이나 코드 너머의 도메인에 배포된다. 이 논문은 그런 추론 중심 레시피를 지식 작업에 그대로 적용할 때 어떤 결과가 나오는지 연구한다. 가설은 이 레시피들이 모델이 긴 추론 연쇄에서 스스로 생성한 환각을 암기하도록 부추긴다는 것이다. 저자들은 표준 사후 학습으로 모델을 학습시키고, RL 중에 모델이RAS에서 생성한 환각을 추출해 나머지 학습 내내 암기 정도를 추적한다. 6개 오픈 모델(Qwen3-4B/8B/14B/30B-A3B, Olmo-3-7B-Think, OLMoE-1B-7B), 두 모델 계열과 두 아키텍처, QuALITY와 TriviaQA에서 실험한 결과 가설이 확인된다.

학습 중에 강화된 환각의 회상률은 평균 +4.83%p 오르는 반면, 학습 신호를 받지 않은 자기 환각은 +0.17%p에 그친다. 모델은 추론 연쇄에서 즉시 되돌아보는 거짓 사실까지 암기한다. 추론 중심 학습에서 물려받은 되돌아보기 템플릿은 지식 회상에 이점이 없지만, 철회된 거짓 사실도 그만큼 강하게 학습된다. 암기는 가장 어려운 학습 문제에서 가장 강한데, 정답 롤아웃이 적을수록 GRPO의 그룹 정규화로 소수의 정답 롤아웃이 더 큰 양의 이점을 받아 그 안의 환각이 더 강하게 강화되기 때문이다.또한 환각을 보상하면 모델이 나중에그것을 거부("모두 해당 없음")할 가능성이 평균 7.23%p 낮아진다. 이 연구는 모델이 학습 중에 환각을 배우는, 기존에 검토되지 않은 경로를 찾아내 체계적으로 연구한다.

## 핵심 내용

- 지식 작업에 추론 중심 레시피(결과 기반 RL 보상, 가설/되돌아보기 템플릿)를 적용하면 모델이 자신이 생성한 환각을 암기하게 된다.
- 강화된 환각: 암기 점수(학습-보류 격차)가 평균 +4.83%p vs 강화되지 않은 자기 환각 +0.17%p. 6개 모델(Qwen3, OLMo 계열), QuALITY/TriviaQA 기준.
- 되돌아본 거짓 사실도 철회되지 않은 환각만큼 강하게 암기된다. 연쇄 안의 되돌아보기가 거짓 주장을 학습으로부터 보호하지 못한다.
- 암기는 학습 문제 난이도가 오를수록 커진다(정답 롤아웃 수 감소). GRPO 그룹 정규화가 희귀한 정답 롤아웃에 더 큰 양의 이점을 주어 환각을 더 강하게 강화한다.
- 환각을 강화하면 나중에 거부할 가능성이 줄어든다. "모두 해당 없음" 선택지가 있을 때, 환각이 보상된 후 정답으로 거부를 고르는 비율이 7.23%p 감소.
- 시사점: 지식 도메인 사후 학습에 추론 도메인 RL 레시피를 맹목적으로도입해서는 안 되며, 결과만의 보상은 자기 생성 거짓을 암기시킨다.

## 상세

방법: 표준 사후 학습(SFT + 결과 보상의 RL, 예: GRPO류 그룹 대비 이점) 후 RL 중 추론 연쇄에서 모델이 생성한 환각을 추출하고 HalluSet-train과 보류 세트에서 암기 점수(Δ = train − heldout)를 측정한다. QuALITY에서 모델별 Δ는 약 3.9~6.3(Qwen3-8B 5.90, OLMoE-1B-7B 6.33)인 반면 보류 점수는 0에 가깝다. ablation: (1) TriviaQA에서 되돌아본 환각 vs 그렇지 않은 환각 — 둘 다 강하게 암기됨. (2) 난이도 곡선 — 정답 롤아웃 수가 줄수록 암기 점수 증가. (3) 거부 프로브 — 오답 선택지를 "모두 해당 없음"으로 바꾸면 강화 후 거부율이 감소(표 2). 실무적 결론: 지식 도메인 사후 학습은 환각을 고려한 보상 설계가 필요하며, 특히 어려운 문제에서 결과만의 보상이 자기 환각을 암기시킨다.
