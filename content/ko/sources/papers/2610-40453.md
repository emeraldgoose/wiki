# PhysInsert: 기하 사전과 양방향 객체-장면 상호작용을 쓰는 물리적으로 그럴듯한 객체 삽입

출처: Yue Gong, arXiv:2610.40453, 2026-10-29.

**핵심 요약**: 기존 reference-based 객체 삽입 방법은 masked 입력, generation-based 쌍, 또는 viewpoint 변화가 제한된 학습 쌍에 의존해 pose와 illumination適応과 양방향 객체-장면 상호작용이 충분히 제약되지 않습니다. **PhysInsert**는 객체와 주변 장면을 함께 적응시키는 **물리적으로 그럴듯한 reference-based 객체 삽입** 프레임워크입니다. viewpoint와 lighting 조건에 걸쳐 strictly aligned Blender-rendered counterfactual pair와 object reference를 가진 **Insert World** 데이터셋을 구축했습니다. 이 데이터 위에서 **Geometry-Guided Adaptation** 은 target-scene feature supervision 아래 VGGT geometry stream을 image와 text stream에 결합해空間적으로 일관된 삽입을 안내합니다. 보완적인 2D Object-Scene Spatial Supervision은 객체 occupancy와 환경 변화를 함께 지도하고 image-text attention으로 공간 지시를 객체 영역에 grounding합니다. **PhysInsert-Bench**는 appearance 복사 이상의 조명·pose 적응을 요구하는 cross-environment와 cross-view 케이스를 도입합니다. PhysInsert-Bench와 DreamBooth에서 이미지 fidelity가 개선되었고, 사용자 연구에서는 배치 정확도와 lighting integration, perspective, pose plausibility가 더 좋게 나타났습니다.

## 핵심 내용

- reference-based 삽입은 pose와 illumination適応이 부족하다.
- Insert World는 viewpoint·lighting에 걸친 aligned counterfactual pair를 제공한다.
- Geometry-Guided Adaptation이 기하를 image·text stream에 결합한다.
- 보완 지도가 occupancy와 환경 변화를 함께 supervises한다.
- PhysInsert-Bench는 cross-environment·cross-view 적응을 요구한다.
- 벤치마크에서 이미지 fidelity가 개선됐다.
- 사용자 연구에서 배치·조명·관점·포즈 그럴듯함이 높아졌다.

## 상세

프레임워크는 appearance만 복사하지 않고 객체와 장면을 함께 적응시킵니다. geometry-guided adaptation과 spatial supervision이 객체-장면 상호작용을 제약합니다.
