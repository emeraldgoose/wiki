# R^2Orch: 스킬 내재화 루프 내 자기 대전을 통한 에이전트 오케스트레이션의 재귀적 자기개선

**원문**: [arXiv:2610.22740](https://arxiv.org/abs/2610.22740) · **게시일**: 2026-10-22
**저자**: Mingda Zhang, Yun Huang, Qiang Huang, Yanjin Li, Rui Qian, Qichao Zhao, Tiesunlong Shen, Na Zhao, Jian Wang, Xiaoying Tang

## 개요

에이전트 오케스트레이션은 복잡한 인간 태스크 해결에 널리 사용되지만, 기존 학습 방식은 직접 설계한 커리큘럼, 모든 롤아웃이 동일한 결과에 도달할 때의 이점 붕괴, 각 스킬을 단일 잡음 있는 점수로 평가하는 불신호라는 문제에 직면한다. R^2Orch는 재귀적 자기 대전 오케스트레이션을 제안한다. 자기 선택 태스크 위에서 오케스트레이터를 개선하는 내부 자기 대전 루프와, 그 루프의 개선 방식 자체를 개선하는 외부 루프로 구성된다. 이 방법은 스킬 내재화 루프 내에 위치하여 오케스트레이션 학습을 더 견고하게 만든다.

## 핵심 내용

- 직접 설계한 커리큘럼과 이점 붕괴 문제를 다룬다.
- 자기 선택 태스크에서 수행되는 내부 자기 대전 루프를 사용한다.
- 개선 과정 자체를 최적화하는 외부 루프를 제공한다.

## 상세

R^2Orch는 자기 대전과 스킬 내재화를 결합하여 태스크 해결과 메타 수준 학습 품질을 모두 개선하는 재귀적 자기 개선 방향의 오케스트레이션 학습으로 전환한다.
