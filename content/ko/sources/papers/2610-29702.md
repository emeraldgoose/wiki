# CausGround: 적응형 구현 planning을 위한 causal interaction grounding

**원문**: [arXiv:2610.29702](https://arxiv.org/abs/2610.29702) · **게시일**: 2026-10-21
**저자**: Yijun Shen et al.

## 개요

멀티모달 LLM은 유망한 reasoning capability를 보이지만, 신뢰할 수 있는 물리 상호작용은 action execute possibility와 world change를 account 하는 planning이 필요하다. precondition과 effect는 environment-dependent하고 MLLM이 종종 capture하지 못한다. CausGround는 interaction experience를 reusable action-centered causal knowledge로 distill하는 non-parametric causal interaction grounding framework이다. 이를 factorized world-state로 organize해 object attributes와 inter-object relations를 포착한다.

## 핵심 내용

- parameter update 없이 reusable action precondition과 effect를 구축한다.
- planning time에 task-relevant causal dependencies를 current observations에 ground한다.
- precondition backward reasoning과 effect forward reasoning을 지원한다.
- vision-based high-level planning을 VirtualHome에서 24.9%→53.3%, RoboCasa closed-loop에서 43.0%→57.0%로 개선한다.
- SWITCH에서 interaction reasoning accuracy를 25.8%→31.9%로 높이고 real-world sequential manipulation을 보인다.

## 상세

재사용 가능한 causal knowledge는 재학습 없이 diverse environment에 plan 적응을 가능하게 하고 long-horizon planning을 개선한다.
