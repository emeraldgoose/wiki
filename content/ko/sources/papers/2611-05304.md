# LoopVQ: 루프 트랜스포머를 위한 서브 1비트 KV 캐시 양자화

**원문**: [arXiv:2611.05304](https://arxiv.org/abs/2611.05304) · **게시일**: 2026-11-03
**저자**: Minsoo Cheong, Sungjoo Yoo

## 개요

Looped transformer는 language modeling용 parameter-efficient 대안이다. 동일 레이어를 여러 loop step에 재사용함으로써 최근 looped language model은 non-looped model보다 several times 큰 모델 성능에 match한다. architecture가 parameter memory를 줄이지만 각 loop step은 own keys/values를 저장하므로 KV cache는 loop step 수에 선형으로 커져 main memory bottleneck이 된다. 논문은 looped model KV cache가 loop axis에서 highly redundant하고 loop steps가 quantization sensitivity에서 substantially differs 한다는 것을 관찰한다. 이러한 관찰에 기반해, LoopVQ는 여러 루프 단계의 채널을 결합하여 코딩하고 풀프레시전(full-precision) 모델 출력에 맞추어 코드북을 미세조정하는 루프형 트랜스포머(looped transformer) KV 캐시 벡터 양자화 방법을 제안한다. 0.5 bits per element에서 LoopVQ는 Ouro/Huginn 모델 general, long chain-of-thought reasoning, long-context retrieval tasks에서 standard LLM KV cache vector quantization baselines보다 성능이 더 뛰어났다. 이 설계는 이들 방법과 독립적(orthogonal)이며 TaSQ와 결합하면 0.25 bits에서도 BF16 정확도의 상당 부분을 유지한다. 논문은 SGLang 구현도 수행해 32K-token context decode latency를 거의 half reduction하고 Ouro 1.4B/2.6B에서 BF16 대비 peak serving throughput을 4.3x/6.1x 증가시킨다.

## 핵심 내용

- looped transformer는 parameter memory를 줄이지만 loop step마다 KV cache가 선형으로 증가한다.
- loop axis redundancy와 uneven quantization sensitivity를 활용한다.
- LoopVQ는 여러 루프 단계 채널을 결합하여 VQ하고 풀프레시전 출력에 맞게 코드북을 미세조정한다.
- 0.5 bits/element에서 general/long-CoT/retrieval tasks baselines 능가.
- TaSQ 결합 시 0.25 bits BF16 유사 정확도, SGLang 32K latency 절반 + 4.3x/6.1x throughput.

## 상세

SGLang implementation이 serving gains를 demonstrate한다. extensive benchmark는 general reasoning과 long-context retrieval를 포괄한다. full accuracy tables/experiments는 연결된 원문을 참고한다.
