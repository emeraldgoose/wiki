# SIMIT: 상상력을 활용한 테스트 시점 자기 개선 비전-언어 모델

**원문**: [arXiv:2611.00053](https://arxiv.org/abs/2611.00053) · **게시일**: 2026-10-11
**저자**: Mehmet Onurcan Kaya, Desmond Elliott, Dim P. Papadopoulos

## 개요

SIMIT은 레이블 없는 테스트 쿼리에 답하기 전에 비전-언어 모델이 쿼리별 학습 데이터를 직접 생성하는 테스트 시점 자기 개선 프레임워크이다. 목표는 주석이나 외부 모델 없이도 특정 테스트 집합에서 성능을 개선하는 것이다. 일부 테스트 시점 방법은 더 긴 추론이나 반복 샘플링으로 답을 개선하지만 모델 자체는 바꾸지 않는다. 다른 방법은 여러 후보 답의 다수 합의나 모델 자신의 정확성 판단에 기반한 보상으로 모델을 갱신하지만, 그런 보상은 기존 오류를 강화할 수 있다. SIMIT은 대신 쿼리에 맞춘 합성 학습 데이터를 생성해 답을 개선한다.

## 핵심 내용

- 비전-언어 모델을 테스트 시점에 개선한다.
- 외부 레이블이나 외부 모델 없이 동작한다.
- 답하기 전에 쿼리별 학습 데이터를 생성한다.
- 다수 자기 일관성에 대한 의존을 줄인다.
- 자기 생성 레이블의 확증 편향을 다룬다.

## 상세

핵심 아이디어는 각 테스트 쿼리를 국소적인 학습 기회로 전환하는 것이다. 답을 여러 번 샘플링하거나 불확실한 자기 판단으로 파라미터를 갱신하는 데 그치지 않고, SIMIT은 먼저 관련 학습 예시를 상상해 생성한다. 이를 통해 모델은 특정 쿼리에 맞게 행동을 개선할 수 있다. 논문은 주석이나 외부 모델이 없는 제약 하에서의 개선을 강조하며, 잠재적으로 편향된 레이블을 재사용하는 테스트 시점 증강이나 자기 증류 접근법과 구분된다.
