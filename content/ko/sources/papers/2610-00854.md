# Are Frontier VLM Agents Ready to Be Robot Generalists? Embodied Agent Arena 실증 연구

**원문**: [arXiv:2610.00854](https://arxiv.org/abs/2610.00854) · **게시일**: 2026-10-23
**저자**: Haojian Huang, Pukun Zhao, Zexi Li, Yehang Zhang, Yangkai Wei, Wenqian Li, Han Yang, Kaiwen Zhou, Ying-Cong Chen, Yinchuan Li

## 개요

로봇 generalist는 장면을 해석하고 행동하며 task의 모든 조건을 만족해야 한다. 본 연구는 Frontier vision-language models가 Embodied Agent Arena로 그 요구를 얼마나 충족하는지 묻는다. 벤치마크는 Geometry, Spatial Reasoning, Affordance, Task Planning, Manipulation 전반에서 10개 VLM agent를 평가한다. 1,000 cases는 32 sources와 GeoProbe 168-case benchmark를 결합하며, 최소 harness가 task decisions를 source-native interfaces로 모델에 맡긴다. Closed-weight models는 다섯 domain 전반에서 앞서고, Open-weight VLMs는 uneven하고 task-dependent한 embodied competence를 보인다.

## 핵심 내용

- 벤치마크는 다섯 embodied capability domain에서 10개 VLM agent를 평가한다.
- 32 sources와 GeoProbe suite로 총 1,000 cases를 구성한다.
- geometry, spatial reasoning, affordance, planning, manipulation을 분리 평가한다.
- minimal harness가 benchmark-specific scaffolding을 줄인다.
- closed-weight models가 모든 evaluated domains에서 leading한다.
- open-weight models는 broad하지만 inconsistent한 embodied capability를 보인다.

## 상세

연구는 benchmark construction, evaluation protocol, task requirement analysis를 제공한다. 결과는 minimal harness와 selected interfaces에 의존하므로 Open-weight models가 다른 prompting/tooling에서 improve 될 수 있다. per-domain profiles가 이유별 weakness를 reveal하고, embodied deployments model selection과 targeted data/methods를 guide한다.
