# 훈련으로 컴파일하기: 자연어 명세를 로컬 신경 함수로

출처: Yuntian Deng, Pengyu Nie, Stuart Shieber, arXiv:2609.04199, 2026-09-03. EMNLP 2026 System Demonstrations. 데모 programasweights.com.

**핵심 요약**: 반복되는 텍스트 함수(이메일 분류, 사이트 도우미)는 설명은 쉽지만 규칙 인코딩은 손이 많이 가고, 입력마다 대형 원격 모델을 부르면 비용·지연·종속이 반복됩니다. **훈련 컴파일**은 자연어 명세를 재사용 가능한 **신경 함수**로 바꿉니다. 컴파일 타임에 교사 모델이 과제 예제를 합성해 소형 인터프리터용 어댑터를 훈련하고, 결과물은 교사 없이 돌아가며 저장·버전관리·조합됩니다. Program-as-Weights 고속 컴파일러가 exact match 0개였던 **FuzzyBench-Hard**에서 **의미 정확도 83.6%**(LEM 0.224 → 0.836)를 내고, 컴파일 시간은 수초 대신 약 1분입니다.

## 컴파일 경로

모든 프로그램은 동결된 **양자화 Qwen3-0.6B 인터프리터**를 공유하고, 각 함수는 **랭크-64 LoRA 어댑터** + 컴파일러 생성 프롬프트 스캐폴드입니다. PAW amortized 컴파일러 예측으로 웜스타트한 뒤 100스텝 cosine 스케줄로 다듬습니다. 공개 레시피는 저가 교사(대량 예제)와 대형 교사(보완 supervision)를 섞고, GPT-5.4-mini/GPT-5.5 2:1 혼합이 개발셋 LEM을 0.746 → 0.851로 올립니다. 배포 서비스는 합성과 훈련을 겹쳐(GPU가 교사를 기다리며 놀지 않음) 백그라운드 빌드 잡으로 진행하고 교사 출력을 캐시 재사용합니다. 콜드 컴파일은 50.9초(B300), 68.2초(H200), 99.2초(RTX).

## 조합된다는 증거

| 배포 | 결과 |
|---|---|
| 멀티사이트 도우미(분류기 + BM25 + 검증기의 프로그램 트리) | 페이지+포럼 증거 결합 실시간 답변 |
| 언어 조종 3D 아바타(명세 → 액션 DSL → 브라우저 렌더) | 검증 지시 44개 중 43개 정확 |
| 영어↔Claudish 양방향 번역기 | 2026-08-22~09-02 100,747 성공 요청 |

분업이 핵심입니다. 컴파일 함수는 퍼지 결정을 맡고, 검색·캐싱·분기 같은 정확한 연산은 보통 코드가 합니다.

## 주의할 점

정확도는 LLM Exact Match(GPT-5.5 grader, 저자 대비 κ=0.946) — 모델 채점 지표라 자체 실패 모드가 있습니다. 합성 supervision은 교사 오류를 상속하므로 보장된 정확도가 필요하면 검증 경로를 유지하세요. 분 단위 컴파일은 안정된 함수용이지 빠르게 바뀌는 명세용이 아닙니다.

## SW 엔지니어와의 관련성

- 적응을 **빌드 단계**로 다루세요. 명세 들어가서 버전 있는 `.paw`식 산출물 나오고, 캐시·조합은 보통 소프트웨어처럼 — 호출마다 프롬프트 거는 것보다 sane한 운영 이야기입니다.
- amortized 예측으로 웜스타트하고 최적화 예산은 돈 되는 곳에만 쓰세요. 컴파일 3.5초 → 50.9초가 LEM +0.612를 삽니다.
- 느린 교사 합성과 훈련을 겹치고 컴파일을 백그라운드 잡으로 — 증류 파이프라인 일반에 통하는 서빙 패턴입니다.
- 파싱·검증·분기 같은 제어 경로는 결정적 코드에 두고, 신경 함수는 퍼지 결정만 맡기세요.
