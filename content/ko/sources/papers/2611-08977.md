# 에너지 기반 추론자: 순환 추론기는 에너지 기반 모델이어야 한다

**출처**: [huggingface](https://arxiv.org/abs/2611.08977)
**게시일**: 2026-11-06

## 개요

루프(순환) 아키텍처는 동일한 블록을 잠재 상태에 반복 적용함으로써 모델의 유효 깊이를 키우며, 어려운 알고리즘 추론 과제에서 최근 강력한 성과를 보여 왔다. 그러나 이러한 반복 갱신에는 진행 상황을 재는 명시적인 척도가 없다. 현재 잠재 상태가 얼마나 좋은지, 언제 반복을 멈춰야 하는지, 어떻게 개선해야 하는지를 알려 주는 신호가 없는 것이다. 토큰 기반 추론에서는 chain-of-thought가 중간 단계를 노출해 평가할 수 있게 함으로써 이 문제를 해결하지만, 잠재 공간에서 동작하는 루프 모델에는 그런 손잡이가 부재하다.

Energy-Based Reasoners(EBRs)는 잠재 추론 상태 위에 스칼라 에너지 함수를 학습하고, 루프 갱신을 그 에너지에 대한 경사 하강으로 정의함으로써 이 문제를 푼다. 에너지 값은 각 후보 상태를 채점하고, 에너지의 기울기는 상태 개선을 이끌며, 그 기울기의 크기는 순환을 멈출 시점을 알려 주는 원칙적인 정지 신호가 된다. 상태가 제약 없는 순환 갱신이 아니라 하강 방식으로 개선되기 때문에, 동역학의 정지점은 기울기가 0에 가까워지는 지점과 일치하며, 수렴 여부로 중단 시점을 정하기가 잘 정의된다.

학습은 저자들이 Explorative Modeling(SXM)이라 부르는 탐색 기반 방식으로 완성된다. 모델이 생성한 궤적을 유도하고 적절한 목표와 맞추어 에너지 지형을 더 넓은 상태 집합 위에서 빚어 주며, 이는 서로 다른 유효 해에 대응하는 추가 모드까지도 포함한다. 추론 시에는 반복 상태에 가벼운 RMS 정규화와 노이즈를 더하고, 투영된 기울기 노름이 임계값 아래로 떨어지면 조기에 멈춘다.

## 핵심 포인트

- 루프 추론을 에너지 최소화로 재정식화했다. 갱신은 잠재 상태 z와 문제 x에 대한 학습된 에너지 E(z; x)의 경사 하강 단계다.
- 하나의 에너지가 세 역할을 겸한다. 잠재 상태 채점, 기울기를 통한 상태 개선 유도, 그리고 반복 중단 시점 신호.
- 탐색 기반 학습(SXM)은 에너지 지형을 넓혀 단일 끌개에 머무르지 않고 여러 해 모드를 발견하도록 돕는다.
- 네 가지 알고리즘 추론 벤치마크(Sudoku-Extreme, Maze-Hard, N-Queens, Graph Coloring)에서 EBRs는 기존 순환 추론 모델에 필적하거나 그것을 능가한다.
- Sudoku-Extreme에서 99.9% 정확도를 달성하면서 차점 모델 대비 345배 적은 추론 연산량을 사용하며, 학습 연산량은 비슷하고 외부 검증기도 필요 없다.
- 다중 해 벤치마크 모두에서 거의 100%에 가까운 단일 샘플 정확도를 유지하면서 서로 다른 유효 해의 커버리지 측면에서 최고 성능(SOTA)을 기록했다.

## 상세

**방법.** 인스턴스 x가 주어지면 EBR은 z ~ N(0, I)로 잠재 상태를 초기화하고 S개의 구간(segment)에 걸쳐 반복 개선을 수행한다. 각 단계는 z를 RMS 정규화하고, 필요 시 스케일 sigma의 노이즈를 주입하며, 음의 에너지 기울기를 따라 보폭 alpha로 이동한 뒤 상태 다양체 M 위로 다시 사영한다. 수렴 손실(convergence loss)은 올바른 예측이 에너지의 정지점(투영 기울기가 0에 가까운 지점)에 도달하도록 유도한다. 학습 시에는 구간당 n개의 경사 단계를 n과 alpha를 무작위로 샘플링하며 펼치고, 하강 과정 전체를 통해 역전파하며, 모델이 생성한 궤적상의 상태들이 적절한 목표와 맞춰진 감독을 받도록 SXM 탐색 목적을 더한다. 잔차 r_n이 임계값 delta 아래로 떨어지면 조기 종료한다. 추론은 동일한 하강을 따르되 투영 기울기 노름이 tau 아래로 떨어지면 그 구간을 멈추고, 마지막 상태에서 예측 헤드로 답을 복호한다. HRM/TRM식 계층적 순환과 달리 EBR은 계층 없이 단일 잠재 상태를 사용하고, IREM/IRED/Energy-Based Transformer와 달리 에너지가 후보 예측이 아니라 잠재 추론 상태를 채점하며, ERM 같은 과제 제약 에너지 방식과 달리 에너지를 끝까지(end-to-end) 학습하고 하드코딩된 과제 특성을 쓰지 않는다.

**결과.** 이 논문은 네 가지 어려운 알고리즘 추론 벤치마크인 Sudoku-Extreme, Maze-Hard, N-Queens, Graph Coloring을 보고한다. EBRs는 이들에서 기존 루프 추론 모델과 동등하거나 그보다 우수하다. 헤드라인 수치: Sudoku-Extreme에서 99.9% 정확도와 차점 모델 대비 345배 적은 추론 연산량(학습 연산량은 유사), 그리고 모든 다중 해 벤치마크에서 거의 100%에 가까운 단일 샘플 정확도를 유지한 채 서로 다른 유효 해 커버리지 SOTA를 달성했다. 부록은 GRAM과의 학습 연산량 비교, Maze-Hard 한계 및 최단 경로 정확도 분석, 부분 해 집합을 이용한 Reverse SXM 분석을 추가로 다룬다.
