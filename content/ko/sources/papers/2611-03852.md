# 긴 추론에 돈을 쓰지 말자: 추론 이력 압축이 미래 생성과 에이전트 비용에 미치는 인과 효과

**원문**: [arXiv:2611.03852](https://arxiv.org/abs/2611.03852) · **게시일**: 2026-11-02
**저자**: Anton Hristov

## 개요

추론은 언어 모델의 어려운 문제 해결 능력을 크게 높이지만, 긴 추론 trace는 그 이득을 비싸게 만든다. 효율적 추론은 반복과 낮은 가치 텍스트를 줄여 유용한 분석을 더 적은 토큰으로 표현해야 한다. propriétaire 모델의 진전이 이 목표를 동기 부여하지만, hidden scratchpad는 그것이 어떻게 달성되는지 직접 연구를 제한한다. 논문은 재학습 없이 open-weight 모델이 자기 자신 이전 사고의 형태를 바꾸어 덜 장황한 추론을 생성할 수 있는지 조사한다. 개입은 보류된 도구 결과가 드러나기 전에 이전 추론을 압축 상태 레코드로 재작성하고, 원래 이력과 압축 이력에서의 continuation을 비교한다. 실험한 모델 전반에서 accepted compact history는 대개 future reasoning을 단축했고, 코딩 case study에서는 공유 후보 solution 이후 반복 검증이 줄어들었다. software-agent deployment에서는 compaction이 총 지출을 줄일 수 있지만, task quality와 rewrite-inclusive time은 target/compressor에 의존한다. 이런 결과는 reasoning history가 future reasoning-token 사용을 줄이는 한 수단이고, 효율성과 retained capability를 함께 평가하는 model-specific compaction policy를 동기 부여한다.

## 핵심 내용

- 긴 추론은 문제 해결 능력을 높이지만 비용도 크게 만든다.
- 이전 추론을 압축 상태 레코드로 재작성하는 개입을 재학습 없이 실험한다.
- accepted compact history는 대개 future reasoning 길이를 줄인다.
- 코딩 case study에서 공유 candidate 이후 반복 검증이 감소했다.
- agent deployment에서 비용 절감은 가능하지만 품질/시간은 model·compressor에 의존한다.

## 상세

개입은 retrieval이나 tool 추가가 아닌 과거 추론 형태를 조작한다. 효율성, faithful, rewrite cost 사이 tradeoff는 연결된 원문에 논의되어 있다.
