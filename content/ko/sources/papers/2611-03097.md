# DR Pixel: VLM을 활용한 페이지 네이티브 심층 리서치

**원문**: [arXiv:2611.03097](https://arxiv.org/abs/2611.03097) · **게시일**: 2026-11-02
**저자**: Tiansheng Hu, Yichuan Wang, James V. Talwar, Nicholas Tomlin, Chen Zhao, Sewon Min

## 개요

과학 논문과 같은 복잡한 문서는 표, 그림, 수식에 풍부한 정보를 담고 있지만 심층 리서치 에이전트는 보통 OCR로 추출한 텍스트로 문서를 축약한다. DR Pixel은 VLM이 렌더링된 문서 페이지 이미지를 직접 검색하고 추론해 페이지 네이티브 심층 리서치를 가능하게 하는지를 묻는다. 1.06M 페이지 코퍼스 위에서 렌더링된 페이지 이미지를 유일한 검색 및 추론 단위로 사용하는 최초의 개방형 종단간 멀티모달 심층 리서치 에이전트로 소개된다. DRPixelBench가 이 설정을 평가한다.

## 핵심 내용

- 문서의 표, 그림, 수식은 중요한 정보를 담는다.
- OCR 텍스트 축소는 많은 구조를 잃는다.
- 페이지 네이티브 심층 리서치는 렌더링된 페이지 이미지로 추론한다.
- DR Pixel은 개방형 멀티모달 심층 리서치 에이전트이다.
- 페이지 이미지가 검색 및 추론 단위이다.
- 코퍼스에는 1.06M 페이지가 있다.

## 상세

핵심 아이디어는 시각 문서 구조를 펼쳐내지 않고 보존하는 것이다. 렌더링된 페이지는 레이아웃, 그림, 수식을 원래 맥락에 유지하므로 VLM이 페이지 전체를 holistic하게 추론할 수 있다. DR Pixel은 이를 중심으로 한 종단간 시스템을 구축하며 큰 페이지 코퍼스에서 검색을 포함한다. 벤치마크는 텍스트 추출만이 아니라 시각 문서에서의 answer quality와 grounding을 평가한다.
