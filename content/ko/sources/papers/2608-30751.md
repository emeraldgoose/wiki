# Autoregressive Mosaics: Probing 2D Spatial Reasoning in Text-Only Language Models

: Text-and-code-only LLMs can sometimes generate programs that draw recognisable images — but is that an internal representation of 2D spatial layout, or just the ability to **translate spatial descriptions into code**? AM-Bench separates the two with two complementary tasks: a **translation task** that hands the model a fully specified geometry and asks for the code, and a **layout task** that requires composing an image from an underspecified prompt. Across **eight open-weight text-and-code-only models**, all reliably translate specified geometry into code, but **open-ended layout performance differs substantially** — so the differences are not explained by code-generation ability. An output-medium ablation adds a third finding: **replacing procedural code with raw SVG improves layout scores across all models**. Probing activations shows a coarse plan exists before generation but reflects only the prompt's layout, and during generation models **track the evolving geometric state** rather than executing a fixed plan.

The ambiguity worth separating: The motivating observation is familiar: ask GPT-4 for a unicorn in TikZ and you get something recognisable, from a model that has never seen an image. Explanations abound, and they are not the same claim.

An LLM-generated image alone cannot tell you whether a poor layout results from:

Design: two tasks, one control: AM-Bench represents an image as an autoregressive mosaic — a small raster produced by a program and rendered by a deterministic executor. The pipeline is four stages: prompt → internal plan → program code → rasterised geometry.

Findings: Translation is solved; layout is not. Every model reliably turns specified geometry into code. Open-ended layout performance varies a great deal between them. This is the paper's central empirical claim: layout ability is not a proxy for coding ability.

Scope: The authors are careful about what the benchmark measures: allocentric 2D layout at mosaic granularity. It is a necessary-condition probe for embodied spatial competence, not a sufficient one, and it does not cover metric egocentric continuity, depth, or occlusion. The activation-level claims are behavioural; the authors flag direct causal analysis via activation patching as future work.
