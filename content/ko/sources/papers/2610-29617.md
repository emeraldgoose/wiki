# TernScope: 효율적인 삼진수 내시경 분할을 위한 모델-하드웨어 공동 설계

**원문**: [arXiv:2610.29617](https://arxiv.org/abs/2610.29617) · **게시일**: 2026-10-21
**저자**: Zhuoyu Wu, Wenhui Ou, Qiawei Zheng, Xuhong Qiu, Wenqi Fang, Raphaël C. -W. Phan

## 개요

엣지 의료 분할은 작은 모델 크기, 높은 정확도, 빠른 추론을 동시에 만족해야 한다. TernScope는 모델-하드웨어 공동 설계를 통해 low-bit 연산자가 하드웨어 실행을 단순화하는 compact 분할 네트워크를 학습한다. Split-channel large-kernel 블록은 제한된 연산으로 공간 컨텍스트를 보존하고, branch fusion은 중복 추론 경로를 제거한다. 삼진수 점진적 양자화 인식 학습은 깊은 계층에서 얕은 계층, 디코더, 입력 및 예측 계층 순으로 융합 네트워크를 적응시킨다.

## 핵심 내용

- 엣지 내시경의 모델 크기–정확도–속도 삼중 딜레마를 다룬다.
- 네트워크 단계 전반에 걸친 삼진수 양자화 인식 학습을 사용한다.
- 효율성을 위해 모델과 하드웨어 실행을 공동 설계한다.

## 상세

TernScope는 아키텍처와 양자화 선택을 통합하여 메모리에 맞고, 병변을 정확히 구획하며, 제약 하드웨어에서 빠르게 예측을 제공하는 배포 가능한 모델을 만든다.
