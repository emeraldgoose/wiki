# 검색 증강 생성으로 주식시장 정보 검색 강화

**원문**: [arXiv:2611.03747](https://arxiv.org/abs/2611.03747) · **게시일**: 2026-11-02
**저자**: Huan Phong Thai, Thu Anh Ngoc Le, Nhu Huynh Thi Le, Nhan Huu Tran, Lenh Cong Phan Pham, Hong Nhung Nguyen

## 개요

자연어 처리는 금융 분야에서 널리 사용되지만 전통적 자연어 처리는 동적 금융 환경에서 문맥 정확도와 관련 응답 생성을 어려워한다. 이 논문은 주식시장 정보에 대한 응답을 생성하는 검색 증강 생성 시스템을 제안한다. 검색 기반과 생성 기반 접근을 통합해 정확성과 관련성을 향상한다. 평가는 100개 주식시장 관련 질의에 ROUGE-1, ROUGE-2, ROUGE-L을 적용하고, 평균 응답 시간 1.16초도 측정한다. 시스템은 정확하고 시기 적절한 금융 통찰을 목표로 하며, 보편적 시장 커버리지를 가정하지 않는다.

## 핵심 내용

- RAG는 검색 근거와 생성 응답을 결합한다.
- 초점은 주식시장 정보 검색과 생성이다.
- 데이터셋은 100개 주식시장 관련 질의로 구성된다.
- 평가는 ROUGE-1, ROUGE-2, ROUGE-L을 보고한다.
- 평균 응답 지연 시간은 1.16초이다.
- 결과는 시기 적절한 통찰 가능성을 보여주지만 운영 준비를 보장하지 않는다.

## 상세

논문은 질의 집합과 지연 시간에 대해 검색·생성 파이프라인을 평가한다. 높은 ROUGE 지표는 참조 문서와의 정렬을 나타내지만 동적 시장에서 사실 정확성을 단독으로 보장하지 않는다. 실제 배포 시에는 다양한 브로커, 데이터 품질 이슈, 사용자 의도를 더 평가해야 한다.
