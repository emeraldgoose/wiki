# JEPAs로 플라톤 표현 가설 증명 및 개선

출처: Randall Balestriero, arXiv:2610.39302, 2026-10-29.

**핵심 요약**: 서로 다른 모달리티로 훈련된 모델이 세계의 같은 표현으로 수렴하는지 여부는 AI의 핵심입니다. **플라톤 표현 가설(PR H)** 은 scale에 따라 그렇게 된다고 추측하지만, 증명 없이는 보장도 레시피도 제공하지 않습니다. 저자들은 가설을 정리로 바꿉니다. **첫째, 플라톤 표현 정리**: Joint-Embedding Predictive Architecture(JEPA)는 여러 모달리티에서 따로 학습되더라도 양성 쌍이 한 장면의 두 관측, 즉 **good view**일 때 misalignment가 bounded인 경우 회전 하나 차이까지 동일한 표현을 학습합니다. 둘째, **next-token prediction은 bad view를 쓰는 JEPA**, 즉 단일 문서의 일부라는 것을 보여 언어 모델이 vision과 scale을 통해서만 align되는 이유를 설명합니다. 셋째, 145k 캡션에서 940M 웹 이미지 텍스트까지 이론을 검증하고 unseen run을 시드 노이즈 수준으로 예측하는 **정렬 scaling law**를 발굴했습니다. 동일 정렬에 good view는 next-token prediction과 같은 코퍼스에서 **42배 적은 훈련 샘플**을 필요로 하며, **109M 파라미터 text JEPA**는 72B까지의 모든 언어 모델과 CLIP 텍스트 인코더보다 DINOv2·CLIP 이미지 인코더에 더 잘 align됐습니다. next-token prediction은 플라톤 표현으로 가는 현저히 비효율적인 경로입니다. 쇼케이스로 회전 하나로 따로 학습된 인코더를 이미지 캡셔너로 바꿀 수 있었고(CIDEr .838 on COCO), 그 회전조차 쌍이 필요 없습니다. 최신 pair-free 벤치마크에서 text JEPA는 8B까지 언어 모델 기반 zero-shot 정확도를 모두 넘어섰습니다(예: ImageNet-100 top-5 64% 대 최대 56%). **positive view, scale만이 아닌** 것이 플라톤 표현을 만드는 레버입니다.

## 핵심 내용

- JEPAs에 대해 플라톤 표현 가설을 정리로 증명했다.
- good view는 같은 장면의 두 관측이다.
- good view에서 학습한 JEPAs는 회전까지 같은 표현을 공유한다.
- next-token prediction은 bad view를 쓰는 JEPA다.
- good view는 동일 정렬에 42배 적은 샘플이 필요하다.
- 109M text JEPA가 72B까지 LM과 CLIP 텍스트 인코더보다 align이 좋다.
- pair-free 평가에서 ImageNet-100 top-5 64%를 달성했다.

## 상세

이론은 145k 캡션에서 940M 웹 이미지 텍스트까지 scale 전반에서 검증되고 정렬 scaling law를 낳습니다. 쇼케이스는 인코더를 회전으로 연결할 수 있고 짝 없는 retrieval도 강함을 보입니다.

- perceptual contrast가 좋은 표현 학습의 핵심입니다.
- good-view 설계는 샘플 효율을 크게 높일 수 있습니다.
- 표현 align은 scale만으로는 회복되지 않을 수 있습니다.
