# LifeSearch: 실제 생활·생산성 딥리서치 에이전트 벤치마크

출처: Yibo Wang 외 8인, arXiv:2610.18092, 2026-10-13.

**핵심 요약**: 딥리서치 에이전트는 다단계 추론, 장기 웹 검색, 증거 종합으로 개방형 정보 요구를 해결합니다. 기존 벤치마크는 주로 학술 연구나 합성 과제에 치우쳐, **실제 생활·전문 생산성**에서의 능력을 충분히 평가하지 못했습니다. **LifeSearch**는 실사용자 질의 시드에서 출발한 203개 중국어·영어 과제로 이 공백을 겨냥합니다.

## 구성

7개 생활·생산성 영역을 다루며, 4,500시간 이상의 사람 주석으로 **4,000개 이상의 전문가 작성 세밀 루브릭**을 만들었습니다. 보고서 내용의 커버리지·정확성 기준과 함께 값·단위·날짜·URL을 명시하는 구체 기준을 포함합니다. 12개 최신 딥리서치 에이전트를 통일된 평가 하네스에서 실험해 성능 패턴과 실패 모드를 분석했습니다.

## 결과

최고 성능 프런티어 에이전트인 **GPT-5.6 Sol도 63.4%**에 그쳐 현실적인 생활·전문 딥리서치 과제에 개선 여지가 크다는 것을 보여줍니다. 채점 구성은 후보 LLM 판정자를 사람 루브릭 라벨과 비교해 선택했고, 사람 순위 연구에서 집계 점수와 인간 판단의 정렬이 강했습니다(Spearman ρ=0.89, Kendall τ=0.81).

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 과제가 중국어·영어에 한정되고, 루브릭 채점은 판정자 모델에 의존합니다. 63.4%가 어떤 영역에서 특히 낮은지, URL·날짜 기준이 실제 최신성 문제를 얼마나 잡는지는 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 사내 리서치 에이전트를 평가할 때 학술 QA만 쓰지 말고, 실제 업무 질의와 값·단위·날짜·출처 기준을 루브릭에 넣으세요.
- 집계 점수만 보지 말고 커버리지와 정확성을 분리해 실패 모드를 진단하세요.
- LLM 판정자를 쓸 때는 사람 라벨과의 정렬을 먼저 검증하고, 채점 구성을 고정하세요.
