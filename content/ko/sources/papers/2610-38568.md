# A-RSI: 무데이터 멀티모달 자기 개선을 위한 적응형 과제 갱신

출처: Yu Liu 외 19인, arXiv:2610.38568, 2026-10-28.

**핵심 요약**: 재귀적 자기 개선은 모델이 유용한 훈련 경험을 얻을 뿐 아니라 현재 경험이 더 이상 유용하지 않은 시점을 결정해야 합니다. 기존 방법은 다음에 어떤 경험을 생성할지에 집중하고 새 경험이 언제 도입되어야 하는지는 덜 고려했으며, self-consistency나 다수결로 훈련 목표를 만들면서 감독이 모델 자신의 불확실한 예측에 의존했습니다. **A-RSI**는 이 두 질문을 분리합니다. 훈련 역학이 새 경험을 언제 획득할지를 결정하고, 새 과제의 답은 독립적으로 검증 가능하게 남습니다. 저자들은 과제 풀의 학습 신호가 감소할 때 검증/테스트 점수가 아닌 **훈련 로그의 보상 변동성과 정확도**로 풀을 갱신합니다. 모델이 작성한 프로그램의 정적 라이브러리가 멀티모달 질문을 만들고 참조 답을 유도하며, 과제 생성 계약을 명세하고 보상·갱신 규칙의 선택된 성질을 자동 검증하며 생성 답을 별도 감사합니다. 훈련 루프는 외부 훈련 예제나 사람 라벨 정답을 쓰지 않습니다. 주요 11개 벤치마크 스위트에서 A-RSI는 800개 신규 과제로 평균을 **57.77에서 61.05로** 높였습니다.

## 핵심 내용

- 새 경험 도입 시기는 생성 내용 선택과 분리한다.
- 과제 풀 갱신은 훈련 로그의 보상 변동성과 정확도만 사용한다.
- 검증/테스트 점수를 갱신에 사용하지 않는다.
- 모델이 작성한 프로그램이 질문과 참조 답을 생성한다.
- 보상·갱신 규칙은 자동 검증하고 답은 별도 감사한다.
- 외부 훈련 예제나 사람 라벨 정답이 없다.
- 800개 신규 과제로 11개 벤치마크 평균이 57.77에서 61.05로 올랐다.

## 상세

과제 생성과 감독을 모델의 불확실한 예측에 의존하는 self-consistency가 아니라 검증 가능한 형태로 만들었습니다. 갱신은 훈련 수준 학습 신호 감소로 트리거되어 테스트 데이터를 건드리지 않습니다.
