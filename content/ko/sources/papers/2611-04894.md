# VisSearch-Bench: 멀티모달 에이전트의 장기 시각 탐색 평가

**원문**: [arXiv:2611.04894](https://arxiv.org/abs/2611.04894) · **게시일**: 2026-11-03
**저자**: ZhengXian Wu, Qianhao Nie, Zhuohong Chen, Junjie Gao, Yuyao Zhang, Yunyao Yu, Hangrui Xu, Cheng Cheng, Guiyu Ma, Jin Zhang, Xingzhong Xu, Kai Yang, Haoqian Wang

## 개요

멀티모달 에이전트는 내부 지식을 넘어선 질문에 답하기 위해 web과 image tool을 사용한다. 많은 탐색 작업은 image를 초기 entity 식별에만 사용하고 이후 text retrieval에 의존하므로 agents가 image, object, search step 전반에서 정보를 연결하는 능력을 충분히 드러내지 못한다.

VisSearch-Bench는 시각 맥락 관리에 집중한다. 즉 search 중에 visual information을 organize하고 use하며 다른 findings와 link하는 능력이다. 시각 집약적 task는 object appearance, local details, spatial relation을 external information과 결합해야 한다. benchmark는 7개 main domain과 25개 subdomain에 걸친 204개 human-written task를 포함한다.

task type에는 set-wise visual search, sequential visual search, hybrid wide-deep search, competitive visual disambiguation, visual-structure-guided search가 있다. 각 task는 reference answer, traceable evidence, scoring rules를 제공한다. Accuracy는 완전한 task 성공을, Process Score는 개별 result와 subquestion answer의 correctness와 completeness를 측정한다. 16개 multimodal model 중 best system도 search tool을 사용했음에도 task의 약 26.47%만 fully solve한다.

## 핵심 내용

- 7개 domain과 25개 subdomain에 걸친 204개 human-written visual search task를 제공한다.
- 다단계 탐색 중 visual context management에 집중한다.
- set-wise와 sequential visual search를 포함한 다섯 task category를 정의한다.
- reference answer, traceable evidence, scoring rules를 포함한다.
- Accuracy와 Process Score를 보완 metric으로 사용한다.
- best system도 약 26.5%의 task만 fully solve한다.

## 상세

41頁 paper에는 22 figures가 포함된다. visual evidence와 search result를 연결해 complete answer를 만드는 어려움을 강조한다.
