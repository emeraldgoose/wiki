# HubEgo-100K: 로봇 학습을 위한 실제 현장의 숙련 작업 자기중심(Egocentric) 비디오

**Source**: [arXiv](https://arxiv.org/abs/2611.21938)
**게시일**: 2026-11-16

## Overview

모방 학습으로 훈련한 로봇 정책은 학습에서 보지 못한 환경과 물체 밖으로 일반화하지 못한다. 공개된 데이터 스케일링 연구들은 일반화가 환경당 시연 수보다 학습 환경·물체의 다양성과 함께 증가한다고 보고한다. 로봇 데이터는 많은 환경에서 수집하기 비용이 크지만, 자기중심(1인칭) 인간 비디오는 야생에서 대규모로 촬영할 수 있다 — 다만 기존 자기중심 비디오는 대부분 일상 활동을 보여주고 실제 작업 현장의 숙련 작업은 적다.

HubEgo-100K는 다양성을 위해 구축한 데이터셋이다. 이 논문은 첫 릴리스 v1.0을 다룬다: 하나의 머리 장착형 휴대폰 카메라에서 동기화된 100 Hz 관성(IMU) 데이터와 함께한 10,124시간의 1080p 자기중심 비디오. v1.0에서 12,227명의 기여자가 11개 환경 유형, 30개 작업 카테고리, 56개 과제 유형, 35개 행동 계열에 걸친 15,548개 환경에서 자기 자신의 무각본 작업을 촬영했으며, 시간의 83%가 작업장 환경이다. 릴리스는 기계 생성 행동·언어 주석이 달린 72,754개 에피소드로 이뤄지며, CC BY 4.0으로 LeRobot·MCAP 형식으로 제공된다.

## Key points

- 규모와 다양성: 10,124시간의 1080p 비디오, 72,754개 에피소드, 12,227명 기여자(누구도 전체 시간의 0.22%를 넘지 않음; 2,824명이 1시간 이상 촬영), 11개 환경 유형의 15,548개 환경; 시간의 82.6%가 작업장 환경(가정 내 기술직 포함, 26.9%), 17.4%가 가정; 30개 작업 카테고리(제조·조립이 5.4%), 56개 과제 유형, 35개 행동 계열.
- 손 가시성과 과제 집중도: 모델 추정 최소 한 손이 표집 프레임의 94.7%에 보임(양손 76.3%); 시간 가중 on-task 비율 96.9%.
- v1.0 내부의 개방 집합 성장: 에피소드를 무작위 순서로 놓으면 새 기여자와 새 단어가 계속 나타나, 릴리스 내부에서 커버리지가 포화되지 않음을 보인다.
- 에피소드는 모든 비디오 프레임을 프레임별 휴대폰 IMU 데이터(100 Hz), 과제 유형, 기계 생성 행동·언어 주석과 짝짓는다 — 대부분의 선행 자기중심 말뭉치에 없는 관성 신호다.
- 이 논문은 측정값을 정책 성능과 결부된 여섯 가지 데이터 특성에 대한 공개 증거(손 가시성, 관성 감지 포함)와 연결하고, 수집·큐레이션·프라이버시 조치·데이터 형식을 문서화하고 데이터시트를 제공한다. 이후 버전에는 벤치마크와 100,000시간을 향한 추가 릴리스가 추가될 예정이다.

## Details

- 수집: 기여자가 머리 장착형 휴대폰 카메라(단일 시점)로 자기 자신의 무각본 작업을 촬영; 큐레이션 파이프라인, 주석(기계 생성 행동/언어), 프라이버시·윤리 처리, 데이터 형식(LeRobot·MCAP)을 문서화; CC BY 4.0, 데이터시트 포함 릴리스.
- 선행 데이터셋과의 위치: Ego4D(일상), EPIC-KITCHENS(주방), Ego-Exo4D(123개 장면 맥락, 다중 시점 장비), Egocentric-10K/100K(공장·노동, 프레임별 IMU나 이 폭의 과제/행동 주석 없음)와 달리, HubEgo-100K는 숙련 기술직이 주도하는 30개 작업 카테고리를 아우르고 비디오를 관성 데이터·주석과 짝짓는다.
