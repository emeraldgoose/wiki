# AI 리뷰는 부록에 치우쳐 있다

**원문**: [arXiv:2611.17811](https://arxiv.org/abs/2611.17811) · **게시일**: 2026-11-13
**저자**: Saptarshi Ghosh, Mohammad Saim, Tianyu Jiang

## 개요

논문 심사에 대형 언어 모델(LLM)을 쓰는 일은 이제 눈에 띄는 관행이 됐다. ICLR 2026에서는 전체 리뷰의 5분의 1가량이 완전히 AI로 작성된 것으로 분류됐고, 리뷰어들은 모델이 뽑아 준 약점 목록을 그대로 자기 리뷰에 옮겨 적곤 한다. 기존 연구가 AI 리뷰와 인간 리뷰가 얼마나 일치하는지를 비교해 왔다면, 모델이 논문의 어느 부분을 실제로 비난하는지는 거의 알려지지 않았다. 신시내티 대학의 Saptarshi Ghosh, Mohammad Saim, Tianyu Jiang 연구팀은 이 물음을 처음 다룬 연구에서 최신 GPT와 Claude 모델이 비판의 화살을 대부분 부록(appendix)에 겨눈다는 사실을 밝혔다.

ACL 2026, EMNLP 2026, COLM 2026, ICLR 2027에서 뽑은 800편의 논문을 보면, GPT-6-Astra, GPT-6.1-Sol, Claude-Opus-5.5, Claude-Sonnet-5.5는 리뷰 약점의 절반 안팎 또는 그 이상을 부록 관련 내용에서 가져왔다. API, Codex나 Claude Code 같은 코딩 에이전트, 웹 인터페이스 중 무엇으로 모델을 부르든 결과는 같았다. 이 편향은 세대 차이로 보인다. GPT-5는 약점의 30% 미만만 부록과 연결했지만, GPT-6-Astra와 GPT-6.1-Sol은 어느 대회에서든 60~70% 수준에 이른다.

인간의 읽기 방식은 다르다. 2021~2024년에 작성된 ICLR 인간 리뷰에서는 약점의 8.4%만이 부록에서 나왔고, 그 내용도 주로 논문의 표현과 핵심 아이디어를 둘러쌌다. 반면 LLM 약점은 부록 깊숙한 곳에서 정점을 찍고 30페이지를 넘어서도 이어진다. 더 우려되는 점은 인간 수치가 모델을 향해 움직이고 있다는 것이다. GPT-6-Astra와 Claude-Opus-5.5가 공개된 뒤 진행된 2026년 심사 주기(ICLR 2027)에서 인간 리뷰 약점 가운데 부록 비중이 거의 3배인 27.60%로 뛰었다.

## 핵심 내용

- 연구 규모: 총 2,000편 — 부록이 15페이지 이상인 최근 논문 800편(ACL 2026, EMNLP 2026, COLM 2026, ICLR 2027에서 각 200편)과 2021~2026년 ICLR 논문 1,200편 — 을 GPT-6-Astra, GPT-6.1-Sol, Claude-Opus-5.5, Claude-Sonnet-5.5 네 모델로 리뷰했다.
- 핵심 결과: 거의 모든 모델과 네 대회 전반에서 LLM 약점의 절반 이상이 부록 관련 내용에서 나왔다. GPT는 약점의 17.33%를 부록만으로 귀속했고 Claude는 10.16%였다.
- 편향은 새로 생긴 것: GPT-5는 부록 관련 약점이 30% 미만이었지만, 새 모델 GPT-6.1-Sol과 GPT-6-Astra는 모든 대회에서 대략 60~70%에 달해, 이 편향이 최신 모델의 특성임을 시사한다.
- 접근 방식에도 강건: ICLR 2027 제출본 100편에 GPT-6-Astra로 API 직접 PDF 입력, 추출 텍스트 API 입력, Codex 코딩 에이전트, 웹 인터페이스 네 방식을 모두 돌려도 부록 관련 약점 비율은 50%를 넘었다.
- 인간과의 대조: ICLR 2021~2024 인간 리뷰는 약점의 8.40%(±1.44)를 부록으로, 4.36%(±1.03)를 부록만으로 귀속한다. LLM의 ICLR 2027 리뷰는 각각 62.00%(±7.70)와 14.19%(±3.32)다. 표본 800건의 인간 리뷰 가운데 부록 비판이 하나라도 있던 것은 159건뿐이지만, LLM 리뷰 200건 전부가 부록 비판을 담았다.
- 인간 리뷰의 추이: 부록 관련 약점 비율은 2020~2024 심사 연도에 10.47, 8.37, 8.39, 6.37, 6.06%를 유지하다가, GPT-5 출시 뒤 첫 심사 주기인 2025년에 11.27%로 올랐고(ICLR 2026 리뷰의 5분의 1가량이 완전 AI 생성으로 분류된 주기다), 2026년에는 27.60%로 급등했다.
- 읽는 위치의 차이: 인간은 논문 첫 5페이지에 비판을 집중하고 부록 안에서 비중이 급감한다. LLM은 6~7페이지에서 비중이 올라가고, 부록 중반부에서 정점을 찍으며 30페이지를 넘어서도 약점을 제기한다.
- 무엇을 비난하는가(8개 범주 분류): LLM의 부록 비판은 방법론 54.0%, 분석 25.2%, 결과 13.6%인 반면 표현은 2.1%에 불과하다. 인간은 방법론 35.7%와 표현 32.2%로 나뉜다. LLM은 기술 세부를 감사하고, 인간은 논문이 쓰인 방식까지 평가한다.

## 상세

파이프라인은 두 단계로 이뤄진다. 먼저 익명화한 논문을 넘기며 '이 논문을 [대회명] 심사용으로 [대회명] 스타일로 리뷰해 달라'는 의도적으로 짧은 프롬프트만 사용했다. 실제 리뷰어가 모델을 활용하는 방식을 재현하고 특수한 프롬프트 표현이 리뷰에 끼치는 영향을 없애기 위해서다. 네 대회가 비슷한 리뷰 형식을 공유하기 때문에 대회명만으로도 요약·강점·약점·점수가 담긴 구조화된 리뷰가 나온다. 그다음 같은 모델에게 논문과 리뷰를 다시 주고 각 약점의 근거가 나오는 섹션을 최대 둘까지, 범용적인 문장이면 'not specified'로 답하게 해 약점 귀속(weakness attribution)을 수행한다. 근거가 부록에서 조금이라도 나오면 부록 관련 약점으로 센다. ACL, EMNLP, COLM의 채택 논문은 저자명·소속·링크를 지워 익명화했고, 웹 검색과 브라우징 도구는 꺼서 모델이 PDF에만 의존하게 만들었다.

접근 방식 비교는 하네스가 결과를 좌우하지 않음을 보여 준다. Codex는 PDF를 직접 받지 않고 pdftotext 같은 셸 명령으로 파일을 읽으며, 도구 호출당 최대 약 10k 토큰만 돌려받는다. 출력이 길면 앞뒤만 남기고 가운데를 버리므로, 모델이 후속 명령으로 나머지를 찾아 읽어야 한다. 웹 인터페이스는 사용자가 조정할 수 없는 시스템 프롬프트, 메모리, 안전 레이어를 얹는다. 그럼에도 네 방식 모두 50%를 넘는 부록 의존을 보였고, 저자들은 이를 인터페이스의 문제가 아니라 기반 모델의 성질로 해석한다.

한계도 분명하다. 약점 귀속과 8개 범주 분류는 GPT-6.1-Sol이 수행하고 표본 검증만 수작업으로 이뤄졌다. 인간 리뷰와 LLM 리뷰는 서로 다른 연도의 다른 논문에서 왔는데, 오래된 논문과 리뷰는 모델 학습 데이터에 들어 있을 가능성이 높아 이런 설계를 택했다. 인간 리뷰에서 부록 비판이 늘어난 것은 시간적 상관일 뿐 인과의 증거가 아니며, 이 연구는 비판이 어디에서 왔는지만 살피지 각 약점이 옳은지는 판단하지 않는다. 수치 점수도 분석 대상이 아니다. 코드는 github.com/cincynlp/review_appendix에 공개돼 있다.
