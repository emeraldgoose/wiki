# Signed but Steerable: 오프라인 RAG에서 텍스트-벡터 무결성 간극 측정과 보완

**원문**: [arXiv:2611.06498](https://arxiv.org/abs/2611.06498) · **게시일**: 2026-11-04
**저자**: Georgios Feretzakis, Alexandros Papaspyridis

## 개요

edge device의 오프라인 retrieval-augmented generation은 text와 precomputed embedding vectors를 함께 실은 signed knowledge packs로 업데이트된다. signature는 publisher identity를 증명하지만 vectors가 text를 encode한다는 보장은 하지 않는다. 본 논문은 이 text-vector integrity gap을 연구한다.

vector를 재계산해 cosine tolerance 안에 있는 값만 accept하는 verifier는 vector를 control하는 attacker에게 predictable share의 query를 내줄 수 있다. hijack rate는 tolerance에서 angular retrieval margin의 distribution, 즉 margin law와 같아진다. 다섯 corpus와 두 embedding model에서 margin이 작아 threshold가 엄격해도 일부 query가 노출된다. Raspberry Pi 5에서 local language model을 사용할 때 such an attack은 correct answers를 0.75에서 0.39로 낮춘다. compressed vector audit도 좋지 않아 tampered vectors가 audit을 pass하고 target의 약 25%에서 attacker document를 first로 놓는다.

논문은 verifier가 ambiguity를 결정하고 calibrated guard band와 canonicalization을 더하는 quantization code 검증을 제안한다. 이 방법은 honest vector를 accept하고 adversarial freedom을 제거한다. floating-point와 dynamic INT8 inference pipeline이 bit-reproducible하지 않은 점도 문서화하며 abstention, context pruning, semantic screening에 대한 negative results를 보고한다.

## 핵심 내용

- signed offline RAG pack의 text-vector integrity gap을 정의한다.
- hijack rate가 angular retrieval margin distribution과 같음을 보인다.
- 작은 margin이 non-negligible query fraction을 노출시킴을 발견한다.
- edge hardware에서 answer quality가 크게 저하됨을 보인다.
- compressed vector audit이 tampered vectors에 bypass가 가능함을 보인다.
- guard band와 canonicalization을 포함한 code verification으로 gap을 보완한다.

## 상세

20頁 paper에는 2 figures와 7 tables가 포함되며 code와 data를 공개한다. five corpora, two embedding models, 57,638 documents의 FAISS product-quantization index를 다룬다.
