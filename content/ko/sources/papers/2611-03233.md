# Axion 1.0: 단순화된 오픈 에이전트 파운데이션 모델

**원문**: [arXiv:2611.03233](https://arxiv.org/abs/2611.03233) · **게시일**: 2026-11-02
**저자**: Yuqi Jia, Yunjie Tian, Jiayu Zheng, Yijun Liang, Jingchen Sun, Mengyu Zhao, Di Fu

## 개요

Axion 1.0은 강력하고 폭넓은 에이전트 역량을 놀랍도록 단순한 학습 레시피와 결합한 완전 오픈 에이전트 파운데이션 모델이다. 모델은 세 단계만으로 학습된다. 두 차례 경량 지도 파인튜닝 이후 강화 학습을 수행하며, 전용 중간 학습, 직접 선호 최적화, 온정책 증류는 사용하지 않는다. 첫 단계는 도전 문제를 합성하고 기반 모델 자신의 성공적 해결 전략을 이용해 문제를 적대적으로 강화하는 모델 인식 데이터 구성을 통해 자기완결적 추론을 키운다. 두 번째 단계는 실세계 출처와 결정적 계산에 근거한 자동 검증 작업을 통해 도구 의존 추론으로 확장한다. 강화 학습은 장기 추론과 외부 도구 상호작용을 더 강화한다.

## 핵심 내용

- 학습 레시피는 단 세 단계만으로 구성된다.
- 전용 중간 학습, 선호 최적화, 온정책 증류를 생략한다.
- 첫 단계는 모델 인식 데이터 구성을 사용한다.
- 두 번째 단계는 실세계 데이터와 결정적 계산에 근거한 검증 작업을 사용한다.
- 강화 학습은 장기 추론과 도구 상호작용 능력을 강화한다.
- 레시피, 데이터, 프롬프트, 학습 코드 전체가 공개된다.

## 상세

간결한 레시피에도 Axion 1.0은 폭넓은 에이전트 벤치마크에서 강한 성능을 보이고 여러 선도 상용 모델과 경쟁적이다. 가중치를 넘어 데이터 구축, 합성, 필터링, 검증, 프롬프트, 학습 코드까지 공개되어 재현과 확장이 가능하다. 보고된 성능은 선택된 벤치마크와 기반 모델에 묶인다.
