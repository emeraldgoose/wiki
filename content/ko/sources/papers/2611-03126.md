# CUA-Master: 개방형 월드 재귀 개선을 통한 컴퓨터 사용 에이전트 확장

**원문**: [arXiv:2611.03126](https://arxiv.org/abs/2611.03126) · **게시일**: 2026-11-02
**저자**: Xinlei Yu, Gen Li, Ji Zhao, Zhangquan Chen, Congcong Wang, Shuai Dong, Zelin Peng, Yuqi Xu, Hongrui Wu, Kaiwen Tuo, Cheng Yang, Kaituo Feng, Yifan Wu, Jiayi Zhang, Dongming Wu, Wenqi Shao, Jiaqi Wang, Xiangyu Yue

## 개요

컴퓨터 사용 에이전트의 최근 진전에도 불구하고 개발은 상호작용 데이터의 제한된 다양성, 제어성, 신뢰성에 의해 제약된다. 기존 최적화 파이프라인도 반복 피드백이 부족하고, 재귀 개선은 자체 생성 경험에 의존하여 능력 확장이 제한되고 수익 체감을 일으킨다. CUA-Master는 이중 루프 재귀 개선 프레임워크를 제안한다. 시스템 수준에서는 외부 world-data-model flywheel이 개방형 corpus를 통합하고 evolving agent capability를 활용해 약한 능력을 드러낸다. 상호작용 수준에서는 내부 data-model feedback loop가 학습 데이터를 기록, 큐레이션, 정제한다.

## 핵심 내용

- CUA 개발은 상호작용 데이터 다양성에 제한된다.
- 기존 파이프라인은 반복 피드백이 부족하다.
- 자체 생성 개선은 수익 체감을 일으킨다.
- CUA-Master는 이중 루프 프레임워크를 사용한다.
- 외부 flywheel은 개방형 데이터를 통합한다.
- 내부 루프는 궤적을 큐레이션하고 정제한다.

## 상세

두 루프는 시스템 확장과 궤적 정제를 분리한다. 외부 world-data-model 루프는 개방형 corpus를 끌어와 약한 능력에 집중함으로써 학습 신호를 확장한다. 내부 data-model 루프는 피드백을 사용해 데이터를 큐레이션하며 자체 생성 경험을 맹목적으로 재사용하지 않는다. 두 루프는 더 높은 품질의 상호작용 데이터와 지속적인 능력 평가를 통해 컴퓨터 사용 에이전트를 확장하는 것을 목표로 한다.
