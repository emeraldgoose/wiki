# UUBench: 전체 이중향 상호작용을 위한 언스포큰 이해 벤치마크

**원문**: [arXiv:2611.30157](https://arxiv.org/abs/2611.30157) · **게시일**: 2026-11-23 (v1)
**저자**: Ye Pan, Chenfei Liao, Bin Ren, Hanqian Li, Haocong He, Jialei Chen, Jinlin He, Kunyu Peng, Mengyu Jin, Shijie Li, Wenqian Cui, Yuanqi Yao, Yuqian Fu, Kailong Ruan, Yuan Gao, Wei Wang, Xuming Hu, Irwin King, Nicu Sebe, Xu Zheng

## 개요

일상 대화에서 사용자는 억양, 표정, 시선, 제스처를 통해 명시되지 않은 의사소통 필요를 전달하며, 단순히 문자 그대로의 단어만을 사용하지 않는다. UUBench는 "암묵적(intent)" 의도를 정의하되, 이는 말의 내용에 완전히 명시되어 있지는 않지만 언어 단서, 관찰 가능한 비언어적 행동, 맥락으로부터 추론 가능한 의사소통 목표라고 정의한다. 그리고 디지털 휴먼 시스템이 그 이해를 실제로 해당 필요에 부응하는 응답으로 전환하는지 묻는다. 기존 벤치마크(MIntRec2.0, VAGUE, GesBench, AvaMERG, VidChatBench, LiveTalk)는 의도 인식이나 생성 품질을 각각 따로 다룰 뿐, 멀티모달 단서에 의한 암묵적 의도 충족 여부를 다루지는 않는다.

TalkVerse, TalkCuts, TalkVid, SpeakerVid-5M에서 나온 28,548개 사용자 클립 후보 중 평가자는 216개의 고품질 평가 클립을 선정했다. 주석자는 각 화자의 의도와 청각/시각 원시 피처, 그리고 해석을 뒷받침하는 말과 행동을 표시했다. 암묵적 의도 추론은 본질적으로 주관적이므로, 단일 종합 평점은 응답이 필요의 어떤 측면을 다루었는지 감출 수 있다. 이에 UUBench는 사실 기반 채점 모듈 JEV에 기초를 둔 두 가지 보완적 채점 관점을 도입한다. 사용자와 응답의 구조화된 타임스탬프 오디오-비주얼 관찰(침묵 프레임, 6 FPS 샘플링)을 jev-1.14.0이 [-3, +3] 척도로 하나의 원시 피처 또는 기준씩 채점한다.

원시 중심 채점(Process-Oriented Scoring)은 각 해당 원시 피처(예: 얼굴 표정, 시선, 머리 움직임, 제스처)에 대해 응답이 해당 신호가 전달하는 필요를 얼마나 잘 충족하는지 평가한 뒤, 각 원시 피처의 주석된 증거에 대한 관련성에 기반한 가중치를 사용해 집계한다(s_ip = Σ w_ik x_ipk). 시스템 수준 의도 충족 점수 S_p는 모든 N = 216 입력에 대한 s의 평균이다. 결과 중심 채점(Outcome-Oriented Scoring)은 응답 자체를 측정한다: Q_ip는 아홉 개 모달리티-기준 쌍(모달리티: 오디오/비주얼/옴니 × 기준: 자연스러움/적절성/인간다움)의 평균이며, Q_p는 입력에 대한 Q의 평균이다.

## 핵심 내용

- 동일한 216개 입력에서 단일 공통 프롬프트로 9개 시스템을 평가했다: 클로즈드 소스 Emma, Tavus, Vidu, D-ID, bitHuman; 오픈 소스 CyberVerse (SoulX-LiveAct), OpenAvatarChat (LiteAvatar), Open-LLM-VTuber (Live2D), EmpaAva (GaussianAvatars + DEEPTalk).
- 핵심 발견: 9개 시스템 모두 전체 오디오-비주얼 품질 점수가 양수(Q = 1.01~2.03)인 반면, 모든 시스템이 4개 시각 원시 피처(얼굴 표정, 시선, 머리 움직임, 제스처)에서 모두 음수 점수를 받으며, 평균은 -0.35~-0.02이다 — 자연스러운 응답도 시각적으로 전달된 필요를 체계적으로 놓칠 수 있다.
- 두 관점은 시스템 순위를 다르게 매긴다: Emma가 Q가 가장 높음(2.03), Tavus가 증거 가중 의도 충족 점수 S가 가장 높음(0.47); 오픈 소스 시스템 중에서는 CyberVerse가 둘 다 선도(Q 1.64, S 0.18).
- 인간다움은 모달리티별로 나뉜다: Vidu가 오디오 인간다움 선도(2.13), Emma가 시각(1.94)과 오디오-비주얼(1.76) 선도; 오픈 소스 시스템은 모두 오디오 인간다움이 약 1.92로 수렴하지만 시각은 -1.24~-0.30이다. 아홉 개 시스템 전체에서 발화는 가시적 행동보다 더 인간다운 평가를 받으며, 모두 시각적 자연스러움에는 양수, 5개는 시각적 인간다움에는 음수이다.
- 최고의 응답 품질조차 약한 신호 응답과 공존할 수 있다: Emma의 사용자 얼굴 표정, 시선, 머리 움직임, 제스처 응답 평균은 각각 -0.08, -0.15, -0.13, -0.15로, 최고 수준의 시각적 인간다움에도 불구하고 낮다.
- 커버리지 규칙: Q는 아홉 개 유효 q 점수를 모두 요구하며, s는 정의된 가중치와 유효한 x 점수를 갖는 비어 있지 않은 해당 피처 집합을 요구하고, 시스템 총계는 시스템당 N = 216개의 유효한 응답을 요구하며, 누락된 총계는 커버리지와 함께 보고된다.

## 상세

응답 시간 관례는 시스템 유형에 따라 다르다: 클로즈드 소스 시스템의 경우 사용자 비디오 재생 종료부터 아바타가 말하기 시작할 때까지(API 지출도 보고된다); 오픈 소스 시스템의 경우 응답 생성에 아바타 렌더링/녹화를 더한다. 그림 6는 Q와 S를 평균 응답 시간에 대해 시간-점수 경계선과 함께 표시한다. 예시 실패 사례: Tavus는 "내가 죽었다"고 말하는 것이 농담인지 묻는 동안 사용자가 직장을 그만둔다는 distress를 놓치고, Vidu는 부모님 손님 앞에서 공연했다는 내용에 대해 장난스럽게 응답하면서 "나는 연기를 해야 했다"의 의무를 간과한다. 평가 파이프라인(그림 5)은 클립×시스템을 반복하고, 전체 프레임 사용자 관찰 U_i, 가중치 w_i를 가진 동결된 원시 피처 주석 A_i, 승인된 얼굴 크롭 응답 클립 선택, 응답 관찰 V_ip 및 보조 측정 M_ip 추출, 각 모달리티-기준 쌍과 각 해당 원시 피처에 대한 JevScore 채점으로 진행된다. 미리보기 버전(49페이지, 37개 그림, 9개 표).
