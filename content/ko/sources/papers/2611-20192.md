# GlyphAtlas: 장면 텍스트 합성을 위한 획 디테일과 레이아웃의 분리

**출처**: [arXiv:2611.20192](https://arxiv.org/abs/2611.20192)
**게시일**: 2026-11-15 (v1)

## 개요

장면 텍스트 합성(scene text synthesis)은 장면 이미지의 지정된 영역 안에 주어진 문자열을 렌더링하면서 주변 배경과 시각적으로 조화롭게 만들도록 생성 모델에 요구하는 과제입니다. 사진 편집, 포스터 디자인 등에 활용됩니다. 기존 방법들은 보통 목표 텍스트를 의도된 위치에 미리 렌더링한 "글리프 이미지"를 조건으로 사용하며, 이 이미지는 레이아웃과 글리프 구조를 함께 담고 있습니다. 이 표현은 공간적 기준으로는 잘 작동하지만, 각 글리프 참조의 해상도가 대상 영역의 크기에 종속되기 때문에 작고 밀집되어 있거나 구조가 복잡한 텍스트에서는 획을 표현할 픽셀이 부족해지고, 결과적으로 불완전하거나 뭉개지거나 왜곡된 글자가 생성됩니다.

Luozheng Qin, Changhai Zhou, Yiyi Zhou(Xiamen University, Fudan University)이 제안한 GlyphAtlas는 이 두 역할을 분리합니다. 글리프 이미지는 각 글리프가 어디에 속하고 대략 어떤 형태인지 알려주는 공간적 기준으로만 유지됩니다. 세밀한 획 디테일은 별도의 글리프 아틀라스가 제공하며, 아틀라스는 각 문자 또는 단어를 독립된 셀에, 대상 영역 크기와 무관한 해상도로 렌더링합니다. 셀은 별도의 텍스트 인코더가 아니라 백본에 내장된 VAE로 인코딩되므로, 획 수준의 변동에 둔감해지도록 학습된 인식용 인코더 없이도 저수준 획 구조가 보존됩니다.

아틀라스를 다시 레이아웃에 묶기 위해 저자들은 아틀라스 앵커드 어텐션(atlas-anchored attention)을 도입했습니다. 각 텍스트 영역은 자신에 대응하는 아틀라스 셀에서만 획 정보를 가져올 수 있으며, 글리프 이미지가 제공하는 거친 구조를 세밀하게 다듬는 coarse-to-fine 조건화가 이루어집니다. 이로써 명시적인 레이아웃 대응을 유지하면서도 모델이 풀어야 할 획 렌더링 문제를 단순화합니다.

## 핵심 내용

- 글리프 이미지는 공간적 기준과 획 참조라는 두 역할을 겸하고 있으며, GlyphAtlas는 이 둘을 분리하되 서로 협력하도록 설계했습니다.
- 전용 글리프 아틀라스가 문자/단어를 각각의 셀에, 대상 영역과 독립된 해상도로 렌더링하여 작은 글리프에도 상세한 획 참조를 제공합니다.
- 아틀라스 셀은 백본의 VAE로 인코딩되어 픽셀 수준 복원 목표 덕분에 저수준 획 구조가 보존되며, 별도의 OCR/텍스트 인코더가 필요 없습니다.
- 아틀라스 앵커드 어텐션은 각 텍스트 영역이 자신의 셀만 참조하도록 제한하여, 획 디테일을 레이아웃 위치에 묶습니다.
- 학습에는 마스크 가중 플로우 매칭 목적함수와 타임스텝 가중 텍스트 지각 손실(timestep-weighted text perceptual loss)이 함께 쓰여, 각각 필기 정확도와 배경 일관성을 목표로 합니다.
- 아틀라스 셀 해상도의 무작위 증강으로 추론 시 아틀라스 토큰 예산을 조절할 수 있습니다.
- 보고된 결과에 따르면 작고 밀집되며 구조가 복잡한 텍스트의 획 정확 합성, 과제 특화 학습에서 보지 못한 문자 체계로의 제로샷 전이, 텍스트 영역이 많은 장면에서의 선도적 성능을 달성했습니다.

## 상세

**방법.** GlyphAtlas는 FLUX.1 Fill을 기반으로 합니다. 이는 MM-DiT 계열의 플로우 매칭 트랜스포머로, 프롬프트 토큰과 이미지 토큰을 하나의 시퀀스로 처리하며 모든 블록에서 조인트 어텐션을 수행합니다. 장면 스트림은 노이즈 잠재 변수, 마스크된 장면 이미지의 인코딩, 그리고 space-to-depth로 재배열된 텍스트 마스크를 채널 방향으로 이어 붙이고, 두 번째 스트림은 글리프 이미지를 인코딩합니다. 아틀라스는 추가 토큰으로 덧붙여집니다. 아틀라스 앵커드 어텐션은 어텐션을 마스킹하여 각 텍스트 영역이 아틀라스 전체가 아니라 자신에 대응하는 셀만 보도록 합니다. 학습은 텍스트 마스크로 가중한 조건부 플로우 매칭 손실(쓰여야 할 영역을 강조)과, 적절한 노이즈 수준에서 필기 정확도를 강조하고 그 외 영역의 배경 일관성을 지키는 타임스텝 가중 텍스트 지각 손실을 함께 최적화합니다. 학습 중 아틀라스 셀 해상도를 무작위로 증강하기 때문에, 추론 시 아틀라스 토큰 수를 상황에 맞게 늘리거나 줄일 수 있습니다.

**결과.** 논문에 따르면 GlyphAtlas는 네 개의 장면 텍스트 벤치마크에서 기존 방법들을 텍스트 정확도 측면에서 앞서며, 과제 특화 학습에서 보지 못한 문자 체계로 제로샷 전이를 보여(저자원 언어에 대한 잠재력) 주고, 텍스트 영역이 많은 장면에서 선도적인 성능을 냅니다. 저자들은 한계도 명시합니다. 아틀라스 셀이 균일 폰트로 렌더링되므로 획은 지정하지만 타이포그래피는 지정하지 못해 폰트 굵기·색상 오류가 가끔 발생하고, 조절 가능한 예산에도 불구하고 추가된 아틀라스 토큰은 추론 비용을 늘립니다. 정확한 벤치마크 수치는 논문 본문과 보충 자료에 수록되어 있으므로, 구체적인 수치는 원문을 참고하시기 바랍니다. 프로젝트 페이지: https://fr0zencrane.github.io/project-glyphatlas/
