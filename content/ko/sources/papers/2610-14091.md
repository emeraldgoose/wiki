# Pristine Models: 안전한 개념과 위험한 개념을 분리하는 이미지 생성 모델

**원문**: [arXiv:2610.14091](https://arxiv.org/abs/2610.14091) · **게시일**: 2026-10-08
**저자**: Anirudh Sundara Rajan, Krishna Kumar Singh, Richard Zhang, Yong Jae Lee

## 개요

넓고 필터링되지 않은 데이터로 학습하면 고품질 이미지를 생성할 수 있지만, 생성해서는 안 되는 개념까지 배울 수 있습니다. 반대로 안전을 위해 학습 데이터를 제한하면, 위험한 개념을 담은 예시가 제공하던 유용한 지식까지 잃어 품질이 떨어집니다.

기존 접근은 사후 개념 삭제(unlearning)로 이 균형을 맞추려 했지만, 제거할 개념이 늘수록 치명적 망각이 생길 수 있습니다. Pristine Models는 사전학습 단계에서 안전·위험 지식을 분리해 두고, 추론 시 위험 브랜치를 분리하는 구조를 제안합니다.

## 핵심 내용

- 안전한 지식과 위험한 지식을 독립 파라미터 브랜치로 분리하는 어텐션 구조를 사용합니다.
- 브랜치별 파라미터는 학습 중에 익히고, 추론 시 위험 브랜치를 분리할 수 있습니다.
- ImageNet에서 안전한 생성과 전체 데이터 학습의 유용성을 함께 유지합니다.
- 안전 데이터만 학습하거나 사후 개념 제거를 적용한 경우보다 이미지 품질과 텍스트 정렬이 좋습니다.
