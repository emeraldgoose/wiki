# Read Less, Solve More: AI 에이전트를 위한 토큰 효율적인 희소 읽기

**원문**: [arXiv:2608.22237](https://arxiv.org/abs/2608.22237) · **게시일**: 2026-08-23

## 개요

웹 기반 에이전트는 웹페이지, 문서, 저장소, 도구 응답을 반복해서 읽지만, 읽기 인터페이스는 각 결정에 필요한 게 몇 개 문단뿐이어도 객체 통째로 노출하는 경우가 많다. 이 과잉 읽기는 비용 문제를 넘어 해롭다. 기존 연구에 따르면 외부 관측이 에이전트 궤적에서 처리되는 토큰의 60~80%를 차지하고, 짝지은 실행 실험에서 수정하지 않은 에이전트는 품질 이득 없이 최대 17.3배 더 많은 토큰을 쓴다. 넘치는 내용은 관련 증거를 희석해 잘못된 도구 사용, 출처 혼동, 멈추지 못하는 실패를 부르고, 일찍 받아들인 내용은 이후 모델 호출 여러 번에 걸쳐 재생된다. 논문은 이를 재생 가중 노출로 잰다. 새로 노출된 조각을 그것을 유지하는 이후 호출 수만큼 가중하는 방식이다. 주석 연구는 실제 표적이 얼마나 희소한지 확인해 준다. LooGLE 장문 질의응답에서 정답 근거는 소스 토큰의 중앙값 3.17%에 불과하고, 주석 달린 Qasper 문항에서도 약 5.8%다.

기존 해법은 각각 문제의 일부만 다룬다. 롱컨텍스트 아키텍처와 KV 캐시 압축은 문맥 유지 비용을 줄이지만 모델이 어떤 소스 내용을 봐야 하는지는 결정하지 않는다. 반복·에이전틱 변형을 포함한 검색은 문단을 필요할 때 가져올 수 있지만, 진화하는 읽기 의도와 명시적 커버리지, 제한된 노출, 전체 보기 폴백을 아우르는 아티팩트 수준 계약을 제공하지 않는다. 일반 메커니즘을 막는 과제는 둘이다. 정보 필요량이 서브골을 진행하며 바뀌므로 부분 읽기마다 목적과 미커버 범위를 기록해야 하고, 희소 접근이 항상 경제적이지도 않다. 작은 객체나 전체 보기 요구에서는 반복 부분 읽기가 직접 접근보다 비쌀 수 있는데, 그 경계는 읽기 전에는 알 수 없다.

SparseRead는 넓은 내용이 모델 문맥에 들어가기 전에 콘텐츠 입장을 통제하는 재사용 가능한 읽기 제어 계층이다. 에이전트 모델을 수정하지 않고 별도의 생성형 압축 모델도 쓰지 않는다. Read Intent 프로토콜은 넓은 아티팩트 접근을 유한하고 상태를 가진 과정으로 바꾼다. 에이전트가 접근별 필요를 밝히면 계층이 출처 기반의 증거와 명시적 커버리지를 담은 EvidencePack을 돌려주고, 충분성과 중단 판단은 에이전트에 남는다. 적응형 리더 백엔드는 통합 Reader 인터페이스로 읽기 제어와 증거 획득을 분리하고, 보정된 증거 신뢰도와 예상 읽기 비용으로 아티팩트별 위치 찾기·처리 방법과 노출 형태를 고른다. 예산화된 읽기 게이트는 추론 시점 제어기로 에피소드별 누적 원본 노출을 제한하고, 전달 전에 예산을 점검하며, 충실한 전체 보기 폴백을 유지한다. 희소 읽기가 맞지 않는 과제에서는 희소 경로를 건너뛴다.

여섯 모델(Claude Opus 5 포함) 곱하기 다섯 시나리오의 30개 설정에서 SparseRead는 총 토큰을 15.7~92.9%(중앙값 61.4%), 벽시간을 23.0~89.0%(중앙값 53.7%) 줄이면서 30개 설정 중 29개에서 품질을 유지하거나 끌어올린다. 유일한 하락은 AI for Science의 GLM-5.1이다. 웹 심층 탐색 과제에서는 여섯 모델 모두 5~14%포인트를 얻으면서 토큰을 31.0~43.0% 아낀다. 여섯 방법 비교와 세 에이전트 프레임워크(NanoBot, OpenCode, OpenClaw) 통합이 일반성과 이식성을 뒷받침한다.

## 핵심 내용

- 세 설계가 일한다. Read Intent 프로토콜은 접근별 필요와 소스 커버리지를 명시화하고, 적응형 리더 백엔드는 아티팩트 유형별로 증거 위치 찾기와 노출 방식을 고르며, 예산화된 읽기 게이트는 에피소드별 누적 노출을 제한하면서 충실한 전체 보기 폴백을 유지한다.
- 쓸모 있는 증거는 실제로 희소하다. LooGLE 문항의 중앙값 3.17%, Qasper 주석 문항의 약 5.8%라서 객체 단위 읽기는 대부분 과잉 읽기다.
- 과잉 읽기는 누적된다. 재생 가중 노출 지표는 노출된 조각을 이를 유지하는 이후 호출마다 세며, 높은 희소도 조건의 짝지은 실행에서 전체 읽기 에이전트는 점수 이득 없이 최대 17.3배 토큰을 쓴다.
- 대표 결과: 30개 설정에서 토큰 15.7~92.9%(중앙값 61.4%), 벽시간 23.0~89.0%(중앙값 53.7%) 감소, 품질 유지·향상 29건. 롱컨텍스트 과제는 토큰 76.5~92.9%, 시간 67.1~89.0%를 아낀다.
- 웹 심층 탐색은 품질도 오르는 사례다. 여섯 모델 모두 5~14%포인트 상승과 함께 토큰 31.0~43.0%, 시간 23.0~37.0%를 줄인다. AI for Science에서는 토큰 절감이 82.7~89.1%에 이른다.
- 15개 설정의 기준선 비교에서 SparseRead는 모든 설정에서 점수를 유지·향상시키고, 토큰 최소가 6개 설정, 시간 최소가 9개 설정이며, 다중 파일 진단에서는 다섯 모델 모두 두 최솟값을 동시에 달성한다(점수 +17.8~34.5%포인트).
- 기준선의 실패도 유익하다. RAG Static은 웹 다섯 설정 모두에서 빠르지만 15개 중 9개에서 Naive보다 점수가 낮고, RAG Agent는 같은 반복·시간 초과 조건에서 여덟 설정에서 점수를 잃는다. ACON은 다섯 설정에서 점수가 떨어지고 여섯 설정에서 두 비용이 모두 늘며, 관측 마스킹은 다섯 설정에서 점수를 잃는다.
- 이식성: NanoBot, OpenCode, OpenClaw의 18개 설정 모두에서 토큰과 시간이 줄고, 15개에서 품질이 유지·향상되며, 토큰 절감 중앙값은 65.0%, 65.2%, 30.6%다.
- 절제 실험이 각 부분을 검증한다. 세션·접근 의도를 결합하면 과업당 반복 읽기가 4.8에서 1.5로(68.8% 감소) 줄고 추적 불가 증거가 28%에서 8%로 줄며, 증거 부족으로 실패하는 답이 25%에서 5%로 줄고 유효 검증이 37%에서 89%로 오른다. 하이브리드 위치 찾기는 같은 노출에서 BM25보다 5.2%포인트 높고, 전달 전 예산 점검은 누적 원본 노출을 전체 보기의 1.62~1.93배 안에 유지한다(전달 후 점검은 2.10~2.33배까지 초과).

## 세부 사항

- 버전 노트: v1은 2026-08-23, 현재 개정판 v2는 2026-11-07이다. 이 요약은 v2를 따른다.
- 설계의 기반이 되는 세 가지 양이 있다. 처리 범위(Reader가 계산하는 대상), 모델 노출(문맥에 들어가는 것), 증거 커버리지(어느 의도 슬롯에 근거가 있는지)다. 노출을 줄여도 처리 범위를 줄일 필요는 없어서 Reader가 표 전체를 훑으면서 결과만 노출할 수 있고, 정확한 전체 객체 연산도 그대로 가능하다.
- 리더 위치 찾기 보정: LooGLE 문서 47개와 문항 741개에서 80% 이상 주석 증거 커버리지를 적중으로 정의하면, 어휘 매칭은 780자에서 39.5%, BM25는 1,497자에서 60.1%, 하이브리드는 1,490자에서 65.3%다. BM25 창을 넓히면 노출이 2,106자로 늘고 적중률은 56.7%로 떨어진다.
- 게이트 경제학: DeepSeek-V4-Flash에서 코호트마다 다섯 과제 세 번 반복으로 비교하면, 전달 전 예산 점검은 여섯 누적 원본 노출 비율을 모두 전체 보기의 1.62~1.93배 안에 두고 15회 중 5회에서 업그레이드가 일어난다. 전달 후 점검에서는 세 업그레이드가 2.10~2.33배까지 초과한다.
- 게이트는 반대 영역도 처리한다. 희소 읽기가 맞지 않는 과제에서는 희소 경로를 건너뛰고 네이티브 도구 사용을 유지해 프로토콜 오버헤드를 피하며, 부록 C에서 희소 읽기를 강제했을 때의 비용을 정량 비교한다.
- 모델 커버리지는 Claude Opus 5, GLM-5.1, DeepSeek-V4-Flash 등 여섯 모델이다. Opus 5는 다섯 시나리오 전체에서 토큰 41.0~89.0%, 시간 35.0~78.1%를 아끼고, 세 프레임워크에서도 토큰 32.5~58.6%를 아낀다.
- 통합은 프로토콜·리더·게이트를 얇은 어댑터로 재사용하며 모델 재학습이 없다. 세 프레임워크 통합에서 점수 하락은 0.013~0.031의 세 건뿐이고, 토큰 절감 중앙값은 65.0%, 65.2%, 30.6%다.
