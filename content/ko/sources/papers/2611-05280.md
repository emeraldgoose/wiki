# YANAMI: Multiturn Stateful Interaction을 위한 대규모 Multimodal Dataset/Benchmark

**원문**: [arXiv:2611.05280](https://arxiv.org/abs/2611.05280) · **게시일**: 2026-11-03
**저자**: Shengyu Wang, Tengyue Nong, Junming Liu, Haosong Peng, Siyu Li, Ruiqi Lei, Fushuo Huo, Yuhao Pan, Yunfeng Fan, Ding Wang, Nan Cheng, Haozhao Wang, Wenchao Xu

## 개요

Unified multimodal models는 visual understanding, generation, editing을 하나의 framework에서 통합하지만 기존 dataset/benchmark는 single-turn tasks가 지배적이다. 최근 multi-turn datasets에서도 many turns가 independently solve 할 수 있어 turn-to-turn information tracking이 필요하지 않다. YANAMI는 stateful interaction을 위한 first large-scale multimodal dialogue dataset and benchmark다. 이는 400K multi-turn multimodal dialogues (2M+ images, 2.6M turns), 400 multi-turn benchmark dialogues로 구성되며 multi-image fusion, image editing, world modeling, visual reasoning 시나리오를 다룬다. models가 evolving dialogue states를 track, preserve, revise하도록 요구한다.

## 핵심 내용

- dataset은 400K multi-turn multimodal dialogues를 제공한다.
- 2M 이상 images와 2.6M turns을 포함한다.
- 네 시나리오는 fusion, editing, world modeling, visual reasoning을 포괄한다.
- 기존 single-turn benchmarks는 stateful supervision이 제한적이다.
- benchmark는 400 dialogues로 systematic evaluate를 지원한다.
- state understanding과 visual realization gap을 평가한다.

## 상세

YANAMI-400K로 BAGEL을 fine-tuning 하면 image editing 10.3%, generation 2.0%, multimodal stateful interaction 13.23% 개선되며 general visual understanding은 보존되었다. benchmark는 evolving dialogue states 이해와 visual output faithful realization 사이 gap을 characterize 한다. evaluations show existing UMMs still struggle to maintain, update, visually realize evolving multimodal dialogue states. gap metric은 state comprehension failures와 generation failures를 구분한다.
