# HiVe-Mem: 멀티모달 에이전트를 위한 수평 메모리 확장과 수직 증거 구성

**원문**: [arXiv:2611.12872](https://arxiv.org/abs/2611.12872) · **게시일**: 2026-11-09
**저자**: Haozhen Zhang, Bohan Liu, Jianzhu Bao, Qingyuan Liu, Haodong Yue, Xiao Li, Zi Pong Lim, Wenya Wang

## 개요

장기간 상호작용을 이어가는 멀티모달 에이전트에게는 과거 대화와 관찰을 저장하고 꺼내 쓰는 메모리가 필수적이다. 기존 메모리 시스템은 상호작용 기록을 요약 같은 고정 표현으로 압축한 뒤 의미 유사도로 검색하는데, 개체와 관계 중심 구조는 에피소드 사이의 맥락적 연관을 놓치기 쉽고 고정된 표현은 질의마다 다른 증거 수요를 충족하지 못한다.

HiVe-Mem은 이 두 한계를 서로 다른 축에서 해결한다. 수평 확장은 메모리 에피소드를 텍스트와 시각 앵커의 IDF 가중 겹침으로 잇는 무방향 친화 그래프로 구성해, 의미 검색으로 찾은 씨앗 메모리 주변 이웃을 질의 관련도 순으로 추가 회수한다. 수직 구성은 회수된 메모리마다 원본 대화 텍스트, 요약, 이미지 캡션, 원본 이미지, 그라운딩 시각 뷰 다섯 가지 증거 형태를 유지하고, 경량 학습 선택기가 질의와 요약 임베딩을 한 번의 순전파로 보고 각 메모리에 노출할 증거를 고른다.

세 개 멀티모달 메모리 벤치마크에서 HiVe-Mem은 백본 모델 전반에서 성능을 끌어올리면서 가장 효율적인 멀티모달 경쟁 기준 대비 약 90%의 토큰을 절약했다.

## 핵심 내용

- Mem-Gallery, WorldMemArena, H2HMem 세 벤치마크에서 Qwen3-VL-4B-Instruct 기준 평균 F1/LJ가 32.32/57.96, GPT-5-mini 기준 35.94/64.69로 최고 기록을 세웠다.
- GPT-5-mini 실험에서는 Qwen 모델에서 학습한 선택기를 재학습 없이 그대로 옮겨 썼는데도 세 벤치마크 모두에서 최고 F1과 LJ를 기록했다.
- 평균 토큰 소비는 두 백본에서 각각 0.658M, 0.748M로, 가장 효율적인 경쟁 멀티모달 기준의 7.812M, 7.350M 대비 91.6%, 89.8% 감소했다.
- 수평 확장을 제거하면 LJ가 57.96에서 56.51로 떨어지고, 시각 앵커 제거 시 57.30, IDF 가중 제거 시 56.55를 기록했다.
- 요약만 남기는 수직 구성 제거가 가장 큰 폭으로 LJ를 44.47까지 떨어뜨렸고, 원본 텍스트와 원본 이미지 제거도 각각 49.68, 51.02로 하락했다.
- Mem-Gallery에서 첫 토큰 생성 시간은 1.03초로, 응답 전에 메모리 연산을 수행하는 다른 멀티모달 시스템보다 실질적으로 낮았다.
- 그래프 차수 K_edge는 4가 최선이었고, 총 7개 회수에서 의미 씨앗 대 확장 비율 5:2가 최고 성능을 냈다.
- 시각 중심 질의조차 회수된 메모리의 35.2%에서만 원본 이미지를 선택해, 압축 증거로 충분한 경우 원본을 아끼는 정책을 확인했다.
- 질의 유형별로 선택 양상이 갈려 텍스트 중심 질의는 시각 증거를 거의 쓰지 않는 반면, 요약은 세 유형 모두에서 자주 선택되고 원본 기록은 안정적인 텍스트 기반이 된다.

## 세부 사항

### 수평 확장

친화 그래프는 텍스트와 시각 앵커의 겹침, 그리고 한 에피소드에서는 텍스트로 다른 에피소드에서는 이미지로 나타나는 교차 양상 단서까지 연결하며, 자주 등장하는 흔한 단서는 깎아내고 특이적인 단서는 키운다. 후보 이웃은 질의와 공유 앵커 사이 코사인 유사도에 IDF를 곱한 점수로 순위가 매겨지므로, 씨앗과도 연관되고 질의와도 관련된 이웃이 우선 회수된다.

### 수직 구성과 예산 제어

선택기는 질의와 각 메모리 요약의 임베딩을 이어 붙여 입력으로 삼고 한 번의 순전파로 증거별 선택 확률을 함께 예측한다. 예산 매개변수 λ를 키우면 원본 기록 선택이 크게 줄며 구성이 압축되는 한편, 원본 이미지는 선택 빈도는 낮지만 선택될 때 소비 토큰에서 차지하는 비중이 커서 선택 빈도와 선택 비용을 함께 최적화해야 함을 보여준다.

### 에피소드 구성과 그라운딩 뷰

메모리 에피소드는 대략 일정한 토큰 길이 구간을 기준으로 만들되 대화나 세션 중간에서 억지로 끊지 않고 가장 가까운 자연스러운 경계로 구간을 늘린다. 각 원본 에피소드는 시각 언어 모델로 한 번만 처리되어 요약과 텍스트·시각 앵커를 동시에 얻는다. 그라운딩 시각 뷰는 원본 이미지와 관련 맥락을 시각 언어 모델에 주어 대상 물체의 공간 좌표를 예측한 뒤 해당 영역을 잘라내는 방식으로 만들어지며, 배경의 무관한 내용을 걷어내 벤치마크에 따라 원본 이미지 대비 약 20~40%의 토큰을 줄인다.

### 소거 실험의 시사점

요약 전용 메모리는 전체 시스템보다 13 LJ 포인트 이상 낮아 압축 요약만으로는 다양한 멀티모달 질의를 답할 수 없음을 보인다. 다섯 증거 형태 모두 기여하며, 캡션이나 그라운딩 뷰를 빼도 성능이 내려간다. 또한 백본이 바뀌어도 학습된 선택기가 일반화되어, 증거 선택 정책이 특정 모델에 갇힌 습성이 아니라 전이 가능한 기술임을 시사한다. 한계로는 증거 공간이 대표 형태 다섯 가지에 머문 점, 선택기가 효율을 위한 경량 다층 퍼셉트론이라는 점, 평가가 두 개 대표 백본에 한정된 점이 꼽히며, 후속 연구로 구조화된 시각 서술 같은 파생 증거와 다양한 모델 규모로의 확장이 제안된다. 저자들은 에이전트가 단발성 질의응답에서 지속적 상호작용 체계로 발전할수록 저장된 정보를 무차별적으로 처리하는 대신 무엇을 회수하고 어떻게 노출할지 적응하는 능력이 핵심 역량이 될 것이라 전망한다.
