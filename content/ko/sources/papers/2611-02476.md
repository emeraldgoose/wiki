# GigaSpeech 3: 약한 라벨 데이터를 활용한 다방언 아랍어 음성 인식 확장

**원문**: [arXiv:2611.02476](https://arxiv.org/abs/2611.02476) · **게시일**: 2026-11-02
**저자**: Junzhe Liu, Yujie Tu, Yifan Yang, Peng Wang, Haoran Wang, Guodong Lin, Leyan Liao, Chengquan Zhang, Zhifu Gao, Xiangang Li, Qinyuan Cheng, Xipeng Qiu, Wei-Qiang Zhang, Guoguo Chen, Kai Yu, Xie Chen

## 개요

방언 아랍어 음성 인식은 웹 오디오가 충분함에도 불구하고 방언 구분 전사 데이터 부족으로 제한된다. GigaSpeech 3는 알제리, 이집트, 이라크, 사우디, 시리아 아랍어를 다루는 39,000시간과 1,000만 개 약한 전사 세그먼트 코퍼스를 제안한다. 방언당 60시간 수동 전사로 시작해, 음성 인식 편향 자기 지도 학습으로 라벨링 모델을 훈련하고 방언 일치 웹 오디오에 적용한다. 데이터 선택과 사우디·시리아 방언에 대한 네 차례 노이즈 학생 정제가 최종 코퍼스를 만든다. 검증은 방언별 및 다방언 인식 훈련, 교차 도메인 평가로 이루어진다.

## 핵심 내용

- 코퍼스는 다섯 아랍어 방언을 다루며, 현대 표준 아랍어만을 대상으로 하지 않는다.
- 총 39,000시간 오디오와 1,000만 개 약한 전사 세그먼트를 포함한다.
- 방언당 60시간 수동 전사라는 적은 시작 데이터에서 라벨링을 수행한다.
- 사우디와 시리아 방언에 노이즈 학생 정제를 적용한다.
- 최종 방언별 모델은 다섯 방언 모두에서 라벨링 모델을 앞소힌다.
- 다방언 모델은 자기 예측 방언 식별을 사용해 현대 표준 아랍어도 지원한다.

## 상세

저자 벤치마크에서 최종 방언별 모델은 거시 평균 단어 오류율 23.86%를 달성하며, 다섯 방언을 모두 다루는 가장 강력한 타사 시스템 대비 16.6% 상대 개선이다. 다방언 모델은 거시 평균 단어 오류율 25.51%이다. 외부 코퍼스 세 개의 여덟 조건에서 GigaSpeech 3로 훈련한 Zipformer는 평가된 여섯 모델 중 모든 조건에서 가장 낮은 단어 오류율을 달성하며, 코퍼스에 적응한 Qwen3 음성 인식기도 여덟 조건 모두를 개선했다. 코퍼스와 레시피는 추가 방언 인식 아랍어 음성 처리를 위해 공개된다.
