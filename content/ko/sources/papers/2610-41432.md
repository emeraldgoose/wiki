# 하이브리드 컴퓨터 사용: 범용 에이전트용 통합 프로그래밍/의미/시각 인터페이스

**원문**: [arXiv:2610.41432](https://arxiv.org/abs/2610.41432) · **게시일**: 2026-10-30
**저자**: Haoqing Wang, Xiaoyi Zhang, Sicheng Fan, Zhexin Zhang, Xinjie Zhang, Jiahao Li, Bin Li, Yan Lu

## 개요

컴퓨터 사용 에이전트는 일상 데스크톱 작업부터 장기 전문 워크플로까지 처리하지만, 스크린샷과 마우스/키보드 중심 인터페이스는 인간 상호작용 prior를 강요할 수 있다. 화면 해석을 반복해야 하고 컴퓨터의 의미·프로그래밍 역량을 충분히 드러내지 못한다. 논문은 이런 역량을 노출하고 모델이 선택·결합하도록 하자고 주장한다. 프로그래밍 (코드·CLI), 의미 (액세시빌리티/AX), 시각 (GUI) 세 채널을 결합한 범용 에이전트용 통합 인터페이스 Hybrid Computer Use(HCU)를 제안한다. HCU는 효율적인 AX 상호작용을 지원하고 채널 전환 중 stale-state 행동을 방지하며, 채널 선택·조정을 안내하는 보조 HCU 스킬을 제공한다. AX 도구는 간결한 관측, 배치 실행, AX diff 보고로 round-trip을 줄인다. OSWorld 2.0에서 HCU는 비교 시스템 중 Partial/Binary 최고 점수를 기록했다. 추적 분석 결과 모든 평가 모델이 HCU로 향상되었고, 채널별 작업 분담이 다르면서 효율성과 과업 성공 모두에서 baseline을 일관되게 능가했다. 이는 유연한 채널 선택과 결합을 허용하는 통합 컴퓨터 사용 인터페이스의 가치를 보여준다.

## 핵심 내용

- 스크린샷/마우스-키보드 인터페이스는 인간 상호작용 prior를 강요하고 의미·프로그래밍 역량을 충분히 드러내지 못한다.
- HCU는 프로그래밍(코드/CLI), 의미(액세시빌리티), 시각(GUI) 채널을 통합한다.
- AX 도구는 간결한 관측, 배치 실행, AX diff로 round-trip을 줄인다.
- 채널 전환 중 stale-state 방지와 채널 조정 보조 스킬을 제공한다.
- OSWorld 2.0에서 HCU가 최고 Partial/Binary 점수를 기록하고 모든 평가 모델이 향상되었다.

## 상세

평가 초점은 데스크톱 워크플로의 종단 과업 성공과 효율성이다. 논문은 여러 모델이 세 채널을 활용하는 방식과 실패 모드를 분석한다. 구현 세부와 벤치마크 설정은 연결된 원문을 참고한다.
