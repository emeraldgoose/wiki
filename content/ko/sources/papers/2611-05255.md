# Going Deeper With Memories: Byte-Level 언어 모델을 위한 다중 스케일 메모리 아키텍처

**원문**: [arXiv:2611.05255](https://arxiv.org/abs/2611.05255) · **게시일**: 2026-11-03
**저자**: Afshin Khadangi

## 개요

Byte-level language models는 tokenizer 의존을 피하고 universal coverage를 제공하지만 모든 byte를 full resolution에서 처리하는 것은 비싸다. DeepMem은 semantic compression과 exact byte preservation을 분리하는 causal multiscale architecture다. learned invertible subband transform이 더 짧은 sequence hierarchy를 구성하고, lossless carrier와 explicit detail sidebands가 byte identity를 보존한다. fast weight memory blocks가 encoder를 따라 동작하며, compressed bottleneck에서 iterative shared state computation을 수행하고 attention-based super-resolution decoder가 byte resolution representation을 복원한다. DeepMem은 FineWeb-Edu와 PG19에서 matched byte-level Transformer보다 stronger language modeling performance를 보이고 evaluated Flores languages에서 best macro average를 얻으며, code modeling, multiple-choice reasoning, byte-level corruption robustness에서도 경쟁적 성능을 유지한다.

## 핵심 내용

- architecture는 semantic compression과 exact byte preservation을 분리한다.
- invertible subband transform이 shorter-sequence hierarchy를 생성한다.
- lossless carrier와 sidebands가 exact byte identity를 보존한다.
- fast weight memory blocks가 encoder를 따라 작동한다.
- compressed bottleneck에서 iterative shared state computation이 수행된다.
- bottleneck refinement는 full-resolution reasoning보다 훨씬 적은 counted FLOPs를 사용한다.

## 상세

DeepMem은 PIQA accuracy를 개선하고 code modeling, multiple-choice reasoning, byte-level corruption robustness에서 경쟁력을 유지한다. bottleneck refinement는 equivalent full-resolution reasoning 대비 약 7,600배 더 적은 counted FLOPs를 사용하면서 evaluation throughput도 경쟁적으로 유지한다. 효율 이득은 hardware mapping과 layer implementation에 의존하므로 large-scale deployment 전에 micro-level benchmarks를 reproduce해야 한다.
