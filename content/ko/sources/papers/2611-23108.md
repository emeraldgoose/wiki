# FMT: 고정된 수의 병렬 단계로 무손실 이미지 압축하기

**Source**: [arXiv](https://arxiv.org/abs/2611.23108)
**게시일**: 2026-11-17

## Overview

Learned lossless codec은 고전 codec보다 작은 파일을 만들지만, 우리가 아카이브하고 학습에 쓰는 이미지는 여전히 고전 codec으로 저장된다. 주된 이유는 시간이다. learned codec은 고전 codec이 밀리초에 열어보는 사진을 디코딩하는 데 수 초가 걸리고, 그 빠른 변형들은 파일 크기 이득의 대부분을 포기한다. 저자는 이 시간의 상당 부분이 계산이 아니라 대기에서 쓴다고 지적한다 — 네트워크는 자신이 조건화하는 값을 기다리고, arithmetic decoder는 그 값을 하나씩 읽는다. FMT(Fixed-step Multiscale Tree)는 디코딩 순서와 entropy coder를 함께 설계한 무손실 이미지 형식으로, 어느 대기도 이미지 크기에 따라 커지지 않게 한다.

FMT는 이미지를 coarse-to-fine 트리로 저장하고, 트리의 각 단계는 서로 독립인 값들을 담는다. GPU는 각 단계를 한 번에 예측하고, 상태를 단계 간에 이어받는 병렬 rANS lane으로 디코딩하므로, 어떤 크기의 이미지든 고정된 수의 순차 단계로 디코딩된다. 이 트리 위에서 저자는 네트워크 없는 규칙 기반부터 대형 네트워크까지 비트 정확(bit-exact)한 codec 계열을 만들었고, 같은 GPU에서 실행한 어떤 codec도 크기와 속도 양쪽에서 이들을 능가하지 못했다.

## Key points

- 프런티어 결과: 네트워크 없이 FMT는 NVIDIA의 HTJ2K를 크기와 속도 모두에서 능가한다. 큰 네트워크를 쓰면 같은 A100에서 실행한 learned codec보다 동일 크기 이하에서 Kodak 사진을 9–61배 빠르게 디코딩한다.
- 단일 모델(전체 이미지 공용) learned codec 대비(Kodak): HPAC-Fast(2.95 bpsp, 0.40 s) → FMT −5.9% 크기, 7.5배 빠름; HPAC(2.73, 0.90 s) → FMT +1.7%, 17배; DLPR(2.86, 1.42 s) → FMT −3.0%, 27배; LC-FDNet(2.94, 1.00 s) → FMT −5.6%, 17배; ArIB-BPS(2.78, 3.6 s) → FMT −0.2%, 61배.
- 이미지별 적응 codec: FNLIC(2.88, 0.52 s) → FMT 512×4 −10.2%, 8.8배; HPAC-Fast-FT·HPAC-FT·CALLIC은 더 작지만 수십 배 더 걸린다.
- 단계 수: 값 단위 디코더는 1,179,648픽셀 이미지에서 1,179,648번의 순차 단계가 필요하고, JPEG XL 그룹은 196,608번, HTJ2K 블록은 5단계(단 단계당 4,096개 값)가 필요하다. FMT는 트리 단계에 완전히 독립인 값만 담아 병렬 예측과, 상태를 단계마다 이어받는 rANS 디코딩을 가능하게 한다.
- FMT는 codec의 프런티어를 제공한다: dense(공유 히스토그램), neural(학습된 확률), 이미지별 튜닝, 그리고 entropy coder가 없는 fast 모드; 비트 정확 확률이 어떤 GPU에서도 무손실을 보장한다.

## Details

- 설계: coarse-to-fine 픽셀 트리(예측-후-보정), 세 가지 코딩 모드(dense/공유 히스토그램, neural/학습된 확률, fast/entropy coder 없음), 병렬 정확 디코딩(한 단계가 모든 값을 한 번에 디코딩; lane이 rANS 상태를 유지; 비트 정확 확률).
- 평가: Kodak, DIV2K, 대형 사진 세트; 같은 A100에서 크기(bpsp)와 디코딩 시간 비교. HTJ2K, JPEG XL, DLPR, LC-FDNet, FNLIC, ArIB-BPS, HPAC 계열과 비교. 대형 사진과 CPU 프런티어는 S1.
- 한계: Sec. 5 참조(인코더 선택, 튜닝 비용, 작은 이미지, 인코딩 시간 — S4); 디코딩 순서·root/lane/튜닝·네트워크 크기 절제 실험은 Sec. 4.4와 S3.
