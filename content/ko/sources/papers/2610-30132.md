# LongZero: 제로 데이터 환경에서 LLM의 long-context reasoning 강화

**원문**: [arXiv:2610.30132](https://arxiv.org/abs/2610.30132) · **게시일**: 2026-10-21
**저자**: Zhennan Wan, Jianfei Chen

## 개요

강화학습은 LLM의 long-context reasoning을 강화하지만, 길고 다양하며 도전적이고 검증 가능한 학습 데이터가 필요하고 이런 데이터의 인간 주석은 비용이 크며 자연 발생 데이터는 RL을 sustain하기에 부족하다. 기존 synthesis는 외부 corpus나 stronger teacher model에 의존하는데, 모델이 강해질수록 이를 얻기 어렵다. LongZero는 external data 없이 LLM이 자신의 long-context reasoning을 개선하도록 한다.

## 핵심 내용

- short-context zero-data methods가 아닌 long-context reasoning을 target한다.
- 모델이 먼저 compact structured form으로 question/answer와 supporting evidence를 합성한다.
- 그다음 evidence를 long multi-document context로 확장한다.
- self-written multi-hop reasoning과 self-written multi-round retrieval task를 결합한다.
- GRPO로 학습하고 5개 long-context reasoning benchmark에서 baseline을 능가한다.

## 상세

zero-data self-generation은 주석자/corpus/teacher에 대한 의존성을 피하면서도 generalize 가능한 long-context reasoning 개선을 제공한다.
