# 드리프팅(Drifting)을 통한 데이터셋 증류

**Source**: [huggingface](https://arxiv.org/abs/2611.16642)
**게시일**: 2026-11-12

## Overview

데이터셋 증류(dataset distillation)는 대규모 실제 데이터셋을 대체할 수 있는 소규모 합성 샘플 집합을 학습하는 과제다. 이 문제가 제안된 이후 나온 대부분의 방법들은 그래디언트 매칭, 학습 궤적 매칭, 특징 매칭, 분류기 확신도 최대화 등 주로 분류기를 기준으로 증류 데이터를 최적화해 왔다. 저자들은 결정 경계에 맞춰 증류된 데이터가 분류기의 편향을 그대로 물려받으며, 이는 다른 과제로의 전이와 다른 모델로의 일반화를 제한할 수 있다고 지적한다.

이 논문은 다른 목적함수를 제안한다. 즉, 합성 샘플이 클래스별 데이터 분포를 직접 근사하도록 학습하는 것이다. 최근 생성 모델링 연구에서 영감을 받아, 사전 학습된 특징 추출기의 잠재 공간에서 증류 샘플을 "드리프팅"하여 각 샘플이 실제 데이터 쪽으로 끌어당겨지는 동시에 다른 합성 샘플로부터는 밀어내도록 만든다. 이 과정에서 분류 목적함수는 전혀 사용하지 않는다. 상반되는 힘이 증류 집합을 실제 분포 전체에 걸쳐 퍼뜨리도록 유도하여 분포 커버리지와 다양성을 모두 높인다.

소수의 이미지만으로는 분포를 충분히 근사할 수 없기 때문에, 이 방법은 각 합성 이미지의 여러 증강(augmentation)을 한 번에 함께 드리프팅한다. 저자들은 이렇게 얻은 드리프트된 데이터가 기존 방법보다 실제 분포를 훨씬 잘 커버하면서도 분류 학습용 샘플로서 여전히 강력하다는 것을 발견했다. 또한 이 방법을 모델 해석을 위한 시각화 도구로 제시하고, 이미지 외 다른 모달리티로 확장할 수 있음을 보였다. 이 연구는 데이터셋 증류의 평가 지표로 분포 기반 메트릭을 분류 정확도의 보완 수단으로 제안한다.

## Key points

- 분류기 중심의 증류 목적함수를 클래스별 실제 분포에 대한 분포 매칭 목적함수로 대체한다.
- 실제 샘플을 향하는 인력(attractive)과 다른 합성 샘플을 밀어내는 척력(repulsive)으로 구성된 드리프팅 필드를 사용하며, 거리 기반 소프트맥스로 가중한다.
- 픽셀 공간이 아닌 사전 학습된 특징 추출기의 잠재 공간에서 동작하며, 어떤 특징 추출기를 쓰느냐가 분포 매칭이 이루어지는 공간을 결정한다.
- 각 합성 이미지의 여러 증강(랜덤 리사이즈 크롭, 수평 뒤집기, 가우시안 노이즈)을 동시에 드리프팅하여 이미지와 증강이 함께 목표 분포를 커버하게 한다.
- 기존 방법보다 실제 분포를 더 잘 커버하며, 분류 학습 데이터로서도 강한 성능을 보인다고 보고한다.
- 이 방법을 모델 해석용 시각화 도구로 시연하고, 이미지 외 모달리티로 확장 가능함을 보인다.
- 분류 정확도 평가를 보완하는 분포 기반 메트릭을 제안한다.
- NeurIPS 2026에 채택되었다.

## Details

**방법.** 이 접근법은 생성 모델링의 드리프팅 프레임워크를 각 합성 샘플에 작용하는 "힘"의 장으로 재해석한 것이다. 합성 샘플 x에 대해 드리프팅 필드 V(x)는 두 성분으로 분해된다. 하나는 양(+)의(인력) 성분으로, 커널 κ(x, y) = exp(-||x - y|| / τ)로 가중된 실제 샘플들에 대한 기댓값이고, 다른 하나는 음(-)의(척력) 성분으로, 다른 합성 샘플들에 대한 커널 가중합이다. 합성 샘플은 stop-gradient를 적용한 손실을 통해 각 샘플이 x + V(x) 쪽으로 끌려가도록 최적화되며, 드리프팅 손실은 생성기의 가중치가 아니라 합성 데이터 자체에 직접 역전파된다. 필드는 각 이미지의 증강된 뷰에 적용한 사전 학습 특징 추출기 φ의 잠재 공간에서 계산되며, 드리프팅 선행 연구에서 가져온 정규화 항도 함께 적용된다. 이 방법은 DINOv3 특징으로 시연되었으며, 예를 들어 무작위 노이즈에서 초기화한 일부 ImageNet-1k 클래스에 대해 클래스당 10개의 이미지를 생성했고, 인력과 척력이 높은 품질과 다양성을 만들어낸다.

**결과와 발견.** 저자들은 드리프트된 합성 데이터셋이 기존 증류 방법보다 실제 분포를 훨씬 잘 커버하면서도 분류 학습용 샘플로서 강력하게 작동한다고 보고한다. 추가 분석에서는 드리프팅 증류가 다른 모달리티로 일반화되고, 증류된 데이터가 모델의 편향을 드러내며, 증류된 샘플이 모델을 더 잘 해석하기 위한 시각화 도구("an image is worth a thousand paintings")로 쓰일 수 있음을 보인다. 논문은 또한 Laplacian 피라미드를 통한 암묵적 정규화(implicit regularization)를 다루며, 부록에 한계, 계산 비용, 더 넓은 영향, 라이선스 관련 내용을 포함한다. 이 논문은 NeurIPS 2026에 채택되었다. 구체적인 정량적 벤치마크 수치는 여기에 재현하지 않았으므로, 전체 평가는 원 논문을 참조하라.
