# G-CAST: 진화하는 수요 속 전자상거래 에이전트를 위한 거버넌스 기반 지속 자가 학습

**원문**: [arXiv:2611.17814](https://arxiv.org/abs/2611.17814) · **게시일**: 2026-11-13
**저자**: Yuechun Yu, Wenzheng Kong, Xiaofeng Mao, Jin Zhang

## 개요

대규모 언어 모델(LLM) 기반 대화형 쇼핑 에이전트가 전자상거래에서 빠르게 확산되면서, 모델이 상대해야 하는 과제도 계속 움직인다. 사용자는 새로운 상품 카테고리, 조달 시나리오, 기능 요구를 끊임없이 제시하고, 에이전트의 실행 하네스(harness) — 도구, 스킬, 운영 절차 — 도 점점 정교한 상호작용을 지원하려고 함께 진화한다. 저자들은 이 상황을 두 가지 실무적 난제로 정리한다. 첫째, 수요 드리프트(demand drift)는 사용자 요청의 분포·의도·복잡도를 바꾸기 때문에 한 번 학습한 모델은 금세 뒤처진다. 둘째, 하네스가 진화하면 모델은 새로 도입된 기능을 올바르게 사용하면서도 이미 사용자가 의존하던 행동은 잃지 않아야 한다. 주기적인 수동 재학습으로는 이 속도를 따라잡기에 너무 느리고 노동 집약적이다.

G-CAST는 이런 환경을 위한 거버넌스 기반 지속 자가 학습 시스템이다. 진화하는 수요 계약과 역량 계약 아래 쌓이는 일일 프로덕션 증거를 두 갈래로 바꾼다. 하나는 보상 라우팅과 엔트로피 우선순위를 거친 훈련 데이터이고, 다른 하나는 보상 신호 자체의 통제된 진화다. 모델 갱신은 누적 평가가 관리하는 통제된 체크포인트 전환을 통과하는데, 덕분에 에이전트는 새로 도입된 행동을 배우면서도 이미 검증된 기존 역량을 잃지 않는다.

실험은 벤치마크 대신 실제 프로덕션 전자상거래 에이전트에서 수행됐다. 강한 자율 후속 학습(autonomous post-training) 기준선과 비교했을 때, G-CAST는 새로 도입된 수요에 더 잘 적응하면서 기존에 인정받은 행동을 더 잘 지켰고, 소거 실험은 이 성과가 데이터 오케스트레이션과 보상 진화 두 요소 모두에 기인함을 보였다. 이 시스템은 알리바바 1688 플랫폼의 B2B 조달 에이전트인 Yuancai에 배치되어 운영 중이다.

## 핵심 내용

- 프로덕션 LLM 쇼핑 에이전트의 두 가지 실패 모드: 수요 드리프트(새 상품 카테고리·조달 시나리오·기능 요구가 등장하면서 사용자 요청의 분포·의도·복잡도가 계속 이동)와 하네스 진화(새 도구·스킬·운영 절차를 올바르게 받아들이면서 이미 사용자가 의존하던 행동은 유지해야 하는 문제).
- 논문은 주기적 수동 재학습으로는 진화하는 수요와 하네스 속도를 따라잡을 수 없다고 보며, 너무 느리고 노동 집약적이라고 지적한다.
- 데이터 측면: G-CAST는 일일 프로덕션 증거를 보상 라우팅·엔트로피 우선 오케스트레이션으로 걸러 훈련 데이터로 바꾼다. 현재 계약 아래 무엇을 학습할지 보상과 엔트로피로 선택하는 방식이다.
- 보상 측면: 계약 기반 보상 진화는 수요·역량 계약이 바뀔 때 보상 신호 자체를 갱신하며, 정의된 평가 지표와 동결된 평가 보상(frozen evaluation reward)이 점수의 일관성을 지킨다.
- 통제된 체크포인트 전환: 모든 모델 갱신은 누적 평가의 관문을 통과하므로, 에이전트는 새 행동을 흡수하면서도 기존에 인정받은 역량을 희생하지 않는다.
- 프로덕션 비교: 실제 전자상거래 에이전트에서 G-CAST는 강한 자율 후속 학습 기준선보다 새로 도입된 수요에 더 강하게 적응하고, 기존에 인정받은 행동도 더 잘 보존했다.
- 소거 실험: 보상 라우팅·엔트로피 우선 데이터 오케스트레이션과 통제된 보상 진화 중 하나라도 빼면 성과가 떨어져, 두 요소 모두 중요하다는 결과다.
- 배치: G-CAST는 알리바바 1688 플랫폼의 B2B 조달 에이전트인 Yuancai(cai.1688.com)에서 운영 중이다.

## 상세

방법 구조는 공통 계약층을 두고 맞물린 두 메커니즘이다. 보상 라우팅·엔트로피 우선 데이터 오케스트레이션은 어떤 일일 프로덕션 증거를 훈련 데이터로 승격할지 결정하고, 계약 기반 보상 진화는 수요·역량 계약의 변화에 맞춰 보상 신호를 갱신한다. 방법 절은 여기에 평가 지표 정의와 동결된 평가 보상을 함께 두어 계약이 움직여도 점수 비교가 유지되게 하며, 체크포인트 전환은 자동 공개가 아니라 누적 평가에 따라 통제된다.

실험 절은 진화하는 계약 아래의 지속 자가 학습, 라우팅·우선순위 소거, 보상 진화 평가를 다루며 모두 프로덕션 에이전트 위에서 진행된다. 관련 연구는 자동 학습 에이전트, 자율 LLM 후속 학습, 자율 데이터 엔지니어링, 자가 진화 에이전틱 AI 계열로 G-CAST를 자리매김하고, 하네스·컨텍스트 진화 연구와 하네스-모델 공동 진화를 구분한다. 결론은 운영상 효과와 한계를 논의하며, 논문은 공개 코드 릴리스를 발표하지 않는다. 이 문서는 v1(2026년 11월 13일) arXiv 제출본을 다룬다.
