# Continual-ARC: 생애 동안의 스킬 습득 측정

**Source**: [huggingface](https://arxiv.org/abs/2611.14505)
**게시일**: 2026-11-15 (v3)

## 개요

Continual-ARC는 ARC-AGI 3개의 에디션을 기반으로 구축된 평생 벤치마크로, agent harness가 단일 패스 태스크가 아니라 생애에 걸쳐 어떻게 스킬을 습득하는지를 측정한다. 이 벤치마크는 기존 연속학습 벤치마크의 세 가지 한계 — 단일 응용 도메인에 집중하고, 인스턴스를 한 번씩만 제공하며, 단일 학습자 계열을 가정한다는 점 — 를 해결하여 메모리 기반 시스템과 가중치 기반 시스템을 같은 척도로 비교할 수 있게 한다.

벤치마크가 제시하는 태스크는 도메인 지식 없이 해결 가능하다. 이미 본 태스크는 휴면 기간을 거쳐 새로운 인스턴스로 다시 등장하고, 동시에 새로운 태스크가 계속 추가된다. 각 인스턴스에서 학습자는 데모를 구매하거나, 답변을 제출하거나, harness 내부에서 행동할 수 있으며, 오류 제출에 대한 재시도도 비용을 지불한다. 각 인스턴스는 피드백 예산을 얼마나 소비했는지로 채점되어, 메모리 기반과 가중치 기반 학습자를 동일한 척도로 놓는다. 스트림이 끝나면 학습자는 동결되고, (a) 이미 경험한 태스크의 새 인스턴스로 기억을 측정하고, (b) 보지 못한 태스크로 일반화를 측정한다.

저자들은 가중치가 동결된 agent harness를 지속성 있음/없음 조건으로 Qwen3.5-9B와 GLM-5.3 Flash에 적용하고, 두 가지 프롬프팅 플로어, 프로그램 귀납 방법, 그리고 Qwen3.5-9B가 GLM-5.3 Flash를 모방하도록 학습된 모델과 비교했다.

## 핵심 내용

- harness에서의 지속성은 명시적인 전문가 가이드(규칙, 다이제스트, 조언)가 없으면 **기억력을 개선하지 못한다**.
- 대부분의 harness 기반 방법은 태스크의 데모를 캐시하는 플로어보다 **여전히 적게 학습**한다(테스트한 모든 모델에서).
- harness 기반 방법은 보지 못한 태스크에서 거의 이득을 얻지 못하는 반면, 가중치 기반 학습은 상당한 이득을 보인다.
- 이 벤치마크는 메모리와 가중치 학습자를 동일한 피드백 예산 척도로 채점하므로, 단일 도메인·단일 계열에 국한된 기존 벤치마크와 달리 동등 비교가 가능하다.

## 상세

이 논문은 학습 체제를 개인과 집단의 두 양상으로 규정하고, harness 구현 세부사항을 부록 D에 기술한다(인터럽션, 서버 시간창과 포기 결정 등). 부록 E는 harness가 무엇을 지속하는지와 그 충실도를 검토하며, prime-agent on GPT-6 Luna(세션 간에 아무것도 전달되지 않음), prime-agent on GLM-5.3 Flash(다이제스트가 규칙을 거의 보여주지 않음), hermes-agent(인스턴스마다 바뀌는 조언), openclaw(승격할 수 없는 통합)를 다룬다. 부록 F와 H는 전문가 가이드와 함께 저장을 수행하도록 요구한 harness와 오픈 모델들에 적용한 방법을 다룬다.

동결된 학습자 프로토콜 — 경험한 태스크의 새 인스턴스 vs 보지 못한 태스크 — 로 기억과 일반화를 분리해 측정했다. 가중치 기반 학습은 특히 보지 못한 태스크에서 강점을 보여, 가중치 기반 연속학습이 새로운 도메인에서 harness 행동을 이끄는 가능성을 열었다.
