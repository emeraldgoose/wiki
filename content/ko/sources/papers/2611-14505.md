# Continual-ARC: 작업 수명을 통한 기술 습득 측정

**원문**: [arXiv:2611.14505](https://arxiv.org/abs/2611.14505) · **게시일**: 2026-11-11
**저자**: Daniel Lenton, Yusha Arif, Haris Mahmood

## 개요

에이전트 하니스는 지속 학습과 테스트 타임 파라메트릭 학습을 함께 연구하는 일반적인 방식이 되었다. 그러나 기존 벤치마크는 단일 도메인에 집중하고, 각 작업을 한 번만 제시하며, 학습자 계열을 하나만 가정하는 등 한계가 있다. 메모리 기반과 가중치 기반 시스템을 공정하게 비교하기 어렵다.

Continual-ARC는 세 차례의 ARC-AGI 에디션에서 구축된 평생 평가 스트림을 제안한다. 작업은 도메인 지식이 필요 없으며, 휴지기를 거쳐 새로운 인스턴스와 함께 재등장하고 새로운 작업이 계속 유입된다. 각 인스턴스에서 학습자는 시범을 구매하거나 답안을 제출하거나 하니스 내에서 행동할 수 있으며, 오답 제출 시 재시도가 허용되지만 비용이 든다. 점수는 피드백 예산 소비 비율을 기준으로 산정된다.

학습자가 인스턴스 사이 정보를 유지할 수 있기 때문에 메모리 기반과 가중치 기반 접근법을 동일한 척도로 평가할 수 있다. 스트림 이후 학습자는 동결되어, 본 적이 있는 작업의 새로운 인스턴스로 기억력을, 본 적 없는 작업으로 일반화 능력을 측정한다.

## 핵심 내용

- Continual-ARC는 반복되는 작업, 새로운 인스턴스, 통합 피드백 예산을 갖춘 ARC-AGI 평생 스트림을 제공한다.
- 메모리 기반과 가중치 기반 지속 학습자를 직접 비교할 수 있다.
- Qwen3.5-9B와 GLM-5.3 Flash 위에서 동결 가중치 하니스 에이전트를 실험한 결과, 명시적 전문가 가이던스 없이는 지속성만으로는 기억력이 크게 개선되지 않는다.
- 하니스 기반 방법은 여러 모델에서 단순 시범 캐시 전략에도 못 미치는 경우가 많다.
- 하니스 기반 방법은 새로운 작업에서 거의 이득이 없고, 가중치 기반 학습은 상당한 일반화 향상을 보여 하니스를 구동할 가중치 기반 지속 학습의 필요성을 시사한다.

## 상세

하니스 프레임워크는 시범 구매, 답안 제출, 비용이 드는 재시도를 허용한다. 각 인스턴스 점수는 피드백 예산 사용량을 반영한다. 평가는 재방문 작업에서의 기억력과 새로운 작업에서의 일반화로 분리된다.

저자들은 지속성 유무에 따른 동결 가중치 에이전트, 프롬프팅 기준, 프로그램 귀납 방법, Qwen3.5-9B가 GLM-5.3 Flash를 모방하도록 학습된 가중치 모방 설정을 비교했다. 결과는 하니스 내 지속성이 기억력 개선을 보장하지 않으며, 종종 시범 캐시에 밀린다. 반면 가중치 기반 적응은 명확한 일반화 향상을 보인다.
