# GaussianRenderFormer: 3D 가우시안 스플랫 렌더링을 위한 트랜스포머

**원문**: [arXiv:2611.05593](https://arxiv.org/abs/2611.05593) · **게시일**: 2026-11-03
**저자**: Shahaf Valencia Levy, Sagie Benaim

## 개요

neural network가 rasterizer 없이 스스로 3D 가우시안 스플랫을 렌더링할 수 있는가? 논문은 GaussianRenderFormer를 제시하며, 이는 가우시안 집합과 카메라를 받아 이미지를 직접 출력하는 transformer이다. 각 Gaussian은 view-independent encoder에서 하나의 token이 되고, view-dependent decoder는 camera ray의 small patches를 those tokens에 attend하여 pixel로 변환한다. 26,820개 Objaverse objects pruned to 20,000 Gaussians로 훈련된 모델은 300 unseen objects를 full unpruned splats 대비 38.08 dB PSNR로 render하는 반면, 동일 pruned input rasterizing은 44.02 dB에 도달한다. gap은 generalization 문제가 아니며 diagnostics는 view decoder bottleneck과 consistent하다: 각 Gaussian의 projected footprint를 decoder에게 알려주면 (in principle infer 가능) 1.4 dB가 추가된다. under-training은 excluded되지 않는다. code/trained models/videos는 project page에서 제공된다.

## 핵심 내용

- rasterizer 없이 가우시안/카메라로부터 직접 이미지를 출력하는 neural renderer.
- view-independent encoder가 Gaussian token을, view-dependent decoder가 ray patch에서 pixel 생성.
- 26,820개 pruned objects로 train, 300 unseen objects 평가.
- direct rendering 38.08 dB PSNR vs pruned rasterization 44.02 dB.
- projected footprint 제공 시 +1.4 dB, view-decoder bottleneck 시사.

## 상세

generalization vs decoder bottleneck diagnostics를 포함한다. code/trained models/videos는 project page를 통해 release한다. scaling과 architecture 세부는 연결된 원문을 참고한다.
