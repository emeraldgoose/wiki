# SoloQ: 디퓨전 언어 모델을 위한 캘리브레이션 없는 양자화

**Source**: Donghyun Lee 외, arXiv, 2026-10-05

**Lead**: 디퓨전 대형 언어 모델(dLLM)은 반복적인 전체 시퀀스 디노이징과 KV-캐시 메모리 압박으로 인해 배포 비용이 높습니다. 기존 사후 학습 양자화 방법은 캘리브레이션 데이터를 필요로 하지만, dLLM의 활성화 분포는 마스킹 상태와 디노이징 단계에 따라 크게 변합니다. SoloQ는 구조화된 K-RPBH 회전과 경량 리스케일링으로 예측 가능한 주변 분포를 만들어 캘리브레이션 없는 4비트 양자화를 가능하게 합니다.

## 배경

자기회귀 LLM이 언어 모델링을 주도해왔으나, LLaDA, Dream, Fast-dLLM v2, Nemotron-Labs-Diffusion 같은 디퓨전 LLM(dLLM)은 양방향 대안을 제공합니다. dLLM은 반복적 디노이징으로 토큰을 생성하며 많은 순전파가 필요합니다. 전체 시퀀스 dLLM은 전체 시퀀스에 대해 계산 집약적 패스를 반복하고, 블록 디퓨전 변종은 영구 KV-캐시를 추가합니다. 두 특성 모두 저비트 양자화를 매우 바람직하게 만듭니다.

dLLM 대상 기존 양자화 접근법은 캘리브레이션 데이터로 양자화 파라미터를 결정합니다. 하지만 dLLM의 활성화 분포는 디노이징 단계와 마스킹 설정에 따라 크게 변해 정적 캘리브레이션이 비효과적입니다. 캘리브레이션은 배포 마찰과 데이터 의존성도 추가합니다.

## SoloQ 방법

SoloQ는 구조화된 크로네커 곱 무작위 순열 블록 아다마르(K-RPBH) 회전을 사용해 가중치와 활성화를 정규화된 회전 기저로 매핑합니다. 이 회전은 예측 가능한 주변 분포(준-가우시안 및 준-균일)를 산출해 캘리브레이션 데이터 없이 분포 매칭 코드북을 가능하게 합니다.

주요 구성 요소:
- **구조화된 K-RPBH 회전**: 효율적 계산, 하드웨어 친화적, 표현력 보존.
- **스케일-온리 바이어스 보정**: 가중치에는 커밋 시, 활성화에는 런타임에 적용되는 경량 리스케일링 단계로 잔여 분포 불일치 보정.
- **KV-캐시 양자화**: 블록 디퓨전 모델에서 활성 디노이징 블록을 교란하지 않고 영구 KV-캐시를 커밋 시 양자화.

예측 가능한 회전 후 분포는 하드웨어 네이티브 NVFP4(4비트 부동소수점) 포맷으로 직접 매핑도 가능하게 합니다.

## 결과

LLaDA, Dream, Fast-dLLM v2, Nemotron-Labs-Diffusion 다중 스케일 전반에서:
- SoloQ는 4비트 가중치-활성화 양자화 하에서 정확도를 유지하며, 지식·추론 집약적 벤치마크(MMLU, GSM8K, BBH, ARC)에서 캘리브레이션 기반 베이스라인을 능가합니다.
- NVFP4로 피크 메모리 최대 **2.61×** 감소, 엔드투엔드 추론 지연 최대 **2.24×** 단축.
- 오버헤드 최소화: 회전과 리스케일링은 모델에 폴딩되거나 단일 커널로 실행.

## SW 엔지니어 관점에서의 의의

- **배포**: SoloQ는 캘리브레이션 데이터 요구사항을 제거해 dLLM 프로덕션 양자화 파이프라인을 단순화합니다.
- **하드웨어 효율**: NVFP4 지원은 블랙웰 GPU 및 차세대 가속기 로드맵과 정렬됩니다.
- **메모리 제약 환경**: 2.6배 메모리 감소로 고정된 GPU 메모리 예산에서 더 큰 dLLM 실행 가능.
- **열린 연구**: 구조화된 회전 접근법은 활성화 분포가 변하는 다른 아키텍처로 일반화됩니다.
