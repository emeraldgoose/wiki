# WebHarbor: GUI 에이전트 환경을 위한 실제 웹사이트 도킹

**원문**: [arXiv:2611.03634](https://arxiv.org/abs/2611.03634) · **게시일**: 2026-11-02
**저자**: Zhaoyang Wang, Qianhui Wu, Boyu Gou, Demi Wang, Jiacheng Zhang, Peichun Hua, Qize Li, Shi Qiu, Yifan Jiang, Yifan Zhang, Zexu Jin, Baolin Peng, Bolin Shen, Chetan Bansal, Dehan Kong, Deren Lei, Dongshen Peng, Fengqing Jiang, Hao Cheng, Haoqing Wang, Jiaming Shan, Jicheng Wang, Jingguang Zhou, Jixuan He, Kaide Zeng, Kangyu Zhu, Lama Moukheiber, Mufan Qiu, Peng Xia, Qihan Sun, Qingwei Lin, Qiushi Sun, Ruichen Zhang, Shuqing Luo, Si Qin, Sicheng Fan, Tao Xiong, Wenlin Yao, Xinyu Zhang, Xinyue Zeng, Xuanrui Li, Xuchao Zhang, Yian Wang, Yichao Liu, Yiming Liang, Yiyang Zhou, Yizhu Jiao, Yuetai Li, Yurun Chen, Yuxuan Zhang, Zheyuan Yang, Zhiyuan Yao, Zhongyang Li, Zihao Li, Zili Wang, Jianfeng Gao, Huaxiu Yao

## 개요

GUI 웹 에이전트는 평가와 훈련 중 안정적으로 유지되는 현실적이고 상호작용 가능한 환경이 필요하다. 라이브 웹사이트 평가는 변화하는 콘텐츠, 접근 제한, 인증된 워크플로우 커버리지 부족으로 어려움을 겪고, 기존 합성 훈련 환경은 기능적 깊이와 시각 충실도가 부족하다. WebHarbor는 실제 웹 서비스의 시각적 인터페이스, 콘텐츠, 기능 워크플로우를 결정적 제어 아래에서 충실히 재구성하는 153개 실행 가능하고 도커화된 웹사이트 환경 묶음이다. 작업 주도 휴먼-에이전트 협업으로 구축되어 새로운 작업이 기능 범위를 확장하면 환경도 진화한다.

## 핵심 내용

- 환경 묶음은 153개 실행 가능 도커화 웹 사이트로 구성된다.
- 시각적 인터페이스, 콘텐츠, 기능 워크플로우를 현실적으로 재구성한다.
- 평가와 훈련 중 환경은 결정적이고 제어 가능하다.
- 다단계 및 인증 후워크플로우를 포함하는 작업을 다룬다.
- 휴먼-에이전트 협업이 환경 품질을 확장하고 감사한다.
- 비용 효율적 강화 학습을 위한 고품질 합성 웹 환경을 제공한다.

## 상세

 이 묶음은 3,518개 작업과 시각 충실도, 기능 정확성, 작업 타당성 같은 감사 가능한 값을 포함한다. 기존 GUI 에이전트 평가는 인증 후워크플로우를 자주 놓치지만 이 묶음은 이를 다룬다. 평가를 넘어 WebHarbor에서 강화 학습으로 훈련한 Qwen 4B 수준 GUI 에이전트는 보지 못한 작업으로 일반화하고 네 벤치마크에서 선도 오픈 소스 GUI 웹 에이전트와 경쟁적으로 수행했다. 결과는 작업과 웹 사이트가 대상 분포를 대표하기만 하면 결정적이고 고품질인 웹 환경이 신뢰할 만한 평가와 비용 효율적인 훈련 모두를 지원할 수 있음을 보여준다.
