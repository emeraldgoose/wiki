# CANTraj: 자연주행의 CAN 신호에서 차량 궤적 복원

**원문**: [arXiv:2611.18442](https://arxiv.org/abs/2611.18442) · **게시일**: 2026-11-13
**저자**: Yuhang Wang, Qiushi Wang, Rongqing Zhu, Yixiao Shi, Zucheng Cheng, Xiaohui Li, Zhiming Lu, Xinbing Fu, Tianyue Wang, Jiaqi Li, Songwu Lu

## 개요

개방형 주행 데이터 공개나 사용량 기반 보험 상품은 차량 로그에서 GPS 좌표를 빼면 프라이버시가 보호된다고 주장해 왔다. 이 논문은 그 주장이 거짓 위안임을 보여준다. GPS를 지워도 일반 차량 신호에 담긴 위치 정보는 지워지지 않는다. 조향각, 속도, 주행 이벤트는 일단 도로망과 매칭되면 궤적의 상당 부분을 복원해 낸다. 선행 경로 추론 공격이 원리를 증명했지만, 서로 다른 가정과 평가 지표를 쓰고 작고 제한된 데이터셋에서만 시험돼 결과 비교가 어려웠다.

저자는 두 공개 산출물로 이를 고친다. CANTraj는 자연주행 데이터셋으로, 디코딩된 CAN 이벤트와 시간 정렬 GNSS 궤적을 쌍으로 묶었다(주행 3,940건, 운전자 454명). CANTraj-Bench는 궤적 복원 평가를 위한 통제 스위트로(주행 3,675건, 운전자 431명, 1,380시간, 85,919km), 명시적 정보 접근 프로토콜, 쌍대 비교, 실패를 함께 세는 지표로 여섯 가지 재구현 공격과 기본 벤치마크를 비교한다.

핵심 발견은 분명하다. 조향을 도로망 제약과 결합하면 가장 큰 이득이 난다. 시작점과 진행 방향을 알고 있다는 설정에서 조향을 속도에 더하면 온라인 맵 필터의 5분 경로 복원이 56%에서 87%로 올라가고, 중간 평균 변위 오차는 43m로, 지도 없는 추측 항법의 921m보다 훨씬 낮다. 오프라인 빔 서치는 진행 방향을 알 때 테스트 경로의 88%, 모를 때 81%를 복원한다. 방법마다 실패하는 구간이 달라, 659개 5분 구간에서 후보 경로 중 하나를 고르는 LLM 하네스는 테스트에서 79%, 퓨샷에서 83%를 복원해 베스트 기본선을 능가하고 퓨샷에서는 대등하다.

## 핵심 내용

- 공개 산출물: CANTraj 데이터셋(주행 3,940건 / 운전자 454명)과 CANTraj-Bench(주행 3,675건 / 운전자 431명 / 1,380시간 / 85,919km)에 디코딩된 CAN 이벤트와 시간 정렬 GNSS 궤적을 모두 포함한다.
- 명시적 프로토콜: 공격자가 무엇을 아는지를 명시하고, 같은 주행을 방법별로 비교하며, 실패를 포함해 지표를 매겨 연구 간 비교 가능성을 확보했다.
- 조향이 결정적 신호다: 시작점과 방향을 알 때 조향을 속도에 더하면 온라인 맵 필터 5분 경로 복원이 56%에서 87%로 오르고 중간 ADE는 43m(지도 없는 추측 항법은 921m)다.
- 오프라인 빔 서치: 방향을 알 때 88%, 모를 때 81% 복원해, 적은 정보 예산에서도 강건하다.
- LLM 하네스: 659개 5분 구간의 후보 경로 선택기가 테스트에서 79%, 퓨샷에서 83%를 복원해 베스트 기본선을 능가하고 퓨샷에서는 대등하다.
- 프라이버시 함의: 주행 로그에서 GPS를 제거해도 CAN 신호에서 경로 복원이 가능하므로, 개방형 주행 데이터 공개에는 더 강한 완화가 필요하다.

## 상세

문헌에서 여섯 가지 공격을 재구현하고 간단한 기본선과 함께 같은 정보 접근 프로토콜로 돌린다. 세 단계 프로토콜이 중요하다. 가장 약한 단계에서는 공격자가 아무것도 모르고, 중간 단계에서는 시작 위치나 시작 방향을 알고, 가장 강한 단계에서는 둘 다 안다. 지표는 쌍대 방식이다. 같은 5분 구간을 모든 방법이 채점하고, 매칭된 도로 순서가 구간 내내 허용 오차 안을 유지할 때만 '경로 복원'으로 센다. 실패를 명시적으로 포함해 버리지 않기 때문에 백분율이 신뢰할 수 있고 비교가 공정해진다.

조향 결과는 온라인 파티클 맵 필터에서 나온다. 후보 위치를 속도로 전파하고, 도로망으로 가지치며, 조향 제약으로 재가중한다. 조향이 순수 속도 기반 외삽의 모호성을 충분히 줄여 5분 복원을 31%포인트 올렸다. 지도 없는 추측 항법은 도로 제약이 전혀 없어 5분 만에 중간 ADE가 921m로 드리프트한다. 도로망 제약이 이득의 나머지 절반인 이유다.

오프라인 빔 서치는 같은 구간을 다루지만, 앞으로 탐욕적으로 확정하지 않고 부분 신호로부터 도로 그래프를 거꾸로 탐색한다. 진행 방향을 알 때와 모를 때의 88%/81% 격차가 여기서 생긴다. LLM 하네스가 가장 새롭다. 후보 경로 하나를 고르는 대신 여러 후보를 보고 어떤 것이 관측된 CAN 구간을 가장 잘 설명하는지 묻는다. 다양한 후보 사이의 선택이 기하학적 공격 위에 언어 추론이 측정 가능한 값을 더하는 지점이고, 퓨샷 수치는 예시 몇 개만 줘도 일반화됨을 보여준다.

위협 모델과 범위: 이 작업은 특정 차량을 기억해 겨냥하는 스토킹이 아니라, 캐주얼한 데이터 공개와 보험 상품을 겨냥한다. 저자는 결과를 최악이 아닌 전형적 프라이버시 위험의 정량화로 명시한다. 코드와 데이터가 공개돼 있어 수치를 감사하고 공격을 재현할 수 있다.
