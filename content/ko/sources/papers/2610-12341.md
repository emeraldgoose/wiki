# AI 에이전트가 학습으로 정상에 오를 수 있을까? 장기 게임 에이전트 대회에서의 휴리스틱 학습 평가

**Source**: Yang 외, arXiv, 2026-10-08

**핵심**: 적대적 게임은 AI를 휴리스틱 탐색에서 심층 RL로 이끌었으나, 제한된 경험으로부터 학습하는 것은 여전히 어렵다. 본 연구는 **적대적 휴리스틱 학습(AHL)**을 소개한다: 모델 가중치를 고정한 채 경험을 통해 *실행 가능한 게임 정책*(코드)을 개선하는 AI 에이전트. AAArena 벤치마크(12개 게임, 1,920개 인간 프로그램)가 에이전트가 학습으로 챔피언급 플레이에 도달할 수 있는지 평가한다.

## 배경

전통적 게임 AI 패러다임:
- **휴리스틱 탐색** (DeepBlue): 수작업 평가 함수 + 탐색
- **강화 학습** (AlphaGo): 자기 대국으로 가치/정책 네트워크 학습
- **LLM 에이전트**: 모델에 프롬프트로 행동 직접 생성

세 가지 모두 한계가 있다: 수작업 휴리스틱은 적응 못 함; RL은 막대한 컴퓨트 필요, 지식이 가중치에 고정; LLM 에이전트는 장기지평 일관성 부족. **휴리스틱 학습(HL)**은 중간 지대를 제공한다: 에이전트가 정책을 구현하는 *코드를 작성하고 개정*한다. 모델 가중치는 동결; 학습은 정책 코드 레벨에서 발생.

## AAArena 벤치마크

**12개 실제 적대적 게임**: 보드 게임(바둑, 체스 변형), 카드 게임, 자원 관리, 실시간 전략—각각 다른 상태 공간, 행동 공간, 전략적 깊이.

**1,920개 아카이브된 인간 프로그램**: 수년간 인간 프로그래머의 제출물로, 초보자부터 전문가까지 풍부한 전략 커리큘럼 제공.

**평가 프로토콜**: AI 에이전트는 기본 정책으로 시작해 반복적으로:
1. 상대(인간 프로그램 또는 다른 에이전트)와 게임 플레이
2. 승패 분석으로 정책 약점 식별
3. 정책 코드 개정 제안
4. 자기 대국으로 개정 검증
4. 고정된 상호작용 예산까지 반복

에이전트는 인간 프로그램 아카이브 대비 Elo로 순위 매겨짐.

## 적대적 휴리스틱 학습(AHL) 프레임워크

AHL 에이전트는 **정책 코드**(Python 함수 `get_action(state)` 구현)에서 작동:

```python
def get_action(state):
    # 정책 로직 - 에이전트가 편집 가능
    return best_action
```

**학습 루프**:
1. **경험 수집**: N게임 플레이, 궤적 기록
2. **실패 분석**: LLM이 패배 궤적 분석, 패턴 식별
3. **정책 개정**: LLM이 코드 변경 제안(새 휴리스틱, 버그 수정, 새 전략)
4. **검증**: 수정된 정책을 보류된 상대로 테스트
5. **수락/거부**: Elo 향상 시 유지; 아니면 롤백

이는 **코드 레벨 학습**—해석 가능, 버전 관리 가능, 이전 가능.

## 결과

**최상위 AHL 에이전트, 다수 게임에서 인간 Elo 상위 10% 도달** (~500회 상호작용 후).

**주요 발견**:
- **코드 개정이 가중치 업데이트 능가**: AHL 에이전트가 여러 게임에서 RL 베이스라인 대비 100배 적은 컴퓨트로 우위
- **인간 커리큘럼 중요**: 인간 프로그램부터 시작(무작위 대비) 학습 3-5배 가속
- **실패 주도 개정 효과**: 패배를 명시 분석하는 에이전트가 무작위 돌연변이만 제안하는 것보다 빠르게 개선
- **정책 해석 가능성**: 승리 정책이 읽을 수 있는 코드—전략 검사, 디버깅, 이전 가능

**한계**: 고차원 연속 행동(RTS 마이크로 관리) 게임에서 휴리스틱 코드 작성 어려워 AHL 고전.

## 소프트웨어 엔지니어를 위한 시사점

AHL은 **새로운 에이전트 아키텍처 패턴**을 도입: 에이전트가 *자신의 정책을 재작성하며 학습하는 코드 편집기*. 이는 다음에 함의:
- **자기 개선 코드 에이전트**: 실행 실패 분석으로 스스로 버그 수정하는 에이전트
- **해석 가능한 RL 대안**: 정책이 코드, 가중치 아님—감사 가능, 패치 가능, 설명 가능
- **저컴퓨트 적응**: 재학습 아닌 휴리스틱 편집으로 새 환경 적응
