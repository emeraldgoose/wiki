# L3G-World: 잠재 3D Gaussian 기억으로 하는 실시간 무한 월드 생성

출처: Jinhyeok Choi, arXiv:2610.40614, 2026-10-29.

**핵심 요약**: 인터랙티브 월드 모델은 사용자 행동에 따라 비주얼 콘텐츠를 생성하지만 장시간 탐색에서 실시간 공간 일관성을 유지하기 어렵습니다. 기존 방식은 temporal context나 explicit 3D memory에 의존하는데, 메모리가 생성 스트림 길이에 비례해 커져 확장성이 나쁩니다. 또한 explicit 3D memory는 RGB rendering을 재인코딩해 latent video generator를 조건하기 때문에 실시간 생성이 불가능합니다. **L3G-World**는 feed-forward reconstruction의 효율과 compact·rapidly renderable scene representation을 결합한 **Latent 3D Gaussian Memory(L3G)** 를 도입합니다. memory updater와 video DiT가 자동회귀적으로 번갈아 가며 공간적으로 일관된 월드를 생성합니다. updater는 newly observed region에 Gaussian을 spawn하고 기존 것을 refine하므로 memory는 stream 길이가 아니라 scene extent에 비례해 성장합니다. 각 Gaussian은 VAE latent feature를 저장해 VAE re-encoding 없이 memory를 직접 DiT의 latent space로 render할 수 있습니다. 실험상 L3G-World는 state-of-the-art 생성 품질과 장시간 spatial consistency를 달성했고, 가장 효율적인 prior 3D-memory baseline 대비 primitive 수 최대 38.6배, memory update 최대 3.2배, memory rendering 최대 359배 향상해 **9 FPS 실시간 월드 생성**을 가능하게 했습니다.

## 핵심 내용

- memory는 stream 길이가 아니라 scene extent에 따라 성장한다.
- 각 Gaussian은 VAE latent feature를 저장해 latent space에서 직접 render한다.
- memory updater와 DiT가 자동회귀적으로 번갈아 동작한다.
- 장시간 spatial consistency에서 state-of-the-art를 달성했다.
- prior 대비 3D primitive 수 최대 38.6배 적다.
- memory update 최대 3.2배, rendering 최대 359배 빠르다.
- 9 FPS 실시간 생성이 가능하다.

## 상세

L3G는 VAE latent feature를 저장해 DiT latent space에 직접 render함으로써 VAE re-encoding을 피합니다. updater/DiT 교대 설계가 시간에 비례한 메모리 성장 없이 연속 생성을 지원합니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. memory updater와 DiT 훈련 세부는 원문을 함께 확인해야 합니다.

## SW 엔지니어와의 관련성

- 장시간 월드 생성에서 memory scaling을 scene extent로 바꾸는 설계가 핵심입니다.
- latent feature 저장으로 render 경로를 단순화할 수 있습니다.
- 실시간 인터랙티브 환경 구축에 활용할 수 있습니다.
