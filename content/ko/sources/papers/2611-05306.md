# You don't need long context: 긴 문맥이 항상 필요하지는 않다

**원문**: [arXiv:2611.05306](https://arxiv.org/abs/2611.05306) · **게시일**: 2026-11-03
**저자**: Peter Belcak, Saurav Muralidharan, Jindong Jiang, Yonggan Fu, Wonmin Byeon, Hanrong Ye, Ryan Angilly, Ali Taghibakhshi, Shih-Yang Liu, Siru Ouyang, Greg Heinrich, Pavlo Molchanov

## 개요

나중 토큰은 앞 토큰보다 생성 비용이 크고, frontier open-weight models에서는 비용 차이가 7배까지 이를 수 있다. 논문은 frequent compaction을 통해 frontier language models가 short context를 유지하면서도 broad long-horizon and long-input tasks에서 accuracy를 거의 잃지 않을 수 있음을 보인다. 더 나아가 long-horizon software engineering tasks에서 context마다 최대 한 action만 취해도 LLM performance가 collapse하지 않음을 보이고, 이를 바탕으로 semantic state space models(SSSMs) 개념을 제시한다. 결과는 모든 agentic workflow에서 long-context language models가 필요한지에 의문을 제기한다.

## 핵심 내용

- 뒤쪽 토큰 생성은 earlier 토큰보다 훨씬 비싸질 수 있다.
- 보고된 cost disparity는 frontier open-weight models에서 7배까지 이른다.
- 빈번한 compact는 accuracy loss를 최소화하면서 짧은 문맥을 유지한다.
- 주장은 diverse long-horizon and long-input tasks에서 테스트된다.
- software engineering tasks에서 context당 최대 한 action만 취해도 성능이 유지된다.
- 보고서는 extremely long context window의 보편적 필요성에 의문을 제기한다.

## 상세

논문은 31 pages, 8 figures의 technical report다. findings는 context maintenance through compaction이 long windows의 alternative일 수 있으나 accuracy는 state extraction quality, task type, evaluation setup에 의존한다. large source material의 exact preservation이 필요한 workflow에서는 long-context models가 여전히 중요하다.
