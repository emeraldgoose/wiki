# QCell: Recombining and Aligning Cell Queries for Overlapping Instance Segmentation

: Instance segmentation of overlapping cells in microscopy stays hard because semi-transparent structures produce **weak boundaries and mixed visual evidence** exactly in the overlap regions. Existing methods handle this with local regions of interest or shape priors, but lack **global reasoning across overlapping objects**. QCell is a query-based model with two components: an **instance recombination module** that decomposes and recombines query representations in latent space — letting the model reason about complete object structure under overlap — and a **contrastive query alignment objective** combining distinctive-instance feature learning with separation of overlapping queries. It also introduces a new **Organoid** benchmark for overlapping cell segmentation, and achieves **+2.2 AP and +2.7 AJI on ISBI2014**.

Why overlapping cells break instance segmentation: Instance segmentation assigns a distinct identity to every object. That assumption fails in microscopy for a specific physical reason: cells are semi-transparent. Where two cells overlap, the image contains:

- Weak boundaries — there is no sharp intensity edge to separate the objects
- Mixed visual evidence — the pixel values in the overlap region are a composite of both cells

Approach: QCell operates in query space, where each object is represented by a learned query vector.

 Instance recombination

The first component decomposes and recombines query representations in latent space. The intuition is that an overlapping object's identity is not present in any single local crop — it has to be assembled. By allowing the model to build up and tear down query representations, it can reason about the complete structure of an object that is partly occluded, rather than about whateve

Results and the Organoid benchmark: QCell outperforms state-of-the-art methods across multiple benchmarks, with +2.2 AP (average precision) and +2.7 AJI (Aggregate Jaccard Index) on ISBI2014.

The paper also contributes a new Organoid dataset benchmark specifically for overlapping cell segmentation. This matters beyond the paper: existing public benchmarks for this task are sparse, which is part of why the problem has been under-addressed relative to its difficulty. A benchmark makes the problem measurable.
