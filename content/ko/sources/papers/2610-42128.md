# DecisionRank: 의사결정 모델 리랭커를 위한 온폴리시 증류

**원문**: [arXiv:2610.42128](https://arxiv.org/abs/2610.42128) · **게시일**: 2026-10-30
**저자**: Yanran Wu, Dian Yu, Chongyang Bai, Jieyi Zhang, Rui Liu, Tianyi Chen, Shike Mei, Hang Cui, Frank Shyu, Sandeep Pandey, Luke Simon, Chunwei Liu, Xi Liu

## 개요

의사결정 모델은 선택이나 점수를 직접 예측하여 구조화된 작업을 처리하며, 자기회귀 디코딩 지연을 피한다. 그러나 생성형 언어 모델의 순위 지식을 의사결정 모델로 전달하는 것은 어렵다. 교사 모델은 문서 식별자 시퀀스의 순위 목록으로 선호를 표현하는 반면, 학생 모델은 첫 토큰 위치의 점수로 순위를 결정한다. DecisionRank는 아이템 공간 온폴리시 증류로 이 간격을 연결한다. 문서 점수를 정렬된 목록으로 구성해 학생의 롤아웃을 만들고, 생성 중 부하 불균형을 교정하며, 유효하지 않은 항목을 마스킹한다. 이를 통해 학생은 자기회귀 디코딩 없이도 교사의 순위 구조를 학습할 수 있다.

## 핵심 내용

- 의사결정 모델은 텍스트를 디코딩하지 않고 선택이나 점수를 직접 예측한다.
- 순위 작업에서 자기회귀 디코딩 지연을 피할 수 있다.
- 교사 모델은 문서 식별자 시퀀스 순위로 선호를 표현한다.
- 학생 모델은 첫 토큰 위치 점수로 순위를 결정한다.
- DecisionRank는 아이템 공간 온폴리시 증류로 두 모델을 연결한다.
- 정렬된 점수 기반 롤아웃과 유효 항목 처리를 활용한다.

## 상세

핵심 문제는 생성형 순위와 점수 기반 순위 사이의 표현 불일치이다. DecisionRank는 학생이 문서 시퀀스를 디코딩하게 하지 않고, 자신의 점수에서 순위를 유도한다. 아이템 공간에서 온폴리시 롤아웃을 구성함으로써 학습 과정은 학생의 실수에 노출되면서도 교사의 선호 구조를 학습한다. 부하 불균형과 유효하지 않은 항목에 대한 추가 처리는 증류 과정을 안정화한다. 결과는 교사 수준 순위 지식을 유지하면서 효율적인 의사결정 모델 리랭커를 지향한다.
