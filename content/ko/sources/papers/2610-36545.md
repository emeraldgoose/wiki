# FrameForge: 통합 이미지 생성을 위한 비디오 파운데이션 모델 prior 활용

**원문**: [arXiv:2610.36545](https://arxiv.org/abs/2610.36545) · **게시일**: 2026-10-27
**저자**: Yijing Lin, Zhendong Mao, Mengqi Huang, Yuxin Wang, Yongdong Zhang

## 개요

통합 조건부 이미지 생성은 시각 입력의 서로 다른 측면을 보존하면서 텍스트 지시에 따라 목표 이미지를 생성하는 단일 모델을 요구한다. 사전학습 비디오 모델은 시간에 걸친 시각 변환을 인코딩하기 때문에 유망한 기반이지만 기존 방법은 조건과 목표를 고정된 temporal 위치에 할당한다. FrameForge는 입력 적응형 가상 temporal 관계를 통해 조건부 생성을 모델링한다. Mixture of Temporal Experts(MoTE)는 조건에서 목표까지의 거리를 모델링하기 위해 가상 간격이 다른 temporal RoPE 전문가를 동적으로 선택하고, Chain of Temporal Reasoning(CoTR)은 잠재 중간 상태와 reasoning-bottleneck attention mask로 조건을 목표로 변환한다. 실험은 subject-driven 생성, canny-to-image 생성, 이미지 편집에서 강력한 결과를 보인다.

## 핵심 내용

- 통합 이미지 생성에 비디오 파운데이션 모델 prior를 활용한다.
- 조건과 목표 사이의 적응형 가상 temporal 관계를 모델링한다.
- 다양한 이미지 생성/편집 벤치마크에서 강력한 성능을 보인다.

## 상세

FrameForge는 MoTE와 CoTR을 결합하여 조건부 이미지 생성의 유연성과 성능을 개선한다.
