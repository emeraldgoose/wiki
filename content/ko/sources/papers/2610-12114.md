# LLM을 위한 범용 텍스트 교습

**Source**: Lu & Wang, arXiv, 2026-10-08

**핵심**: 표준 지식 증류(KD)는 강한 교사 모델을 모방하도록 학생 파라미터를 학습시켜, 증류된 지식을 특정 아키텍처와 체크포인트에 고정한다. 범용 텍스트 교습(UTT)은 대신 교사와 학생 사이의 *지식 격차*를 **텍스트 프라이머**(primer)—어떤 학생의 프롬프트 앞에 붙일 수 있는 자연어 문서—로 증류해, 파라미터 없는 교차 아키텍처 지식 전이를 가능하게 한다.

## 배경

지식 증류는 강한 교사의 역량을 약한 학생에게 전이한다. 그러나 거의 모든 KD 방법(로짓 매칭, 피처 매칭, 온-정책 증류)은 **학생 가중치 업데이트**를 요구한다. 이는 다음을 의미한다:
- 증류된 지식이 하나의 아키텍처/체크포인트에 종속
- API 전용 모델(GPT-4, Claude)을 학생으로 사용 불가
- 새 학생 모델마다 재증류 필요
- 증류된 지식이 불투명함(가중치에 내장)

## 범용 텍스트 교습(UTT)

UTT는 증류를 **텍스트 교습 문서**(프라이머) 합성으로 재정의한다. 이 문서는 교사가 알고 학생이 모르는 것을 포착한다.

**3단계 파이프라인**:
1. **격차 발견**: 시드 태스크 세트에서 교사와 학생에 질의; 차이가 나는 (질문, 교사_답변, 학생_답변) 삼중항 수집
2. **프라이머 합성**: 강한 LLM(교사 가능)을 사용해 격차 삼중항을 간결한 자연어 프라이머로 압축—설명, 휴리스틱, 예시, 경고
3. **배포**: 추론 시 어떤 학생의 프롬프트 앞에 프라이머를 붙임; 가중치 업데이트 없음

프라이머는 **모델 불가지론적**: 동일한 프라이머가 다른 학생 아키텍처, 크기, 심지어 API 전용 모델에서도 작동한다.

## 실험

**설정**: 교사 = GPT-4o; 학생 = LLaMA-3-8B, Qwen2.5-7B, Mistral-7B, Gemma-2-9B, API 전용(Claude 3 Haiku 프롬프트만).

**벤치마크**: MMLU, GSM8K, HumanEval, BBH, GPQA.

**결과**:
| 학생 | 바닐라 | +UTT 프라이머 | 향상 |
|---------|---------|-------------|------|
| LLaMA-3-8B | 62.1% | 68.4% | +6.3% |
| Qwen2.5-7B | 65.3% | 70.1% | +4.8% |
| Mistral-7B | 58.7% | 65.2% | +6.5% |
| Gemma-2-9B | 61.4% | 67.8% | +6.4% |
| Claude 3 Haiku (API) | 73.2% | 77.9% | +4.7% |

**교차 모델 전이**: GPT-4o→LLaMA-3-8B 격차에서 합성된 프라이머가 Qwen2.5-7B(+4.1%)와 Mistral-7B(+3.8%)도 개선해, 프라이머가 일반화 가능한 지식을 포착함을 보인다.

**효율성**: 프라이머 합성 비용 ~$2(일회성); 추론 오버헤드 = 프라이머 토큰(일반 500-2000). vs. 표준 KD: 학생당 수 시간 GPU 학습.

## 소프트웨어 엔지니어를 위한 시사점

UTT는 **LLM 애플리케이션을 위한 새로운 배포 패턴**을 가능하게 한다:
- **일회성 프라이머 합성** → **스택 내 모든 모델에서 재사용**
- **API 모델을 학생으로**: Claude Haiku / GPT-4o-mini를 파인튜닝 접근 없이 개선
- **해석 가능성**: 프라이머는 인간이 읽을 수 있음—전이된 지식 감사 가능
- **버전 관리**: 프라이머는 텍스트 파일; 코드처럼 diff, 리뷰, 롤백 가능

여러 모델(로컬 + API)을 유지하는 팀에게 UTT는 모델별 파인튜닝의 경량 대안을 제공한다.
