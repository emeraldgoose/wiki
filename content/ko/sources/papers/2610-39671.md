# 강화학습으로 대규모 언어 모델의 자기 학습을 유도하기

**원문**: [arXiv:2610.39671](https://arxiv.org/abs/2610.39671) · **게시일**: 2026-10-29

## 개요

대규모 언어 모델은 파라미터에 담긴 지식과 검색 증강 생성을 결합해 지식 집약 과제를 풀지만, 낯선 영역의 문제 해결에는 지식 획득과 추론이 빈틈없이 맞물려야 한다. 단순한 사실 검색·취합을 넘어, 미리 조립된 문맥에서 학습하는 것과도 다르다. 논문이 다루는 능력은 자기 학습이다. 과업이 진행되는 동안 긴 형태의 참고 자료에서 스스로 찾고 공부하고 적용하는 것으로, 시도한 유도 과정이 빠진 전제를 드러내고 새로 접한 정리가 풀이 전략을 다시 짜게 만드는 순환을 모델 자신이 운영해야 한다.

탐지 도구는 교과서 기반 수학 문제 풀이 과제다. 파이프라인이 고등 수학 교과서 158권을 장별 인덱스 텍스트로 파싱하고, 연습문제를 본문과 분리하며, 풀이를 모델이 볼 수 있는 자료에서 걷어낸다. 그 결과 참조 풀이 없이 증명을 만들어야 하는 문제 5,183개가 나온다. 모델은 본문을 탐색하고 관련 원리를 익혀 연습문제의 증명을 구성해야 한다. 사람의 교과서 공부 과정을 본뜬 BookNavigator 인터페이스가 목차 확인, 관련 절 탐색, 추론이 진행되는 동안의 본문 읽기를 지원하고, LLM 판정기가 최종 증명을 숨겨 둔 풀이와 비교해 채점한다.

학습은 GRPO에 두 가지 정밀한 보상을 얹은 형태다. 에이전트형 학습의 상반된 실패를 겨냥한다. 탐사 보너스는 도구 호출이 한 번 이상 성공한 정답 궤적에만 더해지며 양의 바닥값을 둔 코사인 일정으로 감쇠해, 문제 해결 능력이 좋아져도 교과서 접근 유인을 유지한다. 라운드별 도구 크레딧은 초기 정책의 얼린 복사본을 판정기로 써서 마지막 라운드가 아닌 각 라운드를 유용·중립·유해로 표시하고(참조 풀이는 보지 못한다), 궤적 어드밴티지를 토큰 가중 평균을 보존하면서 라운드별로 재분배한다.

결과는 프로토콜의 출발점을 뒤집는다. RL 전 자기 학습은 다섯 프로토콜 중 최하위다(전체 51.5%, No-Book 55.7%와 모든 고정 검색 기준선보다 낮음). RL 후에는 79.5%(+28.0%포인트)로 최강이 되고, RL로 학습한 No-Book보다 11.0%포인트, 최강 기준선 Top-k Sections보다 6.4%포인트 높으며, 미학습 교과서에서 85.2%, 미학습 교과에서 86.7%에 이른다. 이득은 출처 암기가 아니다. 출처 절과 인접 절들을 제거해도 74.6%가 남는다. 그리고 원래 추론 환경 그대로인 BrowseComp-Plus(+1.7%포인트, 기준선을 넘은 유일한 프로토콜)와 CL-bench(+2.3)로 전이된다.

## 핵심 내용

- 핵심 반전: 학습 전 자기 학습 프로토콜은 전체 51.5%로 No-Book 55.7%, Top-k Sections 62.2%보다 낮지만, 학습 후에는 79.5%와 최대 폭의 향상(+28.0%포인트)으로 모든 프로토콜을 앞선다.
- RL 후 고정 검색 기준선: No-Book 68.5, Top-k Sections 73.1, Long-Context 72.2, Oracle Section 71.0으로 모두 자기 학습의 79.5%에 못 미친다.
- 영역 외 일반화도 유지된다. 미학습 교과서 85.2%(최강 기준선 대비 +4.2), 미학습 교과 86.7%(+5.4)다.
- 이득은 암기가 아니다. RL은 도구 없는 추론도 강화한다(No-Book 55.7%에서 71.7%로). 출처 절과 양옆 네 절을 제거하면 4.9%포인트만 떨어지고(79.5%에서 74.6%), 같은 교과의 다른 교과서로 바꾸면 75.2%, 출처 밖 절 제거 대조군에서는 79.8%다.
- 탐사 보너스 설계: 도구 호출이 한 번 이상 성공한 정답 궤적에만 부여하고, 양의 바닥값이 있는 코사인 일정으로 계수를 감쇠시켜 초기 탐사는 강하게, 후기에는 작은 교과서 접근 유인을 남긴다.
- 도구 크레딧 설계: 초기 정책의 얼린 복사본이 각 라운드를 유용(관련 신규 정보 획득, 미해결 조건 명확화, 의미 있는 탐색 단서), 중립, 유해(명백히 중복·무관한 검색, 실패 요청의 근거 없는 반복, 프로토콜 위반)로 판정하고, 라운드 어드밴티지는 A + 알파·절대값(A)·(c − c바) 형태로 비마스크 토큰에 재분배한다.
- 절제 실험은 두 보상의 보완성을 보인다. 정답만 보상한 RL은 탐사를 무너뜨리면서(도구 사용 궤적 36.9%에서 6.7%, 호출 1.5에서 0.3회) 그래도 74.9%에 이른다. 도구 크레딧은 영역 내 +3.3을 더하지만 영역 외는 거의 움직이지 않고, 탐사 보너스는 도구 사용을 79.9%로 되살리며 영역 외 +2.0·+2.9를 더한다. 결합하면 모든 분할이 정점이다(ID-Book 65.5, OOD-Book 85.2, OOD-Subject 86.7, 전체 79.5).
- 과업 간 전이는 선택적이지만 실재한다. BrowseComp-Plus는 50.2에서 51.9로(+1.7, 나머지 RL 프로토콜은 모두 기준치 하회, No-Book은 −1.6), CL-bench는 14.8에서 17.1로(+2.3) 오른다. 상승은 도메인 지식 추론(+4.5)과 경험적 발견·시뮬레이션(+5.0)이 이끌고 절차적 과업 수행은 0.6 후퇴한다.
- 전이 측정은 각 벤치마크의 원래 설정(BrowseComp-Plus는 BM25 검색, CL-bench는 문맥 전용 생성)에서 이뤄졌으므로, 이득은 BookNavigator 인터페이스가 아니라 학습된 전략에서 나온다.

## 세부 사항

- 데이터 구축: 고등 수학 교과서 158권을 장별 인덱스로 파싱해 문제 5,183개를 만들고, 연습문제를 본문과 분리하며 풀이를 모델 가시 자료에서 제거한다. 판정기가 숨겨진 참조 풀이와 최종 증명을 비교해 채점한다.
- BookNavigator는 한 라운드 안에서 목차 확인, 관련 절 탐색, 본문 읽기의 세 가지 학습 행동을 지원하고, 정책은 교과서 학습과 문제 풀이를 번갈아 수행한다.
- 도구 판정기는 참조 풀이와 최종 정오 판정을 받지 못하고, 마지막 라운드는 교과서 접근이 없으므로 중립으로 고정된다. 판정기가 초기 정책의 얼린 복사본이므로 도구 크레딧의 영역 내 +3.3%포인트는 더 강한 모델 없이 얻은 것이다.
- 평가 분할: ID-Book(학습 교과서의 홀드아웃 문제), OOD-Book(미학습 교과서), OOD-Subject(미학습 교과)이며, 자기 학습의 분할별 향상은 +31.5, +20.0, +29.9%포인트다.
- 기반 모델은 Intern-S2-Preview-35B이고, 정책 최적화는 GRPO에 탐사 보너스와 라운드별 크레딧을 얹으며, 재분배 강도 알파가 라운드 품질이 토큰별 어드밴티지를 옮기는 정도를 조절한다.
- 결합 보상은 도구 호출 빈도를 최대화하지 않으면서 일반화를 높인다. 탐사 보너스 변형의 과업당 평균 호출은 5.9회로 정답 전용 RL의 0.3회보다 많지만 자기 학습 전체의 최고 점수는 호출 수가 아니라 탐사 유인과 과정 수준 크레딧의 결합에서 나온다.
