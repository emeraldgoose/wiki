# SketchDirector: 에이전틱 layout reasoning과 detail refinement로 complex scene sketching

**원문**: [arXiv:2610.41260](https://arxiv.org/abs/2610.41260) · **게시일**: 2026-10-27
**저자**: Yiqi Liang, Xiaodong Cun

## 개요

기존 sketch generation 방법은 image guidance에 의존하고 individual object나 simplified scene에 largely limited되어 text-guided complex scene sketching은 underexplored다. SketchDirector는 human sketching workflow를 mimicking하고 automatic multi-concept scene sketch를 text에서 생성하는 agentic framework다.

text description을 받아 coarse structural guide를 생성한 뒤 object layout과 arrangement를 reasoning한다. detail refinement stage는 diffusion prior에서 scene sketch를 distill하는 structural consistency challenge를 개선하며, object curve segment를 optimization unit으로 treat한다.

## 핵심 내용

- individual-object sketching이 아닌 complex scene sketching from text를 target으로 한다.
- iterative human sketch creation을 mimic하는 agentic workflow를 사용한다.
- object layout reasoning 전에 coarse structural guide를 생성한다.
- detail을 refine하여 structural consistency를 improve한다.
- holistic image뿐 아니라 multi-concept scene composition을 evaluate한다.

## 상세

traditional automatic method는 scene sketch를 indivisible entity로 treat하여 local edit을 어렵게 한다. real sketching은 iterative하며 artist는 element를 revise, group, rearrange하고 goal에 맞게 refinement를 adapt한다.

SketchDirector는 layout reasoning과 curve segment detail refinement를 combine하여 이 flexibility를 automatic generation에 가져오려 한다. 이를 통해 scene 내 여러 concept의 structural relationship을 보존하는 것이 목표다.
