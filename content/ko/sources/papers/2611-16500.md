# EvenVLM: 에벤어용 텍스트·멀티모달 데이터셋과 시각-언어 파인튜닝

**원문**: [arXiv:2611.16500](https://arxiv.org/abs/2611.16500) · **게시일**: 2026-11-12
**저자**: Daniil Makovetskii, Ivan Bondarenko

## 개요

에벤어(라무트어)는 시베리아의 마가단·캄차카·사하 지역에서 에벤 정체성을 가진 19,900명 가운데 약 6,800명이 쓰는 북퉁구스어다. 원어민이 급감하고 세대 간 전승이 끊겨 소멸 위기 언어로 분류되며, NLP 연구에서는 거의 다뤄지지 않았다. 노보시비르스크 국립대학교 저자 두 명은 이 언어를 위한 최초의 텍스트·멀티모달(VQA) 데이터셋 EvenVLM과, 저자원 교착어에 시각-언어 모델을 적응시키는 재현 가능한 전체 파이프라인을 발표했다. 이 작업은 ORACLE 워크숍의 취지에도 부합한다. 러시아어 번역을 거치지 않고 에벤어 자체로 평가 도구를 제공해 원주민 공동체가 모델 출력을 모국어로 검증할 수 있게 한다.

데이터셋은 사전·회화집 소스에서 GPT-4o Mini 기반 파싱으로 뽑아낸 구조화된 에벤어-러시아어 엔트리 50,521개에서 시작해 번역·문법·독해·의미 분류에 걸친 107,543개 학습 예시로 합성 확장된다. 멀티모달 세트는 이미지 189장에 이중 언어 주석 477개를 더해 1,908개 VQA 예시를 만든다.

표준 토크나이저는 저자원 교착어 단어를 지나치게 조각내므로, 저자들은 3단계 확장으로 Qwen 토크나이저를 고친다. 에벤어 고유 특수 문자(ӈ, ө, ӫ) 추가, 화이트리스트 어휘와 BPE 병합, 특수 문자 조합이 그 단계다. 단어당 평균 토큰 수는 4.99에서 3.64로 27% 줄었다.

## 핵심 내용

- 데이터셋 규모: 사전·회화집에서 나온 에벤어-러시아어 엔트리 50,521개를 4개 과제군의 107,543개 합성 학습 예시로 확장하고, 이미지 189장·이중 언어 주석 477개에서 1,908개 VQA 예시를 만들었다. 에벤어에는 이런 자원이 처음이다.
- 토크나이저 확장 알고리즘(특수 문자 → 화이트리스트+BPE 병합 → 특수 문자 조합)은 단어당 평균 토큰 수를 27% 줄인다(4.99 → 3.64). 에벤어 교착 형태론의 조각화를 직접 겨냥한다.
- Qwen3-VL-4B(4.4B 파라미터 VLM) 2단계 LoRA 파인튜닝: 1단계는 학습 파라미터 0.53%(rank 32)로 텍스트 과제를 적응시키고, 2단계는 시각 인코더를 동결한 채 rank 64로 VQA를 파인튜닝한다.
- 최고 구성 결과: 텍스트 벤치마크에서 완전 일치 11.4%, 가중 점수 13.6, 문장 번역 chrF 0.1283, VQA 정확도 65%. 베이스 모델과 텍스트 전용 파인튜닝의 0%에서 크게 올라간 수치다.
- 데이터셋·평가 벤치마크·학습 파이프라인 전부가 공개로 배포되고 모델 가중치는 게재 승인 시 공개 예정이며, 파이프라인은 다른 저자원 교착어로 옮겨 가도록 설계됐다.

## 상세

논문은 저자원 언어용 멀티모달 모델 조사를 배경에 깔고 출발한다. 해당 조사는 화자 1만 명 미만 언어에 VLM을 적용한 논문이 10편 미만임을 확인했다. 본문은 에벤어 언어 프로필과 소스 데이터, 추출 파이프라인, 템플릿 기반 데이터 합성, 토크나이저 확장 알고리즘과 결과, LoRA 구성과 학습 동력학을 포함한 두 학습 단계를 다룬다. 평가는 지표가 명시된 벤치마크 스위트, 범주별 VQA 결과, 번역·분류·VQA의 정성 관찰로 이어지며 오류 분석으로 마무리된다. 저자들은 데이터셋·적응·평가라는 모든 첫걸음이 에벤어를 기록·보존·지원하는 데 가치 있다고 보고, 이 파이프라인을 문화적으로 착지한 시각-언어 모델 다국어 평가의 템플릿으로 제시한다. 이 문서는 HF 등록 v1(2026년 11월 12일)을 다룬다.
