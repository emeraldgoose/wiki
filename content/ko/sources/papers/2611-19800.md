# Multi-Branch Transformer: 병렬 브랜치 트랜스포머

**Source**: [arXiv](https://arxiv.org/abs/2611.19800)
**게시일**: 2026-11-15

## Overview

Transformer는 보통 블록을 넓히거나 더 깊게 쌓아 스케일링한다. 이 논문은 이를 보완하는 축으로 브랜칭 — 전체 Transformer 블록의 병렬 구성 — 을 탐구한다. Multi-Branch Transformer(MBT)는 입력을 공유 초기 계층으로 처리하고, 독립적으로 파라미터화된 순차 블록 브랜치들을 병렬 실행한 뒤, 출력을 융합하여 공유 최종 계층으로 전달한다. 세 변형(Wide-Shallow: 블록 너비 유지, Narrow-Deep: 순차 깊이 유지, Balanced: 중간 절충)을 동일 학습 연산량에서 연구한다.

네 개의 MoE 스케일(총 0.8B–2.1B 파라미터) 통제된 사전학습 실험 전반에서, 2-브랜치 Wide-Shallow MBT는 동일 파라미터·연산량 예산의 순차 Transformer를 일관되게 능가하며, Balanced MBT는 그보다 더 향상된다. 브랜치를 2→3→4개로 늘려도 품질이 유지된다. 긴 컨텍스트 추론을 위해 Joint-KV는 각 깊이의 브랜치 표현으로 공유 KV 캐시를 구성하여 전체 KV 캐시 저장량을 최대 34% 줄이고, H200 한 대에서 디코딩 처리량을 최대 51.4% 높인다.

## Key points

- 2-브랜치 Wide-Shallow MBT는 네 스케일(0.8B–2.1B) 모두에서 동일 파라미터·연산량의 순차 Transformer를 능가한다.
- Balanced MBT는 Wide-Shallow보다 추가로 향상되며, 브랜치를 2→3–4개로 늘려도 품질이 유지된다.
- Joint-KV(브랜치 표현 기반 공유 KV 캐시)는 전체 KV 캐시 저장량을 최대 34% 줄이고, H200 한 대에서 디코딩 처리량을 최대 51.4% 높인다.
- 적합된 스케일링 곡선은 표준 Transformer가 최종 레시피의 검증 손실을 따라잡으려면 최대 1.26배의 학습 본체 연산이 필요함을 시사한다.
- 제거 실험: 이득은 너비/깊이 조정보다 크며, Joint-KV는 효과적인 KV 공유 전략이고, 융합 함수에 강건하며, 브랜치는 중간 계층에서 가장 효과적이다.

## Details

- 아키텍처: 공유 초기 계층 → 독립 파라미터화된 순차 블록 브랜치 병렬 실행 → 출력 융합 → 공유 최종 계층; Wide-Shallow, Narrow-Deep, Balanced 변형으로 평가.
- Joint-KV: 각 깊이의 브랜치 표현에서 공유 KV 캐시 구성; 브랜치 그룹핑과 공유 캐시 재사용을 활용하는 추론 엔진으로 지원.
- 평가: 0.8B/1.xB/2.1B 래더 네 MoE 스케일의 통제된 사전학습, H200 한 대에서 검증 perplexity 대 디코딩 처리량(16K 입력 토큰, 64 요청); 2-브랜치·다중 브랜치 MBT 및 Joint-KV 구성에 대한 스케일링 법칙 적합.
- 제거 실험: 너비/깊이 대조군, 브랜치 간 KV 공유 vs Independent-KV(캐시 매칭), 융합 메커니즘, 브랜치 배치(중간 계층 최적).
- 유의점: MoE 사전학습(≤2.1B)에서의 실험이며, 추론 이득은 단일 H200의 지정 벤치마크 프로토콜 기준; 다운스트림 평가는 제한적(부록 A.3).
