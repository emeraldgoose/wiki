# Multics: 계층적 통신을 갖춘 생성형 다중 플레이어 월드 모델

출처: Kaiyi Huang 외 8인, arXiv:2610.17201, 2026-10-12.

**핵심 요약**: 다중 플레이어 상호작용 월드 모델은 여러 플레이어 관점에서 공유 환경을 시뮬레이션하는 것을 목표로 하지만, 플레이어가 늘어나도 강건한 생성을 유지하기 어렵습니다. 완전 연결 통신(Solaris 등)은 플레이어 수에 따라 **이차 어텐션 비용**이 들고, 중앙 집중식 접근(γ-World 등)은 공유 전역 표현에서 **무관한 사건 간 간섭**을 겪습니다. **Multics**는 정보 교환을 **플레이어·그룹·전역** 수준으로 구조화한 다중 플레이어 비디오 생성 프레임워크입니다.

## 계층적 통신

계층 구조는 **그룹 토큰**을 자기 어텐션에 도입해 지역적으로 관련된 플레이어 정보를 집계하는 중간 표현으로 씁니다. 그룹 토큰은 전역 토큰과 연결되어 그룹 간 통신을 하고, 계층 토폴로지가 무관한 지역 사건의 직접 혼합을 제한합니다. 그룹 토큰 파라미터는 그룹 슬롯 간 공유되어, 그룹별 새 파라미터 없이 가변 플레이어 수를 수용합니다. 최근 카메라 궤적에 기반한 **예산 제약 동적 그룹핑**도 제안해 관련 플레이어를 적응적으로 묶고 불필요한 통신을 줄입니다.

## 결과

4·6인 설정에서 최신 성능을 냈고, 플레이어 간 일관성, 플레이어별 행동·카메라 제어성, 간섭 강건성이 개선됐습니다. 4인 훈련에서 **6·8·10인 추론으로 재훈련 없이** 일반화되고, 완전 연결 통신보다 자기 어텐션 연산을 줄입니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 동적 그룹핑이 카메라 궤적에 의존하므로 궤적이 불안정하거나 급격히 변하는 장면에서 성능이 달라질 수 있습니다. 10인 이상 확장과 장기 일관성은 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 다중 사용자·다중 시점 생성에서 모든 참가자를 완전 연결하면 비용이 급증합니다. 그룹 토큰으로 지역 정보를 먼저 집계하세요.
- 그룹 파라미터를 공유하면 플레이어 수가 바뀌어도 모델을 다시 훈련할 필요가 없습니다.
- 관련 없는 사건의 간섭을 줄이려면 전역 표현에 모든 정보를 섞지 말고 계층 토폴로지를 두세요.
