# EmoReward: 정서적 비디오 생성 RL을 위한 자기 진화 reward calibration

**원문**: [arXiv:2611.06518](https://arxiv.org/abs/2611.06518) · **게시일**: 2026-11-04
**저자**: Mingzhe Zheng, Yue Wu, Jing Tan, Chang Zou, Dengyang Jiang, Zeyue Tian, Xuanhua He, Ryan Xu, Yunyang Ge, Sihui Ji, Yunlong Lin, Kaihang Pan, Hongru Yan, Sixiang Chen, Dianyi Wang, Julian Zhang, Weijie Kong, Changlin Li, Lanqing Guo, Zhao Zhong, Qifeng Chen, Harry Yang

## 개요

GRPO는 code/math-like verifiable domains에서 generative model post-training을 advanced했지만, video quality, 특히 emotional expression 평가는 subjective aesthetics에 의존하고 uniquely correct target이 없다. existing approaches는 visual quality/motion quality/text alignment용 fixed rewards에 의존해 emotional intent를 poor capture하고 reward hacking을 invite할 수 있으며, RLHF는 scale 어렵고 individual aesthetic differences가 narrative contexts across facial/body motion/chromatic cue calibration을 어렵게 한다. 논문은 EmoReward를 introduce한다: self-evolving training mechanism으로 actual training run 중 collected reward traces에서 evidence reliability를 distill해 subsequent training에서 어떤 emotional evidence를 trust하고 얼마나 weight할지 adaptive하게 guide multi-reward weight allocation을 수행한다. EmoReward는 emotional prompt에서 specific grounding cues를 first plan하고 act stage에서 heterogeneous signal primitives로 generated video를 score한다. Reflective Reward Gating은 phase/face confidence/conflict/subtlety instance-level gates로 contributions를 calibrate하고 active set renormalize로 sample fused reward를 produce한다. RewardMemory는 finished training run 내 emotional regimes에서 rollout scores/outcomes를 이용해 각 primitive reliability를 estimate하고 reward model을 update하지 않고 next training run fusion weights를 calibrate하는 bounded multipliers를 fix한다. HunyuanVideo 1.5 experiments에서 multiple RL algorithms improvements와 SAGE-GRPO under 다른 agentic reward methods 비교를 보이며, SD 3.5/FLUX transfer experiments/ablations는 adaptive reward calibration for visual generation을 further support한다.

## 핵심 내용

- GRPO는 verifiable reward에 강하지만 비디오/정서 품질에는 정답이 유일하지 않다.
- fixed rewards는 emotional intent capture가 약하고 reward hacking 가능.
- EmoReward는 reward traces에서 reliability를 distill해 subsequent run weights를 적응.
- grounding cues와 heterogeneous primitives, reflective gating, renormalization으로 fused reward.
- RewardMemory가 bounded multipliers를 produce하며 SD 3.5/FLUX transfer를 support.

## 상세

실험은 multiple RL algorithms, agentic reward comparisons, ablations/transfer를 전계한다. reward tensors/reliability-memory specifics는 연결된 원문을 참고한다.
