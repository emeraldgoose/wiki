# ViDecide: 비디오 확산 모델이 단계별로 추론하고 계획하도록 가르치는 법

**원문**: [arXiv:2611.26389](https://arxiv.org/abs/2611.26389) · **게시일**: 2026-11-19 (v1)
**저자**: Kaiwen Zhang, Yiming Gao, Zeqi Xiao, Xintao Wang, Pengfei Wan, Kun Gai, Xingang Pan

## 개요

선도적인 비디오 생성 모델은 사실적인 클립을 만들지만, 대규모 추론 데이터나 확산 RL로 학습한 후에도 다단계 추론과 계획에서 물리·논리 제약을 자주 위반한다. ViDecide는이것를 기존 학습 패러다임이 해법을 고정 길이 클립이 아니라 결정의 연쇄로 다루지 않기 때문으로 본다. 대신 비디오 확산 모델이 상태 전이를 인과적으로 예측하도록 학습시킨다. 생성되는 각 프레임이 이전 시각 상태에 의존해 생성 순서가 결정의 인과 순서와 align되도록 한다(규칙 기반 게임에는 주로 단계당 K=1 상태, 조작처럼 상태가 오래 지속되는 작업에는 더 큰 K). 또한 학습된 시각적 EOS 토큰을 통해 언제 멈출지 결정하게 한다. 언어 모델의 EOS와유사하게 작업 완료 후에 생성되며 별도 종료 예측기 없이 비디오 생성 목적식 자체로 학습된다.

결정 중심 학습 스케줄은 플로 매칭 학습이 작업 관련 상태 전이와 배경을 구분하게 한다. 그리고 교정 미세조정(Corrective Fine-tuning, CFT)은 실패한 결정의 노이즈를 모델 자신의 성공적 연속에 매핑해 교정하므로 정책 경사 최적화 없이 안정적으로 향상된다. 추상 게임, 계획 작업, 새로운 다단계 로봇 계획 벤치마크(RoboTwin 2.0 양팔 블록 계획 RoboTwin-Plan)에서 ViDecide는 평균 엄격 성공률 83.8%를 달성해,표준 미세조정 23.3%, 기존 최고 방법 67.8%를 크게 앞선다. RoboTwin-Plan에서는 78.0%로 종전 최고 63.9%를 앞섰고, 결정 중심 스케줄만으로도 Wan2.2 기본 스케줄의 33.3%를 73.9%로 끌어올렸다. 학습 범위를 넘어 더 큰 퍼즐과 본 적 없는 레이아웃에도 일반화되어, 암기된 해법이 아니라전이 가능한 규칙을 배운다는 것을 시사한다.

## 핵심 내용

- 결정 중심 공식화: 해법은 고정 길이 클립이 아니라 결정의 연쇄이며, 비디오 확산 모델은 상태 전이를 인과 순서로 생성한다(결정 단계당 K 프레임).
- 학습된 시각적 EOS를 통한 적응형 종료: 작업 완료 후 생성되며 비디오 목적식 자체로 학습되고 별도 종료 예측기가 필요 없다.
- 결정 중심 학습 스케줄: 플로 매칭이 작업 관련 전이에 집중하게 하며, RoboTwin-Plan 로봇 비디오에서 성공률을 33.3%(Wan2.2 기본)에서 73.9%로 올린다.
- CFT: 자기 회귀 비디오 확산을 위한 사후 학습으로, 실패한 결정의 노이즈를 모델 자신의 성공적 연속에 매핑해 정책 경사 RL 없이 안정적 이득.
- 네 테스트스트 평균 엄격 성공률 83.8% vs표준 미세조정 23.3%, 최고 기존 방법 67.8%. RoboTwin-Plan(RoboTwin 2.0 양팔 다단계 블록 계획): 78.0% vs 63.9%.
- 더 큰 퍼즐과 미학습 레이아웃으로 일반화되어 학습된전이 가능 규칙을 시사한다.

## 상세

프레임워크는 세 구성 요소를 갖는다. 인과적 생성(각 프레임이 이전 시각 상태에 조건화), 적응형 종료(시각적 EOS), 결정 중심 스케줄. CFT는 자기 회귀 비디오 확산의 사후 학습 단계로 적용되며, 실패한 결정의 교정 목표로 모델 자신의 성공적 연속을 사용해 정책 경사 최적화의 불안정성을 피한다. 실험은 추상 게임, 계획 작업, RoboTwin-Plan을 다루며 엄격 성공률을 지표로 하고, 더 큰 퍼즐과 미학습 레이아웃에서 일반화를 조사한다. 베이스라인은표준 지도 미세조정과 최고 기존 확산 RL/추론 방법이다.
