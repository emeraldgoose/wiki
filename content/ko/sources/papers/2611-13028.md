# GTAGym: 평가와 강화학습을 위한 실제 AAA 게임 과업 환경

**원문**: [arXiv:2611.13028](https://arxiv.org/abs/2611.13028) · **게시일**: 2026-11-09
**저자**: Jiajun Chen, Shicheng Fang, Jiahao Lu, Yuxin Wang, Xipeng Qiu

## 개요

상용 게임에서 파운데이션 모델 에이전트를 평가하면 현실성과 검증 가능성 사이에서 균형을 잡아야 한다. MineDojo 같은 샌드박스 플랫폼은 프로그램적 결과 검증을 제공하지만 상용 게임의 복잡도가 없고, Cradle·SIMA·Lumine·OctoGTA 같은 상용 3D 세계 연구는 현실성을 얻는 대신 OCR이나 사람 판정으로 점수를 매겨야 했다. 푸단대학교와 상해혁신연구원의 GTAGym은 GTA V에서 이 간극을 메운다. 저자들은 메인 스토리 미션 75개를 목표·상호작용 순서·완료 제약·동적 개체 행동으로 규정된 하위 과업으로 수작업 분해하고, 이를 Babylon.js 3D 환경에서 엔진 상태를 직접 확인해 재구성한다. 여기에 병렬 평가용 공통 스크린샷-행동 웹 서버와, 사용자 지정 범위에서 과업 파라미터를 표본화해 보상·종료 신호가 자동으로 붙은 강화학습 환경을 일괄 생성하는 템플릿 기반 생성기가 함께 제공된다.

평가 스위트 GTAVBench는 도로·도보·수상·수직·항공 항해와 실내, 추종·차단·회피의 아홉 카테고리 103개 온라인 3D 과업에, 원본 게임 플레이 이미지로 만든 사격·저격 47개 과업을 더해 총 150개 과업으로 구성된다. 두 번째 트랙 GTAVBench-AGI는 과업 지시를 첫 스크린샷 안에만 보여주고(실제 플레이처럼 게임 화면에서 목표를 읽어야 한다) 자동 맥락 압축을 갖춘 Codex 하네스 아래에서 에이전트를 구동한다. 반면 기존 방식은 텍스트 지시와 상한이 있는 스크린샷 이력을 JSON 행동 루프에 넣는다.

결과는 뚜렷한 능력 격차를 보여준다. 여섯 모델(GPT-6-Astra, GPT-6.1-Sol, DeepSeek-V4.1-Flash-1017, GLM-5.3-Flash, Kimi-K3, Qwen3.8-27B)을 두 프로토콜로 평가한 결과, 최고 구성(GPT-6-Astra + Codex)도 전체 정확도 70.9%로 사람 평균 89.8%보다 18.9%p 낮았다. 항공 항해는 모든 모델이 0.0%(사람 45.8%)였고, 차단과 회피는 GPT 계열을 제외하면 낮은 수준에 머물렀다. AGI 방식은 여섯 모델 모두에서 0.9-10.0%p 정확도를 올려주었는데, 항해에서 개선이 가장 일관됐다.

논문은 평가를 넘어 강화학습 루프도 처음부터 끝까지 시연한다. 생성한 도보 항해 인스턴스 50개로 Codex 하네스 안에서 LoRA(랭크 32) + GRPO로 Qwen3.8-27B를 학습하자 홀드아웃 도보 과업에서 54.2%에서 72.9%로 올랐고, 학습에 쓰이지 않은 카테고리(수직 46.7%→73.3%, 수상 57.6%→69.7%)와 네이티브 GTA V 미션 100개(기록 성공률 15%→23%)로까지 전이됐다.

## 핵심 내용

- 과업 스위트: 150개 = 온라인 3D 103개(도로 20, 도보 16, 수상 11, 수직 5, 항공 8, 실내 8, 추종 6, 차단 13, 회피 16) + 이미지 기반 47개(사격 24, 저격 23). 워크스루 영상에서 분해한 GTA V 메인 스토리 미션 75개에서 유래한다.
- 과업 구성: 목표·상호작용 순서·완료 제약·개체 행동을 수작업으로 규정하고, 미니맵에 직접 경로를 그려 환경 도시 기하학에서 비슷한 회전 수의 경로로 재구성한다. 사격은 플레이 프레임에 피격 영역을 주석하고, 저격은 배율에 따라 렌더링이 달라지는 비조준/조준 뷰를 직접 캡처해 만든다.
- 모든 하위 과업은 초기 상태·지시·예산·이동 방식/높이/목표 거리/상호작용 사건을 검사하는 실행 가능한 성공·실패 술어를 갖는 템플릿으로 인스턴스화되고, 추적자·회피자 컨트롤러가 추종·차단·회피 역학을 구현한다.
- 상호작용: 키보드-마우스 기반 스크린샷-행동 폐루프. 기본적으로 각 키는 (0, 1초]의 유지 시간을 갖고 동시 실행되며, 추론 중에는 시뮬레이션이 일시정지한다. JSON 프로토콜의 온라인 이력은 10쌍으로 상한이 있고 초과 시 가장 오래된 5쌍을 버린다.
- GTAVBench-AGI: 지시를 첫 스크린샷에만 담고, 이력이 늘면 Codex 하네스가 맥락을 자동 압축한다.
- 주요 결과(과업 정확도): GPT-6-Astra 66.4/70.9%, GPT-6.1-Sol 66.0/66.9%, GLM-5.3-Flash 38.9/41.8%, DeepSeek-V4.1-Flash-1017 33.8/38.2%, Qwen3.8-27B 24.2/34.2%, Kimi-K3 28.4/33.1%(각각 GTAVBench/AGI). 사람 평균 89.8%.
- 동적 조종이 병목: 항공 항해는 두 프로토콜 모두에서 전 모델 0.0%, 차단은 0-41.0%(GPT-Astra만 16% 넘김), 회피는 8.3-25.0%인 반면, 도보·실내·수직 항해는 GPT 모델이 최대 100%로 포화에 가깝다.
- 효율: GPT 모델이 가장 좋은 정확도-토큰 균형을 유지하고, JSON 프로토콜에서 DeepSeek는 Astra의 약 26배 출력 토큰을 쓰면서도 성공률이 따라가지 못했다.
- 강화학습: Qwen3.8-27B를 대상으로 GRPO + LoRA(랭크 32, α 64, 학습률 1e-6), 업데이트당 8 롤아웃 × 4 과업. 보상은 성공 여부에 실패 롤아웃에 정규화된 이동 가능 거리 진행도 0.3을 더하고 100라운드 초과 시 0.1을 감점한다. 학습용 도보 인스턴스 50개는 벤치마크 경로와 공간적으로 분리됐다.
- 강화학습 성과: 도보(ID) 54.2%→72.9%, 전체 34.2%→38.9%, OOD 카테고리 31.8%→34.8%(수직 46.7%→73.3%, 수상 57.6%→69.7%). 도로는 3.3% 그대로, 항공과 차단은 0% 유지, 사격은 73.6%→68.1%로 후퇴. 네이티브 GTA V 전이는 100개 미션에서 15%→23%.
- 실패 유형 4가지: (1) 조향 시점 실수 — 회전을 인지하고도 너무 늦게 혹은 너무 오래 조향해 도로를 이탈, (2) 하강 수정 지연 — 활공장 도달 후 자세·속도·하강을 조율하지 못해 추락, (3) 차단 유지 실패 — 충돌로 늦춘 뒤 감속하지 않고 가속을 이어가 목표가 재가동, (4) 벽 갇힘 — 건물에 부딪힌 뒤 전진 스로틀과 조향을 계속 반복하다 뒤로 빠짐. 모두 움직임 예측과 제어 전략 전환의 어려움이다.
- 오류 복구: 6개 모델 900개 궤적 중 565개에서 첫 오류를 지각/계획/보정/조절 네 범주로 주석한 결과, 보정과 조절이 63.2%로 지배적(폐루프 제어 병목). 10번 의사결정 안에 복구한 비율은 GPT-Astra 65.7%, GPT-Sol 49.3% vs 나머지 21.6-25.6%.
- 평가 설정 효과: 행동 시간 상한을 0.5초로 줄이면 정확도가 62.1%에서 66.3%로 오르지만(시각 피드백 증가) 평균 라운드 62.6→121.2, 입력 토큰 4.32M→11.20M로 늘어난다. 2초 상한은 60.5%로 하락, 행동의 66.6%가 1초를 초과했다. 추론 중 일시정지를 없애면 정확도가 22.3%p 하락해 39.8%가 되고 추종·차단·회피는 0이 되는 반면 도보·실내는 100% 유지 — 동적 상호작용에서 추론 지연이 병목이다.
- 산출물: 코드 github.com/ljbro/GTAGym, 데이터셋 huggingface.co/datasets/OpenMOSS-Team/GTAVBench. 재구성된 3D 환경은 공개된 GTA_SZ 프로젝트 위에 세워졌다.

## 세부 사항

### 과업 구성 파이프라인

미션 분해는 메인 스토리 75개 미션의 워크스루 영상 수집에서 시작한다. 각 하위 과업은 미션의 한 단계에 대응하며 목표·필요 상호작용 순서·완료 제약·개체 행동이 주석된다. Babylon.js 3D 환경은 과업별 상태 컨트롤러를 노출하고, 항해 경로는 원본 미니맵에 손으로 그려 환경 도시 기하학에서 회전 수가 비슷한 경로로 옮겨지며 과업이 요구하면 등반 표면과 착지 지역을 추가한다. 이미지 기반 과업은 병렬 파이프라인을 따른다. 템플릿 인스턴스화 단계에서 엔진 상태로 검사되는 실행 가능한 성공·실패 술어가 붙어 결과 검증에 사람이나 VLM 판정이 필요 없다.

### 평가 프로토콜과 모델

두 트랙은 과업 인스턴스·행동 인터페이스·채점 규칙을 공유하고 지시 제시와 맥락 관리만 다르다. GTAVBench는 스크린샷 기반 컴퓨터 사용 평가 방식을 따른다. 고정 시스템 프롬프트, 텍스트 지시, 10쌍으로 제한된 스크린샷-응답 이력, 어댑터가 검증하는 JSON 행동. GTAVBench-AGI는 지시를 첫 스크린샷에 넣고 이력 관리를 성장에 따라 맥락을 압축하는 Codex 하네스에 맡긴다. 에피소드는 성공·실패·예산 소진(항해/상호작용 300라운드, 총기 사용 20라운드)으로 끝나며 점수는 카테고리별과 150개 과업 미시평균으로 보고한다. 평가 모델은 GPT-6-Astra, GPT-6.1-Sol, DeepSeek-V4.1-Flash-1017, GLM-5.3-Flash, Kimi-K3, Qwen3.8-27B 여섯이고, 사람 기준선(평균 89.8%)은 11개 카테고리 전체를 커버한다.

### 주요 표를 넘어선 분석

궤적 검토에서 네 가지 반복 실패 기제가 확인됐고, 모두 움직임 예측과 제어 전략 전환의 어려움을 가리킨다. 900개 궤적의 첫 오류 주석은 지각이나 계획보다 보정·조절(63.2%)이 지배적임을 보여 폐루프 제어가 병목임을 시사하며, GPT 모델은 그런 오류를 10번 의사결정 안에 다른 모델(21.6-25.6%)보다 훨씬 자주 되돌린다(65.7%/49.3%). 하네스 비교에서는 압축된 긴 이력이 시도한 전략과 탐색한 영역을 기억하게 도와주지만, 잘못된 해석을 보존하거나 압축 시점에 목표가 표류하는 부작용도 있다(Kimi-K3가 옥상 목표를 주행 목표로 바꾼 사례, GLM-5.3-Flash가 뒤집힌 미니맵 마커를 끌고 간 사례). GPT-6.1-Sol + Codex로 진행한 타이밍 실험은 짧은 행동 상한이 라운드와 토큰 비용을 치르고 정확도를 올리는지 보여주고, 추론 중 일시정지를 제거하면 움직이는 표적 과업이 무너진다는 점에서 실시간 에이전트 성능을 추론-행동 주기가 과업의 대응 창 안에 들어오는지의 문제로 규정한다.
