# MedJev: 빠르고 효과적인 의료 영상 이해를 위한 System One 비전-언어 의사결정 모델

**Source**: [arXiv](https://arxiv.org/abs/2611.20992)
**게시일**: 2026-11-16

## Overview

의료 영상 이해를 위한 비전-언어 모델(VLM)은 대개 추론과 답변 토큰을 자기회귀적으로 생성하는 방식으로 동작한다. 이러한 생성 비용은 응답 길이에 비례해 커지고, 게다가 자유 형식 텍스트에서 답변을 파싱해야 하므로 지연 시간과 피할 수 있는 결정 오류가 발생한다. MedJev는 의료 영상, 질문, 후보 답변 집합을 하나의 멀티모달 순전파(forward pass)에서 곧바로 결정에 매핑하며, 자기회귀 디코딩을 전혀 사용하지 않는다. 속도를 위해 전체 비전 경로와 모든 비주얼 토큰은 유지한 채 상위 언어 레이어와 생성 출력 경로를 제거한다.

이 단축된 백본 위에서 의사결정 헤드는 사전학습된 query–key 매칭으로 각 후보를 채점하고, 경량 MLP 잔차(residual)로 그 점수를 보정한다. 사전학습된 매칭 구조와 작업 특화 비선형 판별을 결합한 것이다. Qwen3.5-4B를 기반으로 한 MedJev-4B는 네 가지 의료 영상 분류 및 시각 질의응답 벤치마크 각각에서 원래 모델보다 정확도와 속도를 모두 개선하며, 절대 정확도 7.93% 향상과 6.04배의 종단간 속도 향상을 보인다. 4B–9B 규모의 최신 범용·의료 VLM 20종과 비교해도 성능과 추론 속도 모두에서 최고 수준이며, 직접적인 멀티모달 의사결정이 빠르고 효과적인 의료 영상 이해로 가는 유효한 경로임을 시사한다. 코드: https://github.com/zfkarl/MedJev.

## Key points

- 벤치마크 향상: 네 벤치마크(HAM10000, PneumoniaMNIST, MedThinkVQA, PMC-VQA) 모두에서 가장 정확한 모델이며, 셋에서 가장 빠르고 평균으로도 가장 빠르다. 비전 인코더·커넥터·첫 언어 레이어를 공유하는 Qwen3.5-4B 대비 평균 정확도 7.93% 향상, 결정 지연 6.04배 단축.
- 생성 지연은 네 벤치마크에서 두 자릿수 규모로 차이난다. MedThinkVQA에서 Qwen3.5-9B는 사례당 20,947.7 ms를 쓰는 반면 MedJev-4B는 250.7 ms에 그친다. 자유 텍스트 실패(LLaVA-Med-v1.5-7B / LLaVA-1.6-Vicuna-7B의 컨텍스트 초과, HAM10000에서 파싱 불가능한 선택지 문자)는 예측이 후보 인덱스이므로 원천적으로 발생하지 않는다.
- 절제 실험: 32개 언어 레이어를 J=23으로 줄여도 정확도 손실이 없고(query–key 헤드에서 평균 68.31%→68.70%, 잔차 의사결정 헤드에서 68.93%→69.06%) 약 16 ms를 절약한다. QKH 단독 68.70%, 단순 MLP 채점기 68.83%, 제로 초기화 잔차 의사결정 헤드(RDH, 1.97M 파라미터 추가, QKH 대비 1.4 ms)가 최고 평균 69.06%를 기록.
- 통계적 유의성: 10,000회 페어드 부트스트랩 재표집 결과 HAM10000(+9.99%), MedThinkVQA(+15.56%), PMC-VQA(+4.73%)의 향상은 0을 벗어나지만 PneumoniaMNIST(+1.44%, 구간 [-0.80, 3.69])는 그렇지 않다. 불일치 분해(MedJev만 정답: PMC-VQA 5,615건, MedThinkVQA 221건; Qwen3.5-4B만 정답: 4,035건, 109건)는 향상이 실제 뒤집힌 결정에서 나옴을 보여준다.
- 견고성: 후보 순서를 세 시드로 섞어도 비가중 평균은 69.06%→68.10%로만 하락한다. 고정 레이블 어휘는 PneumoniaMNIST에서 손실이 없고 HAM10000에서 1.6% 손실에 그치는 반면, 자유 형식 선택지는 MedThinkVQA 13.1%, PMC-VQA 9.4%를 잃는다. t-SNE에서 학습 전 벤치마크별 마커 군집(군집 내/간 거리비 2.36)이 학습 후 단일 영역(비 1.36)으로 붕괴해 2–7개 답을 갖는 후보 집합을 하나의 헤드가 공유한다.
- 공개된 의사결정 모델(d1-3B, Visual Jev-4B, OmniMed-Jev-4B)을 네 벤치마크 평균에서 앞선다.

## Details

- 방법: 언어 측 깊이 축소는 사전학습 비전 경로와 커넥터를 그대로 유지한다. 의사결정 헤드는 결정 마커 위치를 읽고, 사전학습된 query–key 매칭으로 각 후보를 채점하며, 제로 초기화 MLP 잔차가 점수를 보정한다. 네 벤치마크의 학습 분할로 학습하고, 추론은 고정된 비주얼 예산의 단일 순전파이므로 모든 사례가 입력 창에 들어간다.
- 설정: 네 벤치마크 — HAM10000(피부경 영상, 7클래스), PneumoniaMNIST(흉부 X선), MedThinkVQA(다중 이미지 의료 추론 VQA), PMC-VQA(생의학 그림 VQA). 백본은 Qwen3.5-4B이며, 4B–9B 규모의 범용·의료 VLM 20종과 비교했다.
