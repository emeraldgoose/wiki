# CADMAGEDDON: 로컬 추론으로 고충실도 CAD 재구성하기

**Source**: [arXiv](https://arxiv.org/abs/2611.22563)
**게시일**: 2026-11-18

## Overview

CAD 실무자는 외부 서비스에 공유하고 싶지 않은 독점 부품을 자주 다룬다. 재구성을 사내로 가져오는 일도 단일 GPU 시스템과 현행 노트북에서 감당 가능한 컴퓨팅 자원 안이어야 한다. CADMAGEDDON은 메쉬로부터 편집 가능한 특징 기반 CAD 모델을 재구성하는 오픈소스 에이전트로, 엔지니어가 곧바로 편집할 수 있는 설계 의도(스케치, 돌출, 회전, 구멍)를 복원하며 로컬에서 실행된다. 이 방법은 복잡한 작업을 "무엇을 구성하고 무엇을 수정할지"에 대한 일련의 단순한 시각적 결정 사슬로 분해한다. 기하 도구가 정밀한 구성을 지원하므로 에이전트는 시각적 추론에 집중할 수 있다. FreeCAD와 통합되어 재구성 결과물을 실무자의 기존 CAD 워크플로로 가져온다. 코드: https://github.com/kulibinai/cadmageddon.

중형 Qwen3.8-27B 모델을 사용한 CADMAGEDDON은 주요 벤치마크 모두에서 재구성 품질 기준으로 프런티어 모델 기반 시스템을 포함한 선행 접근법을 능가한다.

## Key points

- 다섯 벤치마크 결과(Table 1): DeepCAD(>0.999 IoU), Fusion 360(0.993), MCB(0.933), BenchCAD-1000(0.999), CADENA-Bench(0.981)에서 최고 IoU·GMS와 최저 Chamfer distance를 달성. MCB IoU는 CADFather의 0.862에서 0.933으로, CADENA-Bench는 0.918에서 0.981로 상승; GMS(표면 유형 유사도)도 0.705→0.818(MCB), 0.800→0.909(CADENA-Bench) 상승.
- 실행 가능성: 기하가 없는 부품은 최대 0.67%; CADFit은 DeepCAD/Fusion 360/MCB 부품의 18.7–24.3%에서 실패.
- BenchCAD 리더보드(Table 2, 64³ 복셀 IoU, 1,000개 부품 서브셋): CADMAGEDDON(Qwen3.8-27B, 메쉬)이 0.3% 무효 예측으로 0.991 달성 — 이미지+도구 프런티어 최고 0.963(Claude Sonnet 5.5 max), 이미지 전용 프런티어 최대 0.747, CADENA-RL 0.910(17,900개), CADFather 0.968. 같은 1,000개를 전달된 메쉬로부터 채점하면 0.995 vs CADFather 0.968, CADENA 0.930.
- 최강 베이스라인(CADFather) 대비 격차는 DeepCAD에서 가장 작고 기계 부품 세트에서 커진다 — CADMAGEDDON의 강점이 표면 구조(GMS 격차)라는 분석과 일치.
- 로컬 실행은 독점 부품에 중요하다: 클러스터도 외부 API도 필요 없고 FreeCAD와 통합된다.

## Details

- 방법: 메쉬 전처리 → 명명된 기하 엔티티 → 기하 도구(구성/수정 도구) → 구성-수정 에이전트 루프. 에이전트는 시각적 결정을 하고, 도구는 정밀 측정을 수행. 구현 세부사항은 Sec. 3.6, 호출 예산·도구 사용 분석은 Appendix A.
- 벤치마크: DeepCAD(300), Fusion 360(300), MCB(300), BenchCAD(1000; BenchCAD-2와 FreeCAD 통합은 Sec. 4.4), CADENA-Bench(60). 지표: IoU, GMS, 중앙값 Chamfer distance(×10³), 무효율(IR). CADFit을 제외한 모든 방법은 예측 메쉬로부터 저자들의 평가 코드로 채점.
