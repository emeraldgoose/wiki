# LLM 에이전트는 여전히 자기 개선 방법을 지시받아야 하는가?

**Source**: [arXiv](https://arxiv.org/abs/2611.23219)
**게시일**: 2026-11-17

## Overview

LLM 에이전트는 점점 자기 학습을 주도하고 있지만, 자기 개선 기법들은 여전히 최적화의 일부 구성 요소만 모델에 위임하고 절차는 인간이 지정한다. 이 논문은 점점 강력해지는 모델이 여전히 어떻게 자기 개선해야 하는지 지정받아야 하는가를 묻는다. 저자들은 자율적 패러다임을 연구한다: 기본 프리미티브, 자원, 일반적 자기 개선 목표만 주어지면, 에이전트가 컨텍스트 기반 최적화를 위한 자기 학습 알고리즘을 스스로 구성하는 것이다.

시험대는 정보가 제한된 게임플레이다. 동결된 LLM 에이전트는 경험 수집과 텍스트 문서 갱신 도구, 컴퓨트 예산을 받고, 외부에서 부과된 루프나 실제 데이터 접근 없이 자유롭게 실험한다. 같은 에이전트의 teacher 변형은 플레이어를 텍스트로 개선하라는 일반 목표(프롬프트 수정, skill 파일), 예산, 그리고 도구({Read, Write, Bash, Gameplay})를 받아 플레이어를 관찰하고 플레이어 컨텍스트를 편집한다. 충분히 유능한 모델은 고전적 자기 조절 학습(self-regulated learning) 프레임워크와 자기 생성 커리큘럼 같은 ML 구성 요소에 정렬된 전략으로 자기 개선하며, 학습된 아티팩트는 지평·메커니즘·3D 내비게이션에 걸쳐 전이된다. 프로젝트 페이지: https://ssundaram21.github.io/self-org/. 라이선스: CC BY-NC-SA 4.0.

## Key points

- 더 새로운 모델 세대가 스스로를 더 잘 가르친다(Sec. 4.1); 모델들은 알아볼 수 있는 자기 개선 전략을 만들며, 자기 조절 학습 및 학습 가능성(learnability) 구성 요소와 정렬된 게임플레이/업데이트 행동으로 정량화된다(Sec. 4.2).
- 자기 학습 아티팩트 전이: 게임 지평·메커니즘·3D 내비게이션에 걸쳐 개선; 자기 생성 게임이 외부 벤치마크(ARC-AGI-3 Level 1 등)로 전이.
- 자기 최적화 컨텍스트의 교차 모델 전이(Table 1, PuzzleScript-t20, 3 시드 평균 ± std): Opus 5 플레이어 — 25.4%(아티팩트 없음) → 47.5%(GPT-6 Astra의 아티팩트); GPT-6 Astra 플레이어 — 67.1%(없음) → 72.1%(Opus 5의 아티팩트). GPT-6 Astra의 베이스라인이 더 높음에도 양방향 전이.
- teacher의 정보가 일반화를 형성한다(Sec. 5.2): 더 풍부한 컨텍스트는 초기에는 근사(PuzzleScript-Narrow)와 일반화(ARC-AGI-3)를 모두 돕지만 토큰 수가 최대일 때는 근사는 향상·일반화는 정체/하락; 도구/예산 인식은 성능을 높이지만 t20 예산을 그대로 부여하면 t20은 오르고 t30 전이는 하락 — 인식이 과제 특화로 편향시킨다.
- 자기 개선에 외부 루프는 불필요하다: teacher는 도구와 예산만으로 자신만의 학습 절차(테스트 게임 생성, 플레이어 세션, 실패 분석, 컨텍스트 업데이트)를 조합한다.

## Details

- 설정: teacher–player 구조; 플레이어는 비공개 메커니즘의 턴제 게임을 컴퓨트·지평 예산 아래 플레이; teacher는 플레이어를 관찰하고 플레이어 컨텍스트(프롬프트, skill 파일)를 다시 쓴다 — 실제 게임이나 검증 점수에는 접근하지 못한다. 벤치마크는 PuzzleScript-t20/t30, ARC-AGI-3 (Level 1), MazeBench 포함(Appendix B).
- 절제 실험: 도구/예산 인식(PuzzleScript-t20 토큰/턴 예산 vs t30 전이), 컨텍스트 크기 vs 일반화, GEPA vs self-organized learning(Appendix D), 자기 조절 학습 주석, 자기 조직화의 컴퓨트 스케일링.
- 분석: teacher 세션 타임라인(Appendix D.7), 아티팩트 간 정성 예시(E), SRL 심사 루브릭(F).
