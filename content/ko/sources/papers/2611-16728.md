# EgoX — 엠바디먼트 드리밍으로 하는 자기중심적 크로스 엠바디먼트 조작

**Source**: [arXiv:2611.16728](https://arxiv.org/abs/2611.16728) · **게시일**: 2026-11-12
**Authors**: Yaru Niu, Binghong Chen, Changwei Yao, Shangtao Li, Zhenlong Fang, Revanth Krishna Senthilkumaran, Shuai Zhou, Yuemin Mao, Kalie Ching, Po-Ju Chao, Yudong Luo, Peiqi Yu, Heng Zhang, Hao Zhang, Bingqing Chen, Chen Qiu, H. Eric Tseng, Ye Yuan, Umar Iqbal, Changliu Liu, Jonathan Francis, Ding Zhao

## 개요

일반 조작(generalist manipulation) 정책은 세 가지 상호 보완적 경험을 활용하고 싶다. 기존 로봇 배치 환경을 넘어 다양한 물리적 상호작용을 담은 자기중심적(egocentric) 인간 데이터, 서로 다른 몸체와 말단장치를 지닌 실제 로봇의 시연, 데이터 수집을 확장하는 시뮬레이션이 그것이다. 걸림돌은 이 시연들이 서로 다른 형태(morphology)·시점·고유감각·행동 의미·운동 역학으로 상호작용을 부호화한다는 점이라, 단순히 한데 모으면 전이가 거의 일어나지 않는다. EgoX는 하나의 방법론적 전제 위에 세워졌다. 전이는 의미적으로 대응하는 모달리티를 통해 일어나야 하고, 감각과 제어 인터페이스는 엠바디먼트별로 유지되어야 한다.

프레임워크는 세 구성 요소를 가진다. 첫째, 이질적인 시연을 공유된 관찰-행동 표현으로 정리한다. 각 엠바디먼트를 해부학적·기능적으로 대응하는 모달리티(자기중심 이미지, 몸통 자세, 좌우 손목 자세, 말단장치 키포인트 위치, 엠바디먼트별 고유감각)로 분해하고, 자세는 지면 투영 루트 프레임, 자기중심 메인 카메라 프레임, 손마다의 손목 프레임이라는 통일된 좌표계로 표현해 서로 다른 몸체의 대응 부위가 비교 가능한 신호를 갖게 한다. 말단장치 키포인트는 구동기 관절 좌표가 아니라 손가락 끝, 그리퍼 접촉점, 도구 접촉점 같은 기하를 기술하기 때문에 다섯 손가락 손, 두 손가락 그리퍼, 고정 스쿱이 하나의 어휘를 공유할 수 있다. 둘째, MXT+(모듈형 크로스 엠바디먼트 트랜스포머 + 엠바디먼트 드리밍)는 엠바디먼트마다 관찰 모달리트별 전용 토크나이저와 행동 모달리트별 전용 전문가를 두고, 이들을 하나의 공유 트랜스포머 트렁크로 연결한다. 셋째, 엠바디먼트 드리밍은 학습 전용 보조 목표로, 드리밍 전문가가 미래의 시각·고유감각 상태의 압축 잠재 표현을 예측한다. JEPA류 EMA 교사와 stop-gradient를 쓰므로 공유 트렁크는 픽셀 재구성이나 배포 시점 계산 없이 각 엠바디먼트의 상태가 어떻게 변하는지를 학습한다.

학습은 2단계다. 인간·실제 로봇·시뮬레이션이 섞인 데이터로 MXT+를 사전학습한 뒤, 대상 엠바디먼트의 대상 과제 시연으로 미세조정한다(해당 과제-엠바디먼트 쌍은 사전학습에서 제외). 평가는 5개 조작 과제 — Kitchen-Bread(소스 바르기), Kitchen-Cleanup(도구 정리), Sort(블록 분류), Insert(T자 블록 삽입), Scoop(고양이 모래 퍼기) — 과 6개 로봇 엠바디먼트(실물 5종 + 시뮬레이션 휴머노이드 1종)에 걸친 13개 과제-엠바디먼트 쌍이며, 자기중심 인간 시연은 추가 사전학습 원천이다.

## 핵심 내용

- 사전학습이 13개 과제-엠바디먼트 쌍의 평균 정규화 과제 진행도를 0.63에서 0.80으로 끌어올린다. 개선은 분포 내 평가에서 13쌍 중 11쌍, 분포 외 평가에서 13쌍 전부에서 나타났다.
- 분포 외 효과가 핵심이다. 평균 과제 진행도가 0.53에서 0.77로 오르며 G1-Dex5 Insert와 Z1-Tool Scoop에서 개선이 가장 컸다. 평가된 모든 방법 중 사전학습된 MXT+가 13쌍 중 12쌍에서 1위를 기록했다.
- 기준선은 대상 엠바디먼트 시연으로 학습한 ACT, 같은 데이터로 사전학습 체크포인트에서 미세조정한 pi-0.5, 같은 대상 데이터로 스크래치부터 학습한 MXT+(사전학습 없음, 동일 아키텍처·동일 드리밍 목표)다.
- 사전학습 구성 소거: 인간 데이터만으로도 시험한 6쌍 중 5쌍에서 OOD 성능이 개선되고(가장 큰 개선은 G1-Dex5 Insert), 다른 로봇 시연을 더하면 6쌍 중 5쌍에서 ID 성능이 오르며, 대상 로봇의 다른 과제 시연을 더하면 모든 쌍에서 OOD가 개선된다. 전체 혼합이 무사전학습 대비 ID +0.12, OOD +0.23이다.
- 엠바디먼트 드리밍 소거: 드리밍 구성 요소를 제거한 MXT와 비교해 5개 엠바디먼트에 걸친 7개 설정에서 평균 과제 진행도가 0.63에서 0.78로 오르고 7개 설정 모두에서 개선됐으며, 가장 큰 폭은 G1-Dex5 Scoop이었다.
- 모듈형 vs 조악(coarse) 인터페이스: 사전학습 후 모듈형 설계는 시험한 모든 ID·OOD 설정에서 조악 변형(모든 카메라에 토크나이저 1개, 자세+고유감각 연결에 1개, 행동 모달리트 전체에 전문가 1개)과 같거나 더 좋다. 사전학습은 오히려 조악 변형의 xArm7-Dex4 Scoop과 시뮬레이션 주방 두 과제 성능을 떨어뜨렸고, Kitchen-Cleanup에서 사전학습된 조악 변형은 과제 진행도 0을 기록한 반면 모듈형 MXT+는 상당한 성능을 유지했다.
- 모듈성이 중요한 이유: Kitchen-Cleanup은 이동(locomotion)으로 시작하므로 51차원 행동 공간에서 비중이 작은 3D 속도 명령이 결정적인데, 전용 행동 전문가가 이 모달리티를 지켜 준다. 미세조정 때 손목 뷰가 새로 등장할 때도 카메라별 토크나이저 분리가 도움이 된다.
- 잠재 기하: Scoop 시연에서 추출한 엠바디먼트별 트렁크 잠재 표현 사이의 Gromov-Wasserstein 거리는 사전학습으로 10쌍 중 9쌍에서 감소했고(평균 21.30% 감소), 엠바디먼트 드리밍으로는 10쌍 전부에서 감소했다(평균 38.52% 감소). 같은 과제에 대해 트렁크의 내부 기하가 몸체와 무관하게 비슷해진다는 뜻이다.

## 상세

### 엠바디먼트와 시행 프로토콜

6개 로봇 엠바디먼트는 매우 다른 몸체를 아우른다. G1-Dex5는 다섯 손가락 Inspire RH56F1 데릭터러스 핸드를 단 양팔 Unitree G1 휴머노이드, xArm7-Dex4는 네 손가락 LEAP Hand를 단 테이블톱 xArm7, G1-Sim-Dex3은 세 손가락 Dex3-1 핸드를 단 시뮬레이션 Unitree G1, LocoMan-Dex2는 앞다리에 두 손가락 그리퍼를 단 사족보드(단팔 평가), R1Lite-Gripper는 병렬 그리퍼를 단 Galaxea R1 Lite 바퀴 달린 양팔 모바일 매니퓰레이터, Z1-Tool은 구동되지 않는 고정 스쿱을 단 테이블톱 Unitree Z1 암이다. Human-Dex5 자기중심 인간 시연은 사전학습에만 참여한다. 실물 쌍은 20회(분포 내 13, 분포 외 7), 시뮬레이션 쌍은 50회(분포 내 32, 분포 외 18) 시행하며 시행 구성은 방법 간 동일하다. 정규화 과제 진행도 점수는 중간 단계에 점수를 주고 완료 보너스 1점을 더한 뒤 과제 최대 점수(보너스 포함)로 나눈다.

### 엠바디먼트 드리밍의 작동 방식

드리밍 원천은 자기중심 이미지, 로봇 관절 상태, 말단장치 관절 상태 중 엠바디먼트가 제공하는 것들이다. 로봇 관절 상태는 행동 공간 밖에 있지만 몸체별 역학을 알려 주는 상태 정보를 지닌다. 엠바디먼트 토크나이저는 학습 가능한 쿼리 8개로 cross-attention을 해 선택된 특징을 8개 잠재 토큰으로 모으고, 학생 인코더의 EMA 복사본이 각 예측 오프셋의 미래 관찰을 목표로 요약한다. 드리밍 전문가는 행동 전문가와 같은 트렁크 출력을 읽으며, 미래 오프셋과 토큰 지수에 걸쳐 평균한 코사인 정렬 손실과 선택적 smooth-L1 크기 항으로 감독된다. 목표에는 stop-gradient가 걸리고 EMA 갱신으로만 느리게 변하므로 픽셀 재구성이 필요 없고 이 가지는 배포 시점에는 사라진다.

### 구성·기하 결과의 의미

혼합 소거 실험은 세 데이터 원천이 서로 다른 지점에서 기여한다고 말한다. 인간 데이터는 엠바디먼트 차이에도 불구하고 전이 가능한 조작 사전지식을 제공하고, 다른 로봇의 경험은 주로 분포 내 역량을 돕고, 대상 로봇의 다른 과제 시연은 시험한 모든 쌍에서 OOD 강인성을 다듬는다. 잠재 기하 분석은 행동상의 이득을 표현 학습과 연결한다. 사전학습과 드리밍 모두 같은 과제에 대한 트렁크의 내부 기하를 몸체 간에 더 비슷하게 만드는데(드리밍의 효과가 더 크다), 이 때문에 엠바디먼트를 가로지르는 공유 트렁크가 대상 엠바디먼트 미세조정만으로 새 몸체를 지원할 수 있다.
