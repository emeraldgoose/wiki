# DiffusionART: 확산 모델의 효율적이고 안정적이며 확장 가능한 강화학습

**Source**: Wan 외, arXiv, 2026-10-08

**핵심**: 온라인 RL은 블랙박스 보상으로 확산 모델을 미세조정하지만, 역과정 방법(Flow-GRPO)은 신용 할당이 나쁘고 순과정 방법(DiffusionNFT)은 효율적이지만 과업별로 정교하게 튜닝한 EMA 스케줄 없이는 불안정하다. 이 논문은 두 실패 모드를 정밀 진단한다—결합된 양성–음성 훈련이 부분적으로만 상쇄하는 숨은 순방향–역방향 일관성 힘, 그리고 오프폴리시 데이터가 아니라 복원을 통해 안정화하는 EMA—그리고 일관성 힘을 구조적으로 제거하는 집계 우선 보상 틸팅과 EMA를 대체하는 드리프트 적응 복원을 담은 DiffusionART를 제안한다. 미분 가능한 보상이 필요 없고, 프롬프트당 적은 샘플로 동작하며, 쌍별 보상 모델도 지원한다.

## 배경

온라인 확산 RL은 진화하는 생성기의 깨끗한 샘플을 블랙박스 보상으로 평가하므로, 출력 수준 피드백을 많은 디노이징 상태에 걸친 업데이트로 바꾸는 신용 할당 문제에 직면한다. 역과정 RL은 샘플된 디노이징 전이를 궤적 수준 어드밴티지로 최적화하고(전이상 신용 할당 불량, ODE→SDE 변환 필요), 순과정 RL(DiffusionNFT)은 생성된 끝점을 순방향 노이징해 보상 가중 양성/음성 목적함수로 속도를 회귀한다—효율적이지만 결합 양성–음성 훈련 + 과업별 튜닝 EMA 롤아웃 정책 없이는 불안정하다(기본 EMA 스케줄은 OCR에서 붕괴하고, SD3.5-M/GenEval 설정을 FLUX로 옮기면 실패한다).

## 진단: 일관성 힘과 복원

논문의 첫 기여는 이론이다: 순방향 노이징된 끝점으로 만든 NFT 타깃은 모델의 샘플링 속도가 자기 끝점이 유도하는 이상적 순방향 속도와 같다고 암시적으로 가정한다. 그 격차 $e$가 보상을 개선하지 않는 일관성 힘을 만든다—양성 분기는 이상적 순방향 속도로 당기고 음성 분기는 민다. 결합 훈련은 안내 항을 합치고($g + g$) $e$ 방향으로는 상쇄해 잔차 $(2q-1)e$를 남기는데, 보상 중심화는 샘플 평균으로만 균형을 맞추지 상태별로는 맞추지 못한다. 잔차는 디노이징이 끝점 품질을 드러낼수록 커진다. 둘째, EMA의 안정화 장치는 오프폴리시 롤아웃이 아니라 손실 속 후행 참조를 향한 2차 복원 항이다(검증: 예전 정책 앵커를 뺀 EMA 롤아웃은 여전히 붕괴한다). 하지만 EMA lag는 과업별 튜닝이 필수다—너무 작으면 붕괴하고 너무 크면 정체되며, EMA 없는 롤아웃당 2회 업데이트는 붕괴는 피하지만 15.2배 느려진다. 이성질 안내가 상태 간 상쇄되는 동안 복원이 우세해지기 때문이다.

## DiffusionART 방법

**집계 우선 안내**: 각 프롬프트의 롤아웃 분포를 고보상 쪽으로 지수 틸팅하면, 끝점 평균의 1차 변화는 보상–끝점 공분산과 같다. 프롬프트의 $K$개 끝점으로 추정해 RMS 정규화한 $G(c)$를 구하고(보상 스케일/산포 제거, 안내 계수 불필요), 방문한 모든 역과정 롤아웃 상태의 속도를 캐시된 예측 $+ G(c)$로 회귀한다. 타깃에 순방향 속도가 전혀 들어가지 않으므로 일관성 힘은 구조적으로 제거되고, 각 상태는 가능도비를 거친 스칼라 어드밴티지가 아니라 명시적 보상 개선 방향을 받는다.

**2회 업데이트 복원**: 각 롤아웃 배치를 서로소 미니배치 둘로 나눠 같은 동결 타깃으로 업데이트한다. 두 번째 업데이트의 그래디언트는 안내 $G(c)$와 상태별 드리프트에 비례하는 복원 $-d(s_t)$를 합친다—상태마다 적응적이고 튜닝할 스케줄이 없다. 프롬프트의 상태들이 $G(c)$를 공유하므로 NFT에서 복원이 우세해지던 상태 간 상쇄가 줄어든다.

ODE 롤아웃용 **트러스트 리전 마스킹**이 과도한 업데이트에 대한 최종 안전장치를 더한다(비디오에서 가장 중요하며, 마스크 없는 실행은 200스텝 부근에서 떨어진다). 쌍별 피드백 확장(DiffusionART-Pairwise)은 같은 프롬프트의 쌍들을 공분산 계산 전에 모은다.

## 실험

**설정**: SD3.5-M 위 T2I(LoRA r=32, 512×512, GenEval/OCR/PickScore + 4보상 결합)와 FLUX.1-dev 12B(GenEval), HunyuanVideo-13B 전체 파라미터 미세조정 T2V(53프레임, 480×480, 16스텝, VideoReward TA/VQ/MQ), Wan2.1-I2V-14B 위 I2V. 베이스라인: Flow-GRPO, Flow-GRPO-Fast, DanceGRPO, Flow-DPPO, DiffusionNFT ± EMA.

**결과**:

| 설정 | DiffusionART 대 베이스라인 |
|---------|---------------------------|
| SD3.5-M: Flow-GRPO 500스텝 보상 도달 (GenEval / OCR / PickScore) | 10.0배 / 5.2배 / 9.6배 적은 스텝 |
| HunyuanVideo T2V, VQ:MQ=1:1: 베이스라인 후기 평균 보상 도달 | DiffusionNFT 대비 12.02배, Flow-GRPO-Fast 대비 11.72배 적은 GPU 시간 |
| HunyuanVideo T2V: 마지막 50스텝 평균 보상 | 13.018 대 10.105(NFT, +28.8%)·8.510(Fast, +53.0%) |
| HunyuanVideo T2V (7:2:1 가중): VQ 5.5 | 24스텝 / 63.4 GPU-h 대 NFT-EMA 273스텝 / 1,401.4 GPU-h (11.4배 스텝, 22.1배 GPU-h) |
| HunyuanVideo T2V 평가: VQ / MQ | 최강 베이스라인 대비 +31.4% / +57.4% |
| Wan2.1 I2V: MQ 6 도달 | 45.8 대 220.3 GPU 시간 (4.8배 절감) |
| 그룹 크기 $K=2$ 대 $K=8$ (쌍별, 동일 400스텝) | 3.4배 적은 GPU 시간에 동등 이상 최종 VQ |

DiffusionART는 EMA나 과업별 튜닝 없이 SD3.5-M에서 NFT-EMA 효율과 동등하고, NFT 하이퍼파라미터가 요동치는 FLUX에서 가장 빨리 학습하며, 400스텝 T2V 내내 이득을 유지한다. 코드가 공개됐다.

## 소프트웨어 엔지니어를 위한 시사점

인간 선호·품질 보상(블랙박스, 미분 불가)으로 생성형 이미지/비디오 모델을 미세조정하는 팀은 바로 이 안정화 비용에 직면한다: 새 백본으로 옮기면 조용히 깨지는 과업별 EMA/스케줄 튜닝이다. DiffusionART의 두 아이디어는 확산을 넘어 이식된다: (1) 샘플별 어드밴티지 가중 업데이트를 보상 스케일을 제거하도록 정규화된 프롬프트 수준 집계 방향으로 대체—더 단순하고 보상 모델 교체에 강건하다, (2) 튜닝된 EMA 스케줄 대신 서로소 미니배치의 두 번째 업데이트와 드리프트 비례 복원으로 안정성을 확보한다. $K=2$ 결과는 운영상 중요하다: 프롬프트당 한 쌍이면 충분해 롤아웃 연산이 4배 줄어든다. 트러스트 리전 마스킹 ablation도 경고한다: 긴 호라이즌 롤아웃(비디오)에서는 훈련 곡선이 초반에 건강해 보여도 명시적 업데이트 상한을 두는 것이 좋다.
