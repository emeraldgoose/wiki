# CrossSWE: 코딩 에이전트를 위한 교차 저장소 공동 개발 벤치마크

**원문**: [arXiv:2611.01484](https://arxiv.org/abs/2611.01484) · **게시일**: 2026-11-01
**저자**: Silin Chen, Yuling Shi, Heng Lian, Zihan Zhang, Xiaodong Gu, Haotian Lin, Zhensu Sun

## 개요

코딩 에이전트가 소프트웨어 엔지니어링 벤치마크에서 높은 성공률을 거두자 최근 연구는 더 긴 horizon과 더 큰 코드 변경으로 과제 복잡도를 높여 왔다. 실제 개발은 여러 상호 의존 저장소에 걸치는 경우가 많아 의존성 추론, 변경 전파, 인터페이스 일관성이 추가로 요구된다. CrossSWE는 교차 저장소 공동 개발을 위한 벤치마크로, 171개 실제 사례를 포함한다. 단일 저장소 내부의 편집 규모를 더욱 키우는 대신 여러 저장소 간 호환 변경을 조율하는 문제로 초점을 옮긴다.

## 핵심 내용

- 코딩 에이전트는 기존 SWE 벤치마크에서 강한 점수에 근접한다.
- 실제 프로젝트는 보통 여러 저장소에 걸친다.
- 교차 저장소 작업에는 의존성 추론이 필요하다.
- 변경은 인터페이스 전반에 일관되게 전파되어야 한다.
- CrossSWE는 171개 실제 사례를 포함한다.
- 벤치마크는 교차 저장소 공동 개발을 목표로 한다.

## 상세

논문은 단일 저장소 작업을 길게 만들어도 협업적 소프트웨어 진화를 포착하지 못한다고 주장한다. 교차 저장소 공동 개발은 API 일관성과 버전 호환성 같은 정렬 문제를 도입한다. CrossSWE는 실제 개발 활동에서 뽑은 구체적인 사례를 제공해 에이전트가 조율된 변경을 수행하면서 인터페이스 수준 계약을 관리할 수 있는지 평가할 수 있게 한다. 고립된 코드 편집보다는 현실적인 다중 저장소 작업에 초점을 둔다.
