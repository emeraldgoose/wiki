# 단일 트랜스포머 잠재 디퓨전, UNIFIED

**원문**: [arXiv:2611.29064](https://arxiv.org/abs/2611.29064) · **게시일**: 2026-11-21 (v1)
**저자**: Hao-Yu Hsu, Shenlong Wang, Alexander G. Schwing

## 개요

잠재 생성 모델은 보통 세 개의 분리된 네트워크를 학습한다. 픽셀을 latent로 토큰화하는 인코더, latent 분포를 모델링하는 제너레이터, latent를 다시 픽셀로 매핑하는 디코더다. 전형적으로 단계별로 학습되며 오토인코더를 먼저 학습한 뒤 동결하고 제너레이터를 그 latent에 맞춘다. UNITE는 최근 인코더와 제너레이터를 단일 스테이지로 학습되는 하나의 생성 인코더로 합쳤지만, 디코더는 여전히 별도 네트워크로 남아 있다. 이 논문은 디코더까지 접어서 하나의 디퓨전 트랜스포머(DiT)가 인코딩·생성·디코딩을 모두 하게 할 수 있는지 묻는다.

순진한 해법 — UNITE의 공유 백본이 세 번째 모드로 디코딩하게 하되 학습된 readout 토큰을 유지하는 것(UNITE++) — 은 통하지 않는다. 약 215M 파라미터에서 gFID는 UNITE와 대등하지만(2.24 vs 2.23) 재구성이 훨씬 나쁘다(rFID 2.20 vs 1.41). latent readout이 이미지 위치와 고정된 공간적 대응을갖지 않아 모든 픽셀이 어텐션을 통해 latent에서 내용을 모아야 하기 때문이다. 완전 공유가 동작하게 하는 것은 세 모드를 위치 정렬된 시퀀스 맵으로 casting하는 것이다. 즉 픽셀 패치, latent 토큰, 노이즈된 latent 토큰이 시퀀스 인덱스 i에서 모두 같은 이미지 위치를 가리키게 한다(K = N, 패치당 latent 토큰 하나). 각 패스는 길이 N+1이며 위치 0에 학습된 모드 토큰(q_enc / q_gen / q_dec)을 prepend한다. 모드는 그 토큰, 경량 입출력 헤드(네 개의 사영 헤드 중 픽셀 출력 헤드만 새로 추가), (타임스텝, 클래스)에 대한 AdaLN conditioning만으로 구분된다.

두 타임스텝 선택이 중요하다. 인코딩은 깨끗한 이미지 패치를 읽으므로 타임스텝은 클린 엔드포인트 t_enc = 1이다(readout을 쓸 때는 readout이 시작하는 노이즈와 맞추기 위해 t_enc = 0이어야 했다). 디코딩도 깨끗한 latent를 읽지만 t = 1에서는 모드들이 출력에서 충돌한다. 인코딩과 생성은 깨끗한 latent를 내놓지만 디코딩은 픽셀을 내놓고, 클린 엔드포인트 근처에서는 생성 입력과 디코딩 입력이거의 동일해져 마지막 블록들이 두 출력 공간을 동시에 served해야 한다(t_dec = 1일 때 t = 0.995에서 인코딩-생성 패스 간 layer-wise CKA가 0.37로 하락). 디코딩에 고유의 학습된 타임스텝 임베딩 t_dec = -1([0,1] 밖)을 주면 충돌이 사라지고(마지막 블록 CKA 0.92–0.93 유지) 최선의 결과가 나온다. 학습은 재구성 손실(L1 + LPIPS, 노이즈를 약간 섞은 latent에 적용해 견고성 확보)과 깨끗한 latent를 예측하는 flow-matching 손실(목표와 입력 모두 stop-gradient)만으로처음부터 단일 스테이지에서 이루어진다. 적대적 손실도, DINO 같은 사전학습 인코더도 없다. 모드별 파라미터(헤드, 모드 토큰, 디코딩 타임스텝)는 Base 파라미터의 1.63%에 불과하다.

## 핵심 내용

- ImageNet-1K 256x256, 동일 크기 비교, 200 에폭, 5개 시드 평균, 최적 CFG: UNIFIED(t_dec = -1)가 세 크기 모두에서 UNITE를 앞선다 — Tiny 62M: gFID 2.78 vs 3.00(IS 280.1 vs 272.4); Small 116M: 2.43 vs 2.76(IS 295.9 vs 283.9); Base 215M: 2.08 vs 2.23(IS 314.4 vs 282.1), rFID 0.95 vs 1.41. Tiny UNIFIED(62M)가 파라미터 절반으로 Small UNITE(117M, 2.76)에 필적한다.
- Base에서의 절제 경로(Table 3): UNITE++(readout, t_enc=0, t_dec=1): gFID 2.24 / rFID 2.20. 위치 정렬만 적용(t_enc=0, t_dec=1): 2.31 / 1.39 — 재구성은 좋아졌지만 타임스텝 불일치로 생성은 나빠짐. t_enc=1 + t_dec=1: 2.15 / 0.97. t_enc=1 + t_dec=-1: 2.08 / 0.95 — 각 설계 선택이 분리되어 평가됐다.
- 250M 파라미터 이하 공개 모델 대비(Table 4): UNIFIED-B(215M, gFID 2.08, IS 314.4)가 사전학습 오토인코더도 비전 파운데이션 모델도 없이 최저 gFID를 달성했고, 학습은 200 에폭뿐(픽셀 공간 베이스라인은 600 에폭). UNIFIED-T(62M, 2.78)는 131–164M 픽셀 공간 베이스라인 전체(2.96–3.66)를 능가한다. 전체 비교에서 UNIFIED-B보다 gFID가 낮은 모델은 모두 545M 파라미터 이상이다.
- CKA 분석: 위치 정렬된 UNIFIED의 인코딩 패스는 초기 블록부터 생성 패스를 추적한다(모든 t에서 블록 1–5의 CKA 0.48–0.72).반면 readout 기반 UNITE/UNITE++는 마지막 블록까지 0.15 이하 — readout은 어텐션이 정보를 써 넣기 전까지 이미지 정보가 없다(마지막 블록에서야 0.84–0.92).
- 학습/샘플링 예산: UNIFIED-B는 120 에폭에서 이미 UNITE의 최종 gFID에 근접(2.22 vs 2.23, 약 10% 적은 계산량). 64 NFE에서 UNIFIED가 2.23을 달성해 UNITE와 UNITE++의 256 NFE 결과(2.28)를 적은 샘플링 FLOPs(5.2 vs 12.8 TFLOPs/이미지)로 능가한다. CFG는 t ∈ [0.1, 1]에서만 적용된다.
- 텍스트-이미지 생성: 클래스 conditioner를 Qwen3-0.6B 텍스트 임베딩으로 교체하고, JourneyDB + BLIP3-o 캡션으로 100K 이터레이션(배치 1024, 텍스트 드롭아웃 10%) 사전학습, 선택적으로 BLIP3o-60k로 2K 스텝 SFT. 256x256에서 UNIFIED-L(554M)이 픽셀 JiT(615M) 및 FLUX-VAE를 쓰는 DiT DH-XL(959M)을 GenEval/DPG-Bench/GenAI-Bench 모두에서 앞선다(SFT GenEval 0.878 vs 0.841 / 0.516). 512x512에서 UNIFIED-B(218M)가 GenEval 0.87, DPG-Bench 0.827로 단일 스테이지 픽셀 모델 PixelFlow-XL/4(882M, 0.60), PixNerd-XXL(1.2B, 0.73), PixelGen-XXL(1.1B, 0.79), DeCo-XXL(1.1B, 0.86)을 능가한다.
- 한계: 공유 토큰 그리드가 없는 QM9 분자(순서 없는 집합)에서는 UNIFIED가 UNITE만큼 생성하지만 재구성은 약간 나쁘다. 완전 가중치 공유는 latent 공간을 동결할 수 없다는 뜻이기도 해서, 재구성 손실이 학습 내내 유지되어야 하고 매 스텝이 생성과 함께 인코딩·디코딩 패스 비용까지 지불한다.

## Details

메서드: 각 학습 스텝은 같은 배치로 공유 DiT 백본 T_theta(RoPE, (t, c) 조건의 AdaLN)를 통해 세 패스를 실행한다. 인코딩 E_theta(x) = P_z^out T_theta([q_enc; P_x^in(x)], t_enc=1, ∅), 생성 G_theta(z_t, t, c) = P_z^out T_theta([q_gen; P_z^in(z_t)], t, c), 디코딩 D_theta(z) = P_x^out T_theta([q_dec; P_z^in(z)], t_dec, ∅). latent는 K = N 토큰이고, z_t = t·z + (1−t)·ε는 t = 1이 깨끗한 상태인 rectified-flow 보간이다. 손실: 재구성 L_rec = E||x̂ − x||_1 + λ_perc·LPIPS(x̂, x)(약간 교란된 latent z̃ = z + σ_rec·ε_r에 적용), 생성 L_gen = E||G_theta(sg(z_t), t, c) − sg(z)||², 전체 L = λ_rec L_rec + λ_gen L_gen. 추론: t = 0의 가우시안 노이즈에서 시작해 [0,1] 구간을 반복 생성 패스로 적분(CFG는 t ∈ [0.1, 1]에만 적용)한 뒤 디코딩 패스 하나가 최종 latent를 픽셀로 매핑한다. 각 옵티마이저 스텝은 같은 배치에서 재구성 스텝 하나와 flow-matching 스텝 12개를 결합한다. 부록에는 ImageNet 학습/평가 프로토콜(적응형 dopri5 솔버, 시프트된 타임 그리드, CFG 설정), 계산량 분석, 전체 베이스라인 표(더 큰 모델 포함 Table 10), 추가 절제, 텍스트-이미지 세부사항(50스텝 Euler, CFG 6.0, MS-COCO zero-shot FID, 512x512 확장), QM9 분자 실험이 있다. 프로젝트 페이지: https://haoyuhsu.github.io/Unified-LDM/.
