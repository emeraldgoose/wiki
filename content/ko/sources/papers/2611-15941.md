# Lang-SVG: 언어 사전 정보를 활용한 계층적 이미지 벡터화

**Source**: [arXiv:2611.15941](https://arxiv.org/abs/2611.15941) · **게시일**: 2026-11-11

## 개요

이미지 벡터화는 래스터 이미지를 간결하고 확장 가능한 벡터 그래픽(SVG)으로 재구성해 구조적이고 편집 가능한 코드 표현을 제공한다. 그러나 기존 방법은 픽셀 수준의 렌더링 정확도에 최적화되어 인간이 인식하는 오브젝트-부위 계층과 정렬되지 않은 SVG를 생성해 조작이 어렵다.

Lang-SVG는 SVG 기본 요소를 의미 레이블과 부모-자식 관계로 정의하는 명시적 트리 구조를 도입한다. granularity-controllable과 open-vocabulary 세그먼테이션 사전 정보를 활용해 오브젝트-부위 계층을 초기화하고, SVG 트리 맥락과 함께 멀티모달 대규모 언어 모델(MLLM)을 사용해 레이블 없는 노드에 의미 레이블을 할당한다.

중복을 줄이기 위해 depth-adaptive simplification으로 도형 복잡도를 낮추고, Tree-Guided Pruning and Merging으로 중복 SVG 노드를 제거한다. L1-SAM-Prompting은 누락 영역을 복구해 재구성 정확도와 구조적 완전성을 향상시킨다. 재구성 정확도 외에도 구조적 품질과 의미 부위 정렬을 측정하는 새로운 평가 프로토콜을 도입한다. 실험 결과 Lang-SVG는 렌더링 정확도와 구조적 품질 모두에서 최신 기술 성과를 달성한다.

## 핵심 내용

- Lang-SVG는 의미 레이블과 부모-자식 관계를 가진 SVG 기본 요소의 명시적 트리 구조를 도입한다.
- granularity-controllable 및 open-vocabulary 세그먼테이션 사전 정보가 오브젝트-부위 계층을 초기화한다.
- MLLM이 SVG 트리 맥락과 함께 레이블 없는 노드에 의미 레이블을 할당한다.
- depth-adaptive simplification이 도형 복잡도를 낮춘다.
- Tree-Guided Pruning and Merging이 중복 SVG 노드를 제거한다.
- L1-SAM-Prompting이 누락 영역을 복구해 재구성 정확도와 구조적 완전성을 향상시킨다.
- 새로운 평가 프로토콜이 구조적 품질과 의미 부위 정렬을 측정한다.
- Lang-SVG는 렌더링 정확도와 구조적 품질 모두에서 최신 기술을 달성한다.
- 트리 구조 SVG 표현은 언어 레이블이 부여된 계층적 오브젝트-부위 SVG로 가능하다.
- open-vocabulary 세그먼테이션은 언어 수준 개념을 활용해 의미 영역을 유연하게 추출한다.
- Grounded SAM은 open-vocabulary 검출과 SAM 기반 세그먼테이션을 결합해 언어 수준 후보 마스크를 생성한다.
- open-vocabulary 부위 세그먼테이션과 오브젝트-부위 파싱이 세분화와 의미 제어를 개선한다.
- MLLM은 벡터화된 층의 계층 정보를 통해 의미 정렬을 제공한다.
- Lang-SVG는 SVG 기본 요소의 그룹핑과 의미 분석 같은 응용이 가능하다.
- 이 표현은 SVG 기본 요소의 의미 분해를 가능하게 한다.
- 평가 프로토콜은 구조적 품질과 의미 부위 정렬을 측정한다.
- Lang-SVG는 렌더링 정확도와 구조적 품질 모두에서 새로운 기준을 설정한다.
