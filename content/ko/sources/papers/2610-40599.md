# HairDeck: 단일 이미지에서 만드는 애니메이션 준비 스타일라이즈드 헤어 카드

출처: Yuze He, arXiv:2610.40599, 2026-10-29.

**핵심 요약**: 게임과 아바타의 스타일라이즈드 캐릭터 헤어는 spring bone으로 애니메이션되는 artist-placed ribbon인 **헤어 카드**로 만들어집니다. 기존 이미지 기반 방법은 realistic hair나 single fused mesh를 만들고, 유일한 스타일라이즈드 헤어 카드 생성기 CHARM은 헤어스타일을 control point의 긴 시퀀스로 자동회귀 디코딩합니다. 헤어 카드 스타일이 artist 정의 프리미티브의 **무순서 집합**이라는 관찰에서 HairDeck는 이를 그렇게 생성합니다. 각 카드는 single token이고 set diffusion transformer가 모든 카드를 함께 denoise합니다. 단일 이미지에서 카드와 이를 구동하는 **spring-bone chain**을 생성해 다운스트림 포맷으로 내보낼 수 있는 애니메이션 가능 asset을 얻습니다. CHARM 테스트 세트에서 **Chamfer 거리 44%**, **card-orientation error 절반 이상**을 줄이고 **33배 빨라졌으며**, 단일 이미지 기준으로 CHARM, image-to-3D, strand-based 방법을 앞섰습니다.

## 핵심 내용

- 헤어 카드는 spring bone으로 애니메이션되는 artist 프리미티브이다.
- CHARM은 control point 시퀀스를 자동회귀 디코딩한다.
- HairDeck은 헤어스타일을 카드의 무순서 집합으로 본다.
- 각 카드는 single token이며 set diffusion이 함께 denoise한다.
- 단일 이미지에서 카드와 spring-bone chain을 생성한다.
- CHARM 테스트 세트에서 Chamfer 44% 감소.
- orientation 오차 절반 이상 감소, 속도 33배 향상.

## 상세

핵심 아이디어는 자동회귀 control-point 시퀀스를 카드 üzerinde의 set diffusion으로 대체하는 것입니다. 헤어스타일의 무순서적 본질에 더 잘 맞고 더 빠르고 정확한 애니메이션 asset을 만듭니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. set diffusion 아키텍처와 렌더 세부는 원문을 함께 확인해야 합니다.
