# RoboArchitect: persistent memory를 가진 robotic agent 설계 자동화

**원문**: [arXiv:2610.42141](https://arxiv.org/abs/2610.42141) · **게시일**: 2026-10-27
**저자**: Shengguang Wu, Suning Huang, Cherie Ho, Ria Doshi, Hao Zhu, Serena Yeung-Levy

## 개요

frozen robot policy가 policy 호출 timing, vision tool consult, arm command를 결정하는 agent harness 안에서 far better performance를 낸다는 최근 결과가 있지만, 이런 harness는 지금도 hand-built이고 new robot/benchmark마다 redesigned된다. RoboArchitect는 harness design과 optimization을 coding model로 automate한다.

frozen policy, auxiliary vision/language tool, step-by-step rollout recording에 접근할 수 있으면 coding model이 failure mode를 diagnose하고 updated harness를 제안한다. diverse benchmark/policy에서 auto-optimized harness는 unseen scene/task success를 substantially raise한다. harness는 또한 persistent memory를 equipped하여 experience가 episode across accumulates.

## 핵심 내용

- robotic agent harness 설계를 automate한다.
- coding model이 failure를 diagnose하고 harness update를 제안한다.
- unseen scene 평균 성공률을 9.7%에서 43.3%로 raise한다.
- unseen task 평균 성공률을 12.7%에서 40.2%로 raise한다.
- diverse training pool에서 single cross-embodiment harness를 build한다.
- evolving persistent memory를 harness에 equip한다.
- harness evolution trajectory와 failure diagnosis를 report한다.

## 상세

harness는 policy call, tool usage, arm command를 mediating하여 control code를 policy만큼 중요하게 만든다. RoboArchitect는 이 harness를 automatic engineering artifact로 treat한다.

persistent memory는 predefined schema 없이 optimization에서 emerge한다. 목표는 harness evolution을 통해 frozen policy를 robot, task, environment across adaptable하게 만드는 것이다.
