# SALD: 확산 모델을 위한 자기 참조 이점 학습

출처: Aryan Das 외 6인, arXiv:2610.01496, 2026-10-01.

**핵심 요약**: 언어 모델 적응 연구는 단일 모델이 시연·피드백이 추가된 맥락에서 자기 행동을 평가해 유용한 훈련 신호를 얻을 수 있음을 보였습니다. **SALD**는 이 내부 참조 원리를 확산 모델로 가져와, 외부 시연이나 교사 네트워크 없이 **자기 참조 훈련 신호**를 찾습니다.

## 두 경로의 오차 차이

SALD는 같은 모델로 각 이미지-캡션 쌍을 **두 잡음 수준**에서 평가합니다. 더 쉽고 잡음이 낮은 경로는 기울기 추적 없이 참조를 제공하고, 더 어렵고 잡음이 높은 경로가 훈련 기울기를 제공합니다. 쉬운 경로 예측을 직접 증류하는 대신 **두 경로 오차의 차이**로 어려운 경로 목표를 적응시킵니다.

## 세 구성요소

**Advantage-Guided Diffusion(AGD)**은 상대 오차를 미분 가능한 샘플 수준 가중치로 바꿉니다. **Temporal Advantage Memory(TAM)**는 훈련 전반의 상대 난도를 누적해 두 잡음 수준 사이의 미래 격차를 조정합니다. **Spectral Advantage Decomposition(SAD)**은 두 경로의 잔차 파워 스펙트럼을 비교해 주파수에서 유도한 미분 가능 잠재 요소 가중치를 만듭니다. 모든 구성요소가 한 모델 파라미터를 공유하며, 훈련·추론에 외부 교사나 추가 학습 파라미터가 필요 없고 추론 절차도 바꾸지 않습니다.

## 결과

여러 아키텍처와 데이터셋에서 생성 품질이 일관되게 개선됐고, 구성요소별 절제 실험이 각 기여를 정량화했습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 두 잡음 수준과 가중치 스케줄의 민감도, 고해상도·비디오 확산으로의 확장성, FID 외 지각 품질 지표는 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 확산 모델 파인튜닝에 별도 교사 모델을 두기 어렵다면, 같은 모델의 난도 차이를 활용한 자기 참조 신호가 비용 효율적입니다.
- 추론 절차를 바꾸지 않는 훈련 기법은 기존 서빙 스택에 그대로 적용할 수 있습니다.
- 잡음 수준별 오차 차이가 실제 품질 개선으로 이어지는지 자체 데이터로 검증하세요.
