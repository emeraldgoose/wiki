# 계층별 오차 모델 탐색을 통한 SVD 기반 LLM 압축 발전

**원문**: [arXiv:2610.32878](https://arxiv.org/abs/2610.32878) · **게시일**: 2026-10-23
**저자**: Moritz Thoma, Maximilian Groezinger, Maximilian Forstenhäusler, Emad Aghajanzadeh, Manoj Rohit Vemparala, Christos Anagnostopoulos, Pierpaolo Mori, Nael Fasfous, Alexander Frickenstein, Daniel Mueller-Gritschneder, Ulf Schlichtmann

## 개요

저계수 SVD 기반 압축은 LLM 계산 비용을 줄이는 유망한 방법이지만 기존 방법에는 두 가지 한계가 있다. 전역 순위 할당은 복잡한 오류 전파를 포착하지 못하는 보정되지 않은 오류 대리값에 의존하고, 피셔 기반 분해는 심각한 순위 붕괴에 시달릴 수 있다. 이 논문은 이 두 문제를 해결하기 위해 계층별 오차 모델 탐색과 KFAC-SVD를 소개한다.

LEMS는 지역 및 전역 계층 중요도와 전파 편향을 결합한 계층별 오차 대리값을 도입하고, 전역 순위 할당을 정수 선형 계획 문제로 해결하여 순위 할당을 발전시킨다. KFAC-SVD는 토큰별 통계를 사용해 분해 품질을 높여 기존 피셔 기반 SVD 접근법에서 보인 순위 결핍을 완화한다. Mistral, Qwen3, Llama 3 계열 전반에서 LEMS는 기존 탐색 전략을 일관되게 앞서며 70B 모델까지 일반화되는 최대 4.7 포인트의 제로샷 정확도 향상을 보였다. KFAC-SVD는 평균 19%의 퍼플렉시티 개선을 달성했다.

## 핵심 내용

- 저계수 SVD 압축은 LLM 비용을 줄일 수 있지만 할당과 분해 품질에 약점이 있다.
- 전역 순위 할당은 종종 보정되지 않은 대리값에 의존한다.
- 피셔 기반 분해는 순위 붕괴를 겪을 수 있다.
- LEMS는 계층별 오차 대리값과 전파 편향을 추가한다.
- 순위 할당은 정수 선형 계획 문제로 수식화된다.
- KFAC-SVD는 분해 개선을 위해 토큰별 통계를 사용한다.

## 상세

이 논문은 순위 할당과 분해 품질을 분리한다. 더 나은 할당은 각 계층이 보유할 용량을 선택하고, 더 나은 분해는 보유한 용량이 원래 가중치를 얼마나 효과적으로 표현하는지를 결정한다. LEMS는 전파를 고려한 할당에 집중하고, KFAC-SVD는 순위 붕괴가 없는 피셔 정보에 집중한다. 둘을 함께 사용하면 여러 모델 계열과 규모에서 정확도와 퍼플렉시티를 모두 개선한다.
