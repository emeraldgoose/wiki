# FDSML: 파라미터 인식 삼중항 손실을 가진 공식 기반 지도 메트릭 학습

출처: Shinei Arakawa, arXiv:2610.39423, 2026-10-29.

**핵심 요약**: Formula-Driven Supervised Learning(FDSL)은 실제 이미지 없이 비전 사전학습을 가능하게 하지만, 기존 메서드는 이산 라벨 분류로 사전학습을 구성해 생성 과정의 연속성을 버립니다. **Formula-Driven Supervised Metric Learning(FDSML)** 은 이산 클래스 라벨을 넘어 **이미지 생성 파라미터로부터 관계 지도**를 유도합니다. **FineFractalDB**, 즉 클래스 내부 변형이 더 높고 구조가 더 안정적인 정제 프랙탈 데이터셋과, underlying Iterated Function System 파라미터 공간의 거리에 따라 positive·negative를 할당하는 **Parameter-Aware Triplet(PA-Triplet) Loss** 를 결합합니다. 이 목적은 임베딩이 파라미터로부터 유도된 상대 유사도 순서를 존중하도록 학습시킵니다. 실험상 FDSML은 다운스트림 분류에서 경쟁력을 유지하면서 **이미지 retrieval 전이성**을 높이고 여러 손상 설정에서 강건성을 개선했습니다. ResNet-50에서 Stanford Online Products의 Recall@1이 65.6%에서 74.0%로, Stanford Cars에서 56.2%에서 78.4%로 FDSL 사전학습 대비 향상됐습니다. 이 결과는 라벨 기반 분류보다 **파라미터 유도 관계 지도**가 인식을 넘는 전이에 더 강한 합성 사전학습 신호를 제공함을 시사합니다.

## 핵심 내용

- 공식 기반 FDSL 사전학습은 실제 이미지가 필요 없다.
- 기존 FDSL은 이산 라벨 분류로 생성 연속성을 버린다.
- FineFractalDB는 클래스 내부 변형과 구조 안정성을 높인다.
- PA-Triplet Loss는 IFS 파라미터 공간 거리로 positive/negative를 할당한다.
- 임베딩은 파라미터 유도 상대 유사도 순서를 학습한다.
- Stanford Online Products Recall@1이 65.6%에서 74.0%로 올랐다.
- Stanford Cars Recall@1이 56.2%에서 78.4%로 올랐다.

## 상세

지도는 이산적이지 않고 관계적입니다. fractal 생성기 파라미터 공간의 거리에서 positive·negative를 얻어 분류 라벨이 버리는 연속성을 보존하며, retrieval과 강건성에 더 강한 합성 사전학습을 낳습니다.
