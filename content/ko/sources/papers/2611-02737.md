# MoviEdit: 장편 멀티샷 비디오 편집을 쉽게

**원문**: [arXiv:2611.02737](https://arxiv.org/abs/2611.02737) · **게시일**: 2026-11-02
**저자**: Suhyeon Lee, Zhengang Li, Soo Ye Kim, Peihao Zhu, Jong Chul Ye, Chun-Hao Paul Huang, Duygu Ceylan, Yan Kang, Hyeonho Jeong

## 개요

장편 멀티샷 비디오 편집은 장면, 시점, 피사체 외형이 급격히 바뀌는 구간에서도 의도한 편집을 일관되게 유지해야 하며, 일반 단일샷 편집기보다 훨씬 긴 시각 문맥을 처리해야 한다. MoviEdit는 데이터, 모델링, 평가를 함께 다루는 확장형 장편 멀티샷 비디오 편집 엔드투엔드 프레임워크다. 대규모 교차 샷 지도학습을 제공하기 위해 수동 주석 없이 동기화 다중 뷰 영상, 실제 멀티샷 영상, 생성된 멀티샷 영상을 포괄하는 87,000개 짝 편집 비디오를 자동 생성한다. 구조적으로는 연계된 양방향-자기회귀 설계를 사용한다.

## 핵심 내용

- 프레임워크는 단일 샷이 아니라 여러 샷에 걸친 일관성에 초점을 둔다.
- 수동 주석 없이 87,000개 짝 편집 비디오를 자동 생성한다.
- 데이터는 동기화 다중 뷰, 실제 멀티샷, 생성 콘텐츠를 아우른다.
- 양방향 단계가 먼저 압축 표현에서 전역적으로 일관된 편집 초안을 만든다.
- 초안은 전체 비디오에 대해 자기회귀적으로 전파·정제된다.
- 전용 벤치마크 MoviEdit-Bench가 체계적 평가를 지원한다.

## 상세

프레임워크는 충분한 교차 샷 지도학습, 장편 문맥 모델링, 벤치마킹이라는 세 과제를 직접 다룬다. 광범위한 실험에서 MoviEdit는 기존 오픈 소스 모델을 크게 앞서고 텍스트 가이드 및 이미지 가이드 편집에서 산업 프론티어 모델과 비슷한 수준을 보인다. 전용 벤치마크 MoviEdit-Bench도 제안되며, 프로젝트 페이지에서 완전한 결과와 벤치마크에 접근할 수 있다. 결과는 평가된 편집 유형과 영상 범주 범위에서 해석해야 한다.
