# Agent-Reflex: Teaching Language Agents to Act Reflectively (한국어 요약)

이 논문은 대규모 언어 모델 기반 에이전트가 도구 사용 환경에서 잘못된 피드백이나 사용자의 개입에 대응하여 스스로 반성(reflection)하는 능력을 학습하도록 훈련하는 일반적인 프레임워크인 **Agent-Reflex**를 제안합니다. Agent-Reflex는 세 단계로 구성됩니다: 환경 반성 기술 발굴, 반성 기술 강화, 테스트 타임 적용. 결과 기반 RL과 달리 환경 기반 반성 신호를 활용하여 장기 과제 중 오류 복구를 향상시킵니다.

## 배경

LLM 기반 에이전트는 단순 대화형 챗봇에서 벗어나 장기 추론과 도구 사용이 가능한 형태로 발전해 왔습니다. 그러나 실제 배포 환경에서는 MCP 기반 도구 서비스가 노이즈가 있는 피드백을 반환하거나 사용자가 직접 개입하여 수정할 수 있으나, 기존 방법들은 이러한 상황에서 반성 학습과 실패 복구를 지원하는 감독이 매우 제한적입니다.

## 방법

Agent-Reflex는 결과 기반 감독이 아닌 환경 기반 반성 신호를 학습하는 세 단계 프레임워크입니다. 첫째 단계에서 실제 도구 실행 결과의 교란을 주입하여 반성 기술을 발굴하고, 둘째 단계에서 발굴된 기술을 강화 학습합니다. 셋째 단계에서는 테스트 타임에서 강화된 반성 능력을 활용하여 오류 복구와 적응적 행동을 수행합니다.

## 결과와 시사점

Agent-Reflex는 기존 결과 기반 RL 프레임워크와 비교하여 반성 기반 오류 복구 성능을 개선함을 실험적으로 확인했습니다. 특히 장기 과제와 노이즈가 있는 도구 환경에서의 적응 능력이 향상되었으며, 이는 향후 에이전트 시스템의 안정적인 배포를 위한 중요한 설계 원칙을 제공합니다.
