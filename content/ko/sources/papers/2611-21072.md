# Sage S2.1 Flash 기술 보고서

**출처**: [huggingface](https://arxiv.org/abs/2611.21072)
**게시일**: 2026-11-16

## 개요

Sage S2.1 Flash는 과학적 증거를 추론하고 대화형 환경에서 행동하도록 설계된 3200억 파라미터 규모의 범용 전문가 혼합(MoE) 모델입니다. 과학 업무에서 반복적으로 요구되는 두 가지, 즉 과학 문헌에서 시각적 증거를 검색·해석하는 일과 중간 시각 출력을 활용해 분석을 이끄는 일을 겨냥합니다. 과학적 컴퓨터 사용의 경우, 전문 소프트웨어의 상태를 해석하고 행동의 결과로 얻은 시각 피드백을 바탕으로 다음 단계를 결정합니다.

Sage Sci-Perception은 분자 그래프와 생물학적 서열을 위한 전용 인코더를 사용하고, 스펙트럼은 측정값의 순서가 있는 패치로 표현합니다. 모달리티별 프로젝터가 이러한 표현을 공유 백본의 입력 공간으로 매핑하며, 백본은 이들을 텍스트와 이미지와 함께 처리합니다. 이 백본을 둘러싸고 도구 사용, 검색, 코딩뿐 아니라 머신러닝 실험과 과학 소프트웨어를 다루는 특화 워크플로까지 포괄하는 검증 가능한 환경을 구축했으며, 과제 완료 여부는 실행 결과, 환경 상태의 변화, 제출된 산출물을 기준으로 확인합니다.

33개 벤치마크, 7개 도메인에서 평가되었습니다. 5개 기준 모델과의 주요 비교에서 OfficeQA Pro(72.2), MLE-bench Lite(90.3 HumanRank), Harvey LAB, SpreadsheetBench 2에서 1위를, OSWorld-Verified(85.2), WebArena-Verified(67.6), DeepResearch Bench II(54.2)에서 2위를 기록했습니다.

## 핵심 내용

- 과학적 추론과 대화형 에이전트 능력에 초점을 둔 3200억 파라미터 범용 MoE 모델.
- Sage Sci-Perception: 분자 그래프·생물학적 서열 전용 인코더, 스펙트럼은 순서가 있는 측정 패치로 표현, 모달리티별 프로젝터가 텍스트·이미지와 함께 공유 백본에 입력.
- 도구 사용, 검색, 코딩을 위한 검증 가능한 환경과 머신러닝 실험·과학 소프트웨어 워크플로로 에이전트 능력을 학습.
- 과제 완료는 모델 자체 보고가 아니라 실행 결과, 환경 상태 변화, 제출 산출물로 검증.
- ToolSpace 프레임워크는 실제 실행 추적에서 도구 조합 공간을 재구성하고, 필요 시 환경을 합성하며, 장기 호라이즌 도구 사용 과제를 생성.
- 사후 학습(post-training) 프레임워크로 XTuner 사용.
- 7개 도메인 33개 벤치마크로 평가, 그림 1의 15개 선정 벤치마크에서 6개 비교 모델 중 4개 1위·7개 2위.
- 문서 증거 활용, 검증 가능한 워크북 작성, 머신러닝 과제에서 강점, 시각 피드백 기반 데스크톱·브라우저 워크플로에서도 경쟁력 있는 성능.

## 상세

방법: Sage Sci-Perception은 과학적 입력을 위한 통합 인터페이스입니다. 각 모달리티의 인코더가 만든 국소 상태(local state)를 학습된 항등 임베딩과 결합해 프로젝터(레이어 정규화 후 GELU 활성화를 사이에 둔 두 개의 선형 변환)에 통과시킵니다. 선택적 측면 분기는 시간·스케일 같은 명시적 측정값을 언어 임베딩 공간에 매핑하고, readout 분기는 과학적 예측 점수를 추가 임베딩 기여로 변환할 수 있습니다. 이후 컨텍스트 잔차(context residual)가 같은 과학적 객체에 속한 상태들 사이에서 정보를 교환합니다. 모달리티 내 모든 과제는 하나의 완전한 프로젝터를 공유하며, 요청하는 연산은 지시문(instruction)으로 표현되므로 같은 인터페이스를 여러 과제에 재사용할 수 있습니다.

사후 학습에서는 범용 도구 사용, 검색, 코딩부터 머신러닝 실험 워크플로와 과학 소프트웨어 상호작용까지 검증 가능한 환경을 대규모로 구축합니다. 이를 뒷받침하는 도구 중심 프레임워크 ToolSpace는 실제 실행 추적에서 도구 공간을 탐색하고, 필요에 따라 환경을 합성하며, 장기 호라이즌 에이전트 과제를 생성해 도구 오케스트레이션 능력을 강화합니다.

결과: 7개 도메인 33개 벤치마크에서 5개 기준 모델과 비교한 결과, OfficeQA Pro(72.2), MLE-bench Lite(90.3 HumanRank), Harvey LAB, SpreadsheetBench 2에서 1위, OSWorld-Verified(85.2), WebArena-Verified(67.6), DeepResearch Bench II(54.2)에서 2위를 기록했습니다. 문서 증거 활용, 검증 가능한 워크북 생성, 머신러닝 과제에서 뚜렷한 강점을 보였고, 시각 피드백이 필요한 데스크톱·브라우저 워크플로에서도 경쟁력 있는 성능을 나타냈습니다.
