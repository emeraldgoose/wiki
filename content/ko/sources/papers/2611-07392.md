# WeLM-Image: visual intelligence를 향한 unified image generation model

**원문**: [arXiv:2611.07392](https://arxiv.org/abs/2611.07392) · **게시일**: 2026-11-05
**저자**: Canmiao Fu, Chen Li, Guohui Zhang, Hao Lu, Hongyang Wei, Huadong Wu, Huaisong Zhang, Hubery Yin, Liyuan Cui, Qixin Yan, Tong Shao, Xiaoqiang Zhou, Xinhang Leng, Ying Zhang, Zhenhai Liu, Zhipeng Huang

## 개요

WeLM-Image는 multimodal understanding을 text-to-image generation, instruction-guided editing, multi-reference synthesis에 통합하는 unified image foundation model이다. single-GPU deployment를 목표로 하며 text, reference image, target latent을 one interleaved sequence로 process한다.

Mixture-of-Transformers backbone은 shared attention과 independent understanding/generation parameters를 결합해 optimization interference를 limit한다. Mixture-of-Experts modules는 sparse capacity를 제공하고 per target latent token당 31.7B stored parameters와 약 5.4B generation parameters를 activate한다. generation-oriented data engine은 semantic coverage와 editing tasks를 balance하고 bilingual annotations, verified editing supervision을 지원한다.

training은 generation과 editing을 별도 optimize한 뒤 rubric-와 checklist-based rewards로 specialized policies를 consolidate한다. 1536-resolution model은 reported benchmark에서 evaluated open-source models 중 first를 차지한다. MeanFlow-based few-step distillation은 WeLM-Image-Turbo를 만들어 single NVIDIA H20 GPU에서 8 guidance-free steps로 1024x1024 image를 4.98 seconds에 생성한다.

## 핵심 내용

- 이해, 생성, 편집, multi-reference synthesis를 unify한다.
- text, reference images, target latents를 one interleaved sequence로 처리한다.
- Mixture-of-Transformers와 Mixture-of-Experts로 capacity와 interference를 control한다.
- bilingual generation-oriented data engine로 scale한다.
- rubric-와 checklist-based rewards로 policies를 optimize한다.
- specialized policies를 few-step turbo variant로 distill한다.

## 상세

progressive training은 native 1.5K resolution에 도달한다. paper는 PRISM-Bench, Qwen-Image-Bench, UnicBench comparison과 turbo variant deployment timing을 보고한다.
