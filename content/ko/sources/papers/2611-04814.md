# Think Less, Locally: 추론 압축을 위한 로컬 선호 학습

**원문**: [arXiv:2611.04814](https://arxiv.org/abs/2611.04814) · **게시일**: 2026-11-03
**저자**: Muyao Yuan, Liyan Xu, Weizhan Zhang, Muyan Jiao, Jiangnan Li, Jinchao Zhang, Jie Zhou

## 개요

대형 reasoning 모델은 강한 성능을 보이지만, 충분한 정보를 얻은 뒤에도 계속 추론하면서 긴 CoT가 큰 inference cost를 만든다. 기존 압축 방법은 주로 trajectory에 작동하고 현재 state에서 추가 추론이 필요한지에 대한 local decision을 덜 다룬다. LoCo는 모델 trace에서 candidate overthinking state를 감지하고, 해당 reasoning prefix를 freeze한 뒤 같은 state에서 더 짧은 검증된 continuation을 재생성하여 state-conditioned preference pair로 DPO를 학습한다. 이렇게 단순히 더 짧은 trajectory를 유도하는 것이 아니라 when to continue와 when to conclude를 가르친다.

## 핵심 내용

- 방법은 전역 trajectory 축소보다 state 수준 연속 결정에 초점을 둔다.
- candidate overthinking state는 모델 자신의 trace에서 감지된다.
- preference 생성 중 reasoning prefix는 freeze된다.
- 같은 state에서 더 짧은 검증된 continuation이 생성된다.
- state-conditioned preference pair에 DPO가 사용된다.
- 수학 전용 훈련 데이터에서도 코드로 전이된다.

## 상세

LoCo는 self-generated mathematical trace로 학습 데이터를 구축하고 다섯 수학, 세 코드 생성 벤치마크에서 평가했다. 수학 completion length는 41.7~45.4%, 코드는 23.4~36.3% 줄였으며 정확도를 유지하거나 향상했고 code benchmark에서 가장 좋은 trade-off를 달성했다. compression threshold는 verification과 OOD model behavior에 의존할 수 있다.
