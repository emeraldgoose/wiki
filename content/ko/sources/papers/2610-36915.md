# Do We Need an LLM to Know Why Sources Conflict? RAG 지식 충돌 Typing을 위한 Decision Models

**원문**: [arXiv:2610.36915](https://arxiv.org/abs/2610.36915) · **게시일**: 2026-10-27
**저자**: Parv Khatri, Harshul Jain, Mehak Kapoor, Tanya Sah

## 개요

검색된 sources가 disagree 할 때 올바른 반응은 disagree의 이유에 따라 달라진다. 여러 valid answers, contested topic, stale information, false source는 각각 다른 behavior를 요구한다. 이전 연구는 conflict type을 generator에 알려주면 response가 약 24 points 향상됨을 보였지만, type 예측 자체는 어렵다. 이 논문은 text generation 대신 single forward pass에서 fixed options에 대한 probabilities를 반환하는 typed decision models로 빠르고 cheaply conflict type을 분류할 수 있는지 묻는다. 거의 모든 evaluated decision models가 cost/latency에서 훨씬 유리하면서도 strong baseline accuracy와 match/beat한다. low-confidence fraction만 strong model로 보내는 cascade는 quality-cost trade-off를 더욱 favorable하게 만든다.

## 핵심 내용

- 지식 충돌 type은 적절한 answer behavior를 결정한다.
- decision model은 text generation을 피하고 fixed classification을 수행한다.
- 많은 모델이 expensive LLM baseline accuracy와 match/beat한다.
- evaluated decisions models는 bil Cost와 latency가 훨씬 낮다.
- cascade strategy는 low-confidence queries만 stronger model에 보낸다.
- 이 방법은 favorable quality-cost trade-off를 달성한다.

## 상세

prompt는 prior work에서 verbatim으로 사용되어 직접 comparability를 제공하지만 evaluation scope는 single benchmark and cascade construction에 한정된다. confidence score가 systematic errors를 놓칠 수 있고 routing policy quality가 trade-off에 directly 영향을 준다. 그럼에도 retrieval pipeline에서는 many conflict typing decisions에 text generation이 unnecessary 함을 보여준다.
