# GPBam: 검색 인식 독일 공법 시험 벤치마크

**원문**: [arXiv:2611.18981](https://arxiv.org/abs/2611.18981) · **게시일**: 2026-11-13
**저자**: Abdullah Al Zubaer, Lorenz Wendlinger, Simon Alexander Nonn, Michael Granitzer, Jelena Mitrović

## 개요

대륙법계의 법적 추론은 단순한 규칙 조회가 아니다. 독일 제1차 국가시험은 수험생에게 구조화된 의견서(Gutachten)를 요구한다. 쟁점을 파악하고 지배 규범을 지목한 뒤, 각 규범의 요건을 진술하고, 사실관계에 적용하여 결론에 이르는 논증을 문제의 하위 쟁점마다 반복해야 한다. 최종 결론이 맞더라도 중간 분석이 부실할 수 있으므로, 객관식이나 단답형 같은 선택형 형식만으로는 시험이 실제로 측정하는 것을 평가할 수 없다. GPBam(German Public Law Bar-style Exam)은 바로 이 문서를 중심에 둔다. 국가시험 대비 강좌에서 추출한 81개의 공법 사례와 모범 답안, 그리고 200개 법조문에 대한 암송 과제로 구성된다.

사례는 비공개 시험 대비 자료에서 나왔으며, 범위는 넓지만 반복 출제가 드물다. 저자들은 오염을 줄이기 위해 사례를 공개하지 않았고, 평가한 모델들에서 정답 암기(exact-solution memorisation)의 증거는 찾지 못했다고 보고한다. 각 모범 답안이 인용하는 규범이 곧 그 사례의 검색 정답 집합(gold set)이 되므로, 채점 대상 인스턴스 자체 위에서 검색과 장문 생성 능력을 함께 측정할 수 있다. 이는 GPBam을 단순한 법률 글쓰기 벤치마크가 아니라 법률 검색 벤치마크이기도 하게 하며, "법률 의견서에 실제로 어느 정도의 검색 품질이 필요한가"라는 질문을 가능하게 한다. 이 논문은 JURIX 2026(제39회 법지식·정보시스템 국제학술회의)에 채택된 논문의 확장판이다.

## 핵심 내용

- 모범 답안이 포함된 81개의 독일 공법 국가시험형 사례와, 200개 법조문을 대상으로 하는 암송 과제를 제공한다.
- 모범 답안은 평균 약 7,080단어로, 비교 대상인 LEXam의 평균 참조 답안(약 247단어)보다 훨씬 길다.
- 답안에 인용된 규범이 검색 gold set 역할을 하여, 같은 인스턴스에서 검색과 장문 생성을 동시에 평가한다.
- 검색 없이 32개 개방형·상용 모델을 평가한 결과, 점수는 100점 만점에 4.81에서 76.42까지 분포했다.
- 암송 과제로 측정한 verbatim 조문 회수율이 32개 모델에서 논술 점수와 ρ = 0.92로 강하게 상관했다.

## 상세

방법. GPBam은 사례당 하나의 완성된 Gutachten을 채점한다. 사실관계(Sachverhalt)가 제기하는 모든 질문에 답하는 목차와 완전한 서술이 포함되며, 출력 토큰 상한을 인위적으로 두지 않는다. 모범 답안에 인용된 규범이 사례별 검색 gold set을 정의한다. 평가는 두 가지 질문을 분리한다. 모델이 매개변수(parametric) 지식만으로 의견서를 얼마나 잘 쓰는가, 그리고 검색이 이를 얼마나 바꾸는가. 검색 측면에서는 질의 재작성·다양화, dense+lexical 융합, 재순위화(reranking) 등 점점 풍부해지는 검색 구성을 독일 법령 코퍼스 위에서 사다리처럼 비교하며, 별도의 조문 암송 과제로 200개 조문의 verbatim 회수를 측정한다.

결과. 검색 없이 32개 모델의 점수는 100점 만점에 4.81~76.42로 넓게 분포하며, 논술 품질은 verbatim 조문 회수율(ρ = 0.92)로 강하게 예측된다. 법령을 제공해도 향상은 소폭에 그친다. 7개 모델과 8가지 검색 구성에서 검색 성능은 거의 세 배 차이로 벌어지지만, 논술 점수는 최대 약 4.1점만 올랐고 그중 3개 모델에서는 유의미한 향상이 없었다. gold 규범 회수율 91%인 oracle 검색기를 써도 2~6점 향상에 그쳤다. 종합하면, 독일 공법 의견서 작성에서 검색 품질은 결정적 제약이 아니며, 조문 회수율로 드러나는 사전 법률 지식이 성능을 훨씬 강하게 좌우한다.
