# 행동 궤적을 통해 코딩 에이전트 해석하기

**원문**: [arXiv:2611.17440](https://arxiv.org/abs/2611.17440) · **게시일**: 2026-11-12
**저자**: Ibragim Badertdinov, Alexander Golubev

## 개요

표준 코딩 에이전트 벤치마크는 복잡한 다단계 상호작용을 이진 결과 — 이슈를 해결하고 테스트를 통과했는가 — 로 줄인다. 이렇게 얻은 해결률은 시스템 순위를 매기는 데는 쓸모가 있지만 시스템이 어떻게 작동하는지는 거의 말해 주지 않는다. Nebius 저자 두 명은 결과 뒤의 행동이 실패 진단과 모델·스캐폴드 비교에 중요하며, 행동은 기반 모델만이 아니라 시스템 전체에 달려 있다고 본다. 대규모 행동 분석이 어려운 이유는 실행 궤적이 이질적이기 때문이다. 하네스마다 도구·명령 형식·기록 스키마가 달라 직접 비교하면 의미적 행동과 구현 세부가 뒤섞인다.

해법은 공용 표현이다. 이질적 궤적 이벤트를 저장소 탐색, 파일 편집, 테스트 실행 같은 상위 행동의 공용 분류로 사상하는 결정론적·규칙 기반 파서다. 파서는 500개 표본 이벤트에서 6모델 합의 기준으로 감사됐고, SWE-rebench의 143,209개 실행 궤적 — 125개 에이전트 구성, 117개 고유 모델 — 에 적용됐다.

분석 결과는 세 가지다. 해결률만으로는 에이전트 행동을 특정할 수 없고, 행동 프로파일만으로 분리된 저장소는 물론 프로그래밍 언어를 넘어 배포 스택을 식별할 수 있으며, 스캐폴드 선택과 추론 노력 구성이 탐색·수정·검증 행동을 체계적으로 바꾼다.

## 핵심 내용

- 결과-매칭 비교: 같은 하네스를 공유하고 해결률이 거의 같은 구성 쌍 60쌍 전체(중앙값 |Δsolve| = 0.40pp, 최대 1.0pp 이하, 공유 과제 50개 이상)에서, 과제-페어 95% 부트스트랩 기준 모든 쌍이 6개 워크플로 지표 중 최소 2개에서 갈렸고 58/60(96.7%)은 3개 이상에서 갈렸다.
- 널 대조군 보정: 6개 지표 중 3개 이상 동시 분리는 동일 스택 절반-분할 널 실행에서 0.78%에 불과했다(실제 결과-매칭 쌍 96.7%). 차이는 실행 간 잡음이 아니다.
- 모델 세대는 메커니즘 수준에서 다르다. Claude Opus 계열은 `sed -n` 라인 범위 슬라이싱이 6.9%(Opus 4.6)에서 57.7%(Opus 5)로, `pytest -q` 무음 플래그는 22.7%에서 99.8%로 늘었다. 새 GPT 모델은 행동 수열을 압축해 도구 작업이 24.4회(GPT-5.4)에서 12.8회(GPT-5.6 Sol)로 줄면서 인식된 편집의 72.1%를 인라인 파이썬 스크립트로 처리했다.
- 추론 노력을 올리면 탐색이 늘어난다. GPT-5.5를 Medium에서 xHigh로 올리면 도구 행동이 24.2회에서 43.4회로, Claude Code의 Claude Opus 4.8은 Low 31.3회에서 xHigh 54.4회로 늘었다.
- 스캐폴드가 편집·읽기 방식을 결정한다. Claude Code 스택은 인식된 편집의 92.4%, 읽기의 90.5%를 네이티브 API로 처리한다. 일반 bash 하네스에서는 셸 리다이렉션과 인라인 파이썬이 주를 이루며, Codex는 편집의 30.9%를 네이티브 편집으로 처리한다.
- 교차 저장소 검색(파이썬 저장소 413개를 207/206으로 분할, 111개 스택, 222회 질의)은 해결 결과·토큰 수·네이티브 도구명을 배제한 8차원 프로파일로 무작위 기준 0.9% 대비 Top-1 85.1%·Top-3 96.8%를 기록했다. Go·Java·Python·Rust·TypeScript 교차 언어 검색(16개 구성, 8,880개 궤적)은 우연 기준 6.25% 대비 Top-1 90.3%·Top-3 98.8%다.

## 상세

8차원 프로파일은 정규화된 행동 좌표 4개(탐색, 파일 읽기, 비테스트 저장소 쓰기, 공식 테스트 호출)와 순차 검증 특성 4개(정규화 엔트로피, 도구 전환율, 쓰기 후 작업공간 검사, 미검증 종료)를 결합한다. 저자들은 한계를 분명히 밝힌다. 저장소 분리 분할만으로는 과제 구성을 통제하지 못하므로 검색 결과가 과제 독립적 행동 서명을 입증하지는 않으며, 다국어 패널에서 행동 구성만으로 Top-1 87.5%에 달하므로 프로파일은 상위 수준 추론이 아니라 하위 수준 운영 서명으로 해석해야 한다. 부록에는 관찰 이벤트 코드북, 항목별 합의율을 포함한 다중 모델 감사, 널 대조군 위양성률, 두 에이전트가 5회 롤아웃 모두에서 성공한 과제에서도 워크플로가 갈리는 사례를 포함한 페어드 과제 사례 연구 3건, Claude Code의 노력 분해, 컴퓨팅 자원이 있다. 결정론적 파서·분석 파이프라인·주석 궤적 부분집합이 공개됐다. 이 문서는 HF 등록 v1(2026년 11월 12일)을 다룬다.
