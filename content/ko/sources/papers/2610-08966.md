# 인류의 여섯 번째 감각: 멀티모달 모델의 직관적 시각 추론 벤치마킹

**Source**: Xingang Guo 외, arXiv, 2026-10-08

**Lead**: 인간은 픽셀이 묘사하는 것보다 훨씬 더 많은 것을 인지합니다—한눈에 과거 원인, 미래 궤적, 차량이 주차된 차 사이로 통과 가능한지, 방에서 누가 권위를 가지는지, 불문율이나 숨은 라벨 같은 추상 패턴을 파악합니다. 이 "여섯 번째 감각"은 빠르고, 제로샷이며, 일상 탐색을 뒷받침합니다. Humanity's Sixth Sense(HSS) 벤치마크는 이 직관적 시각 추론을 측정해, 프론티어 MLLM(GPT-6-astra 53.6%)이 인간 성능(93.1%)에 크게 미치지 못함을 드러냅니다.

## 배경

기존 시각 벤치마크는 다음 중 하나를 대상으로 합니다:
- **숙고적 전문가 분석**: 학문적 수학, 과학적 추론 (MMMU, MathVista).
- **저수준 지각**: 객체 탐지, OCR, 캡셔닝.

어느 것도 인간이 끊임없이 만드는 빠르고 직관적인 추론—시간적 외삽, 공간적 추론, 사회적 귀인, 추상 패턴 완성—을 포착하지 못합니다. HSS는 이미지와 비디오 입력 전반에 걸친 구조화된 분류로 이 공백을 메웁니다.

## HSS 벤치마크

**구조**: 직관적 추론 유형의 분류 체계 하에 다양한 이미지/비디오 입력 구성:
- **시간적**: 정지 프레임에서 과거 원인, 미래 궤적 추론.
- **공간적**: 맞음, 포함, 가림 추론.
- **사회적**: 권위, 주의, 상호작용 역학.
- **추상적**: 불문율, 숨은 라벨, 구조적 패턴.

각 항목은 시각 입력과 암묵적 구조를 탐구하는 인간 작성 프롬프트로 쌍을 이룹니다. 항목은 제로샷; 전문 지식 불필요.

**인간 베이스라인**: 93.1% 정확도 (참여자 연구).

## 결과

프론티어 MLLM 평가 (GPT-6-astra, Claude-4-Opus, Gemini-3-Ultra, 오픈 모델):
- **최고 모델 (GPT-6-astra)**: 최대 추론 노력 시 53.6%.
- **격차**: 인간 대비 ~40%포인트 차이.
- **에이전틱 설정** (동적 시각 조작, 다단계 추론): 격차 좁히나 닫지 못함.

복잡한 지각/지식 태스크에서 뛰어난 모델도 인간이 사소하게 여기는 직관적 추론에서 실패.

## SW 엔지니어 관점에서의 의의

- **평가 사각지대**: 현재 벤치마크(MMMU, MMBench 등)는 이 역량 미측정—모델이 높은 점수받으면서 일상적 시각 직관 결여 가능.
- **배포 위험**: 로보틱스, AR/VR, 보조 기술의 MLLM은 직관적 공간/시간/사회적 추론 필요; HSS가 격차 노출.
- **스케일링 한계**: 현재 벤치마크 스케일링만으론 이 격차 미해결—새로운 학습 목표나 아키텍처 필요할 수 있음.
- **에이전틱 완화**: 동적 시각 조작(줌, 크롭, 재생) 도움되나 단독으론 불충분.
