# UniSpark: 멀티모달 이해와 생성을 위한 하이브리드 어텐션 탐구

**원문**: [arXiv:2611.16517](https://arxiv.org/abs/2611.16517) · **게시일**: 2026-11-12
**저자**: Jiancheng Pan, Yuzheng Liu, Hengyuan Cao, Qiyuan Zhang, Yangyan Li, Biao Gong, Zheng Zhang, Ka Long Cheng, Xinyang Wang, Yujun Shen

## 개요

통합 멀티모달 모델은 서로 다른 두 작업을 동시에 감당해야 한다. 이해는 시각 입력을 해석해야 하고, 생성은 텍스트나 시각 조건에서 이미지를 합성해야 한다. 고해상도 이미지와 여러 장으로 이어지는 시퀀스가 시각 토큰 수를 폭발적으로 늘리면 두 작업 모두 비용이 급격히 커진다. UniSpark-9B는 이 문제를 하이브리드 어텐션으로 푼다. 백본은 브랜치당 약 9B 파라미터를 가진 혼합 트랜스포머 전문가 구조이고, 모든 층이 명시적인 쿼리-키 상호작용을 담당하는 전체 어텐션과, 순환 행렬 상태를 통해 맥락을 전파하며 시퀀스 길이에 선형으로 비용이 늘어나는 GatedDeltaNet 선형 어텐션을 섞어 사용한다.

논문의 핵심 모델링 아이디어는 뒤쪽 예측이 무엇을 볼 수 있는지를 정하는 것이다. 교차(interleaved) 생성에서 모델은 이미지를 노이즈가 남은 대상으로서 디노이징하고, 생성이 끝난 뒤에는 그 깨끗한 표현이 이후 텍스트와 이미지 예측의 맥락이 된다. UniSpark는 노이즈가 남은 대상을 사적으로 유지한다. 대상은 앞선 텍스트와 깨끗한 시각 블록의 공개 맥락을 읽을 수 있지만, 어떤 뒤쪽 블록도 그 대상을 볼 수 없다. 전체 어텐션 층은 블록 단위 마스크로 이를 강제하고, 선형 어텐션 층은 노이즈 블록 내부에서 일어난 순환 상태 갱신을 버림으로써 이를 강제한다.

학습은 이해와 생성을 함께 최적화하는 4단계 커리큘럼으로 진행되며, 이미지 합성을 512 규모에서 1024 규모 정밀화를 거쳐 2K까지 확장한다. 선정된 학습 데이터는 생성 샘플 159.7M개, 이해 샘플 213.4M개, 교차 시퀀스 624.8K개다. UniSpark는 MME-S에서 2470.3, GenEval에서 0.83을 기록했고, SFT 이후 추가 적응을 통해 비디오 생성과 비디오 편집 능력도 질적 예시로 보여준다.

## 핵심 내용

- UniSpark-9B는 브랜치당 약 9B 파라미터를 가진 혼합 트랜스포머 전문가 백본을 쓰며, 텍스트와 의미 시각 토큰은 이해 전문가가, VAE 잠재 토큰은 생성 전문가가 처리한다.
- 전체 어텐션 층은 토큰 간 명시적 상호작용을 담당하고, GatedDeltaNet 층은 앞선 맥락을 순환 행렬 상태로 압축해 시퀀스 길이에 선형인 비용으로 전달한다.
- 노이즈가 남은 시각 대상은 사적이다. 전체 어텐션 층에서는 어떤 블록도 이를 참조할 수 없고, 선형 어텐션 층에서는 출력을 만드는 데 쓴 상태 갱신이 뒤에서 버려지므로 이후 예측이 일시적 디노이징 노이즈에 노출되지 않는다.
- 전문가를 바꿔도 누적 맥락이 초기화되지 않는다. 이해 토큰과 생성 토큰은 각자의 파라미터로 쿼리, 키, 값을 계산하지만 순환 상태와 짧은 컨볼루션 이력은 공유한다.
- 학습 데이터는 생성 샘플 159.7M개, 이해 샘플 213.4M개(이 중 OCR 10.0M, 그라운딩 4.5M), 교차 시퀀스 624.8K개로 이루어진다.
- 이해 벤치마크에서 MME-P 1766.0, MME-S 2470.3, MMBench 86.7, MMVP 72.0으로 비교 대상 중 최고 점수를 기록했고, BAGEL 대비 MM-Vet에서 6.2포인트, MathVista에서 4.1포인트 앞선다. MMMU-Val은 56.7로 MetaQuery-XL의 58.6에는 못 미친다.
- 통합 SFT 이후 텍스트-이미지 생성 GenEval 전체 점수 0.83을 달성했고, Qwen3-VL 심사 하의 737개 ImgEdit 샘플에서 전체 3.13을 기록했다.
- BAGEL과 비교할 때 중간 이미지 생성 지연은 512 x 512에서 11.76초에서 7.27초로(1.62배), 1024 x 1024에서 45.80초에서 14.16초로(3.23배) 줄었다. 2048 x 2048에서는 SenseNova-U1보다 빠르다(51.48초 대 58.34초)하지만 피크 메모리는 62.74GB 대 37.39GB로 더 크다.
- 1024 해상도에서 BAGEL은 이미지 하나를 4,096개 토큰으로 표현하는 반면 UniSpark와 SenseNova-U1은 1,024개를 쓰므로, BAGEL의 높은 초당 토큰 처리량이 더 빠른 이미지 생성을 의미하지는 않는다.

## 세부 사항

### 공개 맥락과 사적 대상을 둘러싼 하이브리드 구조

모든 디코더 층은 전문가별 정규화, 어텐션 투영, 피드포워드 파라미터를 따로 두고, 두 전문가는 각 어텐션 연산자가 허용하는 맥락을 통해서만 정보를 주고받는다. 교차 시퀀스 프로토콜은 텍스트, 노이즈 대상, 깨끗한 맥락 블록의 나열에서 드러난다. 뒤따르는 텍스트나 노이즈 블록은 이전의 깨끗한 시각 맥락을 쓸 수 있지만 이전 노이즈 대상은 볼 수 없고, 노이즈 대상 역시 자신의 깨끗한 후신을 훔쳐볼 수 없다. 블록 내부에서는 텍스트가 인과 어텐션을, 깨끗한 시각 블록과 노이즈 대상이 양방향 어텐션을 사용한다. 선형 어텐션 층에서는 현재 블록이 공개일 때만 공개 상태가 전진하며, 노이즈 대상은 앞선 공개 상태에서 출발해 자기 출력을 위한 지역 갱신을 수행한 뒤 그 갱신을 폐기한다.

### 데이터와 단계적 학습

4단계 커리큘럼은 공동 멀티모달 기반 학습으로 시작해, 해상도 확장 단계에서 생성을 512 규모로 올리고, 고해상도 정밀화 단계에서 1024 규모를 거쳐 2K까지 확장하며, 지도 학습 단계에서 답변 정확도와 지시 수행 능력을 다듬는다. 이해 입력은 독자적인 해상도 예산을 유지하므로 생성 해상도를 올린다고 해서 모든 의미 조건이 같은 비율로 늘어나지는 않는다. 교차 시퀀스는 이후 단계에서도 계속 투입되어 하이브리드 어텐션이 더 긴 시각 블록과 출력 간 의존성을 다루게 한다.

### 측정된 효율과 한계

효율성 실험은 각 모델을 전용 H20-3e GPU에서 BF16 정밀도, 배치 크기 1로 구동해 12회 측정의 중간값 지연을 보고한다. UniSpark의 이점은 해상도가 커질수록 확대되지만 메모리 비용이 따르는데, 저자들은 이를 해상도 의존적 지연 이점과 메모리 비용으로 정직하게 명시한다. 또한 ImgEdit 점수는 기준 모델들과 심사 모델이 달라 직접 비교가 아니라 참고치임을 밝히고, MMMU 격차를 근거로 지각 능력이 좋다고 해서 추론 능력까지 균일하게 좋은 것은 아니라고 짚는다.
