# Reasoning LLM에서 순차적 실험 설계를 amortize하기

**원문**: [arXiv:2610.20832](https://arxiv.org/abs/2610.20832) · **게시일**: 2026-10-14
**저자**: Anita Kriz, Antonin Berthon, Nicolás Astorga, Mihaela van der Schaar

## 개요

LLM은 광범위한 사전학습 지식과 강력한 추론 능력을 가지지만, 실험 설계 과제에서 정보를 적응적으로 수집하는 데 약하다. 이 연구는 information-gain 보상을 사용해 action selection을 이끄는 reasoning을 명시적으로 학습함으로써 sequential Bayesian experimental design(BED)을 LLM에 amortization하는 방법을 탐구한다. 또한 실험 generative model을 LLM 자신의 belief와 독립적으로 지정해, 선택한 model 하에서 expected information gain을 최적화한다.

## 핵심 내용

- sequential BED를 LLM의 학습 가능한 reasoning 스킬로 amortization한다.
- information-gain reward로 정보 수집 행동을 학습한다.
- generative model 지정을 LLM belief와 독립적으로 둔다.
- Twenty Questions에서 정보 수집/과제 성능을 개선한다.
- 더 낮은 비용으로 inference/training-time BED baseline을 능가한다.
- 미지 categories로 일반화하고 Medi-Q clinical dialogue로 transfer한다.

## 상세

정보 수집은 LLM에서 일반화可能な reasoning 스킬로 학습할 수 있으며, 이를 통해 더 싸고 효과적인 sequential experimental design이 가능하다.
