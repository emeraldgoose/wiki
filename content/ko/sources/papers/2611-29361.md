# 어텐션 맵을 넘어서: 비주얼 값으로 의료 MLLM의 이해와 개선

**Source**: [arXiv:2611.29361](https://arxiv.org/abs/2611.29361) · **게시일**: 2026-11-22 (v1)
**Authors**: Yichen Zhao, Fenghe Tang, Wenxin Ma, Rongsheng Wang, Zihao Wan, Shaohua Kevin Zhou

## 개요

의료 MLLM은 보통 올바른 영역을 바라보는지로 평가되며, 공간 어텐션 맵 [M]을 시각 지각의 핵심으로 본다. [M]은 어디를 읽을지를, 비주얼 값 [V]는 무엇을 읽을지를 제공한다. 이 논문은 같은 해부 구조의 비대조(NC)/대조증강(CE) 이미지 쌍(간 CT, 뇌 MRI, 유방 MRI, 환자 단위 분할, 부록 A의 주석 기반 샘플링과 임상의 검토)으로 만든 페어 진단 VQA 데이터셋으로 이 가정을 검증한다. CE 분기가 정답, NC 분기가 오답인 같은 질문에서 말이다. 발견 1: Qwen3-VL과 MedGemma 모두 NC/CE 분기의 층별 이미지 토큰 어텐션 비율과 전경 어텐션 맵 코사인 유사도가 매우 높게 유지되는데 답은 반대다. 즉 어디를 보는지만으로는 예측 차이를 설명할 수 없다. 발견 2: 분기 간 [M]과 [V]를 양방향으로 교환한 결과, 예측은 [V]에 훨씬 민감하다. CE 값을 NC 분기로 옮기면 CE 어텐션 가중치를 옮기는 것보다 훨씬 큰 이득이 있고, NC 값을 CE 분기로 옮기면 훨씬 큰 손해가 난다. NC 어텐션 가중치를 가우시안 잡음으로 교란(질량 유지)해도 CE 값의 이점은 유지된다. 따라서 어텐션은 값을 활용하게 하지만 그 이점 자체를 설명하지 못한다.

이 발견에 이에 기반한 VIVID(Visual Value Intervention Distillation)는 CE 지식을 NC 전용 학생에게 on-policy로 증류한다. 층마다 보조 분기가 누적 헤드 평균 어텐션이 tau = 0.5에 도달하는 최소한의 비배경 이미지 토큰 집합을 고르고, 그 값들을 CE 교사의 것으로 alpha = 0.5 강도로 섞되 어텐션 가중치는 고정한다(식 1). 그 결과 생긴 예측 이동 u_t = C(log p_aux - log p_S)(상위 K=100 토큰 + 잔차 빈에서 중심화)를 이용해 반응 유도 목표를 만든다. 교사 교정 r_t = C(log p_T - log p_S)를 u_t에 투영하되 양의 정렬만 남기고(d_t, 식 3), q_t = softmax(log p_S + d_t)(식 4). 학습은 JSD(p_S, q_t)와 약한 CE 지도 항(가중치 w_t = clip(1 - ||d_t|| / ||r_t||), 식 5)을 최소화하며 NC 학생만 갱신하고 추론은 NC 이미지만 사용한다.

## 핵심 내용

- 진단 데이터셋: 간 CT, 뇌 MRI, 유방 MRI의 NC/CE 페어 VQA. 환자 단위 분할(유출 방지), 이미지 표준화, 주석 기반 샘플링, 주석 근거 증거 생성, 임상 QA(부록 A). 테스트는 모달리티/암종별 내부+외부 6개.
- 발견: NC/CE 분기의 어텐션 맵이 정반대 답에도 불구하고거의 동일(발견 1); 양방향 [M]/[V] 교환에서 [V]가 예측 변화를 지배(발견 2, 표 1), 어텐션 가중치 잡음 교란에도 견고(표 2).
- VIVID 주요 결과(표 3, 정답률): Qwen3-VL-2B + VIVID는 간 내부 66.47 / 외부 52.64, 뇌 86.37/82.53, 유방 79.44/75.25로 시판 최고(Gemini 3.5 Flash 54.26, 간 내부)와 on-policy 증류 기준선(OPSD 63.98, Med-OPD 64.36, VA-OPD 62.85)을 앞선다. 4B + VIVID는 71.29/57.91/86.46/83.06/80.72/75.19로 시판 최고 70.99와 모든 증류 기준선을 능가한다. 시판 최고 대비 델타가 대부분 양수(+12.21 간 내부 2B, +17.03 4B 등).
- 제로샷 일반화 유지: VQA-RAD, SLAKE, PMC-VQA, ChartQA에서 강한 점수 유지. 모든 방법은 추론 시 NC 이미지만 받는다.
- 하이퍼파라미터: alpha = 0.5, tau = 0.5, K = 100. 부록 C에 학습 설정, 시드, 질문 유형, 패치 선택/투영 분석, 생성 증거 품질 절제.

## 세부 사항

3장은 진단을 상술한다. 질의 [Q]가 이미지 토큰 키 [K]에 어텐션해 [M]을 만들고, 값 [V]를 집계해 판독값을 이룬다. 페어 데이터셋 구축(환자 단위 분할, 표준화, 주석 유도 샘플링, 주석 근거 증거, 임상 QA)을 설명한다. 4장은 방법의 식 (1)-(5)를 위와 같이 정의한다. 5장은 표 3과 분포/비주얼 값 분석(5.3)을 보고한다. 부록 B는 데이터셋 간 어텐션 맵 유사도, 확장 [M]/[V] 개입 분석, 학습 레짐 간 일관성을 다룬다. 프로젝트 페이지: qiuzyc.github.io/VIVID.
