# Instruction Capacity: 제어된 부하에서 언어 모델의 행동과 성능 저하

**원문**: [arXiv:2610.36095](https://arxiv.org/abs/2610.36095) · **게시일**: 2026-10-26
**저자**: Hennadii Kutomanov

## 개요

언어 모델의 지시 이행 품질은 부하가 커질수록 떨어지지만, 부하 단위로 표현되는 모델 한계량과 그 불확실성은 아직 없다. 이 연구는 load가 의미 없는 텍스트의 단일 토큰 단어를 치환하는 규칙으로 구성되는 측정 도구를 제안한다. 지시는 원자적이고 규칙은 task 구성에 의해 독립적이며, 각 규칙 적용 결과는 계산 가능한 참조 정답으로 결정된다.

단어 발생마다 위치와 규칙 번호가 알려진 베르누이 시도가 된다. 통계 모델은 치환 확률이 텍스트 길이, 단어 위치, 치환 밀도, 규칙 수, 규칙 번호에 어떻게 의존하는지 측정한 뒤 smooth 법칙으로 기술하고 코딩 선택에 의존하지 않는 참조 수준을 복원한다.

## 핵심 내용

- instruction capacity를 정의한다: 주어진 정답 치환 비율에서 모델이 유지하는 규칙 수(불확실성 포함).
- GPT-4o mini 측정(2,958 requests, 642,430 시도)에서 모든 load factor와 답변 collapse에 규칙적 법칙이 나타났다.
- 정답 치환 비율 0.95에서 instruction capacity는 약 37-38 규칙, 전체 치환 밀도에서는 약 18-19 규칙이다.
- 도구 코드, 측정 데이터, passport가 공개되며 passport의 모든 수치는 공개 지점으로부터 재계산된다.
- 모델 passport는 프롬프트의 instruction load를 측정하는 미래 계측기의 교정 자료로 쓰인다.

## 상세

방법은 지시 이행을 제어된 베르누이 시도로 바꿔 부하가 성능을 어떻게 저하시키는지 분리한다. 규칙 수로 표현된 capacity와 불확실성을 통해 모델과 프롬프트 설계 간 비교 가능한 값을 제공한다.
