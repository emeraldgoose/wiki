# CRISP: 구조적 질량 기반 라우팅을 쓰는 입력 적응형 희소 프리필

출처: Huu Huy Nguyen 외 6인, arXiv:2609.01925, 2026-09-01. EMNLP 2026 본회의 채택.

**핵심 요약**: 긴 컨텍스트 LLM 추론의 프리필 단계는 2차로 커지고, 고정 패턴·오프라인 프로파일 희소 어텐션은 입력 의존적 어텐션 구조에 적응하지 못합니다. FlexPrefill 같은 동적 라우터는 헤드를 실시간 라우팅하지만 간접적인 Jensen-Shannon Divergence 프록시(자체 matmul+KL 오버헤드 포함)와 사후 softmax 질량 구조를 무시하는 누적 커버리지 임계값에 의존합니다. CRISP는 둘 다 고칩니다. 싱크·최신 위치의 질량에서 라우팅을 직접 읽는 구조적 프록시 **C_struct**(Llama 헤드의 94.0%에서 JSD 판정 재현, 추가 비용 0)와 노이즈 플로어에 접지된 **싱크 인식 임계값**입니다. 두 모델 계열의 InfiniteBench·RULER·LongBench에서 CRISP는 최강의 희소 기법으로, 검색 중심 벤치마크에서 dense 어텐션과 동등 이상에 **최대 +28.0pp 회복**, **512k 토큰에서 5.30배 가속**을 냅니다.

## JSD 라우팅은 간접적이고 비싸다

FlexPrefill은 각 헤드를 Vertical-Slash 경로(집중 헤드)나 Pooled-Estimation 경로(확산 헤드)로 보내고, 풀링 어텐션 추정치와 쿼리별 평균 사이의 JSD로 판정합니다. 그 풀링 추정치는 비교のために만 존재합니다 — 헤드마다 추가 matmul, 두 번째 softmax, 두 번의 로그·리덕션 패스가 듭니다. CRISP는 현재 아키텍처의 집중 헤드가 질량을 구조적으로 예측 가능한 자리(어텐션 싱크+국소 최신 윈도우)에 둔다는 점을 봅니다. 앵커 위치 질량 자체가 라우팅 신호인 셈입니다. C_struct는 인덱스 선택용으로 이미 계산된 프록시 어텐션 맵 위의 상수 시간 슬라이스 리덕션으로, JSD와 Llama-3.1-8B 94.0%·Qwen2.5-7B 88.1% 일치합니다.

## 질량 절벽이 누적 임계값을 무너뜨린다

사후 softmax 질량은 경직된 위계를 이룹니다. 건축적 싱크(때로 전체 질량의 90% 초과), 과제 관련 신호 블록, O(1/n)으로 옅어지는 near-zero 배경 노이즈입니다. 누적 커버리지 임계값 gamma는 신호와 노이즈 사이 절벽을 항해하지 못합니다 — 싱크 안에서 끝나거나(**싱크 전용 붕괴**, 의미 토큰 0개 선택), 노이즈로 넘어가 **O(n) 배경 토큰**을 긁어모읍니다. gamma 튜닝으로 탈출 불가입니다. FlexPrefill을 0.95에서 0.97로 올려도 정확도 이득은 거의 없고 지연시간만 폭증합니다. CRISP의 싱크 인식 규칙은 비앵커 블록 평균 배경 질량의 alpha배를 임계값으로 삼고(alpha=1.0이 무보정 기본값), 예산이 커버리지 목표가 아니라 과제 복잡도에서 나오게 합니다.

## 결과가 보여주는 것

CRISP alpha=1.0은 검색 중심 InfiniteBench에서 정확한 dense 어텐션과 동등 이상(Llama 48.7 vs 48.6, Qwen 28.7 vs 24.0)이며 FlexPrefill 대비 큰 검색 격차를 회복합니다.

| FlexPrefill 대비 이득 | Llama | Qwen |
|---|---|---|
| KV 검색 (InfiniteBench) | +17.8pp | — |
| Passkey (InfiniteBench) | 0.0pp | +28.0pp |
| 구절 검색 EN / ZH (LongBench) | +12.50 / +3.16pp | +13.50 / +4.50pp |

지연시간은 이론대로 스케일됩니다. 세 CRISP 설정 모두 131k 토큰 너머에서 FlexPrefill을 추월해 단일 H100 512k에서 FlashAttention 대비 5.17배/5.30배/5.40배에 도달합니다. Ablation은 두 수정이 상호작용함을 보입니다 — C_struct 라우팅만 쓰면 깨진 gamma 선택에 더 많은 헤드가 노출돼 Llama에서 후퇴하고, 완전한 조합만 아키텍처 전반에 안정적입니다.

## 주의할 점

근거는 7~8B 두 모델 계열에 한정됩니다. C_struct는 어텐션 싱크를 이용하므로 싱크 억제 아키텍처(예: 게이트 어텐션)에서는 깨지고 논문도 이를 명시합니다. Llama RULER는 소폭 후퇴(-0.40pp)합니다 — 집계 과제는 중간 범위 넓은 커버리지가 필요한데 보수적 임계값이 과소 선택할 수 있습니다. ~64k 토큰 미만에서는 희소 프리필이 dense에 집니다(라우팅 오버헤드 우세). 디코딩 시점 KV 선택이 아니라 프리필 전용입니다.

## SW 엔지니어와의 관련성

- 긴 컨텍스트 모델 서빙이라면 ~64k 토큰 미만에서는 희소 프리필을 끄세요 — 라우팅 오버헤드가 우세합니다. 131k 너머에서는 CRISP류 기법의 승리가 누적됩니다.
- 두꺼운 꼬리 질량 분포 위의 커버리지 목표(top-p식 gamma)는 조용히 O(n) 노이즈를 긁어모읍니다 — 노이즈 플로어 기준 임계값을 쓰세요.
- 가장 싼 라우팅 신호는 이미 계산 중인 구조인 경우가 많습니다. 프록시 matmul을 추가하기 전에 헤드당 오버헤드를 감사하세요.
- 검색 중심과 집계 중심 워크로드는 동작점이 다릅니다(정확도는 alpha=1.0, 속도는 1.25~1.5) — 모델별이 아니라 워크로드별로 고르세요.
