# MomentMem: 로봇 조작을 위한 핵심 순간 암기

**원문**: [arXiv:2611.26745](https://arxiv.org/abs/2611.26745) · **게시일**: 2026-11-19 (v1)
**저자**: Guangyu Zhao, Yongchang Zhang, Ruizhang Jiang, Zhihong Yu, Yuhao Zhang, Tao Wu, Qimin Zhou, Kunsong Shi, Haoran Wen, Zeyu Zhang, Yin Li, Kun Zhan, Yiwu Zhong

## 개요

로봇 조작은 종종 현재 관측할 수 없는 시각 정보 — 예컨대 물건의 원래 위치 — 를 기억해야 한다. 기존 접근은 전체 관측 이력을 유지하거나(장기 상황에서 중복) 텍스트 요약을 쓰는데(정확한 시각 세부사항을 잃는다). 이 논문은 시각적 순간 기억, 즉 핵심 순간의 그러한 세부사항을 나중 조작을 위해 유지하는 능력을 연구한다. 이를측정하기 위해 저자들은 VMBench를도입한다. 공간 위치, 시각적 외형, 그 연관성의 정밀한 시각 세부사항를 회상해야 하는 9개 폐루프 조작 작업 묶음이다.

MomentMem은 두 관심사를 분리하는 계층적 아키텍처다. VLM 기반 암기 모듈이 행동 예측과 독립적으로 시각 관측에서 키프레임을 선택하고(EventVLA는 한 모델 안에서 예측된 미래 행동으로부터 키프레임을 예측하는 것과 대조), 실행 모듈이 선택된 기억에 조건화되어 행동을 예측한다. 이 분리는 암기 선택을 폐루프 작업 성공과 분리해 평가하고 암기 모듈의 일반화를 독립적으로 연구하게 한다. VMBench에서 MomentMem은 평균 49.9% 성공률 — 최고 베이스라인보다 31.7%p 높다(EventVLA 18.2%, NativeMEM 15.8%). 5개 작업에서 최고, 1개에서 동률이며, Placement Imitation, Mine Sweeper, Seal Checking에서 이득이 가장 큰데 이 작업들은증거가 시야에서 사라진 뒤에도 정밀한 시각 증거를 유지해야 한다. 기억 없는 π0.5 정책은 7.0%에 불과하다. 암기 모듈은 미학습 외형에도 제로샷 전이되고, 소수 암기 주석만으로 미학습 작업에 적응해 43.7%를 달성한다(전체 암기감독 시 44.3%). RMBench에서도 경쟁력 있고 실제 로봇 조작을 개선한다.

## 핵심 내용

- 문제: 기억 의존 조작은 현재 뷰에서 사라진 시각 증거가 필요하고, 전체 이력은 중복이며 텍스트 요약은 정확한 시각 세부사항을 잃는다.
- VMBench: 공간 위치, 외형, 연관성 회상이 필요한 9개 폐루프 조작 작업. 암기 모듈 전이 테스트용 시각 OOD 변형과 소수샷 적응용 보류 작업 포함.
- MomentMem 아키텍처: VLM 암기 모듈이 관측에서 키프레임을 선택(행동 예측과 독립적), 실행 모듈이 선택된 기억에 조건화 — 암기 선택과 작업 성공의 분리 평가 가능.
- VMBench 평균 성공률 49.9%, 최고 베이스라인 대비 +31.7%p(EventVLA 18.2%); 기억 없는 π0.5는 7.0%. Placement Imitation, Mine Sweeper, Seal Checking에서 이득 최대.
- 암기 일반화: 미학습 외형에 제로샷 전이. 미학습 작업에 소수 암기 주석만으로 43.7%(전체감독 44.3%).
- RMBench 경쟁력과 실제 로봇 조작 개선도 보고. 코드 공개.

## 상세

베이스라인들은 기억 저장과 사용 방식이 다르다. 순환 상태, 메모리 뱅크, 압축 토큰, 규칙/휴리스틱 키프레임 선택, 행동 조건화 키프레임 예측(EventVLA) 등. MomentMem의 암기 모듈은 미리 정의된 규칙 대신 나중에 필요한 증거를포함 관측을 언제 저장할지 학습한다. VMBench 작업은 폐루프로 공간 위치, 외형, 연관성 기억을 아우른다. 시각 OOD 변형은 암기 모듈이 작업 의미가 아닌 외형에 의존하는지를 검증한다. 실험은 작업별 폐루프 성공률, 암기 선택 품질, 제로샷 OOD 전이, 보류 작업의 소수샷 적응 곡선, RMBench와 실제 로봇 결과를 보고한다.
