# M3OPD-Reasoner: Multi-Teacher On-Policy Distillation으로 멀티모달 추론을 사후학습하는 공개 레시피

**Source**: [arXiv](https://arxiv.org/abs/2611.23034)
**게시일**: 2026-11-18

## Overview

Multi-Teacher On-Policy Distillation(MOPD)은 단일 학생 모델이 자기 자신이 생성한 응답으로 학습하면서 여러 도메인 교사의 스킬을 흡수하게 한다. M3OPD-Reasoner는 이미지 STEM, 이미지 지각, 비디오 세 추론 도메인에 걸친 비전-언어 모델(VLM) 사후학습을 위한 완전 공개·완전한 레시피다. 저자들은 M3OPD-SFT-1.35M(지도 미세조정용)과 M3OPD-RL-193K(검증 가능한 보상의 RL용) 두 데이터셋을 큐레이션하고, Qwen3.5-9B에서 출발하는 레시피들을 비교했다: 혼합 도메인 학습(MixSFT / MixRL), 도메인별 GSPO 교사 학습(직접 또는 SFT 워밍업 후), 그리고 그 교사들을 MOPD로 하나의 학생으로 증류.

오염 제거된 21개 벤치마크에서, Qwen3.5-9B에서 직접 학습한 GSPO 교사들을 증류한 MOPD가 최고의 레시피다: 학생은 각 교사에 자기 도메인에서 근접하며, 같은 프롬프트에서 평균적으로 혼합 학습 베이스라인을 능가한다. MOPD는 MixRL이 따로 학습해야 할 도메인 역량을 이미 병합하므로, 그 학생은 RL을 위한 더 강한 출발점이다 — 같은 프롬프트가 MOPD 학생을 더 끌어올려 붕괴 없이 주 모델 M3OPD-Reasoner-9B를 만든다. 모든 데이터, 학습 코드, 모든 단계의 체크포인트가 공개됐다.

## Key points

- Overall(21개 벤치마크, avg@8): Qwen3.5-9B 69.4 → MixRL 74.4(+5.0), MixSFT 67.7(−1.7), MixSFT로부터의 MixRL(베이스라인) 73.5(+4.1) → MOPD(base에서 직접 학습한 교사) 75.2(+5.8) → M3OPD-Reasoner-9B = MOPD + MixRL 75.9(+6.5). SFT 워밍업 계열도 교사 75.2 → MOPD 75.2 → +MixRL 74.8.
- 같은 프롬프트에서의 MOPD vs 혼합 학습: 직접 학습한 교사의 MOPD는 base로부터의 MixRL을 평균과 대부분의 벤치마크에서 능가; MixSFT 단독은 해롭다(이미지 STEM 평균 −6.6).
- MOPD 위에 MixRL을 얹어도 붕괴는 없다 — 두 학생 변형 모두에서 21개 벤치마크 대부분이 향상되고 소수의 하락은 작다; 가장 큰 이득은 비디오에서 나온다. 저자들 아는 한 MOPD 위에 같은 프롬프트로 MixRL을 얹은 VLM 레시피는 이전에 연구된 바 없다.
- M3OPD-SFT-1.35M과 M3OPD-RL-193K는 이미지 STEM·이미지 지각·비디오를 포괄하며, 21개 평가 벤치마크에 대해 오염 제거됐다.
- 공개물: 완전한 데이터, 학습 코드, 모든 단계의 체크포인트(SFT, 도메인 교사, MOPD 학생, 최종 모델)를 재현 가능한 연구를 위해 릴리스.

## Details

- 레시피: SFT(lmms-engine) → 도메인별 GSPO 교사(verl + vLLM 롤아웃) → MOPD(학생이 응답을 샘플링하고 도메인 교사가 토큰마다 채점; 프롬프트 도메인으로 라우팅) → 같은 프롬프트·같은 GSPO 설정·규칙 기반 검증 보상의 선택적 MixRL.
- 평가: lmms-eval, thinking 활성화, 응답 32,768 토큰 상한; 질문당 8회 샘플링(T=0.6, top-p 0.95, top-k 20), avg@8 정확도; 이미지 ≤ 1,605,632 px, 비디오는 최대 150프레임.
