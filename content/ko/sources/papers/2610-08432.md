# EMHO: 경험 흔적으로 체화 에이전트 하네스 최적화하기

출처: Hyun Jung Lee 외 5인, arXiv:2610.08432, 2026-10-06.

**핵심 요약**: 체화 에이전트 개선은 보통 모델 자체를 훈련하는 데 집중하고, 계획·컨텍스트·도구 사용을 제어하는 주변 **에이전트 하네스**는 사람이 설계합니다. 이 논문은 희소한 환경 피드백 아래에서 하네스가 **경험 흔적만으로 스스로 개선**될 수 있는지 묻습니다.

## EMHO

**EMHO**(EMbodied Agent Harness Optimization)는 체화 모델을 **동결**한 채 실행 궤적과 이전 하네스 이력을 분석해 하네스를 반복 수정하는 자기 진화 프레임워크입니다. 단순 스킬이나 복구 프롬프트를 넘어, 에이전트가 **진행 상황을 모니터링하고, 비전 도구를 쓰고, 관찰에 근거를 붙이고, 실패에 대응하는 방식** 자체를 바꿉니다. 여러 하위 과제를 하나의 하네스로 지원하기 위해 **EMHO-Merge**를 도입합니다. 에피소드 수준 이득과 손실로, 수정된 행동을 언제 어떻게 적용할지에 대한 증거 기반 개선을 안내해 공유 하네스 공동 최적화의 상충을 다룹니다.

## 결과

EmbodiedBench의 내비게이션·조작 과제에서 EMHO는 Qwen 9B와 27B 모델 모두 과제 성공률을 일관되게 개선했습니다. 정성 분석은 EMHO가 실패와 비생산적 행동에서 복구하는 수준을 넘어, 체화 에이전트가 환경을 해석하고 상호작용하는 방식을 재구성함을 보였습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 하네스 진화가 특정 벤치마크에 과적합되거나, 희소 피드백에서 잘못된 인과를 학습할 수 있습니다. 모델 동결 대비 훈련 기반 개선과의 비용 비교, 진화 반복 예산은 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 에이전트 성능 문제를 모델 교체로만 풀지 말고, 계획·도구 사용·실패 대응 프롬프트와 제어 흐름을 버전 관리되는 하네스로 분리하세요.
- 실행 궤적과 하네스 변경 이력을 남기면 하네스 자체를 데이터로 개선할 수 있습니다.
- 여러 과제를 하나의 하네스로 묶을 때는 에피소드 단위 이득·손실로 적용 범위를 좁히세요.
