# FlowTranslator: Flow 기반 편집을 이용한 훈련 없는 이미지 내 기계 번역

**원문**: [arXiv:2611.04303](https://arxiv.org/abs/2611.04303) · **게시일**: 2026-11-03
**저자**: Zhixian Li, Xingsong Ye, Yongkun Du, Yunyan Xiao, Yanglin Huang, Pinxuan Chen, Jiyu Zhuang, Cong Xu, Zhineng Chen

## 개요

이미지 내 기계 번역은 주변 시각 문맥을 보존하면서 이미지 안의 텍스트를 번역으로 바꾼다. 기존 작업별 모델은 한 쌍의 번역 전후 이미지가 많이 필요하다. FlowTranslator는 OCR과 LLM으로 번역 프롬프트를 생성한 뒤 텍스트-이미지 디퓨전 모델에 주입하는 훈련 없는 프레임워크다. 초기 궤적에서 텍스트 영역의 target 브랜치 노이즈를 부분적으로 분리하는 Region Coupling Release와 중간 궤적에서 편집 변위를 증폭하는 Coupling Expansion으로 정확하고 자연스러운 번역 텍스트 생성을 제어한다.

## 핵심 내용

- 접근법은 완전히 훈련 없이 동작한다.
- 다국어 텍스트 생성 능력을 이미지 번역에 전이한다.
- OCR과 LLM이 번역 프롬프트를 생성한다.
- Region Coupling Release는 초기 궤적에서 작동한다.
- Coupling Expansion은 중간 궤적에서 변위를 증폭한다.
- ScenePair 전체 이미지 번역에서 exact-match 40.1%를 달성한다.

## 상세

EasyOCR read-back protocol에서 FlowTranslator는 평균 PRIM BLEU 20.6, COMET 57.2을 달성하며 훈련 기반 UniTranslator를 앞선다. 중국어로 번역된 보다 도전적인 ScenePair 전체 이미지 사진에서 40.1% exact-match accuracy를 기록했고 기존 편집 시스템을 넘어섰다. 일부 기존 시스템은 전체 번역 작업이 아니라 텍스트 렌더링 단계만을 다룬다. 결과는 OCR과 read-back 조건에 의존할 수 있다.
