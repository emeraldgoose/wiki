# APEX: 극한 압축을 위한 비동기 프리픽스 디노이징

출처: David Dinkevich 외 3인, arXiv:2610.12843, 2026-10-09.

**핵심 요약**: 잠재 토큰을 줄이면 확산 생성이 저렴해질 수 있습니다. 그러나 공격적인 잠재 압축은 **재구성-생성 딜레마**를 만듭니다. 채널을 늘리면 재구성은 좋아지지만 생성이 어려워집니다. **APEX**(Asynchronous Prefix denoising for EXtreme compression)는 **계층적 잠재 공간**과 채널 그룹에 대한 **비동기 디노이징**을 결합합니다.

## 작동 방식

오토인코더가 채널 프리픽스를 **구조에서 세부 순**으로 정렬하고, 하나의 공유 디노이저가 토큰을 추가하지 않으면서 이들을 **어긋난 국소 시간(staggered local times)** 으로 생성합니다. 구조 채널은 먼저, 세부 채널은 나중에 생성되는 식으로 압축의 어려움을 시간 축으로 분산하는 것입니다.

## 결과

ImageNet-512에서 APEX는 평가한 모든 채널 수에서 **64x·128x 압축** 기존 방법을 앞섰습니다. 훈련·가이드 샘플링 연산을 맞춘 조건에서도 모든 예산에서 256토큰 모델을 앞섰고, 연산이 적을수록 이득이 컸습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 극한 압축은 세밀한 텍스트·얼굴 재현에서 손실이 커질 수 있고, 비동기 시간 스케줄의 튜닝이 필요합니다. FID 외 지각 품질과 다해상도 일반화는 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 확산 생성 비용을 줄이려면 토큰 수만 줄이지 말고, 잠재 채널을 구조·세부로 나눠 생성 순서를 다르게 하는 설계를 검토하세요.
- 재구성 품질과 생성 난도의 상충을 채널 설계로 분리할 수 있습니다.
