# APEX: Asynchronous Prefix Denoising for Extreme Compression

이 논문은 확산 모델에서 극단적인 공간 압축의 한계를 극복하기 위한 APEX 프레amework를 제안합니다. 기존 방법은 압축이 증가할수록 재구성과 생성 사이의 딜레마가 심화됩니다. APEX는 계층적 잠재 공간과 비동기적 노이즈 제거를 결합하여 이 경계를 이동시키고, 채널 접두사를 구조에서 세부로 정렬하며 공유된 노이즈 제거기가 서로 다른 지역 시간에서 이들을 생성하도록 합니다.

## 배경
확산 모델은 점점 Transformer 기반으로 전환되며 입력 토큰 수에 따라 주의 비용이 이차적으로 증가합니다. 잠재 확산은 이미지를 작은 잠재 토큰으로 압축하여 비용을 줄이지만, 공격적인 공간 압축은 재구성과 생성 사이의 상충을 만듭니다. 채널 수를 늘리면 재구성은 향상되지만 생성이 더 어려워집니다.

## 방법
APEX는 계층적 잠재 공간과 비동기적 노이즈 제거를 결합합니다. 자동 인코더는 채널 접두사를 구조부터 세부까지 정렬하고, 하나의 공유된 노이즈 제거기가 서로 다른 지역 시간에서 이들을 생성합니다. 이를 통해 극단적인 공간 압축에서도 경쟁력 있는 생성 품질을 유지할 수 있습니다.

## 결과와 시사점
APEX는 기존 방법 대비 압축 효율과 생성 품질을 동시에 개선함을 실험으로 보여줍니다. 이는 향후 고해상도 확산 모델의 효율적인 배포를 위한 중요한 설계 원칙을 제공합니다.
