# Prefill-to-autoregressive cross-model transfer의 기회와 과제

**원문**: [arXiv:2611.06976](https://arxiv.org/abs/2611.06976) · **게시일**: 2026-11-04
**저자**: Zhenyi Shen, Junru Lu, Wei Liu, Jiangnan Ye, Jiazheng Li, Di Yin, Xing Sun, Tameem Adel, Yali Du, Lin Gui, Yulan He

## 개요

Prefill-to-Autoregressive Cross-model Transfer는 larger model의 prompt representations을 smaller model의 efficient generation과 결합해 capability와 inference cost를 균형 잡는 latent communication이다. PLatour는 froze model들을 task reward로 직접 trained lightweight zero-initialized linear bridges로 연결하고 hybrid-attention architectures를 support하는 오픈 PACT framework이다.

PLatour는 generation tasks에서 open-source baselines를 outperform하고 substantially smaller sender로도 shared math/coding benchmark에서 reported Mostik results를 surpass한다. 그러나 controlled experiments는 일부 task에서 gain이 uninformative sender signal, self-communication, receiver-only training으로도 reproduce될 수 있음을 보여준다. trainable bridge가 useful sender information을 exploit하지 않고도 receiver adaptation mechanism으로 작동할 수 있기 때문이다.

논문은 communication gain이 실제로 얼마나 기여하는지 quantify하기 위한 PACT-Check를 제안한다. 마지막으로 PACT systems의 opportunities and challenges를 논의한다.

## 핵심 내용

- sender prefill representation을 receiver autoregressive generation과 결합한다.
- zero-initialized linear bridge를 사용하는 오픈 프레임워크를 제공한다.
- 직접 task reward training과 hybrid attention을 support한다.
- generation task에서 open baselines를 outperform한다.
- 일부 gain이 communication이 아니라 receiver adaptation에서 올 수 있음을 보인다.
- PACT-Check로 genuine communication gain을 측정한다.
