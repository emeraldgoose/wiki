# SynthFaces: 균형 잡힌 대규모 인간 데이터셋

**원문**: [arXiv:2610.40119](https://arxiv.org/abs/2610.40119) · **게시일**: 2026-10-29
**저자**: Sergey Karpukhin

## 개요

실제 얼굴 데이터셋은 정체성 분포가 치우쳐 있고 개인정보 위험을 안고 있어 생성 모델을 편향시키기 쉽다. SynthFaces는 유용한 생성 모델 학습과 미세 조정을 위한 고도로 균형 잡힌 정체성 중심 인간 얼굴 데이터셋을 만드는 제어 가능한 생성 파이프라인을 제안한다.

파이프라인은 Arc2Face diffusion 모델을 정체성 임베딩 매니폴드에서 동작하는 flow matching 생성 모델로 확장한다. 이 조합은 실제 인간 중심 데이터셋에서는 동시에 얻기 어려운 생성 충실도와 레이블 다양성을 모두 목표로 한다.

정체성과 이미지가 합성되므로 실제 개인 이미지에 대한 직접 의존도를 낮춘다. 저자들은 nearest-neighbor non-leakage metric으로 정체성 분리를 경험적으로 확인하고, 어댑터 기반 개인화 생성 방법의 미세 조정에 활용 가능성도 보인다.

## 핵심 내용

- 균형 잡힌 대규모 얼굴 데이터셋 생성을 위한 제어 가능한 파이프라인을 제안한다.
- Arc2Face를 정체성 임베딩 공간의 flow matching으로 확장한다.
- 합성 정체성 균형 데이터셋 SynthFaces를 제공한다.
- 실제 개인 이미지 의존도를 줄인다.
- nearest-neighbor non-leakage metric으로 정체성 분리를 확인한다.
- 어댑터 기반 개인화 생성 방법 미세 조정에 활용한다.

## 상세

모티베이션은 인간 중심 작업에서의 공정하고 형평성 있는 인공지능을 지원하는 균형 잡힌 표현 개선이다. 이 작업은 BMVC 2026에 채택되었고 코드가 제공된다.
