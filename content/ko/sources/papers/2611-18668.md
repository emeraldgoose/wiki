# UMM-JEPA: 통합 멀티모달 모델을 위한 마스크드 다음-스케일 표현 예측 기반 생성 사전학습

**Source**: [arXiv:2611.18668](https://arxiv.org/abs/2611.18668) · **게시일**: 2026-10-26

## 개요

통합 멀티모달 대형 언어 모델은 한 시스템 안에서 시각 이해와 생성을 모두 수행할 수 있지만, 생성 학습을 더 한다고 해서 이해 능력이 반드시 좋아지지는 않습니다. 저자들은 이 한계가 생성이 겨냥하는 표현과 이해가 실제로 소비하는 지각적 표현 사이의 불일치에서 비롯될 수 있다고 주장합니다. 기존의 생성 목표는 이산 시각 코드, 생성용 VAE 잠재 표현, 픽셀 수준 목표처럼 합성(synthesis)에 적합한 공간을 최적화하는 반면, 시각 이해는 비전 인코더가 만들어 언어 모델이 읽는 의미 조직화된 지각 상태에 의존합니다. 그 결과 생성 감독이 공유 파라미터를 갱신하더라도 이해가 나중에 읽을 지각 상태를 직접 다듬지는 못합니다.

UMM-JEPA는 이 문제를 생성의 재정의로 풀어냅니다. 즉 픽셀이나 코드 대신, 시각 이해용 연속 표현을 거친 단계에서 정밀한 단계로 점진적으로 예측하는 과제로 바꿉니다. 모델은 다중 스케일 표현 계층을 구성하고, 픽셀 렌더링은 표현 사전학습과 분리하여 나중에만 붙입니다. 설계는 두 가지 분석에 근거합니다. 하나는 다음 스케일을 상위 스케일 조건으로 인수분해하는 분석이고, 다른 하나는 마스킹이 목표 상태를 직접 관측하지 못하게 하여 텍스트·공간·교차 스케일 문맥으로부터 복원하도록 강제한다는 분석입니다.

통제된 비교 실험은 이해 측 개선의 대부분이 표현 예측 목표 자체에서 온다는 것을 보여 주며, 데이터 양을 맞춘 대조군은 그룹 평균을 거의 움직이지 못했습니다. UMM-JEPA는 16개 벤치마크 시각 평균 51.71을 기록해 이해 전용 Qwen-VL 기준선의 46.36을 앞섰고, 텍스트 평균도 함께 올랐습니다. 이산 코드나 잠재 흐름 기반 생성 목표와 비교하면 지각 표현 예측이 이해로의 전이를 더 강하고 일관되게 이끌었습니다. 선형 프로브와 시각 증거 개입 실험에서는 더 풍부한 객체·공간 구조와 더 강한 이미지 특이 정보 활용이 관찰되었습니다.

요지는 이렇습니다. 생성이 이해에 도움이 되려면 이해가 실제로 소비하는 지각 표현을 직접 감독해야 하며, 데이터 양이나 파라미터 공유만으로는 부족하고 목표 함수 자체를 바꿔야 합니다.

## 핵심 내용

- 핵심 아이디어: 합성 지향 목표(이산 코드, VAE 잠재, 픽셀)를 이해용 지각 표현을 직접 예측하는 목표로 교체하여, 생성 감독이 이해가 읽는 상태와 같은 대상을 다듬도록 합니다.
- 다중 스케일 계층: 64/128/256/512 해상도(4/16/64/256 시각 토큰)에서 거친 단계부터 세밀한 단계로 표현을 쌓고, 각 상위 스케일이 다음 스케일의 네이티브 자식을 예측하며 고정 교사(teacher)를 기준으로 감독합니다.
- 마스크드 다음-스케일 예측: 학습 중 시각 상태를 무작위로 가리며(완전히 가린 표본 포함), 모델은 캡션과 교차 스케일 문맥으로부터 목표를 복원해야 합니다. ℓ2-정규화된 목표에 대해 제곱 손실이 실무에서는 코사인 표현 손실로 최적화됩니다.
- 렌더링 분리: 픽셀 렌더링은 표현 사전학습에서 떼어내 이후에만 부착하며, 512 스케일은 시퀀스에 예측 목표로만 들어갑니다.
- 주요 결과: 16개 벤치마크 시각 평균 51.71, 이해 전용 Qwen-VL 기준선 46.36 대비 우위이며 텍스트 평균도 상승.
- 절삭 실험(ablation)은 이득의 대부분을 표현 예측 목표에 귀속시키며, 데이터 양을 맞춘 대조군은 그룹 평균을 거의 바꾸지 못했습니다.
- 지각 표현 예측이 이산 코드·잠재 흐름 계열의 생성 목표보다 이해 전이를 더 일관되게 개선했고, 선형 프로브와 시각 증거 개입에서 더 풍부한 객체·공간 구조와 이미지 특이 증거 활용이 확인되었습니다.
- 논문의 평가 절에 따르면 이해 측 우위는 지시문 튜닝 이후에도 유지되는 것으로 보고됩니다.

## 상세

방법. 표현 목표는 깨끗한 원본 이미지를 고정된 SigLIP2(23층) 교사에 통과시켜 64/128/256/512 해상도에서 얻은 특징이며, 교사는 깨끗한 이미지만 독립적으로 처리합니다. 생성은 p(z64|c), p(z128|c,z64), p(z256|c,z64,z128), p(z512|c,z64,z128,z256) 형태로 점진적으로 인수분해되며, c는 조건 문맥(캡션과 마스킹 하에 보이는 상태)입니다. 각 상위 스케일은 다음 스케일의 네이티브 자식 넷을 코사인 손실로 예측하고, 네 스케일은 동등 가중·정규화됩니다. 학습은 교사 강제(teacher-forced) 방식입니다. 64/128/256 입력 범위는 학생 시각 경로(인코더, 머저, 마스킹 레시피)를 통해 원본 이미지에서 만들어지며, 모델 자신의 이전 예측을 되먹이지 않습니다. 공유 백본은 교차 스케일 인과 어텐션과 각 시각 범위 내부의 양방향 어텐션으로 이를 문맥화하고, 예측 헤드가 각 부모 은닉 상태를 자식 넷의 특징으로 사상합니다. 4→16 토큰 전이는 거친 격자의 보간이 아니라 학습된 조건부 예측입니다. 추론 시에는 캡션에서 시작해 예측 상태를 재귀적으로 재사용합니다(ẑ64 → ẑ128 → ẑ256 → ẑ512).

이론적 틀. 논문은 세밀한 각 스케일이 이전에 주어진 거친 상태로부터 최적으로 예측됨을 보이는 점진적 인수분해 상한을 유도하고, 제곱 예측 손실 하에서 마스킹된 예측의 베이즈 최적해가 보이는 상태와 문맥이 주어졌을 때 마스킹 상태의 조건부 기댓값임을 보입니다. 마스킹은 목표에 대한 직접 접근을 차단하고 사용 가능한 문맥으로부터의 복원을 요구합니다. 목표 표현이 ℓ2-정규화되어 있으므로 제곱 유클리드 거리는 상수 차이를 두고 코사인 거리와 동치이며, 실무에서는 코사인 손실을 최적화합니다.

결과. UMM-JEPA는 16개 벤치마크 시각 평균 51.71을 기록하여 이해 전용 Qwen-VL 기준선의 46.36을 넘었고, 텍스트 평균도 개선되었습니다. 통제 비교에서 이해 개선의 대부분은 표현 예측 목표에서 비롯되었으며, 데이터 양을 맞춘 대조군은 그룹 평균을 거의 움직이지 못했습니다. 지각 표현 예측은 이산 코드·잠재 흐름 계열 생성 목표보다 이해 전이에서 더 나은 성능을 보였습니다. 선형 프로브와 시각 증거 개입은 더 풍부한 객체·공간 구조와 이미지 특이 정보의 더 강한 활용을 드러냈고, 이해 측 우위는 지시문 튜닝 후에도 지속되는 것으로 보고됩니다.
