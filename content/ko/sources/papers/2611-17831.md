# V-JEPA-LM: 정적·텍스트 정렬 표현 너머의 역학을 읽는 비디오-언어 모델

**원문**: [arXiv:2611.17831](https://arxiv.org/abs/2611.17831) · **게시일**: 2026-11-13
**저자**: Keuntae Kim, Dongjun Kim, Yong Suk Choi

## 개요

V-JEPA 같은 월드 모델(world-model) 비디오 인코더는 캡션 없이 비디오만 보고 장면이 어떻게 변하는지, 즉 방향·속도·순서·사물 상태를 배운다. 그러나 이런 인코더 위에 만드는 비디오 언어 모델(VLM)은 여전히 이미지-텍스트 방식의 캡션·질의응답(QA) 학습 레시피를 따른다. 캡션이나 질문 하나하나가 클립의 몇 가지 속성만 지목하기 때문에 언어 모델은 클립을 읽는 대신 그 속성을 찾아 오는 법만 배우고, 인코더가 품고 있는 역학은 쓰이지 않는다. 실제로 같은 속도 비율 문제에서 선형 프로브(linear probe)는 얼려 둔 V-JEPA 특징만으로 87%를 맞히지만, 그 특징 위에 만든 VLM 본인은 찍는 수준의 정답률에 머문다.

한양대학교 팀은 먼저 얼려 둔 인코더 안에서 역학이 어디에 자리 잡는지 확인한다. V-JEPA 같은 예측형 인코더에서는 클립을 거꾸로 재생하거나 좌우 반전·재타이밍하면 특징 토큰이 비디오마다 같은 방향을 가리키는 공유 변화 성분을 따라 움직이며, 이 영상 간 일관성(κ)은 SigLIP보다 20~100배 크다. 프레임별 텍스트 정렬 인코더인 SigLIP에서는 시간 반전이 토큰 순서만 뒤바꿀 뿐이라 어떤 토큰의 내용에도 시간의 화살표가 없어, 이런 공유 성분이 존재하지 않는다.

해결책은 변화를 반드시 읽어야만 정답을 낼 수 있는 반사실 감독(counterfactual supervision)이다. 픽셀 변환으로 공개 비디오에서 정답 균형이 잡힌 변형 문제를 만들고, 정답은 변환 자체가 결정한다. 같은 클립에 같은 질문을 던졌는데 정답이 서로 다르다면 둘을 구별하는 정보는 변화뿐이므로, 공유되는 장면 내용은 정답에 개입할 수 없다. 6개 계열의 14가지 구성을 33개 공개 소스에서 새 수동 주석 없이 렌더링했다.

4.53M 공개 샘플과 프레임당 32개 시각 토큰으로 단일 단계에 학습한 결과(공개 비디오 LLM들은 보통 여러 단계에 9M~172M 샘플, 프레임당 64~256토큰을 쓴다), V-JEPA-LM(1B~8B, Qwen3·Llama 기반)은 11개 비디오 벤치마크 평균에서 모든 크기 등급 1위를 기록한다. 4B 모델은 72.14로 최고 성적 공개 4B(61.08)와 최고 성적 공개 8B(64.79)를 모두 앞선다.

## 핵심 내용

- 격차는 측정 가능하다. 학습에 쓰지 않은 속도 비율 문제 540개(3개 선택지, 찍으면 33.3)에서 얼린 V-JEPA 특징은 선형 프로브에 86.7%, 캡션+QA 모델의 브리지(bridge) 출력은 83.5%를 유지하지만, 정답 위치의 VLM 답은 33.7%로 확률 수준이다. 반사실 행을 더하면 같은 인코더·혼합에서 답이 92.8%로 오른다.
- 역학의 위치: V-JEPA의 반전·좌우 반전·속도 일관성 κ는 SigLIP보다 20~100배 크다. 텍스트 정렬형 ViCLIP에는 공유되는 시간 반전·좌우 반전 방향이 없고(κ 0.002 이하), 픽셀 예측형 VideoMAE는 속도·좌우 반전은 공유하지만 시간 반전은 공유하지 않는다(κ 0.003). SigLIP도 토큰 위치를 보면 시간 방향 65.3%, 속도 73.5%를 읽을 수 있는데, 이는 내용이 아니라 관계 경로다.
- 반사실 생성기는 33개 공개 소스에서 14개 구성(6개 계열)으로 509k 행을 렌더링해 표본 학습 행의 6.1%를 차지한다. 정답은 픽셀 변환에서 기계적으로 따라 나오고 소스별 정답 균형을 맞추며 새 수동 주석이 필요 없고, 행의 29%는 같은 클립에서 나온 반대 정답의 짝을 갖는다.
- 단일 단계 레시피: 얼린 V-JEPA 2.1 인코더(1B·2B는 ViT-L, 3B~8B는 ViT-g)가 32프레임을 읽고, 스펙트럼 브리지(spectral bridge, 고정 PCA 회전·스케일링 후 학습 가능한 MLP)가 9,216개 패치를 1,024토큰으로 압축한다. 언어 모델은 175개 공개 소스에서 뽑은 4.53M 행으로 통째로 학습되며, 이는 공개 비디오 LLM이 보고한 데이터량의 2~38분의 1 수준이다.
- 주요 결과(동일 프로토콜의 12개 점수): 4B 72.14 vs 최고 공개 4B 61.08·최고 공개 8B 64.79, 2B 66.02 vs 최고 공개 2B 52.45이며, Llama 계열도 각 등급에서 1위다(Llama-3.2-3B 68.97, Llama-3.2-1B 62.21). 격차는 역학 벤치마크에 집중된다. 4B 등급에서 TOMATO 53.5 vs 36.5, Vinoground 비디오 66.8 vs 33.8.
- Meta의 미공개 V-JEPA 비디오 LLM과 양쪽 다 보고하는 6개 벤치마크에서 8B 모델은 6.7점(Qwen3-8B)·4.9점(Llama-3.1-8B)을 앞서며, 학습 데이터는 20분의 1에 그친다.
- 통제된 인코더 × 감독 실험은 둘을 분리한다. 같은 예산에서 반사실 행은 2B 평균 +4.5, 속도 문제 +38(8k 스텝 기준 65.3 vs 32.4)을 더하지만, 화살표 시간 문제만 넣은 변형(최종 61.17)이나 혼합의 주석 기반 시간 QA 22개 소스(58.21)는 캡션+QA만 쓸 때(61.53)보다 낫지 않다.
- 일반화도 학습 구성을 넘어 유지된다. 홀드아웃(hold-out) 6세트(3,294개 문항)에서 V-JEPA-LM은 평균 94.5~96.3, 공개 모델은 43.5~55.5다. 학습에 없던 속도 비율 1.6/2.5/4.0, 미사용 코퍼스, 미사용 시뮬레이터를 포함하며, 중간에 재생 속도가 바뀌는 연속 재생 문제에서는 92.5~99.2 vs 19.4~51.9를 기록한다.

## 상세

학습은 일부러 가볍게 설계됐다. 처음 0.6~0.8% 스텝 동안 언어 모델을 얼려 둔 채 브리지만 적응시키는 워밍업을 거친 뒤, 전역 배치 150~300, 최대 시퀀스 2,560토큰으로 모든 것을 한 번의 연속 단계에 학습한다. 연산량은 4B 모델 499 H100-시간, 2B 모델 229 H100-시간(전 모델을 통틀어 최대 650)이다. 추론 시에는 1,024토큰 클립 표현 덕분에 같은 크기 공개 모델 대비 프리필 연산이 2~18배 적고 첫 토큰 지연은 70~182ms다. 여섯 모델이 Llama-V-JEPA-LM-Qwen3-1.7B/4B/8B, -Llama3.2-1B, -Llama3.2-3B, -Llama3.1-8B라는 이름으로 가중치·추론 코드·모델 카드와 함께 공개됐으며, GitHub에는 데이터 생성기와 학습 코드가 뒤따를 예정이다.

분석은 감독이 언제 효과를 내는지 설명한다. 인코더는 무엇을 읽을 수 있는지를, 감독은 무엇을 실제로 읽는지를 결정한다. 반사실 행이 없어도 방향·개수 세기·세밀한 동작은 이미 강하고(SigLIP은 이 항목에서 처음부터 19.7점, 7.7점, 11.5점 뒤처진다), 행을 더하면 속도·카메라·상태 변화가 가장 크게 오른다. 대표적으로 속도 점수는 V-JEPA에서 +32.8, SigLIP에서 +11.4다. 행을 넣은 뒤에는 상대 속도 답의 0.94~0.98이 내용이 아니라 차등 성분에서 나오고, 언어 모델 안에 공유 속도 축이 생긴다(κ 0.035 → 0.648). 추정한 속도 방향 8개를 모든 시각 토큰에서 제거하면 미지 속도 조합이 98.9에서 65.7로, TOMATO는 50.9에서 46.4로 떨어지는 반면 같은 에너지의 무작위 부분공간은 97.2·49.9를 유지한다. 명시적 짝은 주로 일관성을 산다. 미지 속도 비율 짝에서 두 영상 모두 정답인 비율이 96.7% vs 84.4%이고 상태 변화(+4.5)와 반의어 뒤집기(+4.6)는 이득, 개수 세기(−3.1)는 손해다. 다만 짝 없는 팔이 서로 다른 영상을 22% 더 많이 다루고, 속도 소스에는 애초에 명시적 짝이 없으므로 속도 향상은 정답 균형만으로 나온 것이다.

한계도 분명하다. 모든 모델은 클립당 32프레임(수 초~수 분)을 읽으므로 한 시간짜리 비디오는 범위 밖이다. V-JEPA가 텍스트와 정렬된 적이 없으므로 이미지 QA·문서·OCR도 목표가 아니며, 2~38배 더 많은 데이터로 학습된 공개 모델들이 NExT-QA, PerceptionTest 같은 지식 중심 벤치마크에서는 우위를 유지한다.
