# EmbodiedCLBench: 자기 진화 체화 에이전트의 지속 학습 평가

**Source**: Huang et al., arXiv, 2026-10-09

**핵심**: 지속 학습 — 과거 경험을 축적해 새 작업에 전이하는 능력 — 에는 체화 벤치마크가 거의 없다. EmbodiedCLBench는 이를 조합 일반화로 정의해 그 간극을 메운다: 에이전트는 기본 가정 작업을 학습한 뒤 그 기술을 재조합해 미지의 고급 작업을 풀어야 한다. 4개 에이전트 하네스 모두에서 기본 작업 경험이 고급 작업 성공률을 일관되게 3배로 올리지만, 학습 샘플을 늘려도 추가 이득은 없다.

## 배경

자기 진화 에이전트는 인간 감독 없이 개선되길 약속하지만, 지속 학습 벤치마크는 지식·웹·기호 영역에 머물고, 체화 벤치마크는 지각·내비게이션·조작을 테스트하되 시간에 따른 학습 차원이 없다. EmbodiedCLBench는 둘을 결합한다: TongSim 가정 시뮬레이터(풍부한 객체/액션 공간, 데이터 오염 위험 낮음)에, 기본 작업을 고급 작업의 테스트시점 학습 데이터로 쓰는 프로토콜을 얹는다.

## 벤치마크 구성

4단계 — 환경 설정(TongSim), 작업 생성, 그래프 구축, 평가 프로토콜:

- **3단계 조합 수준**: 원자 액션(단일 객체 상호작용, 각 3 스텝) → 기본 작업(원자 액션 2개, 최단 경로 6 스텝, 가정 활동 6 범주, 168 작업) → 고급 작업(2–4개 기본 범주에서 가져온 원자 액션 4개, 최단 경로 12 스텝, 100 작업).
- **오프라인 상태 전이 그래프**: 각 노드는 환경 상태 + 1인칭 이미지 + 액션 후보(최적 / 실행 가능하나 차선 / 무효); 간선은 결정적 전이이며, BFS 최단 경로에서 벗어난 방해 경로를 분기한다. 라이브 시뮬레이터 없이 완전 재현 가능하고 병렬 실행된다.
- **평가 프로토콜**: 학습 단계(기본 작업 수행, +6 추가 스텝 허용) 후 테스트 단계(그 경험으로 미지 고급 작업 시도, +3 추가 스텝). 스텝별 액션 유형 라벨로 세밀한 오류 분석이 가능하다.

## 실험

**설정**: 3개 조건 — 제로샷, 인컨텍스트 학습(기본 작업 전체 궤적 유지), 스킬 학습(궤적 대신 간결한 마크다운 스킬 요약). 4개 하네스(OpenClaw, Claude Code, Codex, Hermes) × 2개 백본(Qwen3.8-Flash, GPT5.6-Terra). 지표: 스텝 예산 내 성공률.

**벤치마크**: 기본 168 + 고급 100 작업, 복잡도 분석용 3–6 원자 액션 확장 고급 작업 포함.

**결과**:

| 하네스 / 모델 | 기본(제로샷) | 고급 제로샷 | + ICL | + 스킬 학습 |
|---|---|---|---|---|
| Hermes / Qwen3.8-Flash | 58.9% | 8.0% | 44.0% | 33.0% |
| Codex / GPT5.6-Terra | 54.8% | 11.0% | 52.0% | 26.0% |
| OpenClaw / Qwen3.8-Flash | 50.6% | 5.0% | 35.0% | 38.0% |
| Claude Code / Qwen3.8-Flash | 42.9% | 3.0% | 27.0% | 31.0% |

핵심 발견: (1) 경험 전이 — 고급 성공률이 모든 조건에서 ~10%에서 30% 이상으로 상승; (2) 복잡도가 원자 액션 3→6개로 늘어도 제로샷 대비 이득 ~30%p 유지; (3) **샘플 확장 불가** — 기본 작업 1개로 거의 모든 이득(8–10% → 28–40%), k=2…6은 평탄하게 변동; (4) 경험은 선택을 무효(−13–20%)에서 최적으로 이동; (5) ICL-vs-스킬 순위는 스텝 예산 전반에 유지.

## 소프트웨어 엔지니어를 위한 시사점

- **메모리 설계 신호**: 좋은 과거 에피소드 1개가 평범한 다수보다 낫다 — 컨텍스트에 궤적을 많이 넣기보다 가장 관련 있는 경험 1개의 검색/선택에 투자하라.
- **compact 스킬 요약이 원시 궤적과 대등**한 성공률에 더 작은 결정 변화 — 전체 트레이스의 행동 교정이 필요 없다면 서빙 비용상 요약 메모리가 유리.
- **오프라인 그래프 평가**: 시뮬레이터 작업을 결정적 상태 그래프로 컴파일하면 불안정한 라이브 환경 없이 병렬·재현 가능한 에이전트 평가 — 상태ful 에이전트 벤치마크에 차용할 패턴.
- **액션 유형 계측**(최적/차선/무효)은 통과/실패 지표를 메모리가 실제로 바꾸는 것의 진단으로 바꾼다 — 추가 비용은 적고 디버깅 가치는 크다.
