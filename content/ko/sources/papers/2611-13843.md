# PolyRoute: 타입 기반 라우팅을 위한 12개 언어·코드 믹스 벤치마크

**원문**: [arXiv:2611.13843](https://arxiv.org/abs/2611.13843) · **게시일**: 2026-11-10

## 개요

타입 기반 결정 인코더(typed-decision encoder)는 텍스트에 대한 질문을 포워드 패스 한 번으로 답한다. 지원 티켓 라우팅 같은 분류 시스템의 기본 패턴이지만, 영어 밖에서의 동작은 고정된 자로 측정되는 경우가 드물다. PolyRoute는 이 공백을 메우기 위해 공개된 벤치마크이자 프로토콜이다. 12개 언어와 9개 문자 체계를 아우르는 322개 원어 지원 메시지, 힌글리시·스팽글리시·아랍지 같은 156개 코드 믹스 및 로마자 메시지, 선택적인 967행 원어 학습 데이터, 그리고 3방향 부서 라우팅 결정 과업 프로토콜로 구성된다. 저자들은 모든 텍스트와 레이블이 LLM 생성물이라는 점을 명시한다.

레이블 품질은 2단계 파이프라인으로 관리한다. 후보 레이블은 Qwen3.8-27B가 만들고 블라인드 2차 검수를 거치며 후보의 91%가 살아남는다. 독립 모델 gemma4-31b는 살아남은 레이블과 테스트 항목의 97.2%에서 일치한다. 암기로 점수가 부풀려지는 일을 막으려는 장치도 있다. 어떤 테스트 텍스트와 어떤 학습 텍스트 사이의 문자 5-그램 유사도 최댓값이 0.33이라, 점수가 거의 같은 문자열 때문에 나올 수 없다.

13개 시스템 리더보드는 다국어 격차를 수치로 보여준다. 영어 루트 체크포인트는 61.2%, 출시된 다국어 체크포인트는 77.3%, 최고 파인튜닝 시스템은 96.6%를 기록한다. 고전적인 TF-IDF에 로지스틱 회귀를 얹은 시스템도 91.9%에 이른다. 이는 출시된 다국어 체크포인트를 크게 앞선다. 일반화는 분할에서 뺀 4개 언어로 확인하는데, 다국어 시스템 세 개가 각각 77%, 90%, 93%를 냈다. 코드 믹스 텍스트에서는 영어 루트가 85%로 출시된 다국어 체크포인트의 79%를 표면상 앞서지만, 논문은 p=0.134라는 점, 즉 유의한 차이가 아니라고 밝힌다.

두 가지 측정 유의점이 이 벤치마크를 특히 정직하게 만든다. 첫째, 이 분할은 대략 4점 이상의 차이만 구분한다. 리더보드 격차가 그보다 작으면 과대 해석해서는 안 된다. 둘째, 텍스트가 LLM 생성물이기 때문에 결과는 자연 발생한 지원 트래픽이 아니라 이 특정 구축 분포에서의 성능을 측정한다.

## 핵심 내용

- 과업: 타입 기반 결정 인코더가 포워드 패스 한 번으로 3방향 부서 라우팅을 결정하며, 원어·코드 믹스·로마자 텍스트 전반에서 평가된다.
- 규모: 12개 언어·9개 문자 체계의 322개 원어 메시지, 156개 코드 믹스 및 로마자 메시지(힌글리시, 스팽글리시, 아랍지), 선택적 967행 원어 학습 데이터.
- 레이블: Qwen3.8-27B가 생성하고 블라인드 2차 검수에서 91%가 채택되며, 독립 모델 gemma4-31b가 테스트 항목의 97.2%에서 일치한다.
- 누출 통제: 임의의 테스트 텍스트와 학습 텍스트 사이 문자 5-그램 유사도 최댓값은 0.33이다.
- 리더보드(13개 시스템): 영어 루트 체크포인트 61.2%, 출시된 다국어 체크포인트 77.3%, 최고 파인튜닝 96.6%.
- 고전 베이스라인: TF-IDF + 로지스틱 회귀가 91.9%로 출시된 다국어 체크포인트를 여유 있게 넘는다. 이 과업 형태에서는 모델 종류보다 원어 데이터 파인튜닝이 중요하다는 뜻이다.
- 미포함 언어 일반화: 분할에서 뺀 4개 언어에서 다국어 시스템 세 개가 77%, 90%, 93%를 기록했다.
- 코드 믹스 텍스트는 영어 루트가 버티는 유일한 구간이다. 85% 대 79%지만 p=0.134로 명목상 우위에 그친다.
- 비교 규칙: 이 분할은 약 4점 이상의 차이만 구분한다. 그보다 작은 격차는 측정 해상도 이내다.
- 투명성: 모든 텍스트와 레이블이 LLM 생성물임을 공개 자료로 명시한다.

## 세부 사항

- 논문(25페이지, 그림 18개, 표 26개, cs.CL·cs.AI, v1은 2026-11-10 제출)은 PolyRoute를 벤치마크이자 프로토콜로 제시하고, 리더보드를 비영어 라우팅 행동의 고정된 자로 쓰도록 한다.
- 최고 파인튜닝 96.6%와 영어 루트 61.2%의 격차가 가장 분명한 결론이다. 다국어 학습 데이터가 없으면 영어 전용 라우터는 비영어 메시지의 약 3분의 1을 잘못 보내고, 파인튜닝하면 과업을 거의 닫는다.
- 출시된 다국어 체크포인트 77.3%와 TF-IDF+로지스틱 회귀 91.9%의 비교는, 이 분포에서 더 큰 다국어 체크포인트가 제대로 피팅된 고전 파이프라인을 이긴다고 단정하지 말라고 가르친다.
- 미포함 언어 결과(77/90/93)는 파인튜닝된 강한 다국어 시스템이 보지 못한 언어에서도 무너지지 않음을 보이지만, 77%라는 하한은 여전히 4건 중 1건 꼴의 오분류이다.
- 5-그램 유사도 상한 0.33과 독립 레이블 일치율 97.2%는 비슷한 LLM 생성 평가 세트를 만들 때 그대로 가져갈 만한 두 가지 품질 통제다.
- 약 4점의 분할 해상도를 고려하면 코드 믹스 텍스트에서의 영어 루트 우위(85 대 79)는 이 벤치마크가 해결하지 못한 차이로 취급해야 하며, 코드 믹스 우월성의 증거로 읽으면 안 된다.
