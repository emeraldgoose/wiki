# 자기 개선 메모리가 지속적 재귀적 자기 개선을 가능하게 한다

**Source**: [arXiv](https://arxiv.org/abs/2611.18856)
**게시일**: 2026-11-13

## Overview

LLM 에이전트의 하네스 최적화 — 고정된 정책 모델을 둘러싼 맥락·도구·실행 스캐폴딩을 개선하는 것 — 는 보통 하나의 고정된 설정에서 연구된다. 이 논문(Xin Yu는 Google 인턴)은 Continual Recursive Self-Improvement(CRSI)를 연구한다. 즉 기존 하네스 최적화 방법을 호환되는 벤치마크나 정책 모델 사이에서 이어가는 설정이다. 핵심 과제는 벤치마크나 모델이 바뀔 때 진화된 하네스의 어느 부분을 재사용할지, 어느 부분을 수정할지 결정하는 것이다. 하네스만으로는 이전 편집이 왜 이루어졌는지, 어떻게 작용했는지 알 수 없기 때문이다.

저자들은 과제 해결 정책이 아닌 하네스 최적화기를 위한 Self-Improvement Memory(SIM)를 제안한다. SIM은 반복되는 하네스 문제별로 편집을 묶고, 그 근거·예측 및 관찰된 결과·평가 맥락을 기록하며, 최적화가 이어지며 새 시도가 이 이력을 확장한다. 네 개 도메인(코딩, 텍스트 분류, 에이전트 워크스페이스 태스크, 엔지니어링 디자인)에서 SIM은 교차 데이터셋과 쌍별 교차 모델 비교 모두에서 하네스 전용·근본원인 전용 이어서 학습보다 높은 최종 점수를 달성했다. 코딩의 10개 독립 소스 실행에서 SIM을 적용한 쌍 이어서 학습은 하네스 전용 이어서 학습보다 평균 2.36점 향상되었다(p = 0.003).

## 핵심 내용

- 교차 데이터셋 CRSI(6개 데이터셋 전환): Full SIM이 6개 모두에서 최고 성적. Harness Transfer를 2.43–4.35점, Problem-Only(근본원인) Memory를 0.20–6.06점 상회. 최강 대안 대비 격차는 NoMemory 0.20점 ~ 엔지니어링 4.35점.
- 소스 개선이 더 나은 타깃 시작을 보장하지 않음: 소스 RSI는 홀드아웃 소스 점수를 2.75–6.41점 올리지만, FewShotAll 하네스는 타깃 RSI를 시드보다 낮게 시작(72.92 대 75.72). Harness Transfer는 74.12(Cold Start 75.92 미만)에 그치지만 Full SIM은 77.92에 도달.
- 교차 모델 CRSI(Opus 5.5 → Gemini 3.8 Flash): Opus 진화 하네스는 Gemini 시드 하네스보다 모든 도메인에서 낮게 시작(적자 0.60 텍스트 분류 ~ 5.48 워크스페이스). Full SIM은 네 도메인 모두에서 최고 성적, 하네스 전용 이어서 학습을 3.60–11.33점 상회(워크스페이스: Full SIM 84.75 vs Harness Transfer 73.42, 시작점 둘 다 68.41).
- 세대 간 지속 개선(TB2.1, Gemini 체인): CRSI는 Gemini 3.5 Flash에서 Fresh RSI를 3.5점, 3.8 Flash에서 1.6점 상회하고, Gemini 4 Argon에서는 0.8점 낮게 마침(seed 89.7 / fresh 95.6 / CRSI 94.8).
- 여러 모델을 위한 하나의 하네스(텍스트 분류, Grok 4.20 Reasoning / Claude Opus 5.5 / Gemini 3.8 Flash): unified synthesis는 홀드아웃 75.24 — 개별 진화 하네스(75.20)와 비슷하고 공유 시드(73.28)보다 높음. sequential CRSI는 74.20.
- 코딩 소스 실행(10개 독립): SIM 이어서 학습은 하네스 전용 이어서 학습보다 평균 2.36점(p = 0.003) 높은 최종 점수를 보임.

## 상세

- 문제 정식화: Harness RSI는 실행 피드백으로 에이전트 하네스를 최적화한다(편집 제안·평가·선택). CRSI는 벤치마크 또는 정책 모델이 바뀐 조건에서 이 최적화를 이어가는 설정으로, 교차 데이터셋·교차 모델 전환 조건을 정의한다.
- SIM 내용: 반복되는 하네스 문제별로 묶인 편집과 각 편집의 근거·예측 및 관찰된 결과·평가 맥락. 최적화 라운드가 이력을 덧붙이므로, 이후 시도는 증거에 기반해 계승된 편집을 재사용·수정한다.
- 비교 조건: Cold Start(시드), Harness Transfer(진화 하네스, 메모리 없음), Problem-Only Memory(결과·맥락 없는 근본원인만), Full SIM(완전한 기록).
- 분석: SIM은 같은 진화 하네스에서의 이어서 학습을 개선하고, 계승 편집의 재사용·수정을 이끌며, 진단을 보존하면서 타깃 증거를 더하고, 코딩에서 더 이른 타깃 진보와 소스 유지에 기여한다.
- 벤치마크: 코딩(Terminal-Bench 2.1/4), 텍스트 분류, 에이전트 워크스페이스 태스크, 엔지니어링 디자인. 벤치마크 동일가중 집계, 진화·타깃 모두 홀드아웃 분할 사용.
- 주의점: CRSI가 항상 더 낫지는 않다(Gemini 4 Argon −0.8 vs Fresh RSI; Harness Transfer는 세 도메인에서 Cold Start 미만). 이점은 연구된 하네스 최적화 프로토콜과 예산 하에서 보고되었으며, SIM은 정책이 아닌 최적화기를 대상으로 한다.
