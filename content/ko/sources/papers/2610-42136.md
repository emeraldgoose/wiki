# ReLift: lifted trajectory repair로서의 dense 3D tracking

**원문**: [arXiv:2610.42136](https://arxiv.org/abs/2610.42136) · **게시일**: 2026-10-27
**저자**: Assaf Singer, Maroun Khriesh, Noam Rotstein, Yoni Kasten, Or Litany

## 개요

monocular video에서 dense 3D tracking은 point correspondences establish, depth estimate, occlusion 중 trajectory inference를 요구한다. 기존 method는 이를 jointly learn하는 경우가 많아 limited 4D supervision 아래 어려운 objective다.

ReLift는 already strong한 pretrained 2D tracker와 geometry model을 leverage한다. 2D correspondence와 depth estimate를 3D trajectory로 lift하고 learned corrector가 그 trajectory를 repair한다. 이는 specific estimator error에 training input을 tie하는 것을 avoid한다.

## 핵심 내용

- tracking과 geometry를 jointly learning하는 대신 lifted trajectory를 repair한다.
- strong 2D correspondence와 pretrained depth/geometry를 사용한다.
- correspondence, geometry, occlusion inference를 separate한다.
- estimator-specific error가 아니라 simulated lift로 corrector를 train한다.
- 다양한 tracker와 geometry model로 provider transfer를 보여준다.
- monocular video의 dense 3D point tracking을 target으로 한다.

## 상세

joint tracker-geometry model은 correspondence, scene geometry, occlusion을 simultaneously solve해야 한다. ReLift는 existing 2D correspondence와 depth/camera estimate를 combine하여 3D path를 만든 뒤 repair한다.

method는 retraining 없이 provider across transfer하도록 design되었다. 논문은 multiple 2D tracker와 geometry estimator로 same corrector를 evaluate하여 underlying component robustness를 보여준다.
