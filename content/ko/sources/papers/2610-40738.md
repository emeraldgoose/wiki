# Apriel Voice 27B Preview: 음성, reasoning, tool use를 위한 open model

**원문**: [arXiv:2610.40738](https://arxiv.org/abs/2610.40738) · **게시일**: 2026-10-27
**저자**: Aman Tiwari et al.

## 개요

유능한 voice assistant는 transcription 이상으로 request를 이해하고, context를 reason하고, conversation을 sustain하며, tool을 invoke해야 한다. Apriel Voice 27B Preview는 shared reasoning backbone으로 이들을 결합하는 open speech-language model이다.

post-trained Gemma checkpoint 기반으로 text, image, audio를 support한다. 핵심 training problem은 이미 유능한 decoder에 speech interface를 추가하면서 useful behavior를 지키는 것이다. 이는 두 단계로 해결된다. frozen backbone으로 multilingual transcription/translation/continuation을 train하여 speech projector를 학습하고, broad supervised fine-tuning을 수행한다.

## 핵심 내용

- speech understanding, conversation, tool use를 위한 open speech-language model이다.
- separate cascaded module대신 shared reasoning backbone을 사용한다.
- speech understanding, response generation, tool decision을 결합한다.
- text, image, audio input을 support한다.
- post-trained Gemma 26B-A4B checkpoint 기반으로 구축된다.
- capability를 보존하기 위해 projector pretraining과 supervised fine-tuning을 사용한다.
- multi-turn evidence integration이 필요한 real workflow를 target으로 한다.

## 상세

논문은 recognition accuracy만으로는 voice-agent success를 충분히 평가할 수 없다고 주장한다. model이 transcription은 정확해도 constraint를 follow하지 못하거나 tool을 invoke 못할 수 있다. speech-conditioned model은 transcript뿐 아니라 acoustic feature를 reasoner에 노출한다.

Apriel Voice는 shared backbone으로 이 capabilities를 연결하고, behavior retention을 위해 broader capability fine-tuning와 별개로 interface learning problem을 분리한다.
