# CausalWAM: World Action Model에서 action의 원인 학습하기

**원문**: [arXiv:2610.42096](https://arxiv.org/abs/2610.42096) · **게시일**: 2026-10-27
**저자**: Juntao Cheng, Jinzhou Tang, Fan Feng, Henrik I. Christensen, Yujia Zheng

## 개요

World Action Model은 observation에서 latent variable을 learning하고 이를 scene evolution prediction과 action generation에 모두 사용한다. prediction은 whole scene을 필요로 할 수 있지만, 특정 action을 directly 유발하는 부분은 scene 일부에 불과하다. demonstration에 fitted된 model이 따라서 action-relevant latent variable을 사용한다는 guarantee가 없다.

CausalWAM은 prediction이 all latent variable을 free하게 사용하도록 두면서 action side에 constraint를 introduce한다. latent variable과 action dimension 사이 dependency를 제한함으로써 action cause를 separate할 수 있다고 주장한다. all latent variable recovery를 target하는 method와 달리, 여기서는 action의 cause만 recover하면 된다.

## 핵심 내용

- World Action Model의 causal ambiguity를 식별한다.
- action을 직접 유발하는 latent와 scene prediction에 필요한 latent를 구분한다.
- all latent representation이 아니라 action에 constraint를 둔다.
- full ICA-style recovery 대신 dependency constraint를 사용한다.
- nonlinear ICA 및 causal discovery research와 related하지만 action cause를 target으로 한다.
- demonstration만으로부터 identifiability problem을 addressed한다.

## 상세

논문은 block stacking 예시를 사용한다. action은 block position과 gripper state에 의존하지만 prediction은 tablecloth나 background clutter와 같은 irrelevant background content도 포함할 수 있다. demonstration에 잘 fit한다 해도 action이 correct latent variable을 use하지 않을 수 있다.

 nonlinear ICA, temporal dependence, sparsity-related function class 등 기존 방법은 all latent variable recovery를 목표로 한다. CausalWAM은 action cause recovery만 요구하여 problem을 단순화하고 prediction을 제약하지 않는다.
