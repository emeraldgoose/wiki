# 함대 경험으로 학습: 96개의 로봇을 위한 집단 경험 학습 패러다임

**Source**: [huggingface](https://arxiv.org/abs/2610.25736) · Yu et al., 2026년 10월 19일 · arXiv:2610.25736
**Date**: 2026-10-19

**Lead**: 본 논문은 로봇이 배포 중 생성한 경험을 공유하여 전문가 시연 없이 정책을 개선하는 집단 경험 학습(CEL) 패러다임을 제안한다. FERT는 실패 맥락을 사용해 성공적인 궤적을 검색하고 우선순위를 부여하며, FATS는 비동기적인 내결함 세로 훈련 시스템을 제공한다. 96개의 로봇으로 전화 포장 작업에서 성공률이 79.2%에서 98.3%로 향상되었으며, 전체 작업은 93.3~99.2%를 달성했다.

## 개요

로봇 기반 모델은 초기 기능을 제공하지만 다단계 작업에서는 신뢰할 수 있는 실행을 보장하지 못한다. 실제 실행은 경험을 생성하며, 기존 개선 방식은 비용이 많이 드는 전문가 시연이나 교정 행동이 필요하다. CEL은 로봇의 자율적인 실행 자체를 감독으로 사용하여 이 문제를 해결한다.

## 방법: CEL, FERT, FATS

FERT는 4단계로 구성된다: 비동기 경험 수집(이진 결과 레이블만), 시각+보행 상태 결합 임베딩을 통한 인코딩, 실패 맥락과 성공 궤적을 매칭하는 S-DTW 기반 검색, 그리고 검색된 구간에 대한 우선순위 미세 조정. FATS는 HotSwarm 기반 지역 복구와 SwarmLink 기반 풀링 추론으로 비동기적 실행과 최적화를 조정한다.

## 주요 결과

- 전화 포장: 79.2% → 98.3% (96개 로봇, 로봇당 고정 수집 시간).
- 전체 평가: 최대 함대 규모에서 93.3~99.2% 성공률.
- 함대 규모가 클수록 성능이 일반적으로 향상됨.
- 22개 로봇에서 30회 장애 발생, 전체 로봇 시간의 1.3%만 손실.
- 초기 정책 초기화 이후 추가 전문가 시연 불필요.
