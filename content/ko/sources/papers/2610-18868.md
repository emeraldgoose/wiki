# Tev: 밀집 진행 보상으로 장기 호라이즌 에이전트 환경 확장하기

**원문**: [arXiv:2610.18868](https://arxiv.org/abs/2610.18868) · **게시일**: 2026-10-13
**저자**: Wenbo Hu, Shraman Pramanick, Krishna Kumar Singh, Nanyun Peng, Kai-Wei Chang, Yong Jae Lee

## 개요

장기 호라이즌 에이전트는 경제적으로 가치 있는 작업을 몇 시간에서 며칠 동안 자율적으로 수행할 수 있다. 이는 자동화된 발견과 재귀적 자기 개선(RSI)에 필요한 핵심 능력이다. 하지만 오픈소스 모델은 아직 이런 작업을 잘 해내지 못한다. 학습 데이터와 학습 레시피가 모두 부족하기 때문이다. 긴 작업은 수집과 검증이 어렵고, 보상은 대부분 희소하다. 에이전트가 여러 단계를 올바르게 수행해도 성공 여부를 판단할 수 있는 시점은 훨씬 뒤에야 온다.

Tev는 이 두 문제를 함께 다룬다. 저자들은 검증 가능한 밀집·점진적 보상을 제공하는 장기 호라이즌 에이전트 학습 데이터셋 **Tev-Gym**을 제안한다. Tev-Gym은 7개 도메인에 걸친 1,170개의 검증된 작업 환경으로 구성된다.

## 잠재 세계 우선 환경 구축

Tev-Gym은 원시 작업 로그에서 출발하지 않고 *잠재 세계(latent world)* 에서 출발한다. 각 도메인에 대해 작업 흐름, 각 단계 이후의 기대 상태, 성공 조건을 담은 숨겨진 명세를 먼저 정의한다. 그다음 이 명세로부터 에이전트가 상호작용할 환경을 단계적으로 렌더링한다. 세계의 구조가 명시적이기 때문에 난이도를 통제 가능한 방식으로 높일 수 있고, 목표까지의 진행도를 추측이 아니라 측정으로 얻을 수 있다.

## PPRS를 이용한 밀집 보상

논문은 이 진행도 신호를 **진행 잠재력 보상 형성(Progress-Potential Reward Shaping, PPRS)** 을 통해 학습 보상으로 바꾼다. 최종 성공이나 실패만 기다리는 대신, 목표에 가까워지는 움직임을 매 단계의 밀집 보상으로 변환한다. 이 방식은 학습 효율을 높이고, 기존에는 신호가 너무 적어 학습이 어려웠던 작업을 학습 가능하게 만든다.

## 결과

이 레시피로 학습한 모델이 **Tev-27B**다. 저자들은 Agents' Last Exam의 컴퓨팅·수리과학 영역(ALE-CM)에서 상당한 성능 향상을 보고하며, Pass@5 기준으로 GPT-6 Astra와 Claude Opus 5 수준에 도달했다고 설명한다. 또한 ALE 관련 데이터로만 학습했음에도 Terminal-Bench 3.0·4.0 하위 집합에서 GLM 5.2와 Gemini 3.7 Flash를 앞서고, TB 2.1 같은 중간 길이 작업에서는 Claude Opus 4.8 수준의 성능을 보인다.

## 의의

핵심 기여는 더 큰 에이전트 벤치마크 하나가 아니라 환경을 만드는 방법론이다. 올바른 숨겨진 세계를 먼저 정의하고, 그로부터 통제된 환경을 렌더링하며, 세계를 통과하는 진행도를 밀집 학습 신호로 사용한다. 이 접근은 장기 호라이즌 에이전트 학습을 더 재현 가능하게 만들고, 희소한 에피소드 종료 보상에 대한 의존을 줄인다.
