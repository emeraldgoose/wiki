# OmniSpectra: 범용 스펙트럼 표현 학습을 위한 통합 파운데이션 모델

**원문**: [arXiv:2601.15351](https://arxiv.org/abs/2601.15351) · **게시일**: 2026-10-23
**저자**: Md Khairul Islam, Zeyu Xia, Adam S. Bolton, Judy Fox

## 개요

표준 시퀀스 모델은 위치를 token rank가 아닌 물리 좌표로 인코딩하지 않아 practice에서 이종 instrument로 관측된 연속 물리 신호(스펙트럼)를 destructively resample해야 한다. OmniSpectra는 이 coordinate mismatch를 cross-instrument representation learning의 구조적 한계로 규정하고 wavelength-native 파운데이션 모델을 제안한다: integer pixel indexing을 버린 continuous-coordinate masked autoencoder. 물리 좌표를 logarithmic basis로 매핑하면 cosmological redshift의 multiplicative scaling이 uniform additive shift가 되며, continuous rotary position embedding에서 이 shared shift는 grid-dependent positional distortion 대신 relative token distance에서 상쇄된다.

## 핵심 내용

- coordinate mismatch를 cross-instrument 표현 학습의 구조적 한계로 둔다.
- token-rank 위치 대신 continuous-coordinate masked autoencoding을 사용한다.
- logarithmic 좌표 basis로 redshift scaling을 uniform shift로 변환한다.
- physics-grounded resolution-gated Fourier decoder로 anti-aliasing을 제공한다.
- 8개 survey로 사전학습하고 7 baseline 대비 12.2M parameters만으로 SOTA를 달성한다.

## 상세

물리 구조를 인코딩하면 매개변수 의존성이 줄어들며, 이를 지닌 표현은 such structure가 없는 더 큰 모델보다 성능이 좋다.
