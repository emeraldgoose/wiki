# Fast-JEPA: 잠재 세계 모델의 성공-지연 전선 발전

**원문**: [arXiv:2611.25927](https://arxiv.org/abs/2611.25927) · **게시일**: 2026-11-19 (v1, v2는 2026-11-22)
**저자**: Yao Zhang, Bin Yu, Shijie Lian, Haishan Liu, Changti Wu, Yu Wu, Kai Chen

## 개요

잠재 세계 모델은 행동 시퀀스의 결과를 예측하지만, 재귀적 롤아웃으로 후보 계획을 비교하는 것은 테스트 시점에 비용이 커서 계획 품질과 지연 시간 사이의 트레이드오프를 강요한다. Fast-JEPA는 예측 계산을 재구성해 낮은 계획 비용으로도 행동 시퀀스 검색이 효과적이도록 한다. 행동을 구성하는 동안에는 관측 앵커에서 선택된 행동 하에 예측된 결과가 다음 행동 선택을 안내하고, 후보 시퀀스가 완성되면 직접 예측된 최종 결과만으로 시각적 목표 목적 아래에서 후보들을 비교하므로, 후보 정제 과정에서 재귀적 상태 롤아웃을 피한다. 계획 목표는 H개 청크 × B개 원시 행동으로 된 계획 A = (a_0,…,a_{H−1}) 중 예측된 최종 잠재 표현이 인코딩된 목표 z_g에 가까운 것을 고르는 것이며, 컨트롤러는 다음 관측 전에 L개의 원시 행동을 실행한다.

PushT, Reacher, Cube, TwoRoom 네 환경에서 Fast-JEPA는 평균 성공률 96.50%(±0.66)를 달성하면서 INTACT보다 계획 속도가 2.41배 빠르고, 검색 예산 스윕에서도 후보 수와 정제 깊이에 걸쳐 성공-지연 우위가 유지된다. 실용성을 검증하기 위해 저자들은 DynaGoal 벤치마크를 제안한다. 같은 네 환경 위에 세 가지 작업군을 둔다. Shift(목표/기하가 변하는 동적 OOD: PushT의 표류하며 반전되는 목표, Reacher/Cube의 목표 전환, TwoRoom의 움직이는 문간), Deadline(실행 시간 제약), Delay(지연된 계획 응답). 원래 환경에서 학습된 모델을 추가 학습 없이 재사용한다. Fast-JEPA는 DynaGoal-Shift 73.83%, DynaGoal-Deadline 87.67%를 기록해, 제어 조건이 변하고 실행 시간 제약이 있는 상황에서도 저지연 예측 계획의 실용적 가치를 보였다.

## 핵심 내용

- Fast-JEPA는 행동 구성에서는 순차적 의존성을 유지하되, 후보 평가에서는 재귀적 상태 롤아웃을 각 완성 후보의 최종 결과 직접 예측으로 대체한다(관측과 목표가 공유하는 잠재 공간에서 비교).
- PushT/Reacher/Cube/TwoRoom에서 평균 성공률 96.50%(±0.66), 환경별 90.00/96.33/100.00/99.67, INTACT 대비 2.41배 빠른계획; 후보 수와 정제 깊이를 바꾸는 예산 스윕에서도 파레토 이점이 유지된다.
- DynaGoal 벤치마크: PushT/Reacher/Cube/TwoRoom에서 Shift/Deadline/Delay 작업군, 기본 학습 모델을 미세조정 없이 재사용하며, 측정된 계획 지연이 계획 비용과 제어 성능을 직접 연결한다.
- DynaGoal 결과: DynaGoal-Shift(동적 OOD) 73.83%, DynaGoal-Deadline(실행 마감) 87.67%.
- JEPA 스타일 잠재 세계 모델 위의 계획 프런트엔드로, 모든 후보를 단계별로 롤아웃하지 않고 예측된 최종 잠재 상태를 목표 잠재 상태와 비교한다.

## 상세

문제 설정: 시점 t에서 이미지 인코더가 관측 o_t와 목표 이미지 o_g를 공통 잠재 공간에 매핑한다(z_t = E_θ(o_t), z_g = E_θ(o_g)). 계획은 각각 B개 원시 행동을 갖는 H개 청크로 이루어지고, 컨트롤러는 다음 관측 전에 L개 행동의 피드백 간격을 실행한다. 관련 예측 검색 방법들은 후보 유도와 평가 방식이 다르다(미분 가능 롤아웃, IMWM의 검색 초기화+하이브리드 점수, NGC의 이웃 그래프 목표 거리). Fast-JEPA는 대신 검색 각 단계에서 실제로 필요한 정보에 세계 모델 질의를 맞춘다. 실험은 환경별 성공률과 계획 지연(ms)을 측정하고, DynaGoal 변형은 표류 목표, 목표 전환, 움직이는 문간, 마감, 제어된 응답 지연을 재학습 없이 주입한다.
