# 물리 기반 관절 3D 에셋을 향하여: 다중 에이전트 파이프라인과 벤치마크

**Source**: Cai 외, arXiv, 2026-10-09

**핵심**: 3D 에셋 생성은 외형 재현을 최적화하지 물체의 움직임·기능은 다루지 않는다. 저자들은 단일 에이전트 Articraft를 확장한 Artisan을 제시한다—설계(청사진+디자인 보드), 코딩(확장 SDK의 Python 프로그램), 리뷰(점수+이슈 목록)의 세 독립 에이전트에 MuJoCo 충돌·중력 안정성 피드백을 닫는다. 공간 충실도·물리 타당성·하류 로봇 과제 효용·인간 판단의 통합 벤치마크도 함께 내놓으며, 10개 이상 모델 중 Artisan이 충돌·안정성에서 선두다.

## 배경

외형·관절·질량·재질·안정성·무충돌 운동은 상호 의존적이지만 기존 방법은 단편 대응이다: 전방향 관절 모델, 재질/질량 예측기, 안정성/충돌 다듬기가 따로 논다. 절차적 생성기는 제약은 강제하나 적용 범위가 좁고, 에이전트형 Articraft는 단일 에이전트가 프로그램을 짜고 스스로 검증해(자기 평가 편향) 실제 시뮬레이터에서 테스트하지 않는다. Artisan은 에이전트 독립성과 직접 물리 검증으로 두 간극을 메운다.

## 방법: 물리 검증 다중 에이전트 파이프라인

$(\mathbf{p}, \mathcal{I}) \mapsto \mathcal{O} = \{\{\mathcal{G}_i, \rho_i, \mathcal{M}_i\}, (\mathcal{K}, \mathcal{J})\}$—부품 형상·질량·PBR 재질·키네마틱 트리·제한/결합 포함 관절을 출력한다. **설계 에이전트**는 텍스트 청사진(부품·재질·키네마틱스에 결합 운동·"믹싱 헤드를 들어 올리기" 같은 기능 과제 서술 추가)과 직교/분해 뷰 디자인 보드를 낸다. **코딩 에이전트**는 관절을 처음부터 모델링 대신 재사용 파라미터 커넥터(힌지·슬라이드 레일·회전 커넥터)로 프로그램 반복 수정·실행하고, 파지 영역·구동 관절·성공 임계값을 하류 과제용으로 주석한다. **리뷰 에이전트**는 코드를 고치지 않고 점수와 구조화 이슈(부품·근거·심각도)를 반환하며, 충돌 검사를 피려 도어 가동 범위를 줄이는 식의 편법을 청사진 대비로 차단한다. 후보마다 볼록 분해 후 MuJoCo 충돌 스윕(단일/이중/다중 관절 표집)과 중력 기울기 테스트를 돌려 침투 깊이·기울기를 물리 리포트로 되먹인다.

## 실험

**설정**: 공간 충실도는 100개 참조 에셋(ArtVIP·LightWheel), 물성은 재질/충돌 ArtVIP·질량 ABO 50개·안정성 고무게중심 선별 50개, 하류는 RoboTwin 2.0(3과제)·RoboCasa365(8과제)의 $\pi_{0.5}$ 정책과 6개 방법 블라인드 MuJoCo 대화형 인간 평가.

**결과(Artisan GPT-6 Astra vs 10개 이상 기준선)**:

| 측면 | Artisan | 최고 기준선 |
|--------|---------|---------------|
| 공간 충실도(ArtVIP) | 11개 중 8개 1위(IoU 0.7675, PSNR 18.65, pIoU 0.3587) | Articraft GPT-6 Astra 근소 2위 |
| 충돌 단일/이중/다중 | 1.7% / 3.7% / 13.0% | 31–46% / 39–66% / 33–82% |
| 안정성 정지/관절 | 98% / 96% | 82–86% / 78–86% |
| RoboTwin / RoboCasa 성공(Native+Artisan 학습) | 84% / 43% | native 단독 80% / 39%, Articraft 단독 60% / 5% |
| 에셋 자격 R1/R2 | RoboTwin 100%/100%, RoboCasa 95%/44% | Articraft 62%/62%, 39%/8% |

어블레이션에서 물리 루프 제거 시 충돌이 ~38–78%로 회귀한다. 전방향 특화 모델(Instruct-Particulate 등)도 대부분 지표에서 에이전트형 방법에 밀린다.

## 소프트웨어 엔지니어를 위한 시사점

코드 생성 에이전트 파이프라인 일반에 통하는 패턴이다:

- **빌더와 리뷰어 분리**: 산출물(청사진·프로그램·이슈 목록)만 교환하는 독립 에이전트가 자기 승인 편향을 줄인다—IaC·설정·코드 생성 에이전트에 적용 가능.
- **눈검사가 아닌 실제 런타임 검증**: LLM 시각/기하 검사가 놓친 것을 MuJoCo 스윕이 잡았다—생성 산출물을 목표 환경(시뮬레이터·스테이징·정책 엔진)에서 실행하고 기계 측정 리포트를 되먹여라.
- **파라미터 표준 부품 제공**: 자유 형상 관절 모델링보다 표준 커넥터가 낫다—코딩 에이전트에 날 API 대신 검증 라이브러리를 줘라.
- **충실도가 아닌 기능 평가**: 렌더 지표가 놓친 실패를 하류 과제 성공과 대화형 인간 조작이 잡았다—생성 에셋은 쓰임으로 벤치하라.
