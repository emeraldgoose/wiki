# TCP4D: 로봇 조작을 위한 도구 중심점(TCP) 추적·생성 통합 모델

**Source**: [arXiv](https://arxiv.org/abs/2611.23143)
**게시일**: 2026-11-17

## Overview

로봇 조작 비디오는 풍부한 시각적 경험을 제공하지만, RGB 관측만으로 로봇 행동과 그리퍼 상태 주석을 복원하기는 여전히 어렵다. 구현체에 무관한 도구 중심점(TCP) 포즈를 행동 공간으로 삼아, TCP4D는 하나의 4D 장면 표현이 관측된 TCP 동작을 추적하고 미래 TCP 궤적을 생성하는 통합 모델이다. 단안 비디오와 초기 2D TCP 질의가 주어지면, 트래커는 장면 기하와 카메라 파라미터와 함께 SE(3)의 TCP 포즈와 그리퍼 상태를 메트릭 스케일로 직접 복원한다. 제너레이터는 복원된 TCP 트랙을 따라 같은 4D 표현에서 국소 특징을 샘플링하고, 로봇 관측과 언어 지시를 결합해 미래 TCP 상태를 예측한다.

교차 구현체(cross-embodiment) 증강 파이프라인은 복원된 동작을 리타게팅하고 대응하는 관측을 합성해 기존 RGB 비디오를 다른 구현체용 시연으로 변환하며, 원본 로봇의 상태 기록이 필요 없다. 실험에서 트래커는 DROID와 RoboLab에서 절대 궤적 오차 7.60/16.07 mm를 달성하고 새 구현체에 열 개의 시연만으로 적응했다. 제너레이터는 RoboTwin에서 평균 69.19% 성공률을 기록하고 두 실제 과제에서 확립된 정책 모델을 능가하며, 원본+증강 시연 공동 학습은 증강만 학습보다 타깃 로봇 성공률을 41.5% 높였다. 라이선스: CC BY 4.0.

## Key points

- 추적(DROID / RoboLab): APD 74.78% / 43.71% — 최강 베이스라인의 네 배 이상; ATE 7.60 / 16.07 mm로 감소; 두 데이터셋 모두 SR 100%(최상 베이스라인 89.64% / 96.33%). VGGT-Omega, DA3, MapAnything, 4RC, VDPM, Any4D, Track4World, CoTracker3, MoSE3를 능가.
- 실제 환경(CoBoT Magic, 양팔, 과제당 60개 시연, 30회 시행): TCP4D는 펜 놓기 83.33%, 그릇 쌓기 73.33% 성공, 평균 78.33% vs DP3 63.33%, ACT 31.67%(+15.0 / +46.7%p); 평균 진행 점수 3.50/4; RGB에서 기하와 TCP 동작을 직접 추론해 추론 시 깊이 센서 없이 DP3를 능가.
- 교차 구현체: 증강 파이프라인은 복원된 동작을 다른 구현체로 리타게팅하고 관측을 합성; 원본+증강 공동 학습이 증강만 학습 대비 타깃 로봇 성공률을 41.5% 개선.
- RoboTwin 제너레이터: 평균 성공률 69.19%; 열 개의 시연으로 새 구현체에 few-shot 적응.
- 방법: 공유 4D 장면 표현; 트래커는 하나의 단안 비디오에서 메트릭 SE(3) TCP 포즈·그리퍼 상태·기하·카메라 파라미터를 출력; 제너레이터는 복원된 TCP 트랙을 따라 샘플링한 특징과 언어 지시를 conditional flow matching으로 결합.

## Details

- 아키텍처: TCP4D Tracker(RGB로부터 메트릭 TCP 복원 + 기하/카메라)와 TCP4D Generator(conditional flow matching으로 미래 TCP 상태 예측); 교차 구현체 증강 파이프라인(RGB만으로 리타게팅 + 관측 합성, 원본 로봇 상태 기록 불요).
- 평가: RoboTwin 시뮬레이션; DROID·RoboLab 추적 벤치마크; 실제 CoBoT Magic(펜 놓기, 그릇 쌓기); 베이스라인 DP3, ACT 및 아홉 가지 4D/포인트 추적 방법; 지표 ATE/RRE/RTE, APD/MPE, AbsRel/MAE/δ₁, 그리퍼 정확도, SR.
- 소속: 프로젝트 페이지는 논문에 링크. 라이선스: CC BY 4.0.
