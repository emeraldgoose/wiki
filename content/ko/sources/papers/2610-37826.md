# DeFT-RAG: 다중 홉 질문을 재사용 가능한 답변이 있는 자기 완결적 하위 질문으로 분해

**원문**: [arXiv:2610.37826](https://arxiv.org/abs/2610.37826) · **게시일**: 2026-10-30
**저자**: Dingyi Kang, Bingzhe Li

## 개요

검색 증강 생성은 대규모 언어 모델이 관련 구절을 검색해 질문에 답하도록 돕지만, 다중 홉 질문은 질문에서 언급되지 않은 중간 엔터티를 통해 여러 문서에 걸친 사실을 연결해야 한다. 그래프 기반 검색 증강 생성은 질문이 이름을 지은 엔터티에서 한 번 검색해 전체 증거 사슬을 거의 복구하지 못한다. 반복적 방법은 단계적으로 복구할 수 있지만 하위 질문 계획, 의존성 결정, 답변 도착 시 재작성, 알려진 사실 추적 등 모델에 부과하는 많은 작업 때문에 정확도가 제한된다.

DeFT-RAG는 세 구성 요소로 이루어진 검색 증강 생성 프레임워크다. 원래 질문과 지금까지 답한 하위 질문 및 답변으로부터 한 번에 하나의 자기 완결적 하위 질문을 생성하며, 묻는 모든 엔터티를 이름으로 명시한다. 이렇게 하면 계획, 의존성 추적, 재작성의 필요가 사라지고 모델은 한 번에 하나의 세밀한 작업에 집중할 수 있다. 또한 알려진 내용을 추적하는 질문 답변 테이블을 규칙 기반으로 갱신하고, 예와 아니오 결정은 가벼운 결정 모델이 맡겨 나머지 언어 모델 작업을 모델 밖으로 이동한다. 마지막으로 답변을 캐시해 이후 질문이 의미적으로 같은 하위 질문을 묻면 그 답변을 재사용한다. MuSiQue, 2WikiMultiHopQA, HotpotQA에서 DeFT-RAG는 13개 기준선 가운데 최고 정확도를 달성하면서 다른 반복 방법보다 모델에 더 적은 입력 토큰을 제공했다. 1000개 MuSiQue 질문에 캐시를 공유하면 하위 질문의 23.1%를 캐시에서 답해 정확도 저하 없이 모델 호출을 12.9% 줄였다.

## 핵심 내용

- 다중 홉 질문은 질문에 언급되지 않은 중간 엔터티 때문에 실패한다.
- 그래프 기반 방법은 증거 사슬을 충분히 복구하지 못한다.
- 반복적 방법은 계획과 추적 부담이 크다.
- 자기 완결적 하위 질문은 계획, 의존성, 재작성 부담을 제거한다.
- 규칙 기반 테이블과 가벼운 결정 모델이 모델 작업을 줄인다.
- 답변 캐싱과 재사용은 정확도를 낮추지 않고 호출을 크게 줄인다.

## 상세

이 논문의 핵심 통찰은 각 하위 질문을 독립적으로 의미 있게 만들어, 하위 질문이 숨겨진 상태나 미래의 재작성에 의존하지 않도록 하는 것이다. 이렇게 하면 생성과 평가가 모두 단순해진다. 지식 관리와 이진 결정을 주 모델 밖으로 옮기면 언어 모델이 처리해야 할 작업 수도 줄어들고, 캐싱은 데이터셋 내 반복되는 하위 질문을 활용한다. 결과는 강한 정확도를 유지하면서 더 토큰 효율적인 반복형 검색 증강 생성 방법이다.
