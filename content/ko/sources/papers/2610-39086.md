# HALO: 주도적 에이전트의 인간 기반 세밀 평가

**원문**: [arXiv:2610.39086](https://arxiv.org/abs/2610.39086) · **게시일**: 2026-10-27
**저자**: HALO Authors

## 개요

주도적 에이전트(proactive agent)는 사용자의 명시적 요청 없이 관찰된 활동으로부터 필요를 추단하고 도움을 시작한다. 기존 평가는 자동 점수나 binary verdict에 의존하는 경우가 많아, evidence 사용과 intervention 품질에 대한 인간 진단이 부족하다. HALO는 실행 가능한 task 환경과 세밀한 인간 annotation을 결합하여 주도적 에이전트를 평가한다.

HALO-Arena는 10개 everyday domain과 50개 personal environment에 걸쳐 4가지 주도적 필요 유형(Dependency, Blockage, Risk, Opportunity)을 다룬다. 에이전트는 structured database query와 unstructured file retrieval을 통해 evidence를 찾아낸 뒤 어떤 행동을 취할지 결정한다. 여기에서 만든 HALO-8K는 400개 scenario에 걸친 10개 모델의 8,000개 response를 포함하며, 20명 expert가 action level, acceptability verdict, rejection diagnosis를 annotation했다.

## 핵심 내용

- 주도적 에이전트가 도와야 하는지, 언제, 얼마나 도와야 하는지를 평가한다.
- evidence retrieval과 인간 기반 세밀 annotation을 결합한다.
- HALO-Arena는 4개 필요 유형, 10개 domain, 50개 personal environment를 다룬다.
- HALO-8K는 400개 scenario, 10개 model, 8,000개 response를 expert 20명이 annotation했다.
- 거부된 response의 61.20%는 premature timing 또는 excessive intensity로 인한 over-proactivity failure mode다.
- 최고 proprietary/open-source model은 각각 72.88%와 56.63% acceptability에 도달한다.
- acceptability에는 intervention success만이 아니라 restraint와 retrieval effort도 중요하다.

## 상세

benchmark는 관찰된 evidence가 reminder를 정당화할 수 있어도 financial action은 정당화하지 못하는 경우를 모델링하며, observation, evidence, permission을 분리해야 함을 보여준다. human diagnosis는 timing, intensity, unsupported evidence, irrelevance, factual contradiction 등을 포함한다. no-action response도 accepted reserve와 unacceptable missed opportunity로 구분된다.

reported analysis는 intervention, restraint, timing, intensity, retrieval effort 사이의 tradeoff를 강조한다. HALO는 단일 binary score 대신 주도적 에이전트가 어디에서 성공하고 어디에서 과도하게 개입하는지 세밀한 그림을 제공한다.
