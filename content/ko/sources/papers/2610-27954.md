# 회복에서 길을 잃다: 목표 지향 행동 재생을 통한 컴퓨터 사용 에이전트의 회복 행동 분석

**원문**: [arXiv:2610.27954](https://arxiv.org/abs/2610.27954) · **게시일**: 2026-10-20
**저자**: Byeonghun Bang, Sangwoo Park, Jinheon Baek, Kangsan Kim, Youngwan Lee, Sung Ju Hwang

## 개요

대규모 시각 언어 모델의 발전으로 컴퓨터 사용 에이전트는 키보드와 마우스의 세밀한 조작으로 디지털 워크플로를 자동화할 수 있게 되었다. 이런 에이전트는 오류가 누적되고 이전 행동이 의도하지 않은 부작용을 남기는 장기 과정에서 여전히 취약하다. 회복 능력이 중요하지만 기존 대책은 제한적이다. 환경 재설정은 독점 환경에서 비실용적이며, 행동 재생은 장기 과정에서 비용이 크고, API 기반 롤백은 웹 환경으로 제한된다.

이 논문은 컴퓨터 사용 에이전트의 회복 행동을 체계적으로 연구하는 확장 가능한 프레임워크 ReTrace를 제시한다. 회복 상태와 목표 상태에서 동일한 하위 행동이 동일한 결과를 낳아야 한다는 전이 일관적 회복을 공식화한다. 이 기준은 제어된 오류 주입 이후 목표 지향 행동 재생을 통해 실행된다. ReTrace는 이상적 회복이 잠재적인 작업 완료 능력을 해제할 수 있고, 현재 에이전트는 그 잠재적 회복 능력을 활용하지 못하며, 정확한 모델 기반 회복이 종단 간 성능 향상을 가져온다는 사실을 밝힌다.

## 핵심 내용

- 장기 컴퓨터 사용 에이전트는 누적된 오류 아래에서 여전히 취약하다.
- 회복은 중요하지만 기존 대책은 좁거나 비용이 크다.
- ReTrace는 모델 기반 회복을 체계적으로 평가한다.
- 전이 일관적 회복은 공식적인 기준을 제공한다.
- 제어된 오류 주입과 재생은 회복 행동을 관찰 가능하게 만든다.
- 더 나은 회복은 잠재된 작업 완료 능력을 해제할 수 있다.

## 상세

이 연구는 회복을 에이전트 설계의 부수적인 효과가 아니라 측정 가능한 능력으로 재구성한다. 회복 상태와 목표 상태에서 동일한 하위 행동에 대한 결과를 비교함으로써 우연한 지속과 진정한 회복을 구분한다. 결과는 컴퓨터 사용 에이전트가 종종 잠재적인 회복 능력을 이미 가지고 있지만 자율적으로 활용하지 못함을 시사한다. 따라서 모델 기반 회복 개선은 더 신뢰할 수 있는 장기 자동화로 가는 직접적인 경로다.
