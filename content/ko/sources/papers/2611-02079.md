# ParetoSaddler: Quality와 Cost를 위한 Pareto-Guided Agent Harness Optimization

**원문**: [arXiv:2611.02079](https://arxiv.org/abs/2611.02079) · **게시일**: 2026-11-01
**저자**: Xingzhi Qian, Sungho Park, Rongyuan Tan, Jianbo Yu, Jue Zhang, Lorenzo Cavallaro, Menglin Xia, Yanzhi Chen, Xinnuo Xu, Yu Kang, Xinran Zheng, Gagan Somashekar, Xuchao Zhang, Chetan Bansal, Qingwei Lin, Victor Rühle

## 개요

Harness optimization은 model weights 변화 없이 LLM agents를 substantial improve할 수 있지만 existing methods는 주로 response quality를 optimize한다. ParetoSaddler는 released systems가 parallel drafting과 richer harness choices가 permit하는 full speedup/quality를 실제로 attain하는지 묻는다. single requests accept few tokens but read every target weight; batching roughly halves speedup over autoregressive decoding; speculative decoding is deployment-specific. ParetoSaddler는 deployment별 algorithm과 system optimization을 discover하는 autonomous agentic loop를 제공한다. gaps를 identify하고 directions explore/integrate, output reward hacking check, validated mechanisms carry forward.

## 핵심 내용

- model weights 변경 없이 harness improvement 가능하다.
- parallel drafters는 blocks를 one pass로 drafting하여 speedup extend한다.
- single requests는 적은 tokens accept하지만 every target weight read한다.
- batching은 per-request speedup을 substantial reduce한다.
- optimization은 deployment, draft, target, GPU specific해야 한다.
- output-token checking이 reward hacking detect한다.

## 상세

reported experimental claims는 speculative decoding speedup에 초점. one request에서 autoregressive decoding 대비 speedup 4.46배에서 10.87배로, batching에서 1.94배에서 3.93배로 training/quality loss 없이 increases. discovered optimizations include lossless 12-bit weight format, tree verification, two-level verification, batching mechanisms. 설정-specific results이므로 exact target/draft/hardware stack에서 reproduce해야 한다.
