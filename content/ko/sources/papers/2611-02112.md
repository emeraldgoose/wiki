# 순서만 고려하는 온폴리시 증류

**원문**: [arXiv:2611.02112](https://arxiv.org/abs/2611.02112) · **게시일**: 2026-11-01
**저자**: Guangzeng Han, Yu Wu, Xiaolei Huang

## 개요

온폴리시 증류는 학생의 자체 생성 결과에 대해 교사의 토큰 확률을 맞추는 방식으로 학생을 학습시킨다. 이 확률은 교사가 선호하는 토큰과 교사의 확신도라는 두 정보를 얽어 둔다. 확신도는 더 작은 학생이 재현하기 어려울 수 있는 교사의 용량과 교정 상태를 반영한다. 교사 온도는 순서를 바꾸지 않고 크기만 바꾸기 때문에 온폴리시 증류는 온도 선택에도 민감하다. 논문은 후보 토큰의 순위만으로 충분한지를 묻고, 상대 순서 정보만 사용하는 Order-Only On-Policy Distillation (O3PD)를 제안한다.

## 핵심 내용

- 온폴리시 증류는 교사 토큰 확률을 맞춘다.
- 확률은 선호와 확신도를 함께 담는다.
- 더 작은 학생은 교사 확신도를 재현하기 어려울 수 있다.
- 교사 온도는 확률 크기를 바꾼다.
- 순위는 크기보다 덜 민감하다.
- 순서만 고려하는 증류는 확신도 의존을 피한다.

## 상세

핵심 질문은 증류에 확신도 크기가 필요한가이다. 논문은 확률을 선호와 확신도로 분해한 뒤, 상대 순위에 집중하면 교사의 교정 상태에 대한 의존성이 줄어든다고 주장한다. 전체 확률 대신 상대 순서를 학습함으로써 O3PD는 온도 선택에 더 견고하고 용량이 다른 학생에게 더 적합하려 한다. 방법은 불가능한 교정 일치를 강요하지 않고 지식을 전달하는 데 초점을 둔다.
