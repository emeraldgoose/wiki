# PanDWM: 파노라마 4D 자율주행 월드 모델

**Source**: [arXiv](https://arxiv.org/abs/2611.19857)
**게시일**: 2026-11-15

## Overview

자율주행 월드 모델은 보통 광학 중심이 서로 다르고 겹침이 작은 6개의 핀홀 카메라로 영상을 생성하므로, 뷰 간 일관성을 별도로 학습해야 한다. PanDWM은 대신 6개 뷰를 하나의 360° 파노라마 밴드로 이어 붙인다. 카메라 경계가 하나의 이미지 안에 들어오므로 뷰 간 일관성은 이미지 연속성 유지 문제로 귀결되고, 각 픽셀은 여전히 자신의 카메라 레이를 기록한다.

레이아웃에 조건화된 인과적 학생 모델이 밴드를 윈도우 단위로 4스텝에 생성하며, 인과적 교사로부터 증류되고 자기 롤아웃으로 학습된다. 피드포워드 디코더가 각 프레임을 레이를 따라 3D 가우시안으로 들어 올리고, 이웃 프레임의 정적 가우시안이 이를 4D 장면으로 완성한다. nuScenes를 하나의 이어 붙인 360° 뷰로 평가하면, PanDWM은 다중 카메라 베이스라인보다 FID와 FVD가 낮고 8–46배 빠르며, 50스텝 교사의 FID를 유지하면서 FVD를 22–25% 낮춘다. 코드: https://github.com/AIGeeksGroup/PanDWM.

## Key points

- 6개의 분리된 핀홀 뷰 대신 단일 360° 파노라마 밴드: 일관성 = 이미지 연속성; 픽셀별 카메라 레이 보존.
- 인과적 학생이 밴드를 윈도우 단위로 4스텝 생성; 50스텝 인과적 교사에서 증류되고 자기 롤아웃으로 학습; 교사의 FID를 유지하면서 FVD를 22–25% 개선.
- 피드포워드 디코더가 프레임을 3D 가우시안으로 부상(lift)시키고, 이웃 프레임의 정적 가우시안이 이를 4D 장면으로 완성.
- nuScenes(360° 이어 붙임 채점): 다중 카메라 베이스라인보다 FID/FVD가 낮고 8–46배 빠름.
- 장기 자기 생성 롤아웃과 멀티뷰 일관성을 Val-150/Test-S/Test-L에서 평가; 카메라 경계의 이음새(seam)를 명시적으로 분석(부록).

## Details

- 입력: 서라운드뷰 레이아웃과 과거 프레임; 밴드 윈도우에 대한 인과적 분해; 50스텝 교사 → 4스텝 학생 증류 + 자기 롤아웃 학습.
- 3D/4D 부상: 픽셀별 레이로 밴드를 3D 가우시안으로 역투영; 이웃 프레임의 정적 가우시안이 동적 내용을 4D 장면으로 완성.
- 평가: nuScenes Val-150/Test-S/Test-L; 360° 이어 붙임 뷰에서 FID/FVD; 동일 각해상도에서의 추론 비용; 베이스라인 재현(UniMLVG, OpenDWM (SD3.5), MagicDrive-V2, DiST-4D, OmniNWM, DreamForge, RAYNOVA).
- 유의점: CC BY-NC-SA 4.0 라이선스; 파노라마 이어 붙이기는 보정된 리그를 가정; 품질은 증류와 레이 정확 역투영에 의존.
