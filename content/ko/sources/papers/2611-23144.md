# π^4: 4D 장면 기하와 동작을 위한 파운데이션 모델

**Source**: [arXiv](https://arxiv.org/abs/2611.23144)
**게시일**: 2026-11-17

## Overview

π^4는 4D 장면 지각을 위한 통합 파운데이션 모델이다. 야생의 다양한 비정형 RGB 관측 — 단일 이미지, 무순 컬렉션, 비디오 시퀀스 — 으로부터 밀집 기하, 카메라 포즈, 미터법 스케일을 복원하고, 다중 이미지 입력에 대해 2D/3D 포인트 트랙과 이동 객체 마스크까지 복원한다. 기하 브랜치와 기하 조건부 동작 브랜치를 결합하며, 후자는 이미지 상의 대응점을 예측하고 재구성된 타깃 뷰 기하를 이용해 3D로 끌어올린다.

다양한 벤치마크에서 π^4는 기하 평가에서 최고의 종합 평균 순위를 달성하고, 단일·멀티뷰 2D/3D 포인트 추적과 이동 객체 분할에서 경쟁력 있는 성능을 보인다. 공유 백본을 쓰는 전체 기하-동작 시스템은 약 0.5B 파라미터 — 대부분의 베이스라인 절반 미만 크기 — 로, 학습 컨텍스트가 최대 64뷰임에도 천 장 이상의 입력 이미지를 갖는 대규모 장면도 단일 순전파로 공동 재구성·추적한다.

## Key points

- Table 2의 기하 벤치마크 전반에서 최고 종합 평균 순위; 단일/멀티뷰 2D/3D 추적과 이동 객체 분할에서 경쟁력 있는 성능(Figure 2); 학습 컨텍스트 ≤ 64뷰임에도 1,000장 이상의 입력을 가진 장면을 단일 순전파로 기하와 동작을 함께 복원.
- 총 ~0.5B 파라미터로 대부분의 베이스라인 절반 미만; π³ 스타일의 순열 동변(permutation-equivariant) 기하(기준 뷰 없음); 두 브랜치 모두 looped Transformer 디코딩(교차 벤치마크 성능, 파라미터 효율, 긴 컨텍스트용 메모리 절약).
- 기하 조건부 동작: 기하 네트워크는 동결하고 별도의 동작 디코더가 이미지 상 대응점을 예측하며, 재구성된 타깃 뷰 표면을 이용해 해석적으로 3D로 끌어올린다 — 씬 스케일에 무관한 목적함수이며 보이는 모든 3D 트랙 포인트는 재구성 표면 위에 놓인다.
- 데이터 엔지니어링: Funes/Sketchfab의 장면 레벨 렌더에 coverage-aware 뷰 선택과 connected chain; 보완적 자연/counterbias 카메라(롤·초점거리); FOV/렌즈 증강; 전경 억제 의사 레이블링(Internet 비디오); 동적 장면을 위한 GameRealm 엔진 네이티브 감독.
- 학습: 단일 이미지, 2–24뷰 세트, 32/48/64뷰 세트에서 확률적 뷰 수 샘플링(짧은 컨텍스트가 대부분); 희소 3D refiner가 국소 표면 디테일 개선.

## Details

- 아키텍처: 공유 이미지 인코더; looped Transformer 기하 브랜치(순열 동변, 기준 뷰 없음); 동결된 기하 특징에 학습하는 별도의 동작 디코더; 희소 3D convolution refiner; 기하 조건부 동작 디코딩(이미지 상 대응점을 재구성 기하와 조합).
- 학습 프로토콜: 뷰 수 커리큘럼, relative-point 감독의 손실 가중, 카메라 읽기 gradient 라우팅(Sec. 6); 학습 데이터 혼합에는 GameRealm 감독 포함; 전체 데이터 큐레이션 파이프라인은 Sec. 4에 문서화.
- 소속: Shanghai Artificial Intelligence Laboratory; GameRealm을 파트너와 공동 개발. 코드와 모델은 Pi4에서 공개. 라이선스: CC BY 4.0.
