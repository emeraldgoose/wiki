# S1CogBench: 인지 실험에서 System One 의사결정 모델이 할 수 있는 것과 할 수 없는 것

**Source**: [arXiv:2611.00911](https://arxiv.org/abs/2611.00911) · **게시일**: 2026-11-14

## 개요

인간과 AI의 의사결정은 다중 인지 능력을 포함한다. System One 의사결정 모델인 Jev, Laya, Intern-Decision 등은 한 번 호출로 허용 옵션 중 하나의 유형화 결정만을 반환해 라우팅, 가드레일, 자동 게이트에 직접 실행될 수 있다. 그러나 그들의 인지적 강점과 한계는 잘 이해되지 않았다.

저자들은 S1CogBench를 제안한다. 24개의 정립된 인지 과제와 27개 평가 모드로 구성된 벤치마크이며, 인간 반응 예측, 자율 실행, 통제된 과제 조작을 결합한다. 오픈 모델 7개와 API 모델 Jev가 평가된다. 어댑터가 가시 상태, 이력, 허용 응답을 공급하고 모델별 커버리지는 부록 A에 기록된다.

결과는 모델 간 뚜렷한 행동 프로필을 보여준다. 일부 학습 과제에서의 강한 성능은 정보 수집 실패나 피드백 적응 실패와 공존하며, 높은 정확도가 변화하는 과제 요구에 대한 인간 유사 반응을 보장하지 않는다. 공유 리드아웃 제어도 모델 순위가 선택 추출 방식에 부분적으로 의존함을 보인다. 생성 언어 모델과의 지연 비교는 장문 응답이 직접 결정보다 훨씬 느리고, 매칭된 1토큰 생성은 오버헤드가 거의 없음을 보여준다.

S1CogBench는 정립된 인지 실험에서의 System One 의사결정 모델 첫 벤치마크로, 자동 의사결정 시스템에 통합되기 전 능력과 한계를 식별하는 공통 경험적 기반을 제공한다.

## 핵심 내용

- System One 의사결정 모델은 검사 가능한 생성 텍스트 없이 유형화된 결정을 출력한다.
- S1CogBench는 예측, 자율 실행, 조작을 아우르는 24개 과제와 27개 모드를 포함한다.
- 7개 오픈 모델과 Jev가 상태·이력·허용 옵션을 공급하는 어댑터를 통해 평가된다.
- 모델은 과제별 강점과 실패를 보이고, 높은 총합 정확도는 적응 부족이나 정보 수집 부족을 가릴 수 있다.
- 선택 추출 방법이 순위에 영향을 미친다. 리드아웃 제어는 모델 간 공유된다.
- 직접 결정은 장문 자유 텍스트 응답보다 훨씬 빠르다. 1토큰 생성 오버헤드는 작다.
- 벤치마크는 정확도, 보상, 의사회귀, MAE, 인간 NLL, Brier, 지연 P50/P95, 무효 응답률 등을 보고한다.

## 상세

- 과제에는 Wisconsin Card Sorting Test, Mouselab, 고정 밴딧 등이 포함되며, 유형화된 출력용으로 어댑팅되고 사후 요약에는 하이브리드 샘플링이 사용된다.
- 평가 지표는 허용 응답에 대한 인간 반응 NLL과 전체 어휘 NLL, 자율 실행 총 보상 G = 합(r_t - c_t) 등을 포함한다.
- 공통 9개 지표가 보고된다. 정확도, 보상, 의사회귀, MAE, 인간 NLL, Brier, 지연 P50/P95, 무효 응답률.
- 원본 인지 효과는 모델 점수와 함께 보고되며, 불확실성은 참가자나 독립 환경에 대해 추정된다.
- 모델은 잘 형성된 분포를 반환하면서도 피드백을 무시하거나 탐색을 너무 일찍 중단할 수 있으며, 폐쇄 루프 환경은 실패 원인을 분리하지 않으면 거의 성공하지 못한다.
