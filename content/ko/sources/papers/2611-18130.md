# JFinBench: 최신 자격시험에서 만든 지속적으로 갱신 가능한 일본 금융 벤치마크

**원문**: [arXiv:2611.18130](https://arxiv.org/abs/2611.18130) · **게시일**: 2026-11-13
**저자**: Issa Sugiura, Taro Makino, Takashi Ishida

## 개요

거대 언어 모델이 금융 분야로 빠르게 확장되면서 금융 역량을 평가할 벤치마크에 대한 수요가 커지고 있지만, 금융 전문성은 나라마다 다른 세법과 회계 기준, 규제에 묶여 있어 기존 벤치마크는 영어와 미국 중심에 머물러 왔다. 일본 금융을 다룬 기존의 자격시험 기반 벤치마크도 4개 시험의 선택형 문제에 그쳐 세금 계산이나 논술 같은 서술형 문제, 그림에 의존하는 문제는 평가하지 못했다. 여기에 한 번 공개된 문제가 학습 데이터로 유출되면 점수가 일반화 능력이 아니라 암기를 재는 쪽으로 기우는 데이터 오염(data contamination) 문제까지 겹친다.

사카나 AI가 공개한 JFinBench는 2026년에 치러진 6개 자격시험에서 321개 예제를 뽑아 만든 일본 금융 벤치마크다. 공인회계사(CPA) 단답형 시험, 공인세무사 시험, FP 기능검정 1급 필기, 금융 창구 서비스 기능검정 1급, 닛쇼 부기 1급, 젠쇼 부기 1급이 회계와 감사, 세법, 재무 설계, 은행 실무를 함께 아우른다. 이 시험들은 정기적으로 치러지고 공식 PDF로 문제가 공표되기 때문에, 새 회차가 나올 때마다 전문가가 만든 새 문제를 벤치마크에 보충해 데이터 오염을 완화하는 라이브 벤치마크(live benchmark) 전략을 일본 금융에 적용한 것이 핵심이다.

구축은 휴먼인더루프(human-in-the-loop) 에이전트 파이프라인으로 이뤄진다. 공용 스크립트가 시험 PDF 페이지를 300dpi 이미지로 만들어 비전 언어 모델(VLM)인 Gemini 3.8 Flash로 표와 그림 위치가 살아 있는 마크다운을 뽑아 내고, 코딩 에이전트인 Claude Code가 시험별 변환 코드를 작성해 구조화된 예제와 원본과 나란히 비교하는 리뷰 페이지를 만든다. 마지막으로 일본어 원어민 저자가 모든 예제를 원본 페이지와 대조해 검증하고 문제점을 자연어로 에이전트에게 되돌려주면, 에이전트가 코드나 레코드를 고쳐 해당 예제를 다시 만든다. 321개 예제 전수 검증에 시험당 2시간 남짓, 총 12시간이 들었다.

최근 LLM 12개를 평가한 결과, 도구 없이는 Claude Fable 5가 95.8점, GPT-6 Astra가 93.6점으로 나란히 90%를 넘겼고 최고 오픈웨이트 모델인 Kimi K3.1 Pro는 83.4점으로 12포인트 뒤졌다. 터미널과 웹 접근을 허용하면 모든 모델의 점수가 오르고 격차도 약 4포인트로 줄지만 모델 순위는 거의 그대로였다. 저자들은 이를 통해 도구를 쓰더라도 모델 자신이 파라미터에 담고 있는 지식이 여전히 중요하다고 해석한다.

## 핵심 내용

- 규모와 형식: 6개 2026년 시험의 267개 원본 문제에서 뽑은 321개의 별도 채점 단위 — 선택형(MCQ) 193, 단답형 87, 최대 40개 안팎의 빈칸을 빈칸별로 채점하는 답안 양식(Form)형 18, 루브릭으로 채점하는 논술형 23이며, 12개 예제에는 토지 구획도 같은 이미지가 시각 입력으로 붙는다.
- 오염 통제: 모든 시험이 보고된 모델 지식 컷오프 이후에 치러졌고, 새 시험이나 새 회차 추가에 에이전트가 작성한 변환 코드와 사람 검증만 필요하도록 설계되어 주기적 갱신으로 유출 문제를 완화한다.
- 도구 없이 최대 추론 노력(reasoning effort) 기준: Claude Fable 5가 95.8점, GPT-6 Astra가 93.6점, Gemini 3.8 Flash는 88.8점으로 독점 모델 셋이 상위 3위를 차지하고, 최고 오픈웨이트 모델인 Kimi K3.1 Pro는 83.4점으로 12포인트 차이이며 모든 오픈웨이트 모델이 모든 독점 모델보다 낮다. 가장 어려운 시험은 공인세무사로 최고 점수가 79.4에 그친다.
- 에이전트 코딩에서는 계급이 뒤집힌다: Kimi K3.1 Pro는 Terminal-Bench 4.0에서 65.7%로 GPT-6 Astra(58.2%)보다 높게 보고됐지만, JFinBench에서는 GPT-6 Astra가 오히려 10.2포인트 앞선다. 일반 역량이 아니라 일본 금융 전문 지식의 결손이 격차의 원인이라는 뜻이다.
- 비용과 규모: 추론 노력을 올리면 모든 모델에서 점수와 비용이 함께 오른다. Gemini 3.8 Flash는 문제당 0.025달러로 가장 저렴하면서도 낮은 노력 설정에서조차 모든 오픈웨이트 모델을 앞선다. 파라미터 수가 공개된 오픈웨이트 9개 모델에서 점수는 총 파라미터 수와 양의 상관(피어슨 r = 0.82)을 보이지만, Kimi K3.1 Pro는 같은 2.8T 파라미터에서 Kimi K3보다 3.5포인트 높아 사후 학습(post-training)의 효과를 보여준다.
- 오류 분석: 실패 예제(점수 0.5 미만)를 여섯 원인으로 분류한 LLM 분류기(사람이 표본 30개를 직접 달았을 때 코헨 κ = 0.84로 일치)에 따르면 지식 오류가 가장 흔하고 계산 실수는 드물며, 토큰 한도 절단은 MiMo-V2.6 두 모델, Mistral Large 4, Qwen3.8 Flash, GLM 5.3 Flash 등 오픈웨이트 5개 모델에 집중된다.
- 도구 사용 평가(Harbor 프레임워크에서 Terminus-2, mini-SWE-agent, 개발사 공식 하네스(harness)로 터미널과 웹 사용): 모든 모델이 향상되고 GLM 5.3 Flash가 +29.9포인트(87.6점)로 가장 크게 올랐다. 최고 오픈웨이트와 독점 모델의 격차는 12.4포인트에서 4.4포인트로 줄었지만(Kimi Code를 쓴 Kimi K3.1 Pro는 92.9점 vs Terminus-2를 쓴 GPT-6 Astra는 97.3점), 순위는 거의 그대로였다(스피어맨 ρ = 0.87).
- 에이전트의 도구 사용: 321개 과제에서 웹 검색은 56~66%, 파이썬이나 bc를 이용한 계산은 9~28%의 과제에서 쓰였고, 네 모델 모두 정부 법령 데이터베이스인 e-Gov를 가장 많이 찾았으며 오픈웨이트 모델은 검색 엔진을 훨씬 많이 썼다(GLM 5.3 Flash의 DuckDuckGo 사용 47% vs 독점 모델 최대 11%). 답안지 노출은 Terminus-2 시도 11,556건 가운데 8건(0.07%)뿐이었고 해당 시도는 0점 처리됐다.

## 상세

채점은 문제 유형별로 다르다. 선택형은 정규식 기반 추출에 출력이 말썽이면 LLM 심사가 보조하고, 단답형은 수학적·법적으로 동치인 표현을 받아 주는 동치 심사, 답안 양식형은 빈칸 단위 부분 점수, 논술형은 모범답안의 핵심 포인트를 루브릭 삼아 커버 비율로 점수를 매긴다. 심사 모델은 GPT-5.1로 통일했고 Claude Opus 5.5로 다시 채점해 점수가 거의 일치하는지 확인했다. 모델과 노력 설정의 조합마다 3회씩 돌려 평균을 보고하며, 프롬프트는 시험일과 법령 기준일(예: "2026년 4월 1일 현재 시행 중인 법령을 적용")을 명시해 시험 시점의 법을 기준으로 채점한다.

파이프라인은 금융에 국한되지 않는다. 받아 적은 전사본은 PyMuPDF로 뽑은 텍스트와 문자 다중집합으로 비교해 누락과 환각을 표시하고, 코딩 에이전트는 출처 URL과 법령 기준일이 담긴 자연어 지시만으로 시험별 코드를 작성하므로 시험 추가에 수작업 프로그래밍이 필요 없다. 저자들은 같은 워크플로가 의사 국가시험이나 변호사 시험 같은 다른 자격시험에도 쓸 수 있다고 본다. 데이터셋과 평가 코드, 구축 파이프라인이 공개됐다(github.com/SakanaAI/JFinBench, huggingface.co/datasets/SakanaAI/JFinBench, 코드는 Apache License 2.0).

한계도 분명하다. 과거 문제를 공식 PDF로 공표하는 시험만 포함되므로 증권 애널리스트(CMA) 시험은 범위 밖이다. 지식 컷오프는 개발사가 스스로 선언한 값이라 정의도 제각각이고 실제 학습 데이터의 유효 컷오프와 다를 수 있어 오염 여부를 완전히 배제할 수 없으며, 주기적 갱신이 기본 완화책으로 남는다. 또 최상위 독점 모델 둘은 공인세무사 시험을 제외한 모든 시험에서 이미 96~100점이라 포화 상태라, 이 벤치마크의 진짜 쓸모는 아직 12포인트 뒤처진 오픈웨이트 모델의 발전을 추적하는 데 있다.
