# Ego Guidance: 행동 라벨이 없는 인간 자기중심 비디오로 로봇 정책 학습 강화하기

**출처**: [huggingface](https://arxiv.org/abs/2611.13685)
**게시일**: 2026-11-10

## Overview

이 논문은 대규모로 수집할 수 있지만 행동 주석이 거의 없는 인간 자기중심(egocentric) 비디오를 행동 감독 없이 로봇 정책 학습에 활용할 수 있는지 탐구한다. 저자들은 생성적 잠재 공간에서 확산을 수행하는 World Action Model 대신, 이미 잘 최적화된 사전학습 Vision-Language Model(VLM)에서 출발해 이를 Mixture-of-Transformers(MoT)로 확장한다. 이렇게 만들어진 SPAR(Shared Prediction on Action and Representation)는 액션 예측 전문가와 미래 시각 상태의 표현을 예측하는 생성 전문가를 결합하여, 시각 상태 예측이 액션 예측과 함께 독립적이고 상호 보완적인 학습 신호를 제공하도록 한다.

핵심 발견은 행동 라벨이 없는 자기중심 비디오로 학습한 표현이 분포 외(out-of-distribution) 로봇 과제의 성능을 향상시키며, 비디오 데이터 규모가 커질수록 이득이 커진다는 점이다. 저자들은 또한 어떤 예측 목적함수와 시각적 타깃이 효과적인지, 데이터 큐레이션이 어떤 영향을 미치는지도 함께 연구하여, 행동 라벨 없는 비디오를 확장 가능한 로봇 학습 감독 신호로 활용하는 실질적 지침을 제시한다.

이 연구는 정밀한 행동 주석 비용이 크기 때문에 대부분의 자기중심 자원이 순수 비디오 형태로만 존재한다는 관찰에서 출발한다. SPAR는 이기종 데이터로 공유 백본을 학습할 수 있도록 설계되었다. 로봇 데이터는 두 전문가 모두를 감독하고, 자기중심 비디오는 생성 전문가만 감독한다. 생성 전문가는 추론 시 제거된다.

## Key points

- SPAR는 사전학습 VLM 위에 MoT 구조로 두 개의 독립 파라미터 트랜스포머 스택(액션 전문가와 생성 전문가)을 공유 백본에 확장한다.
- 액션 전문가는 VLM의 계층별 은닉 상태에 크로스 어텐션하여 flow matching으로 액션 청크를 예측한다.
- 생성 전문가는 액션 전문가와 대칭 구조로 미래 시각 상태의 표현을 예측하며, 로봇 데이터는 두 전문가를, 자기중심 비디오는 생성 전문가만 감독한다.
- 시각 타깃 선택이 중요하다. 학습된 시각 특징 공간에서의 감독이 재구성 잠재보다 정책 학습에 유용하지만, 모든 섭동에 대해 최고인 타깃은 없다.
- SigLIP2 표현 공간에서 미래 단일 프레임만 예측해도 네 프레임 예측과 거의 동일(평균 성공률 74.32% vs 74.62%)하므로 기본 설계는 단일 프레임 예측이다.
- 데이터 큐레이션이 결정적이다. 가공하지 않은 Ego4D 클립은 로봇 전용 베이스라인보다 못하지만, 두 품질 게이트(안정적 움직임 + 보이는 손)를 모두 통과한 클립은 베이스라인을 넘어선다.
- 행동 라벨 없는 자기중심 비디오를 0에서 1,500시간까지 확장하면 LIBERO-Plus 성공률이 꾸준히 오르고 인도메인 LIBERO는 대체로 유지된다. 생성 전문가는 추론 시 제거된다.

## Details

방법. 시점 t에서 현재 관측과 과제 지시, 예측 구간 H가 주어지면 VLM의 언어 모델이 계층별 은닉 상태를 생성하고, 액션 전문가는 여기에 크로스 어텐션하여 flow matching으로 액션 청크를 출력한다. 생성 전문가는 미래 시각 상태의 표현을 예측하도록 함께 학습되며, 로봇 궤적만으로는 충분히 얻기 어렵고 행동 라벨 없는 인간 비디오로는 풍부하게 얻을 수 있는 보조 신호를 제공한다. 두 전문가가 독립적으로 파라미터화되어 있어 백본은 로봇 데이터와 자기중심 데이터의 이기종 혼합으로 최적화할 수 있고, 자기중심 비디오는 생성 경로를 통해서만 기울기를 기여한다.

결과 및 분석. 저자들은 미래 상태 타깃에 대한 다양한 인코더와 예측 목적함수를 비교했다. 표현 공간 감독은 재구성 잠재보다 전반적으로 우수했으나, 모든 상황에서 최고인 타깃은 없었다. DINOv2는 센서 노이즈와 객체 배치 변화에서 가장 높은 확산 기반 점수를 기록했고, Qwen-ViT는 조명과 배경 질감 변화에서 앞섰다. 미래 시각 특징의 직접 회귀 또한 유용한 감독을 제공하여 여러 타깃(특히 SigLIP2와 DINOv2)에서 확산과 비견할 만한 결과를 보였다. 즉 시각 예측의 이득은 확산 목적함수에 의존하지 않는다. 같은 확산 목적함수 하에서 단일 프레임 예측 대 네 프레임 예측의 차이는 평균 성공률 0.30%포인트에 불과하여, 단일 프레임 SigLIP2 예측이 기본 설계로 채택되었다.

데이터 측면에서 Ego4D 비디오는 5초 단위 클립으로 나눈 뒤 EgoSmith 기반의 두 누적 품질 게이트로 필터링한다. Gate 1은 카메라 움직임이 적고 광학 흐름이 안정적인 클립(약 1,893시간, 원본의 48%)을 남기고, 두 게이트를 모두 적용하면 충분히 보이는 손이 포함된 클립(975시간, 약 25%)만 남는다. 로컬에 배포한 Qwen3.6-35B-A3B가 클립당 15프레임에서 짧은 영어 단계 설명을 생성하고, 이를 미래 상태 예측의 언어 지시로 사용한다. 가공하지 않은 Ego4D로 학습하면 로봇 전용 베이스라인보다 낮고, Gate 1만으로는 소폭 개선에 그치며, 두 게이트를 모두 거친 데이터가 가장 좋은 결과를 낸다. 마지막으로 자기중심 비디오 사전학습을 0에서 1,500시간으로 확대하면 인도메인 LIBERO 성공률은 거의 변하지 않지만 LIBERO-Plus 성공률은 꾸준히 상승하여, 행동 라벨 없는 자기중심 비디오가 주로 분포 외 강건성을 개선함을 보여준다.
