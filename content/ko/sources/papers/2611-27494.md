# Typhoon OCR 2: 태국 문서 전사에서 다국어 다중 작업 OCR로

**원문**: [arXiv:2611.27494](https://arxiv.org/abs/2611.27494) · **게시일**: 2026-11-20 (v1, v2는 2026-11-23개정)
**저자**: Surapon Nonesung, Natapong Nitarach, Sittipong Sripaisarnmongkol, Kunat Pipatanakul, Warit Sirichotedumrong

## 개요

Typhoon OCR 1.5는 태국어 문서를 일반 텍스트로 전사할 수 있었지만, 실제 업무 흐름에서는 페이지에서 특정 값 하나만 뽑거나 페이지 전체를 구조화해 저장해야 하는 경우가 많습니다. 특히 값을 추출하려면 먼저 OCR을 돌린 뒤 텍스트를 다른 모델에 넘기는 두 단계가 필요했습니다. Typhoon OCR 2는 이 과정을 하나로 합쳐, 단일 경량 모델이 프롬프트에 따라 특정 정보 추출(차트 데이터, 양식 필드, 문서 라벨, 문서에 대한질문응답 등)과 구조화된 전체 페이지 파싱을 모두 처리합니다. 전체 페이지 파싱은 태국어, 영어, 중국어를 지원합니다.

저자들은 2B와 0.8B 두 크기의 오픈 가중치 모델을 공개합니다. 2B 모델은 Infinity-Parser2-Flash에서, 0.8B 모델은 OvisOCR2에서 시작해 특수 오픈 문서 파서를 개조했습니다. 학습은 먼저 선별된 420,327개 예시(규칙 필터링된 레거시 태국어 데이터, 새로 라벨링한 사내 태국어 페이지, 주로 영어·중국어인공개 다중 작업·VQA·지시 데이터)로 지도 미세조정(SFT)하고, 이어서 작업별 시퀀스 수준 보상을 주는 GRPO(Group Relative Policy Optimization)를 적용합니다. 토큰 상한에 도달하고도 종료 토큰(EOS) 없이 끝난 응답은 보상을 0으로 처리해, 반복 루프나 조기 종료 같은 실패 모드를 직접 겨냥합니다.

## 핵심 내용

- 하나의 모델, 두 가지 작업: 프롬프트 기반 특정 추출과 전체 페이지 레이아웃 파싱(reading order 순의 JSON 요소에 bounding box와 의미 카테고리, 표는 HTML, 수식은 LaTeX, 본문은 Markdown).
- 경량 오픈 모델 2B(Infinity-Parser2-Flash 기반)와 0.8B(OvisOCR2 기반)를 공개하고 가중치, GGUF/MLX/Ollama 양자화, Python 패키지(`pip install typhoon-ocr2`), 평가 스위트를 함께 배포.
- Thai 벤치마크에서 평가된 오픈 모델 중 최고: Thai MDPBench 80.7(Typhoon OCR 1.5는 68.9), ThaiOCRBench 59.91(40.45). 경량 0.8B 모델은 ThaiOCRBench 36.43.
- 영어·중국어 파싱 성능 저하 없음: olmOCR-bench 84.7(기본 모델 84.4), OmniDocBench v1.6 90.97(91.03).
- GRPO가 MDPBench에서 반복 루프가 있는 페이지 비율을 2B 모델 기준 평균 3.2%에서 0.7%로 줄임. 0.8B 모델의 점수 향상은 더 작고 통계적으로 불확실.
- 데이터 정제: 레거시 Typhoon OCR 1.5 데이터의 결정적 규칙 필터링(99,616개 유지), 새 태국어 47,031개 예시의 다단계 라벨링(대형 모델 초기 주석, 규칙+LLM 심사로 품질 점수 90 이상, bounding box 수동 검토 4,562페이지 중 1,961개 수정), PII 필터, MDPBench·SEA-DocBench·ThaiOCRBench와의 이미지 해시 중복 검사.
- GRPO 보상: 작업별 지표(레이아웃은 카테고리별 박스 겹침+reading order 텍스트 유사도, 표는 TEDS, 수식·Markdown은 편집 유사도, 차트는 값 일치 F1, QA는 ANLS)를 구조 패널티 max(0.6, 1-0.1k)(k는 위반된 규칙 패밀리 수)와 곱하고, 토큰 상한-EOS 미도달 시 0점. LoRA 어댑터를 SFT 정책에 대한 KL 패널티와 함께 갱신하며, GRPO 프롬프트 12,993개는 SFT에서 제외.

## 상세

평가에는 5개 공개 벤치마크를 사용합니다. MDPBench(영어·태국어 사진 촬영 페이지 320장, 파싱 점수), olmOCR-bench(영어 PDF 1,403페이지, 테스트 통과율), ThaiOCRBench(태국어 질의 2,808개, 13개 작업), SEA-DocBench(영어·태국어 3,091페이지, 편집 거리), OmniDocBench v1.6(영어·중국어 복합 레이아웃 1,651페이지). 최대 16,384개 새 토큰까지 그리디 디코딩하고, 레이아웃 JSON 프롬프트에는 최대 16.7MP 이미지를 투입하며 vLLM 0.33.0으로 서빙합니다(0.27.0에서는 비교 모델의 출력이 잘못 나왔음). 평가 시 반복 여부는 출력 텍스트 자체로 판정합니다(30줄 이상 비어있지 않은 줄 중 한 줄이 절반 이상을 차지, 6~80자 구문이 15회 이상 연속 반복, 3,000바이트 초과 출력이 zlib 압축 시 8% 미만). SFT는 긴 컨텍스트 윈도와 동적 이미지 해상도를 써 전체 파라미터를 다음 토큰 예측으로 학습하며, 회전·다운스케일링·포토메트릭 증강을 이미지와 bounding box에 동일하게 적용합니다. 본문 HTML은 v1 원고 기준이며, v2(2026-11-23) 초록에서도 동일한 핵심 수치가 보고됩니다.
