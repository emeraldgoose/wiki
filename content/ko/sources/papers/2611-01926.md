# TAC-CoT: 명시적 토큰 인터리빙을 통한 도구 강화 암묵적 사고 연쇄

**원문**: [arXiv:2611.01926](https://arxiv.org/abs/2611.01926) · **게시일**: 2026-11-01
**저자**: Juseon Do, Sangmin Bae, Jeesu Jung, Hwanjun Song

## 개요

LLM 기반 에이전트 시스템은 정확한 추론, 외부 지식, 다단계 deliberation을 요구하는 과업에 사고 연쇄 추론과 결합되는 경우가 늘고 있다. 명시적 사고 연쇄는 큰 생성 비용을 수반하고, 텍스트 근거를 압축 연속 토큰으로 대체하는 암묵적 사고 연쇄는 도구 사용에 필요한 명시적 통신 인터페이스를 자연스럽게 지원하지 못한다. 논문은 TAC-CoT를 제안하며, 명시적 추론 trace를 압축 잠재 추론 세그먼트로 대체하면서 도구 호출, 관측, 최종 응답에만 텍스트 토큰을 유지한다. 이 인터리빙 설계는 모든 중간 추론 과정을 말하지 않고도 에이전트 도구 사용을 가능하게 한다. 에이전트 수학 및 질의응답 벤치마크에서 TAC-CoT는 정확도를 최대 8.8포인트 높이고 모델 forward pass를 최대 6.8배 줄인다. 분석은 단일/다중 도구 환경 모두에서 도구 사용 품질이 개선됨을 보여준다.

## 핵심 내용

- 명시적 CoT는 정확하지만 비용이 크고, 암묵적 CoT는 효율적이지만 도구 통신 인터페이스가 부족하다.
- TAC-CoT는 압축 잠재 추론 세그먼트와 도구 호출/관측/응답용 명시 텍스트 토큰을 결합한다.
- 인터리빙 설계로 상세 중간 추론을 말하지 않아도 도구 사용이 가능하다.
- 벤치마크에서 정확도 최대 +8.8포인트, forward pass 최대 6.8배 감소.
- 단일 및 다중 도구 설정 모두에서 도구 사용 품질이 개선된다.

## 상세

도구와 다단계 추론이 필요한 에이전트 수학/질의응답 벤치마크에서 평가한다. 효율성은 forward pass로 측정한다. 잠재/명시 분할과 도구 사용 패턴 ablation은 연결된 원문을 참고한다.
