# ABF-Bench: 에이전틱 블록체인 포렌식을 위한 검증 가능한 벤치마크

출처: Xiaohang Yu, Hejia Geng, William Knottenbelt, arXiv:2610.23656, 2026-10-16.

**핵심 요약**: 블록체인 포렌식은 적대적이고 열린 문제입니다. 자금세탁범은 자금을 나누고 교환하며 브릿지하고, 믹서나 수탁 서비스에서 흔적을 끊고, 사건마다 전술을 바꿉니다. 조사관도 계속 추적 방식을 바꿔야 합니다. 하지만 공개 원장은 불변이므로 기록된 모든 이동이 공개되어 독립적으로 검증 가능합니다. **ABF-Bench**는 모든 주장한 이동이 에이전트가 인출한 원장 기록을 인용해야 하는 **검증 가능한 자금 추적 과제**로 만들었습니다. 케이스-과제 파이프라인은 원장에 걸쳐 잘 정의된 과제를 만듭니다. 보수적 규칙은 기록이 연속성을 결정하지 못한 곳에서 추적을 중단하고, 각 과제의 참조 그래프는 그 규칙이 결정한 답입니다. 실제 세탁 활동으로 만든 과제는 다중 홉 전송, DeFi 교환, 크로스체인 왕복, 수탁·믹서 입금, 주소 포이즈닝을 결합합니다. 저자는 작업 기억 기반 **ABF 에이전트 하네스**를 제안하고 범용 에이전트와 고정 순서 추적기와 비교 평가했습니다. 하네스는 같은 모델의 Codex(47%)와 Claude Code(10%)를 넘어 **75% 엣지 재현율**을 냈습니다. Claude Code는 인출하지 않은 기록을 인용하는 과신 때문에 재현율을 잃었습니다. 고정 순서 추적기와 비교하면 하네스는 예산 초반에 더 빨리 증거를 수집하고(89% 대 0%) 추적기가 지나치는 미공개 수탁 서비스를 인식하며, 98% 충실도를 보였습니다. 다만 에이전트는 일찍 멈추고 큰 과제에서 재현율을 잃어 최종 재현율은 최고 추적기에 미치지 못합니다. ABF-Bench는 블록체인 포렌식을 검증 가능한 도메인으로 LLM 에이전트에 개방하며, 에이전트를 채점하는 판정은 훈련 신호도 될 수 있습니다.

## 핵심 내용

- 모든 주장한 이동은 에이전트가 인출한 원장 기록을 인용해야 한다.
- 벤치마크는 다중 홉, DeFi 교환, 크로스체인, 믹서, 주소 포이즈닝을 결합한다.
- ABF 하네스는 75% 엣지 재현율로 Codex 47%, Claude Code 10%를 앞섰다.
- 하네스는 고정 순서 추적기가 놓치는 미공개 수탁 서비스를 인식했다(89% 대 0%).
- 에이전트는 일찍 멈춰 큰 과제 재현율을 잃어 최종 성능은 최고 추적기에 못 미친다.

## 상세

벤치마크는 기록이 불완전한 곳에서 연속성을 조작하지 못하도록 보수적 중단 규칙을 사용합니다. 참조 그래프는 수동 정답이 아니라 규칙이 결정한 답입니다. 작업 기억 하네스는 범용 코딩 에이전트와 고정 순서 추적기 양쪽과 비교되며 증거 수집 속도, 재현율, 충실도를 구분합니다.
