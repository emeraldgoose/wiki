# Library of Layers (LoL): 추론 시점에 Transformer Layer를 적응적으로 순서화

**원문**: [arXiv:2611.03526](https://arxiv.org/abs/2611.03526) · **게시일**: 2026-11-02
**저자**: Abdellah Rahmani, Sean McLeish, Ang Li, Sanae Lotfi, Pascal Frossard, Micah Goldblum

## 개요

프로그래머는 조건문이나 반복문 같은 재사용 가능한 계산 primitive를 서로 다른 순서로 연결해 서로 다른 알고리즘을 구현한다. 반면 기존 언어 모델 아키텍처는 항상 같은 순서로 layer를 실행한다. Library of Layers (LoL)은 문제 해결을 위해 추론 중에 transformer block의 순서를 동적으로 바꾸는 아키텍처이다. global transformer block library의 크기라는 단일 hyperparameter를 가지며, 이를 통해 parameter reuse와 sparsity 사이를 seamless하게 전환하고 autoregressive language models, mixture-of-depths designs, early-exit methods를 generalize한다.

## 핵심 내용

- 기존 transformer는 고정된 layer 순서를 사용한다.
- 재사용 가능한 block은 작업에 따라 다르게 순서화될 수 있다.
- LoL은 추론 시점에 layer 순서를 동적으로 바꾼다.
- 단일 hyperparameter가 global layer library 크기를 정한다.
- parameter reuse와 sparsity 사이를 포괄한다.
- 여러 transformer 설계 계열을 generalize한다.

## 상세

논문은 transformer depth를 rigid한 sequence가 아니라 composable resource로 다시 프레임한다. 추론 시점에 LoL은 주어진 문제에 어떤 block을 사용할지와 어떤 순서로 배치할지를 선택한다. library size를 변화시키면 model이 parameter 공유와 specialized sparse subsets 사용 사이에서 trade-off를 할 수 있다. 이는 early exit, mixture-of-depths, autoregressive transformers와 같은 개념들을 하나의 동적 layer-selection mechanism 아래 통합한다.
