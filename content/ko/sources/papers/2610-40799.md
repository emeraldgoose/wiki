# CaPtain: post-training code-as-policy robot agent를 위한 pipeline

**원문**: [arXiv:2610.40799](https://arxiv.org/abs/2610.40799) · **게시일**: 2026-10-27
**저자**: Yijia Fan, Xilin He, Yilei Jiang, Dongming Wu, Jiaxu Wang, Xiangyu Yue

## 개요

code-as-policy는 robot manipulation을 language-model agent와 같은 형태, 즉 policy가 fixed harness 안에서 실행되는 형태로 바꾼다. coding, web, tool-use agent는 SFT 후 multi-turn RL recipe로 흔히 훈련되지만 code-as-policy agent는 종종 training을 피하고 prompted frontier model이나 semantic skill에 의존한다.

CaPtain은 low-level에서 recipe를 적용하기가 더 어렵다는 관찰 위에 구축된 open post-training pipeline이다. semantic skill 없이 policy가 grasp와 approach 결정을 precise하게 내려야 하기 때문이다. policy는 perception, geometric measurement, guarded-motion primitive 22개만 노출하는 CaPtain-Harness 안에서 train/deploy된다.

## 핵심 내용

- code-as-policy robot agent에 SFT 이후 RL post-training recipe를 가져온다.
- 22개 low-level primitive만 제공하는 CaPtain-Harness를 제공한다.
- Qwen3.5-4B에 pipeline을 적용하여 CaPtain-4B를 만든다.
- held-out LIBERO success를 SFT 후 0%에서 55.4%, RL 후 73.8%로 높인다.
- LIBERO-PRO에서 78.5%를 달성하여 여러 frontier-model agent를 초과한다.
- pre-trained agent가 stronger하고 reward가 sparse할 때 RL gain이 더 크다.

## 상세

low-level harness 안에서 train함으로써 policy는 agent가 improve할 수 없는 component에 위임하는 대신 manipulation decision을 직접 학습한다. language agent에서는 arising하지 않는 gap을 다루는 셈이다.

논문은 LIBERO benchmark에서 held-out transfer와 비교 결과를 보고하여 low-level code-as-policy agent를 위한 open pipeline을 제공한다.
