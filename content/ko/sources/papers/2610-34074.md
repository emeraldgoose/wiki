# 동일하게 학습된 언어 모델도 서로 다른 탈옥에 뚫린다

**원문**: [arXiv:2610.34074](https://arxiv.org/abs/2610.34074) · **게시일**: 2026-10-25
**저자**: Chi-Wei Chang, Mu-Tien Kuo, Kuan-Wei Lee, Meng-Hsun Tsai

## 개요

탈옥 벤치마크는 보통 체크포인트 하나를 평가한 뒤, 그 모델을 뚫는 탈옥 목록을 사전학습 데이터와 안전성 학습의 속성으로 해석한다. 논문은 반사실을 곧바로 묻는다. 같은 데이터로 다시 사전학습하고 같은 안전성 사후학습을 적용하면, 두 번째 모델도 같은 탈옥에 뚫릴까? 사전학습은 확률적이며, 난수 시드만 다른 두 실행이 전체 정확도는 거의 같아도 개별 예측과 측정된 편향에서는 서로 어긋난다는 결과가 이미 있다. 안전성 연구도 미세조정 시드, 샘플링 시드와 온도, 심지어 사전학습 실행의 마지막 1% 구간까지는 흔들어 봤지만, 사전학습 실행 전체를 바꿔 본 적은 없었다.

이를 확인하기 위해 저자들은 25개 데이터 레시피마다 3개의 사전학습 시드로 1B 파라미터 모델을 학습시키는 DataDecide를 출발점으로 삼는다. 각 기반 모델에 같은 안전성 사후학습을 2개의 사후학습 시드로 적용해 모두 150개 모델을 만든다. 모든 모델이 공유된 3,212개 탈옥 프롬프트에 각 20개의 응답을 내놓고, 저자들은 모든 모델 쌍에 대해 프롬프트별 비거부율의 피어슨 상관을 계산한다. 쌍은 공유하는 계보로 나뉜다. 기반 모델을 공유하고 사후학습 시드만 다른 두 모델을 일란성 쌍둥이(MZ twins)라 부르고, 데이터 레시피만 공유하면 동일 레시피 쌍, 둘 다 다르면 교차 레시피 쌍이다.

이 비교가 사전학습 실행과 그 데이터를 분리한다. 한 사전학습 실행에서 나온 사후학습본 두 개는 평균 0.984로 상관한다. 사전학습 시드를 바꾸면 상관이 0.811로 떨어지고, 데이터 레시피까지 바꿔도 0.779로 조금 더 낮아질 뿐이다. 즉 불일치의 거의 전부가 데이터가 아니라 사전학습을 다시 돌린 데서 온다. 이 순서는 25개 데이터 레시피 모두에서, 그리고 150M과 300M 파라미터에서도 유지되며, 사람 라벨로 검증한 판정 모델에서도 같다. 실무적으로는 한 체크포인트에서 찾아낸 91개 공격 템플릿 중 최선의 것이 새 사전학습 시드에서도 최선으로 남는 비율이 27%에 그친 반면, 새 사후학습 시드에서는 67%였다. 또 프롬프트별 비거부율 자체가 사전학습 실행의 지문이 된다. 3,211개 프롬프트로 75개 실행 가운데 해당 실행을 매번 정확히 찾아내고, 무작위로 고른 50개 프롬프트로도 98%의 정확도를 보인다.

## 핵심 내용

- 어떤 탈옥이 통하는지는 데이터가 아니라 사전학습 실행을 따른다. 같은 실행의 사본은 0.984로 상관하지만, 사전학습 시드를 바꾸면 0.811, 데이터 레시피까지 바꾸면 0.779로 낮아진다.
- 이 순서는 25개 데이터 레시피 모두에서, 그리고 150M·300M 파라미터에서도 유지되며, 판정 모델의 결과는 사람 라벨과 일치한다.
- 한 실행을 같은 시드로 새 하드웨어에서 두 번 더 학습시켜도 원본과의 상관이 동일 레시피 쌍보다 조금 나은 수준에 그친다. 일란성 쌍둥이가 일치하는 이유는 시드가 아니라 학습된 실행을 공유하기 때문이라는 해석이다.
- 공격 템플릿은 사전학습 실행 사이에서 잘 전이되지 않는다. 91개 중 최선의 템플릿이 새 사전학습 시드에서도 최선일 확률은 27%인데, 새 사후학습 시드에서는 67%다.
- 거부 패턴이 실행을 식별한다. 3,211개 프롬프트는 75개 실행 중 정답을 매번 찾아내고, 무작위 50개 프롬프트로도 98%를 맞힌다.
- 사전학습 실행 전체를 흔든 연구는 이번이 처음이다. 기존 안전성 연구는 사전학습 이후에 적용한 시드나 한 실행의 마지막 일부 구간만 바꿨다.
- 저자들은 체크포인트의 탈옥 취약성을 말뭉치가 아니라 그 학습 실행의 서명으로 읽어야 한다고 결론짓는다.

## 상세

실험의 기반은 DataDecide가 제공한다. 여기서 데이터 레시피는 필터링과 중복 제거, 혼합 비율까지 포함해 공개된 사전학습 말뭉치이고, 사전학습 시드는 초기화와 데이터 순서를 함께 결정한다. 레시피마다 같은 100B 토큰으로 학습된 1B 모델 세 개가 주어지고, 각 기반 모델에 사후학습 시드를 두 개씩 적용하면 150개 모델이 된다. 모든 모델이 같은 프롬프트 집합에 20개씩 응답을 내놓고 판정 모델이 응답별 거부 여부를 정하며, 저자들은 이 판정 모델을 사람 라벨과 대조해 검증하고 더 작은 모델 크기에서도 같은 비교를 반복한다.

논지를 떠받치는 것은 상관 수치다. 기반 모델은 공유하되 사후학습 시드가 다른 경우가 데이터 레시피 평균 0.984, 레시피만 공유하는 경우가 0.811, 아무것도 공유하지 않는 경우가 0.779다. 하락분이 거의 전부 사전학습 재실행에서 나오므로, 저자들은 시드 때문인지 실행 자체 때문인지 확인하기 위해 한 실행을 자기 시드로 자기 하드웨어와 소프트웨어에서 두 번 더 학습시킨다. 새 모델들은 원본과도, 서로와도 동일 레시피 쌍보다 겨우 조금 더 높게 상관했다. 저자들은 이를 일란성 쌍둥이가 시드가 아니라 학습된 실행을 공유하기 때문에 일치한다는 근거로 읽는다.

여기서 두 가지 결론이 나온다. 첫째, 사전학습 실행 사이의 공격 전이는 믿기 어렵다. 한 체크포인트에서 찾은 최선의 템플릿은 다음 실행에도 통할 가능성이 낮은 반면, 사후학습 시드만 바뀌면 훨씬 자주 유지된다. 둘째, 거부 행동 자체가 식별 정보다. 저자들은 이를 사전학습 실행이 남긴 지문으로 보고, 벤치마크가 어느 실행을 평가했는지 함께 보고해야 한다는 근거로 제시한다.
