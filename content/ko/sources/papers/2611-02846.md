# SpecOPD: 추론 가속을 위한 분기 병렬 온정책 증류

**원문**: [arXiv:2611.02846](https://arxiv.org/abs/2611.02846) · **게시일**: 2026-11-02
**저자**: Tianyu Liu, Jun Zhang, Wenjie Huang, Yuhao Shen, Tianqi Xu, Xinyue Hao, Hongyaoxing Gu, Xuyang Liu, Baolin Zhang, Yating Zhu, Shuang Ge, Jun Dai, Lei Chen, Yue Li, Mingchen Wan

## 개요

speculative decoding은 토큰 단위 생성의 순차 비용을 줄여 LLM 추론을 가속한다. 고급 방법은 전체 블록을 한 forward pass로 예측하는 병렬 drafter를 사용해 proposal 비용을 낮추지만, 전체 speedup은 여전히 acceptance length에 의존한다. on-policy distillation은 acceptance plateau를 넘어 drafter를 밀어낼 수 있지만, 기존 pipeline은 순차 draft-and-verify rollout으로 감독을 수집한다. 핵심 통찰은 on-policy 감독이 이런 의존성을 물려받을 필요가 없다는 것이다: draft block은 참조 prefix와 draft 샘플링 이력만으로 감독 받을 수 있다. SpecOPD는 reference anchor에서 진화하는 drafter policy로부터 독립 branch를 샘플링하고 target 감독을 병렬화하는 분기 병렬 온정책 증류 프레임워크다. branch를 proposal tree로 묶어 target-prefix 계산을 공유하며, full attention용 tree mask, sparse attention용 branch-consistent indexer group, linear attention용 indexed state replay로 각 branch의 이력을 보존한다. drafter는 acceptance length를 직접 목표로 하는 E2E-TV surrogate로 훈련된다. 연구 범위는 8B full-attention, 27B full-linear, 125B sparse-linear target, DFlash/DSpark/DFlash V2 세 병렬 draft 아키텍처, dialogue/coding/mathematics/agentic 네 도메인을 포괄한다. SpecOPD는 평균 acceptance length를 최대 41.45% 높이고, native 구조에서 순차 rollout OPD 대비 16.09배 supervised-token throughput, autoregressive decoding 대비 최대 3.56배 생성 speedup을 달성한다.

## 핵심 내용

- 병렬 블록 proposal drafter를 사용해도 speculative decoding gain은 acceptance length에 의존한다.
- on-policy 감독은 엄격한 draft-and-verify 순차 의존성 없이 수집할 수 있다.
- SpecOPD는 reference anchor에서 독립 branch를 샘플링/감독하고 proposal tree로 묶는다.
- attention mask와 state replay로 branch 이력을 보존하면서 prefix 계산을 공유한다.
- E2E-TV surrogate가 acceptance length를 직접 최적화하며 +41.45% acceptance, OPD 대비 16.09x throughput, AR 대비 3.56x speedup.

## 상세

8B full-attention, 27B full-linear, 125B sparse-linear target, DFlash/DSpark/DFlash V2 세 아키텍처, dialogue/coding/math/agentic 네 도메인에서 평가한다. 구성 세부와 전체 speedup 표는 연결된 원문을 참고한다.
