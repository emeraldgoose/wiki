# K2-Horizon: 오픈 소스 언어 모델의 프런티어 플릿

**출처**: [arXiv:2611.21003](https://arxiv.org/abs/2611.21003) · **게시일**: 2026-11-16
**저자**: K2 Team (Zhengzhong Liu, Haonan Li, Xuezhe Ma 외)

## 개요

K2-Horizon은 0.9B dense 모델부터 375B-A23B 혼합전문가(MoE) 플래그십까지 아우르는 6개의 완전 오픈 언어 모델 플릿이다. 수학·과학, 소프트웨어 엔지니어링, 심층 리서치, 사무 자동화 등 범용 추론과 에이전트 작업을 목표로 설계되었으며, 보고서에 따르면 에이전트 및 코딩 벤치마크에서 동급의 강력한 오픈 모델들과 동등하거나 앞선다.

모델링 측면에서는 attention value 투영에 MoE를 적용한 Mixture-of-Value Attention(MoVA)과, 더 유연하고 이론적 근거를 갖춘 게이트인 softplus attention gating을 제안한다. 이 두 가지를 모두 적용한 36B-A4B 모델은 동일한 데이터로 학습한 32B dense 모델에 거의 근접하면서도 활성 파라미터는 약 7분의 1 수준이다. 또한 별도의 드래프트 모델 없이 디코딩 속도를 최대 2.2배 높여 주는 손실 없는(lossless) 확산 어댑터 Uno도 함께 소개한다.

이번 공개는 투명성과 재현성을 위한 LLM360 오픈 소스 정의를 따른다. 최종 가중치뿐 아니라 모든 학습 단계의 중간 체크포인트, 사전학습 데이터, 학습 로그, 학습·평가·인프라 코드 전체를 공개하는데, 특히 dense 및 MoE 학습을 위한 프로덕션 규모의 xLLM 프레임워크와 RL360 강화학습 스택이 포함된다. 데이터 자체를 넘어 데이터를 만든 파이프라인 전반도 문서화하여 공개했으며, 이 파이프라인들이 약 10T 규모의 합성 사전학습 토큰을 만들어 냈다. 6개 모델 중 4개는 하나의 22T 토큰 사전학습 코퍼스와 레시피를 공유하여 스케일링 거동과 희소성을 통제된 방식으로 연구할 수 있게 한다. 모든 아티팩트는 https://ifm.ai/k2/ 에서 받을 수 있다.

## 핵심 내용

- 6개의 완전 오픈 모델 — 0.9B, 3.7B, 7B, 32B dense, 36B-A4B MoE(MoVA 적용), 375B-A23B MoE 플래그십 — 이 범용 추론과 에이전트 작업을 겨냥한다.
- MoVA는 attention value 투영에 MoE를 적용한 기법이며, softplus attention gating은 더 유연하고 이론적 근거를 갖춘 게이트다.
- 두 기법을 모두 쓴 36B-A4B 모델은 동일 데이터로 학습한 32B dense 모델에 거의 근접하면서 활성 파라미터는 7분의 1이다.
- Uno는 별도 드래프트 모델 없이 디코딩을 최대 2.2배 가속하는 손실 없는 확산 어댑터로, 7B와 0.9B 모델용 어댑터가 제공된다.
- 공개 아티팩트: 최종 모델 6개, 체크포인트 380개, 양자화 빌드 23개, 학습 데이터 21.6TB, 학습 실행 58회, 코드 저장소 17개.
- 플래그십 375B-A23B는 15.1T 토큰으로 두 단계에 걸쳐 사전학습되었고, dense 및 MoVA 모델은 22T 토큰을 보았으며 그중 약 10T는 합성 데이터다.
- 미드 트레이닝은 약 1.9T 큐레이션 토큰으로 진행되었고, 컨텍스트를 32k에서 128k, 512k로 확장했다.
- 포스트 트레이닝은 도메인별 RL 전문가(검색, 지식 작업, 도구 사용, 과학 추론, 기권을 포함한 지시 이행)를 개별 학습한 뒤 가중치 병합으로 합치고, 마지막에 SFT를 적용한다.
- 공개 방식은 LLM360 정의를 따르며, 중간 체크포인트·데이터·로그·코드(xLLM, RL360)를 모두 포함한다.

## 상세

방법. 사전학습은 웹 텍스트, 코드, 수학, 과학 문헌, 다국어 데이터를 8k 토큰 시퀀스로 학습했으며, 팀이 문서화한 파이프라인이 만든 약 10T의 합성 토큰이 포함된다. 학습률은 모델 크기에 맞게 적합한 스케일링 규칙을 따랐고, 데이터 믹스는 소규모 절제 실험이 아니라 프로덕션 규모에서 예측한 벤치마크 점수로 선택되어 웹 중심 믹스로 이어졌다. 플래그십은 15.1T 토큰으로 두 단계(두 번째 단계는 갱신된 데이터 믹스)에 걸쳐 학습되었고, dense 및 MoVA 모델은 22T 토큰을 보았다. 대부분의 실행은 끝까지 일정한 학습률을 유지했으며, 감쇠 대신 체크포인트 평균을 미드 트레이닝 전에 적용했다. 미드 트레이닝에서는 컨텍스트를 32k(1단계)에서 128k(2단계), 512k(3~4단계)로 확장하면서 RoPE base도 함께 올렸고, 장문 문서·추론·코딩·지시 이행·에이전트 궤적을 강조한 약 1.9T 토큰으로 진행했다. 포스트 트레이닝은 모델 크기별로 레시피가 다르며, 플래그십의 경우 다섯 도메인(검색, 지식 작업, 도구 사용, 과학 추론, 기권을 포함한 지시 이행)별 RL 전문가를 샌드박스 환경에서 검증기 채점 방식으로 학습한 뒤 가중치 병합으로 하나의 모델로 합치고, 낯선 에이전트 하니스 형식 같은 남은 격차를 메우기 위해 시연 데이터로 마지막 SFT를 수행했다.

결과. 보고서는 이 모델들이 에이전트 및 코딩 벤치마크에서 동급의 강력한 오픈 모델들과 동등하거나 앞선다고 밝히며, 36B-A4B MoVA 모델은 동일 데이터로 학습한 32B dense 모델에 거의 근접하면서 활성 파라미터는 7분의 1이라고 보고한다. Uno 어댑터는 별도 드래프트 모델 없이 디코딩을 최대 2.2배 가속한다. 6개 모델 중 4개는 22T 토큰 코퍼스와 레시피를 공유하며, 일관된 스케일링 거동을 보이고 스케일과 희소성에 대한 통제된 비교를 가능하게 한다.
