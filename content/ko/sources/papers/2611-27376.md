# RL expert를 조합 가능한 soft prompt로 증류하는 CSPD: continual post-training을 향하여

**원문**: [arXiv:2611.27376](https://arxiv.org/abs/2611.27376) · **게시일**: 2026-11-20 (v1; v2 2026-11-24)
**저자**: Zhen Zhang, Changyi Yang, Xuehai He, Chengzhi Liu, Yutong Yin, Ziyue Liu, Zhuoran Yin, Yangmin Li, Zhihan Liu, Jisen Li, Mingyu Jin, Chuhan Li, Zhaotian Weng, Ruoyu He, Wenyao Gao, Jiaxin Deng, Chenwei Wu, Hui Shen, Wenhao Chai, Chenyang Zhao, Zhuofan Ying, Kieran Liu, Andrew Chen, Pony Ma, Zhaoran Wang, Alkesh Patel, Zhe Gan, Xin Eric Wang

## 개요

RL post-training은 보통 도메인별로 따로 수행되어 도메인 expert들을 만들고, 이들을 다시 하나의 모델로 통합해야 하는데, 새로운 expert가 계속 도착하면 이 통합은 일회성이 아니라 continual 과정이 된다. 가중치 병합(weight merging)과 multi-teacher on-policy distillation(MOPD)은 expert가 추가될 때마다 전체 모델을 다시 통합해야 하고 모든 요청에 동일한 혼합을 적용하며,대상 도메인 밖의 능력을 저하시킬 수 있다. 이 논문이 제안하는 Composable Soft-Prompt Distillation(CSPD)는 RL 이전 모델을 동결한 채 각 RL expert를 독립적인 soft prompt로 distill하고, 추론 시점에 prompt들을 단순히 연결(concatenate)해 expert를 조합한다. joint training도, 가중치 갱신도 없다.

방법은 두 부분으로 구성된다. 각 expert는 동결된 RL 이전 체크포인트 위에서 prefix-robust 학습(Muon 옵티마이저, 200회 업데이트)으로 256개 벡터의 soft prompt에 distill되어, 서로 다른 순서로 연결되어도 survive한다. 조합 시에는 모든 prompt를 한 번에 붙이고(예: math-code-science-instruction 순서인 "MCSI"), 백본과 다른 모듈을 고정한 채 prompt를 prepend하거나 삭제하는 것만으로 expert를 추가·제거할 수 있다.

## 핵심 내용

- 단일 expert distillation: 수학, LiveCodeBench 코드, SWE-bench Verified·Terminal-Bench 2.1 에이전트에 걸친 23개의 공개 pre-RL/post-RL 쌍(7B~35B의 dense 및 MoE 모델)에서 prompt를 붙인 student가 22/23 설정에서 teacher 이득의 90% 이상을 회복하고 15개 설정에서는 teacher를 따라잡거나 넘어섰다. 예: DeepSWE의 student는 SWE-bench Verified에서 24.90% → 45.65%로, teacher의 44.05%를 상회했다. 최저 회복률은 MiMo-7B 코드의 88.08%로, expert의 원래 학습 데이터 없이 distill한 경우이다.
- Prompt 길이와 supervision: GPT-OSS math에서 32개 벡터만으로도 90.0% 회복(256개 벡터는 93.1%); 정답 비율이 69%에 불과한 응답으로 학습해도 90.5%를 회복(정답만 사용한 경우 96.1%)하므로 verifier 필터링이 필수는 아니다.
- 조합(composition): M2RL 4도메인 설정(AIME24 / LiveCodeBench v5 / GPQA-Diamond / IFBench, student는 Qwen3-4B-Base 기반 M2RL-SFT)에서 연결된 CSPD prompt는 평균을 50.41에서 67.83(회복률 107.5%)으로 끌어올려 MOPD(67.79)와 동등하고 expert TA 병합(67.27), TIES(67.47), LoRA distill+TA(65.50), 개별 expert의 oracle 라우팅 평균(66.61)을 앞섰다. 같은 prompt를 단일 도메인에서만 쓴 경우 평균은 65.38이었다.
- Continual 추가: expert가 instruction→science→code→math 순서로 도착할 때 기존 모듈을 재학습하지 않고도 평균이 매번 상승했다(50.41 → 60.99 → 61.67 → 63.67 → 67.83). 독립 prompt 학습은 모든 단계에서 progressive 학습을 앞섰고(67.83 vs 65.17), progressive 학습은 가장 먼저 학습된 능력을 잠식했다(IFBench가 중간에 52.71/50.88까지 하락).
- 모듈 간 상호작용: math prompt를 제거하면 평균이 가장 크게 하락(−4.16, GPQA-Diamond −6.54 포함); instruction-following prompt 제거 시 IFBench −12.88; 음의 교차 도메인 간섭도 존재(code 추가가 IFBench를 66.71 → 64.58로 낮춤)하지만 전체 평균은 추가할 때마다 상승했다.
- Out-of-domain 일반화: 6개 held-out 벤치마크(XSTest, TruthfulQA, BFCL, TriviaQA, BBEH, FinQA)에서 CSPD가 최고 평균 56.6을 기록하며 6개 중 4개(XSTest 88.2, BFCL 55.6, BBEH 25.8, FinQA 72.5)에서 1위를 차지했다(MOPD 53.5, TIES 54.1 대비).
- 서빙: 입력 공간 적응은 처리량을 적응 없는 백본 대비 1.5% 이내로 유지하면서 rank-4 LoRA 어댑터 대비 2.40배 처리량을 달성했다.

## 상세

CSPD가 동작하는 이유는 조합이 입력 공간에서 일어나기 때문이다. prompt들은 서로 다른 연결 순서(MCSI 대 역순 ISCM)에서도 견디도록 독립적으로 prefix-robust하게 학습되고, 동결된 백본 덕분에 expert 도메인 밖의 능력은 건드리지 않는다. 부록의 ablation은 정답 전용 대 mixed supervision, prompt 길이 sweep, 옵티마이저와 연결 순서, TA/TIES 베이스라인의 task-arithmetic 계수 sweep, out-of-domain 평가 설정을 다룬다. 코드는 https://github.com/UCSB-AI/CSPD 에 공개되었다.
