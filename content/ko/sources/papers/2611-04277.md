# Harness-S: 일반화 에이전트 학습을 위한 sibling harness 학습

**원문**: [arXiv:2611.04277](https://arxiv.org/abs/2611.04277) · **게시일**: 2026-11-03
**저자**: Kangning Zhang, Wenxiang Jiao, Bowen Fang, Shuai Shao, Jiachen Zhu, Rong Shan, Shijian Wang, Hao Wang, Yuan Lu, Weiwen Liu, Weinan Zhang

## 개요

공통 base에서 evolved한 agent harness들은 locale, complementarity, nonstationarity를 보인다. variant들이 서로 다른 failure를 repair하고 policy가 learns하면서 utility가 변하므로 universally superior harness를 찾는 것보다 failure를 복구하는 전략이 필요하다.

Harness-S는 sibling harness들을 통해 base execution system의 실패를 rescue하고 그 resulting capability를 original harness 아래에서도 effective한 단일 policy로 transfer한다. Directional Harness Evolution은 서로 다른 repair direction에 specialization된 sibling harnesses를 개발해 policy training 동안 fixed한 Sibling Harness Pool을 형성한다. Complementary Harness Rescue Training은 base harness에서 모든 initial attempts가 fail할 때만 pool을 invoke한다.

auxiliary harness 아래의 fresh rollouts가 failed group을 reinforcement learning용 trajectory로 대체한다. adaptive router는 harness behavior profile과 multiple LLM voting으로 top-k variants를 선택하고, policy가 learns하면서 profile을 re-anchor한다. AppWorld, SWE-Gym, DBBench에서 base harness로 돌아갔을 때 policy-only training 대비 substantial improvement를 보인다.

## 핵심 내용

- universally superior harness를 찾기보다 variant complementarity를 활용한다.
- 서로 다른 repair direction에 맞는 sibling harness pool을 형성한다.
- base harness의 모든 initial attempt가 실패했을 때만 training한다.
- harness-elicited behavior를 base-harness policy로 transfer한다.
- harness behavior profile 기반 adaptive router를 사용한다.
- 동일 executor rollout 수에서 rank-one inference를 추가 개선한다.

## 상세
