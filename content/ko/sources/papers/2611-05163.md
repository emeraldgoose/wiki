# RoboTryOn: Virtual Try-On을 통한 Human 비디오에서 로봇 시연 합성

**원문**: [arXiv:2611.05163](https://arxiv.org/abs/2611.05163) · **게시일**: 2026-11-03
**저자**: Seungyong Lee, Suhyeok Jang, Minyoung Kim, Jinwoo Shin

## 개요

로봇 foundation models는 제어에 강한 성능을 보이지만 새 task에 적응하려면 teleoperation demonstrations에 아직 크게 의존한다. Egocentric human 동영상은 확장 가능한 대안이지만 rendered robot overlay나 human pose retargeting은 고자유도 embodiment에서 시각·action gap을 남긴다. RoboTryOn은 human-to-robot translation을 virtual try-on으로 보아, 사람을 keep하고 garment를 swap하듯 motion을 keep하고 human을 robot으로 swap한다. reference image로 지정된 target robot 비디오와 task, object, background를 보존한 비디오를 생성하며, keyframes를 autoregressive하게 translation하고 human hand skeleton으로 motion을 condition한 video synthesis를 사용한다. depth feature를 포함한 inverse dynamics model로 synthesized videos에서 action labels를 추론한다.

## 핵심 내용

- human 동영상은 target robot 동영상으로 변환된다.
- 변환 중 task, object, background가 보존된다.
- selected keyframes가 autoregressive 방식으로 translation된다.
- motion은 human hand skeleton에 condition된다.
- inverse dynamics model이 depth feature로 action labels를 추론한다.
- synthetic data policy는 collection 비용을 줄이며 새로운 task 성공률을 개선한다.

## 상세

여러 humanoid embodiment에서 synthetic data로 학습한 policy는 real demonstrations of those tasks 없이 novel bimanual manipulation task 포함 평균 success를 2에서 60 percent로 높였다. synthetic data만으로 teleoperated demonstrations only policy와 비슷한 성능을 약 1/3 collection cost에서 달성했다. 이득은 generated robot appearance, skeleton tracking, inverse dynamics prediction, target embodiment transfer 품질에 의존한다.
