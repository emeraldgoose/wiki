# 학습 가능한 prefix tokens를 사용한 retrieval embedding의 representational interference 감소

**원문**: [arXiv:2611.07298](https://arxiv.org/abs/2611.07298) · **게시일**: 2026-11-05
**저자**: Seongtae Hong, Youngjoon Jang, Jungseob Lee, Chanjun Park, Heuiseok Lim

## 개요

embedding model은 variable-length text를 fixed-size vector로 압축하지만 이 process는 semantic content와 residual token-level information, 특히 attention sink behavior에서 나온 artifacts를 entangle시킬 수 있다. 본 연구는 embedding model training 동안 input 앞에 trainable `[DUMP]` tokens를 prepend하자고 제안한다.

방법은 architecture, pooling strategy, training loss를 unchanged로 유지한다. prefix tokens는 standard contrastive retrieval objective를 통해 optimize되며 encoding 중 regular tokens와 interact해 residual 또는 uninformative token-level signals가 final retrieval representation에 미치는 influence를 줄인다.

standard retrieval과 long-context benchmarks 실험은 encoder와 decoder embedding models 모두에서 finetuned baselines 대비 consistent improvements를 보인다. 추가 analysis는 `[DUMP]` tokens가 low-information tokens와 associated된 token-level activation과 attention patterns를 alter함을 보여준다. 이는 trainable prefix tokens가 retrieval representation을 improve하는 lightweight way임을 시사한다.

## 핵심 내용

- fixed-size retrieval embedding에서 representational interference 문제를 다룬다.
- architecture나 loss를 바꾸지 않고 trainable `[DUMP]` tokens를 prepend한다.
- standard contrastive retrieval training으로 prefix tokens를 optimize한다.
- residual와 uninformative token-level signals의 영향을 줄인다.
- standard retrieval과 long-context benchmarks result를 개선한다.
- low-information tokens의 activation와 attention patterns change를 보인다.

## 상세

paper는 CIKM 2026에 accept되었고 기존 embedding model architecture와의 compatibility를 강조한다. additional inference changes 없이 lightweight improvement를 목표로 한다.
