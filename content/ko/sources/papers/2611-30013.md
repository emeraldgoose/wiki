# 3AGameFactory-Motion: 다양한 3D 에셋을 위한 에이전트 기반 리깅과 신뢰성 있는 복합 모션 생성

**원문**: [arXiv:2611.30013](https://arxiv.org/abs/2611.30013) · **게시일**: 2026-11-23 (v1)
**저자**: Bohan Zeng, Kaixin Zhu, Yifan Yang, Dongge Yu, Zihao Wu, Yifan Dai, Zhou Liu, Junbo Niu, Xiaochen Ma, Shiran Ge, Zimeng Meng, Junzhu Liang, Huanyao Zhang, Jinhang Liu, Tianqi Xiao, Jinhao Zhang, Tianyi Bai, Zhixiong Zeng, Penghao Zhao, Yuanbo Peng, Key Zhang, Wentao Zhang

## 개요

"왼쪽 날개를 2초 안에 60도로 올리고, 세 번 퍼덕인 뒤 활강해서 착지하라" 같은 지시로 임의의 3D 에셋을 애니메이션하려면 구조 추론(리깅)과 미세 모션 제어가 모두 필요하지만, 기존 모션 벤치마크는 대부분 기존 인간/동물 스켈레톤과 단순 지시만 다룹니다. 저자들은 여섯 형태 범주(인간형, 다족, 축형, 날개형, 혼합사지, 기계형)의 50개 에셋에 428개 텍스트 + 422개 수치 지시로 이루어진 850개 모션 작업을 담은 DivDynBench를공개합니다. 작업은 여러 단계의 부위 협응과 명시적 시간·각도·반복·궤적 제약을 요구하며, 평가는 텍스트 의미 충족과 프로그램 검증 수치 정확도를 분리하고 단계 완수성, 형태 적합성, 애니메이션 품질(0~100점)을 추가로측정합니다.

이 벤치마크에서 세 가지 LLM 기반 패러다임을 체계적으로 비교합니다. (1) LLM +전문 모션 생성기: 저렴하고 자연스럽지만 생성기의 스켈레톤과 거친 의미에 묶여 미세 제어 불가. (2) LLM + 비디오 생성 + 모션 복원: 강력한 시각적 사전지식이 있지만 비용이 크고 복원 모델이 주로 인간용이며 시간·진폭이 소실됨. (3) LLM 직접 모션 생성: 임의 구조에 적응하고 미세 제어가 가능하지만 프레임별 관절 출력이 토큰을 많이 쓰고 운동 제약이 없어 간섭이 발생. 비교 결과적응성과 제어 면에서 직접 에이전트구동 생성이 가장 유망해, 저자들은 에이전트 모션 프레임워크를제안합니다. 에이전트가간결한 파라메트릭 프로그램(지속시간/프레임레이트, 단계 구간과 핵심 이벤트, 루트 제어, 부위별 관절 체인·연산자·모션 파라미터·접촉 구간)을 작성하면 결정적 실행기가 리깅, IK/FK운동 해석, 메시에 기반한 침투·접촉 오차·말단 편차 보정을 수행합니다.

## 핵심 내용

- 에이전트 리깅: 에이전트가 각 부위가 가장 뚜렷한 캘리브레이션 뷰에서 관절을 라벨링하면 실행기가 다중 뷰 라벨을 실제 형태를 따르는 3D 스켈레톤으로 융합(고정 템플릿 불필요)하고, 측지학적으로 게이팅된 이웃 안에서 거리 기반 스키닝 가중치를 평활화한 뒤 프로브 변형으로 검증합니다. 아홉 꼬리 여우에서전문 방법은 대부분 꼬리를 리깅하지 않고 직접 LLM 리그는 체인 일부가 메시에 밖에 놓이는데, 프레임워크는 꼬리마다 각각 체인을 만듭니다. 문에서는 베이스라인이 패널을 가로지르는 대각선 뼈나 인간형 트리를 그리는 반면 프레임워크는 경첩 모서리를 따라 주 뼈를 배치해 Rigid RMS가 낮아집니다. Source Fidelity, J2J, mIoU, 관절 유효성에서 향상되며 Edge p99/Rigid RMS 악화 없음.
- 모션 프로그램: P = (T, f, H, K, R0, {Pp}, ξ). 단계 구간의 이징 제어 곡선, 반복 횟수, 루트 연산자, 부위별(체인, 연산자, 파라미터, 접촉 구간). 말단 effector 연산자는 한 스칼라를 관절별 가중치로 분배해 체인 전체를 굽혀, 꼬리나 촉수 같은 임의 길이 체인도 말단 궤적으로 형태를 잡습니다. 뼈 길이는 변하지 않고 도달 불가 목표는 관절 한계 안에서 가능한 가깝게 가리키며 잔차는 개량으로 전달.
- 모션 결과:전문 생성기와 비디오 복원은 순서 있는 단계와 수치 목표를 거의만족하지 못함. 인간형 부분집합에서 MoMask와 비디오 복원 하위 26, 에이전트가 구조화 IK목표를 준 MotionBricks 49.09, 같은 에이전트 + 프레임워크 57.27. 예: 2.2초 내 왼주먹-오른주먹-회전 뒤돌려차기 시퀀스를 프레임워크는 순서대로 완료하지만, 없으면 일부 단계가 누락됨.
- 비용: 직접 LLM 생성이 이미 경제적인데, 프레임별 관절 값이 아니라 소수의 의미 파라미터만 작성하므로 프레임워크가 비용을 더 낮춥니다.
- 사용자 연구: 30명의 지원자가 세 방법에 대해 Semantic/Completeness/Morphology/Aesthetics를 평가한 결과 GPT-6.1 기반 루브릭 점수와 같은 추세·순위를 보여 자동 채점의 타당성을확인.
- 평가 mara: 리깅은 원시 메시에서 수동 그라운드 트루 대비 프로그램 지표로 채점, 모션은 제공된 참조 리그에서 평가해 점수가 지시 추종만 반영하도록 분리. 생성에는 소스 에셋·지시·참조 리그만 투입, 무효 케이스는 Overall에서 0점 처리.

## 상세

리깅 지표에는 Source Fidelity(메시 보존 — SkinTokens/UniRig/RigAnything는 입력 메시를 처리해 잃고, Puppeteer는 유지하지만 J2J/mIoU/관절 유효성에서 뒤처짐), 관절 대 관절 오차, mIoU, 관절 유효성, Edge p99, Rigid RMS가 포함됩니다. 모션 지표(형태 적합성, 침투, 발 미끄러짐, 변형)는 스킨드 메시에서 계산하고 결과는 고정 뷰에서 렌더링한 애니메이션 GLB로 출력. 베이스라인 에이전트는 동일한 설정과 유사한 턴 수로 프레임워크 유무를 비교한 GPT-6.1-sol과 Claude-ops5.5이며, 인간형 전용 방법(MoMask, MotionBricks, DuoMo 복원)은 인간형 부분집합에서 별도 비교합니다. 관련: 3AGameFactory 오픈소스 프레임워크(github.com/OpenDCAI/GameFactory-3A).
