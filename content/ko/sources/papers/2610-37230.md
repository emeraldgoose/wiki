# TAO: LLM 기반 에이전트 서빙을 위한 도구 인식 연합 스케줄링

**원문**: [arXiv:2610.37230](https://arxiv.org/abs/2610.37230) · **게시일**: 2026-10-27
**저자**: Shuhuai Li, Shengdong Ye, Dongdong Ge, Yinyu Ye, Jianghao Lin

## 개요

에이전트 서비스는 클러스터 GPU의 모델 추론과 분산 CPU의 외부 도구를 번갈아 사용한다. 기존 시스템은 (1) 서비스 평가에서 도구 반환 준비도를 무시해 한정 자원을 낭비하고, (2) GPU admission/placement를 휴리스틱으로 결정해 스케줄링이 비효율적이다.

TAO는 LLM 기반 에이전트 서빙을 위한 도구 인식 연합 스케줄링 프레임워크다. value 인터페이스는 단기 도구 준비도, 시간 감쇠 node-specific cache credit, token footprint를 결합하고, capacity 제약 하에서 dynamic program으로 대기 세션을 연합 선택/배치한다.

## 핵심 내용

- 에이전트 서빙의 admission과 placement를 함께 다루는 TAO를 제안한다.
- value 인터페이스에 단기 도구 준비도, 시간 감쇠 cache credit, token footprint를 통합한다.
- capacity 제약 하에서 휴리스틱 대신 dynamic program으로 세션을 선택/배치한다.
- 12개 model-workload-concurrency 설정에서 지연 26.8%, TTFT 36.3% 감소, decode throughput 29.5% 향상을 보인다.

## 상세

도구 준비도와 캐시 값을 jointly 모델하면 CPU 도구와 GPU 추론 파이프라인을 더 잘 연결하고, 기존 휴리스틱 스케줄링의 낭비를 회수한다.
