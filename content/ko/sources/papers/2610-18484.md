# ReTerm: 자기 개선 터미널 에이전트를 위한 복구 훈련

출처: Wei Xie 외 5인, arXiv:2610.18484, 2026-10-13.

**핵심 요약**: 터미널 에이전트는 복잡한 코딩 과제에서 강한 능력을 보이지만, 장시간 실행 중 명령 오류나 잘못된 구현 같은 실패에서 복구하지 못해 결국 과제를 실패하는 경우가 많습니다. **ReTerm**은 **자신의 실패한 터미널 과제에서 복구하는 법**을 학습하는 자기 개선 에이전트입니다.

## 데이터와 훈련

SFT 콜드 스타트를 위해 효과적인 복구 시연을 담은 고품질 데이터셋 **ReTerm-10K**와 전용 데이터 파이프라인을 구축했습니다. 이어 **ReTerm-GRPO**는 에이전트 자신의 실패 상태에서 분기해 여러 개의 독립적인 자기 복구 시도를 생성하는 온라인 RL 알고리즘입니다. 각 시도가 과제를 성공적으로 완료했는지로 학습하므로, 에이전트는 자기 복구 경험을 통해 스스로 개선됩니다.

## 결과

Qwen3.5-9B 기반 **ReTerm-9B**는 Terminal-Bench 2.0에서 **Pass@1 34.8%**를 기록해 베이스 모델보다 **14.6점** 높았습니다. 추가 분석에서 표준 GRPO보다 다양한 오류 범주에서 일관되게 높은 복구율을 보였습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. 자기 실패 상태에서 분기하는 훈련은 실패 분포에 과적합될 수 있고, 복구 시도가 과제 요구를 우회하는 보상 해킹으로 이어질 수 있습니다. 오류 범주별 정의와 데이터 중복 제거 방식은 원문을 확인하세요.

## SW 엔지니어와의 관련성

- 에이전트 평가에서 최종 성공률만 보지 말고 **오류 후 복구율**을 별도 지표로 두세요.
- 실패 로그를 버리지 말고 복구 시연 데이터로 바꾸는 파이프라인이 훈련 자산이 됩니다.
- 복구 훈련 시 과제 요구를 우회하지 않도록 검증기와 성공 조건을 함께 점검하세요.
