# SleuthVLM: omni 비디오 이해를 위해 오디오 직접 입력이 정말 필요한가?

**원문**: [arXiv:2611.06083](https://arxiv.org/abs/2611.06083) · **게시일**: 2026-11-04
**저자**: Peiran Wu, Fangfei Gou, Zhaoxi Mu, Changhao Zhang, Jian Liu, Weiqiang Wang, Yuntao Wang, Yuanchun Shi, Junxiao Shen

## 개요

omni model들은 sampled frames와 audio를 one turn에 jointly processing하여 비디오 질문에 답하며 progress는 주로 model size scaling과 omni training data scaling에 의해 driven된다. 논문은 모델이 오디오를 직접 hear해야 하는지 ask한다. it presents SleuthVLM, an agent harness built on VLM that never hears audio directly: speech는 text로 transcribed되고, VLM이 predefined workflow 없이 video를 sleuth한다. 90분까지 videos를 갖는 four omni benchmarks에서 SleuthVLM은 best average accuracy 75.0%를 달성하며 Gemini 3.8 Flash보다 2.6 points above, Video-MME-v2 leaderboard에서는 77.8%로 1위를 차지한다. open-source 27B VLM variant는 all open-source omni models를 beats한다. three findings를 draw: SleuthVLM은 glance하는 model beats; hearing이 bottleneck이 아니라 agentic ability가 bottleneck; omni understanding은 modality alignment용 more omni data가 아니라 better agentic ability를 필요로 한다. 논문은 omni video understanding의 simple but effective starting point를 제공하고 conclude: omni understanding needs better agents, not just bigger models that hear.

## 핵심 내용

- SleuthVLM은 오디오를 직접 입력하지 않고 speech를 text로 transcribe하고 VLM이 video를 sleuth.
- predefined workflow 없이 VLM이 증거를 autonomous하게 조사.
- 4개 omni benchmarks 평균 75.0%(최대 90분)로 Gemini 3.8 Flash 대비 2.6 points.
- Video-MME-v2 77.8% 최상, open 27B variant가 open-source omni 전부 beats.
- bottleneck은 hearing이 아니라 agentic ability이다.

## 상세

approach는 modality alignment보다 agent ability를 강조한다. transcription + VLM sleuthing이 direct audio ingestion을 대체한다. full benchmark/ablation/harness details은 연결된 원문을 참고한다.
