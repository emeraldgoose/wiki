# Reflex: 시각 기반 반응형 휴머노이드 제어

**Source**: Jia et al., arXiv, 2026-10-08

**핵심**: 휴머노이드가 던져진 상자를 잡으려면 세 가지 난제가 결합된다: 전신 제어(발 배치, 충격 흡수, 균형), 지연 속 물체 동역학에 대한 1초 내 반응, 움직이는 1인칭 카메라에서의 지각. Reflex는 이를 8차원 물체 동역학 잠재변수로 연결된 세 단계로 분리한다: 특권 상태에서 PPO 전신 제어 학습, 지연/누락 하 동역학 잠재 학습, 제어기 고정 후 RGB-D 히스토리에서 시각 그라운딩. 시뮬레이션에서 1인칭 RGB-D로 85.7%(특권 입력 87.9%); 실제 Unitree G1이 사람이 던진 상자를 2.5m, 5m에서 65%, 40% 포착.

## 배경

기존 포착 시스템은 세 과제 중 최소 하나를 회피한다: 고정 베이스 암은 균형을 생략하고, 휴머노이드 골키퍼/포수는 온보드 시각 대신 모션 캡처나 마커 물체에 의존한다. 정지된 상자를 드는 준정적 loco-manipulation은 로봇이 접촉 시점을 고를 수 있지만, 포착은 그 자유를 없앤다—상자가 도착할 때(약 1초 비행, 카메라-제어 지연 중앙값 ~69ms) 몸이 이미 제자리에 있어야 한다.

Reflex의 분해는 각 역량에 직접 학습 신호를 주고 값비싼 렌더링을 RL에서 분리한다: 렌더링 없는 Stage 2 PPO는 ~28k 스텝/s vs RGB-D 루프 포함 ~1.5k(59M 스텝: ~11시간 대신 ~35분).

## 3단계 방법

**Stage 1 — 전신 제어**: PPO로 상태 기반 29자유도 정책 학습(512–256–128 MLP, 비대칭 크리틱). 접근/홀드 셰이핑, 지속 포착 보너스, 리타게팅 인간 모션 추적 + AMP 스타일 보상, 낙상/몸통 페널티. 투척, 접촉, 동역학 무작위화.

**Stage 2 — 물체 동역학 잠재**: 특권 인코더가 지연·부분 관찰된 26차원 상자 관찰(위치, 속도, 크기, 방향, age, 가시성)을 8차원 유계 잠재로 압축. Stage 1 교사에 대한 행동 매칭 행동 복제(가시 샘플 가중 5배, DAgger 5라운드)로 잠재 경로 초기화 후, 20–60ms 지연 무작위화 하에서 인코더/디코더 합동 PPO 정제. 프로브 결과 잠재는 지연된 위치/속도를 부호화($R^2$ 0.90–0.99)하고 관찰 age를 부분 보상—크기·방향은 아님.

**Stage 3 — 시각 그라운딩**: CNN이 RGB-D에서 상자 위치 히트맵 예측; GRU가 25프레임 히스토리의 8개 기하 특징 + 9차원 ego-motion을 융합해 고정된 Stage 2 잠재 회귀(+ 보조 위치/속도 손실). 제어기 고정; 시각 제어기 롤아웃에 DAgger식 집계; 외형 강건용 색상 증강. 하류에서는 슈퍼바이저가 잡은 상자를 SONIC 보행 제어기로 넘겨 운반 + 전달.

## 실험

**설정**: Isaac Lab 시뮬레이션(물리 200Hz, 제어 50Hz); Unitree G1, 29자유도, 몸통 RGB-D(192×144). 학습 투척 2.5–5.0m; 평가 조건당 640 투척(3.0–3.5m). 포착 = 가슴 영역 지지, 손목이 상자 양옆, 0.6초 저속 유지. 실제 로봇: 조건당 20회, 사람이 던진 상자.

**벤치마크**: 상자 크기·무게·거리·색·측면 오프셋·추가 지연에 따른 포착/차단율; 보상·초기화·시각 입력 제거 연구; 실제 로봇 시험; 검출+칼만 베이스라인.

**결과**:

| 결과 | 수치 |
|--------|--------|
| 시뮬레이션 전체(시각 제어기 6개) | 85.7%(3290/3840) vs 특권 잠재 87.9% — 시각이 성능 거의 보존 |
| 실제 로봇(표준 상자) | 2.5 / 5 / 7m에서 65% / 40% / 15% = 인간 성공률(85.0% / 68.3%)의 76% / 59% |
| 시간 히스토리 제거 | 중앙 −35.6%p, 0.6m 오프셋 −39.8%p — 가장 큰 단일 요인 |
| ego-motion 제거 | −10.4%p / −22.6%p; 잠재 회귀가 전체 상태 회귀보다 ~19%p 우위 |
| 행동 매칭 초기화 | 위치/속도 가중치 매핑 대비 +5.2%p |
| 지연 무작위화 | 전 테스트 지연에서 +5–11%p; +40ms에서 83.0%, +60ms에서 72.7% 유지 |
| 색상 증강 | 파랑/검정 상자 60.2%/61.2% → 88.0%/88.8% |
| 하중 / 크기(시각) | 0.5–2kg: 77.7–91.2%; 소형 25.5% / 대형 39.7%(닿지만 못 잡음—크기 맹인 제어기) |
| 검출 + 칼만 대비 | 동일 검출기 상태 파이프라인 대비 범위 내 13개 조건 전부 승리(+5.0–15.6%p) |
| 하류 데모 | 65% 포착 → 35% 운반 → 30% 전달 → 25% 복귀(20회) |

주요 한계: 장거리 그라운딩—5m 투척은 학습보다 빠르고 Stage 3 데이터 밖(시각 43.0% vs 특권 79.7%); Stage 3에 원거리 투척 추가 시 시뮬레이션 5m가 75.8%로 상승(하드웨어 미검증).

## 소프트웨어 엔지니어를 위한 시사점

- **지각과 제어 분리**: 특권 상태로 압축 잠재 인터페이스를 먼저 학습하고, 제어기를 고정한 채 센서에서 회귀시키면 렌더링 비용 ~19배 절감—시각 기반 로봇 정책의 재사용 가능한 레시피
- **히스토리와 ego-motion이 하중을 짊어짐**: 단일 프레임 지각은 ~36–40%p 손실; 온보드 카메라가 로봇과 함께 움직이면 ego-motion을 명시 입력하거나 ~10–23%p 지불
- **하드웨어가 가할 것을 무작위화**: 학습 중 지연 무작위화가 실전급 지연에서 5–11%p 회수; 실제 파이프라인 지연(여기 중앙값 69ms)을 측정해 그 안에서 학습
- **차단과 유지를 구분**: 비표준 크기 상자에 닿았지만(차단 58–86%) 못 잡음—지각·차단·안정화 실패를 분리하는 지표 설계가 진단을 빠르게 함
- **저렴한 강건성 via 증강**: 색상 증강만으로 최악 외형 케이스 해결(60% → 88%), 디코더 손대지 않음
