# SteerDistill: 폐루프 교사 스티어링으로 LLM 에이전트 양자화하기

**원문**: [arXiv:2611.13410](https://arxiv.org/abs/2611.13410) · **게시일**: 2026-11-10

## 개요

저비트 양자화는 LLM 에이전트의 추론 비용을 줄여 주지만, 양자화된 에이전트는 특유의 방식으로 실패한다. 저자들이 실패 롤아웃을 분석한 결과, 양자화된 학생 모델은 과업 요구 사항이나 환경 조건을 놓쳐서 환경 전이가 성공한 풀프레시전 참조와 어긋나며, 논문은 이 불일치를 행동 발산(behavioral divergence)이라 부른다. 실패 양상은 사소해 보이지만 치명적이다. 읽기 도구가 현재 디렉터리의 파일만 다룰 수 있는데도 디렉터리에 들어가기 전에 파일을 읽으려 하거나, 요청된 파일을 만들면서 지정된 내용을 쓰지 않고 비워 두는 식이다.

기존 방법으로는 이 발산을 고치기 어렵다. 오프라인 증류 데이터는 학생의 상호작용과 무관하게 수집되므로 학생이 실제로 실패하는 맥락을 놓치고, 학생 자신의 롤아웃에서는 바로 그 맥락에서 올바른 응답이 거의 나오지 않는다. SteerDistill의 답은 교사를 루프에 넣은 양자화 인지 증류다. 실패한 롤아웃마다 풀프레시전 교사가 학생을 스티어링해 결정을 수정하게 하고, 수정된 행동을 실행한 결과를 관찰하며, 교정이 로컬에서 검증될 때까지 안내를 다듬는다. 이것이 폐루프(closed-loop) 교사 스티어링이다.

방법은 두 부분이다. 교사 스티어링 궤적 수정 단계에서는 환경 전이를 기준으로 학생과 참조 궤적을 정렬해 첫 번째 행동 발산 지점에 개입하고, 교사가 놓친 조건과 교정 규칙을 명시한 구조화된 스티어링 프롬프트를 제공하면 얼린 학생 모델이 오류 직전 상태부터 재시도한다. 실행 결과의 환경 상태를 참조와 비교해 검증하며, 검증된 교정은 전체 과업이 결국 실패해도 증류용으로 남긴다. 행동 내재화 단계에서는 어떤 안내도 없이 학생을 학습시킨다. 교정된 턴에서는 스티어링된 학생의 예측을 순전 방향 KL로 맞추고, 나머지 턴에서는 풀프레시전 교사의 예측을 역방향 KL로 맞춰, 추론 시 교사도 스티어링 프롬프트도 필요 없게 만든다.

다섯 개 에이전틱 벤치마크와 세 모델에서 SteerDistill은 W4A16 기준 최강 양자화 베이스라인을 평균 점수 1.67~2.18점 넘어서면서 BF16과 1점 이내에 머문다. Qwen3-8B에서는 W4A16 평균 53.18로 QeRL보다 2.18점 높고 BF16 참조와 0.36점 차이에 그친다. τ²-Bench에서는 QeRL보다 성공률이 1.84%포인트 높으면서 학습 GPU 시간은 67% 적게 썼다.

## 핵심 내용

- 양자화 에이전트의 실패는 일반적인 능력 저하가 아니라 행동 발산이다. 과업 요구나 환경 조건을 놓치는 순간 환경 전이가 성공 참조와 갈라진다.
- 개입 지점은 첫 번째 행동 발산이다. 궤적을 환경 상태 기준으로 정렬해 찾으며, 같은 전이를 만드는 행동은 동등하게 취급한다. 무작위 턴 개입은 BFCL V4 점수가 43.52로 떨어져 이 선택을 뒷받침한다.
- 교사는 불일치 설명, 적용 조건, 교정 규칙을 담은 구조화된 스티어링 프롬프트를 제공하고, 얼린 학생이 오류 직전 이력과 상태에서 응답을 다시 만들게 한다.
- 모든 수정은 참조의 환경 상태와 비교한 로컬 검증을 통과해야 남는다. 로컬 검증을 빼면 BFCL V4에서 46.84에서 42.18로 4.66점 무너진다.
- 내재화는 라우팅을 나눈다. 교정된 턴은 안내를 받은 스티어링 학생을 순전 방향 KL로 따르고, 나머지 턴은 풀프레시전 교사를 역방향 KL로 따르며, 추론에는 프롬프트가 없다.
- W4A16 결과: Qwen3-8B 평균 53.18(QeRL 대비 +2.18, BF16 대비 −0.36), Qwen3.5-4B는 QeRL 대비 +1.71, Gemma 4 12B-it는 +1.67로 세 모델 모두 BF16과 1점 이내다.
- 낮은 정밀도에서도 이득이 유지된다. Qwen3-8B에서 W4A8은 QeRL 대비 +1.93, W2A16은 On-Policy QAD 대비 +3.39다.
- 학습 효율(τ²-Bench, A100 80GB 8장): 32 GPU시간 체크포인트에서 Pass@1 31.68%로, 약 40 GPU시간에 수렴하는 On-Policy QAD의 최종 점수보다 2.91%포인트 높다.
- 성공 궤적도 짧다. 성공 과업당 평균 출력 토큰이 4.0K로 양자화 베이스라인의 4.1K~5.2K보다 적고(BF16은 3.9K), 상호작용 단계와 도구 호출 수도 적다.

## 세부 사항

- BFCL V4(Qwen3-8B, W4A16) 절제 연구에서 전체 방법은 46.84로 BF16 46.89, On-Policy QAD 44.43에 근접한다.
- 개입 전략 비교: 안내 없는 학생 재시도 44.46, 교사가 직접 대신 수행하는 방식 45.06에 못 미친다. 교정은 학생 스스로 만들어야 학습 가능한 행동이 되기 때문이다.
- 스티어링 프롬프트는 교사의 구조화된 형식이 최선이다. 교사 자유 형식 44.78, 학생 생성 구조화 프롬프트 41.74로 나쁘고, 외부 교사 GPT-5.6-Sol을 구조화 소스로 쓰면 45.27이다.
- 교정 보존: 로컬 검증만 적용한 기본값 46.84가 최종 성공 궤적만 남기는 변형 46.30보다 낫다. 실패했지만 교정된 궤적에도 쓸 수 있는 감독 신호가 있기 때문이다.
- 증류 라우팅도 중요하다. 역방향 KL 전용 45.29, 순전 방향 KL 전용 44.58로 모두 기본값보다 낮다. 논문의 유일한 벤치마크 예외는 W2A16 Search QA로 BitDistiller가 34.22로 SteerDistill 34.05보다 높다.
