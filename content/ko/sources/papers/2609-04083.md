# CORE: 리랭커 증류로 MLLM 임베딩의 구성 추론 개선하기

출처: Tingyu Song 외 7인, arXiv:2609.04083, 2026-09-03.

**핵심 요약**: MLLM 기반 임베딩 모델은 구성적 검색에 약합니다 — 같은 개념들이지만 속성-객체 결합이 다른 장면을 구분 못 합니다. 그런데 *같은 백본*을 교차 주의 리랭커로 쓰면 구분이 됩니다. **CORE**는 리랭커의 구성 판단을 임베딩 모델에 증류합니다. 5개 구성 매칭 수준에 걸친 후보 리스트를 합성하고, 리랭커의 세밀 순위를 재현하는 **Rank-KL** 목적함수로 학습합니다. 동일 데이터·동일 튜닝 예산에서 리스트형 Rank-KL과 쌍대 CoSENT가 대조 학습보다 다단계 supervision을 잘 쓰며, Rank-KL이 전체 최강입니다.

## 결과가 보여주는 것

| 모델 | 결과 |
|---|---|
| CORE-RERANKER-8B | COLA·SUGARCREPE++·NEGBENCH 총평균 **82.7%** — Jina-Reranker 대비 **+10.7점** |
| CORE-EMBED-8B | 총평균 **0.666** — 평가 임베딩 중 최고 |
| 전이 | MCMR로 이득 전이, COCO·Flickr30K 검색 성능 희생 없음 |

등급 평가 프로토콜(이진 정/오답 대신 5단계 매칭 수준)도 기여의 일부입니다. supervision을 조밀하게 만들어 리스트형 증류가 먹히게 합니다.

## 주의할 점

arXiv 초록·메타데이터 기반 요약이며 5개 매칭 수준·Rank-KL 수식·벤치별 표는 전문 대조 없이 재구성 대신 생략했습니다. 임베딩 점수(0.666)는 벤치마크 평균이라 평가 체계가 다르면 직접 비교 불가합니다.

## SW 엔지니어와의 관련성

- "빨간 큐브 위 파란 구"와 "파란 큐브 위 빨간 구"를 혼동한다면, 더 큰 임베딩보다 자기 리랭커에서의 증류가 답일 수 있습니다.
- supervision이 등급이면 대조보다 리스트형이 낫습니다 — 네거티브 늘리기 전에 다단계 라벨에 투자하세요.
- 학습 목적함수 비교는 데이터·튜닝 예산을 맞춰야 합니다. 아니면 방법 차이 아니라 예산 차이를 재는 겁니다.
- 일반 검색(COCO/Flickr30K) 무회귀를 확인하세요 — 일반 검색을 갉아먹는 구성 이득은 승리가 아니라 교환입니다.
