# 편집 가능한 시각 디자인

출처: Junyan Ye 외 11인, arXiv:2609.04034, 2026-09-03 (v2 2026-09-04).

**핵심 요약**: 확산 베이스 모델(GPT-Image-2·Nano-Banana급)은 시각 표현력이 뛰어나지만 납작한 비트맵에 텍스트 오류가 잦아 레이어별 후편집이 불가능합니다. 반면 코딩 에이전트 경유 코드 기반 시각 생성은 정밀 레이아웃 제어와 분리 레이어를 주지만 전체 미적 직관이 없고 복잡한 시각 자산 코딩이 어렵습니다. **편집 가능한 시각 디자인**은 역할을 나눕니다. VLM이 요구 이해·과제 계획·미적 판단을 맡는 **창작 두뇌**이고, 이미지 모델은 독립 시각 자산을 합성하는 주문형 **시각 세계 시뮬레이터**입니다. **상상 후 행동** 폐루프에서 에이전트는 분리 자산을 만들고 네이티브 HTML/CSS를 쓴 뒤 렌더링 피드백에 맞춰 반복 정제합니다.

## 루프의 동작 방식

| 역할 | 책임 |
|---|---|
| VLM(창작 두뇌) | 요구 이해, 디자인 과제 계획, 렌더링 기반 미적 판단 |
| 이미지 모델(세계 시뮬레이터) | 주문형 독립 시각 자산 합성 |
| 에이전트 루프 | 자산 생성 → 네이티브 HTML/CSS 작성 → 렌더링 → 시각 피드백 정제 |

최종 산출물은 분리 레이어와 실제 텍스트라 GUI에서 마우스 드래그·레이아웃 조정이 됩니다. **에이전트 디자인 리플레이**는 전문 인간 디자이너처럼 창작·추론 궤적까지 충실히 재현합니다. 포스터·인포그래픽 등 검증에서 정제된 미학과 제품급 편집성을 함께 달성합니다.

## 주의할 점

arXiv 초록·메타데이터 기반 요약이며 전문을 절별 검증하지 않아, 정량 평가 수치·베이스라인명·사용자 연구 세부 등은 보고하지 않습니다. 미학·편집성 주장은 초록에 진술된 저자 주장입니다.

## SW 엔지니어와의 관련성

- 강점별 분업으로 만드세요. 구조·취향은 추론/계획 모델에, 픽셀은 이미지 모델에 — 하나에 둘 다 시키지 마세요.
- 납작 픽셀이 아니라 편집 가능한 중간 표현(HTML/CSS·레이어)을 내보내세요. 편집성은 보너스가 아니라 납품물입니다.
- 렌더→판단→정제의 폐루프 시각 피드백이면 기성 부품만으로 일발 생성기가 디자인 에이전트가 됩니다.
- 창작 도구엔 궤적 재생이 필요합니다. 사용자는 최종물뿐 아니라 과정을 보고 분기해야 합니다.
