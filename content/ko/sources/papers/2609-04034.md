# Editable Visual Design

: Diffusion base models (GPT-Image-2, Nano-Banana class) are visually expressive but emit flattened bitmaps with error-prone text — no layer-wise post-editing. Code-based visual generation via coding agents gives precise layout control and decoupled layers but lacks global aesthetic intuition and struggles to code complex visual assets. **Editable Visual Design** splits the roles: the VLM is the **creative brain** (requirement comprehension, task planning, aesthetic judgment) while the image model is an on-demand **visual world simulator** synthesizing standalone assets. Under an **imagine-first-then-act** closed loop, the agent generates isolated assets, writes native HTML/CSS, and iteratively refines against rendered visual feedback.

How the loop works: Role  Responsibility 
------
 VLM (creative brain)  Understands requirements, plans the design task, judges aesthetics from renderings 
 Image model (world simulator)  Synthesizes standalone visual assets on demand 
 Agent loop  Generates assets → writes native HTML/CSS → renders → refines against visual feedback 

The final artifact has decoupled layers and real text, so users can drag elements and adjust layouts in a GUI. Agent Design Replay additionally reproduces the creative and reasoning t

Caveats: This summary is based on the arXiv abstract and metadata; the full text was not verified section by section, so no quantitative evaluation numbers, baseline names, or user-study details are reported here. Claims about aesthetic quality and editability are the authors' as stated in the abstract.

Relevance to SW engineers: - Decompose generation by strength: reasoning/planning models for structure and taste, pixel models for assets — don't ask one model to do both.
- Emit editable intermediate representations (HTML/CSS, layers) instead of flat pixels; editability is a deliverable, not a bonus.
- Closed-loop visual feedback (render → judge → refine) turns a one-shot generator into a design agent with commodity components.
- Replayable trajectories matter for creative tools: users need to see and fork the process, n
