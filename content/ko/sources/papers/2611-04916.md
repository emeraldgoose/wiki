# Video Generation 그 너머: Kling으로부터의 Multimodal Understanding 관찰과 통찰

**원문**: [arXiv:2611.04916](https://arxiv.org/abs/2611.04916) · **게시일**: 2026-11-03
**저자**: Kling Team과 다수 협업자

## 개요

비디오 생성은 개별 클립에서 coherent한 짧은 오디오비디오 시퀀스로 발전했고, 병목은 렌더링에서 의미적 control로 옮겨가고 있다. 이 보고서는 연속된 Kling 세대에서 얻은 multimodal understanding 관찰과 통찰을 요약한다. 생성 품질은 전체 data, conditioning, alignment, evaluation chain을 통해 multimodal understanding이 project된 결과라고 주장하며, chain을 module별로 점검한다. Kling-MLLM은 image, video, audio, synchronized audio-video, interleaved input을 통합하는 공유 multimodal foundation model이고 downstream module별로 특화된다.

## 핵심 내용

- 비디오 생성 품질은 전체 chain의 multimodal understanding에 의존한다.
- 캡셔닝은 description density를 극대화하는 semantic contract로 다뤄진다.
- reference-grounded captioning은 reference binding을 명시적으로 만든다.
- prompt enhancement는 user intent를 caption distribution으로 번역한다.
- 신뢰할 수 있는 text encoder는 더 강한 language ability가 아니라 perceptual training에서 온다.
- reward modeling은 설명 가능한 critique와 빠른 multidimensional scoring을 결합한다.

## 상세

보고서는 캡셔닝 확장, prompt enhancement 훈련, 인코더 특화, reward-model 설계, task-specific automatic evaluation을 다룬다. basic prompt enhancement는 compelling videos의 captions에서 derive되고 text-level, generator-in-the-loop RL로 정제되며, agentic PE는 스토리를 정제하고 example을 retrieve한다. scoring shortcut을 노출하고 failure를 upstream source로 추적하는 평가 프로토콜도 강조된다. 이는 실용 guidance에 가까워 underlying products and data pipelines를 고려해야 한다.
