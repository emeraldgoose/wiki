# Recursa: 재귀적 자기개선 파운데이션 모델 시스템으로

**원문**: [arXiv:2611.04035](https://arxiv.org/abs/2611.04035) · **게시일**: 2026-11-02
**저자**: Erkang Zhu, Yin Lin, Xiaorong Shi, Xuanrui Lin, Jingren Zhou

## 개요

Foundation 모델은 변하는 환경에서 원래 훈련에 없는 낯선 도메인 지식을 만날 수 있다. 새로운 도메인은 보통 전문가 생성 대규모 훈련 데이터나 신뢰할 만한 지도 신호를 제공하지 않는다. Recursa는 인간 전문가나 더 강한 교사 모델 없이 자신의 경험으로 새로운 도메인에 적응한다. 지식 저장소는 학습된 도메인별 기술, 적용 규칙, 과거 작업 기억, 개선점 성찰을 보관한다. Recursa는 도메인 자료에서 저장소를 부트스트랩한 뒤 재귀적 자기개선을 통해 정제한다. 병렬 학습자가 작업을 실행하고 국소 개선을 합성하며, 검증 후 저장소에 병합한다.

## 핵심 내용

- 인간 전문가나 더 강한 교사 없이 적응한다.
- 지식 저장소는 기술, 적용 규칙, 기억을 보관한다.
- 도메인 자료로 초기 지식 저장소를 구성한다.
- 재귀적 자기개선으로 저장소를 정제한다.
- 병렬 학습자가 국소 개선을 합성한다.
- 검증과 병합이 무단 저장소 표류를 줄인다.

## 상세

Harvey LAB Firm Knowledge 벤치마크에서 Recursa는 held-out 테스트 작업 all-pass rate을 DeepSeek-V4.1-Flash에서 30.0%에서 55.0%로, Qwen3.8-Flash에서 35.0%에서 46.0%로 높였다. 이 이득은 벤치마크별이며, 검증이 약하면 자율 개선이 오류나 과적합을 도입할 수 있다. 그럼에도 저데이터 환경에서 자신의 경험으로 도메인 격차를 좁힐 수 있음을 보여준다.
