# Muir: sensitivity-allocated gating과 matched-filter readout을 갖는 linear attention

**원문**: [arXiv:2611.08376](https://arxiv.org/abs/2611.08376) · **게시일**: 2026-11-05
**저자**: Tushaar Gangavarapu, Gil Tabak, Clemens JS Schaefer

## 개요

linear attention은 context를 fixed-size key-value state로 compress해 linear-time training과 constant-memory inference를 가능하게 한다. gated delta-rule models는 state를 decay하고 incoming key에 대해 prediction을 erase한 뒤 new value를 write한다. Gated DeltaNet-2는 channel-wise decay와 decoupled full-rank erase/write gates로 이를 generalize한다.

Muir의 analysis는 state updates가 erasure보다 writes에 far less sensitive함을 보인다. key activation과 unit normalization이 key energy를 sparse channels에 concentrate시키는 반면 value writes는 all channels를 scale하므로 erasure gate는 lower rank로 parameterize될 수 있다. 또한 slow-decaying state rows는 fast rows보다 much larger norms를 accumulate해 unweighted readout을 dominate하고 interference suppression을 위해 stronger write-time erasure를 강제한다.

Muir는 따라서 all gates를 sensitivity-allocated low-rank projection으로 fuse하고 matched-filter readout gate로 state rows를 re-weight하며 saved parameters를 wider feed-forward network에 reinvest한다. 또한 large chunk size에서 stable efficient training을 위한 parallel update를 design한다. across 166M-1.34B parameters에서 Muir는 GDN-2와 Transformer 대비 perplexity를 lower하고 commonsense accuracy를 높이며 extractive recall을 improve하고 throughput을 match한다.

## 핵심 내용

- gated linear attention에서 erasure와 write의 sensitivity asymmetry를 분석한다.
- fused low-rank projection으로 sensitivity를 allocate한다.
- matched-filter readout으로 state rows를 re-weight한다.
- saved parameters를 wider feed-forward network에 reinvest한다.
- large chunks를 위한 stable parallel update를 구현한다.
- scale에서 perplexity, commonsense accuracy, recall, training speed를 개선한다.

## 상세

Muir는 1.34B парамет에서 4K training length에서 10M-token streams로 perplexity drift 없이 extrapolate하고 static readout으로 1M tokens까지 near-100% passkey retrieval을 maintain한다. GDN-2 throughput을 match하고 validation loss에 더 빨리 도달한다.
