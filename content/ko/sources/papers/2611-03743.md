# EvoMemState: 개인화 에이전트를 위한 진화하는 메모리 상태

**원문**: [arXiv:2611.03743](https://arxiv.org/abs/2611.03743) · **게시일**: 2026-11-02
**저자**: Zhishang Xiang, Yunbo Tang, Zhongqiao Liu, Junkai Chen, Zerui Chen, Qingguo Hu, Yuxuan Zhang, William Grant, Qinggang Zhang, Jinsong Su

## 개요

장기 메모리는 대형 언어 모델 personal agent가 상호작용 전반에 걸쳐 사용자 정보를 유지해 연속적인 personalized assistance를 제공하게 한다. 기존 시스템은 fact extraction, organization, updating, retrieval로 이를 지원하지만 메모리를 독립 사실로 주로 유지한다. 이런 fact-centric paradigm은 새 fact가 이전 fact를 업데이트, 제약, 충돌시키는 방식과 현재 요청에 대한 applicability, role, priority를 암묵적으로 남길 수 있다.

EvoMemState는 persistent facts에 두 개의 보완 상태를 더하는 state-centric 프레임워크를 제안한다. 사실들이 시간이 지나며 어떻게 유효하고 서로 관련되는지를 포착하는 relational state와 현재 요청에 사실을 어떻게 적용할지 결정하는 reasoning state가 그것이다. 세 구성요소로 구현한다: ontology-guided memory state induction이 persistent fact를 추출하고 relational state를 구성하며, RL-based state evolution이 reinforcement learning으로 요청 특정 reasoning state 생성을 학습하고, state-aware reasoning이 fact, relational state, reasoning state를 결합해 에이전트를 안내한다.

장기 대화와 memory-use benchmarks에서 기존 메모리 시스템보다 retrieval completeness와 memory-grounded response accuracy가 일관되게 개선된다.

## 핵심 내용

- 장기 메모리를 독립 fact로 유지하는 방식의 한계를 지적한다.
- 사실 간 유효성과 진화하는 관계를 포착하는 relational state를 추가한다.
- 각 요청에 fact를 적용하는 reasoning state를 추가한다.
- ontology-guided induction으로 persistent fact와 relational state를 구축한다.
- reinforcement learning으로 요청 특정 reasoning state를 생성한다.
- retrieval completeness와 memory-grounded response accuracy를 개선한다.

## 상세

프레임워크는 상호작용 전반의 연속 personalized assistance를 지원하기 위한 motivation으로 제시된다. code와 implementation detail이 제공된다. 정보 검색과 artificial intelligence가 관련 subject area이다.
