# 실시간 게임 에이전트를 위한 장시간 범용 비전-언어-행동 파운데이션 모델 Gamer

**원문**: [arXiv:2611.18397](https://arxiv.org/abs/2611.18397) · **게시일**: 2026-11-13
**저자**: Run Luo, Kuan Zhang, Qi Deng, Yukun Chen, Zhihao Yang, Yufei Zhang, Renrong Hu, Yi Zhang, Guiyu Ma 외 (프로젝트 페이지: https://mihoyo-gamer.github.io/)

## 개요

Gamer(v2, 2026-11-13/17)는 장시간 과업에 특화된 범용 시각-언어-행동 파운데이션 모델이다. 특히 게임이라는 복잡한 상호작용 환경을 대상으로 하며, 기존 2D 그래픽 인터페이스와 복잡한 3D 시뮬레이션 세계 모두를 하나의 학습·배포 파이프라인으로 다룬다. 엔드투엔드 아키텍처는 지각, 기억 관리, 다단계 추론을 결합한다.

이 논문이 추구하는 핵심 통찰은 단순해 보인다: 게임과 물리 시뮬레이터에 풍부한 키보드와 마우스 상호작용 궤적 데이터도, 데이터를 충분히 쌓고 학습 알고리즘을 제대로 씌우면 강력한 범용 정책을 지원할 수 있다는 것이다. 모델은 먼저 수만 시간의 장치 수준(디바이스 레벨) 키보드·마우스 상호작용 데이터를 이어서 학습(continue pre-training)하며, 물리 세계와 가상 세계의 환경 동작을 함께 학습한다.

그 위에 세 가지 층을 쌓았다. 첫째, 희소 추론 튜닝(sparse-thinking instruction tuning)은 불필요한 연산을 대폭 줄이면서도 복잡한 결정에 필요한 추론 품질을 보존한다. 둘째, 안정한 다단계 강화학습(Temporal-Aware GRPO)으로 장시간 정책을 학습한다. 유한한 컨텍스트 윈도우, 누적 롤아웃 오류, 희소 보상이라는 문제를 명시적으로 다룬다. 셋째, 실시간 상호작용을 위해 클라우드-에지 추론 엔진(Streaming-vLLM)이 여러 게임 환경을 동시에 서비스하고, 무제한 컨텍스트 실행을 지원하며, 온라인 추론 지연 시간을 낮게 유지한다.

여러 도전적인 3D 오픈 월드 게임에서 Gamer는 숙련된 플레이어에 필적하는 일반화 성능과 실행 효율을 보이고, 기존 2D 게임 벤치마크에서도 경쟁력 있는 결과를 낸다.

## 핵심 내용

- 하나의 일반 모델, 두 환경: 동일한 아키텍처와 학습·배포 파이프라인이 기존 2D 게임과 3D 시뮬레이션 세계 모두를 지원한다.
- 데이터 전략: 시뮬레이션 게임과 물리 환경의 장치 수준 키보드·마우스 궤적 수만 시간을 이어서 학습해 물리·가상 세계 간 공유 동작을 학습한다.
- 통합 관측-행동 표현, 궤적 디바이싱(수정)과 시간 가중 재샘플링이 교차 게임 일반화와 학습 스케일링 법칙을 가능하게 한다.
- 희소 추론 튜닝: 매 단계마다 장시간 사고 사슬(CoT)을 내보내는 대신 상황만 추론을 내보내, 실시간 제어에 적합한 추론 비용을 유지한다.
- 장시간 RL(Temporal-Aware GRPO): 시간 가중 크레딧 할당, 검증 가능한 보상, 관측-행동 공동 정책 업데이트를 통해 유한 컨텍스트, 누적 오류, 희소 보상을 다룬다.
- 서빙: 스트리밍 vLLM 클라우드-에지 엔진이 여러 게임 인스턴스에 동시에 추론을 제공하며, 무제한 컨텍스트를 스트리밍하고 실시간 플레이에 적합한 낮은 지연 시간을 유지한다.

## 상세

파이프라인은 네 단계로 이뤄진다. 이어서 학습 단계는 원시 장치 수준 상호작용에서 통합 관측-행동 표현을 학습한다. 인간의 게임 플레이 로그에 치우친 행동과 맥락을 보정하기 위해 궤적 디바이싱과 시간 가중 재샘플링을 적용하고, 교차 게임 일반화를 위한 스케일링 법칙을 연구한다. 게임을 더 많이, 더 오래 볼수록 일반화가 더 좋아지며, 두 축을 함께 쓸 때가 더 낫다.

지도 미세 조정은 모델이 필요할 때만 추론을 내보내도록 가르친다(다단계 작업 조건화). 매 단계마다 긴 사고 사슬을 내뱉지 않으므로 단계당 추론 비용이 실시간 제어에 적합하고, 30 fps 이상의 실시간 플레이가 가능하다. 기억 모듈(다중 맥락 기억)은 턴 사이에 필요한 기록을 보존해 유한 컨텍스트 윈도우가 장시간 과업을 방해하지 않도록 한다.

RL 단계는 장시간을 명시적으로 겨냥한다. 표준 정책 경사는 여기서 실패한다. 컨텍스트는 유한하고, 롤아웃 오류가 누적되며, 보상은 희소하다. 시간 가중 GRPO는 궤적 전체에 걸쳐 크레딧을 시간 단위로 할당하고, 게임 메커니즘이 허락하는 곳에서는 검증 가능한 보상을 사용하며, 관측-행동 정책을 함께 업데이트해 계획과 실행이 함께 개선되게 한다.

서빙 단계에서 저자는 스트리밍 vLLM 클라우드-에지 엔진을 구축했다. 여러 시뮬레이션 게임 인스턴스에 병렬로 추론을 돌리고, 슬라이딩 윈도우 메모리 손실을 피하기 위해 무제한 컨텍스트를 스트리밍하며, 상호작용 세션에 적합하게 지연 시간을 낮게 유지한다. 이 시스템 작업이 모델을 오프라인 벤치마크 대상이 아니라 실시간 플레이어로 쓸 수 있게 해 준다.

결과: 여러 3D 오픈 월드 게임에서 Gamer는 숙련된 인간 플레이어에 필적하는 일반화 성능과 실행 효율을 보이고, 2D 벤치마크에서도 경쟁력 있다. 저자는 이를 반복적이고 낮은 수준의 궤적(클릭, 이동, 카메라 움직임)만으로도 강력한 범용 모델을 학습할 수 있다는 증거로 읽는다. 이는 디지털-물리 전이에도 직접 연결되는 결과다. 이러한 궤적은 로봇 원격 조작 기록과 매우 흡사하기 때문이다.
