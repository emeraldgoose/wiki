# 주어진 증거에서 수집한 증거로: 종단 의료 추론을 위한 에이전트 학습

출처: Minye Shao 외 8인, arXiv:2609.39566, 2026-09-30.

**핵심 요약**: 파운데이션 모델은 도구 사용 하네스를 통해 임상 에이전트가 될 수 있습니다. 그러나 기존 의료 벤치마크는 임상 기록과 종단 영상을 가로질러 증거를 **찾는 능력**이 아니라 **미리 선택된 증거에 대한 추론**을 평가합니다. 이 논문은 **CASE**를 제안합니다. 증거를 찾는 역할별 임상 에이전트 시리즈, 도구 사용 하네스, 소형 비전-언어 정책 모델을 위한 에이전트형 사후학습 프레임워크입니다.

## 벤치마크

UK Biobank 기반의 종단 멀티모달 벤치마크를 만들었습니다. **4,739명 참가자**의 실제 ICD-10 진단에서 파생한 **50,401개 임상 질문**으로 구성됩니다. 각 질문은 임상 맥락과 기저·추적 방문의 다중 시퀀스 MRI를 담은 환자별 환경에 연결되며, 에이전트는 어떤 방문·장기·모달리티·슬라이스·전문 도구를 검사·비교할지 스스로 고릅니다.

## 훈련과 결과

147,434개의 프런티어 모델 상호작용 궤적으로 증거 탐색 워크플로를 지도 미세조정하고, 학습자 자신의 환경 상호작용에 에이전트형 강화학습을 적용했습니다. 특권 온폴리시 자기 증류와 루브릭 기반 LLM 피드백이 도구 순서를 규정하지 않고 증거→결론 추론을 다듬습니다. 동일 평가 조건에서 Qwen3-VL-8B-Instruct 기반 에이전트는 **GPT-5.4 대비 16% 이상, Claude Opus 4.8 대비 10% 이상** 답변 정확도 상대 개선을 보였습니다.

## 주의할 점

이 글은 초록을 바탕으로 정리했습니다. UK Biobank 코호트 특성상 인구·질환 편향이 있고, 벤치마크 성능은 임상 유효성이 아닙니다. 규제·개인정보·책임 문제와 실제 병원 워크플로 통합은 별도 검증이 필요합니다.

## SW 엔지니어와의 관련성

- 의료 에이전트 평가는 정답 QA가 아니라 **어떤 기록·영상·도구를 선택했는지**까지 봐야 합니다.
- 증거 탐색 정책을 SFT로 옮기고, 이후 자기 환경 상호작용으로 RL을 돌리는 2단계 구성이 재사용 가능한 패턴입니다.
- 도구 순서를 강제하지 않되 루브릭으로 결론의 근거 충실성을 채점하세요.
