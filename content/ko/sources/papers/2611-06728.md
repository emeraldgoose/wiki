# Turns Matter: turn-level credit으로 스트리밍 비디오 RL 전진

**원문**: [arXiv:2611.06728](https://arxiv.org/abs/2611.06728) · **게시일**: 2026-11-04
**저자**: Shuai Dong, Kanghui Tian, Linghan Chen, Wenqi Shao, Hongrui Wu, Haowen Hou, Yongfu Zhu, Xuehui Wang, Ziyue Wang, Wenpu Liu, Weichu Xie, Yuqi Xu, Congcong Wang, Kaiwen Tuo, Caoyuan Ma, Taiqiang Wu, Ji Zhao, Wenzheng Chang, Dianyi Wang, Siyuan Wang, Zhongyu Wei, Yu Qiao, Jiaqi Wang

## 개요

스트리밍 비디오 이해는 모델이 respond할지 continue observing할지를 반복적으로 decide해야 한다. 최근 GRPO가 this setting에 applied되었고 existing approaches는 reward design을 emphasize하지만 turns 전반에 걸쳐 single trajectory-level advantage를 retained한다. 이런 shared credit은 earlier successes 후 redundant replies를 reinforce할 수 있고 earlier failures 후 useful follow-ups를 discourage한다. 논문은 TurnWise를 propose하며, 이는 individual streaming decisions와 align하는 turn-level GRPO framework이다. trajectory-level feedback과 turn-level interaction 사이 mismatch를 addresses하고 informative responses를 promote하며 redundancy를 reduce한다. specifically, turn-level credit assignment은 silence-completed prefix scoring를 사용해 each decision's remaining return으로부터 group-relative advantages를 construct하여 learning signal을 earlier rewards로부터 separates한다. turn-mean policy optimization은 each turn 내 token losses average하고 turns across averages하여 output length와 무관하게 response/waiting decisions에 equal weight를 부여한다. complementary designs는 learned critic 또는 additional rollouts 없이 streaming policy learning을 improve한다. extensive experiments에서 method는 prior RL approaches for streaming video understanding를 outperforms한다.

## 핵심 내용

- 스트리밍 비디오는 respond vs continue를 turn마다 결정해야 한다.
- trajectory-level GRPO credit은 redundancy를 reinforce하고 follow-up을 suppress할 수 있다.
- TurnWise는 turn-level credit으로 learning을 align.
- silence-completed prefix scoring로 remaining return 기반 advantages.
- turn-mean optimization으로 output length와 무관하게 response/waiting 균등 weighting.

## 상세

approach는 learned critics/additional rollouts를 피한다. streaming video understanding tasks에서 평가한다. full training/stability/benchmark details는 연결된 원문을 참고한다.
