# 복잡도 클래스

**요약:** 복잡도 클래스는 문제 해결·검증에 필요한 자원(시간, 공간, 무작위성)에 따라 결정 문제를 묶은 분류이다. 핵심은 **P**(다항 시간에 풀 수 있음)와 **NP**(다항 시간에 검증할 수 있음)의 구분이며, 둘의 동일 여부는 컴퓨터과학 최대의 미해결 문제이다. 엔지니어 관점의 실용적 가치는 **NP-완전** 문제를 알아보고, 정확한 다항 알고리즘 찾기를 멈추고 근사·휴리스틱·매개변수 접근으로 전환하는 것이다.

## 정의

- **결정 문제:** 입력에 대한 yes/no 질문(예: "이 그래프에 해밀턴 사이클이 있는가?"). 복잡도 이론은 튜링 머신에서의 자원 한도로 이를 분류한다.
- **P:** 다항 시간 O(n^k)에 풀리는 문제. "다루기 쉬움(tractable)"의 실무적 정의.
- **NP:** *yes* 답에 대한 인증서(certificate)를 다항 시간에 검증할 수 있는 문제. *비결정적* 머신에서 다항 시간에 풀리는 문제와 동치이다(NP = nondeterministic polynomial, "non-polynomial"이 아님).
- **NP-완전:** NP 중 가장 어려운 문제들. 모든 NP 문제가 다항 시간에 이들로 환원된다. 하나라도 다항 알고리즘이 나오면 NP 전체가 P로 붕괴한다.
- **NP-난해(hard):** NP-완전 이상으로 어렵지만 NP에 속하지 않을 수도 있음(주로 최적화 버전, 예: "최단 투어 찾기" vs "k보다 짧은 투어가 있는가?").
- **NP 너머:** PSPACE(다항 공간), EXP(지수 시간), BPP(오류 제한 무작위 다항 시간). P ⊆ NP ⊆ PSPACE ⊆ EXP 관계가 알려져 있다.

## 왜 중요한가

- **헛수고를 막는다.** 스케줄링/패킹/라우팅 문제가 NP-난해임을 알면(예: 빈 패킹, 외판원, 그래프 색칠) 완벽한 고속 알고리즘 대신 ILP 솔버·근사 알고리즘·휴리스틱을 쓴다.
- **스케일링 절벽을 예측한다.** n=20에서 되던 O(2^n) 정확 알고리즘이 n=100에서 죽는 이유를 벤치마크 전에 설명한다.
- **암호학의 토대이다.** 현대 암호([[cryptography-basics]])는 특정 문제(소인수분해, 이산로그)가 어렵다는 가정 위에 서며, 복잡도 이론이 그 가정을 표현하는 언어이다.

## 동작 방식

### 다항 시간 환원

문제 A가 문제 B로 환원된다(A ≤ₚ B)란, A의 모든 인스턴스를 답을 보존하면서 다항 시간에 B의 인스턴스로 변환할 수 있다는 뜻이다. B가 쉬우면 A도 쉬워진다. *알려진* NP-완전 문제를 *자신의* 문제로 환원하면 자신의 문제가 NP-난해임이 증명된다.

### 대표 NP-완전 문제: SAT

- **SAT:** 불리언 식을 참으로 만드는 할당이 있는가? **쿡-레빈 정리**(1971)가 SAT가 NP-완전임을 최초로 증명했다(모든 NP 계산을 논리식으로 인코딩).
- **3-SAT**(각 절이 정확히 3개 리터럴)은 구조가 단순해 환원의 출발점으로 자주 쓰인다.
- 환원 사슬로 수천 개 문제가 NP-완전으로 증명되었다: 3-SAT → 독립집합 → 정점커버 → 해밀턴 사이클 → TSP 결정 버전.

### 구체적 예: 정점 커버

- **문제:** 그래프 G에 모든 간선을 건드리는 ≤ k개 정점 집합이 있는가?
- **인증서:** 그 집합 자체. O(|E|)에 검증 가능하므로 NP에 속한다.
- **난해성:** 정점 커버로부터의 환원(정점 커버의 여집합은 독립집합). 따라서 NP-완전.
- **실무 탈출구:** 선형 시간 2-근사(극대 매칭의 양 끝점 채택), O(2^k · n) 고정매개변수 알고리즘, 작은 k에 대한 분기한정법.

### 클래스 지형

```
P ⊆ NP ⊆ PSPACE ⊆ EXP        (모두 진부분집합으로 믿어지나 증명된 것은 P ≠ EXP뿐)
RP ⊆ BPP ⊆ PSPACE            (무작위 클래스)
```

- **새비치 정리:** NSPACE(s) ⊆ DSPACE(s²). 즉 NPSPACE = PSPACE — 비결정성은 공간을 최대 제곱만큼만 절약한다.
- **시간 위계 정리:** 시간을 더 주면 provably 더 많은 문제를 풀 수 있다(EXP에는 있고 P에는 없는 문제가 존재).

## 흔한 함정

- **"NP = non-polynomial, 항상 지수 시간."** 둘 다 틀렸다. NP는 nondeterministic polynomial이며, NP 문제 중 다수(최단 경로, 2-SAT, 매칭)는 P에 속한다.
- **"NP-난해 = 절망."** *최악 경우 정확 다항*이 어려울 뿐이다. 근사비(Christofides의 메트릭 TSP 3/2), 유사다항 DP(배낭 O(nW)), FPT 알고리즘이 실제 인스턴스를 잘 푼다.
- **"P vs NP는 해결됐거나 무의미하다."** 미해결(클레이 밀레니엄 문제)이며, P = NP라면 공개키 암호가 하룻밤에 무너진다.
- **결정 vs 최적화 혼동.** 결정 버전이 NP-완전이면 최적화 버전은 NP-난해이다. 어느 쪽인지 명시하라.
- **환원 방향 실수.** 자신의 문제 H가 어려움을 보이려면 *알려진 어려운* 문제를 *H로* 환원해야지 반대가 아니다.
